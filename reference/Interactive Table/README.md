# Interactive Table (Notion Simple Table 1:1 复刻工程)

本项目严格 1:1 复刻了所提供截图中的交互式表格（Notion 风格 Simple Table），实现了高还原度的视觉排版与完整的现代表格交互体系。

---

## 截图重点元素 1:1 对齐说明

| 截图标注位置 | 对应组件 / 控件 | 视觉样式与核心交互 |
| :--- | :--- | :--- |
| **左侧红色箭头** | **行操作手柄 (Row Handle)** | 位于表格左侧留白处，呈现为小胶囊形状的 `||` 双竖条图标。鼠标悬停或选中时浮现；点击可唤出操作菜单（向上/下插行、复制行、删除行、清空行）；同时支持拖拽悬停整行联动高亮。 |

## 交互功能特性一览

1. **单元格内联编辑 (Inline Editing)**：
   - 点击单元格即可直接输入修改。
   - `Tab`：向右移动到下一单元格；行末自动换到下一行首格；表格最后单元格按 `Tab` 自动追加新行。
   - `Shift + Tab`：向左逆向移动。
   - `Enter`：纵向向下移动到同列下一行单元格；最后一行按 `Enter` 自动追加新行。
   - `↑` / `↓`：在多行间灵活漫游。
2. **列宽动态自由调整 (Column Resizing)**：
   - 鼠标悬停在列与列之间的边框，光标转为 `col-resize`。
   - 按住拖拽可实时平滑改变列宽，顶部列柄与右侧添加条实时自动重对齐。
3. **右键 / 气泡上下文菜单**：
   - 点击列手柄 `-`：向左插入列、向右插入列、复制列、清空列、删除列。
   - 点击行手柄 `||`：向上插入行、向下插入行、复制行、清空行、删除行。
4. **一键快速增列 / 增行**：
   - 点击右侧贯穿条柱 `+`：向右添加新列。
   - 点击底部横贯条柱 `+`：向下添加新行。
5. **历史记录与实用功能**：
   - 支持全局 `Ctrl + Z`（撤销）与 `Ctrl + Y` / `Ctrl + Shift + Z`（重做）。
   - 顶部工具栏支持切换“表头行（Header Row）”与“表头列（Header Column）”。
   - 提供“导出 CSV”功能，一键下载表格数据。
