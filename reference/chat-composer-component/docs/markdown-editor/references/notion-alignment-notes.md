## 观测

| 维度 | 值 |
|------|-----|
| 页面内容宽 | ≈720px（该布局） |
| 正文字号 | 16px |
| 行高 | 24px（1.5） |
| 标题 | 可达 40px / 700 |
| 块背景 | 默认透明，无持续描边 |
| 产品 chrome | 顶栏为文档操作（分享/历史），**不是**格式刷工具条 |

## 我们应对

- demo：干净纸张 + 隐藏调试菜单  
- 编辑反馈：把手 + 光标，无 is-active 色块框  
- 表格：hover + / 右键，无「加行」文案  
- Notebook 宿主内仍可用 14px token 体系
