## BAN-01 · 禁止「激活行 / 激活块」全行视觉 chrome

**禁止**任何形式的：

| 垃圾效果 | 举例 |
|----------|------|
| 全行底色 | `.is-active { background: … }` |
| 全行描边 / outline | 1px–2px 边框框住整块 |
| 全行阴影抬升 | `box-shadow` 当「当前行」 |
| 全行左边粗竖条（除 callout 类型色） | 用左边框表示「正在编辑」 |
| 全行闪烁 / 呼吸 / 高亮动画 | transition 描边、脉冲 |

**唯一允许的编辑态反馈**：

1. **系统 caret**（光标）  
2. **块把手**在 hover 时极淡出现（opacity），**不**因 is-active 强制整行变色  
3. **多选**可用极淡 inset 叠加层（`::before`），且 **不是**「激活编辑」语义  

**实现约束**：

- CSS 对 `.mdx-block.is-active` / `.is-editing` / `:focus-within` 的 **background / border / box-shadow / outline 必须 transparent/none**（已有则保持；新增样式禁止破例）。  
- **禁止**新增依赖「激活行高亮」才能告诉用户「在哪编辑」的设计。  
- JS 可保留 `is-active` 作内部状态类名，**不得**再绑任何可见 chrome。

## BAN-02 · 禁止读/写两套皮跳变

**禁止**：

- 未聚焦 = 精致渲染；一点击 = monospaced 整行源码墙（`##` / `> [!NOTE]` 裸 dump）作为**默认**主路径  
- 点待办 / 列表 / 段落 → 突然变成「只能看源码不能点勾选」  
- 点公式 → 渲染公式碎成乱码行（`E=mc` / `2` 分行）  
- 点代码 → 整块不可编辑或双壳（上高亮下 textarea）

**要求**：默认路径必须是 **融合交互**（见重构方案）：所见即所得 + Markdown 可触达，而不是 read 岛 / edit 岛硬切。

---

## BAN-03 · 禁止半吊子「有的能编、有的只能看」

在「实时预览编辑模式」下：

| 能力 | 必须 |
|------|------|
| 行内 `**` `*` `` ` `` `~~` 等 | 键入闭合即渲染；可继续改 |
| 列表 / 待办 checkbox | 可点勾选，不进废源码态 |
| 标题 / 引用 / callout 类型 | 可改内容与类型 |
| 代码块 | 默认可编辑（或明确单表面源码），禁止「打头就不能编」 |
| 公式 | 点击编辑源不碎版；失焦回渲染 |
| 跨行选区 | 必须可用（非仅块级 multi） |

## BAN-04 · 禁止靠「按行/按块换壳」糊弄融合编辑

**block-per-row + enterEdit 换 innerHTML** 作为**长期架构**已被否决（见 `ux-readiness/11-SYSTEMIC-REFACTOR-PLAN.md`）。

允许短期稳定补丁，但：

- **禁止**继续加深 `editor.js` 上帝文件上的换壳逻辑作为终局  
- **禁止**再发明第三套「半表面 / 全源码 / 软源码」并行真相
