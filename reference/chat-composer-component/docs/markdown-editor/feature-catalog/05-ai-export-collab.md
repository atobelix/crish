## 0. 一句话与定位

本分册冻结 **写作增强（AI）**、**导入导出（IO）**、**版本历史**、**协作占位（P3）**、**全局命令面板**、**键盘地图**与 **无障碍** 的完整能力面。

每一项必须同时具备：

1. **功能 ID**（`F-A-XXXX` / `F-IO-XXXX` / `F-COL-XXXX` / `F-CMD-XXXX` / `F-KB-XXXX` / `F-A11Y-XXXX`）  
2. **做到最好**（金标准一句话 + 体验细节）  
3. **验收**（可人工 10 分钟或可脚本化勾选）  
4. **优先级**（P0–P3）与 **模块主人**（路径级，不进 `editor.js` 上帝堆）  
5. **失败态**（无端口 / 无网络 / 超大文档 / 权限拒绝 / 格式不支持）

**本册不做的事**：

- 不规定具体 LLM 厂商、模型名、温度参数

- 不替代 `08-package-modules` 的包边界与文件所有权细则

## 1. 产品边界与硬约束

### 1.1 AI 边界（不可协商）

| 规则 | 说明 |
|------|------|
| **端口注入** | 编辑器只定义端口形状与交互壳；宿主实现真正的模型调用 |
| **无硬编码 LLM** | 仓库内禁止写死 OpenAI/Claude/本地网关 URL、Key、SDK 直连 |
| **无 API Key 驻留** | 编辑器配置与 Doc 快照永不序列化密钥 |
| **无页顶 AI 大条** | 遵守 D16：入口 = 选区/右键/slash/命令面板/可选快捷键 |
| **可撤销** | 凡写回正文的 AI 动作必须进 undo 栈，一条事务 |
| **可取消** | 进行中必须可 Abort；中止后文档不变 |
| **隐私默认** | 默认截断上下文，不全文无上限上传 |
| **结果消毒** | AI 写回与粘贴同路径：parse + 安全消毒，禁止 raw script |

### 1.2 IO / 历史边界

| 规则 | 说明 |
|------|------|
| **MD 主路径无损** | GFM + Conex 扩展往返是 P0；其它格式允许有损但须明示 |
| **导出适配器** | 重格式（Word/PDF/LaTeX/Notion）优先宿主适配器；编辑器提供 Doc/MD/HTML 中间层 |
| **版本 = 快照 +  diff + 回滚** | 本地历史可编辑器内；云端历史宿主侧；接口统一 |
| **导入不静默丢数据** | 无法映射的结构要报告、降级可见，禁止静默删除用户内容 |

### 1.3 协作边界（P3）

| 规则 | 说明 |
|------|------|
| **v3 不实现实时协作** | 本册只定产品契约与预留锚点 |
| **评论 / @ / 分享 / ACL** | 全部 P3；不得阻塞 W1–W7 |
| **身份与权限** | 永远是宿主职责；编辑器只消费只读/可写/可评论能力位 |

## 3. AI — 端口与交互壳

> 编辑器 **只做 AI 端口与交互壳**：取上下文、展示入口、应用替换策略、处理 loading/错误/禁用。  
> **不**内置模型、不持有 API Key、不实现 RAG/Agent 运行时、不做页顶常驻 AI 工具条。

### 3.0 AI 域依赖

```
F-A-0001 端口注入
   ├─► F-A-0002 上下文包
   ├─► F-A-0003 选区驱动
   ├─► F-A-0004 写回策略
   ├─► F-A-0005 流式钩子
   ├─► F-A-0006 取消 / 单飞
   └─► F-A-01xx 各写作动作（按 port 有无显隐）
```

### F-A-0001 · AI 端口注入（禁止硬编码模型）

| 字段 | 内容 |
|------|------|
| **优先级** | **P0**（有 AI 产品承诺时）/ 无 AI 时整域可关 |
| **模块主人** | `ai/ports.ts`（契约）· `ai/controller.ts`（编排）· 宿主 `createXxxAiPort` |
| **做到最好** | 宿主用同一套端口换 mock / 云端 / 本地模型，**零改编辑器内核**；缺省无端口时所有 AI 入口 **完全隐藏**（不是灰掉一排死按钮） |
| **体验细节** | 总开关 `features.ai`；单方法缺失仅隐藏对应菜单项；端口对象可热替换（重挂载或 `setAiPorts`）；编辑器从不直接 `fetch` 模型 HTTP |
| **验收** | ① 不传 ai → 无 slash AI 区、无右键 AI、无命令面板 AI 分组、无选区 AI  ② 只传 `rewrite` → 仅改写相关项可见  ③ mock 与「假失败 port」可切换且 UI 正确  ④ 全库检索无硬编码厂商 endpoint / apiKey 字符串用于生产路径 |
| **失败态** | port 抛错 → toast，文档不变；port 返回空文本 → toast「无有效结果」且不写空 |

### F-A-0002 · 上下文包（AiContext）

| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **模块主人** | `ai/context.ts` |
| **做到最好** | 每次 AI 调用携带 **完整、可截断、可审计** 的上下文：选区文本、是否折叠、所在块切片、前后邻域、光标前后缀、文档统计、可选标题与宿主 meta；**默认不全文裸传** |
| **体验细节** | 代码块传源文本而非高亮 HTML；表格传 GFM pipe；跨块选区用空行拼接；`document` 范围遵守 `documentMaxChars`（默认约 12k）并标注省略；`hostMeta` 禁止 token |
| **验收** | ① 选中一段 → context.selectionText 精确  ② 空选续写 → prefix 非空且有上限  ③ 超长文 summarize document → 带截断标记  ④ 不包含密钥字段  ⑤ 对外暴露 `getAiContext` 供宿主外部按钮复用 |
| **失败态** | 无法收集选区（DOM 失焦竞态）→ 取消调用并提示重试 |

---

### F-A-0003 · 选区驱动（Selection-based）

| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **模块主人** | `ai/controller.ts` + selection 映射 |
| **做到最好** | 改写/翻译/润色/扩缩 **以用户选区为第一公民**；无合法选区时入口禁用并说明原因，**绝不静默拿错段** |
| **体验细节** | 跨块选区支持主路径；表格限格内；仅 atom（芯片）时对 label 文本或禁用；viewOnly 下无写回类入口 |
| **验收** | ① 空选点改写 → toast「请先选中文本」且 **不调用** port  ② 跨两段选区 rewrite 替换后结构合理  ③ 表内选区不污染邻格  ④ 只读模式无写回 AI |
| **失败态** | 选区在 AI 返回前被用户改掉 → 采用「生成开始时冻结的 range」策略或冲突提示，二者产品择一并写进实现；推荐 **冻结 range + 冲突则预览确认** |

### F-A-0004 · 写回策略（Apply Strategy）

| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **模块主人** | `ai/apply.ts` |
| **做到最好** | 策略显式、可覆盖：替换选区 / 插入下方 / 光标插入 / 先预览再应用 / 仅建议；默认映射符合直觉且 **一次成功 = 一条 undo** |
| **默认映射** | 改写类 → 替换选区；总结 → 插入选区或块下方；续写 → 光标插入；审阅 → 仅建议；问答答案 → 默认插入下方或侧栏（宿主可配） |
| **验收** | ① 各动作默认策略可测  ② undo 一次完整撤销 AI 写回  ③ redo 恢复  ④ `preview_then_apply` 取消不写文档  ⑤ markdown/plain 格式标志影响解析路径 |
| **失败态** | 解析结果失败 → 不半写入；可降级为纯文本段落并提示 |

### F-A-0005 · 流式输出（Streaming）

| 字段 | 内容 |
|------|------|
| **优先级** | P1 |
| **模块主人** | `ai/stream.ts` + 预览层 |
| **做到最好** | 续写/改写支持增量流：用户看见生成过程；完成前可中止；**完成才提交一条历史**；中止清除 ghost/临时预览，正文干净 |
| **体验细节** | 端口可返回 Promise（非流）或 AsyncIterable（流）；非流宿主仍可用；流式时 `aria-busy` + live region 适度播报（不逐 token 刷屏）；`prefers-reduced-motion` 下弱化打字机动效 |
| **验收** | ① mock 流式续写可见增量  ② Esc/取消中止后无残留 ghost  ③ 完成后 undo 一次清空  ④ 纯 Promise port 不回归  ⑤ 流中途 port 错误 → 清理预览 + toast |
| **失败态** | 流中断网络 → 同错误态；不留下半截已提交历史 |

### F-A-0006 · 取消、超时、单飞

| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **模块主人** | `ai/controller.ts` |
| **做到最好** | 任意进行中的 AI 可取消；默认单实例单飞（防连点烧 token）；超时由宿主或编辑器默认上限（如 60s）兜底 |

| **失败态** | 宿主忽略 abort → 编辑器仍丢弃迟到结果（generation id 校验） |

### F-A-0101 · 扩写（Expand / Longer）

| 字段 | 内容 |
|------|------|
| **优先级** | P1 |
| **做到最好** | 在保持原意与 Markdown 结构意识下 **充实选区**：补细节、例子、过渡，而不是胡编离题；长度明显增加但可控；代码/表结构不无故拆坏 |
| **入口** | 选区 AI → 扩写；命令面板「AI: 扩写」；slash 可选 |
| **验收** | ① 选中短句扩写后替换原选区  ② undo 恢复  ③ 对代码块选区：仍落在 code 语义内或明确提示  ④ 流式可选 |
| **失败态** | 选区过短（如单字）可提示「选区过短，扩写意义有限」但仍允许执行 |

---

### F-A-0102 · 缩写（Shrink / Shorter）

| 字段 | 内容 |
|------|------|
| **优先级** | P1 |
| **做到最好** | **压缩冗余、保留关键事实与术语**；列表可收束为更短列表；不删用户未选中的上下文；缩写后可读、不断句成电报体失控 |
| **验收** | ① 长段缩写变短且替换  ② 标题层级不乱降  ③ undo  ④ 与扩写可连续对同一选区反复（用户主动） |
| **失败态** | 结果与原文完全相同 → 弱提示「模型未提出更短版本」 |

### F-A-0103 · 改写（Rewrite 通用）

| 字段 | 内容 |
|------|------|
| **优先级** | P1 |
| **做到最好** | 一等入口：改写选区文字，支持子意图（更短/更长/更正式/更口语/纠错/自定义）；**空选禁用**；结果进历史；结构（粗斜链）尽量保留或按 MD 正确重解析 |
| **验收** | ① 子菜单意图正确传入 port（intent 字段）  ② 替换精确  ③ 空选不调用  ④ 跨段改写后块分割合理 |
| **失败态** | 同 F-A-0001/0008 |

### F-A-0104 · 翻译（Translate）

## 5. 导入 / 导出（IO）

> **MD 是真理格式**。其它格式是适配器。  
> 编辑器内核保证 Doc ↔ Markdown 金标准；HTML/Word/PDF/LaTeX/Notion 以适配器 + 宿主能力交付，但本册定义 **用户可感知金标准** 与验收，避免「只有复制 MD」。

### 5.0 IO 总原则

| 原则 | 说明 |
|------|------|
| 明示有损 | 无法保真时 UI 预告「部分格式将降级」 |
| 可取消长任务 | PDF/Word 大文导出可取消 |
| 不进上帝文件 | `io/export/*` · `io/import/*` 分格式模块 |
| 与 mode 联动 | `conex` vs `pure-gfm` 影响扩展语法导出降级 |
| 安全 | 导入 HTML/DOCX 必须消毒；不执行嵌入宏 |

## 14. 验收剧本（人工 30–40 分钟精华版）

### 14.1 AI（Mock 开）

1. 无 port 挂载 → 无任何 AI 入口。  
2. Mock 开 → 选中一段 → 扩写/缩写/改写/翻译/润色 → 替换正确 → Ctrl+Z 恢复。  
3. 空选改写 → 提示且无网络/ mock 调用计数不增。  
4. 总结选区 → 下方新块 → 原文仍在。  
5. 续写 → 光标插入；流式若开：可见增量；Esc 取消干净。  
6. 审阅 → 文档不变 → 应用一条建议才变。  
7. 问答 → 答案可插入。  
8. 生成中连点 → 单飞。  
9. viewOnly → 无写回 AI。  

### 14.2 IO

1. 导出 MD → 再导入 → 主结构一致。  
2. 复制 MD 到外部分页可读。  
3. （若有）HTML/PDF/Word/LaTeX/Notion 各跑一样例 + 有损说明可见。  
4. 危险 HTML 导入无脚本执行。  

### 14.3 历史（若启用）

1. 保存版本 → 列表可见 → diff 有红绿/标记 → 回滚成功 → 回滚前保险版本存在。  

### 14.4 命令面板与键盘

1. Ctrl+P 打开 → 搜「导出」→ 执行。  
2. 搜「续写」→ 执行。  
3. Esc 分层正确。  
4. 快捷键帮助与地图一致。  

### 14.5 无障碍抽测

1. 键盘完成一次 AI 改写。  
2. 键盘完成一次导出 MD。  
3. 读屏：busy 与完成可感，流式不刷屏。  

### 14.6 协作

1. 确认产品无假协作 UI 谎称实时；P3 项保持缺失或明确「即将推出」且不可点坏数据。

## 20. 结语（给验收人）

若只能记住五句：

1. **AI 是端口**，不是仓库里的某个模型。  
2. **选区驱动 + 可撤销 + 可取消 + 可流式**。  
3. **MD 往返是宗教**；其它格式诚实有损。  
4. **历史能 diff 能回滚**；协作整包 P3。  
5. **Ctrl+P 全局命令**；键盘与读屏不是售后补丁。

未达到「做到最好」的 F-ID，不得在发布说明里写「已支持 AI/导出/协作」。  
只做 UI 壳 = **半成品**，分数 ≤1，不算交付。
