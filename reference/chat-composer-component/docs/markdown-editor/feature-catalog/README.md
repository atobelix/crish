## 4. 「做到最好」统一判据（所有功能共用）

一项功能标 **金标准** 必须同时满足：

1. **主路径完整**：创建、编辑、失焦渲染、序列化、再打开一致  
2. **边界完整**：空、极大、粘贴垃圾、IME、撤销  
3. **键盘可达**：不止鼠标  
4. **无错误模型**：不违反行源码 / 单表面 / 无跳布局  
5. **有验收清单**：可自动或可人工 10 分钟测完  
6. **有模块主人**：路径明确，不进上帝文件  
7. **有失败态**：加载失败、不支持语法、降级可读  

只做 UI 壳 = **半成品**，不算交付。

## 6. 调度约定（后续实现）

1. **先文档后代码**：分册未写清「做到最好」的 F-ID 不得开工。  
2. **一轮 ≤12 agent**，按模块所有权并行，禁止抢同一文件。  
3. **一波交付一个完整面**（例如整面「行源码模型」或整面「表格多选+合并」），不做零碎 CSS。  
4. **验收不过不合并波次**。
