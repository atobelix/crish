# 键盘速查（Markdown 块编辑器）

> 短表；细节状态机见 03 / 04 / 05。宿主面板键见 [08-integration.md](../08-integration.md)。

---

## 全局 / 面板

| 按键 | 条件 | 行为 |
|------|------|------|
| `Esc` | slash 开 | 关菜单 |
| `Esc` | 块编辑中 | 退出块编辑（保留内容） |
| `Esc` | 未编辑 | 关闭 Notebook（force，与现网一致） |
| `Tab` | 面板内 | 焦点在块/把手/外壳按钮间移动 |

---

## 块编辑

| 按键 | 行为 |
|------|------|
| `Enter` | 段/标题：下方新建段落并聚焦 |
| `Shift+Enter` | 块内软换行（列表项内同） |
| `Backspace` | 空块：删除并合并到上块 |
| `Delete` | 空块：与下块合并 |
| `Mod+B` / `Mod+I` / `Mod+\`` | 行内粗/斜/代码（M1+ 逐步） |
| `Mod+Z` / `Mod+Shift+Z` | 撤销 / 重做 |
| `Mod+A` | 先选块内；再按选全部块（可选） |
| `↑` / `↓` | 光标到块边界时进入相邻块 |

`Mod` = `Ctrl`（Windows/Linux）/ `Cmd`（macOS）。

---

## 列表

| 按键 | 行为 |
|------|------|
| `Tab` | 增加缩进（深度上限见模型） |
| `Shift+Tab` | 减少缩进 |
| `Enter` 空项 | 退出列表 → 普通段落 |
| `Mod+Enter` | 任务项：切换 checked（若 todo） |

---

## Slash / `、` 菜单

| 按键 | 行为 |
|------|------|
| `/` 或 `、` | 行首（或规则允许处）打开面板 |
| `↑` / `↓` | 高亮项 |
| `Enter` | 执行高亮命令 |
| `Esc` | 关闭；保留已输入过滤字或整段删除触发符（实现二选一，推荐：关菜单保留文本） |
| 可打印字符 | 过滤列表 |

---

## 拖拽替代（a11y）

| 按键 | 行为 |
|------|------|
| `Alt+↑` | 当前块上移 |
| `Alt+↓` | 当前块下移 |

焦点在块上或块内编辑态均可（编辑态优先移块不丢焦点）。

---

## 表格（M4）

| 按键 | 行为 |
|------|------|
| `Tab` / `Shift+Tab` | 下一/上一单元格 |
| `Enter` | 同行下单元格或下行首格 |
| `Esc` | 退出单元格编辑 → 块级选中 |

---

## 明确不做（v1）

| 按键 | 说明 |
|------|------|
| `Mod+S` | 无独立保存；靠 autosave |
| `Mod+/` | 不绑注释切换（与 slash 冲突风险） |
| 多光标 | 非目标 |
