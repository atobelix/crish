# Slash / 顿号面板 — 交互文案与状态

> **性质**：纯 UX 微文案、空态、反馈语气；**不含**注册表 schema 与实现算法。  
> **工程规格**：[../05-slash-commands.md](../05-slash-commands.md)  
> **视觉 token**：见 `07-visual-system.md`（浮层 surface、字号）  
> **原则**：冷静、短句、中文优先；不卖萌、不恐吓（危险操作用中性说明）。

---

## 1. 目标与非目标

### 目标

- 统一 `/` 与 `、` 打开后的 **用户可见文案** 与 **状态机感知**。
- 空查询、过滤中、无结果、加载、失败各态可实现、可验收。
- 为 a11y live region 提供标准播报文案。

### 非目标

- 不定义命令 id / `run` 逻辑（见 05）。
- 不定品牌插画或空态大图（v1 纯文字）。
- 不写 CSS 数值（只写语义层级：主文案 / 次文案）。

## 2. 触发教育（可选首次提示）

v1 **默认不做** 新手气泡，避免吵。若宿主开启 onboarding：

| 键 | 文案 |
|----|------|
| 提示标题 | 快速插入块 |
| 提示正文 | 在空行输入 `/` 或 `、` 打开命令菜单 |
| 按钮 | 知道了 |

关闭后本地记 `slash-onboarding-dismissed=1`，不再出现。

|------|-------------|------|

| 分组：媒体 | 媒体 | |

## 4. 状态一览

```text
[Closed] ──打开──► [Open: FullList]
                      │
                      │ 输入 query
                      ▼
                 [Open: Filtered]
                      │
                      ├─ 有命中 ──► 保持 Filtered（更新列表）
                      └─ 无命中 ──► [Open: NoResults]
                      │
                      │ 异步命令（P1+）
                      ▼
                 [Open: CommandPending]  （面板通常已关，见下）
```

说明：v1 内置命令同步执行 → **成功路径直接 Closed**，无 Pending UI。  
异步扩展命令：面板先关，在 **文档块位** 显示占位/加载（非面板内 spinner）。

## 5. 状态详述与微文案

### 5.1 Open · 空查询（FullList）

| 项 | 内容 |
|----|------|
| 列表 | 全部可见命令，按分组 |
| 默认高亮 | 第一项（通常「正文」或当前 section 首项） |
| 空查询辅助 | **无** 额外说明行（避免噪） |
| SR 播报（打开时一次） | 命令菜单已打开，共 {n} 项 |

### 5.2 Open · 过滤中（Filtered）

| 项 | 内容 |
|----|------|
| 列表 | 仅命中项；空分组隐藏 |
| 高亮 | 重置为过滤结果第 1 项 |
| 无额外「搜索中」 | 本地过滤，无 spinner |
| SR（debounce 300ms） | {n} 个匹配项 |

### 5.3 Open · 无结果（NoResults）

**主文案**（`role="status"`）：

```text
未找到相关命令
```

**次文案**（辅助，次级色）：

```text
试试「标题」「表格」「任务」
```

| 规则 | 说明 |
|------|------|
| 主文案固定 | 不拼接用户 query（防注入感与过长） |
| 次文案 | 固定三例；不随扩展动态改（避免难测） |
| Enter | 不执行、不关闭（防误触清空意图）；用户可改 query 或 Esc |
| Esc | 关闭并清除 `/query` 或 `、query` |

**SR**：

```text
未找到相关命令
```

### 5.4 取消（Closed after cancel）

| 路径 | 用户感知 |
|------|----------|
| Esc | 面板消失；触发符与查询一并消失；无 toast |
| 点外部 | 同 Esc |
| Backspace 删掉触发符 | 同 Esc |
| Tab 移出 | 同 Esc（见 05 a11y） |

**不**显示「已取消」toast。

### 5.5 执行成功

| 项 | 内容 |
|----|------|
| 面板 | 立即关闭 |
| 触发串 | 已从块中移除 |
| Toast | **默认无**（插入本身即反馈） |
| 例外 | 需要系统权限失败时见 5.6 |

### 5.6 执行失败

面板已关闭时用 **非阻塞** 提示（宿主 toast）：

| 场景 | 文案 |
|------|------|
| 通用失败 | 无法插入该块 |
| 无文件权限 | 无法访问文件 |
| 无媒体能力 | 当前环境不支持插入图片 |
| 网络（嵌入） | 无法加载嵌入内容 |

次级操作（可选）：`重试` — 仅异步命令；v1 可只文案。

### 5.7 只读 / 不可用

不打开面板；若用户从调试 API 强行 open：

```text
当前文档不可编辑
```

## 6. 命令行展示模板

每一行 option 的信息架构（左 → 右）：

```text
[图标]  主标题                 [快捷键提示]
```

| 字段 | 规则 |
|------|------|
| 主标题 | 用 `command.title` 中文，不截断至两行（单行 ellipsis） |
| 副标题 | v1 **不显示** description，降噪 |
| 快捷键提示 | 有则显示如 `⌘⌥1`；无则空 |
| 图标 | 与 title 左对齐垂直居中；无图标用首字灰底方 |

### 6.1 内置 title 展示名（与 05 一致，供文案校对）

**基础**：正文、标题 1、标题 2、标题 3、引用、代码块、分割线、高亮  

**列表**：无序列表、有序列表、任务列表  

**媒体**：表格、图片、附件、嵌入  

**高级**：折叠块、公式块、图表  

若产品改名，**以本表与 05 同步修订** 为一轮 PR。

## 7. 危险 / 需确认命令

v1 默认列表 **不含** 破坏性命令。若扩展注册危险操作：

| 模式 | UX |
|------|----|
| 软确认 | 第一次点击后行内展开「再点一次确认」 |
| 硬确认 | 系统 `confirm`：**不推荐**；打断编辑流 |

文案模板：

```text
主按钮：确认清空
取消：返回
说明：此操作可撤销
```

## 8. 键盘与指针的用户感知

| 操作 | 用户应感到 |
|------|------------|
| ↑↓ | 高亮条移动；列表必要时自动滚入视野 |
| Enter | 立刻变成目标块类型，菜单消失 |
| Esc | 回到「从未打开过菜单」的正文 |
| 点击某行 | 同 Enter |
| 在菜单上滚轮 | 只滚菜单，文档不跟着疯滚 |
| 过滤无结果仍敲 Enter | **无事发生**（可极弱闪一下 empty 区，可选，默认不做） |

## 9. 双触发的文案一致性

对外说明（设置、帮助、错误）统一写：

```text
输入 / 或 、 插入块
```

不要只写 slash；不要写「顿号键」过技术化称呼（可用「中文顿号、」一次）。

帮助长文示例：

```text
在空白段落的开头输入半角斜杠 /，或中文顿号、，即可打开插入菜单。
用上下键选择，回车确认。按 Esc 取消。
在「1、」这种列举写法里不会打开菜单。
```

## 10. 移动端文案差异

| 场景 | 文案 |
|------|------|
| 面板 `aria-label` | 插入块（同桌面） |
| 无结果 | 同桌面 |
| 底部 sheet（P2）标题 | 插入块 |
| 关闭 sheet 按钮 | 关闭 |

软键盘收起导致面板翻位：**无**额外文案。

## 11. Live region 文案表（a11y）

| 事件 | `aria-live="polite"` 文本 |
|------|---------------------------|
| 打开 | 命令菜单已打开，共 {n} 项 |
| 过滤结果 >0 | {n} 个匹配项 |
| 过滤结果 =0 | 未找到相关命令 |
| 关闭 | （不播报，避免吵） |
| 执行成功 | （不播报；焦点进新块即可） |

`{n}` 为数字，中文环境直接用阿拉伯数字：`共 12 项`。

---

## 12. 空文档 vs 空段落

| 场景 | 差异 |
|------|------|
| 文档唯一空段打开菜单 | 同普通空段；**无**「开始写作吧」类营销句 |
| 过滤无结果 | 同 §5.3 |
| 删除最后一块后 | 编辑器应保证至少一空段（architecture）；与面板无关 |

## 13. 错误边界文案（实现可映射）

| code（内部） | 用户文案 |
|--------------|----------|
| `SLASH_BLOCK_GONE` | （静默关闭，无文案） |
| `SLASH_RUN_ERROR` | 无法插入该块 |
| `SLASH_FEATURE_DISABLED` | 当前环境不支持该命令 |
| `SLASH_READONLY` | 当前文档不可编辑 |

## 14. 验收清单（UX）

- [ ] 无结果主/次文案与本文一字不差（或经产品改稿后回写本文）  
- [ ] 取消路径无 toast、无残留触发符  
- [ ] 成功路径无多余「插入成功」  
- [ ] 帮助/设置中同时出现 `/` 与 `、`  
- [ ] SR 打开与无结果可闻（抽测）  
- [ ] 分组标题：基础 / 列表 / 媒体 / 高级
