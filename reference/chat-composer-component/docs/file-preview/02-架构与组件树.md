## 3. 核心类型（逻辑）

```ts
type PreviewKind =
  | 'image' | 'pdf' | 'markdown' | 'docx'
  | 'spreadsheet' | 'text' | 'unknown';

type PreviewSource =
  | { type: 'card'; el: HTMLElement }
  | { type: 'file'; file: File }
  | { type: 'text'; name: string; text: string; mime?: string }
  | { type: 'url'; url: string; name?: string }
  | { type: 'path'; path: string; name?: string }; // 桌面预留

type PreviewCapability =
  | 'close' | 'download' | 'zoom' | 'rotate' | 'page'
  | 'thumbnails' | 'search' | 'copy' | 'crop' | 'brush';

interface PreviewModel {
  id: string;
  kind: PreviewKind;
  name: string;
  size?: number;
  mime?: string;
  status: 'loading' | 'ready' | 'error';
  errorMessage?: string;
  capabilities: PreviewCapability[];
  // kind-specific payload
  payload: unknown;
}
```

## 4. 公共 API

```js
FilePreview.open(source, options?)
FilePreview.close({ force?: boolean })
FilePreview.isOpen()
FilePreview.registerAdapter(kind, adapter)  // 扩展点
```

兼容：

```js
window.openPreview = (card) => FilePreview.open({ type: 'card', el: card })
```

---

## 5. 生命周期

```
open
  → shell.mount + enter motion
  → model = { status:'loading' }
  → EmptyViewer skeleton
  → adapter.load(source) async
  → model ready | error
  → router.mountViewer(model)
  → toolbar.bind(model.capabilities)

close
  → 若 image dirty → confirm
  → leave motion
  → viewer.destroy (revoke URLs, terminate pdf worker)
  → shell.unmount
```

## 8. 组件职责一览

| 组件 | 输入 | 输出 |
|------|------|------|
| PreviewShell | root el, title, slots | DOM 壳 + 事件 |
| PreviewRouter | source | model + viewer class |
| Adapter | source | PreviewModel |
| Viewer | host, model | 渲染 / destroy |
| Toolbar | capabilities, handlers | 按钮条 |
| EmptyViewer | loading / error / unsupported | 状态页 |
