# 快捷键

| 键 | 全局（Shell 打开时） | 备注 |
|----|----------------------|------|
| Esc | 关闭（dirty 则确认） | |
| Ctrl/Cmd + S | **不**绑定保存到预览 | 避免误导 |
| Ctrl/Cmd + C | 复制选区 | 浏览态默认 |
| ← → | PDF 翻页 | 焦点在 stage |
| + / − | 缩放 | image/pdf |
| 0 | 重置缩放 | image/pdf |
| Space | PDF 下页（可选） | 勿与按钮冲突 |

Markdown viewOnly：不处理会修改文档的快捷键。
