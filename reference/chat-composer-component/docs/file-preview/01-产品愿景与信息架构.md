# 01 — 产品愿景与信息架构

---

## 1. 目标

用户在 Composer 附件区、对话引用、未来桌面文件树中点击文件时，得到：

1. **立即能看懂**内容（真渲染）  
2. **界面干净高级**（克制动效 + 统一 token）  
3. **动作清晰**（缩放、翻页、下载… 且只出现有用的）  
4. **可迁移**（组件边界清晰 → desktop）

---

## 2. 非目标

- 不做完整 Office 在线编辑  
- 不做云端文档转换服务（本阶段全客户端）  
- 不做预览/源码双模式 toggle  
- 不在预览里嵌 AI 聊天侧栏  
- 不把对话流 Notebook 与 File Preview 合成一个「超级面板」

---

## 3. 核心场景

| # | 场景 | 期望 |
|---|------|------|
| S1 | 点附件 `报告.pdf` | 真 PDF，可翻页缩放，缩略图可选 |
| S2 | 点 `需求.md` | 块级精致阅读，不可编辑，无「只读」标签 |
| S3 | 点 `说明书.docx` | 版式化 HTML 阅读，外链安全 |
| S4 | 点 `压测.csv` / `表.xlsx` | 表格网格，可横滚，统计行数 |
| S5 | 点图片 | 缩放旋转（裁剪/画笔保留为高级工具） |
| S6 | 点 `.ts` / `.log` | 等宽文本，可选高亮 |
| S7 | 点未知 `.onnx` | 元信息 + 下载，不假装预览成功 |
| S8 | Esc / 点遮罩 | 有未保存图片编辑时确认；否则顺滑关闭 |

## 4. 信息架构（屏幕）

```
┌─────────────────────────────────────────────────────────┐
│ Backdrop（点击关闭）                                       │
│  ┌─ PreviewShell ─────────────────────────────────────┐  │
│  │ [图标] 文件名………………………  [工具栏: 按能力]  [×]   │  │
│  ├────────────────────────────────────────────────────┤  │
│  │                                                    │  │
│  │              Viewer 内容区                          │  │
│  │     (PDF | MD | Table | Image | Code | Empty)     │  │
│  │                                                    │  │
│  ├────────────────────────────────────────────────────┤  │
│  │ 可选：底栏（图片工具 / PDF 页码）— 按 Viewer 插槽   │  │
│  └────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### 层级

1. **Backdrop** — 焦点与关闭  
2. **Chrome** — 标题 + 通用动作（关闭、下载）  
3. **ContextToolbar** — 格式相关  
4. **Stage** — Viewer  
5. **FooterSlot** — Viewer 注册的底栏  

---

## 5. 用户信任原则

> 过程可弱，结论要真。  
> 预览里：**解析真、失败诚实、界面不解释废话**。

- 能解析 → 直接给内容  
- 不能 → 「无法预览此格式」+ 下载（文案短、无技术借口长篇）  
- 加载中 → skeleton / 进度，而非空白闪烁  

---

## 6. 与对话流的叙事关系

| 对象 | 角色 |
|------|------|
| 附件 file-card | 输入侧材料 → File Preview |
| 工具路径 chip | 代码/文件 → 右侧面板或 File Preview（产品后续统一） |
| 已生成 artifact | 产出文档 → Notebook **编辑**；若只要看可用 Preview view-only |

本方案优先 **附件预览闭环**；路径打开 hook 预留 `openPreview({ kind:'path' })`。
