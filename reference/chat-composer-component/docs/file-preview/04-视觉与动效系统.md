# 04 — 视觉与动效系统

---

## 1. 设计目标

- **高级**：少装饰、准对齐、好字距  
- **克制**：动效完整但短；无表演型 bounce  
- **统一**：与 `conversation-tokens` / Composer 同语言  
- **清晰**：内容区对比度优先于 chrome 花活  

---

## 2. Token（建议 `css/file-preview/tokens.css`）

```css
:root {
  --fp-radius: 14px;
  --fp-radius-sm: 10px;
  --fp-hairline: 1px solid #e8e8e8;
  --fp-bg: #ffffff;
  --fp-bg-stage: #f7f7f7;
  --fp-ink: #0f0f0f;
  --fp-meta: #5a5a5a;
  --fp-shadow: 0 16px 48px rgba(0,0,0,0.12); /* 静态，仅壳 */
  --fp-backdrop: rgba(15,15,15,0.28);

  --fp-enter-ms: 200ms;
  --fp-leave-ms: 160ms;
  --fp-cross-ms: 160ms;
  --fp-spring: cubic-bezier(0.22, 1, 0.36, 1);
}
```

阴影：**只**用在 shell 静态投影；**禁止** hover 阴影动画。

## 3. 壳层布局

| 区域 | 规格 |
|------|------|
| 最大宽 | `min(1040px, 96vw)` |
| 最大高 | `min(860px, 92vh)` |
| 标题 | 14–15px，单行 ellipsis |
| 工具栏图标 | 16px stroke，hit 32px |
| Stage | `flex:1; min-height:0; overflow:auto` |
| 底栏 | 按需；无则折叠为 0 |

---

## 4. 工具栏能力 → 图标

| Capability | 图标含义 | 显示条件 |
|------------|----------|----------|
| close | × | 始终 |
| download | 下载 | 有 blob/url |
| zoom | ± − 或显示 % | image/pdf |
| rotate | 左/右旋转 | image |
| page | ‹ › 页码 | pdf |
| thumbnails | 侧栏 | pdf 多页 |
| crop / brush | 裁剪/画笔 | image 高级 |
| copy | 复制文本 | text/md |

**不出现**：模式切换、只读徽章、预览/源码 tab。

---

## 5. 状态页（EmptyViewer）

| 状态 | 视觉 |
|------|------|
| loading | 居中 spinner 或 skeleton 条，160ms 淡入 |
| error | 简洁图标 + 一行错误 + 下载 |
| unsupported | 文件图标 +「无法预览」+ 下载 |

文案短；不写堆栈。

---

## 6. 动效清单

### 6.1 Shell 开闭

```
open:
  backdrop opacity 0 → 1 (160ms)
  panel opacity 0 → 1, transform scale(0.98) translateY(6px) → none (200ms spring)

close:
  reverse 160ms
```

### 6.2 内容切换（loading → ready）

```
stage: opacity 0.4 → 1 + translateY(4px → 0) 160ms
```

### 6.3 PDF 翻页

- 页码数字 tabular + 可选轻微 fade（120ms）  
- 不整页 3D 翻书  

### 6.4 工具栏

- hover：仅 `color` / `background: rgba(0,0,0,0.04)` 90ms  
- active：同色阶加深  

### 6.5 表格

- 首屏行可用 staggered 20ms×N（最多 5 行），其余静态  

### 6.6 reduced-motion

全部 transition/animation → none；开闭瞬切。

---

## 7. 滚动

- Stage 内滚动；**不**手写 wheel hijack（避免对话流曾出现的抽搐）  
- `overscroll-behavior: contain` 仅用在 modal stage，防止滚动穿透到背后聊天  
- 与聊天流 nested chain 问题隔离：modal 打开时可选 `body { overflow: hidden }`

## 8. 排版细节（内容）

| Viewer | 要点 |
|--------|------|
| Markdown | 复用 markdown-editor 阅读样式；预览壳内边距 24–32px |
| Docx | 最大测宽 720px 居中，段落行高 1.65 |
| Table | 表头 sticky；斑马纹极淡或无；边线 hairline |
| Code | 13px mono；行号可选 P1 |
| PDF | 页阴影极轻 `0 1px 4px rgba(0,0,0,0.06)` |
