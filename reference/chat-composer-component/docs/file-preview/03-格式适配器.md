# 03 — 格式适配器

---

## 1. Adapter 接口

```js
/**
 * @typedef {object} FormatAdapter
 * @property {PreviewKind} kind
 * @property {(name: string, mime?: string) => boolean} match
 * @property {(ctx: LoadContext) => Promise<PreviewModel>} load
 */

/**
 * @typedef {object} LoadContext
 * @property {PreviewSource} source
 * @property {() => boolean} isCancelled
 * @property {(p: number) => void} [onProgress]  // 0..1
 */
```

规则：

- `match` 纯函数，无 IO  
- `load` 可 async；必须可取消（关闭弹层时）  
- 成功：`status: 'ready'` + payload  
- 失败：`status: 'error'` + 短 `errorMessage`  
- **禁止**在 adapter 里 `document.querySelector` 画 UI

## 2. 分格式规格

### 2.1 Image

| 项 | 规格 |
|----|------|
| 匹配 | png/jpg/jpeg/gif/webp/svg/bmp |
| Payload | `{ objectUrl, width?, height? }` |
| 能力 | zoom, rotate, crop, brush, download, close |
| 销毁 | `URL.revokeObjectURL` |
| 来源 | 现有逻辑迁入 ImageViewer |

### 2.2 PDF

| 项 | 规格 |
|----|------|
| 匹配 | `.pdf` / `application/pdf` |
| 库 | pdf.js（动态加载） |
| Payload | `{ pdfDocument, numPages }` 或封装 handle |
| 能力 | page, zoom, thumbnails, download, close |
| 渲染 | canvas 或 svg；默认 canvas  
| 懒加载 | 当前页 ±1 预渲染 |
| 失败 | error + 下载 |

**禁止**再生成假「一、概述与核心结论」HTML。

### 2.3 Markdown

| 项 | 规格 |
|----|------|
| 匹配 | `.md` `.mdx` `.markdown` 或 mime text/markdown |
| 库 | 复用 `MarkdownEditor.mount(host, { markdown, viewOnly: true })` |
| Payload | `{ markdown: string }` |
| 能力 | download, copy?, close；（无 edit） |
| 细节 | 见 05 |

### 2.4 DOCX

| 项 | 规格 |
|----|------|
| 匹配 | `.docx`（`.doc` 老格式 → unsupported 或尝试失败降级） |
| 库 | mammoth.browser |
| Payload | `{ html: string }`（已消毒） |
| 能力 | download, close |
| 样式 | `viewers/docx.css` 约束文章排版 |
| 安全 | DOMPurify.sanitize |

### 2.5 Spreadsheet

| 项 | 规格 |
|----|------|
| CSV/TSV | 自研 parser（引号、转义）；首行列头 |
| XLSX | SheetJS 读第一张表（可切换 sheet） |
| Payload | `{ sheets: [{ name, rows: string[][] }], activeIndex }` |
| 能力 | download, close；（可选）切 sheet |
| 性能 | >5k 行：只渲染前 N +「已截断」提示，或虚拟列表 P1.5 |

### 2.6 Text / Code

| 项 | 规格 |
|----|------|
| 匹配 | txt/log/json/yml/yaml/ts/js/py/… 及 `text/*` |
| Payload | `{ text, language? }` |
| 能力 | download, copy, close |
| 渲染 | `<pre>` + 可选 highlight 异步 |

### 2.7 Unknown

| 项 | 规格 |
|----|------|
| Payload | `{ name, size, mime }` |
| UI | EmptyViewer unsupported  
| 能力 | download, close |

## 3. 嗅探顺序（sniff）

1. 显式 `data-file-type`（card）  
2. MIME（File.type）  
3. 扩展名  
4. 内容嗅探（可选：PDF `%PDF` 魔数）  
5. `unknown`

## 4. 演示数据策略

| 场景 | 策略 |
|------|------|
| 无 live File 的 demo 卡 | fixture 文本 / 远程小样 / 内置 base64 迷你 PDF |
| 表格 demo | 保留 mock 行，但走 TableViewer 真路径 |
| 勿 | 用假 PDF HTML 冒充 |

建议新增：

```
fixtures/file-preview/
  sample.md
  sample.csv
  sample.txt
  (optional) sample.pdf  # 极小
```
