# 00 调度与执行纪律（wysiwyg-layout-remediation）

> 上位纪律：`C:\Software\conex\AGENTS.md`（通用协作纪律）+ `.agents/LOGIC_PLAN_NO_RETREAT.md`（反退避全文）。
> 本文件只写**本战役的差异化执行细则**；与上位冲突时以上位为准。

---

## 1. 角色与派发

- 仅主 Agent 可派发子 Agent；子 Agent 深度 1，无派发能力（`AGENTS.md` §2 嵌套禁止）。
- 每轮派发 5–12 个；任意时刻存活 ≤16；收尾轮允许 <5。
- 派单必须写明：输入文档、产出路径、验收标准、文件冲突注意事项。
- 探索类子 Agent **最多写一份文档**，且必须由主 Agent 分配写作任务（`AGENTS.md` §4.5）。

## 2. Git 纪律

1. **提交权仅归主 Agent**。子 Agent 完成任务后把改动留在工作区；**严禁** commit / reset / checkout / restore / rebase。
2. 主 Agent 提交用 `git commit --only <paths...>` 限定本单元文件路径，避免误提交并行 Agent 的 staged/工作区文件。
3. 提交路径必须写**相对仓库根**（`C:\Software\conex`）的完整路径，例如 `reference/markdown-editor/src/core/layout/IndentModel.ts`。
4. **严禁** `--no-verify`；lint-staged / pre-commit 报错必须修复后重提。
5. 提交信息遵循仓库风格：`feat|fix|refactor|test|docs|chore(scope): 描述`，本战役加批次标记 `[LAYOUT]`。
6. **每个任务单元收口即提交**（用户裁决 D3），禁止长期堆积。
7. 若改动已被其他 Agent 提交（吞并），**只验证内容完整性**，不因归属不纯而回退重做。

## 3. 反退避与反过度设计

- **效果锁**：用户目标不得降级为「调 CSS / MVP 砍功能」；冲突只标出并请示。
- **禁止退避裁判**：不得以工作量、方案成熟度、生态流行度否决路径。
- **禁止多轨**：同一概念只允许一条实现；新增第二条即回归。
- **禁止硬编码**：几何常量只允许来自 `LayoutMetrics` 实测或 `:root` token。
- **禁止坐标补偿**：不得用魔术数字补偿测距误差；必须穿透到架构断层。
- 遵守 `ANTI_OVERENGINEERING_GUARDRAILS.md` 红线（禁内核级沙箱、SAB 环形缓冲、动态换模路由、六段式中间件等回潮）。

## 4. 门禁与立体验证

- **编译/类型检查仅为底线**，不得作为交付依据。
- 每个任务单元收口必须跑：
  ```bash
  npm run check:gate          # tokens + ssot + length + lint
  npm run test                # tests/unit
  npm run test:commonmark     # 列表/嵌套相关改动必跑
  ```
- 涉及几何/渲染的单元**必须**跑现场取证脚本（`scratch/geom-*.mjs`）并附实测数值。
- **测试资产只增不减**：禁止删除断言、禁止 `skip`、禁止改恒真。
- 允许并必须**升级** `tests/unit/typography-indent.test.ts` 的断言口径（旧断言固化被整改的偏差），但须在 `04-分维` §5 登记逐条映射。

## 5. 续航锚点更新规则

- `00-总方案` **§12** 是跨会话交接的**唯一**状态源。
- 每完成一个任务单元：**就地更新**「当前状态 / 已完成 / 进行中 / 阻塞 / 下一步」。
- 禁止把状态散落到分维文档；分维文档只写规格与设计。

## 6. 禁止的半成品状态

每个任务单元收口必须满足：

1. `tsc -b` 通过；
2. `check:gate` + `test` 绿；
3. **不存在跨单元半迁移态**（例如「parser 已切列宽、渲染仍用字符数」）；
4. 可独立回滚（本单元改动自包含，或整批 revert）。

## 7. 文件域互斥

- 同波次同文件只允许一个执行者。
- 热点文件串行：`parser.ts` / `EditorStore.ts` / `HiddenInput.tsx` / `MarkdownEngine.tsx` / `InlineRenderer.tsx` / `renderToHtml.ts`。
- 新增目录 `src/core/layout/` 为本战役独占。
