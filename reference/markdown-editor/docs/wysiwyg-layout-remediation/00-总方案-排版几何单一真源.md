## 3. 根因断层（G1–G8）

> 全部断层共享**同一个上位根因**：**排版几何没有单一真源**。以下八条是该根因在不同链路的具体显影。

### G1｜缩进语义双轨（字符数 ↔ 列宽）

- 解析层：`listIndent = indent.length`（`parser.ts:2326/2346/2364`）——tab 计 **1 个字符**。
- 列宽层：`leadingIndentColumns` / `textColumns` / `listMarkerInfo` 把 tab 按**停靠 4 列**展开（`parser.ts:1285-1297/1365-1377`）。
- 投影层：`renderToHtml.ts:65-110` 同样按列宽。
- **后果**：同一份源码，`listIndent` 与 `contentIndent` 在 tab 缩进时系统性错位；渲染层拿 `token.indent.length` 算缩进（`InlineRenderer.tsx:745/792/849`），tab 得 1 → 实测缩进 0px（症状 S2）。

### G2｜缩进阶梯是启发式，不是映射

- `computeIndentGuides`（`InlineRenderer.tsx:87-107`）：
  - `indentLen % 3 === 0 && indentLen % 2 !== 0` → `indentStep = 3`；
  - 否则若 `indentLen >= 6 && indentLen % 3 === 0` → **读上一行的缩进**决定 step；
  - 其余 → `indentStep = 2`；
  - `indentGuidesCount = floor(indentLen / indentStep)`。
- **后果**：缩进宽度不是缩进量的函数（还依赖邻行），阶梯非单调、可碰撞（症状 S1）。

### G3｜标记槽无统一几何

- bullet 用 `var(--grid-size)` = 28px 固定槽（`index.css:1046-1051`）；
- task 用 `2em`（`index.css:1074-1079`）；
- 有序列表**没有槽**，`.syntax-marker` 输出自然宽度（`InlineRenderer.tsx:781-786`）。
- **后果**：三种 marker 的内容列各不相同；有序列表连同级项都在抖（Inter 比例数字：`1.` ≠ `2.`，症状 S3/S4）。

### G4｜测量多轨 + 缓存全清 + 死键

- 8 条并行测距轨道（详见 `01-分维` E14）。
- `clearContainerMeasurementCache`（`measure.ts:701-711`）清空全部 token 测量缓存，唯一调用点在**每次光标/选区变化**的 layout effect（`MarkdownEngine.tsx:835`）。
- 缓存键 `index + scrollTop + scrollLeft + decVersion`（`measure.ts:648`）中的 `decVersion` 恒 0（症状 S13）——即装饰变化**根本不在缓存键里**，全靠显式全清兜底；而一旦忘记全清就是 stale。
- **后果**：要么全清（贵），要么 stale（错）。

### G5｜选区高亮与虚拟挂载窗口脱钩

- `SelectionHighlight` 的 effect 依赖 `[decorations, decorationVersion, containerRef]`（`SelectionHighlight.tsx:372`）——**不含滚动位置、不含挂载窗口**。
- 高亮只在「已挂载行」上提取矩形（`SelectionHighlight.tsx:184`），兜底路径同样只遍历已挂载行（`SelectionHighlight.tsx:309-364`）。
- **后果**：滚动导致虚拟器换挂载行后，effect 不重跑 → 矩形留在已卸载的行上 → 视口内高亮消失（症状 S5/S6）。

### G6｜几何常量硬编码

- `--grid-size: 28px` 是**行高**（`index.css:152/222/277`），却被当作**水平缩进单位**（`InlineRenderer.tsx:763/811/888`）。
- `HeightOracle` 的 `lineHeight=28` / `charWidth=8.4` / `containerWidth=800` / `perRow=95` / `step=90`（`HeightMap.ts:184-192`）。
- `TYPE_MULTIPLIER.heading = 1.0`，而同一处的注释写「heading 1.3×」（`HeightMap.ts:28-36`）。
- `LINE_HEIGHT = 28`（`SelectionHighlight.tsx:240`）、`FOLD_PLACEHOLDER_HEIGHT = 28`（`foldState.ts:36`）、`ISLAND_MIN_HEIGHT = 28`（`useTableIslandWiring.ts:84`）、`|| 28` 兜底（`measure.ts:615`、`SelectionHighlight.tsx:204`）。
- **后果**：字号/字体/容器宽一变，全链几何同时漂移且无单一改点。

### G7｜列表嵌套判定规则错误

- `renderToHtml.ts:430`：`(ln.listIndent ?? 0) > indent` → 递归为子列表。
- `renderToHtml.ts:389-395`：`nListIndent >= indent && (nListIndent > indent || nKind === kind)`。
- CommonMark §5.2 要求：子项缩进 ≥ 父项**内容缩进列**（`contentIndent`），而非父项 marker 的缩进列。
- **后果**：`- a` / ` - b`（1 空格）被误判为嵌套（应为同级）；`1. a` / `  2. b`（2 < 3）同样误嵌套。多级嵌套错乱主因。

### G8｜同概念多份实现（SSOT 破裂）

- `leadingIndentColumns` / `stripFourColumns` / `isListMarkerStart` / `textColumns` / `listMarkerInfo` 在 `parser.ts:1285-1377`、`EditorStore.ts:218-257`、`renderToHtml.ts:65-143` **各有一份**（注释自称「镜像」）。
- CJK 宽字符权重 `1.8` 四处复制（症状 S14）。
- Tab 步长：Tab 插 2 空格（`HiddenInput.tsx:2282`）、Shift+Tab 删 1–2 空格（`HiddenInput.tsx:2269`）、粘贴用 2 空格（`htmlToMarkdown.ts:120`）、单测基线用 4 空格（`tests/unit/typography-indent.test.ts:15/25/39`）。
- **后果**：任一处修改必然引发其他处漂移；`scripts/check-ssot.mjs` 的 S2 词表未覆盖这些符号，门禁形同虚设。

## 4. 目标态：排版几何坐标系（L0–L5）

### 反多轨红线（L6 落地）

> **同一概念只允许一条实现。** 新增第二条实现即视为回归；`scripts/check-ssot.mjs` 的 S2 词表必须覆盖本战役引入的全部单源符号。

### L0 `LayoutMetrics` — 度量真源（`src/core/layout/LayoutMetrics.ts`）

**职责**：从真实 DOM **实测**出排版基本量，并向全链广播版本号。

| 量 | 语义 | 来源 |
|---|---|---|
| `lineHeight` | 行盒高 | 实测（探针行盒 `getBoundingClientRect().height`） |
| `spaceAdvance` | 空格前进量 | 实测（探针 span 内含 N 个空格，取斜率） |
| `digitAdvance` | 数字前进量（**取最大数字宽**，保证槽内右对齐） | 实测（0–9 逐个测，取 max） |
| `cjkAdvance` | CJK 全角前进量 | 实测（探针 `中`） |
| `contentWidth` | 内容可用宽 | 实测（容器 `clientWidth` 减内距） |
| `indentUnit` | **缩进单位** = 一个列表层级宽 | 派生：`markerSlot + markerGap`（见 L3） |
| `markerSlot` | 标记槽宽 | 派生：`max(digitAdvance * maxDigits, bulletAdvance) + gap` |

**约束**：字体就绪（`document.fonts.ready`）、容器 resize、字号 token 变化 → 重测并 `version++`。全链**只读此模块**，禁止字面量。

### L1 `IndentModel` — 缩进单一语义（`src/core/layout/IndentModel.ts`）

**唯一语义 = 列宽（columns）**，tab 按停靠 4 展开（CommonMark §Tabs）。

- `expandTabs(s) → TabExpansion`：给出 `columns` 与 **字符下标 ↔ 列宽的双向映射表**（供测量层把「列」还原为「字符下标」）。
- `leadingColumns(s)` / `textColumns(s)` / `stripColumns(s, n)`：**全仓唯一实现**，`parser` / `EditorStore` / `renderToHtml` 全部改为引用。
- 删除 `listIndent`（字符数）字段，改为：
  - `indentColumns: number`（行首缩进列）；
  - `contentIndentColumns: number`（列表项内容起始列，CommonMark §5.2）。

### L2 `ListContext` — 嵌套真源（parser 跨行状态）

**按 CommonMark §5.2 维护列表容器栈**：

- 状态：`{ markerKind: 'ul' | 'ol' | 'task', contentIndentColumns: number }[]`。
- 每行解析前：`while (栈非空 && 当前行缩进列 < 栈顶 contentIndentColumns) pop()`。
- 命中列表标记 → 推入新容器，产出 `listDepth = 栈深 - 1`。
- 未命中标记但缩进 ≥ 栈顶 `contentIndentColumns` → 属该容器内容（continuation），`listDepth` 继承。
- **嵌套判定 = 栈深度**，不再做任何 `>` / `>=` 的数值比较（修掉 G7）。

**产出**：每行带 `listDepth: number`（整数层级）+ `contentIndentColumns: number`。

### L3 `IndentLadder` — 确定性阶梯 + 统一标记槽

- `indentPx(depth) = depth * indentUnit`（`indentUnit` 来自 L0）——**纯函数、单调、无邻行依赖**（修掉 G2）。
- **统一标记槽**：所有 marker（bullet / task / 有序）占同一 `markerSlot` 宽：
  - 有序数字**右对齐**到槽右缘 + `markerGap`；
  - bullet / task 复选框**居中**于槽。
- 内容列 = `indentPx(depth) + markerSlot + markerGap`——三种 marker 完全对齐（修掉 G3）。

### L4 测量收敛（单轨 + 按行失效）

- **一条轨道**：字符 → 坐标唯一入口 = DOM `Range`（Tier1）；仅复合 widget 走盒模型比例投影（Tier2，且比例用**实测前进量**而非等分）。
- **删除重复的像素→行号实现**：保留 `HeightMap.indexAt`（权威偏移表），删除 `HiddenInput.estimateLineIndexFromContentY` / `estimateScrollTopForLine` 的 DOM 几何估算路径。
- **缓存只存内容坐标**：视口坐标 = 内容坐标 + `containerRect.top - scrollTop`（O(1) 加法律，不进缓存）。
- **按行失效**：`clearContainerMeasurementCache` 改为 `invalidateLines(from, to)`——只清受影响行的 token 缓存；装饰版本进缓存键（修掉 S13 死键）。
- **HeightOracle 参数全部来自 L0**：删除 `charWidth=8.4` / `containerWidth=800` / `perRow=95` / `step=90` 字面量；`TYPE_MULTIPLIER` 收敛为「行盒高倍率」并修正 heading。

### L5 选区绑定虚拟挂载窗口

- `SelectionHighlight` 订阅**挂载窗口版本**（虚拟器 `getVirtualItems()` 的行区间 + 滚动位置），窗口变化即重算。
- 选区几何策略：**视口内行 → 精确 `Range.getClientRects()`**；**未挂载区间 → 单块矩形**（保证滚动中即时正确，不出现空洞）。
- `syncDOMSelection` 与高亮**同一帧**完成（`useLayoutEffect`）。

## 5. ADR（架构决策记录，被否决路径禁止回退）

### ADR-1｜缩进语义取「列宽」，不取「字符数」

- **决策**：`indentColumns` / `contentIndentColumns` 为唯一语义；tab 停靠 4 展开。
- **理由**：CommonMark §Tabs 以列定义缩进；渲染与投影已经是列宽口径，取列宽即消除双轨。
- **被否决**：保留 `listIndent` 字符数 + 在渲染层换算（继续双轨，G1 不除）。
- **被否决**：全仓统一改「字符数」口径（与 CommonMark 规范直接冲突）。

### ADR-2｜嵌套层级由容器栈产出，不由数值比较推断

- **决策**：parser 维护 `ListContext` 栈，产出 `listDepth` 整数；渲染层只消费 `listDepth`。
- **理由**：CommonMark 的嵌套是容器语义，数值比较无法表达「内容缩进列」与 lazy continuation。
- **被否决**：在 `renderToHtml` 里继续用 `listIndent > indent`（G7 不除）。
- **被否决**：在渲染层重新做一次容器栈（重复解析，G8 加重）。

### ADR-3｜缩进阶梯为确定性纯函数

- **决策**：`indentPx(depth) = depth * indentUnit`，`indentUnit` 来自实测。
- **理由**：缩进宽度必须是缩进量的函数，否则必然抖动。
- **被否决**：保留 `computeIndentGuides` 的 `%2/%3` 启发式（G2 不除）。
- **被否决**：用 CSS `padding-left: calc(depth * 1.5em)` 的固定 em（与实测 marker 槽不对齐，内容列仍会错位）。

### ADR-4｜标记槽统一，数字右对齐

- **决策**：bullet / task / 有序共用同一 `markerSlot`；数字右对齐，bullet/复选框居中。
- **理由**：内容列对齐是列表可读性的第一要件；Alcove 参考帧亦为内容列对齐。
- **被否决**：让有序列表用自然宽度（G3 不除）。
- **被否决**：用 `font-variant-numeric: tabular-nums` 仅解决同级抖动（`1.`/`10.` 位数不同仍错位）。

### ADR-5｜度量全部实测，禁止字面量

- **决策**：几何常量只允许两个来源——① `LayoutMetrics` 实测；② `:root` design token。
- **理由**：L6 硬红线。
- **被否决**：保留 `28` / `8.4` / `800` 等字面量并加注释说明（注释不是 SSOT）。
- **例外**：`--grid-size` 可继续作为**行高** token，但**禁止**再作为水平缩进单位（新增 `--indent-unit`）。

### ADR-6｜测距单轨 + 按行失效

- **决策**：字符→坐标唯一入口 = DOM Range；缓存只存内容坐标；失效按行。
- **理由**：多轨必然漂移；全清必然贵或 stale。
- **被否决**：保留 8 轨并用「同帧缓存」合并（治标）。
- **被否决**：改用 Canvas `measureText` 全量预排版（与真实 DOM 排版存在字形/换行差异，反而引入新断层）。

### ADR-7｜选区高亮绑定虚拟挂载窗口

- **决策**：高亮重算的触发集 = 选区变化 ∪ 挂载窗口变化 ∪ 滚动。
- **理由**：虚拟滚动下「DOM 里有什么」不等于「文档里有什么」，选区语义必须绑文档、几何必须绑窗口。
- **被否决**：只加 `scroll` 依赖（挂载窗口变化与滚动不完全同步，仍会漏帧）。
- **被否决**：为选区强制挂载全部行（放弃虚拟化，性能不可接受）。

### ADR-8｜标记槽「固定宽度 + 槽内揭示」——零跳变（L9/L13）

- **决策**：列表标记（bullet / task / ordered）**共用同一固定宽度槽** `--marker-slot`；源码层与视觉层在槽内**叠放**（`position:absolute; inset:0`），激活态经**透明度交叉淡入**切换，**槽宽恒定**。
- **理由**：L9「避免跳变」+ L13「减少模式摩擦」。内容列是列表可读性的锚点，任何编辑交互都不得移动它。旧实现把三种 marker 放在**三个不同宽度的盒**里（bullet 28px / task 2em / ordered 自然宽），激活时再切换 `display`，导致内容列在「进入 / 离开编辑」时移动（断层 G3 + 模式摩擦）。
- **推论（零跳变不变量 I13）**：对任意列表行，`激活态内容列 === 非激活态内容列`（几何断言，见 `04-分维` §3）。
- **被否决**：激活时隐藏视觉层、展开源码层（旧实现；视觉跳变 + 潜在回流）。
- **被否决**：让有序列表继续用自然宽度（G3 不除）。
- **被否决**：用 `font-variant-numeric: tabular-nums` 仅解决同级抖动（`1.`/`10.` 位数不同仍错位）。

### ADR-9｜公式「源码与渲染同现」——编辑不牺牲呈现（L12）

- **决策**：行内 / 块级公式在**编辑态与呈现态都渲染**；编辑期额外显示源码，二者**同现**，不做「激活退回源码、失焦才渲染」的二元切换。
- **理由**：L12 明文要求；L13 的上位目标是消除模式感。公式的渲染结果本身就是用户要读的内容，编辑时把它抽走等于「为了改字而失读」。
- **约束**：同现实现必须满足 ADR-8 的零跳变——公式块的**占位几何恒定**（渲染盒宽高不随激活态变化）。
- **被否决**：保持现状的 `syntax-hidden` / `syntax-content` 二元切换。
- **被否决**：编辑期只显示源码、失焦才渲染（正是 L12 要消除的形态）。

## 6. 不变量（I1–I12，验收即断言）

| # | 不变量 | 断言方式 |
|---|---|---|
| I1 | 缩进阶梯**单调**：`depth` 大者物理缩进严格大 | 单测：depth 0..6 的 `indentPx` 严格递增 |
| I2 | 缩进阶梯**确定**：同 `depth` 必得同宽度，与邻行无关 | 单测：置换邻行内容，宽度不变 |
| I3 | **tab 与空格同语义**：`\t- x` 与 4 空格 `- x` 产出相同 `indentColumns` / `listDepth` | 单测：两文档 AST 字段相等 |
| I4 | **三种 marker 内容列对齐**：同 depth 下 bullet / task / 有序的内容起始 x 相等 | e2e：实测 `Range` 左缘差 ≤ 0.5px |
| I5 | **有序列表跨位数内容列对齐**：`1.`/`10.`/`100.` 内容起始 x 相等 | e2e：同上 |
| I6 | **嵌套判定符合 CommonMark**：`- a` + 1 空格 `- b` 为同级；`1. a` + 2 空格 `2. b` 为同级 | 单测：`listDepth` 相等 |
| I7 | **缩进语义单轨**：全仓 `leadingColumns` / `textColumns` / `stripColumns` 各只有一处定义 | 门禁 `check-ssot` S2 |
| I8 | **几何零字面量**：`src/` 无裸 `28` / `8.4` / `800` 用于几何 | 门禁 `check-geometry-literals` |
| I9 | **选区跨视口可见**：任意选区在滚动后视口内必有高亮矩形（非空选区 ∩ 视口 ≠ ∅） | e2e：滚动前后各测一次 |
| I10 | **缓存失效按行**：光标移动不清空全文 token 缓存 | 单测：`invalidateLines` 只清目标行 |
| I11 | **测量坐标单轨**：`src/` 只有一处「像素 → 行号」实现 | 门禁 `check-ssot` S2 |
| I12 | **无多轨残留**：不存在「旧路径 + 新路径」并存的特性开关 | 门禁：扫描 `enable*Layout` 类开关 |
| I13 | **零跳变**：列表行的内容列在「激活 / 非激活」两态下相等（差 ≤ 0.5px） | e2e：同一行取两次几何（光标进入前后）比对 |
| I14 | **公式同现**：公式 token 在激活态下渲染结果**仍然存在且可见**（非 `display:none`） | e2e：光标置于公式内，断言渲染盒可见且尺寸不变 |
| I15 | **槽宽恒定**：三种 marker 的槽宽相等，且等于 `--marker-slot` | e2e：实测三种 marker 槽宽一致 |
