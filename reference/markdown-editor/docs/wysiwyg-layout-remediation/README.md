## 3. 一句话根因与目标态

- **根因**：排版几何**没有单一真源**——「缩进」在解析层是字符数、在投影层是列宽、在渲染层是 `--grid-size`（行高！）的倍数；「位置」有 8 条互不知晓的测距轨道；「选区」只认已挂载的 DOM 行。三者派生 8 条断层 G1–G8。
- **目标态**：建立**排版几何坐标系**——一个度量真源（`LayoutMetrics`，全部实测）、一个缩进语义（`indentColumns` 列宽）、一个嵌套真源（`ListContext` 容器栈产出的 `listDepth`）、一条测距轨道（DOM Range）、一个选区契约（绑定虚拟挂载窗口）。

## 4. 关键约束速查

| 约束 | 内容 |
|---|---|
| 效果锁 | 不得降级为「调 CSS / MVP 砍功能」；L1–L7 见 `00-总方案` §1 |
| 禁止回退 | ADR 的「被否决」路径一律不得实现（`00-总方案` §5） |
| 禁止多轨 | 同一概念**只允许一条实现**；新增第二条即视为回归（`00-总方案` §4 反多轨红线） |
| 禁止硬编码 | 几何常量必须来自 `LayoutMetrics` 实测或 `:root` token（`04-分维` §4 门禁） |
| 测试资产 | 只增不减；禁止 `--no-verify`、禁止 `skip`/恒真断言（`00-调度` §4） |
| 提交权 | 仅主 Agent 可提交；子 Agent 严禁 commit/reset/checkout/restore/rebase（`00-调度` §2） |
| 文件域 | 同波次同文件只能一个 Agent；热点文件错开波次（`00-总方案` §8） |
| 禁止半成品 | 每期收口必须「可编译 + 门禁绿 + 可回滚」（`00-调度` §6） |
