# 源码投影与交互闭环

本分维延续 `00-总方案-排版几何单一真源.md`，补齐测距、选区、列表容器和混合渲染的端到端契约。输入证据来自 2026-09-14 的当前工作区审计；工作区仍在并发迁移，旧行号和旧样式必须在修改前重新核对。

## 1. 与并行工作的边界

- 既有 T1–T9 已覆盖度量探针、列宽模型、列表标记槽、测量缓存与虚拟窗口订阅，不再另造同名实现。
- 表格战役正在 T5b：表格选区相对坐标、结构变更重映射、岛内导航。表格岛仍是表格布局与高级交互的所有者；本分维不复制表格布局或整表源码编辑器。
- 活跃文档的续航锚点可能落后于代码。判断实际状态同时查看任务文件域、当前内容、修改时间和差异；已被并发修复的问题只验证，不重做。
- 独立模块和回归测试先行。`parser.ts`、`measure.ts`、`HiddenInput.tsx`、`SelectionHighlight.tsx`、`MarkdownEngine.tsx`、`InlineRenderer.tsx` 等共享接线文件逐段串行修改；应用修改前重新读取，不覆盖整份并发文件。

## 2. 已复现的根因

| 问题 | 触发方式 | 根因与修复契约 |
| :-- | :-- | :-- |
| 嵌套标记边界映射错误 | 对 `**bold**` 的末尾标记做源码→DOM→源码往返 | token 按起点排序，但结束位置并不单调；使用真实包含区间与显式文本映射，不因遇到短子 token 而漏掉父 token |
| 转义与实体错位 | `A\\*B`、`&amp;`、含代理对的实体 | 可见字符数不等于源码长度；解析时保留边界映射，点击、光标和复制共同消费 |
| 反向选区丢方向 | 从右向左选择后同步原生选区 | 排序后的范围不能替代锚点与活动端；使用原生 anchor/focus 同步并判等，消除异步事件回声 |
| 扩展选区随即折叠 | Shift+Home/End、Ctrl+Shift+Home/End | 设置选区后又调用折叠光标动作；所有导航只提交一次端点变换 |
| 组合输入被导航打断 | compositionstart 后收到方向键 | 输入法拥有组合事务期间，文档导航不得抢占按键 |
| 列表容器不同源 | 同一文本分别加载、逐行渲染和流式追加 | 所有路径消费同一容器状态；任务复选框是内容装饰，不增加 CommonMark 列表容器缩进 |
| 选区触发布局改变 | 跨粗体、链接、列表和公式拖选 | 选择行为不得改变正文投影；编辑表面与预览装饰有显式身份，测量不把预览文字当作源码 |
| 公式编辑抽走结果 | 激活多行数学块 | 块级与行内公式都要保持预览；源码编辑区不能以隐藏渲染结果为前提 |

## 3. 单一投影契约

1. 文档偏移保持源码 UTF-16 偏移，与编辑事务一致。键盘、删除与鼠标端点必须落在完整字素边界。
2. 解析得到的文本投影携带源码边界。相同文本无需分配映射；转义、实体和代码跨度规范化必须保留映射，不能在测量层按宽度或字符串相似度猜测。
3. 渲染 DOM 明确区分文本编辑面、隐藏语法和预览装饰。预览内容永不进入源码文本计数；高级控件只暴露真实可编辑面或原子边界。
4. 源码→DOM 与 DOM→源码共用同一组投影节点。隐藏源码区间投影到相邻可见边界，并保留边界亲和性；不制造控件内部不存在的插入点。
5. 光标和选区读取同一份浏览器 Range 几何。折行、比例字体和双向文字按实际行片段处理，禁止整块宽度等分和固定行高取整。
6. 几何缓存属于编辑器实例，储存内容坐标；字体、宽度、内容或投影变化才失效。滚动只变换坐标，不能触发源码重新解析。

## 4. 编辑与呈现规则

- 普通正文的粗体、斜体、链接、引用和列表在光标移动、拖选时保持同一内容列与折行。格式语义不通过切换整行源码来编辑。
- 表格整体保持高级交互；单元格编辑面可以混合渲染，但其源码映射与正文同源。
- 公式编辑时同时显示源码和渲染结果。预览区域保持身份与位置；源码显示区独立于预览，不参与其字符计数。无效公式也不能阻断源码编辑。
- 输入宿主保持挂载；视口外暂时没有可测光标时，只隐藏光标表现，不卸载输入法和键盘事件宿主。
- 光标位置没有补间动画。光标、隐藏输入和选区在同一布局周期读取真实位置，不靠多帧盲重试追赶布局。
