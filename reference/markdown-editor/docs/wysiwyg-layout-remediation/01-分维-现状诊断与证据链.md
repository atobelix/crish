## 2. 证据台账（E1–E24）

### 缩进语义（G1）

| # | 结论 | 证据 |
|---|---|---|
| E1 | `listIndent` 是**字符数**（tab 计 1 字符），与列宽语义冲突 | `parser.ts:2326`（task）/ `parser.ts:2346`（bullet）/ `parser.ts:2364`（number）：`listIndent = indent.length` |
| E2 | 同一文件内另有**列宽**实现，tab 停靠 4 列 | `parser.ts:1285-1297` `leadingIndentColumns`；`parser.ts:1365-1377` `textColumns`；`parser.ts:1304-1319` `stripFourColumns` |
| E3 | 渲染层用 `token.indent.length` 算缩进引导数 → tab 得 1 → 引导数 0 | `InlineRenderer.tsx:745-748`、`:792-796`、`:849-853`；实测 `\t- b` → `indentPx = 0` |
| E4 | 投影层已按列宽，与 `listIndent` 不同口径 | `renderToHtml.ts:65-110`（`stripIndentColumns`/`textColumns`/`leadingIndentColumns`） |

### 缩进阶梯（G2）

| # | 结论 | 证据 |
|---|---|---|

| E6 | 实测阶梯非单调：3 空格 → 1 级（28px）；6 空格 → 3 级（84px）；9 空格 → 3 级（84px，与 6 空格**同宽**） | `scratch/geom-probe-indent-jitter.mjs` B 组 |

### 选区（G5）

| # | 结论 | 证据 |
