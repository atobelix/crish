## 1. 现状关键结论（6 维分析精华，证据见各分析文档）

1. **数据链路**：StreamBuffer 零生产调用方（测试 7 例 + perf 内联镜像）；真实宿主形态 = 每 token 一次 React 提交（500/s）且**从未被压测**（perf 压测是 rAF 聚合形态）；appendText 每次 5-6 处 O(#blocks) 树操作（只读场景可短路）；C4「滚动触达合并尾段」注释与实现漂移（滚动监听只 flush 直刷累积，从不调 store.flushStreamTail）。
2. **渲染管线**：`&` 未入 DIRECT_STREAM_FORBIDDEN_CHARS → 含 `&amp;` 行直刷字面文本、flush 后跳变解码值（**红线，S-EL-01 击穿**）；canDirect 实为 7 条件、isPlainTextLine 直刷覆盖仅 25-50%（数字/`.`/`=`/`+` 误拒）；组件卸载无 flush（pending 文本丢失）；引擎内 rAF 仅 1 处（滚动合并），直刷同步零提交优于帧聚合模型。
3. **代码块流式**：软渲染只渲染 `{block.raw}` 纯文本，高亮延迟≈整块生成时长，但 parseCodeLine 三色 token 早已生成被丢弃（**C5 复用即 P0**）；LangRenderer 每行重建整块 lines 数组 O(块)（json/diff/log 只消费 lineText）；markdown.worker.ts 是死代码（宿主红线 RL-05 禁 worker 池 → **不做 Worker 高亮**，主控裁决 1）；computeFenceContext 尾段线性扫描；高亮语言无关（30 个 JS/TS 关键字，python/sql 零高亮）。
4. **表格流式**：流式尾表提前锁宽 bug（`nextLn === null` 把流式尾段当闭合，MarkdownEngine.tsx:1315，锁死在表头宽度且永不重定型）；长表锁宽依赖滚动时机（窗口外 sepIdx=-1 跳过）；流式中零列宽估算（flex 1 1 0% 全列等宽）；表格判定宽容无回退（`| a` 误判 table_row）；`:---:` 对齐语义未实现。
5. **宿主接口**：App.tsx 零流式接线；引擎无滚动跟随（dirtyRowOutOfViewRef 可复用但常规路径恒 false——评审修正 D-3）；API 缺口：状态查询/暂停恢复/完成中断信号/discard/导出/直刷计数；EL-08 契约仅半支撑；aria-live 静默。
6. **测试与基准**：流式正确性测试资产强（73 文件/959 用例全绿，append 三族穷举）；M2c 假 PASS（引擎流式注入时复位锁死 scrollTop）；M3 选区丢失 B3 缺陷已量化（33.3% lossRate）；M6 表格锁宽引擎零调用方；M2a 锚点采样失效；无 vitest.config；两个 _scratch 文件入库待处置。
