## 3. 选区设计（ADR-6 落地）

### 3.1 身份：表内相对坐标

`CellSelection` 由「绝对行号」改为「表内相对坐标」。**语义基准**：`row` = 该表在 `TableModel.rows` 中的下标（`0` = 该表第一条源码行；**含表头行**）；**分隔行不占行号、不可被选中**（现状已在 `HiddenInput.tsx:1357,1416,1461,1470` 跳过分隔行，语义不变）；`col` = 列下标，与 `TableModel.cols` / `tableWidths` 同序。

```ts
/** 表内相对坐标（row/col 均相对该表，不携带文档绝对偏移） */
export interface CellCoord { row: number; col: number }

export interface CellSelection {
  /** ADR-3 的稳定块身份（不再是「首行行号」推导值） */
  tableId: string;
  /** 拖选锚点（Shift 扩展的固定端） */
  anchor: CellCoord;
  /** 拖选焦点（当前活动单元格；单选时 anchor === focus） */
  focus: CellCoord;
  /** false = 单元格选区（矩形）；true = 单元格就地文本编辑（单格） */
  isEditing: boolean;
}

/** 归一化：min/max 由纯函数派生，禁止在各消费点各自求 min/max */
export function normalizeSelection(sel: CellSelection): {
  r0: number; r1: number; c0: number; c1: number;
};
```

- **不变量**：`selectedCell` 内**不得**出现绝对行号；绝对行号 ↔ 相对行号的换算**只在 `TableBlock` 内**经 `TableModel.startLine + row`（并跳过分隔行）进行一次，禁止在 `InlineRenderer` / `TableToolbar` / `HiddenInput` 各自换算。
- 过渡期（T2 自愈期）：`TableStore` 读取 `selectedCell` 时校验 `tableId` 是否命中当前 `TableModel`，未命中即 `clearCellSelection()`（对应 ADR-3 的「列数不符即丢弃重算」同款自愈）。
- `setColumnWidth`（`TableStore.ts:20,40`）为死代码（`01-分维` C14），本维**不**复活它：列宽写入统一走 `setTableWidths`（ADR-4 的 `<col>` 真源）。

### 3.2 重映射规则表（I7 的可执行规格）

所有重映射由纯函数实现并单测（落点 `tests/unit/table-selection-remap.test.ts`，`00` §10 已登记）：
`remapSelection(sel: CellSelection | null, op: TableStructOp): CellSelection | null`，其中 `TableStructOp` 是判别联合：`insertRow | deleteRow | insertCol | deleteCol | moveRow | moveColumn | merge | unmerge | setHeader | deleteTable`。

记归一化后选区为 `[r0..r1] × [c0..c1]`；`d` = 被删/被移动的行（列）下标；`p` = 插入位（新行占据的下标）。

| 操作 | 选区结果 | 语义理由 |
|---|---|---|
| 插入行，`p ≤ r0`（选区**上方**） | `anchor.row+1`、`focus.row+1` | 选区跟随原内容，形状不变（I4 的表格内版本） |
| 插入行，`r0 < p ≤ r1`（选区**内部**） | `r1+1`（选区扩张，含新空行） | Excel 语义：在选区内插行 → 选区包含新行 |
| 插入行，`p > r1`（选区**下方**） | 不变 | 选区内容未被触碰 |
| 删除行，`d < r0` | 两坐标 `−1` | 选区跟随原内容上移 |
| 删除行，`r0 ≤ d ≤ r1` | `r1−1`（收缩）；若 `r0 > r1` 则收缩到 `min(d, 行数−1)` | 选区保留剩余部分；单格被删时落到最近邻 |
| 删除行，`d > r1` | 不变 | 无关行 |
| 删除行致表消失 | `null`（`clearCellSelection`） | 语义载体已不存在（现状 `TableOperations.ts:245-250` 即删整表） |
| 插入列，`p ≤ c0` / `c0 < p ≤ c1` / `p > c1` | 与行三条同构（`col ±1` / 扩张 / 不变） | 列与行对称 |
| 删除列，`d < c0` / `c0 ≤ d ≤ c1` / `d > c1` | 与行三条同构；删致 `cols == 0` → `null` | 现状 `TableOperations.ts:323-328` 删至一列即删表 |
| 合并 | 收缩为 `{r0,c0}` 单格，`isEditing=false` | 与现状 `TableToolbar.tsx:85-89` 语义一致，仅改为相对坐标 |
| 拆分 | 收缩为 master 单格 `{r0,c0}` | 拆分后 master 仍是唯一语义格 |
| 行重排（`moveRow d→p`） | 若 `[r0..r1]` 与移动区间相交：按同一置换映射；整行选中时选区跟随该行；否则不变 | 选区语义是「这些行」，不是「这些行号」 |
| 列重排（`moveColumn d→p`） | 与行重排同构 | 同上 |
| 表头开关（`setHeader`） | 全部 `row ±1`（表头行被插入/移除），`col` 不变 | `row` 基准含表头行 → 表头开关是一次「在 `p=0` 处插/删行」 |
| 整表删除 | `null` | — |

**接线约束**：`TableOperations.insertRow` 的 `above` 分支对「表头/分隔行」有特判（`TableOperations.ts:192-206`），重映射**必须**消费 `TableModel` 给出的插入位 `p`，禁止在渲染层或工具条再推导一次插入位（否则重演 D2 的「反复重新推导」）。

### 3.3 单矩形绘制

- **定位键**：单元格补 `data-row-index`（表内相对行号）与既有 `data-col-index`（`InlineRenderer.tsx:546-548`）并列，由 `TableBlock` 统一注入；禁止用 `data-line-index` 反查（E8）。
- **求值（4 角法）**：
  1. 取岛容器 `islandEl.getBoundingClientRect()` 与 `islandEl.scrollLeft/scrollTop`；
  2. 取 4 角单元格 `rectOf(r0,c0)`、`rectOf(r1,c1)`（跨列合并时取 master 的 rect 并按 `colSpan` 右边界扩展）；
  3. `left = min(tl.left, bl.left) − islandRect.left + scrollLeft`；
     `top = min(tl.top, tr.top) − islandRect.top + scrollTop`；
     `width = max(tr.right, br.right) − islandRect.left + scrollLeft − left`；
     `height = max(bl.bottom, br.bottom) − islandRect.top + scrollTop − top`。
- **绘制位置**：岛内绝对定位层（岛容器 `position:relative`）：
  ```css
  .table-selection-layer { position: absolute; inset: 0; pointer-events: none; z-index: var(--z-selection); }
  .table-selection-rect  { position: absolute; box-sizing: border-box;
                           border: 2px solid var(--blue-selection-border);
                           border-radius: 0; background: transparent; }
  ```
  `--z-selection` 与 `--blue-selection-border` 均为既有令牌（`index.css:93`、`index.css:45`），不新增颜色/层级常量。
- **描边规格**：2px、方角、无填充（F-Vis-7）。与现状的差异必须显式消除：删除 `InlineRenderer.tsx:503-539` 的 `selectionShadow` 分支；`.is-cell-selected` 降级为「仅 `position:relative` + `z-index` 提升」（保留类名以兼容既有 e2e `table-cell-modes.spec.ts:27`），**不得**保留 `inset` 描边（`index.css:508`）与 `border-radius:2px`（`index.css:511`）。
- **重算时机（唯一依赖集）**：选区状态（`anchor/focus/isEditing`）、`tableWidths[tableId]`（列宽定型）、岛 `offsetHeight`（`ResizeObserver`）、岛 `scrollLeft/scrollTop`、岛内行窗口 key、`window.resize`。用**一个** `useLayoutEffect` + 一个 RO 承接；**禁止** rAF 轮询、`setTimeout` 补偿、坐标测距魔术数字（`00` §9.2 规则 5）。
- **填充柄迁移**：`.table-fill-handle` 类名与几何保留（`index.css:536-547`、e2e 契约），宿主由「单格内部」迁到岛覆盖层（E8），避免跨格拖拽填充时的逐格 DOM 抖动。

### 3.4 跨窗口 / 越界语义

| 场景 | 规格 |
|---|---|
| 选区水平超出岛可视区 | 岛是唯一横向滚动所有者（I1/ADR-2），矩形随内容滚动，超出部分由岛 `overflow` 裁切；不额外绘制第二滚动容器 |
| 岛内行窗口化（ADR-2 代价项）导致角单元格**未挂载** | 几何改由「已定型列宽累加（`tableWidths`）+ 行高缓存累加」推算；行高缺项时用 `HeightMap` 的岛高度初值口径（ADR-5），**禁止**为测量临时挂载/延时重试 |
| 矩形被裁切 | 在裁切方向绘制 `.table-selection-overflow`：岛可视边缘内 2px 的实心条带 + 三角箭头，颜色 `--blue-selection-border`，语义「选区继续延伸」 |
| 整个岛被外层虚拟化移出视口 | 覆盖层随岛一并卸载，不产生游离矩形（对应 I8 的「无重复节点」精神） |
| 选区折叠（`anchor === focus` 且 `!isEditing`） | 仍绘制单矩形（单格描边），与现状「单格 `0 0 0 1.5px`」视觉等价（`InlineRenderer.tsx:518-522`） |

## 4. 交互范式设计（ADR-8 落地）

### 4.1 hover 就近图标工具条（F-Hint-1/2/3）

- **组件**：`src/components/TableHoverBar.tsx`（新）。`data-table-hover-bar` 作为 e2e 锚点。
- **触发**（落实 L3）：在岛容器上做 `pointerover` 委托，命中 `[data-row-index][data-col-index]` 即记录 `hoverCell`；**不依赖 `selectedCell` 是否存在**。无 `hoverCell` 时锚回落到选区 `focus` 单元格。隐藏条件：`pointerleave` 岛且 `pointerout` 的 `relatedTarget` 不在工具条内 → **立即隐藏**（不用延时计时器）；`Escape` 与岛卸载同步隐藏。
- **定位算法**（全部相对关系，无新魔术数字）：① 锚 = `hoverCell`（无 hover 时回落 `focus`）单元格 rect；② 首选位 `top = anchor.top − barHeight − GAP`、`left = anchor.left + anchor.width/2 − barWidth/2`；③ 夹取 `left = clamp(left, islandLeft + EDGE, islandRight − barWidth − EDGE)`，若 `top < islandTop` 则翻转到 `anchor.bottom + GAP`；④ 硬约束（F-Hint-3）：工具条 rect 与 `anchor` rect **不得相交**，与视口四边各留 `EDGE`；⑤ 跟随：岛的 `scroll`/`resize`、窗口 `resize`、列宽定型均触发重算——与 §3.3 的依赖集**同一套**（避免两套几何真源）。`GAP`/`EDGE` 取自既有 `--grid-size`（`index.css:643` 已在用），不新造常量。
- **上下文动作裁剪矩阵**（F-Hint-2）：

| 上下文 | 判定 | 动作集 |
|---|---|---|
| 单格（非编辑） | `r0==r1 && c0==c1 && !isEditing` | 加粗 / 斜体 / 删除线 / 行内代码 / 单元格换行 · 上方插行 / 下方插行 / 左侧插列 / 右侧插列 · 删除行 / 删除列 · 对齐（左/中/右）· 复制 / 粘贴 |

| 整行（行手柄打开） | 由 affordance 打开 | 上方插行 / 下方插行 / 删除行 / 行重排（拖拽） |
| 编辑态 | `isEditing` | 加粗 / 斜体 / 删除线 / 行内代码 / 单元格换行（结构动作全部隐藏，与现状 `HiddenInput.tsx:1531+` 的编辑态分支一致） |

### 4.2 边缘 affordance（F-Aff-1..5、F-Vis-5/6）

**共同约束**：全部 affordance 渲染在**岛容器内部**（同一 `overflow` 所有者，ADR-2），禁止在岛外另建定位容器（否则重演 D1/S1 的多滚动所有者）。

| 控件 | 触发条件 | 定位几何 | 点击语义 | 源码操作 |
|---|---|---|---|---|
| 列上缘 `-`（列控制点） | hover 该列（表头或该列任一单元格） | `-` 中心 X ≈ 该列中心 ±2px；底边 ≈ 表格上边界（F-Vis-5）；纵向悬于表格上边界外 `GAP` | 打开列操作菜单（左插/右插/删列/对齐×3/排序/拖拽重排） | `deleteColumn`（`TableOperations.ts:319`）、`insertColumn(text, cursorPos, 'left'\|'right')`（`:274`）、`setColumnAlign`（`:363`） |
| 表格右缘 `+`（追加列） | 岛 hover 时浮现（参考帧 17 为常驻形态） | 圆角药丸，中心 Y ≈ 表格垂直中心 ±2px（F-Vis-4）；定位在**岛视口右缘**（不随内容横向滚动，语义是「追加到末尾」） | 在**末尾追加一列** | 需新增纯函数 `appendColumnAtEnd`（现状 `insertColumn` 只能相对 `activeCellIndex`，`:274-278`），落 T6 |

| 行左缘 `+`（追加行） | hover 行时与手柄同现（参考帧 9 的 `+ Add item` 同构） | 手柄邻域，与手柄同基线、间距 `GAP` | 在**末尾追加一行** | `appendRowAtEnd`（`TableOperations.ts:672`，**已存在但零入口**，`01-分维` C14）→ 直接接线 |

- 列手柄拖拽 → 列重排：需新增 `moveColumn(text, from, to)`；与 §4.3 同一协议。
- 每个 affordance 的可访问性：`aria-label` 中文 + `title` 中文 tooltip；图标本体无文本（F-Vis-10）。

### 4.3 拖拽重排协议（F-Drag-1/2/3，零幽灵）

| 阶段 | 视觉 | 状态 | 退出条件 |
|---|---|---|---|
| 起手 | 手柄 `cursor:grabbing` | `pointerdown` 在手柄上 + 位移 **> 4px 阈值**才进入拖拽；未过阈值不进入（避免误触） | 位移达标 / `pointerup` |
| 拖拽中 | 源列/行元素 `opacity: .35`（参考帧 18，F-Drag-1）；**不复制 DOM、不新建列元素** | 落点 = 相邻列/行的边界；绘制 `.table-drop-indicator`（2px 蓝线，纵向跨整个表格高 / 横向跨整个表格宽，颜色 `--blue-selection-border`） | `pointerup` / `Escape` / `pointercancel` |
| 完成 | 落点以**蓝色高亮**标示（F-Drag-2，参考帧 10）：`is-drop-landed` 类，一次 rAF 后淡出（视觉反馈，非几何重算） | 纯函数变换源码 → `applyTableChange` → `remapSelection`（§3.2）→ 列宽数组按同一置换 `setTableWidths` → 选区 col/row 按同一映射重映射 | — |

- **与 `tableId` / 选区 / 列宽的交互**：拖拽期间冻结 `isDraggingCell` 的选区扩展路径（现状 `InlineRenderer.tsx:635-650` 的 `onMouseEnter/onMouseMove` 需按拖拽种类分流：选区拖拽 vs 结构重排拖拽）；重排完成后列宽数组**必须**同序置换，否则触发 D3（列宽落到错误列）。
- **零幽灵硬约束**（对应症状 S2）：断言「拖拽前后该表格的列元素计数不变」「取消后 `.table-drop-indicator` 计数为 0」；实现上靠「只改源码 + 只改透明度 + 只画指示线」，**禁止**任何 DOM 级移动/克隆/临时插入。

### 4.5 左缘行指示器（gutter）：F-Vis-6 / F-Vis-9

- **现状候选来源（未定位，禁止凭猜测归因）**：① `BlockTypeBadge`（`BlockTypeBadge.tsx:13-30,47-49` + `index.css:1868-1891`）——但其定位是 `position:fixed; top:56px; right:26px`（**右上角**，与实测左缘不符），且 `deriveMarker` 对 `|` 开头行返回 `|`（`BlockTypeBadge.tsx:22`）；② 分隔行激活时从 0 撑到 28px 并显示源码（`index.css:441-460`）；③ 表格管道符仅在激活行显示（`index.css:462-468`）。三者均无法解释「左缘竖条与单元格文字粘连」。
- **归属裁定**：左缘行指示器属**行级装饰（gutter）**，**不属于** `BlockTypeBadge`（后者是视口固定右上角徽标，`index.css:1869-1871`），也**不属于**表格岛——表格岛**不得**自绘行指示器。
- **本战役整改边界（F-Vis-6 / F-Vis-9 的表格侧）**：
  1. 同一时刻左缘指示器元素计数 ≤ 1（禁止 `BlockTypeBadge` 与行级 gutter 在同一行同时命中）；
  2. 指示器包围盒与任一单元格文字包围盒**无交集**（几何断言，0 容差）；
  3. 表格行 hover 时左缘由**行手柄**接管（§4.2），行指示器让位；
  4. 表格行**不参与**「行级 gutter 高亮」的绘制（表格的行级视觉由岛统一负责，避免 `contain:paint`（`index.css:955-957`）下的装饰裁切）。
- **越界项**：正文侧 gutter 的双竖条叠加（参考帧 15，`02-分维` 帧 15 批注）与 `BlockTypeBadge.deriveMarker('|')` 分支的清理归 T8；本维只落上表 4 条。
