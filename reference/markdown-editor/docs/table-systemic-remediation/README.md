## 3. 一句话根因与目标态

- **根因**：表格不是**一个块**，而是 **N 个互不相识的虚拟行**——语义（表头/列宽/对齐/选区/滚动/导出）都在「行」这一层被反复重新推导，派生 8 条断层 D1–D8。
- **目标态**：表格成为**自包含布局岛**——一个语义模型（`TableModel`）作唯一真源，一个容器 DOM 作唯一布局与滚动所有者，一次测量决定高度，一个矩形表达选区，一套投影同时服务编辑与导出。

## 4. 关键约束速查

| 约束 | 内容 |
|---|---|
| 效果锁 | 不得降级为「调 CSS / MVP 砍功能」；L1–L6 见 `00-总方案` §1 |
| 禁止回退 | ADR 的「被否决」路径一律不得实现（`00-总方案` §5） |
| 测试资产 | 只增不减；禁止 `--no-verify`、禁止骗 CI（`00-调度` §4、`08-分维` §11） |
| 提交权 | 仅主 Agent 可提交；子 Agent 严禁 commit/reset/checkout/restore/rebase（`00-调度` §2） |
| 文件域 | 同波次同文件只能一个 Agent；跨期可串行；热点文件错开波次（`00-总方案` §8） |
| 禁止半成品 | 每个任务单元收口必须「可编译 + 门禁绿 + 旧路径仍可用」（`00-调度` §6） |
| 待用户确认 | U1（漂浮 `-` 来源定位）、U2（行内公式源码/渲染同现）、U3/U4（行序错乱与灰色重影归属）、U5（`LINE_HEIGHT` 去硬编码是否越界）（`00-总方案` §13.2） |
