## 3. 表格岛设计（ADR-2 / ADR-4 / ADR-5 落地）

### 3.1 DOM 结构

```
<div class="virtual-row virtual-row-gpu" data-index={startLine}>   ← 外层唯一虚拟项（E12/E18）
  <div class="table-island" data-table-id={id} style="--table-cols: 128px 96px minmax(140px,1fr)">
    <div class="table-island-track">                 ← width:max-content; min-width:100%
      <div class="table-island-probe" aria-hidden>   ← 离屏测量行：absolute; 0×0; overflow:hidden
        <span class="token-table-cell table-island-probe-cell">…</span> × cols
      </div>
      <div class="table-island-header" role="row">   ← sticky；与正文行同列网格
      <div class="table-island-pad-top" aria-hidden>  ← 上哨兵（窗口前各行高之和）
      <div class="table-island-row" data-line-index={i}>  ← 岛内行（grid-template-columns: var(--table-cols)）
      <div class="table-island-pad-bottom" aria-hidden>
```

- 岛根 `.table-island` 是**唯一** `overflow-x:auto` 所有者（`overflow-y:hidden`、`width/max-width:100%`），横向滚动条只有一条（F-Vis-3）；`table-last-row` hack（E2）在 T8 删除。
- **为什么不用原生 `<table>`（ADR-2 已否决，理由写清）**：① 原生表格的列宽/行高由表格布局算法整体求解（`table-layout:fixed` 需要完整列结构、`auto` 随内容与视口浮动），无法只挂载「窗口内若干行」而不引起整表重排与高度塌陷，与行式虚拟化（E18）正面冲突；② `<thead>` 的 sticky 与表格布局、`overflow-x` 滚动容器的交互在各引擎不一致，无法作为「一个虚拟项」的稳定高度来源；③ `<colgroup><col>` 只在真实表格布局中生效，若为它引入 `<table>`，列宽真源会从「一次测量」退化为「浏览器二次求解」，与 ADR-4/I2 冲突。
- 岛内行复用既有 `BlockRenderer` 渲染路径（保活「活动行显源码」、行内 token/KaTeX、单元格模式），但**不再自带滚动容器**：新增裸行变体（`tableIsland` 透传，接线点 E20），关闭该变体即回到 `TableRowBlock`/`TableSeparatorBlock` 的旧结构（开关关闭零风险）。
- 活动行：岛内行由岛按 `activeState` 命中自行加 `is-active-line`（`index.css:453-460`、`:466-468` 依赖该 class；`BlockRenderer.tsx:1540` 现状未加，属 `01-分维` V3 待验证项——岛路径是它的接线点）。
- `contain:paint`（E11）保留：岛整体在行盒内被裁剪，但岛自身已把横向溢出收进自己的滚动区，无内容被裁；岛高含自身滚动条，故与上报高度自洽。

### 3.2 横向滚动所有权

- 表头行与正文行位于**同一** `.table-island-track` 内 → 共享同一个 `scrollLeft`，横向同步是**零 JS 的布局结果**；E3 的两处 `useLayoutEffect` + rAF 守卫 + `tableScrollLeft` 跨行回写在本维路径上不再被消费（该字段的存废归 T5/T8 判定，本维不删）。
- 表头 sticky：`position:sticky; top:0` 置于岛内。**诚实边界**：`overflow-x:auto` 使岛成为滚动容器，`overflow-y` 只能取 `hidden`/`clip`（`visible` 会被计算为 `auto`），故 sticky 相对**岛自身滚动口**成立——F-Lay-1（表头随表横向滚动）天然满足；**「随文档纵向滚动而吸顶」不由该机制提供**，且参考帧 16/17 均为短表、无该证据。若验收要求文档级吸顶，表头必须移出横向滚动容器、成为岛拥有的覆盖层，并对**唯一一个** `scrollLeft` 做单点写入（单源同步，不是 D1 所否决的 N 路同步）——该二选一登记为 U-T3-1，需主控裁决（ADR-2 的「表头 sticky」措辞未区分二者）。

### 3.3 岛内行窗口化（R1 的直接缓解）

- **启用条件**：`rows > ISLAND_WINDOW_THRESHOLD`（建议 60，与 `overscan:40`（`MarkdownEngine.tsx:1068`）同量级）时启用；阈值以下整表渲染（有界成本，视觉与窗口化等价）。
- **窗口计算（外层驱动，O(1)）**：`localTop = scrollEl.scrollTop - item.start`，`viewH = scrollEl.clientHeight`，窗口 = `[localTop - OVERSCAN_PX, localTop + viewH + OVERSCAN_PX]` 映射到行号。`item.start` 权威（由 T4 的岛高上报保证）。
- **行高来源**：岛内 `rowHeights: Map<lineIndex, number>`，由一个 **ResizeObserver 实例**观察窗口内已挂载行采样；未测行用 `estimateRow(rowIdx)`——`(冻结列宽, 行内容)` 的**纯函数**（与 `HeightMap.predict` 表格分支同算法，见 3.6）。列宽先冻结 ⇒ 估算是确定函数 ⇒ 窗口滑动不引起高度震荡。
- **窗口外占位**：上/下哨兵 `div` 高度 = 该侧行高之和（已测用实测、未测用估算）。行号→像素前缀和用岛内 Fenwick（点更新 O(log n)、前缀 O(log n)），**避免 O(rows) 扫描**（万行压测：逐帧扫 9 000 行不可接受）。该结构私有于 `TableBlock.tsx`，以守住 §8 文件域；若外提为 `src/core/*` 需主控更新文件域表。
- **一个虚拟项的高度正确性**：岛高 = 表头 + Σ行高（含哨兵），由岛自报（3.6）；断言 `|island.offsetHeight − reported| ≤ 1`。行级 RO **只进岛内 Map**，永不写 `HeightMap`/`virtualizer`（I3 的守卫）。
- **外层折叠**：`rangeExtractor` 把岛区间折叠为 `[startLine]` 一个索引（E19）——岛内行不会成为外层虚拟项，`getVirtualItems()` 不含区间内部行，批量测量循环（E9 的 `1913`）自然跳过表格行，万行表不产生 O(rows) 虚拟项（这是 R1 的关键：**不是靠返回 `null` 跳过，而是根本不成项**）。
- 岛内行以 `data-line-index` 标识、`key=lineIndex`，同一源码行只允许一个节点（I8/F-Lay-4）。
- 跳转（大纲/查找/光标）落到区间内部行时，其逻辑起点等于岛起点 → `scrollToIndex` 落在岛上（行高 0 的语义，见 3.6）。

### 3.4 列宽驱动载体：`<col>` 的 div 等价物

- `<colgroup><col>` 仅在原生表格布局生效，与 3.1 的否决理由③同源，**不采用**。
- **推荐**：岛根写一个 CSS 变量 `--table-cols`（如 `128px 96px minmax(140px,1fr)`），表头行与全部正文行统一 `display:grid; grid-template-columns: var(--table-cols)`。每个 epoch 只写**一个元素的一次样式**（一次 style recalc），单元格不再接受任何宽度属性 ⇒ E5 的写回回路从根上消失（D4）。
- 末列用 `minmax(var(--col-w-last), 1fr)`：`track` 保持 `min-width:100%` 时由末列吸收余量，**不产生** E6 的空白条（S2 的「空列」根因是「行盒被撑到 100% 而列宽之和不足」，余量无处安放）。若视觉对齐（`02-分维` F-Vis 对比）判定参考表窄于内容列，则把 `1fr` 退回 `var(--col-w-last)`——纯 CSS 变量一处改动，无 JS 变更；该二选一登记为 U-T3-2。
- 逐列变量 `--col-w-{i}` 同时供 T6 的列宽拖拽（拖拽直接写该变量，属 T6 文件域）。

### 3.5 列宽计算（ADR-4 落地：「怎么算」）

- **一次测量（岛内、离屏探针）**：`.table-island-probe` 为 `position:absolute; width:0; height:0; overflow:hidden` 的 0×0 容器（不进岛高、不进滚动范围），内放与真实单元格**同一渲染与同一盒模型**（`box-sizing:border-box` + `padding:10px 16px` + `border-right:1px`）的 `white-space:nowrap` 探针格，逐格读 `getBoundingClientRect().width` → `ceil` → `intrinsic[i]`。
- **为什么不用 `scrollWidth`（ADR-4 已否决路径，必须写清陷阱）**：① 真实单元格一旦换行，`scrollWidth` 等于**换行后**的内容宽而非固有宽——列越窄测出来越窄，形成自增强收缩（D4 的循环依赖）；② `scrollWidth` 取整且**不含右边框**，而列轨是 `border-box`，按它设轨会窄 1px → 内容重新换行 → 行高变化 → I2 震荡；③ 现状正是该路径（E4）。改用探针 rect 同时消除①②。
- **分配规则（确定性 ⇒ I2）**：`w_i = clamp(intrinsic_i, MIN_COL_W, MAX_COL_W)`；若 `Σw_i > available`，按「固有宽从大到小」单趟把超出部分从各列减到 `MIN_COL_W` 为止（**不再往下减**）；若 `Σ MIN_COL_W > available`，允许岛横向滚动（F-Lay-1 合法），不牺牲最小可读宽。
- **跨列合并**：从属格不参与测量（`display:none`，`index.css:416-418`、`InlineRenderer.tsx:451-463`）；主格（`colSpan=k`）产生约束 `Σ_{i..i+k-1} w_i ≥ intrinsic(master)`，不足时按固定顺序补足（差额加到该组**最后一个**轨），确定性 ⇒ 无震荡。
- **`<br>` 多行单元格**：探针 rect 宽 = 各硬断行中最宽一行（`<br>` 是硬断行，内容不可能更窄而不截断）；纵向增量由行高测量承担。
- **两级 epoch（精准失效，避免无谓重测）**：内容 epoch 失效 `intrinsic[]`（需重跑探针）；容器宽 epoch 只重跑分配器（`intrinsic[]` 复用）。容器宽变化的精确解因此是 O(cols)，不是 O(rows×cols)。
- **长表边界**：探针集合 = 表头 + 窗口内行 + 首 `MEASURE_HEAD_ROWS`（建议 20）行；未测行进入窗口时若要求更宽 → **grow-only 一次修正**（只增不减、单调有界 ⇒ 必然收敛，无震荡）。这与 `plan-A4` §3 的「候选态估算 + 闭合定型一次修正」**不冲突**：A4 定「何时定型」（`MarkdownEngine.tsx:2090-2114` 的锁宽/grow-only 语义原样保留），本 ADR 只换掉「测量基准」（`scrollWidth` → 探针 rect）。
- **落点与收尾**：定型写 `TableStore.setTableWidths` + `recordTableWidthSettle`（E17，perf 口径不变）+ 岛根 `--table-cols`；`InlineRenderer.tsx:466-478` 的 per-cell 写回在岛内**不被消费**——由 `src/index.css` 的岛作用域规则中和其内联兜底（`.table-island .token-table-cell{flex:none; min-width:0 !important}`，`!important` 有仓库先例：`index.css:442,454,506`）。该文件内分支的**删除**属 T5/T8 文件域，本维不触碰（见 §7 与 U-T3-3）。

### 3.6 高度上报（ADR-5 落地：「谁上报」）

- **唯一上报源**：岛根一个 `ResizeObserver`（**不观察行**）→ `onIslandHeight(startLine, islandH)`：`hm.setHeight(startLine, islandH)` + `virtualizer.resizeItem(startLine, islandH)`；区间内部行 `[startLine+1, endLine]` 一律置 0（零高先例 E13）。`estimateSize` 先查 `hm.getHeight`（`MarkdownEngine.tsx:1045`），内部行未落库时返回 0（与 `:1063` 的 `table_separator` 同款），因此**不需要**改动 `estimateSize` 主体。
- **与 `syncTo` 的次序**：`syncTo` 只填新增行预测高（E14），会把新追加的表内行填成非 0 → 岛上报路径必须在同一 effect 内、`syncTo` **之后**重写「岛头 = 岛高、内部行 = 0」，再 `flush()`。
- **滚动锚定复用**：岛高变化若发生在视口顶线之上（`item.start + oldH ≤ scrollTop`），必须走与批量循环同一锚定语义（`MarkdownEngine.tsx:1952-1954,1959-1963`），否则流式追加大表会跳。
- **对测量纪律的显式例外**：`MarkdownEngine.tsx:1130-1151`（E16）规定「批量测量协议独占、RO 只回缓存值」；ADR-5 允许表格岛自测量。该例外已登记于 `00-调度与执行纪律.md` §7，本维再次确认并落断言（§8 A5）。
- **防两个测量源打架（四道闸）**：① 区间内部行不成外层虚拟项（3.3 的 `rangeExtractor`），批量循环（E9）不可能测到表格行；循环内再加 `kind === 'table_row' | 'table_separator'` 的跳过断言作双保险；② 岛区间内**只有** `onIslandHeight` 一个写者，写入前断言 `startLine === island.startLine`（写错索引即 bug，开发期直接抛）；③ 上报走 `STABLE_EPSILON`（E15）同款阈值护栏，终止「测量→上报→重排」回环；④ 岛只在**列宽已冻结**的前提下上报，使岛高是 `(内容, 冻结列宽)` 的确定函数（3.7）。
- **oracle 降级为初值估算**：`HeightMap.predict` 表格分支（E7）不再承担逐行真值，仅提供岛高初值 `islandH₀ = Σ_rows predict(row) + headerH`；为让初值快速收敛，`predict` 增加可选「冻结列宽」入参（有则用之替代 `containerWidth/cols` 估算，无则保留现状——流式候选态无列宽，行为不变）。E8 的常量漂移由「正确性缺陷」降级为「估算误差」，但**仍需**保持与 CSS 同步（注释义务不变）。

### 3.7 测量时序契约与失效传播

**每 epoch 严格次序**（同帧、不可交换）：

```
① 失效源：内容变化 / 容器宽变化 / 活动行变化 → epoch++
② 列宽：探针一次测量（内容 epoch）或分配器一次求解（容器 epoch）→ 写 --table-cols + TableStore
③ 高度：同帧读 island.offsetHeight（强制 reflow 一次）→ 上报唯一高度 → 内部行置 0
④ 岛内行高采样：仅更新岛内 Map 与哨兵（用于窗口化），不改变已上报岛高；下次上报时并入
```

- **禁止**：同一趟里先测高后定型（E9）；定型后不重测（E10 的后果）。
- **失效传播图**（谁变触发谁）：

| 失效源 | 触发 | 后果 |
|---|---|---|
| 容器宽变化 | ② 分配器 | ③ 岛高重报（RO 自然触发） |
| 内容变化（编辑/流式追加） | ② 探针重测 | ③ 岛高重报 |
| 活动行变化（分隔行 0↔28px，`index.css:441-460`） | 岛内 DOM 变化 | ③ 岛高重报——**旧路径下该高度变化与逐行预测打架，这是 ADR-5 的自然收益** |
| 岛高变化 | `resizeItem(startLine)` | 外层窗口重算（O(1)），**不再回头改列宽** |

- **消除「定型后不重测」**：岛路径下表格高度不再由 `MarkdownEngine.tsx:2201-2210` 的批量 effect 回填，故该依赖数组缺 `tableWidths` 对表格路径**失效**；`tableWidths` 的变化经由 `--table-cols` → 岛内容布局变化 → 岛根 RO → `resizeItem` 这条**自闭环**传播（不依赖 React 依赖数组）。开关关闭时旧路径与旧依赖数组原样保留。

## 5. 边界与不变量

| 不变量 | 落法 | 边界处理 |
|---|---|---|
| **I1** 单横向滚动所有者 | 岛根是唯一 `overflow-x` 非 `visible` 的节点；E1/E2 在本路径不生效 | 表头与正文同容器 ⇒ 无同步代码，无「重挂载先画 0 偏移」帧（S2 根除） |
| **I2** 列宽无震荡 | 分配器确定性 + 两级 epoch + grow-only 单调 | 精确口径：同一（内容、容器宽、窗口行集）下重复测量恒等；长表未测行只允许单调增（有界 ⇒ 收敛） |
| **I3** 单高度源 | 岛根 RO 唯一写者；行级 RO 只进岛内 Map；批量循环跳过表格行 | 例外登记见 `00-调度与执行纪律.md` §7 |
| **I8** 无重复行节点 | 岛内行 `key=lineIndex`、`data-line-index` 唯一；窗口化不重渲染 | 窗口切换时旧行卸载、新行挂载，同一 `lineIndex` 不得同时存在两个节点 |
| 超长表格（万行压测，ADR-2 §R1） | `rangeExtractor` 折叠 + 岛内窗口 + Fenwick 前缀 | 外层虚拟项数 1；岛内 DOM 行数 ≤ 窗口 + 2 哨兵；行高估算不整表扫描 |
| 流式追加 | 岛头高度增长 → 上报 → 锚定补偿（3.6） | 候选态（无分隔行）沿用 A4：估算宽 + `--table-cols` 一次写入，闭合后一次修正 |
| 列宽小于最小宽 | `MIN_COL_W` 钳制；不足时允许横向滚动而非压缩列 | 不出现 0 宽/负宽轨 |
| `<br>` 多行单元格 | 探针 rect 取最宽硬断行；行高由岛内行测量承担 | 不裁切（F-Vis-2）——`contain:paint` 不裁岛内内容（3.1） |
| 跨列合并 | 主格约束 + 从属格不参与测量 | 差额按固定顺序补足，确定性 |
| 容器宽度变化 | 容器 epoch：只重跑分配器（O(cols)） | 末列 `1fr` 吸收余量（U-T3-2 待定） |

## 6. 风险与缓解（承接总方案 §11）

| # | 风险 | 本维缓解 |
|---|---|---|
| **R1** | 岛成为单一虚拟项后超长表退化为一次性渲染 | `rangeExtractor` 折叠（区间内不成项）+ 行数阈值 + 岛内窗口 + Fenwick 前缀（O(log n)）+ 哨兵占位；断言 A6/A9（岛内 DOM 行数上界、`layoutCountPerSec` 不劣化） |

| 新增：sticky 语义歧义 | 「表头随表横滚」与「文档级吸顶」不可同时由同一容器提供 | U-T3-1 交主控裁决；默认取前者（有参考证据：F-Lay-1） |
