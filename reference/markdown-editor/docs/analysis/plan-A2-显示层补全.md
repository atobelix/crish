# 分析 A2：显示层乐观补全（总调度产出）

> 背景：流式输出中未闭合 `**text` / `` `code `` / `$eq` 的显示层优化——格式即时生效，数据层零篡改，闭合无缝切换，避免跳动。

## 1. 现状盘点（文件:行号证据）

| 形态 | 流式中（未闭合）当前渲染 | 闭合后 | 视觉差异 |
|---|---|---|---|
| `**text`（无 `**` 闭合） | scanTokens 无闭合匹配 → 整段按 text token（含 `**` 字符原文）——**无加粗** | `**text**` → bold span + syntax-hidden 标记 | 流式中看不到加粗，闭合瞬间整行重渲染出现加粗——**中等闪烁**（行重渲染） |
| `` `code `` | 同上——text token 原文 | `` `code` `` → style-inline-code | 同上 |
| `$eq` | 同上（math 是 regex 规则须闭合才匹配——R1 实证未闭合回退文本） | 渲染 KaTeX | 同上 + KaTeX 延迟 |
| `*text`/`_text`/`~~text` | 同上 | 对应样式 | 同上 |

**根因**：引擎是行级增量模型——未闭合行按 text 渲染；闭合发生时该行内容变化 → 行重渲染（LineItem 内容帧重渲染——这是 R6 流式场景 A/B 已实证可接受的开销，但**视觉上是"整行切换"而非"样式微调"**——跳动观感来源）。

**直刷路径**（R3-B2）：流式末行纯文本直刷（textContent +=）——该行是纯文本 token（无 `**` 等字符才算纯文本——含 `**` 的行**不直刷**，走常规 append）——所以流式中 `**text` 的末行是常规渲染（非直刷）。

## 2. 多方案设计

### 方案 B（推荐）：样式预演——零 DOM 变化

```
渲染时（行级）：行文本检测未闭合 inline 标记 → 生成"预演样式"提示
  decorateIncompleteInline(raw):
    - 检测：行内 `**`/`*`/`_`/`` ` ``/`$`/`~~` 开标记无对应闭标记（词边界 + 数量奇偶）
    - 输出：{ displayAs: 'bold'|'italic'|'code'|'math'|..., 标记范围 }
  LineItem 渲染：对未闭合标记后的文本段加预演 class（如 is-preview-bold）
    → 视觉上"看起来已加粗"（样式即时），但 DOM 结构与数据层完全一致（无新 token、无假偏移）
闭合时：行内容变化 → 行重渲染 → 真实 bold token 渲染（preview class 消失）
  → **同一行 DOM 的样式 class 切换**（preview-bold → style-bold），非重建
```

- **跳动控制**：切换是"class 变化"（一个节点的 className 更新）——浏览器只重绘该节点样式，无 layout 重排、无 DOM 重建——**视觉连续**（加粗从"预演"变"真实"，样式一致则肉眼不可察）
- **测量零影响**：不产生 DOM 节点、不改变 data-token 映射——光标测量（data-token-start/sub-offset）完全不受影响
- **数据层零篡改**：只在渲染时派生样式提示——undo/编辑/序列化全不受影响

### 方案 A（备选）：视觉补全（span 包裹）——DOM 变化，弃用

临时 wrap span 加粗——闭合时 span 结构变化 → DOM 重建该段——跳动风险 + 测量映射复杂化。仅当方案 B 的样式不足以表达（如复杂嵌套）时局部用。

### 方案 C（混合）：B 为主，A 仅限复杂形态（`***text` 三重嵌套等）——登记

### 方案 D（对照组）：现状——闭合时整行重渲染

## 3. 边界与范围

| 边界 | 决策 |
|---|---|
| 作用范围 | **仅流式进行中的末行**（streaming 态行）——编辑态不预演（编辑是用户主动输入，无"即将闭合"预期）；实现上：LineItem 接收 isStreamingTail 标志（已有 dirty 协议可扩展） |
| 与软渲染边界 | fence/公式块仍软渲染（等宽源文本）——inline 预演只作用于行内 `**`/`` ` ``/`_`/`~~`；`$` 行内数学预演为等宽样式（不调 KaTeX——保持 0 KaTeX 纪律） |
| 代码块内 | 不预演（code 行内 `**` 是字面量——检测必须排除 code 行——codeBlockState 已知） |
| 误判防护 | `**text**x`（半闭合）：只预演"最后未配对开标记"后的文本；`*` 在词中（`foo*bar`）不预演（词边界）——复用 R1-C `_` 围挡的 flanking 语义 |
| 性能 | 每行一次轻量扫描（标记计数——O(行长) 单遍，流式末行才执行；非流式零开销） |

## 4. 测试方案

1. 各形态：`**text`/`*text`/`` `code ``/`_text`/`~~text`/`$eq` 未闭合 → 预演样式断言（class 存在）
2. **闭合切换零跳动**：streamEnd/内容闭合后——同一 DOM 节点（oldEl === newEl 断言——A6 的 M4 指标）+ 预演 class 消失 + 真实样式 class 出现
3. 光标测量零影响：预演行内点击/光标定位坐标不变（roundtrip）
4. 代码块内不误判：``` 内 `**` 不预演
5. 编辑 undo 零影响：预演行 undo 行为不变
6. 误判防护：`foo*bar`/`**text**x` 不误预演

## 5. 结论

**推荐方案 B（样式预演）**——零 DOM 变化、测量零影响、数据零篡改、闭合切换是 class 微调（无跳动）——与 A6 的 M4（补全闪烁 = 存量行重建 0）直接对齐。实现落点：新纯函数 `decorateIncompleteInline`（src/core/ 或渲染层）+ LineItem 渲染时消费 + 流式末行标志接线。工作量：小（1 个执行 Agent）。
