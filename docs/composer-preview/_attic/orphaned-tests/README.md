# orphaned-tests —— 历史归档（不可执行）

本目录下的测试文件为**历史归档**，仅作留存参考，**不可执行**。

## 为什么不可执行

- 这些测试引用的源模块已**全部删除**（composer-preview 早期实验阶段的
  tiptap 扩展 / slash 菜单 / 序列化器等实现已在后续重构中移除）。
- 导入路径已断裂，`vitest run` 会因模块解析失败而报错，不存在可通过的
  断言路径。

## 不在任何 vitest include 范围内

- 仓库根 `vitest.config.ts` 及各中层配置的 `include` glob **未覆盖**
  `docs/composer-preview/_attic/orphaned-tests/**`。
- `_attic` 前缀本身即「 attic（阁楼）」语义——已退役、不再参与构建与门禁。
- CI 的快层 / 中层 test job 均不会收集或运行本目录文件。

## 维护说明

- **禁止**为使其通过而恢复已删除的源模块（那等于回退重构成果）。
- 如需参考其中的测试思路，请复制到活跃测试目录并针对当前实现重写，
  不要原地复活本目录文件。
- 新增测试不应放入本目录；本目录只接收退役归档。
