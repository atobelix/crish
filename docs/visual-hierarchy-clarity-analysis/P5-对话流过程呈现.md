#### 4.2.3 去重与消解规则（穷举算法）
纯函数 `resolveToolPresentation(tc: MessageToolCall, humanExplanation?: string): ToolPresentation` 遵循 5 步去重流水线：
1. **目标对象预提取**：从注册表中匹配 tool registration，执行 `extractTarget(args, tc)` 获得候选 `rawTarget`；
2. **Explanation 意图优先与内含消解（核心 Bug 根治）**：
   - 提取清理后的模型意图 `explanation = cleanHumanExplanation(humanExplanation)`；
   - 若 `explanation` 非空，且**已包含** `rawTarget.text`（或包含不带扩展名的 basename）：
     - 判定为意图已完整表达动作与对象（如 `列出目录 crates`、`搜索「pub async fn run」`、`写入 inventory.json`）；
     - **动作**：`label = explanation`，`target = undefined`（彻底消除对象二次拼接）；

#### 4.7.2 agentIdentity(id) 稳定映射纯函数
在 `apps/crish-desktop/src/api/tool-presentation/agentIdentity.ts` 实现：

```typescript
export interface AgentIdentity {
  hueIndex: number; // 1..8
  hueVar: string;   // 'var(--agent-hue-N)'
  glyph: string;    // 'A'..'Z' 首字母或稳定几何标号
  colorHexApprox: string;
}

const AGENT_GLYPHS = ['◆', '▲', '●', '■', '◈', '⬢', '⬡', '★'];

export function agentIdentity(id: string): AgentIdentity {
  const str = String(id || 'agent');
  let hash = 0;
  for (let i = 0; i < str.length; i++) {
    hash = (hash << 5) - hash + str.charCodeAt(i);
    hash |= 0;
  }
  const hueIndex = (Math.abs(hash) % 8) + 1;
  return {
    hueIndex,
    hueVar: `var(--agent-hue-${hueIndex})`,
    glyph: AGENT_GLYPHS[hueIndex - 1],
    colorHexApprox: `var(--agent-hue-${hueIndex})`,
  };
}
```

```javascript
// 在 Tauri MCP 4000 中执行的真实宿主验收脚本
(() => {
  const audit = {
    duplicateTextCount: 0,
    toolHeaderMaxElements: 0,
    restingChevronCount: 0,
    userBubbleBorderCount: 0,
    userLeftAlignVariance: 0,
    agentHueContrastMin: 999,
    failures: []
  };

  // 1. 验证工具行重复文本与 DOM 元素数
  const toolRows = document.querySelectorAll('.tool-row-head, [class*="toolRowHead"]');
  toolRows.forEach((row, i) => {
    const text = row.textContent || '';
    if (/列出目录.*列出目录|Grep.*Grep|修改.*修改/.test(text)) {
      audit.duplicateTextCount++;
      audit.failures.push(`工具行 [${i}] 存在文案重复: "${text}"`);
    }
    // 检查子元素数量（排除 DisclosureAffordance 占位槽）
    const childrenCount = row.children.length;
    if (childrenCount > 5) {
      audit.failures.push(`工具行 [${i}] DOM 元素过多 (${childrenCount} > 4)`);
    }
    audit.toolHeaderMaxElements = Math.max(audit.toolHeaderMaxElements, childrenCount);
  });

  // 2. 验证静止态 Chevron 是否完全隐退
  const chevrons = document.querySelectorAll('[class*="disclosureAffordance"], [class*="chevron"]');
  chevrons.forEach((c) => {
    const style = window.getComputedStyle(c);
    const isExpanded = c.getAttribute('aria-expanded') === 'true' || c.closest('[aria-expanded="true"]');
    // 未展开且未悬停时，opacity 必须接近 0
    if (!isExpanded && parseFloat(style.opacity) > 0.05) {
      audit.restingChevronCount++;
    }
  });

  // 3. 验证提问块无边框与主轴左对齐
  const userRows = document.querySelectorAll('[data-role="user"]');
  userRows.forEach((r) => {
    const card = r.querySelector('[class*="userBubble"], [class*="userCard"]');
    if (card) {
      const border = window.getComputedStyle(card).borderWidth;
      if (parseFloat(border) > 0) audit.userBubbleBorderCount++;
    }
    const rect = r.getBoundingClientRect();
    // 检查左缘是否对齐主轴 (允许 2px 误差)
    if (Math.abs(rect.left - 68) > 30) {
      audit.userLeftAlignVariance++;
    }
  });

  return JSON.stringify(audit, null, 2);
})();
```

## 9 风险与未确认项

### 9.1 风险登记与防御策略
1. **风险 1：动态高频渲染下 `ResizeObserver` 测高抖动**：
   - *对策*：过程簇展开/收起时严禁直接在组件内部使用 `element.offsetHeight` 强制同步重排；必须通过 `onInvalidateActual(msgId)` 标记脏位，由宿主 `MessageVirtualizer` 在 rAF 节流队列中批量测量回写，消除重排死锁。

   - *对策*：在 §4.6.3 严格保留回退面（仅需翻转 2 处 CSS 属性），不伤及任何 TypeScript 业务逻辑；验收时由真实宿主截图留证，确认无异议后方可收口。
