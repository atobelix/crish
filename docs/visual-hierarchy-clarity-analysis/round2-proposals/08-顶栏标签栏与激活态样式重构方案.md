## 1. 用户痛点溯源与病理根因剖析

### 1.1 用户原声与真实视网膜现场

用户最新反馈指出：
> “顶部行被激活的标签样式这版的也不行。”

结合用户现场界面截图，当前顶栏存在四重严重的“非专业感”与“视觉脱节”病理现象：

```
当前线上病理现象截图线框解构：
┌────────────────────────────────────────────────────────────────────────────────────────────────┐
│  [Crish]  [ 💬 你好啊          ✕ ]  [+]                        [ 🔍 ]             [—] [□] [✕] │  ← PaneHeader (36px)
│           └── 灰底、细硬线、带投影的孤立贴纸 (上下悬空 4px)                                      │
├────────────────────────────────────────────────────────────────────────────────────────────────┤
│  对话 / 你好啊                                                        [🌐] [📁] [⋯] [◨]      │  ← UnitChromeActions (38px)
│  └── 下方面包屑居然把上面的名字又完整写了一遍！(垂直间距 < 20px，双重标题回音)                 │
├────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                │
│  [用户消息气泡] ...                                                                            │
│                                                                                                │
```

具体表现在：
1. **扁平灰色贴纸感**：顶部的标签像是一个带有圆角的扁平灰色贴纸，生硬地贴在顶栏中间；
2. **粗糙灰底与生硬边缘**：激活态 Tab 采用了一个毫无生气的脏灰底色，外加一圈生硬的细边框和黑色投影，与整个窗口顶栏的底色严重脱节；
3. **单会话孤立药丸 + 下方双重回音**：当用户只有一个会话时，顶栏依然突兀地挂着这个带关闭叉号的灰胶囊，同时下方的面包屑又写了一遍同样的名字（“对话 / 你好啊”），上下双重冗余，信息密度灾难；
4. **分屏状态下失去方向感**：左右分屏时，各个分屏的 Tab 轨外观完全相同，激活分屏与非激活分屏没有明确的高低权区分，用户无法一眼判定键盘焦点归属。

---

### 1.2 为什么现在的激活态像“灰贴纸”？（深层技术归因）

通过对 `PaneHeader.tsx`、`PaneHeader.module.css` 与 `tokens-state.css` 的代码审计，发现该问题源于三层结构性缺陷：

#### 缺陷 1：几何孤岛（Island Isolation）
- `PaneHeader` 高度为 `var(--header-height, 36px)`；
- 标签项 `.tabItem` 高度硬编码为 `var(--pane-tab-height, 28px)`，上下各留出了 4px 的空隙；
- `.tabItem` 拥有 `border-radius: var(--radius-lg, 8px)`。
- **后果**：激活态标签在几何上是一个悬浮在 36px 顶栏正中间的独立圆角小盒子。它与下方实际承载内容的卡片（`.leafBody`）被这 4px 的外壳底色和卡片顶边框（`border-top: 1px solid var(--content-frame-border)`）完全切断，既没有现代浏览器“标签即卡片延伸”的陆地连通感，也没有 macOS 现代工具栏“无边框平滑过渡”的极简感。

#### 缺陷 2：脏灰色彩与生硬光影（Muddy Color & Hard Shadows）
- **背景色倒挂**：`.tabItemActive` 使用了 `background: var(--tab-active-bg, var(--bg-card))`。在暗色模式下，`--tab-active-bg` 映射为 `var(--state-selected)`（10% 白色半透明叠加在深灰外壳上），计算出来约为 `#303030` 的脏灰色；
- **边框与阴影冲突**：
  ```css
  /* PaneHeader.module.css 现行代码 */
  .tabItemActive {
    border-color: var(--border-subtle, color-mix(in srgb, var(--border-color) 80%, transparent));
    box-shadow: 0 1px 3px color-mix(in srgb, var(--shadow-color) 6%, transparent);
  }
  ```
  在暗色模式下，`border-subtle` 是一条死板的浅灰细线，而 `box-shadow` 是黑色的向外弥散阴影。暗色背景下画黑色外阴影不仅完全无法表现“抬升感”，反而让标签四周发黑、边缘发脏，如同贴了一块剪裁不齐的灰色胶布。现代暗色体系必须使用**内边缘光（`--edge-rim`）**，严禁使用散落的外阴影。

#### 缺陷 3：常驻关闭叉号的视觉干扰（Visual Noise of Close Button）
- 现行 CSS 中：
  ```css
  .tabItemActive .tabCloseBtn {
    opacity: 0.7;
    pointer-events: auto;
  }
  ```
  激活标签无论何时都在右侧常驻显示一个不透明度 0.7 的关闭叉号。对于用户正在专注阅读或对话的会话，这个叉号时刻提醒用户“这里可以销毁”，并且占据了宝贵的 18px 宽度，使标题文字重心右偏且受到持续干扰。

#### 缺陷 4：单会话状态下的心智模型断裂
- 在单会话（Single Tab）时，根本不存在“标签切换”的多任务需求。但现有逻辑不加区分地直接渲染多标签控件，同时又在卡片内部渲染 `UnitChromeActions`（38px 面包屑）。
- 两个层级垂直堆叠，总垂直高度消耗达 **74px**，且在同一视网膜垂直线上连续两次展示当前会话标题，构成了严重的视觉回音与空间浪费。

## 2. 现代顶级桌面 Tab 工业设计对标

为了彻底摆脱“网页贴纸感”，我们深度解剖四款标杆工具的设计哲学：

| 对标产品 | 核心设计哲学 | 单 Tab 表现 | 激活态视觉语言 | 关闭按钮机制 |
| :--- | :--- | :--- | :--- | :--- |
| **VS Code** | **工作区卡片无缝物理连通（Surface Unification）** | 支持隐藏标签或单标签紧凑展示 | 激活 Tab 背景色与主编辑区 100% 连通无缝；顶部或底部提供精致指示发丝条，消除上下断层。 | 默认微弱或悬浮浮现，正圆微交互区。 |
| **Linear** | **极简 Segmented 胶囊 + 边缘光（Edge Rim）** | 直接以顶级标题呈现，无孤立标签框 | 采用柔和的背景提升（Surface Elevation）配合 `var(--edge-rim)`（0 0 0 1px 微白），绝无外散黑色脏阴影。 | 仅在 Hover 标签时优雅淡入；非激活态保持极致平静。 |
| **Arc Browser** | **沉浸式画板与情境化（Canvas Context）** | 单页面时标签栏与地址栏完全融合，零多余边框 | 激活项与当前视口形成一致的色彩场；没有突兀的粗灰底。 | 鼠标移入标签时平滑滑出关闭按钮。 |
| **Raycast** | **单轨上下文（Single-Track Breadcrumb）** | 面包屑即标题，标题即上下文，原地重命名 | 高对比度纯净文字，背景完全融入窗口，利用高低字重与字色自然分层。 | 无需关闭叉，由全局快捷键/返回键管理。 |

### 设计裁决
本方案汲取 **VS Code 的结构确定性** 与 **Linear / Raycast 的高阶质感**，确立两项核心改造基调：
1. **单/多会话形态彻底分流（State Bifurcation）**：
   - **单会话（Single-Session）**：彻底卸载灰贴纸与关闭叉号，化身为优雅的**单轨顶栏标题（Single-Track Title）**，向上承接外壳拖拽，向下直接指引内容，与卡片面包屑合流，消除第二层重复！
   - **多会话（Multi-Tab）**：化身为**精致的现代标签条（Modern Segmented Tab Strip）**，激活态采用与卡片主体高度和谐的饱满微白/微亮底色，搭配内边缘光（`--edge-rim`），彻底铲除生硬描边与外散黑影。
2. **关闭按钮渐进露出（Progressive Disclosure）**：
   - 默认状态下保持完全隐退（`opacity: 0`），只有当光标悬停在具体标签项上方时，才平滑淡入露出。

## 3. 标签系统全新视觉语言设计规范

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 【全新单会话状态 (Single Session Mode) —— 优雅单轨，合流消除双重标题】                                   │
├────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│  [📁 默认项目 · 会话真实标题 (双击重命名)] ────── [系统拖拽区: drag-region] ───── [🌐] [📁] | [⋯] [◨] [— □ ✕]│
│  └── 纯净无框标题，无突兀灰药丸，无关闭叉号，下方面包屑行彻底清退（净省 38px 高度）                      │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 【全新多标签状态 (Multi-Tab Mode) —— 现代 Segmented 标签，精致边缘光】                                   │
├────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│  [ 💬 会话一 (Hover 显叉) ✕ ] │ [ 💬 会话二 (Active, 边缘光饱满微亮) ] │ [ 💬 会话三 ]  [+]   [拖拽区]  [动作簇]│
│                                └── 纯正 Card 色，无脏灰，无下边框割裂，微边缘光                            │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 3.1 单会话模式（Single-Session Mode）：从“孤立贴纸”到“优雅标题”

当当前分屏窗格内仅有 1 个会话时（90% 以上的日常使用场景）：
1. **形态消融**：不再渲染宽度固定的 `.tabItem` 胶囊，不再渲染常驻的关闭叉号 `×`；
2. **单轨合流**：顶栏左侧直接渲染项目名与会话标题：
   - 项目指示：`--text-tertiary`（浅灰），如 `默认项目 /`；
   - 会话标题：`--text-primary`（高对比主色），字重 500（Medium），字号 13px；
3. **原地交互支持**：
   - 支持 **双击重命名**（弹出无边框原地内联输入框，对齐 P7 的 T-P7-09 契约）；
   - 支持 **右键快捷菜单**（重命名、复制标题、置顶、删除）；
   - 支持快捷键 **F2** 聚焦编辑；
4. **彻底消除下方面包屑**：
   - 伴随单轨标题栏落地，卡片内部的 `UnitChromeActions` 38px 占位彻底删除，垂直空间净释放 **38px**，首屏信息向上浮起。

---

### 3.2 多标签模式（Multi-Tab Mode）：现代高阶视觉阶梯

当窗格内存在 $\ge 2$ 个会话时，自动切换为专业的多标签轨（Tab Strip）：

#### 3.2.1 激活态标签（Active Tab）
- **底色（Background）**：
  - 弃用 `--state-selected` 算出的脏灰底；
  - 采用 **`var(--surface-card)`**（与下方内容卡片完全同源）；在浅色模式下为纯白/极浅暖白，在暗色模式下为精致的微亮抬升色（`#202020`~`#242424`）；
- **边缘反光（Edge Rim）**：
  - 弃用 `border-color: var(--border-subtle)` 与外部阴影；
  - 采用 **`box-shadow: var(--edge-rim), var(--shadow-lift-card)`**：
    - 暗色：`0 0 0 1px hsl(0 0% 100% / 0.05), 0 1px 2px hsl(0 0% 0% / 0.3)`；
    - 浅色：`0 0 0 1px hsl(0 0% 0% / 0.04), 0 1px 2px hsl(0 0% 0% / 0.05)`；
  - 视觉效果：标签具有极其微弱但清晰的高级边缘微光，与顶栏背景形成柔和而分明的层次，绝无生硬的黑色勾边；
- **文字表现**：
  - 文字颜色升级为 **`var(--text-primary)`**（高对比度，保证可读性 $\ge 9.5:1$）；
  - 字重维持 **`var(--font-weight-regular, 400)`**，防止切换标签时文字重排抖动；
- **顶边指示微质感（Top Accent Indicator）**：
  - 可选微弱的高亮顶边（1px，通过 `::before` 提供，透明度 12% 的品牌色或 20% 高光），强化“当前聚焦”的确定性。

#### 3.2.2 未激活态标签（Inactive Tab）
- **底色**：完全透明（`background: transparent`），边框透明；
- **文字颜色**：**`var(--text-secondary)`**（稳态后退，对比度 ~5.5:1）；
- **悬停态（Hover）**：
  - `background: var(--state-hover)`（4%~6% 极微半透明）；
  - `color: var(--text-primary)`；
  - 边缘零硬线，过渡平滑（`transition: background 120ms var(--ease-standard)`）。

#### 3.2.3 标签间精致发丝线（Hairline Divider）
- 在相邻的未激活标签之间，渲染一条居中的精致分隔竖线：
  - 几何尺寸：宽度 1px，高度 12px（居中垂直对齐）；
  - 色彩定义：`background: color-mix(in srgb, var(--border-color) 40%, transparent)`；
- **动态消隐逻辑**：
  - 激活标签自身无分隔线；
  - 紧邻激活标签左侧与右侧的标签，分隔线自动隐藏（透明度 0）；
  - 处于悬浮态（Hover）的标签及其相邻项，分隔线自动隐去；
  - 列表最后一项自动隐去；
  - 保证视觉呼吸感，绝不产生多余线条堆叠。

#### 3.2.4 关闭按钮（Close Button `×`）：渐进显现与精致微交互
- **平时静默**：
  - 无论是激活态还是未激活态，默认 `opacity: 0; pointer-events: none;`；
  - 界面保持完全纯粹、清爽，无视觉红点或噪音；
- **悬停显现（Hover-Reveal）**：
  - 仅当鼠标指针进入 `.tabItem` 容器范围（`:hover`）时，叉号平滑淡入：
    ```css
    .tabItem:hover .tabCloseBtn {
      opacity: 0.7;
      pointer-events: auto;
    }
    ```
- **正圆交互区**：
  - 按钮尺寸：`18px × 18px`，`border-radius: var(--radius-pill, 9999px)`；
  - 内部图标：`AppIcon name="x" size={10}`；
  - 自身悬停态（Button Hover）：
    ```css
    .tabCloseBtn:hover {
      background: var(--state-hover);
      color: var(--text-primary);
      opacity: 1;
    }
    .tabCloseBtn:active {
      background: var(--state-active);
    }
    ```
  - 点击热区扩大：保留隐形 `::before` 扩充 4px 命中区域，确保好点而不误触。

#### 3.2.5 新建标签加号（Launcher `+`）
- 紧贴末尾标签右侧，间距 4px；
- 尺寸：`26px × 26px`，`border-radius: var(--radius-control, 8px)`；
- 常态：透明背景，`color: var(--text-tertiary)`；
- 悬停：`background: var(--state-hover)`，`color: var(--text-primary)`。

## 4. 多分屏（Split-Pane）场景下的响应式与激活态辨识

分屏是桌面级工作台的核心能力。用户反馈“分屏时不知道哪个分屏是当前激活的”，本方案彻底补全分屏视觉感知链路：

### 4.1 激活分屏（Active Pane） vs 非激活分屏（Inactive Pane）

```
┌──────────────────────────────────────────────┬──────────────────────────────────────────────┐
│ 【当前激活分屏 (Active Pane: isActive=true)】 │ 【非激活分屏 (Inactive Pane: isActive=false)】│
├──────────────────────────────────────────────┼──────────────────────────────────────────────┤
│ [ 💬 任务执行中 (Active, 高对比)  ✕ ] [＋]    │ [ 💬 历史记录 (Dimmed, 降低饱和) ]            │
│ └── 顶栏标题亮白，标签边缘光清晰，加号常亮    │ └── 顶栏整体淡化 35%，激活标签无边缘光，加号隐退│
│                                              │                                              │
│ [主卡片区域: 发丝亮边框勾勒焦点]             │ [主卡片区域: 柔和静默]                       │
└──────────────────────────────────────────────┴──────────────────────────────────────────────┘
```

#### 视觉规则定义：
1. **数据驱动透传**：
   - 修复 `PaneHeader.tsx` 中 `void isActive;` 的遗留漏洞，将 `isActive` 正式作为容器根节点的 HTML 属性：
     `<div className={styles.paneHeader} data-active={isActive ? 'true' : 'false'}>`；
2. **非激活分屏（`data-active="false"`）表现**：
   - **文字阶梯下调**：标签标题由 `--text-primary` 降至 `--text-secondary`；
   - **边缘光隐去**：激活标签不再渲染强烈的 `--edge-rim`，而是降级为 `--edge-rim-subtle`，底色与顶栏进一步融平；
   - **加号与动作钮静默**：加号 `+` 与右侧动作钮的不透明度下调至 `0.4`，鼠标 Hover 时才恢复正常；
3. **激活分屏（`data-active="true"`）表现**：
   - 标签文字满血高亮（`--text-primary`）；
   - 激活标签展示清晰的边缘光与高抬升度，卡片顶边与左边呈现高亮微发丝线；
   - 用户视线无需任何寻找，直觉捕捉活跃焦点。

---

### 4.2 左右分屏弹性排布与极窄截断（Elastic Clamping）

当用户进行左右分屏时，单个窗格的宽度可能从 1200px 骤降至 400px 甚至 300px：
1. **等宽锁定通道（CSS `--pane-tab-item-width`）保持不变**：
   - 保留既有 `paneHeaderGeometry.ts` 中的 `computeNaturalTabWidth` 优秀数学算法（动态等宽、关闭时不跳变、鼠标移出后平滑回弹）；
   - 最小收缩宽度限制为 `MIN_TAB_WIDTH = 64px`，最大宽度 `MAX_TAB_WIDTH = 220px`；
2. **文本省略与气泡保护**：
   - `.tabTitle` 设置 `text-overflow: ellipsis; white-space: nowrap;`；
   - 宽度 `< 90px` 时，文字极度精简，但外层仍保留 `<Tooltip>` 悬停展示完整会话标题。
3. **超窄窗格（`< 320px`）单标签兜底**：
   - 当单个窗格宽度 `< 320px` 时，若标签数 $\ge 3$，加号按钮自动转为下拉溢出菜单，确保每个标签至少保留 `60px` 可交互宽度。

```typescript
export interface SingleTrackHeaderViewModel {
  mode: 'single-session' | 'multi-tab';
  singleSession?: {
    sessionId: string;
    displayTitle: string;
    projectLabel?: string;
    canRename: boolean;
  };
  tabs: LeafSessionTab[];
  activeTabId: string;
}

export function resolveHeaderLayoutMode(
  tabsCount: number,
  isMultiPane: boolean
): 'single-session' | 'multi-tab' {
  // 单分屏且仅有 1 个会话时，进入单会话优雅标题模式；多分屏或多会话时，保持多标签模式
  if (tabsCount <= 1 && !isMultiPane) {
    return 'single-session';
  }
  return 'multi-tab';
}
```

## 8. 结论与交付总结

本重构方案直击痛点，系统性解决了用户对顶栏视觉的强烈不满：
1. **告别灰贴纸**：通过将激活 Tab 背景色与主卡片完全同源化（`--surface-card`），配合边缘光（`--edge-rim`），彻底消除了粗糙灰底和生硬描边；

3. **分屏清晰辨识**：注入激活分屏与静默分屏的正向视觉阶梯，彻底根除焦点迷失；
4. **克制高级体验**：关闭按钮悬浮显现机制，使界面回归现代专业桌面的从容与精致。
