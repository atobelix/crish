## 1. 五大系统性病根（Root Cause Clusters）

```
R1 基元内容模型契约残缺
   Button 无条件 span 包裹 / bare 语义靠口口相传 / 基座选择器特异性过高
   └─投影→ DEF-CHAT-01/02/03/06、15+ 处 :global 补丁、内联样式硬编码、257 处幽灵选择器

R2 层叠特异性架构未闭环
   :where() 零特异基座未落地、无 cascade layer 秩序、几何标尺门禁失真
   └─投影→ 41 处药丸圆角逃逸、reduced-motion 穿透、.xterm 规则落空、zIndex 魔数

R3 事件与观察通道多轨残留
   单例双 fork、别名门面、裸监听器与单轨桥并存、挂起状态机竞态
   └─投影→ SafeAimEngine×2、RO 别名、tooltipController 双轨、RO 挂起首帧毛刺

R4 重试/撤回业务状态机链路缺陷
   重试载荷不完整、清理钩子挂载点不全、撤回语义粗暴、节流与清态顺序颠倒、IME 契约未强制
   └─投影→ Defect-01/02/03/04/06、DEF-CHAT-04/05

R5 门禁体系自指失真与 CI 链断裂
   看门人自身失真：正则漏检、目录排除、规则虚标、脚本被 gitignore、husky 未接线、新旧契约打架
   └─投影→ G-04/G-05 假绿、SSOT 虚标、check-no-as-any-store 冲突、ui-layer 阻断、D12 幽灵
```

## 2. 目标架构：单一真理源矩阵（SSOT Matrix）

改造终态下，每个关注点**有且仅有一个属主模块、一条通道、一版实现**：

| 关注点 | 唯一属主（单一职责） | 唯一通道 / 契约 | 物理删除项 |
| :--- | :--- | :--- | :--- |
| 交互原语内容模型 | `ui/Button` `ui/Input` `ui/Textarea` | Button 内容模型自适应（文本才包 label span；元素 children 直渲染）；Enter 提交只走 `onEnter`（IME 守卫内置） | 业务层一切 `:global(.button)` 补丁、内联样式硬编码 |
| 层叠特异性秩序 | `styles/tokens` + 原子基座 CSS | 基座选择器全部 `:where()` 零特异化；业务覆盖只准用自身类名或基座暴露的 `data-*` 钩子 | 257 处 `:global(.button)` 幽灵选择器 |
| 同心几何标尺 | `styles/tokens` radius 变量族 | `--radius-sm/md/lg` + 白名单清单化；药丸圆角物理清零 | 41 处 `radius-full/radius-pill` 业务用法 |
| 图层标尺 | `styles/tokens` z-index 变量族 | 0/10/100/300/400/500/1000/9000 七级，TSX 内联魔数清零 | `zIndex:9999/2010` |
| 尺寸观察 | `ui/utils/ResizeObserverManager`（唯一定义点） | `getInstance().observe()`，挂起/恢复抗竞态 | `services/ResizeObserverManager.ts` 别名 |
| 窗口缩放 | `services/WindowResizeBridge` | `app:window-resize-settled` 唯一广播 | tooltipController 裸 `resize` 监听 |
| 指针安全三角 | `ui/internal/SafeAimEngine`（唯一定义点） | 非单例、显式 destroy、销毁置空 | `SmartExpandablePanel/SafeAimEngine.ts` fork |
| 运行时状态 | `store/sessionRuntimeStatusStore` | `reportRuntimeStatus/clearRuntimeStatus` 唯一写入口 + 硬化门禁 | —（已单轨，补门禁漏洞） |
| 原位重试 | `chat-card/useChatHandlers.regenerateTurn` | 载荷完整化（text+images+attachments）、清态内聚于节流之后 | ComposerErrorBar 前置清态 |
| 消息撤回 | `store/sessionMessageActionsCore` | 撤回=摘除目标节点本身，**严禁截断后续时间线** | `slice(0, idx)` 截断语义 |
| 剪贴板 | 统一 `clipboard` 工具（shared-utils） | 唯一 `copyTextToClipboard`，内置降级 | 各组件散落兜底/裸调用 |
| 门禁基建 | `scripts/check-*.mjs` + `.husky/pre-commit` | 门禁自修与违规清零原子同提交；pre-commit 全量接线 | gitignore 吞噬规则、废弃门面断言 |

## 3. 六大改造流（Stream）技术方案

### S1 · UI 基元契约终版化（治 R1）

**S1.1 Button 内容模型自适应重构**（消灭 DEF-CHAT-01/02/03 与 bare 误用的总根源）
- `Button.tsx`：仅当 `children` 为 `string | number` 时包裹 `buttonLabel` span（保留文字省略/对齐）；children 为元素或数组时直接渲染，`<button>` 自身即 flex 容器，`justify-content`/`gap`/`margin-left:auto` 全部恢复生效，W3C 嵌套合法性自动满足。
- `bare` 语义收窄并文档化：仅用于完全自定义视觉的舞台（列表行、树行 twisty、代码行内按钮），组件 TSDoc 与 `AGENTS.md` 同步写明选型决策树。
- 同步修复：`ComposerFusedTrigger`、`ChatEmptyState`、`FileTreeView`(twisty)、`VirtualPlainCodeViewer`（删 9+ 处内联样式，新增 `DiffCard.module.css` 规范类）。

**S1.2 Input/Textarea Enter 契约**：`onEnter` 为唯一 Enter 提交通道（IME 状态机已内置）；业务 `onKeyDown` 中禁止裸判 Enter 提交（由 S6 新门禁 G-15 强制）。修复 `SessionInlineRename`、`AnnotationChipItem` 改走 `onEnter`；`DiffCard` 搜索框补 `bare` 恢复形态④。

**S1.3 Menu 清尾**：删除 `Menu.module.css:8` `.menuTriggerHost` 死样式；`Menu.tsx` 头注释中"cloneElement 注入"陈旧描述同步更正为 Radix `asChild` Slot 直通契约。

**S1.4 剪贴板统一入口**：新建（或归入既有 shared-utils）`copyTextToClipboard`，内含 `navigator.clipboard` 优先 + 安全降级；`NotePaperStrictHeader`、`StatusDiagnosticsPanel` 等全部收敛到该入口，删除散落兜底。

### S2 · 层叠与几何体系平推（治 R2）

**S2.1 原子基座 `:where()` 零特异化**（一次性，仅触 `components/ui/**`）：Button/Input/Textarea/Menu 的尺寸、变体、hover/focus 态选择器全部下沉 `:where()`，业务层普通类选择器即可合法覆盖——这是物理清除 257 处幽灵选择器的前提。

**S2.2 幽灵选择器物理清除**：59 个模块 257 处 `:global(.button).xxx` 全部删除，替换为：基座 `:where()` 基线之上直接书写 `.xxx`；确需提权处用 `.xxx[data-size]` / 双类名 `.xxx.xxx`。修复 `SidebarSessionList` 图标 16px 跌落、`YamlConfigEditorModal` 搜索 hover 被压。

**S2.3 同心几何平推 + G-04 门禁修复（同一原子提交）**：21 文件 41 处 `radius-full/radius-pill` 按同心公式改 `--radius-sm/md/lg`；同提交修复门禁正则（`var\(--radius-full\b`、`var\(--radius-pill\b`、fallback 魔数 `var\([^)]*,\s*(?:9999px|999px|1000px)\)`）并剔除 G-04 目录排除黑洞。门禁加固与违规清零必须同提交，CI 永不红。

**S2.4 Z-Index 归位 + G-05 修复（同一原子提交）**：`SmartExpandablePanel.tsx:200` 与 `ModelProfileList.tsx:156` 改用 `var(--z-*)` 标尺；正则改为拦截一切 `≥9001` 裸魔数（`9[0-9]{3,}|[1-9][0-9]{4,}`）。

**S2.5 无障碍与第三方穿透**：`ToastStackModern` reduced-motion 提权阶梯（覆盖 `(0,4,0)` 退场动效）；`sessionTabDrag.module.css` `.xterm` 改 `:global(.xterm)` 穿透；`LeafToolTabStrip` 关钮 hover 提权摆脱源码序依赖。

### S3 · 事件与观察单轨硬化（治 R3）

- **S3.1 RO 挂起竞态修复**：`setSuspended(true)` 同步 `cancelAnimationFrame(flushRafId)`；`flushBatch` 执行前与续排前二次检查 `isSuspended`（审计05 §5.3 方案落盘）。
- **S3.2 SafeAimEngine 归并**：保留 `ui/internal/SafeAimEngine.ts`（无单例缺陷版）为唯一定义点，补齐其能力至 SmartExpandablePanel 所需全集；`SmartExpandablePanel.tsx` 改引用；**物理删除** `SmartExpandablePanel/SafeAimEngine.ts`；若保留单例模式则 `destroy()` 必须置空 `defaultInstance`。
- **S3.3 别名门面删除**：删除 `services/ResizeObserverManager.ts` re-export，全部 import 直指 `ui/utils/ResizeObserverManager`（ui 层纯 DOM 工具、零业务依赖，方向合规）。
- **S3.4 tooltipController 去双轨**：删除 `window.addEventListener('resize', dismiss)`（及 cleanup 对应行），仅保留 `app:window-resize-settled`。

### S4 · 重试与撤回状态机根修（治 R4）

- **S4.1 重试载荷完整化**：`regenerateTurn` 判空改为 `!userText && !hasAttachments` 才早退；`streamOptions` 装配 `targetUser.images/attachments`，根治多模态失明与纯图早退。
- **S4.2 清态内聚**：`clearRuntimeStatus(sid)` 从 `ComposerErrorBar.handleRetry` 移入 `regenerateTurn` 节流检查**通过之后**，杜绝"条没了、试没发"。
- **S4.3 瞬态行全帧清理**：`useRunStreamingAssistant` 的 `onThought`/`onToolStart` 首帧补 `clearRuntimeStatus(sid)`，消灭幽灵重试行。
- **S4.4 撤回语义重构**：`withdrawMessage` 废除 `slice(0, idx)` 截断；改为精确摘除目标 assistant 节点（及其派生工具节点），后续 `queued` 用户消息**保留**；如需复位输入，走草稿回填而非删除。
- **S4.5 时间戳兼容恢复**：`NoteSidebarDrawer` 恢复 10 位秒级 Unix 时间戳兼容分支。

### S5 · 门禁体系自修与 CI 链终态化（治 R5）

- **S5.5 gitignore 黑洞修复**：为 `/scripts/**/*.mjs` 增补例外（`!scripts/check-*.mjs`、`!scripts/show-*.mjs` 等门禁与基建脚本白名单），`scripts/show-full-diff.mjs` 正常入库，D12 复绿。
