## 2. 原子层基础设施增强契约（Zero-Overhead Expansion）

为了在消灭裸标签的同时，**不引入任何重叠样式或破坏紧凑布局**，对 `@/components/ui` 进行最小正交增强：

### 2.1 `<Button>` 增强：`bare` 裸语义模式
在 `Button.tsx` 中新增 `bare?: boolean` 选项：
```tsx
export interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'ghost' | 'danger';
  size?: 'xs' | 'sm' | 'md' | 'lg';
  bare?: boolean; // 当为 true 时，剥离 padding/border/background 等视觉包装，保留语义与无障碍
  loading?: boolean;
}
```
- **应用场景**：复杂卡片整体点击（如 `SessionItem`、`SkillCard`）、表格行点击、无内边距的极简文字超链接触点。满足了既拥有 `HTMLButtonElement` 语义和键盘回车触发能力，又不产生样式冲突。

### 2.2 `<Input>` 增强：`bare` 模式与原生类型透传
在 `Input.tsx` 中增强：
```tsx
export interface InputProps extends Omit<React.InputHTMLAttributes<HTMLInputElement>, 'size'> {
  variant?: 'text' | 'search' | 'password';
  size?: 'sm' | 'md' | 'lg';
  bare?: boolean; // 剥离默认 border / background，用于隐藏文件上传框或单行就地编辑
}
```
- **应用场景**：
  - 隐藏文件上传：`<Input type="file" bare style={{ display: 'none' }} />`；
  - 便签/会话就地重命名：`<Input bare className={styles.titleInput} />`。

### 2.3 剪贴板下沉方案
全仓存在 2 处 `document.createElement('textarea')` 用于 `execCommand('copy')` 降级兜底（如 `copyToClipboard`）。将其统一收敛至 `packages/shared-utils/src/clipboard.ts`，禁止在组件层动态 `createElement('textarea')` 触发 AST 门禁。

## 4. W3C 规范与 A11y 无障碍合规准则

在将原生 `<button>` 替换为原子 `<Button>` 时，严禁出现以下常见违规：

1. **绝对禁止按钮嵌套（No Button-in-Button）**：
   - 错误范例：`<div role="button"><Button>点击</Button></div>` 或 `<Button><IconButton /></Button>`。
   - 正确解法：外层若已是按钮，内层操作通过绝对定位浮层并在 DOM 树上与其平级，或者外层使用语义 `<div role="group">` / `<section>`。
2. **强制配备无障碍描述（Accessible Name Required）**：
   - 所有仅包含图标的按钮（`IconButton`），必须显式声明 `aria-label="..."` 属性，并建议外挂 `<Tooltip>`，杜绝盲人读屏软件读出空标签。
3. **键盘可访问性保证**：
   - 所有替换后的原子按钮天然支持 `Tab` 键聚焦，且回车键（`Enter`）与空格键（`Space`）必须触发 `onClick`；
   - 焦点态严格遵循 `AGENTS.md` §13 柔和光环，禁止粗暴实心黑边。
