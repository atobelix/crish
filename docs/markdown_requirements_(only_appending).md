# 用户需求记录 (User Requirements Log)

(此文档记录用户在此项目中提出的所有需求与期望。根据用户要求，此文档**只能追加**，除非获得明确允许否则不可重组。若之前的记录有误，只能通过追加引用的方式说明错误，不得直接删除或修改历史记录。)

## 2026-08-08

- (需求 1)：解决多选或拖拽选择时，列表符号（如 `- [x] `、`- `、`1. ` 等）无法被选中的问题。用户希望选中文本时能连同前缀一起完整选中，以便复制和查看。
- (需求 2)：解决引用块（Blockquote `>`）内部嵌套的代码块（Code Fence ` ``` `）无法被正确渲染为实时预览代码块UI的问题。目前嵌套在引用内的代码块只显示为了普通文本/行内代码样式，用户期望它能像顶层代码块一样正确渲染（带有语言标签、漂亮的语法高亮块等）。
- (需求 3)：列表前缀符号在排版上应当居中（中轴线对齐），但是整体列表项（符号+内容）在视觉上要与同级无前缀的纯文本感觉是左对齐的。
