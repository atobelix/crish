## T6 · A/B 双类分类与登记表落地

**目标**：把「设计 Token」与「运行期量」显式二分，落地登记表，消除「静态不可知」与「靠兜底存活」。

**判据（唯一，不得各自解释）**

| 判据 | A 类（设计 Token） | B 类（运行期量） |
|---|---|---|
| 变更驱动力 | 设计决策（主题/密度/性能档） | 用户交互 / 测量（拖动、悬浮、缩放、索引） |
| 生命周期 | 随档位变化 | 随 DOM 实例 / 单次会话变化 |
| 静态可枚举 | 是 | 否 |
| 默认值 | 静态声明即默认 | **必须有静态声明兜底** |
| 写者 | **只有** `tokens.css`（+ `z-index.css` 授权） | JS，**唯一写者**，必须登记 |

**文件域**：`apps/crish-desktop/src/styles/tokens.css`（**独占**）· `scripts/token-registry.json` · `scripts/check-token-ssot.mjs`

**步骤**
1. **补静态默认**：为全部 B 类 token 在 `tokens.css` 增静态声明（例：`--ui-scale: 1;`、`--sidebar-width: 260px;`、`--chat-col-max: 760px;`、`--leaf-dock-width: 320px;`）。
2. **消除命名空间重叠**：A 类与 B 类不得同名。
3. **登记表对齐**：`bClass[]` 与实扫写入点双向差集为 0；`componentIslands[]` 由 T9 补全。
4. **不越界**：本单元**不删任何 JS 写入点**（那是 T7 的职责）。T6 只做「分类 + 补静态默认 + 登记」。

**验收断言**
1. 每个 B 类 token 在 `tokens.css` 有静态声明（`b_class_no_default` = 0）。
2. `namespace_overlap` = 0。
3. `b_class_drift` 双向差集 = 0。
4. `check-token-consistency` 仍 PASS 0/0/0（补静态声明不得引入新 `dead_tokens`——若某 B 类 token 的消费点是裸 `var()`，补定义后不应变 dead；**若变 dead，说明该 token 实际无消费方 → 上报**）。
5. `git status` 仅 `tokens.css` + 2 个 `scripts/` 文件。

**红线**：**禁止把 `themePersonalization.ts`/`oklchColorGuard.ts`/`fontStore.ts`/`codeBlockIndent.ts`/`visualThemeController.ts` 对语义 token 的写入登记为 B 类**（那是 P1/P2 违规，必须由 `js_inject_a_class` 报出）· 禁自行新增档位 · 不得 git 提交。

## T8 · `--md-*` / `--btn-*` / `--dialog-z` / `--tab-*` 真源归位

**目标**：跨文件重复定义清零（授权白名单外）。

**文件域**：`styles/markdown-typography.css` · `ui/Button` · `diff/DiffCard` · `workspace/PreviewCard` · `sidebar/SidebarNav` · `ui/Dialog` · 5 个 dialog 文件 · `ui/Tabs` · `ui/SegmentedControl` · `styles/tokens.css`（**独占，需在 T7 之后**）

**步骤要点**
- `--md-*`(46)：**删 `markdown-typography.css:12-81` 的 `:root` 与 `html[data-theme='dark']` 定义块**，只留消费规则。理由：亮色下 `tokens.css` 的 `html[data-theme='light']`(0,1,1) 已胜 `:root`(0,1,0)；暗色下同特异性靠导入序（`index.css:4` 在后）→ 该文件胜出 → **胜出方按主题翻转，必须消除**。**此项必须配视觉回归**。
- `--btn-*`(11)：归口 `ui/Button` 单源；另 3 个文件改为消费或改用 `ui/Button`。
- `--dialog-z`(5 文件)/`--dialog-width`(3 文件)：归口 `ui/Dialog`（`--dialog-z` 直接用全局 `--z-modal`）。
- `--tab-duration`/`--tab-press-duration`/`--tab-spring-bezier`：归口 `ui/Tabs`。
- 单点遮蔽逐个裁决：**要么**提升为全局语义 token，**要么**改名为带前缀私有 token 消除同名遮蔽。
- `--z-*` 维持 `z-index.css`，在 `tokens.css:476` 注释处补「唯一真源索引」指向说明。
- `--duration-*`/`--transition-*` 的 `reduced-motion.css:22-25` 4 个选择器收敛为单一 `:root`（`!important` 已保证优先）。

**验收断言**：`multi_file_defs` = 0（授权白名单外）· 暗色 markdown 表头/行 hover/链接色在双主题下与 `tokens.css` 单源一致（视觉回归 + 计算值）· `check-token-consistency` 仍 PASS。

**红线**：禁保留双源（必须删定义块，不是注释掉）· 不得 git 提交。

## T9 · 孤岛命名空间登记 + 泛名修复

**目标**：123 个孤岛 token 在册；消除泛名污染。

**文件域**：`overlay/ToastStackModern.module.css` · `ui/Switch` · `ui/Badge` · `ui/Tabs` · `ui/SegmentedControl` · `chat-composer/ChatComposer.module.css` · `note-paper/NotePaperPanel.module.css` · `workspace/WorkspaceEmptyState.module.css` · `ui/Button` · `ui/ScrollArea` · `chat-message-row/FlowPlanMilestone.module.css` · `scripts/token-registry.json` · `tokens.css`（仅追加索引注释区）

**步骤**
1. **泛名立即修**：`ToastStackModern` 的 `--gap` / `--height` / `--scale` → `--toast-gap` / `--toast-height` / `--toast-scale`（**危害**：无前缀泛名会被任意后代消费者的 `var(--gap)` 意外命中）。
2. **作用域收敛**：私有 token 只定义在**组件根选择器**内，禁止出现在 `:root`。
3. **登记**：全部孤岛进 `token-registry.json.componentIslands`。
4. **索引注释区**：在 `tokens.css` 顶部列出「全局体系 vs 组件私有」边界（只登记名字与归属，不搬定义）。

**验收断言**：泛名 `--gap`/`--height`/`--scale` 在 `ToastStackModern` 内 = 0 · 孤岛全部在册 · `:root` 上无组件私有 token · `check-token-consistency` 仍 PASS。
**红线**：禁复制定义代替晋升 · 禁自行新增全局档位（晋升需登记请示）· 不得 git 提交。
