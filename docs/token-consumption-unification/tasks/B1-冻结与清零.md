**负责的 token 族（严格限定）**：`--transition-*`(13) · `--duration-*` · `--ease-*` · `--opacity-*` · `--shadow-*` · `--focus-ring`/`--focus-ring-color` · `--font-mono`/`--font-sans` · `--line-height-*` · `--font-weight-*`

**处置规则（四分法）**
- **A1 错误兜底**（兜底值与真值不符）→ **必改**，最高优先。
- **A2 等价兜底**（与真值数值一致）→ 渐进去兜底。
- **A3 语义兜底**（兜底是另一个 token，如 `var(--hairline, var(--border-subtle))`、`var(--radius-full, 9999px)`）→ **保留**，不得误判违规。
- **A4 白名单**：`--radix-*` 外部注入；`var(--tooltip-translate, translate(0))`（`style-contract.test.ts:486-491` 已钉）→ 保留。

**核心原则**：**去兜底 ≠ 改兜底**。默认值由静态声明提供；token 缺席应当是门禁可见的失败。**唯一例外**：若某处兜底承担不可省略的语义 → 保留并**加一行注释说明理由**，并在汇报中列出。

**专项裁决**：`--font-size-*` 族**一律去兜底**（任何裸 px 兜底都绕过 `--font-size-adjust`）；`--transition-*`/`--duration-*` **一律去兜底**（降动网格才会真正生效）；`--font-mono`/`--font-sans` **一律去兜底**。属 `--font-size-*` 的实例本单元也可处理（按 A1→A2）。
若某 token 在 `tokens.css` 基础块（`:root, html[data-theme='default'], html[data-theme='light']`，约 33 行起）**无静态定义** → **不删兜底**，列清单上报。

**验收断言**
1. 上述族的重扫「同一 token 兜底值变体数」→ **≤1**；已去兜底者 → **0**。
2. 本族 `var(--token, <裸字面量>)` 出现次数**单调下降**（给前后对比数字）。
3. `--font-size-*` 带兜底实例 = **0**。
4. **降动链证据**：给出 `--transition-fast` 一个消费点 `文件:行号`，说明去兜底后 `prefers-reduced-motion: reduce` 下有效值来源为 `reduced-motion.css` 的 `0ms`。
5. `node scripts/check-token-consistency.mjs` 未因你变红。
6. `git status --porcelain` 仅 `*.module.css` / `*.css`（非 `styles/`），**且无 ` M` 文件被你二次修改**。
