## T11 · 层叠修复与样式假象整治

**目标**：修复密度档层叠失效（P34）；层叠陷阱登记；魔术数字补偿与 `!important` 棘轮下降。

**文件域**：`styles/tokens.css`（**仅选择器，独占**）· `styles/layout-contract.test.ts`（**追加，不得删既有断言**）· 层叠陷阱 10 处 · 魔术补偿 14 处 · `scripts/stacking-traps.json`（新建）

**步骤**
1. **层叠修复（本单元最高价值项）**
   - 事实：`tokens.css:33-35` 基础块最高特异性 **0,1,1**（`html[data-theme='light']`）压制 `:1300`/`:1364` 密度档 **0,1,0**；`data-theme` 与 `data-ui-size` 都写在 `<html>`（`themeStore.ts:80`、`AppBootstrap.ts:255`）→ **亮色下密度档静默失效、暗色下正常**。最小样本 `--space-1`：基础 `:702`=4px、small `:1323`=4px、large `:1387`=6px。
   - 修法（二选一，**推荐 ②**）：① 密度档选择器升为 `html[data-ui-size='small'|'large']`；② **基础块去掉 `html[data-theme='light']`，只留 `:root`**（语义上「基础档」不该与主题挂钩）。
2. **新增 `G-CASCADE`（必须）**：断言 `data-theme ∈ {light,dark}` × `data-ui-size ∈ {medium,large}` 四组合下，关键档位 token 的 `getComputedStyle(html).getPropertyValue(name)` == 该组合应生效的声明值。
   - 落地：优先真实层叠（加载真实 `tokens.css` 文本 + 构造 `<html data-theme data-ui-size>`）；若 jsdom 对自定义属性层叠支持不足 → 降级为**纯逻辑层叠评估器**（按 `(specificity, source order)` 计算胜出声明），**且评估器本身必须有针对 `[attr]` vs `html[attr]` vs `:root` 的特异性单元测试（正/逆/退化态穷举）**。
   - **禁止只做「文本存在性」断言**（现有 `layout-contract.test.ts:73-135` 的缺陷即在此）。
3. **层叠陷阱登记**：`scripts/stacking-traps.json` 收录 10 处（`GlobalErrorBanner` · `ToastStack` · `SettingsPanel`(fixed+isolate:19+contain:strict:279) · `sessionTabDrag`(z-index:100000) · `PreviewCard.positioner` · `ToastStackModern.toastCard` · `Sidebar.sidebarScroll`(contain+translateZ) · `SidebarSessionList` · `FilesCard.filesBody`(isolate) · `SegmentedControl`），每条说明**为何必要**。参照 `Menu.module.css:3-6` 的穿透范式（把 z 挂到 `[data-radix-popper-content-wrapper]`）。
4. **sticky 契约登记**：`G-STICKY-CONTRACT`（`ModelsSettingsTab.module.css:280-282` 自述「`overflow:hidden` 会把 footer 的 sticky 截断在中间祖先里」）。
5. **魔术数字补偿清零**（14 处）：改用布局原语（`inset`/`grid`/`position:sticky`）表达意图；确需语义几何 token → 登记请示。
6. **`!important` 棘轮**：152 → 0（`reduced-motion.css` 的 44 处属**合法**降动强制 → 白名单）。

**验收断言**
1. **四组合真机断言 PASS**（`G-CASCADE` = 0）—— 附四组合的实测 `getComputedStyle` 值表。
2. `G-STACKING-REGISTERED` / `G-STICKY-CONTRACT`：无未登记项。
3. `G-IMPORTANT` 棘轮下降；`G-MAGIC-COMP` 棘轮下降（给前后数字）。
4. **不得删除** `layout-contract.test.ts` 既有的存在性/整数性/单调性断言（只可追加）。
5. `git status` ⊆ 文件域。
