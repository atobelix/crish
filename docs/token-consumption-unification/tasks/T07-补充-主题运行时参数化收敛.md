## 二、目标架构

```
用户偏好（skin / accent / brightness / solarWarmth / fontSizeAdjust / uiScale）
        │  写者：TokenRuntimeController（唯一，且只写「参数」）
        ▼
  参数层（B 类 · 必须在 tokens.css 有静态默认 · 必须登记 token-registry.json）
  --user-accent-h / -s / -l        --user-surface-h / -s
  --user-surface-tint              --user-brightness        （-100..100 的数值语义）
  --user-solar-warmth              --user-green-light-mix / --user-red-light-mix
  --font-size-adjust               --ui-scale
        │  CSS 内派生（color-mix / calc / hsl），零 JS 参与
        ▼
  语义层（A 类 · tokens.css 静态声明 · 亮/暗/密度/性能四档各自给出派生结果）
        │
        ▼
  消费层：裸 var(--token)
```

**结果**：`TokenRuntimeController` 从「34 个 setProperty」降为「≈10 个参数 setProperty」；`tokens.css` 成为语义唯一真源。

## 六、验收断言

1. **`node scripts/check-token-ssot.mjs` 的 `js_inject_a_class` 从 40 降至 ≤ 参数层数量**（预期 ≤ 12，且全部为已登记 B 类参数）。最终目标：各项硬失败指标 = 0。
2. `a_class_multi_writer` = **0**。
3. **`G-CASCADE` 四组合断言**（`theme ∈ {light,dark}` × `data-ui-size ∈ {medium,large}`）：关键档位 token 的 `getComputedStyle(html).getPropertyValue(name)` == `tokens.css` 该组合应生效的声明值。落地方式见 `03-分维-消费面物理清零.md` §5.1。
4. **回归物证（必须真机）**：改 `tokens.css` 中 `--surface-base` 一处 → 四组合下界面**全部**反映该改动。这是「消灭改静态真源界面不变」的唯一客观证据。
5. **视觉无回归**：四组合截图组与改造前逐张对比（浅色/暗色 × 中/大档）。
6. **零裸色**：`TokenRuntimeController.ts` 中 `hsl(0 0% 0%)` / `hsl(0 0% 100%)` 出现次数 = **0**；其余皮肤常数迁出后，该文件不再含任何 `hsl(`/`#hex` 色彩字面量（`var()` 除外）。
7. `oklchColorGuard` 仍为**纯函数**（不得回退为直接写 DOM）。
8. `style-contract.test.ts` 的「注入 token ∈ 静态定义」「双源同值」两类断言仍 PASS。

## 七、不可自动化 / 需人工确认的部分（**明确声明，不假装闭环**）

| 项 | 原因 |
|---|---|
| 视觉无回归 | 需要**真机截图对比**（四组合），本战役的自动化只能验「计算值是否等于声明值」，**不能验「观感是否符合设计意图」** |
| 皮肤预设的色相/饱和度是否保持原设计 | `:184-299` 的百分比与色相是设计参数；迁移时须**逐值核对**，迁移前后同皮肤的 `getComputedStyle` 值必须一致（可作为自动化断言，见验收 6 的扩展） |
| `--chat-stream-pad-x` 的密度耦合裁决 | 见 `../基线记录/gap-registry.md` §三「取值分叉」——需产品裁决「随密度缩放 vs 固定 20px」 |

**执行顺序（不可颠倒）**：
① 参数层引入（新增静态声明，不动消费点，界面不变）→ ② 逐族切换语义 token 为派生形态（`--bg-*` → `--text-*` → `--border-*` → `--surface-*` → `--composer-*` → `--terminal-*` → `--control-*` → `--accent-*-light-adaptive`），每族后跑 `G-CASCADE` + 视觉对比 → ③ 物理删除对应 `setProperty` 与 JS 造色分支 → ④ 跑门禁确认 `js_inject_a_class` 达标 → ⑤ 全链路物证。
