# Conex / Crish 界面色彩平滑与差异面板视觉重构总方案

> **战役定位**：全面根除应用首屏 300ms 变色闪烁（FOUC）、`--accent-color` 异化为死黑导致全界面按钮/开关/徽标/滑块发黑、差异比对面板语法高亮丢失/分栏错位/380px 高度锁死/底板浑浊，以及级联污染、深色 30% 焦点环超标（AGENTS.md §13）、原生 `title` 属性残留（§12）等一系列视觉退化问题。
> **方案定稿**：基于 5 份严苛审查报告（`audits/01`~`05`）、3 份独立提案（`analysis/01`~`03`）、5 份独立实施方案（`independent-plans/01`~`05`）与 3 份交叉评审报告（`plan-reviews/01`~`03`）综合收敛定案，严格遵循“先删后改、单一真源、0ms 零闪烁、柔和克制”的架构铁律。

## 五、验收标准与门禁规范

5. **门禁全绿**：`npm run typecheck`（0 错误）+ `npm run check:line-counts`（0 违规）+ Vitest 单测 100% PASS。
