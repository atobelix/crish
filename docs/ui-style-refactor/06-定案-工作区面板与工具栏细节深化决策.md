# Conex / Crish 工作区面板与工具栏细节深化重构定案决策

> **战役定位**：针对用户在真实交互中发现的 7 大视觉与操作断层（运行时面板背景偏色、面板切换先灰后白跳闪、紧凑工具栏按钮 hover 叠加死黑与高度参差、侧边栏分支文本拼接变形、概览面板伪目录树挤压、`_metaLine_1qjwi_41` 冗余芯片、“代码产物”概念错位与面包屑浮层透明失效）进行地毯式彻底根治。
> **决策依据**：基于 5 份深度专项审计报告（`audits/06`~`10`）综合裁决，确立“卡片底板纯白统一、0ms 切换零跳灰、双层 Hover 叠加归零、工具栏 26px 等高、改动文件扁平列表一览、文件管理器概念归位”的定案总纲。

## 二、【强制专节】删除面清单（Deletion Surface）

- **DEL-WS-01**：彻底删除 `RuntimePanel.module.css:12` 与 `AgentCard.module.css:6` 中的 `background: var(--bg-primary)` 与 `var(--shell-inset-bg)`，统一使用 `var(--bg-card, #ffffff)`；
- **DEL-WS-02**：彻底删除 `BinaryTreeWorkspace.module.css:410` 中 `.emptyState` 的 `background: var(--bg-secondary)`（#eaecee 深灰），改为纯白卡底；
- **DEL-WS-03**：彻底删除 `DiffCard.module.css`、`FilesCard.module.css`、`CompactDiffHeader.module.css` 中所有对 `<Button>` 的二次 `:hover { background: ... }` 覆写，消除双层叠加死黑；
- **DEL-WS-04**：彻底删除 `SessionRow.tsx:206-210` 中的 `isBranched ? '分支: ' + ... : baseTitle` 字符串前缀拼接；
- **DEL-WS-05**：彻底删除 `OverviewHeader.tsx:21-27` 中的 `.metaLine` 容器与 `OverviewCard.module.css:21` 中的 `.metaLine` / `.metaChip` 样式；
- **DEL-WS-06**：彻底删除 `OverviewGitTree.tsx` 与 `OverviewGitTree.module.css` 中的伪目录树递归逻辑与折叠状态；
- **DEL-WS-07**：彻底删除全工程中关于文件管理器 “代码产物” 的历史名称，统一归一为 “文件”；
- **DEL-WS-08**：彻底删除 `FileBreadcrumb.tsx` 中依赖 `bcFlyout.path === b.path` 导致的浮层点击瞬灭逻辑。
