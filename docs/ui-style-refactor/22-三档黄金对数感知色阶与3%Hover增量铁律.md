## 一、核心色度学模型与数学推导

### 1. 纯 HSL 色相与饱和度权威真源（Zero-Blue 铁律）
- **色相基底 $H$ 锁定**：$$H = 35^\circ$$（微暖琥珀黄/暖沙基底，严格杜绝 $B > R$ 的冷蓝发闷灰阶）
- **饱和度 $S$ 锁定**：$$S = 8\% \sim 10\%$$
- **绝禁模式**：严禁使用任何十六进制硬编码（`#f4f5f7`、`#eaecee` 等）与原始 RGB，所有颜色必须经由 HSL 数学公式派生。

## 三、3% 黄金增减量（Hover & Active）绝对铁律

1. **悬停态落差死锁 3%**：
   - 浅色模式下：$$L_{\text{hover}} = L_{\text{background}} - 3.0\%$$
   - 绝不允许使用深色基底（如 30% 亮度的 `--control-mix-color`）进行混合，杜绝 19.2% 的黑膏药死色！
2. **激活态落差死锁 6%**：
   - 浅色模式下：$$L_{\text{active}} = L_{\text{background}} - 6.0\%$$
3. **内容卡片纯白锚点（SSOT）**：
   - 无论是档位 1、2 还是 3，编辑器主卡片与对话内容卡片（`--bg-card` / `--bg-elevated`）**始终保持 100% 纯净纸白 `hsl(0 0% 100%)`**，形成坚挺的空间实体感与层级反差。

## 四、边框发丝规范（Zero-Blue Hairline）

- **实体外发丝边框**：`--border-color: hsl(35 10% 86%)`（1px 纯色发丝，彻底杜绝半透明伪环）；
- **内衬细微分割线**：`--border-subtle: hsl(35 8% 91%)`；
- **同心圆角几何体系**：
  $$R_{\text{inner}} = \max(R_{\text{outer}} - \text{Padding},\ 6\text{px})$$
  （Panel 14px $\to$ Padding 6px $\to$ Item 8px $\to$ Button 6px $\to$ Badge 4px）。
