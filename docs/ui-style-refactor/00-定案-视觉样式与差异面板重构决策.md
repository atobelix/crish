# Conex / Crish 界面视觉修复与差异面板重构定案决策

> **战役定位**：彻底根治应用首屏 300ms 变色闪烁（FOUC）、`--accent-color` 异化为死黑导致全界面按钮/开关/徽标/滑块变黑、差异比对面板语法高亮丢失/分栏错位/380px 高度锁死/底板浑浊，以及级联污染、深色 30% 焦点环违规（AGENTS.md §13）、原生 `title` 属性残留（§12）等一系列视觉退化问题。
> **决策依据**：基于 5 份严苛审查报告（`audits/01`~`05`）与 3 份独立提案建议（`analysis/01`~`03`）综合裁决，确立“先删后改、单一真源、0ms 零闪烁、柔和克制”的重构总纲。

## 四、硬性红线与设计基线守卫

1. **Zero-FOUC 铁律**：应用冷启动时从白屏/黑屏到首帧绘制必须在 0ms 种子脚本下一次性锁定最终主题与皮肤色，严禁出现中间过渡色与 300ms 补间动画；
2. **Zero-Blackening 铁律**：除主要正文文本之外，严禁将 `--text-primary` 或任何亮度 $\le 20\%$ 的死黑颜色作为按钮、开关、徽标、卡片、滑块或进度条的实体背景；
3. **AGENTS.md §13 铁律**：边框与焦点态相对基底加深混入严格控制在 **3%~8%（上限 10%）**，严禁粗、深、实心黑边；
4. **AGENTS.md §12 铁律**：严禁原生 HTML `title=` 气泡，可交互元素一律包裹 `<Tooltip>` 胶囊；
5. **Zero-Blue 铁律**：全局严禁出现 `hsl(215 90% 52%)` 或冷蓝偏灰，活态签名独占使用品牌翡翠绿。

本定案决策作为战役唯一最高行动纲领，即刻生效。
