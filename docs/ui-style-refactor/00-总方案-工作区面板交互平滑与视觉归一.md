# Conex / Crish 工作区面板交互平滑与视觉归一总方案

> **战役定位**：彻底根治运行时面板背景偏色、面板切换先灰后白闪烁、紧凑工具栏按钮 hover 叠加死黑与整行 DOM 高低不齐、侧边栏分支文本拼接变形、概览面板伪目录树挤压、`_metaLine_1qjwi_41` 冗余芯片、“代码产物”概念错位与面包屑浮层透明失效等 7 大问题。
> **方案定稿**：严格遵循“卡片底板纯白统一、0ms 切换零跳灰、双层 Hover 叠加归零、工具栏 26px 等高、改动文件扁平列表一览、文件管理器概念归位”的架构原则。

---

## 一、核心重构目标与主路径

1. **运行时背景统一与面板切换零跳闪（Zero-Flash on Switch）**：
   - 将 `RuntimePanel.module.css` 与 `AgentCard.module.css` 根容器背景一律修正为 `background: var(--bg-card, #ffffff)`，消除偏色与视觉下坠；
   - 将 `BinaryTreeWorkspace.module.css` 的 `.emptyState` 修正为 `background: var(--bg-card, #ffffff)`，彻底根除 Suspense Fallback 深灰底色在 Chunk 加载时导致的“先灰后白”剧烈跳闪；
   - 在 `main.tsx` 的 `idleTask` 中预热加载常用工具视图 Chunk（diff / files / runtime / overview / preview），实现切换 0 延迟。

2. **紧凑工具栏高度对齐与按钮 Hover 去黑（26px 等高与单层 Hover）**：
   - 彻底删除 `DiffCard.module.css`、`FilesCard.module.css` 等业务样式中对 `<Button>` 的二次 `:hover { background: ... }` 覆写，消除双层叠加导致的 15.36% 死黑，统一由 `ui/Button` 单层管理 4% 轻柔遮罩；
   - 为 `DiffHeaderControls.tsx` 中的 `<Select>` 显式传入 `size="sm"`，将工具栏各交互控件（来源胶囊、Select、ActionButtons、搜索框、面包屑）统一锁定在 26px 高度基线上，彻底消除 32px 爆框与高低参差。

3. **侧边栏分支微图标重构与 MetaLine 冗余清理**：
   - 彻底废除 `SessionRow.tsx` 中的 `isBranched ? '分支: ' + ... : baseTitle` 字符串前缀拼接，保持标题纯净；引入 `<GitBranch size={11} className={styles.branchIcon} />` 规范微图标，释放侧栏宽度，杜绝挤压变形；
   - 彻底删除 `OverviewHeader.tsx` 中的 `.metaLine` 容器与 `OverviewCard.module.css` 中的相关样式，清理 `_metaLine_1qjwi_41` 冗余芯片。

4. **概览面板改动文件扁平化列表重构（OverviewChangesList）**：
   - 废除 `ChangesSection.tsx` 中深层嵌套的递归伪目录树与折叠状态；
   - 重构为扁平紧凑的改动文件列表（28px 单行高度，状态徽标 M/A/D/U，主文件名加粗等宽，弱化路径后缀，单行悬浮高亮，单击直达 Diff）。

5. **文件管理器概念归位、根目录固化与面包屑弹窗修复**：
   - ViewRegistry `id: 'files'` 标题全仓统一更名为 “文件” (Files)，图标统一为 `FolderTree`；
   - 在 `FileTreeView.tsx` 顶部固化项目根容器 Header（`📁 conex (c:/Software/conex)`），清晰指引项目根上下文；
   - 修复 `ProjectsSection.tsx` 点击项目文件夹行时调用 `openProject(p.id)` 切换当前工作区；
   - 在 `z-index.css` 补齐 `--z-breadcrumb: 400`，浮层底板使用不透明纯色 `var(--bg-elevated, #ffffff)`；重构 `FileBreadcrumb.tsx` 独立维护浮层下钻导航状态栈，彻底消除点击子目录导致的闪退与无法操作。

## 三、实施顺序与门禁

1. **Phase 0**：物理删除 OverviewHeader 中的 .metaLine 容器与 CSS，移除 DiffCard 中的二次 hover 覆写，删除 SessionRow 中的 "分支: " 字符串拼接；

4. **Phase 3**：`npm run typecheck` + `npm run check:line-counts` + 全量 Vitest 单测 100% 通过。
