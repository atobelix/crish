## 一、做什么（新增 / 改造清单与架构图）

### 1.1 架构设计总览与 Zero-Flash 时序流水线

在 Conex / Crish 工作区界面中，右侧面板承担着高频的代码差异审查、文件浏览、总览分析、应用预览与运行时状态监控等任务。当前存在的“运行时偏色”与“面板切换先灰后白”两大痛点，本质是**容器底色语义倒置**与**异步 Chunk 加载空窗期 Fallback 底色违背卡片底色**造成的。

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│               工作区面板底板统一与零跳灰切换 (Zero-Flash Pipeline) 全景图                 │
├────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                        │
│ 【1. 容器底色单真源对齐 (SSOT)】                                                       │
│   外壳画板 (Shell Canvas)   ──> var(--bg-primary, #f4f5f7) (外围留白垫底)               │
│   工作区大卡片 (Tree Canvas) ──> var(--bg-elevated, var(--bg-card)) (#ffffff 纯白)      │
│   所有叶子面板 (Leaf Panels) ──> var(--bg-card, #ffffff) (Diff/Files/Overview/Runtime)  │
│   Suspense Fallback 占位屏  ──> var(--bg-card, #ffffff) (与真实面板 100% 视觉融合)      │
│                                                                                        │
│ 【2. 切换时序：从“剧烈跳灰”到“0ms 无缝瞬切”】                                          │
│                                                                                        │
│  [重构前 (Before: 50ms 闪黑断层)]:                                                     │
│   点击标签 ──> 挂载 Lazy Component ──> Suspense 激活 ──> 渲染 #eaecee 实体深灰底块 🚨  │
│   (耗时 50ms~200ms 加载 Chunk) ──> 真实面板渲染纯白卡底 ──> 视觉产生【白→深灰→白】剧烈跳闪│
│                                                                                        │
│  [重构后 (After: 双重防御零跳灰)]:                                                     │
│   防御层 A (闲时预热): main.tsx idleTask 提前完成 Diff/Files/Runtime 等 Chunk 加载       │
│                        用户点击标签 ──> 0ms 瞬时命中缓存 ──> 无 Suspense 挂起            │
│   防御层 B (底色同构): 即使首次冷点击发生 Suspense ──> Fallback 底色为 var(--bg-card)   │
│                        仅展示轻量 Spinner，底色完全无差，ΔE = 0，彻底根除跳灰           │
│                                                                                        │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 运行时基座与卡片底板纯白统一（`RuntimePanel` / `AgentCard`）
1. **`RuntimePanel.module.css` 根容器纠偏**：
   - 将 `.panel` 的 `background` 由错误的画板外壳灰 `var(--bg-primary)`（`#f4f5f7`）纠正为标准卡片白 `var(--bg-card, #ffffff)`；
   - 将区段分割线由高对比度的 `border-bottom: 1px solid var(--tint-active)` 统一为标准微发丝线 `border-bottom: 1px solid var(--border-subtle)`；
2. **`AgentCard.module.css` 根容器纠偏**：
   - 将 `.agentCard` 与 `.agentCardLaunch` 的 `background` 由 `var(--shell-inset-bg, var(--bg-primary))` 纠正为 `var(--bg-card, #ffffff)`，拔除历史遗留偏色。

### 1.3 列表行 `.row` 透明化与轻量 Hover 悬浮反馈规范
1. **废除实心深灰堆叠**：
   - 在 `RuntimePanel.module.css` 中，将 `.row` 列表项的默认背景从实心深灰 `var(--bg-secondary)`（`#eaecee`）重构为 `background: transparent;`；
   - 悬停反馈统一采用轻柔微色 `background: var(--bg-hover);`（`color-mix(in srgb, var(--text-primary) 4.5%, transparent)`）；
2. **活跃态与可点击行统一**：
   - 将 `.row.isLive:hover` 的背景从 `var(--bg-secondary)` 统一为 `var(--bg-hover)`，消除不同行在悬停时的色阶参差。

### 1.4 `BinaryTreeWorkspace` 空态 / Suspense Fallback 纯白卡底改造
1. **根除 `#eaecee` 脏灰 Fallback**：
   - 将 [`BinaryTreeWorkspace.module.css`](file:///c:/Software/conex/apps/crish-desktop/src/components/binary-tree/BinaryTreeWorkspace.module.css) 中 `.emptyState` 的 `background: var(--bg-secondary)` 纠正为 `background: var(--bg-card, #ffffff)`；
2. **骨架与过渡融合**：
   - 当 React `Suspense` 触发时，`.emptyState` 呈现与目标卡片完全同色的纯白背景，加载文本采用柔和的 `var(--text-tertiary)`，消除任何色块跳变。

### 1.5 `main.tsx` 空闲预热（Chunk Prewarming / Zero-Latency Switch）
1. **闲时预加载核心视图**：
   - 在 [`apps/crish-desktop/src/main.tsx`](file:///c:/Software/conex/apps/crish-desktop/src/main.tsx) 的 `idleTask` 中，利用 `requestIdleCallback`（降级使用 `setTimeout` 1500ms）提前预加载核心工具视图 Chunk：
     - `DiffCard` (`./components/diff/DiffCard`)
     - `FilesCard` (`./components/files/FilesCard`)
     - `OverviewCard` (`./components/overview/OverviewCard`)
     - `PreviewCard` (`./components/workspace/PreviewCard`)
     - `RuntimePanel` (`./components/workspace/RuntimePanel`)
2. **零延迟命中**：
   - 用户在启动 1.5s 后的常规交互中点击任意面板标签，均能在 0ms 内直接从内存完成模块挂载，跳过 React 挂起链路。

### 1.6 次级容器与内嵌条带杂灰清剿（`FilesCard` / `PreviewCard` / `LeafToolTabStrip`）
1. **`FilesCard.module.css`**：
   - 将 `.filesContextBar`（文件上下文栏）、`.filesPreviewPdf`（PDF 预览区）、`.filesBcFlyoutSearch`（面包屑下拉搜索框）中的 `background: var(--bg-primary)` 统一收敛为 `var(--bg-card, #ffffff)`；
