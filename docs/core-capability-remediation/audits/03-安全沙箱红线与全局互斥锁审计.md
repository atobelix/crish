## 二、 维度一：PowerShell 编码命令深度解码与审批通道明文展示

### 2.1 缩写与变体参数全覆盖

PowerShell 解释器参数绑定支持前缀唯一性与驼峰匹配。过去实现中因限定 `"encodedcommand".starts_with(flag)` 导致高频缩写 `-ec`（`E`ncoded`C`ommand 驼峰）及 `-en` 漏网。

当前实现（[`crates/conex-sandbox/src/semantics.rs:620-648`](file:///c:/Software/conex/crates/conex-sandbox/src/semantics.rs#L620-L648)）采用双规判断机制：
1. **驼峰缩写匹配**：`flag_name.starts_with("ec")`，覆盖 `-ec`, `-eco`, `-ecom`, `-ecomm`, `-ecomma`, `-ecomman`, `-ecommand`；
2. **前缀匹配**：`"encodedcommand".starts_with(flag_name)`，覆盖 `-e`, `-en`, `-enc`, `-enco`, `-encode`, `-encoded` 等；
3. **负向安全排他**：`flag_name.starts_with("ex")` 刚性排除 ExecutionPolicy（如 `-executionpolicy`, `-ex`, `-exec`）；
4. **分隔符与前缀剥离**：支持 `--`, `-`, `/` 前缀，支持 `:` 与 `=` 内联传参（如 `/ec:<b64>`, `-EncodedCommand=<b64>`）。

```rust
// crates/conex-sandbox/src/semantics.rs:620-648
pub fn is_ps_encoded_command_flag(arg: &str) -> bool {
    let lower = arg.to_lowercase();
    let stripped = if let Some(s) = lower.strip_prefix("--") {
        s
    } else if let Some(s) = lower.strip_prefix('-').or_else(|| lower.strip_prefix('/')) {
        s
    } else {
        return false;
    };
    let flag_name = stripped.split(['=', ':']).next().unwrap_or(stripped);
    if flag_name.is_empty() || flag_name.starts_with("ex") {
        return false;
    }
    if flag_name.starts_with("ec") || "encodedcommand".starts_with(flag_name) {
        return true;
    }
    false
}
```

### 4.2 绝对路径安全围栏（CommandPathInspector）

在 [`crates/agent-tools/src/tools/shell.rs:470-793`](file:///c:/Software/conex/crates/agent-tools/src/tools/shell.rs#L470-L793) 中实装了 `CommandPathInspector`，在 Shell 执行入口处设立双重强隔离围栏：

## 五、 维度四：全局分级路径互斥与 TaskType 白名单

### 5.1 HolderId 三元组与同 Run 并行写互斥

过去实现以 `run_id` 字符串作为锁持有者，导致同一次 Run 中若并发执行多个写工具调用（如批量写入多个文件），锁机制误认为属于“自身”而丧失并发互斥能力。

重构后的实现（[`crates/agent-tools/src/write_paths_state.rs:51-109`](file:///c:/Software/conex/crates/agent-tools/src/write_paths_state.rs#L51-L109)）：
1. 升级为 `HolderId { session_id, run_id, tool_call_id }` 三元组；
2. **兼容性断言矩阵**（`is_compatible_with`）：
   - `self == other`：兼容（幂等刷新与自身续期）；
   - 同 session、同 run_id 下：
     - 若其中一方为 Run 级预留（`tool_call_id` 为空）：**兼容**（允许子代理在编排分配给自身的路径范围内执行写工具）；
     - 若双方均为具体工具调用（`tool_call_id` 均非空）且 ID 不同：**不兼容，判定冲突**（`TOOL_WRITE_PATH_CONFLICT`，彻底消除同 run 并行写穿透）；
   - 跨 Run 或跨 Session：严格不兼容互斥。

### 5.2 RAII 精准释放与 15 秒租约心跳续期

1. **RAII 精准释放**（[`write_paths_state.rs:255-287, 466-469`](file:///c:/Software/conex/crates/agent-tools/src/write_paths_state.rs#L255-L287)）：
   `WriteClaimGuard` 在 Drop 时调用 `registry.release_exact_paths(&self.holder, &self.claimed_paths)`，仅精准释放该 Guard 声明的路径，绝不清除该持有者的其余有效锁。
2. **15 秒租约心跳续期**（[`write_paths_state.rs:406-425, 472-481`](file:///c:/Software/conex/crates/agent-tools/src/write_paths_state.rs#L406-L425)）：
   默认 TTL 为 60 秒（`DEFAULT_CLAIM_TTL_MS`）。在 `claim` 成功后，若存在 Tokio 运行时，自动 spawn 后台任务每 15 秒执行一次 `renew_lease`（刷新 `expires_at_ms = now + ttl`）。心跳任务持有 `Arc::downgrade` 弱引用，并在 Guard Drop 时通过 `handle.abort()` 立即终止，兼具防提前过期与防内存悬挂。

### 5.3 TaskType 白名单刚性门禁

子代理指定任务类型时，通过 [`crates/agent-tools/src/readonly.rs:158-183`](file:///c:/Software/conex/crates/agent-tools/src/readonly.rs#L158-L183) 的 `command_allowed_for_task_type` 严格收口：

  - 在 [`crates/agent-tools/src/tools/shell.rs:241-256`](file:///c:/Software/conex/crates/agent-tools/src/tools/shell.rs#L241-L256) 的 `prepare` 阶段前置拦截，任何非 git 命令（如 `npm`, `cargo`, `echo`, `rm`, `del`）直接拒绝执行，返回 `PermissionDenied: 任务类型 [commit] 严格禁止执行非白名单命令`。

### 5.4 彻底拔除 FullAccess 删除特权

在 [`crates/agent-tools/src/tools/shell.rs:296-312`](file:///c:/Software/conex/crates/agent-tools/src/tools/shell.rs#L296-L312)：

## 七、 互斥锁并发与租约心跳验证断言
