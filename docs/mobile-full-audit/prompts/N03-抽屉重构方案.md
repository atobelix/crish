## 任务

### A. 现状还原

读 `app/(main)/_layout.tsx`（`drawerType: 'front'`、`swipeEdgeWidth`、`overlayColor: scrim`、`drawerStyle`、`sceneStyle`）、`src/presentation/components/drawer/*`（`CrishDrawer / DrawerHeader / DrawerNav / DrawerFooter / DrawerSessionGroups`）、`app/_components/useOpenDrawer.ts`、`theme.layout.drawer*`、`ApprovalFloat` 与抽屉的层级关系。还原：当前抽屉的层级模型、手势模型、版式与键盘行为。

### B. 手势唤醒为什么不稳（找根因，不要凭经验猜）

用户实机反馈：从左向右滑**不能唤醒**。逐项排查并给出证据：
1. `theme.layout.drawerSwipeEdgeWidth` 的具体数值与含义；
2. `expo-router/drawer` → `@react-navigation/drawer` / `react-native-drawer-layout` 在当前版本的手势实现（读 `node_modules` 源码行号）：激活条件（边缘宽度、`minSwipeDistance`、速度阈值）、与 `react-native-gesture-handler` 的关系；
3. 与**子页面手势**的冲突：新对话页/会话页里的 `FlatList`/`ScrollView`/输入框、`ApprovalFloat` 的拖拽、Stack 的 `slide_from_right` 返回手势；
4. 与 **Android 系统手势导航**（屏幕左右边缘的系统“返回”手势）的冲突——这是边缘滑动在 Android 上失效最常见的原因之一，若适用，给出**根治**路径（例如扩大激活区的正确做法，而不是堆魔法数字）；
5. `GestureHandlerRootView` 的装配位置是否正确；
6. 抽屉处于 `(main)` 分组内，主页面是 Drawer 的 screen 而非根 Stack——嵌套导航是否影响手势归属。

给出**最可能的根因排序及各自的验证实验**（真机怎么验证、看什么现象），并说明你的推荐依据。

### C. 层叠立体感的实现路线（设计 2–3 个完整方案并给推荐）

目标视觉：**主界面在上、抽屉在下；主界面右移（可伴随极轻缩放/圆角/视差），抽屉内容固定或轻微视差；无遮罩压暗。**
- 方案 1：`drawerType` 取 `'back'`/`'slide'` 等**内置能力**——读源码确认它们各自的真实表现（谁动、谁静、overlay 是否存在），能否达成目标，缺口在哪；
- 方案 2：基于 Reanimated 4 + Gesture Handler 的**自定义抽屉容器**（Worklet 驱动、跟手）——代价是什么、是否值得、能否做成单一抽象供未来其他侧滑面板复用；
- 方案 3：你认为有价值的第三条路径。
- 立体感**不允许靠描边**：只能靠主面板圆角（`theme.radius.*` token）、与抽屉的底色色阶差（`canvas` vs `surface*`）、位移/缩放。若你认为需要阴影才能成立，必须论证“为什么没有阴影无法成立”，并只使用 token 内已有阴影等级，**同时指出这与项目“默认不要重阴影”规范的关系，列入未决问题交用户裁决**。
- 必须覆盖：状态栏颜色与安全区、打开/关闭中途手势打断与回弹、Android 返回键、打开期间点击主界面区域收起、抽屉关闭后无残留遮罩/无命中区域泄漏、与 `ApprovalFloat` 层级、与 Stack 转场的衔接（与 N04 对接）。

### D. 版式重排（用户指令 + 你的设计）

用户要求：
- **顶部**：搜索框 + 扫一扫（现状在底部，输入法弹出后搜索框被挤没）；
- **底部**：头像 + 昵称，然后设置，然后新建对话按钮（用户原话“下面放置头像和名字，然后再是设置再是新建对话的那个按钮”，**顺序有歧义**：请给出推荐的单行/双行布局与备选，并标明歧义让用户裁决）；
- **通知铃铛**：现状在底部，新版没提到它的去向——给出方案并标为**待用户裁决**；
- 中间区域保留会话列表（今天/更早）与审批入口（现 `DrawerNav`）。

必须设计：
1. **软键盘行为**：顶部搜索获得焦点时，键盘出现是否会影响底部栏与列表？底部栏在键盘弹起时是否应隐藏/随动？给出明确规则（以 Android `adjustResize` 实际行为为准——核实 `app.json` 的相关配置）。
2. 搜索的结果态：无结果空态、清空、取消；搜索框与列表的滚动关系（吸顶？）。
3. 头像来源（账号头像 URL `auth.flowbit.me`）加载失败/未登录的占位（与 N05 的图标体系对接，不要自造一套）。
4. 全部尺寸/间距/圆角/色彩必须取自 theme token；列出需新增或修改的 token（`theme.layout.drawer*` 等）与被替换的硬编码。
5. 会话列表性能：当前 `DrawerSessionGroups` 是否 ScrollView 裸铺？是否应虚拟化？（第一轮 06 报告提到 `openSession` 未 `useCallback` 等，请**独立核实**并考虑 React Compiler 是否已覆盖。）
