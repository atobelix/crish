# 移动端全方位体检战役总纲与任务编排

> **战役工作区**：`docs/mobile-full-audit/`  
> **审计对象**：`apps/crish-mobile/`（Crish 移动端伴侣应用）  
> **纪律依据**：仓库根目录 `AGENTS.md`，执行通用协作纪律与反退避原则。

---

## 一、体检背景与前置发现

在首次实机（华为 P50）联调与全量门禁检查中，已初步暴露以下关键现实：
1. **类型门禁断裂**：`npm run typecheck` 抛出 9 处测试用例与 ViewModel 契约漂移错误（TS2554, TS2345, TS2322 等）。
2. **测试告警与安全缺口**：测试日志捕获到 `[PairingWiring] 桌面下发证书指纹格式非法（需 64 位 hex），放弃钉扎（缺口记录）`，表明证书指纹防中间人攻击钉扎在移动端与桌面端存在格式断层。
3. **路由结构违规**：Metro 抛出 `app/_components/accountNavigation.ts` 等非组件路由导出警告。
4. **网络体验与交互痛点**：跨国账号中心请求缺乏中间加载状态提示，首次连接海外服务易超时。

## 三、协作与纪律约束
- 子 Agent 均为只读探索类，**只输出各自分配的单份审计文档**，不擅自修改业务代码；
- 严禁空泛评论，所有缺陷必须标明具体的 `文件路径:行号`、代码断层与确凿证据；
- 完成后由主控 Agent 统一收口评审，并向用户汇报整体健康度与可执行修复路线。
