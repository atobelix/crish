在 PLAN-01 早期草案以及详案 04（AUDIT-FINAL-UI-TOKENS 缺陷 03）中，曾试图将整行声明为单一可点击的 `<button className={styles.fileRow}>`。交叉评审报告（REVIEW-01）与终审审计报告严肃指出了该设计的**致命架构断层与规范灾难（BUG-A01 / 缺陷 03）**：

## 3.3 32px 偶数净高与 Windows DirectWrite 基线防晃（BUG-V04 终极裁决落地）

### 3.3.1 Windows 渲染管线下 Segoe UI 与微软雅黑基线差病理
在 Windows 操作系统（DirectWrite 文本光栅化引擎）中：
- 西文字体（`Segoe UI`）与中文字体（`Microsoft YaHei`）的字体度量衡（Font Metrics）存在巨大偏差；
- 若声明 `align-items: baseline`，当路径中混杂英文和中文文件名时，整行文本的渲染基线会在 1.0px ~ 1.5px 之间上下剧烈浮动；
- 导致文本与左侧固定 16px 的状态徽标产生垂直视差错位，界面呈现“忽上忽下”的晃动感。

### 3.3.2 纠偏方案：垂直居中与固定行高
全面废除 `align-items: baseline`，统一强制锁定为 **`align-items: center`**，并显式锁定行高：
```css
.pathWrap {
  display: flex;
  align-items: center; /* 刚性居中对齐，根除基线漂移 */
  min-width: 0;
  flex: 1 1 auto;
  overflow: hidden;
  height: 100%;
}

.fileNameLinkBtn,
.dirPath {
  line-height: 20px; /* 显式固定行高 */
}
```

### 3.3.3 31px 奇数净高与亚像素抖动（Subpixel Jitter）数学推导
若采用传统 `border-bottom: 1px solid`：
$$H_{box} = 32\text{px} \implies H_{content} = 32\text{px} - 1\text{px} = \mathbf{31\text{px}} \quad (\text{奇数净高})$$
当垂直居中一个 16px 的徽标或 14px 的图标时：
$$\text{Top Margin} = \frac{31\text{px} - 16\text{px}}{2} = \mathbf{7.5\text{px}}$$
在 Windows 100% 或 125% DPI 缩放屏幕上，0.5 像素会导致 DirectWrite 在第 7 像素与第 8 像素之间产生抗锯齿跳跃（Subpixel Blurring），在列表滚动或 hover 高亮重绘时出现令人不适的细微虚化闪烁。

### 3.3.4 内嵌投影解决方案：维持 32px 纯偶数净高
采用 CSS `box-shadow` 内嵌投影实现 1px 底部分割线，使物理绘制区保持完整的 32px 纯偶数：
$$H_{content} = \mathbf{32\text{px}} \implies \text{Top Margin} = \frac{32\text{px} - 16\text{px}}{2} = \mathbf{8.0\text{px}} \quad (\text{纯整数，零亚像素模糊})$$
```css
.fileRow {
  display: flex;
  align-items: center;
  height: 32px;
  min-height: 32px;
  max-height: 32px;
  box-sizing: border-box;
  border: none;
  /* 使用内嵌阴影代替 border-bottom，使可用内容高度精确锁死在 32px 纯偶数 */
  box-shadow: inset 0 -1px 0 0 var(--border-subtle);
  border-radius: 0;
}
```

## 3.5 单一真理 Hover 层级（SLoHT）与 Design Tokens 刚性绑定（纠偏微观叠灰）

### 3.5.1 切断父级 Double-Hover 叠灰机制
现行实现之所以让用户感觉“有的地方很灰啊”，其根因是父级容器 `.accordionItem:hover`（2.5% 灰）与子级行 `.fileItem:hover`（2.5% 灰）发生了 Porter-Duff Over 物理叠加，叠出近 5% 的脏深灰。

- 外层 `.flatFileList`、`.groupSection`、`.fileNode` 严格保持 `background: transparent;`，绝不声明 `:hover` 背景；
- 唯有交互行 `.fileRow` 拥有唯一的悬停背景：`background-color: var(--bg-hover);`（浅色模式 2.5% 微透明灰，暗色模式 3.5%）；
- 激活态锁定：`background-color: var(--bg-active); box-shadow: inset 2px 0 0 var(--brand-primary, #10b981), inset 0 -1px 0 0 var(--border-subtle);`，无外部描边，零视觉冲突。

### 3.5.2 行内快捷按钮微观 SLoHT 防叠加守门（AUDIT-CONFLICT-DIFF §5.1 终审纠偏）
审计报告 AUDIT-CONFLICT-DIFF §5.1 与 AUDIT-FINAL-UI-TOKENS 缺陷 08 严肃指出：
- **微观毒点**：`.rowActBtn` 位于已经处于 `:hover` 状态的 `.fileRow` 内部（背景为 `--bg-hover`）。若快捷操作按钮自身在 `:hover` 时再赋予一层 `--bg-hover`，会产生微观上的二次叠加灰斑（叠灰量达 4.9%~6.8%），违背 SLoHT 单层悬停原则；

```tsx
/**
 * 拆分物理路径为文件名与所在目录
 * @param filePath 原始文件路径
 */
function splitFilePath(filePath: string): { name: string; dir: string } {
  if (!filePath) return { name: '', dir: '' };
  const normalized = filePath.replace(/\\/g, '/');
  const lastSlashIndex = normalized.lastIndexOf('/');
  if (lastSlashIndex === -1) {
    return { name: normalized, dir: '' };
  }
  return {
    name: normalized.slice(lastSlashIndex + 1),
    dir: normalized.slice(0, lastSlashIndex + 1),
  };
}

/**
 * 解析文件 Git 语义状态徽标属性
 * 区分 Modified(M), Added(A), Deleted(D), Renamed(R)
 * 契约收敛：tooltip 字段专供原子 Tooltip 组件消费，严禁暴露原生 title
 */
function resolveStatusBadge(f: FileDiff): {
  char: 'M' | 'A' | 'D' | 'R';
  key: 'mod' | 'add' | 'del' | 'ren';
  tooltip: string;
} {
  if (f.status === 'added' || (f.additions && !f.deletions && !f.oldPath)) {
    return { char: 'A', key: 'add', tooltip: '新增文件' };
  }
  if (f.status === 'deleted' || (!f.additions && f.deletions && !f.newPath)) {
    return { char: 'D', key: 'del', tooltip: '已删除文件' };
  }
  if (
    f.status === 'renamed' ||
    (Boolean(f.oldPath) && Boolean(f.newPath) && f.oldPath !== f.newPath)
  ) {
    return { char: 'R', key: 'ren', tooltip: '重命名文件' };
  }
  return { char: 'M', key: 'mod', tooltip: '已修改文件' };
}

// 快捷操作 Tooltip 文案常量 (遵循同源铁律：aria-label 与 Tooltip content 同源引用)
const TOOLTIP_STAGE = '暂存此文件';
const TOOLTIP_UNSTAGE = '取消暂存此文件';
const TOOLTIP_DISCARD = '放弃此文件的所有修改';

/**
 * 差异面板平直单轨文件列表组件
 * 彻底拔除卡片手风琴外壳、行内工具条，实现 32px 紧凑直角单轨

export const DiffCardFileList: React.FC<DiffCardFileListProps> = ({
  files,
  sourceMode,
  current,
  applyBusy,
  stagingPaths,
  onSetActiveDiffSource,
  onStageFile,
  onUnstageFile,
  onDiscardChanges,
  onStageAll,
  onUnstageAll,
  renderInlineDiffContent,
  getFileDiffData,
  onOpenFileViewer,
}) => {

  const { stagedFiles, unstagedFiles } = useMemo(() => {
    const staged: FileDiff[] = [];
    const unstaged: FileDiff[] = [];
    for (const f of files) {
      if (f.staged) {
        staged.push(f);
      } else {
        unstaged.push(f);
      }
    }
    return { stagedFiles: staged, unstagedFiles: unstaged };
  }, [files]);

  /**
   * 渲染单个平直文件节点（包含三大正交子域与嵌合比对区）
   */
  const renderFlatFileNode = (f: FileDiff) => {
    if (!f || !f.filePath) return null;
    const active = current?.filePath === f.filePath;
    const targetDiff = getFileDiffData ? (getFileDiffData(f) ?? f) : f;
    const additions = targetDiff.additions ?? f.additions ?? 0;
    const deletions = targetDiff.deletions ?? f.deletions ?? 0;
    const { name, dir } = splitFilePath(f.filePath);
    const badge = resolveStatusBadge(f);
    const isStaging = Boolean(stagingPaths[f.filePath]);

    return (
      <div
        key={f.filePath}
        className={styles.fileNode}
        role="listitem"
        data-active={active}
      >
        {/* 平直文件交互行 (32px 纯偶数净高，纯直角贴边容器，div 语义容器彻底杜绝 button 嵌套) */}
        <div
          className={`${styles.fileRow} ${active ? styles.isActive : ''}`}
          data-active={active}
          role="row"
        >
          {/* =================================================================
           * 子域 A：折叠展开控制与语义化状态徽章（原子 Tooltip 包裹）
           * ================================================================= */}
          <button
            type="button"
            className={styles.chevronBtn}
            onClick={() => onSetActiveDiffSource(active ? null : f)}
            aria-label={active ? `折叠 ${name} 差异代码` : `展开 ${name} 差异代码`}
            aria-expanded={active}
          >
            <Lucide.ChevronRight
              size={14}
              className={`${styles.chevronIcon} ${active ? styles.expanded : ''}`}
              aria-hidden
            />
          </button>

          <Tooltip content={badge.tooltip}>
            <span
              className={`${styles.statusBadge} ${styles[badge.key]}`}
              aria-label={badge.tooltip}
            >
              {badge.char}
            </span>
          </Tooltip>

          {/* =================================================================
           * 子域 B：独立超链接与路径分级 (点击在右侧打开独立预览 Tab，原子 Tooltip 包裹)
           * ================================================================= */}
          <div className={styles.pathWrap}>
            <Tooltip content={`在独立标签页打开差异：${f.filePath}`}>
              <button
                type="button"
                className={styles.fileNameLinkBtn}
                onClick={(e) => {
                  e.stopPropagation();
                  if (onOpenFileViewer) {
                    onOpenFileViewer(f.filePath);
                  } else {
                    onSetActiveDiffSource(active ? null : f);
                  }
                }}
                aria-label={`在独立标签页预览文件 ${name}`}
              >
                <span className={styles.fileName}>{name}</span>
              </button>
            </Tooltip>

            {dir ? (
              <Tooltip content={`文件所在目录：${dir}（点击折叠/展开）`}>
                <span
                  className={styles.dirPath}
                  onClick={() => onSetActiveDiffSource(active ? null : f)}
                >
                  {dir}
                </span>
              </Tooltip>
            ) : null}
          </div>

          {/* =================================================================
           * 子域 C：常驻增减统计与 Git 快捷操作 (物理隔离排布，Flex 盒流式并列，永不遮挡覆盖)
           * ================================================================= */}
          <div className={styles.statAndActions}>
            <span
              className={styles.fileStat}
              aria-label={`增加 ${additions} 行，删除 ${deletions} 行`}
            >
              {additions > 0 ? (
                <span className={styles.statAdd}>+{additions}</span>
              ) : null}
              {deletions > 0 ? (
                <span className={styles.statDel}>−{deletions}</span>
              ) : null}
              {additions === 0 && deletions === 0 ? (
                <span className={styles.statNeutral}>0</span>
              ) : null}
            </span>

            {sourceMode === 'git' ? (
              <div
                className={styles.rowActions}
                onClick={(e) => e.stopPropagation()}
              >
                {isStaging ? (
                  <Lucide.Loader2
                    size={13}
                    className={styles.spinner}
                    aria-label="正在处理暂存操作"
                  />
                ) : f.staged ? (
                  <Tooltip content={TOOLTIP_UNSTAGE}>
                    <Button
                      type="button"
                      variant="secondary"
                      size="sm"
                      className={styles.rowActBtn}
                      aria-label={TOOLTIP_UNSTAGE}
                      disabled={applyBusy}
                      onClick={() => void onUnstageFile(f.filePath)}
                      icon={<Lucide.Minus size={13} />}
                    />
                  </Tooltip>
                ) : (
                  <>
                    <Tooltip content={TOOLTIP_STAGE}>
                      <Button
                        type="button"
                        variant="secondary"
                        size="sm"
                        className={styles.rowActBtn}
                        aria-label={TOOLTIP_STAGE}
                        disabled={applyBusy}
                        onClick={() => void onStageFile(f.filePath)}
                        icon={<Lucide.Plus size={13} />}
                      />
                    </Tooltip>
                    <Tooltip content={TOOLTIP_DISCARD}>
                      <Button
                        type="button"
                        variant="danger"
                        size="sm"
                        className={`${styles.rowActBtn} ${styles.danger}`}
                        aria-label={TOOLTIP_DISCARD}
                        disabled={applyBusy}
                        onClick={() => void onDiscardChanges(f.filePath)}
                        icon={<Lucide.Undo2 size={13} />}
                      />
                    </Tooltip>
                  </>
                )}
              </div>
            ) : null}
          </div>
        </div>

        {/* 展开的代码比对视口（无缝垂直嵌合，零外框，零工具行） */}
        {active ? (
          <div className={styles.diffPane}>
            {renderInlineDiffContent(f)}
          </div>
        ) : null}
      </div>
    );
  };

  return (
    <div
      className={styles.flatFileList}
      role="list"
      aria-label="变更文件列表"
    >
      {sourceMode === 'git' ? (
        <>
          {/* 已暂存分组 */}
          <div className={styles.groupSection}>
            <div className={styles.groupHeader}>
              <span className={styles.groupTitle}>
                已暂存的更改 ({stagedFiles.length})
              </span>
              {stagedFiles.length > 0 ? (
                <Button
                  type="button"
                  variant="secondary"
                  size="sm"
                  className={styles.groupActionBtn}
                  disabled={applyBusy}
                  onClick={onUnstageAll}
                  icon={<Lucide.MinusCircle size={13} className={styles.btnIcon} />}
                >
                  全部取消暂存
                </Button>
              ) : null}
            </div>

            {stagedFiles.length === 0 ? (
              <div className={styles.groupEmptyHint}>无已暂存的文件</div>
            ) : (
              <div className={styles.groupBody}>
                {stagedFiles.map(renderFlatFileNode)}
              </div>
            )}
          </div>

          {/* 未暂存分组 */}
          <div className={styles.groupSection}>
            <div className={styles.groupHeader}>
              <span className={styles.groupTitle}>
                未暂存的更改 ({unstagedFiles.length})
              </span>
              {unstagedFiles.length > 0 ? (
                <Button
                  type="button"
                  variant="secondary"
                  size="sm"
                  className={styles.groupActionBtn}
                  disabled={applyBusy}
                  onClick={onStageAll}
                  icon={<Lucide.PlusCircle size={13} className={styles.btnIcon} />}
                >
                  全部暂存
                </Button>
              ) : null}
            </div>

            {unstagedFiles.length === 0 ? (
              <div className={styles.groupEmptyHint}>无未暂存的修改</div>
            ) : (
              <div className={styles.groupBody}>
                {unstagedFiles.map(renderFlatFileNode)}
              </div>
            )}
          </div>
        </>
      ) : (
        files.map(renderFlatFileNode)
      )}
    </div>
  );
};
```
