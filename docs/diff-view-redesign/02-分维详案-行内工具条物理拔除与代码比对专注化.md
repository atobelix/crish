## 1.2 冗余对比维度下拉（Select）病态与微观认知分裂

### 1. 病态本质：与顶层全局维度发生严重双轨冲突
在差异面板顶层 [`DiffHeaderControls.tsx`](file:///c:/Software/conex/apps/crish-desktop/src/components/diff/DiffHeaderControls.tsx) 中，系统已经提供了一个全局权威的维度选择器（统一在 Git 工作区、全会话累计与各 AI 轮次之间切换）。然而在每个展开文件的行内顶部，又硬塞入了一个单文件维度的 `<Select>` 下拉框：
- **认知分裂**：用户不知道当前看到的代码比对是受顶层下拉控制，还是受展开项行内的下拉控制；
- **计算负担**：每次渲染展开项，组件都必须调用 `compareOptions.map(...)` 重新计算选项并生成新对象，带来了严重的内存分配与 V8 垃圾回收抖动；
- **视口浪费**：这一工具条死锁了 36px 垂直高度，加上外层 padding，硬生生削减了代码可读区域近 20% 的高度。

## 1.3 六大功能按钮与装饰分割线逐一解构与职能错位

行内工具条右侧硬塞了 6 个微型图标按钮，职责严重错位且脱离主线：

| 按钮标识 | 原始功能 | 缺陷定性 | 终审定稿处置与归宿 |

## 1.4 Git 模式下的破坏性伪实现剖析（破坏源码与前端欺骗）

行内工具条不仅造成严重的视口浪费与视觉分裂，其承载的两个行内数据流操作在 Git 模式下（`sourceMode === 'git'`）更是具备严重的破坏性与欺骗性：

### 1. `acceptCurrentFile`（接受补丁）——破坏工作区磁盘源码的高危假实现
- **病理本质**：在 Git 工作区模式下，用户所见到的所有变更文件，其内容**早在用户使用编辑器修改或工具写入时就已经物理存在于磁盘上**。
- **破坏机理**：此时如果用户点击展开项行内的“接受并写入磁盘”按钮（`onAcceptFile`），底层实现 [`DiffCardHandlers.ts:17-49`](file:///c:/Software/conex/apps/crish-desktop/src/components/diff/DiffCardHandlers.ts#L17-L49) 会再次调用 `applyFileDiffToDisk(f)`。该函数会以字符串重放或 AST patch 的方式强行向已经包含该改动的物理文件重放 diff patch！
- **灾难后果**：这直接引发**二次拼接与重复补丁**，造成函数块被双重复制、缩进混乱甚至严重的语法错误，直接破坏用户的合法工作区源码！在审查报告（AUDIT-02 与 AUDIT-FEASIBILITY-GROUNDING-04）中，该行为被定性为最高危的前端误操作隐患，必须从根源上连根铲除。代码比对面板的职责是“比对审查与 Git 暂存”，磁盘写入工作早已完成，绝不应提供任何二次覆写按钮。

### 2. `rejectCurrentFile`（拒绝文件）——前端数组过滤掩耳盗铃的欺骗性伪连通
- **病理本质**：行内提供的“从列表拒绝（不回滚磁盘）”按钮（`onRejectFile`），在底层仅仅执行了 `rejectCurrentFileImpl`：
  ```typescript
  // DiffCardHandlers.ts:54-59
  export function rejectCurrentFile(f: FileDiff, removeDiffFile: (filePath: string) => void): void {
    removeDiffFile(f.filePath);
  }
  ```
- **欺骗机理**：该函数仅仅是调用了 Zustand 的 `removeDiffFile`，从前端内存状态树的 `diffFiles` 数组中将该文件记录 filter 过滤掉，而在操作系统的磁盘工作区中，该文件的代码修改**分毫未动、完全未被撤销**！
- **死灰复燃**：由于磁盘物理文件未变，只要用户稍后切换一次顶栏标签页、切换一下会话、触发文件系统 Watcher 或按下 F5 重新加载，该文件立刻在差异面板中**原地复活、再次出现**！这种完全脱离真实 Git 状态机的“前端单机滤除”，既无法还原文件，又给用户造成了“修改已丢弃”的致命认知错觉。
- **终审定稿裁决**：彻底拔除 `acceptCurrentFile` 与 `rejectCurrentFile`！在 Git 模式下，针对变更的唯一合法流转是正交子域 C 的 **“暂存文件（Stage）”** 与带有确认保护的 **“放弃修改（Discard Changes via Git Checkout/Restore）”**。

function splitFilePath(filePath: string): { name: string; dir: string } {
  if (!filePath) return { name: '', dir: '' };
  const normalized = filePath.replace(/\\/g, '/');
  const lastSlashIndex = normalized.lastIndexOf('/');
  if (lastSlashIndex === -1) {
    return { name: normalized, dir: '' };
  }
  return {
    name: normalized.slice(lastSlashIndex + 1),
    dir: normalized.slice(0, lastSlashIndex + 1),
  };
}

 */
function resolveStatusBadge(f: FileDiff): {
  char: 'M' | 'A' | 'D' | 'R';
  key: 'mod' | 'add' | 'del' | 'ren';
  tooltip: string;
} {
  if (f.status === 'added' || (f.additions && !f.deletions && !f.oldPath)) {
    return { char: 'A', key: 'add', tooltip: '新增文件' };
  }
  if (f.status === 'deleted' || (!f.additions && f.deletions && !f.newPath)) {
    return { char: 'D', key: 'del', tooltip: '已删除文件' };
  }
  if (
    f.status === 'renamed' ||
    (Boolean(f.oldPath) && Boolean(f.newPath) && f.oldPath !== f.newPath)
  ) {
    return { char: 'R', key: 'ren', tooltip: '重命名文件' };

  return { char: 'M', key: 'mod', tooltip: '已修改文件' };

export interface DiffCardProps {
  className?: string;
}

const DiffCardInner: React.FC<DiffCardProps> = () => {
  const { showToast } = useToast();
  const activeDiffSource = useTerminalField(selectActiveDiffSource);
  const diffFiles = useTerminalField(selectDiffFiles) as FileDiff[];
  const setActiveDiffSource = useTerminalField((s) => s.setActiveDiffSource);
  const setDiffFiles = useTerminalField((s) => s.setDiffFiles);
  const session = useSessionField(selectActiveSession);

  const [diffViewMode, setDiffViewMode] = useState<'unified' | 'split'>('unified');
  const [rawDiffSearchQuery, setDiffSearchQuery] = useState('');
  const diffSearchQuery = useDeferredValue(rawDiffSearchQuery);
  const searchActive = !!rawDiffSearchQuery.trim();
  const [searchOpen, setSearchOpen] = useState(false);
  const [applyBusy] = useState(false);
  const [sourceMode, setSourceMode] = useState<DiffSourceMode>('list');
  const [turnKey, setTurnKey] = useState('');
  const [panelErr, setPanelErr] = useState('');
  const [_softHint, setSoftHint] = useState('');
  const [commitPanelOpen, setCommitPanelOpen] = useState(false);

  const {
    aiTurns,
    hasAiTurns,
    mergedSessionFiles,
    fileList,
    computedChangesByFile,
    turnOptions,
    plainLoading,
    plainFileContents,
    getFileCompareMode,
    getFileDiffData,
    handleExpandBlock,
    unifiedRenderCache,
    splitRenderCache,
    stagedCount,
    unstagedCount,
  } = useDiffData({
    session: session ?? null,
    diffFiles,
    activeDiffSource,
    diffSearchQuery,
    diffViewMode,
    sourceMode,
  });

  const showSoftHint = useCallback((message: string) => {
    const m = (message || '').trim();
    if (m) {
      setPanelErr('');
      setSoftHint(m);
    }
  }, []);

  const toastFail = useCallback((msg: string) => {
    showToast(msg);
  }, [showToast]);

  const {
    commitMsg,
    setCommitMsg,
    committing,
    stagingPaths,
    gitStatusAvailable,
    handleStageFile,
    handleUnstageFile,
    handleStageAll,
    handleUnstageAll,
    handleCommit,
    handleDiscardChanges,
    handleRefreshGit,
    confirmGateView,
  } = useDiffGitActions({
    diffFiles,
    setDiffFiles,
    activeDiffSource,
    setActiveDiffSource,
    setPanelErr,
    showSoftHint,
    toastFail,
    stagedCount,
  });

  const handleCopyAllPatch = async () => {
    const publishable = filterPublishableDiffs(fileList);
    if (!publishable.length) {
      showToast('当前没有可复制的变更');
      return;
    }
    const patches = publishable.map((f) => formatGitPatch(getFileDiffData(f) ?? f));
    await navigator.clipboard.writeText(patches.join('\n\n'));
    showToast(`已复制 ${publishable.length} 个文件的 Patch`);
  };

  const handleOpenFileViewer = useCallback((filePath: string) => {
    openFileViewerInSession(filePath, 'diff');
  }, []);

  const renderInlineDiffContent = useCallback(
    (f: FileDiff) => {
      const mode = getFileCompareMode(f.filePath);
      const targetDiff = getFileDiffData(f) ?? f;
      const fileKey = f.filePath;
      const uItems = unifiedRenderCache[fileKey] ?? [];
      const sItems = splitRenderCache[fileKey] ?? [];
      const computed = computedChangesByFile[fileKey] ?? [];

      return (
        <DiffCodeViewer
          f={targetDiff}
          compareMode={mode}
          diffViewMode={diffViewMode}
          diffSearchQuery={diffSearchQuery}
          plainLoading={plainLoading}
          plainContent={plainFileContents[f.filePath]}
          unifiedRenderItems={uItems}
          splitRenderItems={sItems}
          computed={computed}
          onExpandBlock={handleExpandBlock}
        />
      );
    },
    [
      getFileCompareMode,
      getFileDiffData,
      unifiedRenderCache,
      splitRenderCache,
      computedChangesByFile,
      diffViewMode,
      diffSearchQuery,
      plainLoading,
      plainFileContents,
      handleExpandBlock,
    ]
  );

  return (
    <div className={styles.container}>
      <DiffHeaderControls
        sourceMode={sourceMode}
        setSourceMode={setSourceMode}
        turnKey={turnKey}
        setTurnKey={setTurnKey}
        turnOptions={turnOptions}
        hasAiTurns={hasAiTurns}
        diffViewMode={diffViewMode}
        setDiffViewMode={setDiffViewMode}
        searchOpen={searchOpen}
        setSearchOpen={setSearchOpen}
        searchActive={searchActive}
        diffSearchQuery={rawDiffSearchQuery}
        setDiffSearchQuery={setDiffSearchQuery}
        onCopyAllPatch={handleCopyAllPatch}
        onRefreshGit={handleRefreshGit}
        gitStatusAvailable={gitStatusAvailable}
      />

      {panelErr ? (
        <div className={styles.panelErrBanner} role="alert">
          <span className={styles.panelErrText}>{panelErr}</span>
          <Button
            type="button"
            variant="ghost"
            size="sm"
            className={styles.panelErrDismiss}
            onClick={() => setPanelErr('')}
            aria-label="关闭提示"
            icon={<Lucide.X size={12} />}
          />
        </div>
      ) : null}

      <div className={styles.bodyWrap}>
        {fileList.length === 0 ? (
          <div className={styles.empty}>
            <div>暂无文件变更</div>
            <div className={styles.emptySub}>
              {sourceMode === 'git'
                ? '工作区干净，无未暂存或暂存改动'
                : '当前会话没有产生代码修改'}
            </div>
          </div>
        ) : (
          <DiffCardFileList
            files={fileList}
            sourceMode={sourceMode}
            current={activeDiffSource}
            applyBusy={applyBusy}
            stagingPaths={stagingPaths}
            onSetActiveDiffSource={setActiveDiffSource}
            onStageFile={handleStageFile}
            onUnstageFile={handleUnstageFile}
            onDiscardChanges={handleDiscardChanges}
            onStageAll={handleStageAll}
            onUnstageAll={handleUnstageAll}
            renderInlineDiffContent={renderInlineDiffContent}
            getFileDiffData={getFileDiffData}
            onOpenFileViewer={handleOpenFileViewer}
          />
        )}
      </div>

      {sourceMode === 'git' ? (
        <DiffCardGitActions
          stagedCount={stagedCount}
          unstagedCount={unstagedCount}
          commitMsg={commitMsg}
          setCommitMsg={setCommitMsg}
          committing={committing}
          commitPanelOpen={commitPanelOpen}
          setCommitPanelOpen={setCommitPanelOpen}
          onCommit={handleCommit}
          onStageAll={handleStageAll}
          onUnstageAll={handleUnstageAll}
        />
      ) : null}

      {confirmGateView}
    </div>
  );
};

export const DiffCard: React.FC<DiffCardProps> = (props) => {
  return <DiffCardInner {...props} />;
};
