## 四、冒烟面（最小实现，未接会话栈）

`app/dev-ondevice-smoke.tsx`：仓内无现成 dev/调试入口，按简报做**不进正式导航的隐藏路由**（无任何链接指向，仅可路由直达 `/dev-ondevice-smoke`）。功能仅四件：

1. 查模型文件在位状态（`documentDirectory + crish-llm-models/qwen2.5-1.5b-instruct-q4_k_m.gguf`，与 O2 目录口径一致）；
2. 「选择模型文件」：DocumentPicker 选已侧载到共享存储的 GGUF → 复制进上述应用文档目录（release 包不可 run-as 直推内部存储，故走选择器复制，这是简报「选已侧载模型文件」的落地形态）；
3. 「加载模型」：`initLlama({ model: toNativeFilePath(...), n_ctx: 4096, n_gpu_layers: 0, use_mlock: true })`，显示加载毫秒数与 `context.reasonNoGPU` 原值（路径剥 scheme 沿 ASR `toNativeFilePath`，复用其真机定根因的纪律）；
4. 流式生成：一句提示词（可改）→ `completion` 逐 token 回调追加显示，结束显示总耗时、首 token 延迟、回调 token 数与原生 `timings`（predicted_n / decode tok/s / prompt_n / prefill tok/s）；「停止」调 `stopCompletion()`。
