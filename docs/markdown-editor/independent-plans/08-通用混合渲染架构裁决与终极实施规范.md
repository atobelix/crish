两位独立架构师在完全隔离、未阅读历史文档的条件下，均从 CSS IFC 第一性原理与现代编辑器（CodeMirror 6 / Typora）架构出发，给出了高度一致、数学级严谨的通用解决方案。

| **简答题 1：行盒高度恒等（$\Delta H \equiv 0$）** | 清退基线偏移与 `transform`；使用 `line-height: 0` 容器隔离行内 Widget；`inline-flex` + 28px 网格高度对齐。 | 全面清退 `vertical-align`；建立统一 `inline-widget-container`（`inline-flex` + `align-items: center` + `line-height: 0`）；上下标与脚注 `line-height: 0; position: relative` 隔离。 | **完全采纳共识**：<br>1. 全面清退 `vertical-align: sub/super` 与硬编码 `transform: translateY(-1px)`；<br>2. 全体行内组件统一采用 `display: inline-flex; height: var(--grid-size); line-height: 0; align-items: center;`；<br>3. 上下标与脚注通过 `line-height: 0; position: relative; top/bottom` 隔离，从物理上保证**单行高度永久恒等于 28px（$\Delta H \equiv 0$）**。 |
| **简答题 2：等宽槽位守恒与幽灵字符流（$\Delta X \equiv 0$）** | 彻底废除 `display: none`，采用 `visibility: hidden; opacity: 0` 的幽灵字符流；Widget 宽度通过 `ch` 绑定源码字符数；保持 DOM 合法物理坐标，消除 0x0 异常。 | 彻底废除 `display: none`；建立 `slot-container`（`width: 6ch; position: relative`），视觉 Widget 绝对居中悬浮（Overlay Pattern），底层幽灵流保留占位；Range 测量永远有效。 | **采纳综合优选方案**：<br>1. 彻底废除 `display: none`；<br>2. 采用**底层幽灵字符流（Ghost Stream）+ 上层 Widget 悬浮对齐（Overlay / Slot Invariance）**；<br>3. 槽位宽度严格等于源码字符数 $N \times 1\text{ch}$（任务项 4ch 或 6ch），消除 14.5px/35.4px 横移（$\Delta X \equiv 0$）；<br>4. 源码字符保留物理几何坐标，Range 测量**永远能获取合法物理矩形，彻底消灭 0x0 失效**。 |

### 2. 测量系统双层投影管道 (`src/core/measure.ts`)
- **根除 0x0 盲测与行首退化**：
  ```typescript
  export function measureTokenExact(
    entry: TokenEntry,
    offsetInToken: number
  ): MeasuredRect | null {
    // Tier 1: 纯文本真实 Range 实测
    const located = locateTextNode(entry, offsetInToken);
    let rect: DOMRect | null = null;
    if (located) {
      const range = getSharedRange();
      try {
        range.setStart(located.textNode, located.localOffset);
        range.setEnd(located.textNode, located.localOffset);
        const r = range.getBoundingClientRect();
        if (r.height !== 0 || r.width !== 0) rect = r;
      } catch {}
    }

    // Tier 2: 复合 Widget 盒模型比例线性插值投影（绝不跌入行首退化）
    if (!rect) {
      const er = entry.el.getBoundingClientRect();
      const ratio = offsetInToken / Math.max(1, entry.length);
      const fontSize = tokenFontSize(entry.el);
      const cursorHeight = fontSize * 1.15;
      return {
        left: er.left + ratio * er.width,
        top: er.top + (er.height - cursorHeight) / 2,
        height: cursorHeight,
        bottom: er.top + (er.height + cursorHeight) / 2,
      };
    }

    const fontSize = tokenFontSize(entry.el);
    const cursorHeight = fontSize * 1.15;
    return {
      top: rect.top + (rect.height - cursorHeight) / 2,
      left: rect.left,
      height: cursorHeight,
      bottom: rect.bottom ?? rect.top + rect.height,
    };
  }
  ```

### 3. 输入层剥离抢拉滚动 (`src/components/HiddenInput.tsx`)
- **彻底删除 804-810 行抢写 `scrollTop` 的代码**：
  将视口跟随完全交由 `Virtualizer` 的稳定锚定机制或专用的 `scrollIntoViewIfNeeded` 统一调度，严禁在组件内部机械直接改写 `scrollTop = top - 40`。

### 4. 行高预测模型与自平衡回填 (`src/core/HeightMap.ts`)
- **标题倍率归一**：`TYPE_MULTIPLIER['heading'] = 1.0`；
- **公式特征模型**：针对独立公式块（`$$`），扫描内部行数预留高度：
  $$\text{Height} = \max(28, \text{lines} \times 40\text{px})$$
- **视口滚动平滑锚定**：挂载回填时，若更新发生在当前视口首行之前，通过 `container.scrollBy(0, deltaH)` 补偿位移，使当前视口阅读内容绝对静止。
