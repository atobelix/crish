### 1.3 静默 chrome

默认应当 **几乎看不见外壳**，只看见内容。

| 对象 | 默认（L0） | 交互 | 禁止 |
| --- | --- | --- | --- |

| 焦点 | 纸面本地 6%（`--np-focus-*`）；壳控件常规 **≤10%**，优先 6% | `AGENTS.md` §13 | `--focus-ring-strong`；`0 0 0 1px var(--text-primary)`；暗色全局 30% 外环当块环 |

### 1.4 hairline

已对齐、不要回退：

UnitChrome 现分隔条用 `--border-subtle`（`UnitChromeActions.module.css:27`）。token 上 `--hairline: var(--border-subtle)`，值同族。若 02 改这块，**改写成 `--hairline`**，不要另起色。
