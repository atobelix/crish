## 0. 一句话与诚实边界

**一句话**：打开笔记只允许 **1 条活路径**（扩展 `registerView('note')` + `openToolInSession(..., 'note')` / `setActiveTab`）；`Workspace` / Canvas / Host / `open-note-paper-strict` / 整份旧壳 CSS / `setChatMainSurface('note')` / 已删插件轨 **都不是**产品入口。有价值的策略测、resolver 测、真壳片 **不是**死层继续活着的理由——测要改挂新宿主，或列入陪葬清单交主控确认后再删。

**本维做什么**：列清单、定删/暂留、点名测、写验收与文件域。
**本维不做什么**：不删代码、不改 spec、不关 EL、不把「测还绿」写成「入口还活」。

**诚实**：

- 做了：按现码把用户点名四簇 + 同簇孤儿 chrome 逐条钉到 `路径:行号`；每条写清删 / 暂留+谁引用 / 测是否陪葬。
- 做到什么程度：静态源码形状 + git 对象（`d00fbaaf` / `96d1df60` / `25762dc1`）可复核。
- 没做：未跑 `tsc` / vitest / cargo / 9222；未打开 `00-现码核验.md`（文件当时不在）。`Workspace.tsx` 对现行 `LayoutStore` 的类型断裂是 **源码对照推断**（见 D1），不是本会话编译器输出。
