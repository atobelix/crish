## 0. 结论先行

### 0.1 总判

相对 `audit/2026-08-13-launch-gap/03` 与 `post-sd50-53-wave/06`：**换代回退（产品树），库/测形状持平**。

- 旧账把 B/C/D/E/G 标「已通」，是因为产品默认走 `Workspace.tsx` → `WorkspaceProductEmptyHost` → `WorkspaceEmptyState` → 点 `open-note-paper-strict` → `NotePaperStrictPanel`。
- 2026-08-18 产品主壳是 `App.tsx` → `BinaryTreeWorkspace` → `TreeLeafPanel` → `SlotOutlet('workspace.leaf.panel')` + `viewRegistry`。内置 **11** 视图，**没有 `note`**。`Workspace` / Host / EmptyState **不在产品树**。
- 因此：jsdom 里 Host 仍能把 C2′ / E2′ 测绿 ≠ 用户打得开纸面。审计 `03` 的总判成立：**库/测大多仍通；产品默认七链从 A 起不可达**。

本维不发明第二套插件运行时，不重写 hydrate / apply / detect / 总线。只换**谁当产品宿主**。

## 5. 产品默装跟到扩展叶（本维核心设计）

### 5.1 原则

1. **策略文件是源，工厂是槽。** C2′ / E2′ 的 `= true as const` 留在原文件。扩展工厂 **import 常量**，禁止复制一个 `NOTE_LEAF_ENABLE_PAPER_LIST = true`。
2. **组件默认继续关。** EmptyState / 未来任何「裸面板」默认仍 false。只有**产品宿主**显式打开。换代后产品宿主 = 扩展工厂，不再是 Host。
3. **总线不动。** G2 已在 adapt；叶只要挂上 Strict 就通。不要在工厂里再 notify 一次（双刷）。
4. **一个组装函数，七链一次挂齐。** 禁止 02 先交「空壳 note 叶」、07 再补默装——那是新的半连通撒谎。
5. **卸扩展 = 默装一起卸。** 注销后不得残留 detect timer / 总线 listener（listener 随面板 unmount；timer 须 `onDispose` 或 hook 清理）。

## 12. 实现备忘（给 02，不是本轮代码）

叶工厂逻辑序（单函数内，避免半挂）：

```
1. 从 ctx 解析 docId（H1 优先级；禁止默认 sessionId）

6. mirrorProps = resolveWorkspaceProductEmptyMirrorProps()

     enabled: WORKSPACE_PRODUCT_ENABLE_MIRROR_DETECT_SCHEDULE,
     docId,
     ipc: mirrorProps.mirrorIpc,
   })

     docId
```
