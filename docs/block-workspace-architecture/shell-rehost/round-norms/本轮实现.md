# 本轮实现通用规范（01 + 02）

- 三原则：诚实、必做禁做、负责。
- 子 Agent **不** git 提交、不回撤、不 `--no-verify`。
- **≠ 关 EL**；不去 `-S`；不改 `EL-dashboard` 表 A。
- 笔记是扩展：禁止把 `note` 写进 `registerBuiltInViews` / 「12 个内置」。
- 禁止复活 `src/plugins`、`ContributeViewRegistry`、整份旧壳 CSS。
- 禁止改未提交的 frontend-convergence / Tooltip / 红队工作区。

- 写文件 UTF-8 无 BOM；中文注释只解释非显然约束。
