## 1. 产品要做成什么

1. 主区是二叉树工作区，叶子高度 > 0。
2. 笔记以 **扩展激活** 挂上：调用已有 `viewRegistry.registerView`（可注销），叶子里渲染 Strict 纸面。
3. 卸扩展 = 注销视图 + 叶子不再出现笔记。内核 11 个内置视图名单 **不** 把 `note` 写死成第 12 个「内置」。
4. 纸面实现继续待在可拆包（契约 / editor-kit / block-paper）；桌面只做宿主与打开。
5. 打开完成（真 WebView + tauri-ipc + doc-session + 已 persist 非 fixture）是下一刀，不是本实现轮关账。

## 2. 主控已锁的设计（不必再争论）

这些来自本会话已读过的现码 + 用户当面口径。细证据、行号、遗漏由 `00-现码核验` 与分维补，主控不再通读仓库。

| 锁 | 口径 |
| --- | --- |
| 主壳 | `App` → `BinaryTreeWorkspace` → `TreeLeafPanel` → `SlotOutlet('workspace.leaf.panel')` |
| 内置视图 | `chat` / `terminal` / `preview` / `overview` / `files` / `diff` / `runtime` / `agent` / `browser` / `flow-dag` / `file-viewer`。这是内核。 |
| 插拔面 | `viewRegistry.registerView` 返回注销函数，并自动挂 keyed 槽。扩展走这条，**禁止**再造第二套插件运行时（旧 `src/plugins` / `ContributeViewRegistry` 已删，禁止复活） |
| 打开命令 | 活路径只有 `openToolInSession` / `setActiveTab`。`setChatMainSurface('note')` 不是合法 API |
| 死路径 | `Workspace` / Host / `open-note-paper-strict` **不是**产品入口 |
| 高度 | `#root` / `.app-container` / `.main-layout` / `.workspaces-*` 现码零规则；要补骨架，不糊回 1.4 万行皮 |
| 纸面库 | `NotePaperStrictPanel` 必填 `docId` + `hydrateTransport`；工厂与 H1 resolver 仍在，喂源改到扩展视图，不喂死 Host |
