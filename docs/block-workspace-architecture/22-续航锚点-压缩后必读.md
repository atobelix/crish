## 4. 多 Agent 轮次模型（用户 2026-08-11 钉死）

| 层                               | 名额                | 说明                                                                            |
| -------------------------------- | ------------------- | ------------------------------------------------------------------------------- |
| **审计 Agent**                   | 每轮 **1**（固定）  | 审上轮落实 → 审历史落实 → 落盘分析 + **追加下一阶段执行计划**（`audit/*/04-…`） |
| **执行 Agent**                   | **独立上限 6**      | **与审计名额无关**；按计划与文件域派 1–6，**不打满也正常**                      |
| **审计方案执行**（后续轮可启用） | 计入**执行层** 6 内 | 专消化审计红/黄项补洞；可与常规前进包并行（不同文件域）                         |

**统一轮次形态**：

1. **基础轮**：`审计 Agent` + `执行 Agent×N`（N≤6）
2. **加强轮**：`审计 Agent` + `审计方案执行 Agent×K` + `前进执行 Agent×M`（K+M≤6）

**禁止**：把 6 理解成「含审计的总人数」；禁止无审计计划就瞎派前进包；禁止执行层为凑数打满。
