## H1 · yrs 全量内存 vs undo（**已钉死**）

### 裁决（合成，非二选一砍效果）

| 项                       | 锁定                                                                                                                                                                        |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **文本引擎默认**         | 仍为 **yrs**（叶子文本）；**不**因 H1 立即切 Loro 全量                                                                                                                      |
| **热集（Hot set）**      | 仅窗口内 + pin（焦点/composing）+ 近编辑 LRU 的块持有 **活动 YText**                                                                                                        |
| **冷藏（Cold）**         | 结构节点仍在 RS 树；叶子文本 **卸载 YText**，保留 `text_snapshot: Arc<str>`（或等价不可变快照）供只读/搜索投影                                                              |
| **冷块可撤销性**         | **受限 undo**：冷块上的文本历史 **不保证** 细粒度 yrs UndoManager 栈；undo 越过冷边界时 → **先 rehydrate 快照再应用结构 undo**，细粒度击键历史可丢（产品须在设置/文档声明） |
| **远端 update 合入冷块** | 必须 **先 rehydrate 或 apply 到快照再编码**；**禁止** 对已卸载 YText 静默丢 update；合入后可按 LRU 再冷藏                                                                   |
| **EL-03**                | 大文档内存上界以 **热集大小** 约束，非「全库 YText 常驻」                                                                                                                   |
| **逃生门**               | Wave 0 起建立 **Loro 文本/树 对照属性测试 harness**（dev）；A-SWAP 触发条件满足前 **不** 切主路径                                                                           |

### 验收钉（新增）

| ID       | 断言                                                                       |
| -------- | -------------------------------------------------------------------------- |
| A-MEM-01 | 10 万块打开后，活动 YText 实例数 ≤ 窗口+pin+LRU 上界（可配置，默认 ≤ 512） |
| A-MEM-02 | 冷块 text 仍可读（快照）；搜索/投影不依赖热 YText                          |
| A-MEM-03 | 远端 update 指向冷块：不丢；最终与双端一致                                 |
| A-MEM-04 | undo 跨冷边界：结构正确；细粒度文本历史允许截断（契约测文档化）            |

## H2 · 混合壳跨引擎一致性（**已钉死 → A-INV-09**）

写锥不仅锁入口，还锁 **跨引擎事务语义**：

| ID            | 断言                                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------------------- |
| **A-INV-09a** | 同一 `Transaction` 内树 Op 与文本 edit **同批提交或同批回滚**（无「树成文本败」半提交）                       |
| **A-INV-09b** | checkpoint / snapshot tick **同源**：一次 commit 的 `CommitBatch` 含结构 rev + 文本 update 集合的同一 `tx_id` |
| **A-INV-09c** | 块删除 → 叶子 YText/快照 **同步释放**；无孤儿文本引擎；undo 恢复块时文本可恢复（热路径完整，冷路径按快照）    |

实现：`DocSession::apply` 内 `StructureEngine` 与 `TextEngine` 共享 `TxGuard`；测试 W0/W1 骨架即红。

## M1 · 树并发合并语义（**规则先于实现**）

### 并发 move 规则（初版，Wave 0 钉死用例）

1. 每块有 `parent_id` + `fractional_index`（或等价 order）
2. 并发 move 同父：按 `(Lamport, peer)` 全序解析 order，**最终无环**
3. 并发 move 使 A 成为 B 子孙且 B 成为 A 子孙： **优先保留较高 Lamport 的边，另一边落到原父或根兜底**（属性测固定）
4. 删除 vs move：删胜（目标不存在则 move no-op 并记审计）
5. 跨块粘贴：生成 **新 BlockId**；文本 deep copy 快照；不共享 YText 句柄

### Loro 对照

- W0 包 **W0-L**：Loro movable tree + 文本 属性测试，**对照 oracle**（非生产依赖）
- 主路径仍自研树；对照失败 → 修自研规则，不默默切 Loro 除非 A-SWAP
