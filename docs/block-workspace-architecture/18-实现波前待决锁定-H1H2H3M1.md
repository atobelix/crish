## H1 · yrs 全量内存 vs undo（**已钉死**）

### 裁决（合成，非二选一砍效果）

| 项                       | 锁定                                                                                                                                                                        |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **文本引擎默认**         | 仍为 **yrs**（叶子文本）；**不**因 H1 立即切 Loro 全量                                                                                                                      |
| **热集（Hot set）**      | 仅窗口内 + pin（焦点/composing）+ 近编辑 LRU 的块持有 **活动 YText**                                                                                                        |
| **冷藏（Cold）**         | 结构节点仍在 RS 树；叶子文本 **卸载 YText**，保留 `text_snapshot: Arc<str>`（或等价不可变快照）供只读/搜索投影                                                              |
| **冷块可撤销性**         | **受限 undo**：冷块上的文本历史 **不保证** 细粒度 yrs UndoManager 栈；undo 越过冷边界时 → **先 rehydrate 快照再应用结构 undo**，细粒度击键历史可丢（产品须在设置/文档声明） |
| **远端 update 合入冷块** | 必须 **先 rehydrate 或 apply 到快照再编码**；**禁止** 对已卸载 YText 静默丢 update；合入后可按 LRU 再冷藏                                                                   |
| **EL-03**                | 大文档内存上界以 **热集大小** 约束，非「全库 YText 常驻」                                                                                                                   |
| **逃生门**               | Wave 0 起建立 **Loro 文本/树 对照属性测试 harness**（dev）；A-SWAP 触发条件满足前 **不** 切主路径                                                                           |

## H2 · 混合壳跨引擎一致性（**已钉死 → A-INV-09**）

写锥不仅锁入口，还锁 **跨引擎事务语义**：

| ID            | 断言                                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------------------- |
| **A-INV-09a** | 同一 `Transaction` 内树 Op 与文本 edit **同批提交或同批回滚**（无「树成文本败」半提交）                       |
| **A-INV-09b** | checkpoint / snapshot tick **同源**：一次 commit 的 `CommitBatch` 含结构 rev + 文本 update 集合的同一 `tx_id` |
| **A-INV-09c** | 块删除 → 叶子 YText/快照 **同步释放**；无孤儿文本引擎；undo 恢复块时文本可恢复（热路径完整，冷路径按快照）    |

实现：`DocSession::apply` 内 `StructureEngine` 与 `TextEngine` 共享 `TxGuard`；测试 W0/W1 骨架即红。

## M1 · 树并发合并语义（**规则先于实现**）

### 并发 move 规则（初版，Wave 0 钉死用例）

1. 每块有 `parent_id` + `fractional_index`（或等价 order）
2. 并发 move 同父：按 `(Lamport, peer)` 全序解析 order，**最终无环**
3. 并发 move 使 A 成为 B 子孙且 B 成为 A 子孙： **优先保留较高 Lamport 的边，另一边落到原父或根兜底**（属性测固定）
4. 删除 vs move：删胜（目标不存在则 move no-op 并记审计）
5. 跨块粘贴：生成 **新 BlockId**；文本 deep copy 快照；不共享 YText 句柄

### Loro 对照

- W0 包 **W0-L**：Loro movable tree + 文本 属性测试，**对照 oracle**（非生产依赖）
- 主路径仍自研树；对照失败 → 修自研规则，不默默切 Loro 除非 A-SWAP

### 补丁 P-H2 · persist 失败策略（钉死 A-INV-09a 原子域）

**问题**：库存路径可能在内存树已 mutate 后 `on_committed` / persist 失败，返回错误但 **内存已新**；huge 自动 split 失败亦难回滚——与 H2「同批提交或同批回滚」字面冲突。

**裁决（二选一已钉默认；实现须二选一并测，禁止静默第三态）**：

| 选项               | 语义                                                                                                                                                                                               | 本补丁 **默认锁定**      |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| **(1) 快照回滚**   | apply 前对 Structure+Text 可恢复快照；persist / 自动 split **任一失败** → 内存回滚到 apply 前；对外错误；零半提交                                                                                  | **默认主路径**           |
| **(2) 两阶段提交** | Phase A：`prepare` 编码 `CommitBatch`（结构可逆 + 文本 update）且 **尚未**发布投影/事件；Phase B：persist 成功后才 commit 内存可见版本并 `on_committed` 收尾；B 失败则丢弃 prepare、内存保持旧版本 | 允许作等价实现，须同测钩 |

**硬禁止**：

- 静默「返回 Persist 错但内存已新、投影已发」
- 用户 Op 成功后 **自动 huge split** 失败却保留用户 Op 半提交（split **纳入同一原子域**，对齐 huge-block-policy 与 H2）
- 远端文本合入路径绕过上述原子域仍改 rev（须并入统一 commit 面；见 D1 写锥）

**原子域边界（关闭 D1 开放冲突 C2 的默认）**：

> 原子域 = **用户可见 Op 批 + 同批触发的自动 huge 分段** + **persist/on_committed 成功**。  
> 任一步失败 → 整域回滚（选项 1）或整域不发布（选项 2）。

**验收挂钩**：

| ID          | 补丁断言                                                                                |
| ----------- | --------------------------------------------------------------------------------------- |
| A-INV-09a   | 增加用例：mutate 后模拟 persist 失败 → 树/文本/rev 与失败前同构；无 ProjectionDiff 外泄 |
| A-INV-09a-H | huge 超阈同批 split 中途失败 → 同 09a（无「用户 Op 已成、分段半截」）                   |
| A-INV-09b   | 仍要求同源 `tx_id`；且结构 bytes **满足下述 P-ENC**（非 rev 占位）                      |

**与 15 权威模型**：权威 = RS 内存树 + SQLite；persist 失败时内存不得假装已提交成功（选项 1/2 均保证「可见权威」一致）。

### 补丁 P-Loro · 对照 oracle = 自研差分（W0-L / M1）

**问题**：仅驱动 Loro 自洽（不环、自身 merge）**不满足** M1「对照 oracle」与 W0-L；对照名存实亡。

**裁决**：

| 项                     | 锁定                                                                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **对照定义**           | **同一场景输入**（块集合、并发 Op 序列或可复现种子）→ 观测 **自研 DocSession 终态约束** vs **Loro movable tree（+ 文本若场景需要）** |
| **观测维度（最低集）** | 无环；parent/children 关系；删胜 move（目标不存在则 move 不生效）；同父 order 全序可复算；跨粘贴新 ID（若场景含）                    |
| **失败处置**           | **修自研规则** 使差分收敛；**禁止** 默默切 Loro 主路径（除非 A-SWAP 客观触发）                                                       |
| **不满足 W0-L 的做法** | 只测 Loro API；只测自研单端；无并排断言；无场景向量表                                                                                |
| **生产依赖**           | Loro 仍为 **dev 对照 / A-SWAP 逃生**；主路径自研树 + yrs 文本不变（H1/M1 正文）                                                      |

**验收挂钩**：

| ID              | 补丁断言                                                                                      |
| --------------- | --------------------------------------------------------------------------------------------- |
| W0-L / M1-Loro  | 至少 N 条（N≥ MV-01…05 对齐场景 + 文本并发 1 条）**双实现并排**；差分失败则测红               |
| A-COL-01 满语义 | 不得以「Loro 绿」或「JSON op 重放绿」单独关闭；结构侧须可解码 update 或已声明的可恢复状态哈希 |

**与 `plans/09`**：Strict 包 **W0-L** = 本差分定义；**W0-L-S** = Loro 自洽脚手架 only。

### 补丁 P-ENC · 结构可恢复 encode 要求（权威载荷）

**问题**：结构 `EncodedUpdate` = `rev.to_le_bytes()` 占位 → SQLite 有行、杀进程无树；A-COL-05 / A-INV-04 / G-HYD 无法诚实关闭。

**裁决**：

| 项                                                    | 锁定                                                                                                                                                                                                                            |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **禁止**                                              | 以 **仅 rev 单调 / rev 的 LE 字节** 作为生产路径唯一结构载荷，并宣称落盘完成、打开完成、A-COL-05/A-INV-09b 满语义                                                                                                               |
| **最低成功定义（可恢复）**                            | 存在自动化：`apply` → `on_committed` 持久化 → **新进程或新 session** `load_doc` → **`DocSession::hydrate`** → 树同构（**id / parent / order / kind / props / children**）+ 文本按 H1 可读                                       |
| **允许的编码形态（效果锁只要求可逆+可测，路径可选）** | **(A)** 整树 snapshot 编码（bincode/等价）+ updates 日志；**(B)** 结构 op log 可完整重放；**(C)** 未来结构 CRDT bytes——**须可 hydrate**。选型在 01 方案钉死前，实现波 **任选能关 X-04 且不破坏单一 apply 者**；**不得**继续占位 |
| **文本**                                              | 继续 yrs 不透明 update 字节；hydrate 时按块槽合入；冷块遵守 H1 rehydrate/快照                                                                                                                                                   |
| **派生表**                                            | `blocks` / FTS / refs **不得**作 hydrate 主路径（02）；灾难抢救若做须 `origin=system` 进 apply 并审计                                                                                                                           |
| **CommitBatch**                                       | 结构+文本可分条，但同 `tx_id`（A-INV-09b）；可选 `op_audit` 在删胜/Agent 场景建议一等（待 01 评审是否强制）                                                                                                                     |
| **脚手架**                                            | JSON op 重放 / MemoryPersistence 可留在 harness，**必须**标注过期条件：A-COL-01 满语义或 W1-H 绿后退出（A-INV-08）                                                                                                              |

**验收挂钩**：

| ID              | 补丁断言                                                          |
| --------------- | ----------------------------------------------------------------- |
| G-HYD-1 / W1-H  | 结构 payload 可逆；禁 rev-only                                    |
| G-HYD-2         | `hydrate(HydrateBlob)` 公共/crate API 存在且被 store 打开路径调用 |
| A-INV-04 / X-04 | 杀进程恢复以 RS/SQLite 为准                                       |
| A-INV-09b       | 同源 `tx_id` **且** 结构 bytes 满足本 P-ENC                       |

**与 `plans/00`/`09`**：G-HYD-\* 硬闸；未过禁止「打开文档完成 / 落盘完成」。
