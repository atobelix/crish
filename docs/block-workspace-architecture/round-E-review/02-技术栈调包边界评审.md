# 结论（5 行内）

1. **D1–D6 主路径在「真相是否回 JS」上整体同向正确**：权威 merge/块树/MD parse·serialize/落盘/Agent 写均声明在 RS；TS 为投影/Intent/扩展 chrome；**未发现「推荐终局把文档权威放回浏览器 Y.Doc/PM 整树」的结构级回潮**。
2. **未达可交付栈锁**：`07-技术栈矩阵裁决.md` **未落盘**（开放）；**D3「磁盘 MD 一等」与 D4「snapshot+updates 权威 / MD 导出非权威」默认落盘形态未闭合**——不解决则实现会分裂成 note-gen 文件真相或「MD 仅导出」两种产品。
3. **自研边界表完整度高、跨层可测性未矩阵化**：各层魔鬼用例自洽；**缺 D7 总表 + 跨层联测 ID**（PM 叶↔RS text、MD apply↔事务、插件 DOM 写 vs 版本号）。
4. **本仓沉没成本未系统性误锁次优**：`pulldown`/`conex-markdown` 正确降为聊天面；行级引擎只共享纪律；`rusqlite`/`agent-tools` 延续有机制论证。**风险点**是 **yrs 因 y-protocol/AppFlowy 同构略偏生态**（可测，非结构否决）。
5. **最危险缩水/漂移口**：叶子 PM/乐观缓冲「滑成页级第二真相」；脚手架单写者事务永久化（E1 V12）；**未钉 ID 编码**导致 Agent/反链与 MD 契约嘴遁。
