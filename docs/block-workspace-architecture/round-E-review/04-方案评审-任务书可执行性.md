# 结论（5 行内）

1. **方向正确、调度骨架可用**：`01`–`07` 均含效果/文件域/依赖/禁止/验收入口；`09` Wave 依赖边与文件域冲突表大体对齐 `00`/`15` L0–L8，**不是**「无域无依赖的口号并行」。
2. **未达「可直接开大规模实现波」**：跨 crate **接口仅点名未冻结**（`PersistencePlugin` / `ProjectionDiff` / `MountSpec` / BlockIR 归属），同 Wave 会 **假并行** 出两套签名；验收 ID 多处 **范围口语** 不可单包钉死。
3. **S1 落盘语义在 02/03/06 已「引用级」贯彻，未「钉死级」抄表**：02 锁 15§4 + 禁纯 FS 当局；03/06 禁默认读陈旧 mirror——**但 03 单独读仍可能回潮「磁盘 MD 一等真相」**；09 未把 mirror 水位 / 三路测绑到具体 W 包。
4. **文件域有 4 处已知冲突温床**：BlockIR 双归属、W3 全挤 `editor-kit/block-paper`、02「或扩展 conex-db」、W1-D「两边」无主责 crate。
5. **裁决：须补丁后开实现波**（补丁小、可与 **Wave 0 契约冻结包** 同启；**禁止**跳过补丁直接开 W1 真实 apply/落盘）。**无换栈 / 无推翻 15 理由**。

1. **PersistencePlugin**（名可调，语义不可调）：`load(doc_id) → snapshot⊕updates`；`on_committed(CommitTick{doc_id, update_bytes?, snapshot_hint?})`；错误不吞。
2. **ProjectionDiff**：`upserts: [{block_id, …}]` + `removes: [block_id]`；未出现 = 未变。
3. **MountSpec**：`blockId, flavour, props, textSlice?, y?`（与 D5 对齐）。
4. **BlockIR**：唯一 crate 导出路径写死在 09。
