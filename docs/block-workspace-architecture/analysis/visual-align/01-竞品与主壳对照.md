## 1. 三方角色

| 产品                    | 角色                                                              | 本仓应怎么用                                                    |
| ----------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------- |
| **AFFiNE (BlockSuite)** | Notion 皮：拖拽把手、slash、页宽、标题字阶、hover 矩形            | 学 **节奏与静默策略**，色板不搬                                 |
| **AppFlowy**            | 桌面原生块编辑：左 option 栏 44、`+`/`...`、行高 1.4、标题 base+N | 学 **gutter 与字阶公式**，Flutter 栈不搬                        |
| **Conex / Crish**       | 暖中性灰工作区壳 + chat 列宽 + 密度档                             | **唯一真源**：`tokens.css`；note-paper 必须看起来像壳内一等公民 |

## 3. 主壳审美锚点（note-paper 必贴）

从 `tokens.css` + shell 抽 **纸面相关** 子集（完整定义见源文件）：

| 族     | 关键 token                                                                   | 用途                      |
| ------ | ---------------------------------------------------------------------------- | ------------------------- |
| 表面   | `--bg-primary` `--bg-secondary` `--bg-card` `--bg-elevated` `--bg-workspace` | 工作区 / 顶栏 / 纸 / 浮层 |
| 字色   | `--text-primary` `--text-secondary` `--text-tertiary`                        | 正文 / 元信息 / 把手      |
| 淡染   | `--tint-hover` `--tint-active` `--tint-strong` `--tint-focus-ring`           | 块 hover/focus/multi      |
| 线     | `--hairline` `--hairline-strong` `--hairline-width`                          | 头底部分隔、focus inset   |
| 间距   | `--space-0_5`…`--space-8`；`--panel-pad-x/y`；`--card-header-*`              | 密度统一；禁裸 5/7/9px    |
| 字阶   | `--font-size-xxs`…`--font-size-2xl`；`--font-size-chat`                      | 标题映射                  |
| 行高   | `--line-height-tight/ui/body/relaxed`                                        | 标题/UI/正文              |
| 圆角影 | `--radius-*`；`--shadow-sm/md/lg`                                            | 面板与 slash              |
| 控件   | `--icon-size`；`--control-height-xs`；`--row-height-sm`                      | 把手与行高                |
| 动效   | `--transition-micro`；`data-perf-tier=eco` 压平                              | hover 显隐；eco 停转      |
| 列宽   | `--chat-col-max` 760                                                         | 阅读列可复用              |
| 字体   | `--font-sans` `--font-mono`                                                  | CJK 一体                  |

**Shell 一体感参考**

- inset 工作区：`shell-workspace.css`（`--shell-inset-radius: 14px` 等）— 笔记面板应嵌在此语言内，不另起「网站文档」全白通栏除非产品明确要求。
- 卡片顶栏：`shell-polish.css` `.card-header` → note-paper `.header` 已对齐 min-height / pad。
- 对话正文：`chat-markdown.css` 标题相对 em 级差偏**保守**（h1 1.2em）；笔记纸面标题可略**大于 chat**（用绝对 token 档，而非再嵌套 em），因纸面是主阅读面。

## 4. 建议字阶映射表（Conex token · 供 02 落地）

> 对标 AppFlowy「base + N」与 AFFiNE h1–h6 **节奏**，数值全部落在既有 token，**不**新增魔法 px。

| 块               | 建议 font-size token    | weight           | line-height | margin-block（约）                                 |
| ---------------- | ----------------------- | ---------------- | ----------- | -------------------------------------------------- |
| paragraph / list | `--font-size-base`      | normal           | body        | 0（靠行 gap）                                      |
| heading 1        | `--font-size-2xl` (22)  | heavy 或 content | tight       | top space-5 / bottom space-2                       |
| heading 2        | `--font-size-xl` (19)   | content          | tight       | top space-4 / bottom space-2                       |
| heading 3        | `--font-size-lg` (17)   | content          | ui          | top space-3 / bottom space-1_5                     |
| heading 4        | `--font-size-md` (15)   | content          | ui          | top space-3 / bottom space-1_5                     |
| heading 5–6      | `--font-size-base`      | content          | ui          | top space-2 / bottom space-1                       |
| code 块          | `--font-size-sm` + mono | code             | base/body   | 块级 padding space-3；底 `--md-code-bg`            |
| 引用             | base                    | normal           | body        | 左边 2–3px 条 `--text-tertiary` 或 hairline-strong |

**与 chat-markdown 差异（故意）**

|      | chat 气泡      | note-paper                                             |
| ---- | -------------- | ------------------------------------------------------ |
| 场景 | 辅助阅读、窄列 | 主编辑纸面                                             |
| h1   | 1.2em ≈ 16.8   | 2xl 22（更清晰层级）                                   |
| 行高 | 1.65           | body 1.55（略紧于 chat，接近 AppFlowy 1.4 与中文折中） |

## 6. 对照结论（给设计）

1. **色与材质**：100% 主壳；竞品只借「静默 + 淡 hover」。
2. **节奏**：借 AFFiNE/AppFlowy 的 **gutter、标题 margin、slash 浮层尺寸感**；数字改写为 `--space-*` / `--font-size-*`。
3. **字号基准**：保持 Conex **14** 与 UI 一体，**不要**为「更像 Notion」擅自全局改 16（若要做文档字号设置，应是独立 appearance 档，而非偷改 base）。
4. **暗色**：只测 token 切换；不写第二套 note-paper 调色板。
