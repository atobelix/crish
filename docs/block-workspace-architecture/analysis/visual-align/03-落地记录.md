## 1. 改了什么

### 1.1 `NotePaperPanel.module.css`（主改）

| 区域        | 前                                  | 后（对齐 token）                                                                                                                     |
| ----------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **面板底**  | 暗色 fallback `#0f1115` / 裸 border | `--bg-card` + `--hairline` + `--shadow-sm` + `--radius-lg`                                                                           |
| **顶/底栏** | 固定 12/16 padding                  | `--card-header-*` / `--panel-pad-x` 密度；底栏 `--font-size-xxs`                                                                     |
| **徽章**    | `999px` + 暗 rgba fallback          | `--radius-full` + `--control-soft-bg*`；可点 badge `:hover/:focus-visible` 走 `--focus-ring`                                         |
| **轨标识**  | 裸 `--accent-blue` 字色             | `--color-info-bg` + `--color-info`（语义信息色）                                                                                     |
| **块行**    | 6×8 硬编码；focus 高饱和蓝 inset    | padding→`--space-1_5/2`；hover=`--bg-hover/--tint-hover`；focus=`--bg-active` + **中性** `--hairline-strong` inset（静默、不抢纸面） |
| **把手**    | 实心条 `opacity 0→0.55`             | 六点径向纹理 + 仅 hover/focus/multi 显（L0）；`--icon-size`                                                                          |
| **正文**    | `line-height: 1.5` 硬编码           | `--line-height-body`（1.55）+ `--font-size-base`                                                                                     |
| **flavour** | `10px` 硬编码                       | `--font-size-xxs` + `--letter-spacing-wide`                                                                                          |
| **状态面**  | 仅 `.empty`                         | `.state` + `.stateLoading` / `.stateEmpty` / `.stateError`（Skeleton∩Strict）                                                        |
| **加载**    | 纯文案                              | 微转圈 `::before` + `--transition-spin`；eco 档停动画                                                                                |
| **错误**    | 与空态同灰                          | `--color-error*` 软底 + 边                                                                                                           |

### 1.2 组件 class 接线（不改 data 契约）

| 文件                       | 变更                                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------------- |
| `NotePaperPanel.tsx`       | 空 → `state + stateEmpty`；transport 错 → `state + stateError`                              |
| `NotePaperStrictPanel.tsx` | loading / empty / error 分接三态 class（testid / data-* 不动）                              |
| `SendToNoteButton.tsx`     | 去掉内联魔术色；改用 `feedbackError` / `feedbackOk`（`--color-error` / `--text-secondary`） |

## 2. 对齐的 token 族

| 族            | 使用点                                                        |
| ------------- | ------------------------------------------------------------- |
| **色 · 表面** | `--bg-card` / `--bg-secondary` / `--bg-hover` / `--bg-active` |
| **色 · 字**   | `--text-primary` / `--text-secondary` / `--text-tertiary`     |
| **色 · 线**   | `--hairline` / `--hairline-strong` / `--hairline-width`       |
| **色 · 淡染** | `--tint-hover` / `--tint-active` / `--tint-strong`            |
| **色 · 语义** | `--color-info*`（轨 badge）、`--color-error*`（错误态）       |
| **控件**      | `--control-soft-bg*` / `--focus-ring` / `--control-height-xs` |
| **间距**      | `--space-*` / `--panel-pad-x` / `--card-header-*`             |
| **圆角**      | `--radius-xs`…`--radius-lg` / `--radius-full`                 |
| **字阶/行高** | `--font-size-*` / `--line-height-body                         | ui  | tight`/`--font-sans` |
| **动效**      | `--transition-micro` / `--transition-spin` / eco 档停转       |

## 3. 前后对照要点（观感）

| 维度        | 前                                  | 后                                        |
| ----------- | ----------------------------------- | ----------------------------------------- |
| 主题一致性  | fallback 偏暗终端灰                 | light-first 暖中性 + 暗色主题变量接管     |
| 纸面感      | 普通面板                            | card 暖白 + 极轻 shadow + 连续块缝        |
| 静默 chrome | 有 hover，但 focus 蓝描边吵         | 非 hover 零 chrome；focus 中性 inset      |
| 行距        | 1.5 硬写                            | body 1.55，中文阅读更松                   |
| 双轨状态    | Strict 加载/空/错与 Skeleton 空同灰 | 统一 state 语言；错有软红底；加载有微指示 |
| 魔术色      | SendToNote 内联 `#f07178` 等        | 全走 token / 模块 class                   |
