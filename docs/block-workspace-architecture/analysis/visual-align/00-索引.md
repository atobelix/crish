## 3. 结论摘要（一页）

### 3.1 审美北极星（本产品）

- **一体感**：note-paper 看起来是 **Conex 工作区里的一张纸面卡片**，不是外来 AFFiNE 皮肤岛。
- **静默 L0**：默认无常驻把手/菜单噪声；hover/focus/multi 才抬 chrome（A-SIL / `BlockChromeModel`）。
- **暖中性灰**：light 护眼暖灰 + dark 炭灰；**禁止**引入竞品品牌蓝紫作纸面主色。
- **阅读优先**：正文用 `--font-size-base` + `--line-height-body`；标题层级用主壳字阶族，**不**另造一套 px 表。

### 3.2 竞品借用边界

| 借                                       | 不借                                   |
| ---------------------------------------- | -------------------------------------- |
| 块侧把手 **按需显**、拖条/六点暗示       | 整套 `--affine-*` 色板                 |
| 左 gutter 为把手预留空间                 | 像素级 grabber 宽/高动画               |
| 标题级差 + 段上/下 margin 节奏           | AppFlowy Flutter 字体栈 / Google Fonts |
| Slash 浮层：分组、项高、overlay 阴影语言 | Slash 目录功能全集（属交互/引擎）      |
| 阅读列 max-width 居中                    | 画布 edgeless / note slicer 视觉       |

### 3.3 当前态（诚实）

- **一期已做**（见 `03` + 读盘 `NotePaperPanel.module.css`）：面板 `--bg-card` / hairline / card-header；块 hover tint + 中性 focus；把手 L0 六点；正文 `--line-height-body`；状态面；**阅读列** `--note-paper-col-max` / `--chat-col-max` + 左 gutter `space-6`；**标题** `data-heading-level` 字阶；**flavour 默隐**（仅 `data-debug`）。
- **二期余量**（见 **`04`**）：slash 浮层无产品皮（仅 `data-slash-open` + DomHost 宿主契约）；落点线 DomHost 有、React 壳无皮；code/quote 块无 `--md-code-*` / 左边条；把手仍 **`pointer-events: none`**（装饰）；React 壳与 `.bp-*` DomHost **双轨无共享皮肤类**。

## 4. 最优先落地建议

### 4.1 一期（已收口意图 · 完整表见 `02`）

1. 标题字阶 → 块行
2. 阅读列 max-width + 左 gutter
3. flavour 默隐

### 4.2 二期（当前下一棒 · 完整表见 `04`）

> 主壳 token 优先；≠ 关 EL；≠ fork 竞品皮肤。

1. **Slash 浮层皮**（`04` S1+S2）  
   宿主 `min(280px,100%)` + `--bg-elevated` + `--shadow-lg` + `--dropdown-padding` / `--item-padding`；项 hover `--bg-hover`。功能未全时只做打开态宿主，避免空壳冒充产品完成。

2. **把手可点热区**（`04` S6）  
   去掉装饰-only `pointer-events: none`（`data-handle=hidden` 行除外）；热区 min `--control-height-xs`；显隐仍 L0（0 → 0.45）；**禁止**常驻半透明把手。

3. **落点线 + 代码块皮**（`04` S3+S4；引用 S5 可同 PR）  
   落点 **2px** 中性 `color-mix(text-primary 35%)`；code 容器走 **`--md-code-bg/border/fg`** + mono sm——与 chat-markdown 同族。
