## 3. 结论摘要（一页）

### 3.1 审美北极星（本产品）

- **一体感**：note-paper 看起来是 **Conex 工作区里的一张纸面卡片**，不是外来 AFFiNE 皮肤岛。
- **静默 L0**：默认无常驻把手/菜单噪声；hover/focus/multi 才抬 chrome（A-SIL / `BlockChromeModel`）。
- **暖中性灰**：light 护眼暖灰 + dark 炭灰；**禁止**引入竞品品牌蓝紫作纸面主色。
- **阅读优先**：正文用 `--font-size-base` + `--line-height-body`；标题层级用主壳字阶族，**不**另造一套 px 表。

### 3.2 竞品借用边界

| 借                                       | 不借                                   |
| ---------------------------------------- | -------------------------------------- |
| 块侧把手 **按需显**、拖条/六点暗示       | 整套 `--affine-*` 色板                 |
| 左 gutter 为把手预留空间                 | 像素级 grabber 宽/高动画               |
| 标题级差 + 段上/下 margin 节奏           | AppFlowy Flutter 字体栈 / Google Fonts |
| Slash 浮层：分组、项高、overlay 阴影语言 | Slash 目录功能全集（属交互/引擎）      |
| 阅读列 max-width 居中                    | 画布 edgeless / note slicer 视觉       |

### 3.3 当前态（诚实）

- **一期已做**（见 `03` + 读盘 `NotePaperPanel.module.css`）：面板 `--bg-card` / hairline / card-header；块 hover tint + 中性 focus；把手 L0 六点；正文 `--line-height-body`；状态面；**阅读列** + 左 gutter；**标题** `data-heading-level`；**flavour 默隐**（仅 `data-debug`）。
- **二期已做**（见 `05` + `blockChrome.css`）：DomHost `.bp-slash-host` / `.bp-drop-line` / 把手热区 token 皮；note-paper **side-effect** `import '@crish/block-paper/chrome.css'`；code/quote 块行轻量 flavour 皮。
- **三期缺口**（见 **`06`**）：React **无** slash catalog 浮层 DOM（仅 `data-slash-open` + 模型实例）；桌面**未**默认挂 `BlockChromeDomHost`；React `.handle` 仍 **`pointer-events: none`**（装饰）；挂载后须按 `06` 清单做静默/双轨/落点回归。

## 4. 最优先落地建议

### 4.1 一期（已收口意图 · 完整表见 `02`）

1. 标题字阶 → 块行
2. 阅读列 max-width + 左 gutter
3. flavour 默隐

### 4.2 二期（皮规格 · 完整表见 `04`；落地见 `05`）

> DomHost/css 侧大体已落；React 可点热区 / 真浮层仍属挂载轨。

1. Slash 宿主容器 + 项密度（S1+S2）— **css 已有**；React 列表待挂
2. 把手可点热区（S6）— DomHost 已扩；**React 仍装饰-only**
3. 落点线 + code 皮（S3+S4）— **css + module 已有**；React 落点线待挂载投影

### 4.3 三期（挂载检查 · 完整清单见 `06`）

> 主壳 token 优先；≠ 关 EL；≠ fork 竞品皮肤。

1. **React slash 浮层吃 `.bp-slash-host` 族**（`06` §7 P1）
   `min(280px,100%)` + elevated + shadow-lg + dropdown/item token；z=`--z-popover`；打开态才可见；绑 `SlashMenuModel` snapshot。

2. **桌面 chrome 挂载后跑 `06` §4 全表**（P2）
   L0 静默、落点 2px 中性、双轨同皮、阅读列/标题/flavour 不回退；React 把手可点时仍 opacity 0 默认。

3. **材质锚 chat slash、节奏锚 AFFiNE 280**（P3）
   与 `TiptapSlashMenu` 同 elevated/中性 hover；块 slash 允许 shadow-lg（面板族）；**禁止**搬 `--affine-*` 或第三套魔法色。

### 4.4 四期（可执行对照 · 配方真源见 `08`）

> 压缩 `01`/`04`/`06` 为 **设计可抄** spacing / 字阶 / shadow / z-index 表；竞品只借节奏。落地自检见 **`08` §9**。

1. **P1 React slash catalog 同 `.bp-slash-*` 公式**（`08` §6）→ 验收 **A2**
2. **P2 挂载后 L0 静默不回退** → 验收 **A1**
3. **P3 双轨同皮**（module ↔ DomHost）→ 验收 **A3**
4. **P4 标题 margin 贴 01 §4**；**P5** 把手可点仍 L0；**P6** 落点线 React 投影（`08` §9.2 扩展勾选）

### 4.5 六期（PaperList 产品挂载 · 配方真源见 `10`）

> 列表宿主 **尚无 CSS**；嵌 note-paper 阅读列 + 三轨同温 + spacer 零噪声。落地自检见 **`10` §7 A1–A4**。**挂载 ≠ 关 EL**。

1. **P1 `.bp-paper-block` ≡ `.bp-block-row` / `.blockRow` 同温**（`10` §6）→ **A3**
2. **P2 嵌阅读列 / card 一体**（col-max + gutter space-6；不二次影）→ **A1**
3. **P3 Spacer 零噪声 + gap space-0_5 连续纸** → **A2**
4. **P4 挂载后 L0 静默 + 滚动不闪 chrome** → **A4**
