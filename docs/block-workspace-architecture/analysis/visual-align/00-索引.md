## 3. 结论摘要（一页）

### 3.1 审美北极星（本产品）

- **一体感**：note-paper 看起来是 **Conex 工作区里的一张纸面卡片**，不是外来 AFFiNE 皮肤岛。
- **静默 L0**：默认无常驻把手/菜单噪声；hover/focus/multi 才抬 chrome（A-SIL / `BlockChromeModel`）。
- **暖中性灰**：light 护眼暖灰 + dark 炭灰；**禁止**引入竞品品牌蓝紫作纸面主色。
- **阅读优先**：正文用 `--font-size-base` + `--line-height-body`；标题层级用主壳字阶族，**不**另造一套 px 表。

### 3.2 竞品借用边界

| 借                                       | 不借                                   |
| ---------------------------------------- | -------------------------------------- |
| 块侧把手 **按需显**、拖条/六点暗示       | 整套 `--affine-*` 色板                 |
| 左 gutter 为把手预留空间                 | 像素级 grabber 宽/高动画               |
| 标题级差 + 段上/下 margin 节奏           | AppFlowy Flutter 字体栈 / Google Fonts |
| Slash 浮层：分组、项高、overlay 阴影语言 | Slash 目录功能全集（属交互/引擎）      |
| 阅读列 max-width 居中                    | 画布 edgeless / note slicer 视觉       |

### 3.3 当前态（诚实）

- **已做**（见 `03`）：面板走 `--bg-card` / hairline / card-header 密度；块 hover 用 tint；把手 L0 隐显；正文 `--line-height-body`；状态面 loading/empty/error。
- **未做 / 余量**（见 `02`）：标题字阶未投影；阅读列宽未限；flavour 调试标仍常驻；slash/落点线无产品皮肤；把手 `pointer-events: none`（装饰非交互）；DOM chrome 与 React 壳双轨。

## 4. 三条最优先落地建议（给下一棒）

> 完整表与验收句见 `02`。此处只列 **效果完整度最高、仍贴主壳 token** 的三项。

1. **标题字阶接到块行**  
   heading 块按 `level` 映射 `--font-size-2xl|xl|lg|md|base` + 段上 margin（参考 chat-markdown 与 AppFlowy `base+16…` 节奏，**值用 token**）。无级差 = 永远像「列表调试器」不像笔记。

2. **纸面阅读列 + 左 gutter**  
   `.body` 内层 `max-width`（建议 `--chat-col-max` 或独立 `--note-paper-col-max` 默认 720–760）居中；左侧为把手预留 `--space-5`～`--space-6`（对标 AFFiNE side-padding 24 / AppFlowy optionMenu 44 的**意图**，数字落 space token）。

3. **产品默隐 flavour 调试标**  
   `.flavour` 默认 `display: none`；仅 `data-debug="1"` 或 dev 轨显示。调试元信息常驻 = 破坏静默纸面（A-SIL 观感）。
