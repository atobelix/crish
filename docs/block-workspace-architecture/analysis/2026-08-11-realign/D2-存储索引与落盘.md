### 3.2 权威 vs mirror（语义 vs 效果）

| 层              | 文档                 | 代码事实                                                                     | 判定                                                                                        |
| --------------- | -------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| **权威表**      | snapshot+updates     | `on_committed` 真 append；`load_doc` 真读回 `HydrateBlob`                    | 存储 **管道** 真                                                                            |
| **结构字节**    | 可 hydrate 的 encode | `session.rs`：`bytes: rev.to_le_bytes()`，注释「结构侧尚无独立 CRDT encode」 | **载荷假**                                                                                  |
| **文本字节**    | yrs update           | `UpdateKind::Text` 带 `encode_state_as_update_v1` 类 payload                 | 文本侧 **较真**，但无树则孤立                                                               |
| **compact**     | squash pending       | length-prefix 拼接旧 snap+updates                                            | **正确压缩了无语义结构块**                                                                  |

| **工具读**      | 即时 S               | note-runtime `document_to_md` / `get_md` 明确禁 mirror                       | **遵守**（上层纪律；缺「误读 mirror」硬门禁测）                                             |

### 3.3 结构 encode / hydrate / 杀进程

```
apply(ops)
  → 内存树变 (真)
  → CommitBatch.structure = rev 的 8 字节 (假编码)
  → on_committed → doc_updates (真落库假载荷)
  → apply_projection_diff → blocks/FTS (真，依赖内存 diff)

杀进程
  → load_doc → HydrateBlob { snapshot?, pending: [占位…] } (管道真)
  → DocSession::hydrate(??)  → **不存在**
  → ensure_session: DocSession::new 空树 + 丢弃 blob (诚实逃逸)
  → 结果：SQLite「权威」行在，用户文档树没了
```

| 检查点                                                    | 结果                                |
| --------------------------------------------------------- | ----------------------------------- |
| `PersistencePlugin::load_doc`                             | 有                                  |
| `DocSession::hydrate` / `from_blob`                       | **无**                              |
| 结构可逆 encode（bincode/CRDT/整树 snapshot_tick 真载荷） | **无**（仅 rev 占位）               |
| 杀进程自动化（X-04 / A-INV-04）                           | **无 / 红**                         |
| note-runtime 是否假装已恢复                               | **否**（注释认账）——仍 **效果锁红** |

**跨维归类（必须写进再生方案）**：

- **根因主责：01（doc-collab）** encode + hydrate API。
- **02 共责**：若 `plans/02` / Round 叙事宣称「落盘完成 / 杀进程可恢复」即 **虚标**；store 必须 **拒绝** 把「表写满」当 S1 关闭。
- **打开路径合同**：`interfaces/00` 写明 load → hydrate；02 的 T7 在 01 未交付前 **不得标完成**。

| 项                        | 再生锁定建议                                                                                                                             |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Structure `EncodedUpdate` | **禁止**以 `rev.to_le_bytes()` 为唯一生产载荷；须可逆（整树 snapshot 编码 / 结构 op log / 未来 CRDT——**路径由 01 方案钉**，02 只存字节） |
| Text `EncodedUpdate`      | 继续 yrs 不透明字节；hydrate 时按 block 槽合入                                                                                           |
| `snapshot_tick`           | compact 后的 snapshot blob 必须仍可被 hydrate 理解（framing 文档化：length-prefix 是否保留）                                             |
| **派生表非权威**          | `blocks`/`FTS`/`refs` **不得**作为 hydrate 主路径；灾难重建索引可以树为准重放，不能反客为主                                              |
| mirror                    | 保持非权威；工具读 S(树)                                                                                                                 |

### 6.3 打开路径（T7）——写进 02 验收

```
load_doc(doc_id) -> HydrateBlob
DocSession::hydrate(blob) -> 内存树 + 文本引擎热/冷策略(H1)
optional: rebuild 投影 from 树（若索引落后/损坏）
```

- 02 验收：**store 集成测**提供「假可逆结构 payload」或对接 01 真 encode 后的 **杀进程测**。
- 在 01 未交付前：02 包状态标 **blocked-on-01**，**不是**「store 已完成」。

### 6.4 P6 / W2-E——从「扩展点」升为正文 API

在 `02` 钉最小接口形状（名称可调，语义不可缩）：

| API / 步骤                    | 语义                                                        |
| ----------------------------- | ----------------------------------------------------------- |
| `detect_mirror_drift(doc_id)` | mtime/hash vs `mirror_meta`；输出 仅 mirror / 权威变 / 双变 |
| `import_mirror_proposal(...)` | 产出 **Op 批或冲突报告**，**不**直接盖 unpushed             |
| 三路策略枚举                  | RetainLocalAndReimport / DropUnacked / ConflictBlocks       |
| 禁止项                        | 默认 `full_rebuild` / 静默 overwrite 内存树与 unpushed op   |
| watcher                       | 可选 FS 事件或轮询；须可测注入 fake clock/fs                |

验收：**A-INV-02** + **X-05** 最小骨架；水位 API **保留**为必要子句。

### 6.5 refs 物化（W2-F 补完）

`02` 明确：

- **边来源**（至少一种主路径）：正文 wiki/块链语法 / 专用 props / 显式 Ref Op——**选一写死**，禁止「留给后续 indexer」无限期。
- **时机**：与 `apply_projection_diff` **同事务**（upsert 出边 + remove 清边）；`query_blocks` ref_* **端到端无手工 seed**。
- 文案：删除「已投影 refs」虚写，或实现后改回真写。

### 6.6 Schema 对齐

| 计划名        | 实现         | 再生选项（须二选一写死）                                                |
| ------------- | ------------ | ----------------------------------------------------------------------- |
| `peer_clocks` | `doc_clocks` | **A** 文档改称 doc_clocks；**B** 迁移改名                               |
| `outbox`      | 无           | **A** 增表+与 A-COL-05 映射；**B** 移出 02 目标并改 00 架构图（须评审） |
| backup        | 无           | 最小 `backup_hint(path)` 或明确后置波                                   |

### 6.7 CAS（W2-D）

回写最小可用定义：

1. 默认 bytes 内联或阈值上外置 `blobs/{hash}`；
2. `unlink` 块附件 + **未引用 GC** 测；
3. **结构门** A-PERF-11：附件字节 **不**进入 `doc_snapshots` 热路径（测）；数值门后置 H3。

### 6.8 投影完备性

- `text_touches`：要么 01 保证 touch 必带 upsert plain_text，要么 02 对 touch 重读树/快照更新 FTS。
- 裸 apply：文档 **fail-closed** 建议——生产 `NoteBackend` 只暴露 `commit_ops`；单测允许半接线。

### 6.9 验收映射补丁（建议同步 08/09）

| 包                            | 再生完成定义（缺测=未交付）               |
| ----------------------------- | ----------------------------------------- |
| W1-D1/D2 + **hydrate 闭合包** | 杀进程绿；非「表有行」                    |
| W2-C                          | FTS+投影+rebuild；A-PERF-10 结构门        |
| W2-D                          | put/get/link + GC 最小 + 不进 snapshot 测 |
| W2-E                          | export+lag **且** detect+三路+X-05        |
| W2-F                          | query 白名单 **且** 自动 refs 端到端      |

`09` 叙事：Wave 2 **不得**再标「存储完成」除非 G1+G2 相关 ID 非红。

### 6.10 明确 **不** 回写进 02 的项

- 换 SQLite / 上 tantivy 默认（仅 baseline 逃生条件触发）。
- 用 mirror 或 blocks 表冒充权威恢复。
- 把 markdown-rs 接线算作 02 文件域（归 03）。
- 工期/MVP 砍杀进程或三路。
