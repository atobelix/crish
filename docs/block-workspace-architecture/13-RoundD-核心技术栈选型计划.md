# 13 · Round D · 核心技术栈选型计划

> 在 **壳/皮/心终局**（Tauri + TS + Rust，见 08/12）已锁定的前提下，下钻到 **可调包 vs 自研** 的边界。
> 裁判键（`.agents/LOGIC_PLAN_NO_RETREAT.md`）：效果完整度 → 正确性/不变量 → 可验证性 → 与已锁契约一致 → 结构干净。

## 2. 每份文档强制结构

1. 该层效果锁（必须满足的用户可见/不可见不变量）
2. 候选横评表（上限 / 不变量 / 与 RS 真相兼容性 / 可验证钉法）
3. **调包边界**：可依赖的公开 API 面
4. **必须自研**：禁止用包顶替的部分
5. **否决路径**及原因（结构洞，非工期）
6. 推荐主路径 + 备选 + 迁移触发条件（仅当不变量被破坏）
7. 与竞品机制对照（AFFiNE/AppFlowy/思源/…）

---

## 3. 硬约束（写进每份任务书）

- **呈现引擎不得持有文档权威**；最多持「当前窗口投影 + 本地 selection 映射」。
- **禁止** yjs 在 JS 作唯一真相（可研究 y-protocol 互通，权威仍在 RS）。
- **禁止** 用「先嵌 TipTap+Yjs 再迁移」当终局捷径。
- 本仓已有：`pulldown-cmark`、`rusqlite`、`reference/markdown-editor`（行级）——**可延续须论证**，不得默认「已有=最优」。
- 聊天行级引擎与块引擎 **接口可共享 IME/虚拟化纪律，模型不可混**。

## 4. 依赖边（逻辑，非排期）

```
D1 呈现 ──┐
D2 合并 ──┼→ D7 矩阵
D3 MD   ──┤
D4 存储 ──┤
D5 投影 ──┤
D6 扩展 ──┘
```
