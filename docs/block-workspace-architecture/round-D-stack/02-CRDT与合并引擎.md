## 0. 结论先行

| 项                           | 裁决                                                                                                                                                                                                 |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **主路径**                   | **混合层**：自研 **块树结构化 Op + 事务/校验/审计壳** + 叶子 **细粒度文本 CRDT（首选 `yrs`，备选 `loro` Text）**；**权威状态只在 RS**；TS 只发意图、收投影与 awareness 绘制                          |
| **强备选**                   | **Loro 全量**（Movable Tree + Text + shallow snapshot）作「树也进 CRDT」的备选；触发条件见 §6                                                                                                        |
| **否决**                     | **全量 JS Yjs 作唯一真相**；**整嵌 AppFlowy-Collab / Anytype any-sync 源码**（AGPL / Source Available）；**纯 diamond-types 作文档底座**（文本专用、树模型缺失）；**「先 TipTap+Yjs 再迁移」当终局** |
| **必须自研（不可用包顶替）** | 稳定块 ID 契约、块 schema 校验、工具面事务语义（origin/agent 批、原子性、可测回放）、权限与审计、投影/索引侧车、与 MD/AST 纪律的接线                                                                 |
| **可调包**                   | 文本（与可选树）CRDT 合并/编码/state-vector 差分、y-protocol **互通适配层**（非权威）、二进制 update 编解码                                                                                          |

**一句话**：

> 合并热路径在 Rust；块宇宙用 **自研结构化 Op 壳** 保证 Agent/schema/权限可测；叶子文本用 **成熟 CRDT 内核** 保证击键级并发与（可选）y-protocol 互通。**真相不在浏览器 `Y.Doc`。**

## 1. 该层效果锁（不可降级）

### 1.1 用户可见

| ID      | 效果                       | 不变量                                                                     |
| ------- | -------------------------- | -------------------------------------------------------------------------- |
| E-D2-01 | **离线可写**               | 断网本地 commit 成功；上线后收敛，不丢本地未推送编辑                       |
| E-D2-02 | **实时多人**               | 双端并发打字/改 prop/移动块最终一致；远端光标/选区可显示（awareness 可丢） |
| E-D2-03 | **冲突可理解**             | 树结构冲突（并发移动/删除父）有确定语义；可选冲突痕迹/历史回放             |
| E-D2-04 | **Agent 批量 mutate 安全** | 千次块 patch 原子批、可回放、可失败回滚、带 origin 审计；不撕裂半树        |
| E-D2-05 | **大文档可活**             | 十万级块/长文：合并不在 UI 主线程；投影窗口化（与 D5 协同）                |
| E-D2-06 | **MD 契约不破**            | 合并结果可导出为 MD 契约视图；块 ID 稳定引用不被 merge 打乱                |

### 1.2 架构不可见不变量

| ID      | 不变量                                                                                   |
| ------- | ---------------------------------------------------------------------------------------- |
| I-D2-01 | **merge/apply/encode 热路径在 RS**；WebView 内不持权威 Doc 的第二份完整合并引擎          |
| I-D2-02 | 可与 **y-protocol / Yjs update 二进制** 互通（适配层），但 **浏览器 `Y.Doc` 不是真相**   |
| I-D2-03 | **块树结构化 op** 与 **文本细粒度 delta** 都一等；禁止「整块替换伪装协同」作为唯一写路径 |
| I-D2-04 | 每条变更可带 **origin**（user / agent / remote / system）；undo 可按 origin 过滤         |
| I-D2-05 | schema 校验在 **apply 前**；非法 op 不得污染编码态                                       |
| I-D2-06 | 权限判定在合并入口（谁可写哪棵子树/哪类 prop）；失败可局部隔离                           |
| I-D2-07 | 持久化：编码态 + 可选 op 日志/快照；杀进程后 state 可恢复                                |
| I-D2-08 | 许可：依赖 MIT/Apache 等可商用；**不**整嵌 AGPL collab 栈                                |

### 1.3 裁判键（重申）

效果完整度 → 正确性/不变量 → 可验证性 → 与「RS 心 + TS 皮 + Tauri 壳」契约一致 → 结构干净。  
**不得**以「Yjs 生态最火」「先上 JS 再沉」砍掉 RS 权威。

### 2.3 分维深评

#### 2.3.1 历史 / GC / 内存

| 候选              | 历史                                                                                                                                                                                   | GC                                                                        | 内存与加载                                                                       |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **yrs**           | `Snapshot` + `encode_state_from_snapshot`；分支后与主干 update **不保证**再互通。`UndoManager` 按 origin/scope。长期历史常靠 **外部 update 日志 + 压缩**（AFFiNE 式 snapshot+pending） | `skip_gc` 关 GC 才能保留删除块做修订；开 GC 省内存丢细修订                | 大文档全量 Doc 常驻有压；需 **投影窗口 + 非活动子树冷藏**（应用层）              |
| **Loro**          | **DAG 历史**、`checkout`/`fork`、time travel；应用层可做 rebase/squash                                                                                                                 | **Shallow snapshot** 类 git shallow：保留状态裁历史 → 体积/导入速度显著降 | 1.0 懒解析、分块；百万 op 级 import 毫秒级（公开 bench）；更贴「长生命周期笔记」 |
| **Automerge**     | 变更图与压缩格式成熟；sync protocol 完备                                                                                                                                               | 有压缩/GC 路径                                                            | 历史曾偏慢/偏大（近年 RS 改进）；仍偏 **通用 JSON** 而非块编辑器专用             |
| **diamond-types** | 文本编辑 trace 极强                                                                                                                                                                    | 文本向                                                                    | 文本热路径极快；**不解决**块树内存模型                                           |
| **自研事务**      | 逆 op + 文件/快照历史（思源 dejavu 形）                                                                                                                                                | 完全可控                                                                  | 无 CRDT tombstone；多副本并发需另建                                              |
| **混合**          | 树：op 日志/快照；叶：yrs/loro 策略                                                                                                                                                    | 分治：结构快照配额 + 文本 shallow/GC                                      | 非活动块可不 hydrate 文本 CRDT                                                   |

#### 2.3.2 树结构 + 文本细粒度

| 候选      | 树                                                             | 文本                                 | 嵌套模型                                   |
| --------- | -------------------------------------------------------------- | ------------------------------------ | ------------------------------------------ |
| yrs       | YMap/YArray/Xml* 拼块树；**并发移动**语义弱于专用 Movable Tree | YText format/embed 成熟              | 根类型 + 嵌套 branch；**同一对象不可多父** |
| Loro      | **Movable Tree**（并发 move 后无环、单位置）                   | Fugue + rich text                    | 容器可嵌套 JSON 形 schema                  |
| Automerge | 嵌套 map/list                                                  | 有，但非块编辑器主叙事               | JSON-CRDT                                  |
| diamond   | 无                                                             | 专用 list/text                       | —                                          |
| 自研      | `insert/move/delete/update` 一等                               | 易做成整块替换；细粒度需自研 OT/CRDT | 完全自定义                                 |
| 混合      | 自研树 op（语义=产品）                                         | 库                                   | 块 id → text handle 映射表                 |

#### 2.3.3 移动块

| 候选      | 并发 A 移子树、B 删祖先 / 两处同时 move                                                     |
| --------- | ------------------------------------------------------------------------------------------- |
| yrs       | Array 重排 + tombstone；**易出现**与「意图保留 move」不符的结果；move 能力历史上分支/不完全 |
| Loro      | 产品级 **movable tree** 声明：合并后无环、元素单位置                                        |
| Automerge | list 移动需组合 delete+insert，意图保留一般                                                 |
| 自研/混合 | **显式 `move_block`** + 规则表（如：祖先已删 → 落地到根/冲突副本）；可单测钉死              |
| 思源事务  | 单写者下 move 正确；**多副本实时**不靠 CRDT                                                 |
| AppFlowy  | 领域 Document action + yrs 底层；语义在 collab Document 层                                  |

**效果锁要求**：移动块是块工作区一等操作 → 要么 **Loro tree**，要么 **自研 move 规则 + 可测不变量**。不宜赌 yrs Array 隐式重排。

#### 2.3.4 权限

所有 CRDT 库 **都不**提供文档 ACL。权限必须在：

1. **入站 apply 闸门**（RS）：校验 principal + 目标 block 范围 + op 类型；
2. **同步通道**（谁可 push/pull 哪 object）；
3. **投影过滤**（只读用户不收写能力）。

Anytype 的 space/ACL、AFFiNE 的 doc 权限错误隔离（round-A `03`）是 **机制对照**，不是可选库。

#### 2.3.5 Agent 批量 mutate

| 需求                               | 纯 CRDT 库                                    | 自研事务壳 / 混合壳                                |
| ---------------------------------- | --------------------------------------------- | -------------------------------------------------- |
| 千次 insert/move/set_prop 一原子批 | 多 txn 或大 txn，缺产品级「批失败全回滚」语义 | **Transaction { ops[], origin=agent }** 一次 apply |
| 可测：给定初始树 + ops → 期望树    | 需从 CRDT 状态抽投影再比                      | 直接投影树断言 + 编码态哈希                        |
| 半失败不落脏                       | 库级 apply 原子，但 **schema 失败点**要外层   | begin → validate all → commit / rollback           |
| 与用户击键交织                     | origin 区分 + 不抢 UI 锁过久                  | 队列/优先级 + 批大小上限 + 可取消                  |

思源 `PerformTransactions` + `flushLock` + 大插入批处理（round-C `02`）是 **Agent 友好标尺**；本产品要在 **不放弃实时 CRDT** 的前提下 **吸收事务壳**，而不是退回纯单写者。

## 4. 必须自研（禁止用包顶替）

| #   | 模块                 | 为何不能调包顶替                                                              | 验收钉                                                  |
| --- | -------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------- |
| M1  | **稳定块 ID**        | CRDT 内部 item id ≠ 产品 block id；引用/反向链接/Agent 工具键必须稳定、可导出 | ID 格式与生成单测；移动/合并后引用仍解析                |
| M2  | **块 schema 校验**   | 库接受任意 Map 形状；产品有 flavour/prop 约束                                 | 非法 prop/非法子类型 apply 失败且状态不变               |
| M3  | **工具面事务**       | MCP/Agent 要「批、原子、origin、错误码」                                      | 千次 patch 回放测试；失败批零写入                       |
| M4  | **树不变量**         | 单根、无环、父子一致、order 键（可 fractional index）                         | 并发 move 属性测试 + 魔鬼用例表                         |
| M5  | **权限闸门**         | 库无 ACL                                                                      | 越权 op 拒绝；只读 peer 不产生本地 commit               |
| M6  | **投影与索引侧车**   | FTS/refs 非 CRDT 职责                                                         | 与思源类似：权威编码态 + 可重建索引                     |
| M7  | **MD/AST 接线**      | 合并结果 → 契约导出                                                           | round-trip 子集黄金文件                                 |
| M8  | **外部文件变更策略** | Agent 改盘上 md 与打开文档                                                    | 检测 + 三路/重载，禁止静默覆盖未推送 Op                 |
| M9  | **同步状态机**       | outbox、reachability、按 doc 优先级                                           | 断网队列、上线 drain、单测 mock peer                    |
| M10 | **历史产品语义**     | 版本列表 UI、命名快照、冲突副本策略                                           | 与 Loro checkout 或 yrs snapshot **组合**，产品语义自研 |

## 5. 否决路径及原因（结构洞，非工期）

### 5.1 否决「全量 JS Yjs 作唯一真相」

| 结构洞     | 说明                                                                      |
| ---------- | ------------------------------------------------------------------------- |
| 与硬锁冲突 | merge 热路径必须在 RS；JS 真相 = 主线程/V8 堆持全量 Doc                   |
| Agent 批量 | 千次块 patch 打在 JS CRDT 上：卡 UI、难原子事务、难与 RS 工具面同进程共享 |
| 双真相风险 | 「UI Y.Doc + 偶尔 native 存盘」必然漂移（AFFiNE 已暴露双引擎运维面）      |
| 内存上限   | 大文档 + 扩展 + Agent 同 WebView → 被 AFFiNE 类天花板锁死（round-C `08`） |
| 可验证性   | 权威断言应在 RS 单测；放到 JS 则 CI 与内核分家                            |

**允许的残留**：调试桥、只读预览解码、**非权威** 的临时 Y.Doc（明确 lifecycle：丢弃且不写回）。

### 5.2 否决其它

| 路径                      | 原因                                                                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **整嵌 AppFlowy-Collab**  | AGPL；API 漂移；Flutter 通知模型不匹配；**学管线即可**（建造器、磁盘插件常驻、云插件按需、本地先写）        |
| **整嵌 Anytype any-sync** | Source Available 禁商用嵌入；对象模型非 MD 一等                                                             |
| **纯 diamond-types 底座** | 文本性能标尺可学；**无块树/无通用 schema** → 效果锁树+文本同时失败                                          |
| **纯 Automerge 当块引擎** | 可做协同 JSON；**移动块/块 ID/Agent 事务**仍全自研，且与 y 生态互通弱；作为「第二备核」可保留压测，不作默认 |
| **纯思源形无 CRDT**       | Agent/MD/块 ID 极强；**实时多端并发编辑**结构上限不够（文件级冲突副本 ≠ 击键 merge）                        |
| **先 TipTap+Yjs 再迁移**  | 明确终局捷径禁止（`13` 硬约束）；第一天真相放错 = 中途换栈主因（`08`）                                      |

## 6. 推荐主路径 + 备选 + 迁移触发

### 6.1 主路径：**混合（推荐）**

**结构层（自研）**

- Op 集（最小）：`insert_block` / `delete_block` / `move_block` / `set_prop` / `set_type` / `text_edit`（指向文本引擎）/ …
- `Transaction { id, origin, ops[], undo_ops? }`
- apply：鉴权 → schema → 树不变量 → 提交编码/投影 → 审计
- order：fractional indexing（Logseq/思源同类思想，实现自研或小 MIT 库）
- 块 ID：产品级稳定 ID（可参考思源时间戳+随机，算法自定）

**文本层（调包）**

- **默认：`yrs` YText**（每块或每文本字段一个逻辑 Text；或按页分片减少根类型膨胀）
- 选择理由：
  1. **y-protocol / update 互通**硬需求友好；
  2. AppFlowy 已证明 **yrs 在 RS + UI 只通知** 可量产（round-B `03`）；
  3. UndoManager + StickyIndex + Awareness 现成；
  4. MIT，可嵌。

**同步/存储（学 AppFlowy，自研实现）**

- 对象生命周期：open/close/软缓存 TTL
- `PersistencePlugin`：load/save encoded state（KV 或 SQLite blob，D4 另裁）
- `SyncPlugin`：state vector / update 交换；本地 commit 先于 replicate
- 快照配额环形；索引 state_vector 游标侧车

**为何不主选「Loro 全量」作默认**

- 树用 Loro 很强，但 **y-protocol 互通**要另建网关或放弃外部 Y 兼容；
- 产品块 schema/Agent 事务 **仍必须自研壳**——Loro 不能删掉 M1–M10；
- 混合让 **树语义 100% 产品可控**（冲突规则、权限子树、MD 导出），文本并发交给库。

### 6.2 备选 A：**Loro 全量（树 + 文本）**

| 何时切换                                               | 信号                          |
| ------------------------------------------------------ | ----------------------------- |
| 并发 move 在混合方案中用自研规则 **测不过** 或规则爆炸 | movable tree 属性测试稳定胜出 |
| 版本时光机/shallow 成为 **效果锁级** 产品能力          | Loro history 原语明显更贴     |
| **确认不需要** y-protocol 外部互通                     | 互通成本 > 收益               |

仍保留：**同一 DocSession 壳**（schema/权限/Agent 事务）；仅 StructureEngine+TextEngine 都落到 Loro 容器。

### 6.3 备选 B：**yrs 全量拼树（弱推荐）**

仅当：团队接受用 YMap/YArray 编码块树，且 move 语义用严格封装测过。  
风险：块移动/嵌套意图与 YATA 重排不一致 → **长期债**。默认不采纳。

### 6.4 备选 C：**自研事务为主，CRDT 后置（不推荐作终局）**

仅单机/单写者阶段可临时；与「多人实时协同」效果锁冲突。可作 **开发期脚手架**，不得锁定为终局。

### 6.5 迁移触发（仅当不变量被破坏）

| 触发                                          | 动作                                |
| --------------------------------------------- | ----------------------------------- |
| yrs 文本内存/合并在魔鬼用例下不可接受         | 叶子换 Loro Text，树壳不动          |
| 必须与外部 Yjs 世界深度互通且混合适配成本过高 | 强化 yrs 全页策略，仍禁止 JS 权威   |
| Loro 格式/API 破坏性变更无法钉版本            | 退回 yrs 文本 + 自研树              |
| 编码态损坏率异常                              | 引入校验和 + 快照回滚（两核都要有） |

**禁止**的触发：流行度变化、「竞品换栈」传闻、纯工期叙事。

## 8. 推荐架构契约（给 D1/D4/D6/D7）

### 8.1 写路径

```
TS UI 意图 ──invoke──► normalize_ops
Agent tool ──────────► normalize_ops  (origin=agent)
Remote update ───────► decode ──► authz ──► apply_remote
                              │
                              ▼
                     Transaction.apply (RS)
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
        树结构提交      文本引擎 apply    审计/undo/outbox
              │               │
              └──────► 投影事件 ──► TS 窗口 reconcile
```

### 8.2 读路径

- 打开：本地 encoded 优先 → miss 再拉云（AppFlowy 形）
- UI：只订 **投影补丁**（块级 + 文本 δ），不订原始 CRDT 内部结构
- 索引：异步侧车，不阻塞 apply

### 8.3 文本 δ 形态（示例契约，非最终 IDL）

```text
TextEdit { block_id, crdt_range_or_sticky, insert?: str, delete?: u32, marks?: ... }
```

块级 op 与 text_edit **可同批事务**；Agent 大改写允许 `replace_text` 粗粒度，但 **不得删除** 细粒度路径。

## 9. 验收断言（魔鬼用例）

| #   | 场景                                                          | 期望                                                                      |

## 12. 最终锁定声明（D2）

1. **权威合并在 Rust**；TS 无第二真相。
2. **主路径 = 自研块树事务壳 + yrs 叶子文本**（C6 + C1）。
3. **强备选 = Loro 全量**（C2），在 move/历史/无需 y 互通时升级。
4. **必须自研**块 ID、schema、Agent 事务、权限、投影索引、MD 接线。
5. **否决**全量 JS Yjs 真相、AGPL collab 整嵌、diamond 唯文本底座、纯无 CRDT 作协同终局。
6. **验收**以 §9 三簇（并发回放 / 断网合并 / Agent 千次 patch）为门禁级断言。
