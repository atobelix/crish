## 0. 结论先行（五句话）

1. **主路径已齐**：呈现 = 自研块壳 + 叶子裸 PM（代码叶 CM6）；合并 = 自研树 op 壳 + `yrs` 文本；MD = 双轨 IR+`markdown-rs`；存储 = `rusqlite`/WAL + snapshot/pending + CAS + FTS5；投影 = 块窗口 + `blockId+offset` + IME 状态机；扩展/Agent = 同进程 plugin-sdk + 统一 `ToolRegistry` + 单一 RS apply。
2. **真相单点**：权威永在 RS；TS 只持窗口投影 / 逻辑选区 / 乐观缓冲；**禁止** JS Y.Doc / 编辑器 doc / 行级 `lines[]` / 磁盘旁路 MD 作第二真相。
3. **集大成而非单家复刻**：交互学 AFFiNE、心学 AppFlowy、事务/Agent/MD 纪律学思源、query/order 学 Logseq、心壳切分学 Anytype、静默学 Typora/VNote——**栈形态与许可边界自研收敛**。
4. **高代价正当项**已显式列入（文档级虚拟化、混合 CRDT 壳、完整 MD 往返、块完成度清单）——用结构换上限；**过度工程**也显式否决（双 codec、整嵌 monorepo、全量挂载「以后再虚拟」）。
5. **E1 V5/V6 在本文关闭意图**：§5 给出块操作验收矩阵 + 性能红灯维度全集；具体毫秒初值可标定修订，**维度不可删**。

**一句话**：

> **多软件效果拼图 × 单一 RS 写锥 × 可测契约**；调包只买「显微镜与螺丝」，不买「宇宙中心」。

## 7. 高代价正当项 vs 过度工程

> 用户补充：**性能/体验有极大提升时允许更高代价**。下列用裁判键区分「该花」与「不该堆」。

### 7.1 正当高代价（应用结构换上限 / 体验）

| 项                                       | 代价形态                | 极大收益                                | 若不做的结构洞                      |
| ---------------------------------------- | ----------------------- | --------------------------------------- | ----------------------------------- |
| **文档级块窗口 + HeightMap + pin**       | 自研窗口管理；测量协议  | 10 万块可活；输入与滚动不绑全量 DOM     | AFFiNE 全挂载天花板                 |
| **混合合并：树自研 op + yrs 文本**       | 双引擎封装 + DocSession | Agent 可测事务 + 击键并发 + 可选 y 互通 | 纯 Y 树 move 弱；纯事务无实时       |
| **完整 MD 往返 + ID in-band + 有损报告** | 规格+golden+P/S         | Agent/互操作/Git 可读；非「导出凑合」   | 双真相或不可测契约                  |
| **块完成度清单（A-BLK）自研 chrome**     | 大量交互与测试          | Notion 级效果；禁嵌引擎锁死上限         | 永久半完成编辑器（E1 最危险缩水口） |
| **IME 状态机一等 + 合成期禁结构**        | 状态机+quirks+测        | CJK 基本盘；禁整树重建恢复              | 静默写作与输入不可用                |
| **单一 apply + 审批矩阵 + batch token**  | 工具面工程              | Agent 批改不毁库；可审计                | note-gen 旁路 / 确认疲劳 / 半树     |
| **索引可重建 + CAS 附件分离**            | 侧车管道                | 大库搜索；附件不拖垮文档                | 索引当权威；snapshot 写放大         |
| **逻辑选区 `blockId+offset`**            | 映射层                  | 虚拟化/协同/测试可证                    | DOM Range 当局 → 窗口化崩           |

### 7.2 过度工程（禁止用「高级」堆复杂度）

| 项                                           | 为何过度                    | 替代                                 |
| -------------------------------------------- | --------------------------- | ------------------------------------ |
| 双 codec 并行 merge（yjs + y-octo 无属性测） | AFFiNE 漂移教训；不可验证   | **单一 codec 真源在 RS**             |
| 整嵌 BlockSuite/思源「换完成度」             | 许可+真相绑死；中途换栈主因 | 清单自研 + 叶子调包                  |
| 先 TipTap+Yjs 再迁移                         | 第一天真相放错              | 第一天 RS 权威                       |
| 默认全量挂载「以后虚拟化」                   | 选区/CE 耦合后补成本爆炸    | 窗口化 = 打开契约                    |
| CSS hidden / 不卸载当虚拟化                  | 内存仍线性                  | 真 unmount + 预算                    |
| 每键整篇 MD S∘P                              | IME/性能灾难                | 热路径块 op                          |
| 纯 redb 唯一库 + 手写半套 SQL/FTS            | 重复造轮；丢运维面          | rusqlite 主路径                      |
| 向量 RAG 作默认块搜索                        | 成本高、块 ID/属性不匹配    | FTS5+属性；语义后置可选              |
| React+Lit 双运行时进编辑热路径               | 焦点/IME 桥接税             | 单一 TS 皮                           |
| iframe 作唯一 Agent 工具宿主                 | 双状态机批/审批             | 同进程 registry；iframe 仅不可信挂件 |
| 旁路 ID map + 纯 GFM 称「引用无损」          | 与 E-D3-03 冲突             | in-band ID                           |
| 文档级 undo 只靠 PM history                  | 与 Agent/远端时间轴分裂     | **RS undo 权威**；叶子可 group       |

### 7.3 代价裁决口诀

```

只提升「与某 monorepo 同构安全感 / 招聘熟悉度 / 少写胶水」？
  → 过度或换栈诱惑（§7.2 / §1.2）

不确定？
  → 设计验证（魔鬼用例 / 视觉对齐），禁止写成「不可能」或「先砍效果」
```
