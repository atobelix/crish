## 4. 落盘语义（关闭 S1）

```
权威：RS 内存树 + SQLite(doc_snapshots, doc_updates, clocks, …)
派生：blocks 投影、FTS、refs（可重建）
契约视图：workspace/**/*.md mirror（S(树)，含 <!--c:ID-->）
人/git：读 mirror
工具/Agent 默认读：S(树) 即时序列化 或 编码态导出 API
mirror 延迟：可测水位；冲突：外部改 mirror → import 检测，禁静默盖 op
```
