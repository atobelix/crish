## 3. 修订后的终局锁定（跨产品上限，非路径依赖）

```
皮：单一 TS 运行时
    · Notion 级块交互（完成度对标 AFFiNE/Protyle 清单）
    · 默认 Typora 级静默（chrome 按需）
    · TS 扩展一等
    · 行级流式编辑器（AI 输出）与块纸面并存，行级不当局

壳：轻量 WebView（Tauri 2 类）
    · 只做窗口/IPC/系统能力；不持文档真相
    · 禁止以 Electron「生态」换回永久内存税

心：Rust
    · 块树 + 增量 Op + 事务/可测 merge（CRDT 在此层）
    · 存储 + 索引 + doc-tools（block/document/search…）
    · MD ⟷ 块 一等契约
    · 与 AI Agent 运行时同语言同进程优先

许可：只内化机制；零 AGPL / Source Available 整嵌
```

| 锁           | 值                                                   |
| ------------ | ---------------------------------------------------- |
| 真相层       | **永远原生心（RS）**                                 |
| 扩展语言     | **TS**                                               |
| 默认纸面     | **静默写作**；DB/画布后挂                            |
| 聊天 vs 笔记 | **双引擎并存**；禁止行级冒充块                       |
| 换栈条件     | **无**——卡顿只许换实现，不许把真相迁回 JS/第二心语言 |

Go 心（SiYuan 同构）在 **无 AI 原生约束** 时与 Rust 上限接近；**有 AI 工作栈时 Rust 因单语言闭环胜出**（08 §2.2）。

## 4. 中途不会换栈的前提（第一天就必须对）

1. 不嵌 BlockSuite / Protyle / TipTap **当局**（可学交互，不可让 Yjs/DOM 当真相）
2. 不做「行级权威 + 块壳」
3. 不做双真相并行写
4. Agent **只**走结构化 op / 事务（学思源 MCP 纪律）
5. 文档级虚拟化 / 窗口化挂载一等
6. IME composition 隔离，禁止整树重建当默认

违反以上 → 中期会「想换栈」；那是**路径错了**，不是 Tauri/RS 上限不够。
