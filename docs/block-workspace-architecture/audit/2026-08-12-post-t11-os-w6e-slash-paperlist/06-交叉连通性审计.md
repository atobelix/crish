## 0. 总判（先看）

| 链                              | 色  | 一句话                                                                                                                   |
| ------------------------------- | --- | ------------------------------------------------------------------------------------------------------------------------ |
| **A** hydrate 产品默认          | 🟡  | 空态→transport→IPC/fixture→三态 UI **真通**；后端仍是 query 投影派生，**≠ DocSession 全链**                              |
| **B** slash React→真 apply      | 🟡  | 库内 collab sink **绿**；产品空态 **未注** `slashIntentSink`，浮层可点但默认 **无写**                                    |
| **C** PaperList↔viewport↔chrome | 🟡  | 库 + `PaperListDomMount` 可点名挂；**空态默认关**；chrome 分槽共存测有，pin/focus **未**与 chrome 自动联动               |
| **D** turn-into / MD 前缀       | 🔴  | 纯函数库可测；**桌面零接线**；`pending_turn_into_flavour` **无 RS 消费**                                                 |
| **E** mirror poll↔OS            | 🟡  | RS 双通道 + X-05 提案门 **库内通**；UI 状态条可注入；**无** poll/OS→IPC→UI 产品装配；双通道打架风险 **未产品化**故暂未爆 |
| **F** W6-E-S batch/token        | 🟢* | Skeleton 夹具↔Memory batch↔token↔plan Deny **自洽**；`*-S` 与 `W6E_S_NOT_CLOSING` 防假关 EL-05；\*仅骨架域               |
| **G** send_to_note / SURF       | 🟢  | 薄桥 + isolation 真扫 **通**；≠ EL-08 满关（诚实）                                                                       |

### 最危险断点 Top 3

1. **B · 产品 slash 无默认 sink** — `NotePaperStrictPanel.slashIntentSink` 可选；`WorkspaceEmptyState` 只注 hydrate，**不**注 apply。用户/演示可点 catalog，**Intent 不进 collab**；与库测「collab 真 apply 形状」叙事 **交叉断裂**。
2. **D · `pending_turn_into_flavour` 无 RS 消费** — `turnIntoIntentToProvisionalOps` 写 props 标记 + 可剥前缀 `text_edit`；RS **无** `turn_into` Op / 无读该 attrs 改 kind。MD 前缀「能绿单测」**不能**改权威 kind。
3. **A/C/E 空态默认「只展示读路径」** — hydrate 三态通、PaperList/mirror 条/slash 写 **均 opt-in**。交叉时易被当成「纸面全栈已挂」；实际产品默认 = **只读投影 + chrome 皮**，写锥/窗口虚拟化/镜像 **未同屏默认连通**。

| **③ 若有红断点** | **3** | 须先裁定或硬门禁，禁止用单文件绿测关叙事 |

## 1. 链 A · hydrate 产品默认

```

  │    → adaptNoteHydrateIpcAsTransport
  │    → invoke note_document_hydrate
  │         apps/agent-workbench/src-tauri/src/note_commands.rs

  │         → JSON source="tauri-ipc"
```

### 1.2 连通判定：**🟡 半连通**

| 段                               | 状态    | 证据                                                                                                     |

- **无**「真 Tauri WebView 打开空态 → 真 workbench 命令 → 真 store 块」e2e（有 RS 命令测 + 前端 mock IPC）。

- **A-X1**：`createProductStrictHydrateTransport(isTauri=true, 真/录制 backend)` → Strict 面板 `data-hydrate-source=tauri-ipc` + 空/失败 DOM 三态（跨 React+adapter，禁只测纯函数）。
