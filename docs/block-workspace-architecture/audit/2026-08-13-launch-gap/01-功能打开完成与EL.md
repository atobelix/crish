**因此「打开面板后投影非空」缺的是整条产品句，不是缺一个 `expect(blocks.length>0)` 单测：**

2. **真运行时**：`isNoteTauriRuntime()===true` 且 `try_store_backend()` 已安装（`note_runtime.rs:116–133` `init_default`；失败不阻断启动 → 可能 `unwired_failure`）。
3. **分轨探针**：`data-hydrate-source=tauri-ipc` **且** `data-hydrate-path=doc-session` **且** `data-block-count≥1` **且** 块 id **≠** `empty-strict-*`。
4. **G-HYD-2 最低验收**：同文档 `outline` / `get_md` / 投影文本 ≡ persist 的内容（09 `:114`）。
5. **层**：须 **真 WebView / 真 IPC**（或可信 Tauri 夹具）。jsdom + `createMockNoteHydrateIpc` **不算**（`w5b_*` 测头已自钉）。
6. **冷开加深（可选同包或下包）**：关进程重开同一 `workspace.db` 再点开，投影仍非空（库内 `hydrate_document_cold_*` **≠** 本句）。
