## 1. 对用户问题的直接回答

**质量分层，不能一刀切：**

| 层                     | 判定                                                                                                                                                          |

### 1.2 「是不是每轮 agent 都缝缝补补没按文档？」

**部分属实，主责在主控派单，不全在执行 Agent：**

| 原因                 | 说明                                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **派单缩水**         | `plans/09` 要求每包强制附 15/00/0N/D-stack/接口/验收 ID；前序 Round **经常只给摘要清单**，未强制「先读计划再改」。 |
| **无第二通道**       | 子 Agent **不会**自动加载 `docs/block-workspace-architecture/**`；只有提示词 + 全局 Agents.md。                    |
| **执行侧仍有真交付** | 在摘要任务下，不少包仍写出可运行实现；问题是 **边界被任务书偷换**（W6-A→抽样、W6-C→结构门 TBD）。                  |
| **伪完成高危点**     | 不在「没写代码」，在 **用验收 ID 锚测名却不交付语义**（如 A-MEM-04 / A-COL-04 undo）。                             |

## 3. 伪完成 / 上限塌风险清单（优先焊）

按「不做就会把后续全盖在演示真相上」排序：

1. **结构持久化空心**（G1）：`EncodedUpdate` 结构 = `rev` 字节；无 `DocSession::hydrate` → SQLite「权威」不可恢复树（01+02+04 交叉确认）。
2. **Undo 缺失却挂 A-\* ID**：A-MEM-04 / A-COL-04 / plans/01 undo（01 🚨）。
3. **写锥泄漏**：`pub tree`/`rev`；`apply_remote_text_update` 旁路 persistence；`on_committed` 失败不回滚（01）。
4. **Intent 主路径 mock sink**：块纸面未进真 `DocSession.apply`（03+05）。
5. **文本叶无 ProseMirror**：W3-D 名实不符；叶子核锁禁止（03）。
6. **W6 包号定义性缩水**：调度/进度文件挂 W6-A/C/D 于抽样/TBD/子集（05）。
7. **并发 move 无 Lamport 破环** + Loro oracle 不对照自研（01）。
