## 1. 总判

**Wave 2 在「派生索引 / 契约视图 / 受限 query / Conex-MD 结构-only」层面有可运行的 crate 实现与较厚测例，但尚未闭合 S1「杀进程可恢复的权威」；外部改盘三路与 refs 自动物化几乎空白。整体评为：索引与 MD 契约骨架偏实，权威可恢复性与 W2-E/F 物化闭环偏虚。**

## 3. 严重缺口（按效果锁排序）

### G1 · 权威不可 hydrate（S1 / A-COL-05 / A-INV-04 / X-04）— **致命**

- **事实**：`DocSession::apply` 写入的 structure update 为 `rev.to_le_bytes()` 占位（`conex-doc-collab/src/session.rs` 约 438–442 行注释「结构侧尚无独立 CRDT encode」）。
- **事实**：`WorkspaceStore::on_committed` 忠实地把占位字节 append 进 `doc_updates`，`compact_snapshot` 做 length-prefix 拼接——**正确落库了无语义载荷**。
- **事实**：`conex-note-runtime` `ensure_session` 明文：`结构 CRDT 字节现为 rev 占位，不能从 blob 重建树；会话树在进程内累积`（`store_backend.rs` 约 111–127 行）；`load_doc` 仅「触达」校验。
- **效果**：杀进程后 SQLite 有「权威」行，**内存 BlockTree 无法恢复**；派生 `blocks` 亦非 hydrate 入口。与 `15`§4「权威 = RS 内存树 + SQLite(snapshot+updates)」及 `02`「杀进程可恢复」**直接冲突**。
- **归类**：根因在 W1 encode/hydrate，但 W2 若宣称「存储落盘完成」即 **虚标**。W2 索引再建得再好，也挂在不可恢复的树上。

### G2 · 外部改 mirror 三路 / watcher / X-05 — **高**

- 计划：`02` P6 状态机；W2-E 验收 A-INV-02 + X-05 骨架。
- 实现：仅有 `export_md_mirror` + `pending_lag`；`lib.rs` 将 watcher/三路标为「后续扩展点」。
- **零** detect API、零 import 路径、零「禁静默盖 unpushed op」测。
- A-INV-02 / X-05 = **未交付**（缺测=未交付）。

### G3 · refs 未随投影物化 — **高（Logseq 维蒸发风险）**

- `apply_projection_diff` 文档写「投影到 blocks / FTS / **refs** / mirror lag」，但 upsert 路径 **从不** `upsert_ref`；仅 remove 时删边。
- `refs.rs` 自承：「本波次仅 upsert/query 骨架；正文解析抽边留给后续 indexer」。
- `query_blocks` 的 `ref_to`/`ref_from` **依赖手工灌边**；无边则查询永远空 → A-QRY-01「refs 路」产品上不可用。
- 评审 P2（受限 query 防蒸发）只闭合了 **query API 形态**，未闭合 **边从何来**。

### G4 · 栈锁 markdown-rs 未接线 — **中高（契约真源）**

- `15`§3：MD = `markdown-rs`。
- `conex-md-ast/Cargo.toml`：**无** markdown-rs 依赖；手写行解析（`parse.rs` 自承「W2 后续可换」）。
- 后果：GFM 边界（嵌套列表缩进、表格真 AST、HTML 块等）与锁定栈漂移；A-MD-01 全表不可关。
- 当前 golden 覆盖：段落/标题嵌套/列表/引用/plain 中文 emoji 等 **子集**。

### G5 · Schema 与计划漂移 — **中**

| 计划（02）        | 实现                                   |
| ----------------- | -------------------------------------- |
| `peer_clocks`     | `doc_clocks`（可接受改名，须文档对齐） |
| `outbox`          | **缺失**（A-COL-05 上线收敛缺挂点）    |
| CAS GC / `blobs/` | 仅注释扩展点                           |
| backup 钩子       | 未见                                   |

### G6 · `text_touches` 在 store 投影中未单独消费 — **低中**

- `ProjectionDiff.text_touches` 存在；`apply_projection_diff` 只处理 upserts/removes/full_rebuild。
- 若 collab 某路径只填 `text_touches` 不填 upsert plain_text，FTS 会陈旧。当前 session 路径 TextEdit 会 upsert（旁证 session），**依赖隐式约定**，缺「仅 touch」回归测。

### G7 · 性能维未钉 — **中（门禁口径）**

- A-PERF-10/11：无基准语料、无 P95、无 CI 数值门。
- CJK `instr` 全表扫在大 doc 下是已知逃生条件（`fts-chinese-baseline.md`），**尚未**有规模测证明可接受。

## 6. 补做包（问题同权；按效果完整度排列，非工期）

### 包 R2-A · 结构权威可 hydrate（解锁 S1 / 跨波）

- **文件域**：主 `conex-doc-collab`；store framing 与之对齐；note-runtime 去掉「不能重建」逃逸注释。
- **验收**：X-04 / A-INV-04 / A-COL-05 子集自动化；禁止继续 `rev` 占位作为唯一 structure payload。
- **说明**：无此包，W2 其它工作无法支撑「落盘完成」。

### 包 R2-B · 外部改盘状态机（W2-E 补完）

- detect（mtime/hash vs `mirror_meta`）→ 分类 → 三路（保留 unpushed re-import / 丢弃未 ACK / 冲突块）→ **禁止默认 fullRemount**。
- 联测 X-05 最小骨架。
- 验收：A-INV-02。

### 包 R2-C · refs 自动物化

- 投影或独立 indexer：从 props / 正文 wiki·块链语法抽 `block_refs`；upsert 与 remove 同事务。
- 与 `query_blocks` ref_* 端到端测（非手工 seed）。
- 验收：A-QRY-01 refs 路真实数据。

### 包 R2-D · markdown-rs 基座替换（或书面改锁）

- **效果锁路径**：parse 换 markdown-rs AST 再映射 BlockIR；golden 扩 GFM 核心；保留 `<!--c:ID-->` 落位。
- **若坚持手写**：须修订 `15`/D7 栈锁并主控确认——Agent 不得默许漂移。

### 包 R2-E · CAS 最小可用

- 可选外置 `blobs/{hash}` 大文件；未引用 GC；删块 unlink + GC 测。
- A-PERF-11 先结构门（不塞 snapshot）再数值。

### 包 R2-F · outbox / clocks 命名对齐

- 计划 `outbox` 与 A-COL-05 上线收敛；或显式降级文档并改验收映射。
- `peer_clocks` 命名统一。

### 包 R2-G · 投影完备性钉死

- `text_touches` 无 upsert 时行为契约 + 测。
- `apply_projection_diff` 文档删除「refs 全量投影」虚写，或实现真正 refs 同步。
- 「裸 apply 无 index」文档化 fail-closed 或强制在 plugin 侧双写（慎选，避免第二写语义）。

### 包 R2-H · 性能与中文检索规模

- 固定中文语料下 instr P95；不达标才触发 tantivy 侧车（已有 baseline 逃生条件）。
