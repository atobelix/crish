## 4. `send_to_note`：是否禁止静默缝合

### 4.1 正面（纪律落地）

| 层                   | 行为                                                                          |
| -------------------- | ----------------------------------------------------------------------------- |
| 规格                 | 否决 `onStreamEnd` 默认写笔记；否决 token 级 `doc_apply_ops`                  |
| 桥 `send-to-note.ts` | 注释钉死禁止静默；`assertStreamCompleted` 仅 `completed` 放行；拒绝 `lines[]` |
| 按钮                 | `canSend = status === 'completed'`；disabled 非完成态                         |
| Agent 工具           | `send_to_note` 显式参数 + `maybe_ask_note_write`；无 stream 钩子              |
| 前端 hooks/store     | **未发现** stream 完成自动 `noteSendToNote` / `document_apply_md`             |
| IPC                  | `note_send_to_note` 要求非空 `intent_id`                                      |

### 4.2 负面 / 漏洞

1. **`dispatchSendToNote` 的 `streamStatus` 为可选**：未传时**跳过**流完成守卫（注释写「可跳过」）。按钮传了 status；**任意调用方直调可绕过「未完成流拒绝」**（规格默认钉死拒绝）。
2. **按钮未进聊天消息 DOM**：产品用户**几乎无法**从完成态气泡触发；静默缝合风险低，**显式路径也未产品化**。
3. **失败幂等缓存**：失败结果也写入 intent 缓存，同 intentId 重试会被桥层直接返回失败而不再 sink——与规格「可重试（同 intentId 幂等）」在**失败重试**语义上可能过严（成功幂等 OK）。
4. **前端双重幂等**（桥 Map + 后端 intent 表）+ 后端进程内 HashMap：**重启后 intent 丢失 → 同 intent 可双插**（A-SURF-06 长期不变量未满足）。

**总判**：静默缝合在当前代码路径上**被结构禁止**；完整「完成态 → 用户一点 → 真树」产品链**未闭合**。

## 5. `StoreNoteBackend`：完整管线还是半截

### 5.1 进程内写路径（完整）

```
validate_batch_token?
→ intent 幂等命中则 return
→ ensure_session (load_doc 触达 + DocSession::new + with_persistence)
→ apply_md_fragment | append TextEdit → Ops
→ commit_ops(session, store, origin, ops)
     → session.apply  (权威 updates via PersistencePlugin)
     → index_after_apply / apply_projection_diff  (blocks + FTS)
→ 缓存 intent 结果
```

证据：`crates/conex-note-runtime/src/store_backend.rs`；单测 apply→query FTS、幂等、outline、get_md 含 `<!--c:`；`tests/x01_cross_layer.rs`。

### 5.2 半截与硬伤（必须写进审计）

| 缺口                        | 说明                                                                               | 影响                                                                           |
| --------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **结构 encode 占位**        | `conex-workspace-store` 文档：结构 update 为 rev 占位；**禁止** decode 重建索引/树 | 杀进程后 **内存树丢**；`ensure_session` 新建空树，**不**从 snapshot 恢复块结构 |
| **`get_md` 仅 session 树**  | 无 session / 空 `root_children` → `Ok("")`；**不**从投影表或 blob 重建             | 工具「即时 S」在冷启动失效                                                     |
| **读 query 可、写续接不可** | 投影/FTS 可残留；新 session 再 apply 可能与旧投影 **分叉**                         | 权威语义与索引一致性风险                                                       |
| **intent 幂等非持久**       | 进程内 `HashMap`                                                                   | 重启双插                                                                       |
| **mirror 非默认路径**       | 符合禁止默认读 mirror；但 `commit_ops` **未**走 `commit_ops_with_mirror`           | 契约 mirror 水位未自动推进（产品可后挂，须知）                                 |

**总判**：**热路径（单进程不杀）apply→commit→index 完整**；**持久 hydrate / 冷启动 / 幂等持久化 半截**。不得宣称「笔记权威库生产级闭环」。

## 11. 风险清单（按效果锁排序）

1. **EL-08 假关闭风险**：静态测子集 + Round 绿表冒充 A-SURF 全表。
2. **冷启动树丢失**：占位 encode → 权威「内存 + 半持久」；杀进程后写路径语义漂移。
