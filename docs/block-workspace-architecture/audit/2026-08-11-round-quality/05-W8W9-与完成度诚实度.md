## 6. 总评（必须二选一）

### 倾向：**地基可用，但远未效果锁**

（**不是**「结构已歪、需推倒重来」。）

### 证据（正）

1. **方向与契约未歪**：DocSession / Op / yrs 文本私有、store 编码态、Conex-MD、`query_blocks` 白名单、ImeMachine、ProjectionDiff mock、DualSessionHarness、CM6 代码叶——与 15/D7/H1–H3 **同向**，不是另一套野架构。
2. **防缩水句在关键交付物里反复出现**（intentBridge、A-BLK-progress、ime-matrix L2/L3、perf TBD 铁律、`19` 纪律行）——说明实现波 **知道**效果锁，不是全然无知冲 EL。
3. **可编译可测的地基层** 已厚于「空文档」：R1–R8 连续 `feat(block-workspace)` 落盘，非纯 PPT。

### 证据（负 · 效果锁距离）

1. **EL-01**：A-BLK 01–14 **远未**；无结构 undo；无块纸面 e2e；文本叶 **无 PM**。
2. **EL-02/静默**：chrome 模型测 ≠ 视觉/产品静默关闭。
3. **EL-03**：数值门 **零标定**；结构门 checklist 未勾；merge/写放大仍契约。
4. **EL-04**：双 peer 仅 in-process A-COL-01 加深；传输未钉（`19` 自承）。
5. **叶子核锁定（L3）**：矩阵明文禁止；IME 必测格无 e2e。
6. **跨层 X-02…06**：基本蒸发；X-01 骨架。
7. **账本分裂**：`17` 说未启动 / `19` 停 R8 / 树内 Round9 标签 —— **完成度语言不可信，须以验收 ID 为准**。

### 为何不选「推倒」

- 未发现与锁定栈 **硬冲突** 的第二套心（例如 UI 真相、Y.Doc 外泄、整嵌 PM 当文档权威）。
- 问题是 **完成度会计造假风险 + 关键链路未焊**，应用 **重钉验收账本 + 禁 W6 包号缩水 + 补 PM/e2e/数值标定**，不是烧仓。

### 主控必须立刻执行的诚实动作（审计建议，非实现）

1. **改写 `19`**：R8 交付改称「W6-C **结构门骨架**（数值未生效）」；R9 已落盘项单列「**非关闭**」；禁止再用裸「W6-A/D」不带「抽样/子集」。
2. **冻结包语义**：任何 PR 标题/commit 使用 W6-* 必须对照 `09` 原文验收；缩水交付改称 **W3-x-hotfix / W6-pre**。
3. **以 `A-BLK-progress` + `ime-matrix` + `perf-baseline` 为完成度 UI**，`19` 只链过去，禁止摘要时丢掉黄/☐。
4. **作废 `17` 实现波未启动** 或标注历史，避免双账本。
5. **下一闸真实排序（问题同权下的依赖）**：文本叶 PM 接线、Intent→真 `DocSession::apply`、结构 undo 暴露、Win WebView2 A-IME 必测格、A-BLK 真 e2e、perf 指纹+手填初值——**任一用单测冒充则记叙事事故**。
