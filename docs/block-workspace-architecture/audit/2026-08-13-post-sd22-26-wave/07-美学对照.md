## 1. 对照锚（内部真源，不引入第三套色）

### 1.1 Token / 焦点环（`tokens.css`）

| 族         | 位置                 | 值 / 含义                                                                                                      | 与 §13/§14                                        |
| ---------- | -------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 表面       | `tokens.css:10-18`   | `--bg-primary` / `--bg-secondary` / `--bg-card` 均为暖灰 `hsl(35, …)`                                          | 纸面应用 `--bg-card` 浮在 `--bg-workspace`        |
| 字色       | `tokens.css:20-25`   | `--text-primary #111` / `--text-secondary #555` / `--text-tertiary #696969`                                    | 对比度用固定 hex（注释写明禁裸 color-mix 当字色） |
| tint       | `tokens.css:31-34`   | hover **4%** / active **8%** / `--tint-focus-ring` **10%**                                                     | 焦点混入上限正好 10%                              |
| 浅色 focus | `tokens.css:63-65`   | `--focus-ring-color` = control-mix **8%**；`--focus-ring` = `0 0 0 2px`；`--focus-ring-strong` = **12%** / 3px | 常规环合规；`strong` 12% **略超** 10%             |
| 暗色 focus | `tokens.css:487-489` | `--focus-ring-color` = text-primary **30%**；`strong` **22%** / 3px                                            | **超 §13 上限**（登记；禁改 tokens）              |
| 注释纪律   | `tokens.css:1`       | 「pure neutral … no blue/purple tint」                                                                         | 空态 hover `--accent-blue` 与此冲突               |

浅色 `--focus-ring`（8%）是壳内按钮的合法默认。**全页空态落地**另走 `AGENTS.md` §13 例外：混入至多约 5%，甚至 0；对标已落地的 composer：

```27:48:apps/crish-desktop/src/components/chat-composer/ChatComposer.module.css
.container:focus-within {
  /* … */
  border-color: color-mix(
    in srgb,
    var(--border-color) 94%,
    var(--text-primary) 6%
  ) !important;
  box-shadow: none !important;
}
.container[data-empty-kind='session-empty']:focus-within {
  border-color: color-mix(
    in srgb,
    var(--border-color) 95%,
    var(--text-primary) 5%
  ) !important;
  box-shadow: none !important;
}
```

全局键盘环（`focus-visible.css:6-18`）：非 button 走 `outline: 2px solid var(--focus-ring-color)`；`button` / `[role=button]` 走 `box-shadow: var(--focus-ring)`。空态 CTA 是 `ui/Button`，因此实际吃 **`--focus-ring`**（`Button.module.css:21-24`）。

### 1.2 Shell 空态配方（`shell-polish.css`）

统一空态（跨组件全局类，`shell-polish.css:1115-1143`）：

| 槽          | shell `.emptyState*`                                                                   | 工作区 `WorkspaceEmptyState.module.css`                                              |
| ----------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 布局        | column / center；`min-height: 200px`；`gap: var(--space-2)`；`padding: var(--space-5)` | `min-height: 160px`；`gap: var(--space-4)`；`padding: var(--space-6) var(--space-4)` |
| 图标        | `--text-tertiary`；`opacity: 0.6`；**无 hover 变色**                                   | 同底色/透明度；**hover → `--accent-blue` + `scale(1.05)`**                           |
| 标题        | `--font-size-lg` + `--font-weight-medium` + `--text-secondary`                         | `--font-size-lg` + `--font-weight-semibold` + `--text-primary`                       |
| 说明        | `--font-size-sm` + `--text-tertiary`；`max-width: 320px`                               | `--font-size-base` + `--text-secondary`；`max-width: 280px`                          |
| 焦点 / 边框 | 无描边、无影、无 `:focus-within`                                                       | 同「无描边」；**同样零焦点规则**                                                     |

工作区画布本身透明（`shell-workspace.css:179-186` 把 `.workspace-canvas` 打成 `background: transparent`）。空态 **不必**再铺一张 `--bg-card`；纸面打开后由 `NotePaperPanel.module.css` `.panel` 自己做卡片。

### 1.3 空态宿主已有、CSS 可挂的 data（**不必改 tsx**）

`WorkspaceEmptyState.tsx` 已写：

- 落地：`data-empty="true"`（`:477`）
- 打开 Strict / Skeleton：`data-empty="false"` + `data-note-paper-strict` / `data-note-paper-preview`（`:350-351` / `:407-408`）

打开纸面时宿主用 **inline** 压布局（`:369-374` / `:412-417`：`alignItems: stretch`、`justifyContent: flex-start`、`padding: var(--space-3)`、`textAlign: left`）。**不要改这段 tsx**。CSS 不要用 `!important` 去打架；只补 inline **没写**的属性（`gap`、hover 范围、焦点）。

### 4.3 D3 + D5 · 落地焦点：≤5%，无粗黑边、无重影

全页空态：**宿主不画环**（光标进 CTA 已够提示）；**只**给键盘 `:focus-visible` 的按钮一条软环。

```css

  outline: none;
  box-shadow: none;
  border-color: transparent;
}

/* 覆盖 ui/Button + 全局 focus-visible.css 的 --focus-ring（暗色 30%） */
.workspaceEmptyState[data-empty='true'] :global(button):focus-visible {
  outline: none;
  box-shadow: 0 0 0 2px

}
```

约束：

- **禁止** `0 0 0 1px var(--text-primary)`、禁止厚实心黑边、禁止 `var(--focus-ring-strong)`。
- **禁止**给这条规则加生硬的 `border-color` / `box-shadow` transition（§13 落地例外）。

- 不要给空态容器加 `--shadow-md/lg`。
