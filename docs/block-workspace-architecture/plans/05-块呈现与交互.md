| **效果**   | EL-01/02：Notion 级块交互 + 静默默认                                  |

## 1. 目标模块

1. 块列表渲染（仅窗口 DOM）
2. **chrome**：把手、多选框、落点线、slash 宿主
3. **静默状态机** L0 默认
4. 叶子 **ProseMirror** 适配：仅 inline schema；`dispatchTransaction`→Intent→RS
5. 代码叶 **CM6**
6. MD 前缀快路径（非 composing）
7. turn-into / 缩进 / 拖拽（op 语义归 01）
8. 未知 flavour 占位块

## 2. 不变量

- 禁止 `serialize(pmDoc)` 持久化
- 文档 undo 不靠 PM history 当局
- PM 合格 ≠ 工作区合格（A-BLK 独立门禁）

## 3. 验收 ID

A-BLK-01…14，A-SIL-01…04，A-IME 相关 e2e

## 4. 禁止

整嵌 BlockSuite/Protyle；TipTap+Yjs；单 View 整树；行级冒充块

## 5. 可并行

假数据 chrome UI 原型可与 01 并行；**接真实键入**必须等 01+04。

## 6. 高代价正当项

完整块清单与拖拽/多选——对标 AFFiNE 完成度，允许复杂自研壳。
