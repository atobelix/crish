### 2.2 阶段门禁（可执行）

```
W3-D-S 完成 ⇔
  - TextLeaf / intentBridge / mock sink 单测绿

  - 报告明文「plain + mock」

  - package 依赖含 prosemirror-*（或锁定的等价叶子核）

  - 未完成 W3-D-PM 时，任何文档/PR **禁止**写「叶子核=PM」
  - sink 仍 mock 时 **禁止**标 W3-D 完成

  - 已满足 W3-D-PM（真 PM 入库）
  - 集成测：TextEditIntent → apply → 树/投影可观察变化（可无完整 UI）
```

### 2.3 写锥硬门槛（跨 01）
