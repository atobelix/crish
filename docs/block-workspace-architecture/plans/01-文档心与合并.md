## 1. 目标模块

1. **BlockId** 生成/校验（与 MD `<!--c:ID-->` 一致）
2. **BlockIR / Op 枚举**（insert/update/move/delete/text_edit…）
3. **DocSession**：`normalize → authz → schema → apply → events`
4. **StructureEngine**（树）+ **TextEngine**（`yrs` YText，私有）
5. **origin** 标签：user / agent / remote / system
6. **Undo** 按 origin 可过滤
7. **Awareness** 编码（presence only，不进历史）
8. 属性测试：并发 move/删祖先不产生环

## 2. 不变量

- 唯一写入口 `Transaction.apply`
- 无公共 API 返回裸 `yrs::Doc`
- 非法 schema 拒 apply，不污染编码态
- 脚手架「单写者队列」若存在，必须带 **双 peer 绿后删除** 的退出断言注释
