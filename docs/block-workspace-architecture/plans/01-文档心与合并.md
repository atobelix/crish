### 1.3 合并终局叙事（防双账本）

> 主路径 = **自研树 Op 规则 + 可编码结构状态 + yrs 文本**。
> **不是**「永远 JSON op 重放」。
> Loro 全量树 = **A-SWAP / 对照 oracle** 逃生门，不因实现难默认切。
> y-protocol 互通 = **可选兼容**（15 S5），不要求浏览器 Y.Doc 真相。

### 2.2 关键 API 形状（名称可微调，语义不可漂）

```text
// 打开 / 恢复
DocSession::hydrate(blob: HydrateBlob) -> Result<DocSession, HydrateError>
// 成功不变量：树无环、无悬挂 parent、文本登记与叶一致、rev 单调起点、时钟可观测

// 唯一用户批写入口
DocSession::apply(ops: &[Op], origin: Origin) -> Result<ApplyReceipt, ApplyError>
// ApplyReceipt: rev, tx_id, projection: ProjectionDiff, commit: CommitBatch（或已 on_committed）

// 只读（禁止可变权威泄漏）
DocSession::tree_snapshot() / block(id) / rev() / text_snapshot(id)  // 不可变视图

// 远端合入：必须与 apply 共享 commit 面（禁止独立 rev++ 且不 on_committed）
DocSession::apply_remote(updates: &[EncodedUpdate], origin: Origin::Remote) -> Result<…>
// 或：归一为 apply 内部路径；旧 apply_remote_text_update 旁路 → 废除

// Undo v1
DocSession::undo(filter: Option<Origin>) -> Result<…>
DocSession::redo(…) // 可选同波或标未交付
```

### 2.4 跨引擎事务 Tx / A-INV-09（成功定义）

#### 2.4.1 原子域

**钉死（关闭 D1-C2/C3 歧义，实现前若改须评审）**：

| 项                              | 锁定                                                                                                                                                                           |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **用户 Op + 自动 HUGE split**   | **同一原子域**：split 失败 → **整批回滚**（含用户 Op）                                                                                                                         |
| **persist（on_committed）失败** | **方案 A（默认）**：内存回滚到 apply 前快照；返回 Persist 错且 **树/文本/rev 与 apply 前 ≡**。方案 B（两阶段 prepare→persist→publish）可选，须同测等价「调用方见失败则状态旧」 |
| **禁止**                        | 返回 Persist 错但内存已新；huge 尾 split 失败留半树                                                                                                                            |

#### 2.4.2 CommitBatch 字段冻结

| 字段            | 语义                                                    |
| --------------- | ------------------------------------------------------- |
| `tx_id`         | 本批唯一；结构与文本 updates **同源**                   |
| `origin`        | user \| agent \| remote \| system                       |
| `updates[]`     | `EncodedUpdate`：Structure 与/或 Text 分条              |
| `snapshot_tick` | compact 后 snapshot 是否替换                            |
| `op_audit`      | **可选**；MV-03 删胜 / Agent 回放推荐填充；有则 ID 稳定 |

#### 2.4.3 结构 encode 字节语义（非占位）

| 项           | 要求                                                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **最低形态** | 任一可逆路径：**整树 snapshot 编码**（bincode/JSON+版本头）或 **结构 op-log 可重放至等价树** 或 **真结构 CRDT update**——**效果锁只要求可逆+可测** |
| **禁止**     | 生产路径 `structure.bytes = rev.to_le_bytes()` 作为唯一载荷                                                                                       |
| **hydrate**  | 从 `HydrateBlob.snapshot ⊕ pending` 重建 **同一** 等价树                                                                                          |
| **文本**     | 不透明 yrs bytes；冷块按 H1 rehydrate/合入快照                                                                                                    |
| **compact**  | length-prefix framing 可保留；合并后 blob **仍可 hydrate**                                                                                        |

### 2.5 hydrate 成功定义（心维硬前置）

```
load_doc(doc_id) -> HydrateBlob          // 02
DocSession::hydrate(blob) -> session     // 01 本维
  - 结构树 ≡ 杀前（structure_eq 或状态哈希）
  - 文本：热策略可懒；冷块 snapshot 可读（A-MEM-02）
  - rev/clock 单调可观测
optional: 通知 02 重建投影（若索引落后）
```

| 失败             | 行为                                                                    |
| ---------------- | ----------------------------------------------------------------------- |
| 载荷不可解码     | `HydrateError::Corrupt`；**禁止**静默 `DocSession::new` 空树当成功      |
| 部分 update 失败 | 整开失败或停在可验证 checkpoint（须文档化）；**禁止**丢弃 blob 装空会话 |

**与 02 合同**：02 在 01 未交付可逆 encode+hydrate 前，**不得**关闭「落盘完成 / A-INV-04」。

### 2.6 M1 树并发合并（规则 + 时钟）

| 规则  | 语义                                                                                                                                                  |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 标识  | 每块 `parent_id` + `fractional_index`（或等价 order）                                                                                                 |

| MV-03 | 删胜 move：目标不存在 → move **no-op + 审计**（默认规格语义）。若实现选「同批整批 schema 失败」，须 **改 `concurrent-move-rules` 并双评审**，不得静默 |

### 3.4 状态哈希（A-COL-01 可验证性）
