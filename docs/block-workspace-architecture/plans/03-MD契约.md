### 2.1 等价关系 `≡`

**计入**：块类型、块序、父子、任务勾选、表格行列与对齐、围栏语言、链接目标与标题、强调边界语义、块 ID、Conex 扩展类型与载荷。

**不计（允许 N 吞）**：行尾空格、最终 EOF 换行、无序列表 `-`/`*` 统一、有序显示策略（规格写死）、围栏反引号个数 ≥ 最小、无意义空行压缩（策略写死）。

**禁止偷渡进 N**：丢块 ID、拆合并单元格、剥数学——属 **lossy 模式** 或 bug。

### 2.2 分层说明（防「结构测关 inline」）

| 层                 | 范围                                       | A-MD-01 关系                                                                     |
| ------------------ | ------------------------------------------ | -------------------------------------------------------------------------------- |
| **块结构 RT**      | kind/父子/序/ID/表/任务列表容器语义        | 本波主关闭面                                                                     |
| **叶子 inline RT** | 强调/链接等富文本 vs plain `text_snapshot` | **分期写清**；禁止用结构-only 测关闭 inline 全文 RT；依赖 01 TextEngine 投影策略 |

**列表模型（现状钉死）**：列表 **项** 为块（BulletItem/OrderedItem）；无独立 List 容器——与当前实现一致。若未来要 List 容器，**单独立项**，不静默改 P 语义。

### 3.4 API 形状（对齐 D3 §7.3）

```text
parse_md(md, ParseOpts { mode, strict_ids }) -> Result<(BlockTree, LossyReport)>
serialize_md(tree, SerializeOpts { mode, emit_ids }) -> Result<(String, LossyReport)>
normalize_md(md) -> String          // 或 normalize 规则作用于树/源，规格写死入口
normalize 幂等：N(N(x)) = N(x)

apply_md_fragment(target, parent, md, opts)
  -> Result<ApplyReport { ops, lossy, new_ids }>
// 继续：不 mutate target；IdConflict / UnknownParent → 整批 Err
// document_to_md(tree) ≡ serialize_md(conex, emit_ids=true)  Agent 读捷径
```

| 成功                             | 禁止                                          |
| -------------------------------- | --------------------------------------------- |
| 空片段 → 空 ops                  | 尽力插入半树                                  |
| 合法 ID 复用；文档内冲突整批失败 | apply 路径丢弃 lossy 不透出（Agent 不可审计） |
| 与 `DocSession::apply` 形状联测  | md-ast 内直接 mutate 树权威                   |

### 3.5 normalize 规则表（最低集 · 实现可扩展但须测）

| 规则 | 行为                                                                     |
| ---- | ------------------------------------------------------------------------ |
| N1   | 行尾空格 strip                                                           |
| N2   | 文件末恰一个 EOF 换行（或规格钉「无」——二选一写死，默认 **保留单换行**） |
| N3   | 无序列表标记统一为 `-`（S 侧）                                           |
| N4   | setext 标题 parse 可接受；**S 只出 ATX**                                 |
| N5   | 缩进代码块 parse 可接受；**S 只出围栏**                                  |
| N6   | 围栏长度 ≥ 内容所需最小                                                  |
| N7   | **不**把丢 ID / 扩展降级算进 N                                           |

### 3.9 结构 IR 与无损往返（2026-10-28 · Phase 6）

**BlockKind 扩展**（`conex-doc-collab::ir`）：

| kind                                | 语义                      | 载荷位置                                              |
| ----------------------------------- | ------------------------- | ----------------------------------------------------- |
| `TaskItem { ordered }`              | GFM 任务列表项            | 勾选态 `conex_md_task_checked` attr                   |
| `Code`                              | 围栏代码                  | `conex_md_code_lang` / `conex_md_code_meta` attrs     |
| `Table`                             | GFM 表格                  | `text_snapshot` = 规范化表格源（含对齐分隔行）        |
| `Math`                              | 块级数学 `$$…$$`          | `text_snapshot` = 公式源                              |
| `Callout { kind }`                  | GFM alert / callout       | `text_snapshot` = 去掉 `[!KIND]` 的正文               |
| `FootnoteDefinition`                | 脚注定义                  | 标签 `conex_md_footnote_label` attr；正文 `text_snapshot` |

- 可变状态（勾选、语言、脚注标签）放 attrs，不进 kind，避免每次变更触发 turn_into。
- `from_flavour` 只映射编辑器已知 flavour（含 `task` → `TaskItem`）；Table/Math/Callout/Footnote 由 Markdown lowering 产生。

**嵌套规则**：

- 列表项 / 引用：按 mdast 显式缩进嵌套为父子；同/不同秩不再拍平。
- 标题：保留 Conex 章节约定——更高级标题挂到上一标题下，同/低级标题回上级。
- 首段文本进容器节点 `text_snapshot`，其余子节点成为子块。

**序列化缩进**：

- 列表子块：bullet 缩进 2 空格；ordered 缩进「序号位数 + 2」。
- 引用 / callout 子块：`> ` 前缀；容器内空行保留 `>`。
- 脚注定义子块：4 空格。
- 标题章节子块：不缩进（由 parse 侧章节栈重组）。
- 段落 / 引用首行若形似块级结构（`#` / `>` / 列表 / 围栏 / HTML / 脚注 / alert / 强调 run），
  S 必须转义或实体化，保证 `text_snapshot` 与结构双往返。

**仍为有损**：inline 富文本（强调 / 代码 span / 链接目标）、链接定义、frontmatter；
HTML 不升格结构块。以上差集在 `LossyReport` 中显式记录（inline 属已知模型边界，不刷 note）。
