## 1. PersistencePlugin（01 ↔ 02）

```rust
// 语义草稿 — 落 crate 时编译为 trait
trait PersistencePlugin: Send + Sync {
    /// 打开：snapshot ⊕ pending updates → 交给 DocSession hydrate
    fn load_doc(&self, doc_id: &DocId) -> Result<HydrateBlob, PersistError>;

    /// apply 成功后的提交钩子（编码 update 或 snapshot tick）
    fn on_committed(&self, doc_id: &DocId, commit: &CommitBatch) -> Result<(), PersistError>;

    /// 提示尽快 flush（可合并）
    fn flush_hint(&self, doc_id: &DocId) -> Result<(), PersistError>;
}

struct CommitBatch {
    origin: Origin,           // user | agent | remote | system
    updates: Vec<EncodedUpdate>,
    snapshot_tick: bool,
    op_audit: Vec<OpId>,      // 可选
}
```

不变量：UI/Agent **不得** 直接调 sqlite 写笔记权威。

## 2. ProjectionDiff / DocEvent（01 → 04）

```ts
// 语义草稿
type BlockId = string;

type ProjectionDiff = {
  docId: string;
  rev: number; // 单调
  upserts: Array<{ id: BlockId; props: unknown; children?: BlockId[] }>;
  removes: BlockId[];
  textTouches: BlockId[]; // 叶子文本变了，需重投
  fullRebuild?: false; // 默认禁止 true；仅灾难恢复
};

type DocEvent =
  | { type: 'projection'; diff: ProjectionDiff }
  | { type: 'reject'; intentId: string; reason: string }
  | { type: 'awareness'; peers: unknown };
```

不变量：未知块 **不推断** 变更；`fullRebuild` 默认路径计数进 A-IME-07 / A-COL-03。

## 3. MountSpec / HeightMap（04 → 05）

```ts
type MountSpec = {
  window: { startIndex: number; endIndex: number };
  pinned: BlockId[]; // 焦点 + composing
  heights: Array<{ id: BlockId; px: number; estimated: boolean }>;
};

type Intent =
  | {
      type: 'text_edit';
      blockId: BlockId;
      range: [number, number];
      insert: string;
      intentId: string;
    }
  | { type: 'op'; ops: unknown[]; intentId: string };
```

不变量：composing 块必须在 `pinned`；卸载焦点块 = 违规。
