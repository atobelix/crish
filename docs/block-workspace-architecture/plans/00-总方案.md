## 1. 产品效果（集大成，不偏科）

做 **AI 工作栈上的块笔记纸面**，效果同时覆盖：

| 来源     | 取                                      |
| -------- | --------------------------------------- |
| AFFiNE   | 块交互完成度、扩展分轨、远端选区体验    |
| AppFlowy | RS 心、协同沉底                         |
| 思源     | 块 ID、事务、Agent/MCP 工具面、AST 纪律 |
| Logseq   | 块引用 / 受限 query 思想                |
| Anytype  | 心壳切分                                |
| Typora   | 默认静默写作                            |
| 本仓     | Agent 运行时 + Tauri + 行级流式引擎     |

**不要**：只做协同、只做 PKM 双链、只做原生写作、只做聊天 MD。

**可以高代价**：文档级虚拟化、混合 CRDT 壳、完整 MD 往返、块清单全绿、WebView IME 矩阵——这些直接抬性能/体验上限。

**效果锁（15 §2，本方案不得降级）**：EL-01…EL-10 全文仍有效；关闭条件见 `08`，**只引用 Strict 包 ID**。

## 2. 架构图（方向未歪，保持）

```
┌─ TS 皮 ─────────────────────────────────────────────┐
│ 块壳(chrome/slash/多选) │ 叶子 PM/CM │ 行级聊天引擎   │
│ SelectionBroker │ 窗口虚拟化 │ 扩展 View 贡献       │
└──────────┬──────────────────────────┬───────────────┘
           │ Intent / Tool call       │ 投影 Diff
┌──────────▼──────────────────────────▼───────────────┐
│ Rust 心：DocSession.apply（唯一写）                   │
│ 树 Op 壳 + yrs 文本 │ BlockIR │ MD P/S │ 权限/origin │
│ Persistence(sqlite) │ Indexer(FTS) │ CAS │ outbox    │
│ 笔记 ToolRegistry ← session-loop 审批                 │
└─────────────────────────────────────────────────────┘
壳：Tauri IPC / 窗口 / OS —— 不持文档
```

**合并终局叙事（钉死，防双账本）**：

> 主路径 = **自研树 Op 规则 + 可编码结构状态 + yrs 文本**；**不是**「永远 JSON op 重放」。  
> Loro 全量树 = **A-SWAP / 对照 oracle** 逃生门，不因实现难默认切换。  
> y-protocol 互通 = **可选兼容**（15 S5），不要求浏览器 Y.Doc 真相。

## 7. 多 Agent 派发规则

### 7.1 通用

1. 每任务书含：**目标效果、不变量、输入文档、产出路径、文件域、验收 ID、禁止事项、Strict/Skeleton 轨声明**
2. 同文件域串行；不同文件域可并行（同时未终态 ≤16）
3. 空返回：查落盘 → 原样重派（不缩短提示词）
4. 发现效果缩水 / 第二写路径 / 伪 A-\* → **上报主控**，禁止私自降级
5. **计划文档 ≠ 已注入**：唯一可靠通道是 **prompt 强制列表 + 要求先 read_file**（20 L1）
6. **没有第二通道** 自动加载本目录文档（20 L2）

### 7.2 文档可见性（对齐 20 §3 · 正式实现窄读）

| 角色                      | 可读                                                                    | 禁止                                                                                 |
| ------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 审计 / 分析 / 方案 / 评审 | 宽读：15/18/00–09/interfaces/specs/acceptance/audit/round-D·E；代码只读 | 擅自改业务代码（按任务书）                                                           |
| **正式实现**              | **仅** prompt 列出的窄集（见 `09` §强制文档集）                         | 自由翻 `audit/**`、竞品 round-A/B/C、全卷 specs「找灵感」；以「继续 Round」代替读 0N |
| 提交专用                  | git 范围 + 本包自检表                                                   | 改验收定义；`--no-verify`                                                            |

### 7.3 实现 Agent 强制文档集（每包必贴路径）

| #   | 文档                                       | 说明                                     |
| --- | ------------------------------------------ | ---------------------------------------- |
| 1   | `plans/00-总方案.md`（本文件）             | 总维度、门槛、库存态度                   |
| 2   | `plans/0N-*.md` **仅本维**                 | 一本，不塞邻维全文                       |
| 3   | `15-评审后锁定修订.md`                     | 效果锁                                   |
| 4   | `18-…H1H2H3M1.md`                          | **仅当**包触及 H1–H3/M1/M2… 或补丁条     |
| 5   | `20` **§1 教训 + §3.2 窄读**               | 防缩水元规则                             |
| 6   | `plans/08` **本包相关 EL 行 + 验收 ID 段** | 可摘录进 prompt                          |
| 7   | 本包依赖的 `interfaces/*`、`specs/*`       | **列路径**，不给整个 specs 目录          |
| 8   | **本包 A-\* / X-\* ID 列表全文**           | 必须出现在 prompt 或单一 acceptance 文件 |
| 9   | **Strict vs Skeleton 声明**                | 本单是 `Wn-X` 还是 `Wn-X-S`              |
| 10  | 对照审计缺口 ID（若本包负责关闭）          | **只贴编号+一句**，不附整份 audit        |

**禁止**：用「交付清单摘要」代替强制阅读列表。

### 7.4 方案/评审 Agent

- 可读分析与审计全卷；**只写/改方案文档**（本再生任务范围）
- 不得改 `crates/` / `packages/` 业务代码；不得 git commit；不得嵌套派发
