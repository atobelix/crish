## 1. 产品效果（集大成，不偏科）

做 **AI 工作栈上的块笔记纸面**，效果同时覆盖：

| 来源     | 取                                      |
| -------- | --------------------------------------- |
| AFFiNE   | 块交互完成度、扩展分轨、远端选区体验    |
| AppFlowy | RS 心、协同沉底                         |
| 思源     | 块 ID、事务、Agent/MCP 工具面、AST 纪律 |
| Logseq   | 块引用 / 受限 query 思想                |
| Anytype  | 心壳切分                                |
| Typora   | 默认静默写作                            |
| 本仓     | Agent 运行时 + Tauri + 行级流式引擎     |

**不要**：只做协同、只做 PKM 双链、只做原生写作、只做聊天 MD。

**可以高代价**：文档级虚拟化、混合 CRDT 壳、完整 MD 往返、块清单全绿、WebView IME 矩阵——这些直接抬性能/体验上限。

## 6. 多 Agent 派发规则

1. 每任务书含：**目标效果、不变量、输入文档、产出路径、文件域、验收 ID、禁止事项**
2. 同文件域串行；不同文件域可并行
3. 空返回：查落盘 → 原样重派
4. 发现效果缩水 / 第二写路径 → **上报主控**，禁止私自降级
5. 实现波启动前：读 `15` + 本总方案 + 本维度全文

---

## 7. 明确不在本方案默认范围（后挂，不污染纸面）

无限画布默认开、DB 视图默认主路径、对象 OS 全量、企业 ACL 完整产品化——**接口可预留**，默认纸面仍是块文档 + AI 工具。
