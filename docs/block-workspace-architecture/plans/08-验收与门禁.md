## 0. 执法总则（加厚 · 不可删）

### 0.1 缺测 = 未交付

| 规则         | 说明                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| **定义**     | 某 A-\* / X-\* 无对应可执行测（或测未覆盖断言语义全文）→ 该 ID **未交付**  |
| **禁止**     | 用类型能编译、常量存在、注释写了 ID、Round 测数、「差不多」关闭验收        |
| **关闭证据** | 仪表盘表 B：断言 ID → **测路径::测名** + 语义状态=真绿                     |
| **半绿**     | 骨架测 / L1 / mock / 属性抽样 → 可记 **Skeleton 支撑**，**不得**标断言关闭 |

### 0.2 产品挂载 ≠ 交付

| 规则         | 说明                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| **定义**     | Workbench / NotePaper / 路由可点可写 **≠** 任何 EL 关闭                |
| **禁止**     | W5-B、假数据 chrome、半 transport 冒充 EL-01/08 或「块工作区完成」     |
| **宣称完成** | 必须附：**A-BLK 报告 + A-INV 报告**（仪表盘表 A 已关行 + 表 B 真绿集） |
| **表 H**     | 挂载入口台账「可关 EL」列对未关 EL **恒为否**                          |

### 0.3 伪 A-\* 禁令（S3）

| 规则                             | 说明                                                                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **定义**                         | 测名 / `pub const A_*` / 进度标题 **挂验收 ID**，但语义不符文档断言全文                                                                    |
| **已知高危（须处置）**           | A-MEM-04（测 reheat 冒充 undo 跨冷）；A-COL-04（Origin 枚举无 undo 过滤）；结构 encode 占位挂 A-INV-09b/A-COL-05；Loro 自测冒充对照 oracle |
| **处置（二选一，禁止长期挂着）** | **(1)** 补满语义并保留 ID；**(2)** **撤销/改名 ID 锚点**，状态改 🟨 缺口直至真交付                                                         |
| **会计**                         | 伪完成 = 未交付，且登记表 I（事故）；**🚨 默认阻塞对应 EL**                                                                                |

### 0.4 关闭证据铁律（08-P1）

宣称 **EL 关闭** 当且仅当：

1. 仪表盘 **表 A** 该 EL 行状态 = 已关闭；且
2. **表 B** 该 EL 断言族真绿集合非空且可点测路径；且
3. 关闭包为 **Strict**（无 `-S`），且满足 §1.0「关闭不得早于」；且
4. **禁止**单独用：Round 完成、vitest 计数、「门禁绿」、裸 W6-\* 进度标题、Skeleton 包完成。

### 0.5 Skeleton 包禁入关闭列（08-P4）

- `Wn-X-S` **不得**出现在「关闭不得早于」列。
- Skeleton 合法交付：类型/接口/假数据/L1/mock/结构门常量/文档矩阵/契约抽样。
- **Skeleton 完成 ≠ Strict 完成 ≠ EL 关闭**（与 `09` 铁律一致）。
