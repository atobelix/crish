# M1 · 并发 move 规则表（Wave 0 钉死）

见 `18` §M1。本文件给属性测用例 ID。

| 用例 ID | 场景                        | 期望                                 |
| ------- | --------------------------- | ------------------------------------ |
| MV-01   | 同父并发 order 插入         | 全序稳定；无环                       |
| MV-02   | A→B 子 与 B→A 子 并发       | 按 Lamport 破环；落地后无环          |
| MV-03   | delete(A) ∥ move(B under A) | A 删胜；B 回退或 no-op+审计          |
| MV-04   | move 到自身子孙             | 拒 / 破环规则一致                    |
| MV-05   | 跨文档粘贴                  | 新 BlockId；文本拷贝；无共享引擎句柄 |

实现：`conex-doc-collab` 单测逐步变绿；Loro oracle 对照见 W0-L。
