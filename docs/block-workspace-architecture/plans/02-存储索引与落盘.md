### S1 落盘（不可推翻，抄自 15§4）

1. 权威 = SQLite snapshot+updates（+ RS 内存树）
2. Conex-MD mirror = 人/git 视图，非第二写入口
3. 工具默认读 = 即时 S(树) / 编码态导出
4. 外部改 mirror = 检测+三路；禁静默盖 unpushed op；禁默认整树 remount
5. mirror 延迟水位可观测

### 外部改盘状态机（P6）

`detect → 分类(仅mirror/权威库/双变) → 三路(保留本地op并re-import | 丢弃未ACK | 冲突块) → 禁止默认 fullRemount`  
联测：X-05。

---

## 1. 目标模块

1. Schema：`doc_snapshots` / `doc_updates` / `clocks` / `peer_clocks` / `outbox`
2. `blocks` 派生表 + attrs/refs
3. **FTS5** 全文 + 属性过滤
4. **CAS** `blobs/` + 引用表 + GC
5. **MD mirror** 导出器（调 03 的 S()）与外部改盘 watcher
6. WAL、迁移、备份钩子（复用本仓 rusqlite 纪律）
7. 打开路径：snapshot ⊕ updates → hydrate DocSession

## 2. 不变量

- 笔记库 **不** 与 sessions 库混库
- 索引损坏可重建，文档仍可开
- 工具默认 **不** 读可能陈旧的 mirror 文件

## 3. 验收 ID

A-COL-05，A-PERF 打开/搜索维，A-MD 导出一致，外部改盘三路测

## 4. 禁止

纯 FS MD 当局；附件塞进 snapshot 默认；JS/IDB 桌面唯一持久

## 5. 与 01/03 接口

- 01：`on_committed(encoded_update | snapshot_tick)`
- 03：`serialize_document(tree) -> Conex-MD`
