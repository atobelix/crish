## 1. 效果与不变量

### 1.1 效果（同权，缺一不可宣称维完成）

| #   | 效果句             | 闭合形态                                                     |
| --- | ------------------ | ------------------------------------------------------------ |

### 1.2 S1 落盘五条（不可推翻，抄自 15§4 / interfaces）

1. **权威** = RS 内存树 + SQLite（`doc_snapshots` + `doc_updates` + clocks…）
2. **Conex-MD mirror** = 人/git 视图，**非**第二写入口
3. **工具默认读** = 即时 `S(树)` / 编码态导出；**禁止**默认读可能陈旧的 `.md` exports
4. **外部改 mirror** = detect→分类→三路；禁静默盖 unpushed op；禁默认 fullRemount
5. **mirror 延迟水位**可观测（必要非充分：有 lag ≠ 有三路）

### 1.3 硬不变量

| #   | 不变量                                                                                      |
| --- | ------------------------------------------------------------------------------------------- |
| I1  | 笔记库 **不** 与 sessions 库混库（A-INV-07）                                                |
| I2  | 索引损坏可重建；**文档仍可开**（开文档依赖 01 hydrate——半绿不得虚标全绿）                   |
| I3  | 工具默认 **不** 读陈旧 mirror                                                               |
| I4  | UI/Agent **不得** 直写 sqlite 笔记权威                                                      |
| I5  | **派生表非权威**：`blocks` / FTS / `refs` **不得**作为 hydrate 主路径                       |
| I6  | 灾难时默认 **禁止**从投影表反客为主恢复；抢救工具须 `origin=system` 进 apply 并审计（若做） |
| I7  | 禁止纯 FS MD 当局；禁止附件默认塞进 snapshot；禁止 JS/IDB 桌面唯一持久                      |

### 1.4 权威载荷契约（与 01 共享 · 再生锁定）

| 项                        | 锁定                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------ |
| Structure `EncodedUpdate` | **禁止**以 `rev.to_le_bytes()` 为唯一生产载荷；须可逆（形态由 **01 钉**，02 **只存字节**） |
| Text `EncodedUpdate`      | yrs 不透明字节；hydrate 时按块槽合入                                                       |
| `snapshot_tick`           | compact 后 snapshot **仍可被 hydrate 理解**；framing（如 length-prefix）文档化             |
| 派生                      | 以树为准可重建；投影落后可 rebuild，**不能**代替 hydrate                                   |
| mirror                    | 非权威；export = `serialize_tree` / 03 S()                                                 |

## 2. 模块与 API 成功定义

### 2.1 目标模块

| #   | 模块                     | 成功定义                                                     |
| --- | ------------------------ | ------------------------------------------------------------ |
| T1  | Schema                   | snapshots/updates/clocks/outbox（命名见 §2.6）；迁移+WAL     |
| T2  | blocks 派生 + attrs/refs | 投影可重建；**refs 边自动来源**（非仅手工 upsert）           |
| T3  | FTS5 + 属性过滤          | 白名单 query；CJK 按 baseline；禁任意 SQL                    |
| T4  | CAS                      | `blobs/` 阈值外置；引用；**未引用 GC**；不进 snapshot 热路径 |
| T5  | MD mirror                | 原子 export + lag；**watcher + P6 状态机**                   |
| T6  | 备份钩子                 | 最小 `backup_hint` / flush 文档化文件集；或书面后置（评审）  |
| T7  | 打开路径                 | `load_doc` → blob → **01 hydrate**；杀进程测绿才算落盘完成   |

### 2.2 PersistencePlugin（形状冻结 · interfaces/00）

```text
load_doc(doc_id) -> HydrateBlob
on_committed(doc_id, CommitBatch) -> Result<()>
flush_hint(doc_id) -> Result<()>
```

| 成功                           | 失败口径                                             |
| ------------------------------ | ---------------------------------------------------- |
| append updates 与 tx_id 一致   | persist 失败须可观测；与 01 回滚策略联合（A-INV-09） |
| load 返回完整 snapshot⊕pending | **不**在 store 内假装 hydrate 成功                   |
| compact framing 稳定           | 压缩占位仍无意义——不宣称恢复                         |

### 2.3 打开路径关闭条件（T7）

```
apply(ops) → on_committed → [杀进程]
load_doc → HydrateBlob
DocSession::hydrate → 树+文本 ≡ 杀前
optional: rebuild 投影 from 树
```

| 包状态            | 条件                                                                    |
| ----------------- | ----------------------------------------------------------------------- |
| **blocked-on-01** | 01 结构仍为占位 / 无 hydrate → 02 **不得**标「存储完成」                |
| **落盘完成**      | 上式自动化绿（store 集成测可先用假可逆 payload，最终对接 01 真 encode） |

**废除效果上的逃逸**：`note-runtime` `ensure_session` 丢弃 blob + `DocSession::new` 空树——实现后删除该路径与「不能 hydrate」注释。

### 2.4 P6 / 外部改盘（从扩展点升正文）

```
detect → 分类(仅mirror / 权威库 / 双变)
      → 三路(RetainLocalAndReimport | DropUnacked | ConflictBlocks)
      → 禁止默认 fullRemount
```

| API（名称可调，语义不可缩）   | 语义                                            |
| ----------------------------- | ----------------------------------------------- |
| `detect_mirror_drift(doc_id)` | mtime/hash vs `mirror_meta`；输出分类           |
| `import_mirror_proposal(...)` | 产出 **Op 批或冲突报告**；**不**直接盖 unpushed |
| 三路策略枚举                  | 上表三值                                        |
| watcher                       | FS 事件或轮询；可测注入 fake clock/fs           |
| 水位                          | `mirror_lag` **保留**为必要子句，非充分         |

验收：**A-INV-02** + **X-05**；仅 export+lag = **未交付 P6**。

### 2.5 refs 自动物化（W2-F 补完）

| 项                         | 锁定                                                                                                                                                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **边来源（第一刀主路径）** | **解析抽边**（wiki/块链语法，与 03 语法钉死对齐）**或** 显式 Ref Op / 专用 props——**实现波开前在评审钉一种可测主路径**；默认建议：**投影时从 plain_text/props 抽 wiki+块引 + 显式 Op 双源最终都进表**，第一刀至少一种 e2e |
| **时机**                   | 与 `apply_projection_diff` **同事务**：upsert 出边 + remove 清边                                                                                                                                                          |
| **query**                  | `query_blocks` ref_* **端到端无手工 seed** 才算 A-QRY-01 refs 路产品绿                                                                                                                                                    |
| **文案**                   | 删除「已投影 refs 全量」虚写，或实现后改回真写                                                                                                                                                                            |

### 2.6 Schema 对齐（二选一写死）

| 计划名        | 实现现状     | **再生钉死**                                                                               |
| ------------- | ------------ | ------------------------------------------------------------------------------------------ |
| `peer_clocks` | `doc_clocks` | **A：文档与验收改称 `doc_clocks`**（不强制迁移改名）                                       |
| `outbox`      | 无           | **A：增表并与 A-COL-05 上线收敛映射**；若降级出 02 须改 08 并评审，**禁止静默删**          |
| backup        | 无           | 最小：`flush_hint` + 文档化「关进程后文件集（db/wal/shm）」；完整备份 API 可标后置但须写明 |

### 2.7 投影完备性

| 项             | 要求                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------- |
| `text_touches` | 要么 01 保证 touch 必带 plain 可投影字段，要么 02 对 touch **重读/更新 FTS**；禁止 touch 后 FTS 陈旧 |
| 裸 `apply`     | 生产 `NoteBackend` **只暴露 `commit_ops`**（fail-closed）；单测允许半接线                            |
| 索引解码       | store **不得**把结构占位当树 decode；投影以 diff 为准（库存正确规避须保持）                          |

### 2.8 CAS 最小可用

1. 默认 bytes 内联或阈值上外置 `blobs/{hash}`
2. `unlink` 块附件 + **未引用 GC** 测
3. **结构门 A-PERF-11**：附件字节 **不**进入 `doc_snapshots` 热路径
4. 数值门后置 H3 baseline

### 2.9 FTS / query

| 项           | 锁定                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| CJK          | 产品路径 `instr`；unicode61 子串 known gap **按 baseline 说**，禁止口语「FTS5 中文完美」 |
| query_blocks | 属性 + refs + fulltext 与；limit 纪律；**禁任意 SQL**                                    |
| A-PERF-10    | 结构门：走索引计划非默认全表 LIKE；数值后置                                              |

### 2.10 接口与 01/03

| 对端   | 合同                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| **01** | `on_committed(CommitBatch)`；`load_doc`→hydrate；结构字节语义见 01 §2.4.3              |
| **03** | mirror export / 工具读用 `serialize_tree` / `document_to_md`；**不**默认读 mirror 文件 |
