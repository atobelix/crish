## 0. 两轨定义（铁律 · 文首钉死）

### 0.1 轨形态

| 轨                     | ID 形态                   | 含义                                                                  | 可否宣称 EL / Wave Strict 关闭                |
| ---------------------- | ------------------------- | --------------------------------------------------------------------- | --------------------------------------------- |
| **Strict（关闭轨）**   | 保持 `Wn-X`（如 W6-A）    | 与 **历史 09 原文关闭语义同义、零降级**；唯一可映射 EL 关闭的包       | **仅**本轨完成 + `08` 条件 + 仪表盘           |
| **Skeleton（骨架轨）** | **`Wn-X-S`**（后缀 `-S`） | 允许：类型/接口/假数据/L1 单测/mock sink/结构门常量/文档矩阵/契约抽样 | **明确禁止**关 EL；完成只表示「可并行脚手架」 |

**命名规范**：

- 推荐后缀 **`-S`**；忌含糊的 `pre` / 无包号却写「W6-A 抽样完成」。
- 既有挂错号的资产：**批量改标签**为 `-S`，不回溯伪造 Strict 绿。
- commit / PR / 进度标题：Skeleton 必须带 `-S` 或明确 `sk`。

### 0.2 硬规则（不可破）

1. **Skeleton 完成 ≠ Strict 完成**；调度态必须分轨。
2. Skeleton **不得**把验收 ID 写成与 Strict 相同的「关闭句」；只挂「支撑测 / 形状测」。
3. `08` EL 表 **只引用 Strict 包 ID**。
4. **禁止**为迁就库存而改严 Strict 定义（例如把 W6-A 改成「抽样即可」）——这是把偷换 **合法化**，违反 15 EL-01 / LOGIC 效果锁。
5. 出现 S1 包号贩卖 → 拒标 Strict 完成（见 `08` §0.6）。

### 0.3 评审检查句

> 任一 PR 若使用不带 `-S` 的 `W6-*` / `W3-D` / `W3-F` 等，关闭条件是否仍等于本文件 Strict 原文？若否 → 拒合或改 ID。  
> **追加**：任一 PR 若使用 `W3-D0` / `W6-A0` / `W4-F`（分维旧号）等，**本文件是否承认该 ID**？若不承认 → **拒合或改 ID**。
