## 1. 目标

1. 定义 **surface**：`chat` | `note-paper`（枚举可引用；禁字符串串门）
2. 抽取 **editor-kit** 共享：IME 守卫接口、虚拟列表工具类型、渲染件（公式/代码）——**纪律共享，真相不共享**
3. 明确 **禁止共享**：Doc store、lines[]、PM 整树 doc、yrs 句柄、混选区 store、行 undo 跨笔记
4. 产品入口：Workbench 笔记视图挂载块纸面；聊天仍走行级
5. 门禁：架构测试「行级/chat **不可** import 笔记 DocSession 写 API」（**真扫路径见 A-SURF-03**）
6. 测试铁律：`reference/markdown-editor` `npm test` 与主仓五 e2e 专项 **禁止删除**
7. 显式桥 **`send_to_note`**：完成态、幂等、失败零半写；**streamStatus 默认拒绝未完成流**

## 2. Surface 与适配契约（关闭 E1 V4 / EL-08 形状）

### 2.1 两套模型

```
┌─ surface=chat ──────────────────┐     ┌─ surface=note-paper ──────────────┐
│ lines[] + 行缓冲 / 流式          │     │ BlockTree (RS) + 单一 apply       │
│ 消息 store（非笔记 Doc）         │     │ 块窗口 + HeightMap + pin          │
└──────────────┬──────────────────┘     └────────────────┬──────────────────┘
               │  显式 send_to_note 仅完成态              │
               └──────────── 薄桥（单向意图） ─────────────┘
```

| 场景               | 规则                                                            |
| ------------------ | --------------------------------------------------------------- |
| 流式 AI 输出在聊天 | **仅**行级缓冲；**禁止**每 token 写块树                         |
| 完成态 → 笔记      | 用户或 Agent **显式** `send_to_note` / apply_md / insert_blocks |
| 笔记内 AI 续写     | 笔记工具 / Op；**不**走行级 store                               |
| 失败               | 块树 **零半写**；chat 草稿保留；intentId 幂等                   |
| 反向               | **禁止**块树写回 lines[] 当局                                   |

全文表：`dual-engine-surface.md` §1–§5。

### 2.2 禁止共享（硬锁 NS-01…07）

DocSession 实例、`lines[]` 权威、yrs 句柄、PM 整树、混选区、跨模型 undo、HTML 反推块权威——跨 surface 共享 = **A-SURF / A-INV-03 失败**。

### 2.3 可共享（白名单 SH-01…07）

IME 守卫**思想**（实例分 surface）、虚拟列表**类型**、HeightMap 算法思想、纯渲染件、data-* 纪律、消毒、grapheme 工具。  
**editor-kit 禁止**依赖任一侧产品 store / DocSession / yrs。

## 5. `send_to_note` API 纪律（补丁级硬锁）

### 5.1 streamStatus：默认拒绝未完成流

| 项          | 锁定                                                            |
| ----------- | --------------------------------------------------------------- |
| **规格**    | dual-engine §5.4：流式未完成就发送 → **默认拒绝未完成流**       |
| **实现须**  | `streamStatus` **必填**，**或** 缺省 = **reject non-completed** |
| **禁止**    | 可选字段 + 未传则**跳过**流守卫（分析时点 API 洞 → **必须堵**） |
| **产品 UI** | 仅 `status==='completed'`（或等价）展示发送入口（B-05）         |

```
关闭 A-SURF-04/05 相关静默洞：
  - token 路径零 apply（04）
  - 无显式 Intent 时完成态不改笔记（05）
  - 未完成流 send → 拒绝（本节）
```

### 5.2 幂等与失败

| 场景               | 期望                                                                        | 跨维                                                          |
| ------------------ | --------------------------------------------------------------------------- | ------------------------------------------------------------- |
| 重复 intentId      | 第二次 no-op 或返回首次结果；**不**双插                                     | 进程内 Map 仅半；**跨进程**依赖 store 表（**plans/02 / 01**） |
| 失败               | 块树与 apply 前一致；草稿保留                                               | A-SURF-07                                                     |
| 失败是否写入桥缓存 | 规格与实现 **二选一钉死**（可重试 vs 失败亦缓存挡重试）；禁止文档与代码相反 | 实现波写进桥 README                                           |

### 5.3 静默缝合否决

| 反例                                    | 裁决           |
| --------------------------------------- | -------------- |
| `onStreamEnd` 默认写入当前笔记          | **否决**       |
| 共享 buffer 引用，块侧读 `editor.lines` | **否决**       |
| 先写 mirror `.md` 再当权威              | **否决**       |
| 聊天 HTML 反序列化成块                  | **否决**（D3） |
