## 1. 目标

1. 定义 **surface**：`chat` | `note-paper`
2. 抽取 **editor-kit** 共享：IME 守卫接口、虚拟列表工具类型、渲染件（公式/代码）
3. 明确 **禁止共享**：Doc store、lines[]、PM 整树 doc、yrs 句柄
4. 产品入口：Workbench 中笔记视图挂载块纸面；聊天仍走行级
5. 门禁：架构测试「行级模块不可 import 笔记 DocSession 写 API」
6. 测试铁律：markdown-editor `npm test` 与 e2e 专项 **禁止删除**

## 2. 适配契约（关闭 E1 V4）

| 场景               | 规则                                                                |
| ------------------ | ------------------------------------------------------------------- |
| 流式 AI 输出在聊天 | 行级缓冲；完成态可「发送到笔记」→ **显式** apply_md / insert_blocks |
| 笔记内 AI 续写     | 走笔记工具 / op，不走行级 store                                     |
| 失败               | 行级缓冲丢弃或保留为草稿消息；**不**半写入块树                      |

## 3. 验收 ID

A-INV 双引擎隔离；现有行级门禁全绿；块纸面冒烟不依赖 lines[]

## 4. 禁止
