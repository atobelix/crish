# 死层清退与契约闭环详案

## 一、领域概念与收敛目标

本方案针对二叉树布局与工作区状态机中的死层、假 Hook、空桩函数与类型断层进行彻底收敛。

* **收敛前**：存在已废弃的全局投影投影空桩函数（5 个）、被掏空的假 Hook（`useTreeDrag`）、不一致的 Context 拖拽类型强转；
* **收敛后**：单一叶级会话管理路径，彻底移除所有 `/* no-op */` 兼容桩，消除 `as unknown as` 类型断言，补齐防回归测试资产。

---

## 二、做什么（修复与增强清单）

1. **类型契约闭环**：
   * 统一 `SessionTabDragContext` 的对外签名与 `PaneHeader.tsx` 的调用参数，消除 `PaneHeader.tsx` 中的 `startSessionDrag as unknown as (...)` 强转断言；
   * 规范 `StartSessionDragArgs` 或 `(leafId: string, tabId: string, title: string, e: React.PointerEvent)` 签名。
2. **测试资产重建（防退化）**：
   * 在 `apps/crish-desktop/src/store/layout-tree/` 下补齐对 `SessionTab` 模型（叶独立会话）的完整测试（`splitTab`, `moveTab`, `removeTab`, `activateTabInTree` 等）；
   * 在 `apps/crish-desktop/src/store/workspace-shell/` 下对 `treeSessionCommands.ts` 与 `treeSessionQuery.ts` 补齐断言保护。

---

## 三、删什么（删除面与负产出清单）

1. **删除 `adapterShapeStoreOps.ts` 中的 5 个 no-op 兼容桩**：
   * `ensureChatOnlyTree`
   * `applyDockToTree`
   * `applyDockToSession`
   * `reprojectAllSessionDocks`
   * `ensureChatPlusSingleToolLeaf`
2. **删除 `storeAccess.ts` 与 `workspace-shell/index.ts` 中的对应 re-export**；
3. **清理 `SessionTabDragContext.tsx` 中的 `@deprecated` 别名与占位空操作**：
   * 移除 `startToolDrag`（工具不再参与会话树切割）；
   * 移除 `@deprecated UseTopBarDragResult`；
4. **清理假 Hook `useTreeDrag.ts` 中的无用桩代码**。

---

## 四、依赖与逻辑顺序（先删后改）

1. **第 1 步（删除）**：删除 `adapterShapeStoreOps.ts` 中的 no-op 桩函数并同步更新 `storeAccess.ts` / `workspace-shell/index.ts`；
2. **第 2 步（收敛契约）**：对齐 `SessionTabDragContext.tsx` 与 `PaneHeader.tsx` 的签名，移除强转；
3. **第 3 步（补齐测试）**：为 `SessionTab` 模型补齐针对性的单元测试。
