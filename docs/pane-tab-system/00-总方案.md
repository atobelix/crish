## 一、战役目标与重构背景

### 1. 现状痛点
1. **顶栏标签与工作区脱节错位**：全局会话标签（`GlobalSessionTabBar`）挂载在 100vw 的全局顶栏（`AppTopBar`）中间偏左，侧栏展开时标签横跨侧栏上方，与右侧工作区卡片起点完全不对齐；
2. **多窗格分屏语义断裂**：分屏时全局顶栏只有一个单行 Tab 列表，无法表达各个分屏窗格（Pane Leaf）独立的会话集合；点击未挂载 Tab 时产生“高亮激活但窗格不渲染”的假死缺陷；
3. **顶栏拖拽区被严重蚕食**：多 Tab 挤占了窗口拖拽区（`data-tauri-drag-region`），导致双击最大化与窗口移动操作困难。

### 2. 目标架构（卡片岛屿 + 独立窗格标签）
- **顶栏瘦身（`AppTopBar`）**：演进为纯净 3 段式系统窗口控制栏（Rail 侧栏开关 + Spacer 大面积原生窗口拖拽区 + Trail 帮助与系统三键），彻底剥离会话标签与拖拽上下文；
- **窗格自成窗口（`TreeLeafPanel` 头部下沉）**：每个叶子窗格顶部独立渲染 36px 的 `PaneHeader`，承载该窗格专属的会话/工具标签列表，与下方内容卡片 1:1 同宽、左对齐；
- **Demo 级高精视觉与物理动效**：26px 胶囊 Tab（6px 圆角）、激活态纯白底色（`#ffffff`）+ 细微发丝边 + 双层微阴影、220ms 弹性展开/离场动画、横向滚轮重定向与 Smart Pinning 智能固定加号；
- **声明式系统通道避让**：顶行最左窗格在侧栏折叠时自动避让 44px（macOS 106px），顶行最右窗格在 Windows 下自动避让 112px 窗口三键。

## 三、施工执行路线（实施波规划）

### 第一波：基础设施与顶栏瘦身（Core Infrastructure & TopBar Slimming）
1. 创建 `paneEdgeGeometry.ts` 并编写边界测试；
2. 瘦身 `AppTopBar.tsx` / `AppTopBar.module.css`，收缩 Props 契约，释放拖拽区。

### 第二波：窗格头部组件与卡片岛屿重构（PaneHeader & Card Island）
1. 实现 `PaneHeader.tsx` 与 `PaneTabItem.tsx`；
2. 升级 `TreeLeafPanel.tsx` 为标准两段式（36px Header + 纯白 CardContent）；
3. 注入 CSS 物理样式与 220ms 弹性动画。

### 第三波：状态机路由与交互闭环（Routing & State Machine）
1. 重构 `leafBindingHelpers.ts` 四级路由决策树，消灭分屏点击未挂载 Tab 假死；
2. 完善 Tab 新建（`+`）、关闭（`×`）、中键关闭与自愈逻辑；
3. 集成 0ms 硬件加速 Drag Card 与分屏放置。

### 第四波：全量验证与回归（Verification & CI Baseline）
1. 运行 `npm run typecheck` 保证 0 错误；
2. 运行 `vitest` 全量单测套件；
3. Tauri MCP 真机截图验证单窗格/多窗格对齐与避让效果。
