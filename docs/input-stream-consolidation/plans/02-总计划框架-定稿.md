## 4. 统一口径基线（执行轮以此为准）

- 波次命名文件 **36**（含 w5bStrict/w5bSkeleton）；`note_w4c_contribute` 实存 5 文件 ~896 行；
- `src/plugins` 纯删除 **1,347 行（实查）**；净删除总量约 **6,000–8,500 行**（评审 03 估计；E1 按实查收敛为 ~2,260）；
- kill_all 事件层 cancelled 为生产真值；persist_plugin 非双实现；
- **R1「先停后截」边界冻结机制 = 硬验收并发测试**（评审 01 最大逻辑漏洞，无方案给出冻结机制——详案必须设计）；
- 陪葬测试删除前逐项真跑确认（评审 03 §④ 清单）。
