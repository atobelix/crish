## 0. 一句话方案

把 X1 做成「**R0 前置小轮（X1b 运行产物解禁，零风险）+ 穿插功能轮间的未接线清零（X1a 三分类）+ R8 集中波次命名重命名冲刺**」三段：
运行产物禁令用 git 层面一次性解禁（保留工作区活文件），波次命名按「零引用裸测试 → 同包测试 → 生产 import 链保符号 → _batch 分诊」四批执行，未接线标记按「接线/半连通/死层」三分类收口且**禁以删注释掩盖事实**。

## 1. 做什么

### 1.0 概念目标（收敛到的形态）

- **波次命名文件 = 0**（36 → 0，脚本口径）；任何文件/模块名不再携带 `wN`/`W N` 波次标记。
- **运行产物零跟踪**（git 层 6 db → 0 跟踪，`.gitignore` 防再入，CI 有门禁）。
- **未接线标记不再用模糊话术掩盖事实**：每一条都是「已接线 / 半连通留待 / 随死层删」三态中的确定一态。

### 1.1 X1a · 未接线标记清零轮（穿插 R3/R5/R6 之间 + R8 冲刷）

> 口径：marker 基线 = `scripts/check-convergence-metrics.mjs` 当前实测 **689 文件 / 2709 行 / 2869 token**（双口径，见 §5 验收）。
> 只做三分类，**不要求本轮清零全部**——本维度的硬删除依据是「非法标记减少且每一处伴随代码事实」，不是「数字降到 0」。

| 分类                      | 判定标准                                                                                      | 处理动作                                                                                                       | 归属/时机                                             |
| ------------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| **① 已接线 → 定稿**       | 对应功能在当前轮已真跑绿、该标记所指路径已闭环                                                | 把「未接线/待接线/临时」改写为「已接线」定稿语义，或直接删除该行                                               | 各功能轮随自身删除/接线完成同步做；X1a 卫生冲刺轮补充 |
| **② 半连通 → 留待功能轮** | 对应功能仍有真实后续轮次消费面（如 note-paper hydrate、conex-browser 快照栈）                 | **不得改注释伪装已接**（违反 review §15.2 半连通诚实性）；保留原文，登记到 D0，由对应功能轮（T2/T4/V1/I1）收口 | 对应功能轮；X1a 只登记不擅改                          |
| **③ 死层 → 随删**         | 对应路径在收敛战役中已被判死（如 localStorage 轨、UserView、nudge、note_w4c、随死层测试注释） | 随死层删除一起清；删除前真跑门禁                                                                               | 各功能轮删除动作 + X1b/E1 死层删时                    |

**红线**：**禁止删注释掩盖未接线事实**。标记减少必须伴随「接线真实发生」或「死层真实删除」的代码事实，不得仅为 Δ 指标好看而删注成文（诚实性高于指标；对齐 independent-plans/06 §4.3、评审 03）。

**高频区域**（analysis/06 §② 类别 2 Top，为 X1a 冲击面）：`crates/conex-browser/src/**`（snapshot/collect.rs、frames/session.rs、snapshot/serialize.rs、browser/mod.rs、import/copy.rs、adapters/screencast_source.rs…）、`apps/agent-workbench/src-tauri/src/**`（core_run_commands_tests.rs、server/_、browser/_、sched.rs、engine_build.rs…）。这些多属「过渡待接线注释」，按三分类逐条处理。

### 1.2 波次命名文件重命名/删除（36 文件，批次 P0/P1/P2/P4）

> **硬约束（决策 13 / review §15.4 / independent-plans 06 §3.1）**：**改名不=收敛**——只允许改**文件路径 / 模块路径**，**绝不改符号名、包 ID、`-S` 轨语义**。改符号 = 假重命名 + 破 `-S` 诚实句。重命名必须同步更新 import 链并在符号层面 grep 零命中验证。

| ------ | ----------------------------------------------------------- | ---- | ------------------------------------------ | ------------------------------------- |
| **P0** | 零引用/裸测试文件名（见 §4）                                | 低   | 每包对应门禁绿                             | R3                                    |
| **P1** | 同包测试 w3f/w3d/w3e（block-paper 包内）                    | 中   | `npx vitest run` block-paper               | R3                                    |

### 1.3 X1b · 运行产物入库禁令固化（R0 前置，独立小轮）

1. **`git rm --cached` 6 个 db 产物**（保留工作区活文件）：
