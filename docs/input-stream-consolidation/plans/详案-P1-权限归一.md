> **「权限的单一权威在引擎」**：`call_verdict + decide_with_redline + ApprovalDecision` 为唯一「哪些工具需要问」的决策链，引擎 `ApprovalGateImpl::resolve` 的 pending 校验为唯一裁决/防伪造权威入口；前端只有「展示审批卡片 + 转呈用户裁决（approve/deny）」两种职责，**消除一切前端自动放行与第二套命令风险分类**；`ToolCategory` 保留为投影标签（安全判定不读类别，折中裁决）。

4. **不把 `readonly.rs` 的 spawn 时命令白名单当 per-command 判定删除**：`command_allowed_for_task_type` 是工具裁剪层，不是每命令放行判据，仅边界登记，不并链不删。
5. **不越界**：permissions.ts 唯一归 P1（E2 不重复计数）；tool-update 死契约删除归 R6/R1（非本文件域）；不碰 T1（context-state/TimelineTruncate 类型）/ R1（回滚注册表实现）文件。
6. **遵守核心模型 §7 抽象纪律**：删除/收敛面不是为「未来抽象」建层；白名单 remember 是真实用户历史存储，保留。
