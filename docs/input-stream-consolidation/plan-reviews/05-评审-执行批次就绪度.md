### 1.1 Agent 数（5-12）约束核对

- **瓶颈是「保底 5」不是「上限 12」**：几乎所有功能批的概念数只有 2-3（R1/R2/R6/R7/R8 都只有 3 个并行概念），单靠「并行 Agent」达不到 5。**需在每个功能批刻意配置 5-12**——建议按「3 并行实现 + 1 审计位 + 1 补洞/收口」固定凑数，避免为凑数硬拆概念（违反「按概念不按文件域」）。
- **R3/R4 是强串行批**，概念只有 1-2：R3 = T2-2→T2-3→T3 串行；R4 = C1a→C1b→C1c 串行。这两批更贴近「1 个概念多个 Agent 递进接力」而非并行——**批内 Agent 间是先后关系不是同时关系**，调度须按「同一文件域排队」而非「并行扇出」。可与 R3 并行的其它批（如审计批穿插）来凑 5。
- **收尾轮 R9 可不保底**（附 B-2 裁决），允许 <5。
