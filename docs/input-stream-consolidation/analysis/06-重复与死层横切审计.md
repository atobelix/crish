### 类别 4｜被 git 跟踪的运行时产物

- **`git ls-files` 中被跟踪 DB：6 个**（全部位于 `apps/agent-workbench/`）：
  - `apps/agent-workbench/sessions.db`（~2.6 MB）
  - `apps/agent-workbench/sessions.db-shm`
  - `apps/agent-workbench/sessions.db-wal`（~4.4 MB）
  - `apps/agent-workbench/workspace.db`
  - `apps/agent-workbench/workspace.db-shm`
  - `apps/agent-workbench/workspace.db-wal`（~593 KB）
- **核实**：`git status` 显示这 6 个文件**正处于被修改状态**（运行期 SQLite 在写），即活数据被误入库。
- **根因**：仓库根 `.gitignore:49-50` 写作 `/workspace.db*`、`/sessions.db*`（根锚定，只忽略根目录同名）；而被跟踪副本在 `apps/agent-workbench/` 子目录，**不命中根锚定规则** → 漏排后随提交入库。
- **无其它被跟踪 `.log` / `.bak` / `.db-journal` 等**。`Cargo.lock` 为合法锁文件，不算运行产物。
- 另注：扫描过程中发现 `apps/agent-workbench/logs/workbench.20260816.log` 等日志文件存在但**未**被 git 跟踪（运行期产物，.gitignore 已覆盖），不列入债。
