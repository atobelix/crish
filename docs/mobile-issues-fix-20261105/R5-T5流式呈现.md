## 一、逐项对账

### 施工 1：时间渐显替换空间梯度 ✅

- **新增纯函数模块** `src/domain/pure/markdown/temporalFade.ts`，替代被删的 `tailGradient.ts`：
  - `fadeAlphaAt(birth, now)`：alpha = 0.22 + 0.78 × progress^1.2，progress = (now−birth)/560ms 钳制 [0,1]——逐字、只动透明度、0.22 起、幂曲线、560ms，口径与 H 分析记录的 ai.html 参数逐项一致。
  - `partitionTemporalFade(text, tailBirths, nowMs)`：按**每字出生时刻**切分（时间维度），相邻同 alpha 字素合并（量化步长 0.04 防碎片重栅格化）；仅尾部 ≤40 字素窗口参与 O(1) 计算。
  - `withAlpha(color, alpha)`：把 alpha 乘进 color 的 alpha 通道（#rgb/#rrggbb/#rrggbbaa/rgb()/rgba() 全覆盖），输出 rgba() 字符串。
- **渲染层**（`StreamingTailText.tsx` 重写）：分段 `<Text>` 样式**恰为 `{ color: rgba(...) }`**——无 `opacity` 键、无任何附加键；基色取显式 `color` prop（代码块传 textPrimary、降级路径传 ctx.color、链接尾跨传 brand），无 prop 时回落 style 内 color。
- **空间梯度生产机制删除干净**：`tailGradient.ts` + 其测试已删；全仓 grep `TIER_OPACITIES / GradientTier / partitionTailGradient / tail-tier` = **0 命中**；旧「≤4 字不渐显」的位置模型行为一并消失（短句同样按出生时间淡入，测试已改钉新行为）。

## 三、遗留风险与登记项

1. **出生配对的近似边界**：出生登记以后缀对齐供给「最后一个文本跨」；当流式原文尾部含 markdown 语法（如未闭合的 `**`）使显示尾跨短于原文尾部时，个别字素的出生配对会偏移一两字——方向恒为偏保守（更早变实/不渐显），不会出现文字闪烁或凭空变淡；封口后整段替换不受影响。如需根治，须由解析层回传显示文本↔原文的偏移映射，超出本主题范围，登记待排期。
2. **非字符串 ColorValue 时渐显静默关闭**：基色若为动态色对象（非字符串），`withAlpha` 原样返回 → 该跨不渐显（fail-safe，不报错）。当前全部调用点传的都是主题 hex/rgba 字符串，生产路径全覆盖。
3. **性能未做真机验证**：渐显期尾跨按 32ms 节流重渲染嵌套 Text 分段（量化合并后通常 ≤6 段），逻辑上开销可控，但本批纪律为不装机——真机帧率与 Android 单次栅格化边缘效果须待整批收口装机验收时一并确认（核查报告原定的实机验收点）。
4. **清单外发现（他线在途）**：tsc 余 1 条错误在 `src/adapters/conversation/useLocalConversationEngine.queueAttachments.test.tsx(190,11)`（TS2554 参数个数）——属本地会话队列附件线（R2 域）的未提交在途文件，非本主题引入，未擅动，登记供收口代理注意。
5. 终态泄洪语义变更（见施工 2）若产品侧坚持「结束即整段定格」，需回协调者裁决；当前实现从方案口径（单路径收敛）出发。
