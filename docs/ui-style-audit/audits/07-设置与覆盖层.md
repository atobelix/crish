## ① 总评

**结论：页面骨架统一度高，行级/控件级漂移重，覆盖层基座收敛好但基座自身有暗色主题硬伤。**

1. **布局语言（页级）**：全部 Tab 均已接入 `SettingsPage / SettingsSection / SettingsRow` 共享件（含 MCP：settings-mcp/McpSettingsTab.tsx:10；扩展：settings-extensions/SettingsExtensionsTab.tsx:7），页头标题/分区标题/内容列宽（`--settings-content-max`）一套语言，复用度合格。
2. **布局语言（行级）**：共享 `SettingsRow`（padding 10px 14px）之外并存 **4 套标签列体系**（Security/Rules 的 labelCol 120px、诊断的 72/150px 网格、用量的 160px 定宽、MCP 的 24px 高密行）与 **6 档控件高度**（22/24/26/28/32/36/40px），"分区卡片 + 行 + 控件右对齐"在卡片以下没有同一套规格。
3. **表单控件一致性**：ui/Input、ui/Button 已确立标准（高 28/32、圆角锁 `--button-radius:7px`、焦点 ring 94/6 + 边框 90/10）；但 FontSelectField 手搓整套 select 绕开 ui/Select，PriceConfigModal 手搓 portal 弹窗绕开 ui/Dialog，FirstRun 按钮用 12px 圆角覆盖 Button 的 7px 锁。
4. **覆盖层族**：TelemetryDialog / FirstRunWizard / CheatsheetModal / RulesEditorDialog / SettingsPanel(全屏) 全部收敛到 ui/Dialog 基座（遮罩/Esc/焦点圈定/动画由基座接管）——方向正确；但基座 `.dialog` 背景硬编码 `#ffffff` 且全仓无暗色覆盖，暗色主题下弹窗白底，是本域最高危问题。PriceConfigModal 是唯一漏网的手搓弹窗。
5. **颜色 token 化率**：主体（SettingsUI/MCP/扩展/Schedule/QuickMenu/ExternalSessionImport）token 化良好；但 FontSelectField、FontSettingsSection、SecurityTab、RulesTab、StatusDiagnosticsPanel 存在成片 `rgba(29,28,26,…)/rgba(245,244,240,…)` 手写色值 + 手写暗色覆盖（§14 违规，且是 sep-* token 值的裸拷贝）；SettingsDevicesTab 整文件引用 **7 个不存在的 token**，靠硬编码 fallback 兜底——真源已失守。
6. **焦点态（§13）**：ui/Input、ui/Button、ShortcutsTab 录制态执行到位；但设置壳搜索框 focus 反向变弱、FirstRun 输入框 light 主题 focus 零变化、Cheatsheet 搜索 20% 混入超上限、定时任务输入借用滚动条 token（18%）当焦点环——四处不合规。
7. **Tooltip（§12）**：四目录内未发现任何原生 `title` 属性（grep 到的 53 处 `title=` 全部是 SettingsPage/Section/Row/Dialog 的 React props），悬停提示均走自定义 `<Tooltip>`，**合规**。

## ④ Top 问题小结

1. **R1 暗色弹窗白底**（Dialog.module.css:31）：影响 Telemetry/RulesEditor/Confirm 全系模态，用户可直接感知，优先修复——改一行 token 即可带平 Y1。
2. **R2/R3 悬空引用**（DevicesTab 7 个颜色 token + FontSelectField 的 `--z-dropdown-menu` + SecurityTab.tsx 的 `--color-text-secondary`）：真源失守的实证，渲染结果由 fallback 决定，主题切换即露馅。
3. **R4–R7 四处焦点态不合规**：设置壳搜索 focus 反向变弱、FirstRun light 下 focus 不可见、Cheatsheet 20% 超限、定时任务 18% 错用滚动条 token——§13 在基础库之外的实施率偏低。
4. **R8 成片 rgba + 手写暗色分支**（FontSelectField/FontSettingsSection/Security/Rules/Diagnostics 五个文件）：§14 违规集中区，且是 sep-* token 的裸拷贝，应随 B3/B4 结构性收敛。
5. **R9+Y3+Y4 基础库旁路**：手搓弹窗 ×1、手搓下拉 ×1、控件高度六档——设置中心"看起来统一"依赖页级共享件，卡片以下仍是各 Tab 方言；建议下一轮以 B1/B3/B5 三项收口。
