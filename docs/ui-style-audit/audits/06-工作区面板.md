## ① 总评

**结论先行：本域整体 token 化率与焦点态纪律是全应用较好水平，但存在四类系统性风险，其中两类已构成行为性缺陷而非纯观感问题。**

做得好的部分：

1. **焦点态合规率高（§13）**：全域普遍使用 `--focus-ring` token 或 `color-mix(border-color 90~96%, text-primary 4~10%)` 的克制混入——PreviewCard 地址栏 90/10（`PreviewCard.module.css:70-78`）、PermissionBar 90/10（`permissionBar.module.css:18-25`）、narrative 折叠头 94/6（`narrative.module.css:54-61`）、ApprovalAskCard 输入框 94/6（`ApprovalAskCard.module.css:192-196`）、NotePaperPanel 统一 94/6 焦点边（`NotePaperPanel.module.css:31-41`）。未发现任何粗黑实心边、厚重 box-shadow 违例。
2. **Tooltip 组件化程度高（§12）**：BrowserPanel（`BrowserPanel.tsx:169-219`）、ComputerPanel（`ComputerPanel.tsx:53-74`）、FlowDagView（`FlowDagView.tsx:98`）、GitStatusBadge（`GitStatusBadge.tsx:36`）、AgentStatusDot/Chip（`AgentStatusDot.tsx:42`、`AgentStatusChip.tsx:21`）、AgentCardHeader、LeafToolTabStrip 均使用自定义 `<Tooltip>`。原生 `title` 仅残存 4 处（见 🔴-1）。
3. **终端域成体系**：`--terminal-bg/fg/err/muted/border/cmd/prompt/bar-fill` 九 token + xterm 16 色 token + `--font-mono`（`tokens.css:282-308`），TerminalCard/xterm 全部经 token 取色，等宽字体一致。
4. **NotePaperPanel 是 token 化范本**：fallback 链带设计注释、焦点边统一 94/6、头部直接挂 `--card-header-min-height`（`NotePaperPanel.module.css:52-63`）。

四类系统性风险：

1. **悬空自定义属性群（最重）**：`--badge-git-*`（18 处）、`--flow-meta*` 族、`--tree-guide-rail`、`--tree-item-height`、`--tint-subtle`、`--z-drag-overlay/highlight` 在全仓（含 tokens.css 与 z-index.css）**均无定义**，「看似 token 化」的声明实际全部静默走死 fallback，其中 `--z-drag-overlay` 无 fallback 导致拖拽 ghost `z-index` 计算无效（见 🔴-2、🔴-4、🟡-1/2/3）。
2. **状态徽章语义色分裂**：同一 `failed/completed/running` 语义在 agent-card 点、agent-card 徽章/进度条、FlowDagView 节点三处配色互斥（见 🟡-8）。
3. **面板容器三种刻度并存**：36px 卡片头（PreviewCard/NotePaperPanel）、38px 叶子标签行（LeafToolTabStrip 硬编码）、无标题栏（Runtime/Browser/Computer/Terminal 实渲染），且 Runtime/Overview 面板 padding 硬编码绕过 ui-size 密度档（见 ② 表与 🟡-4/6）。
4. **暗色主题局部失效**：InlineAgentPanel 子代理流文字回退到固定深灰 hex、左侧竖轨为固定黑 rgba，暗色下对比度塌陷/消失（见 🔴-3/4）。

## ③ 问题清单

### 🔴 违规（规范红线 / 行为性缺陷）

**🔴-1 原生 `title` 作悬停提示 ×4（违反 §12「不要用原生 HTML title 作为主悬停提示」）**

| 位置 | 内容 |
|---|---|
| `components/workspace/RuntimePanel.tsx:98` | `<div role="status" … title={formatEngineStatusTitle(connectionStatus)}>` 引擎状态完整说明走原生气泡 |
| `components/workspace/LiveTasksSection.tsx:60` | 可点击任务行 `title={clickable ? '打开对应会话' : undefined}` |
| `components/workspace/TrashSection.tsx:151` | 回收站条目路径 `title={entry.originalPath}` |
| `components/workspace/SecurityAuditSection.tsx:80` | 审计条目目标列表 `title={entry.targets.join('\n')}` |

四处均为信息型悬停提示（正是 §12 要求 `<Tooltip content>` 承接的场景），且同文件族其他行已在用 Tooltip，属遗漏而非风格选择。

**🔴-2 `--z-drag-overlay` 全仓未定义且无 fallback → 拖拽 ghost 层级计算无效**

- `components/binary-tree/BinaryTreeWorkspace.module.css:300`：`z-index: var(--z-drag-overlay);`——该自定义属性在 `styles/z-index.css:1-27`（七档全表）与 `tokens.css:448-454` 中均不存在，也无 fallback → 按 CSS 规范该声明在计算值阶段无效，`z-index` 回落 `auto`，拖拽幽灵层级完全依赖 DOM 顺序兜底。
- 同源问题：`utils/dragOverlay.ts:13`、`components/shell/GlobalSessionTabBar.module.css:432`（范围外佐证）同样裸引；`SidebarSessionList.module.css:549` 则给了 fallback 1000——**同一语义 token 三处消费、三种实际取值（auto / 100 / 1000）**，是典型的「token 名义存在、契约实际缺失」。
- 配套的 `--z-drag-highlight` 同样未定义，`BinaryTreeWorkspace.module.css:262` 靠 fallback 100 生效（恰好等于 `--z-chrome`，纯属巧合对齐）。

**🔴-3 InlineAgentPanel 左侧竖轨固定黑 rgba（§14 旧式写法 + 暗色适配失效）**

- `components/agent-card/InlineAgentPanel.module.css:141`：`border-left: 1px solid rgba(0, 0, 0, 0.10);`
- 双重问题：① §14 明确「避免散落旧式 rgba」，应为 `hsl(... / 0.1)` 或直接 `var(--hairline)`；② 固定黑色在暗色主题（`--bg-primary: hsl(0,0%,5%)`）下与背景几乎同色，子代理展开流的左轨视觉上消失，明暗两套主题呈现不一致的结构线。

**🔴-4 `--flow-meta*` 字体色 token 族悬空 → 子代理流文字回退硬编码 hex，暗色主题对比度塌陷**

- `components/agent-card/InlineAgentPanel.module.css` 大量引用 `var(--flow-font-meta, 13px)`、`var(--flow-meta, var(--text-secondary, #4a4a4a))`、`var(--flow-meta-hover, var(--text-primary, #2a2a2a))`、`var(--flow-meta-soft, …#5c5c5c / #8c877d)`（`:22-24,33,62,98-99,120,129`）。
- 全仓检索确认：`--flow-meta` / `--flow-meta-hover` / `--flow-meta-soft` / `--flow-font-meta` / `--flow-summary-indent` **没有任何定义点**（conversation-flow 三个 TSX 只注入 `--flow-output-max`：`ActionRow.tsx:76`、`ThinkingBlock.tsx:56`、`SubagentBlock.tsx:28`）。
- 后果：运行时永远走 fallback——正文 `#4a4a4a`、弱化 `#5c5c5c`、提示 `#8c877d` 都是按浅色底调的固定灰，暗色主题下这些行文字亮度远低于 `--text-secondary(#a3a3a3)`，可读性显著劣化；且 `text-secondary` 这层中间 fallback 本可正确适配主题，却被外层悬空变量名拦住。属于「悬空引用 + 暗色适配」复合违规。

### 🟡 漂移（同族不同刻度 / 语义不一致 / 死代码）

**🟡-1 GitStatusBadge 徽章色全部悬空 + 偏离中性墨阶**

**🟡-10 z-index 七档双源维护**

- `tokens.css:447-454` 与 `styles/z-index.css:1-27` 同时定义 `--z-base/dock/chrome/dropdown/popover/modal/tooltip`（现值一致）；z-index.css 另扩展 sticky/sidebar/resizer/drawer/toast 六别名。双源目前无害，但任何一端调档都会静默分叉；tokens.css:477 注释自己都说「见 styles/z-index.css」。建议 tokens.css 侧删除或改为指针注释（配合 🔴-2 一并治理 z 体系）。
