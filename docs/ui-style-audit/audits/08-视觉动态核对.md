## ③ Top 问题小结

1. **动态核对覆盖率不足（流程问题，最大缺口）**：6 项清单中 2 项完全未覆盖（弹窗族、Tooltip）、3 项仅部分覆盖（缺 hover/聚焦/暗色轮），仅侧栏↔顶栏得出一条带证据的不一致观察。建议续作：复用本报告 §1.3 协议封装的客户端脚本直接续跑，优先补「暗色轮 + composer 聚焦对」两张对照截图。
2. **并行启动竞态（运行态缺陷，可复现）**：两个 `dev:workbench` 实例并发时，后到者在 MCP 绑定处 panic（main.rs:1100，os error 10048）、Vite 亦报 5174 占用——多 Agent 协作场景高发。建议：启动脚本前置端口占用检测并复用存活实例，或将 MCP 绑定失败降级为告警而非 panic。
3. **侧栏选中态 vs 顶栏全局标签页材质语言分裂**（本报告唯一完成的实质视觉判定）：同为「当前选中」，侧栏用 tint 胶囊、顶栏用白卡描边，观感重量失衡；建议统一到 tint 族或给出刻度依据（待组件级定位后收敛）。
4. **工具面备忘**：`take_screenshot` 落盘目录白名单限制（temp/home）需写入调试手册；截图取证统一走 base64 回传。
