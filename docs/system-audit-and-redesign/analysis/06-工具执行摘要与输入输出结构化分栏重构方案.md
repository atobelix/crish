## 二、标题与摘要提取缺陷深入剖析与 JSON 逃逸根因

### 2.1 缺陷一：`extractToolCommand` 键集极其狭窄且不支持双向大小写规范

在 `apps/crish-desktop/src/api/tool-presentation/toolCardPresenter.ts:42-59` 中：

```typescript
// 现存代码：硬编码的 13 个键
for (const key of [
  'command',
  'cmd',
  'path',
  'filePath',
  'file_path',
  'target_file',
  'targetFile',
  'filename',
  'file',
  'url',
  'uri',
  'query',
  'pattern',
]) {
  const v = (parsed as Record<string, unknown>)[key];
  if (typeof v === 'string' && v.trim()) return v.trim();
}
```

#### 致命漏洞分析：

1. **多生态命名法失配**：
   - **Antigravity / IDE 工具**（如 `run_command`、`view_file`、`write_to_file`、`grep_search`、`list_dir`）入参普遍采用 **PascalCase**（如 `CommandLine`、`AbsolutePath`、`DirectoryPath`、`TargetFile`、`SearchPath`、`Query`、`Action`、`TaskId`、`Instruction`、`Prompt`）。
   - **Conex Rust 内核工具**采用 **snake_case**（如 `command_line`、`task_id`、`search_path`、`start_line`、`max_lines`、`duration_seconds`）。
   - **MCP 工具**采用 `Arguments`、`toolName`、`toolAction`、`toolSummary`。
   - 上述键在现存循环中**全军覆没**，无法抽取任何主要命令或路径！
2. **嵌套参数解析深度不足**：
   - 现存代码仅简单处理了 `parsed.parameters` 或 `parsed.input`，当参数被包裹在 `arguments` 字符串（JSON 双重序列化字符串）或者 `tool_args` 中时，直接抛出异常并退回原始 raw JSON。

### 2.2 缺陷二：`extractToolCommand` 失败时的危险回退（Raw JSON 穿透）

在 `toolCardPresenter.ts:68`：

```typescript
export function extractToolCommand(args: string): string {
  // ...
  return raw; // 🔴 极度危险：当无法提取出干净的命令/路径时，直接返回完整的原始 JSON 字符串！
}
```

当 `args` 为 `"{}"`、`'{"action":"list"}'`、`'{"taskId":"task-0"}'` 时，`extractToolCommand` 直接返回整串 JSON。

### 2.3 缺陷三：`toolLabelFromArgs` 缺乏工具类型特化与字符串清洗

在 `toolCardPresenter.ts:761-847`：

```typescript
function toolLabelFromArgs(tc: MessageToolCall): string {
  const name = (tc.name || 'tool').toLowerCase();
  const cmd = extractToolCommand(tc.arguments || '');

  // ... 缺少 manage_task / background_task / schedule / set_timer / project_tree / note_* / mcp 特化 ...

  if (
    name.includes('list') ||
    name.includes('glob') ||
    name.includes('dir') ||
    name.includes('ls')
  ) {
    if (cmd && cmd !== '.' && cmd !== './') {
      const short = cmd.length > 36 ? '…' + cmd.slice(-34) : cmd;
      return `浏览 ${short}`; // 🔴 当 cmd 是 "{}" 时，产生 "浏览 {}"！
    }
    return '浏览目录';
  }

  // 兜底分支：
  if (cmd) {
    const short = basename(cmd);
    if (short && short.length < 48)
      return short === cmd ? `处理 ${short}` : `处理 ${short}`;
    // 🔴 当 cmd 是 "." 时，basename(".") === "."，产生 "处理 ."！
    // 🔴 当 cmd 是 '{"action":"status","taskId":"task-0"}' 时，short 长度 39 < 48，产生 "处理 {"action":"status","taskId":"task-0"}"！
  }
}
```

#### 漏洞连锁反应链：

1. **未过滤 JSON 定界符**：只要 `short` 长度小于 48 字符，且前置工具分支未拦截，就会无脑拼接 `处理 ${short}`。没有任何对 `{`、`}`、`"`、`[`、`]` 的拦截与校验！
2. **未处理点号与空路径**：对于 `.`、`./`、`""`、`"{}"`，未转化为“当前目录”或“项目根目录”。
3. **Shell 命令分类泛化**：`humanizeShellCommand` 规则过于死板，未对常规常见 CLI（如 `npm run <custom>`、`cargo check`、`vitest`、`git commit -m`）进行充分匹配，动辄回退为 `运行命令`。

### 3.3 绝对禁止 JSON 字符逃逸的通用安全清洗锁

为防止任何边缘情况下出现未覆盖的参数泄露，设立全局输出过滤器：

```typescript
/**
 * 最终摘要安全清洗器：
 * 1. 拦截并剔除任何以 {、}、[、] 开头或包含裸 JSON 语法的串；
 * 2. 转换孤立的 . 或 ./ 为“当前目录”；
 * 3. 截断超长字符串，确保单行高度安全。
 */
export function sanitizeHumanLabel(
  label: string,
  fallbackToolName = '工具'
): string {
  if (!label || !label.trim()) return `调用 ${fallbackToolName}`;
  let clean = label.trim();

  // 拦截裸 JSON 逃逸
  if (
    /^(\{|\[|"(action|taskId|path|command)":)/.test(clean) ||
    clean === '{}' ||
    clean === '[]'
  ) {
    return `调用 ${fallbackToolName}`;
  }

  // 替换不友好的点号路径
  clean = clean
    .replace(/\b处理 \.\b/g, '处理当前目录')
    .replace(/\b浏览 \{\}\b/g, '浏览当前目录')
    .replace(/\b浏览 \.\b/g, '浏览当前目录')
    .replace(/\s+\.\/?$/g, ' 当前目录');

  // 移除残留的 JSON 引号和括弧
  clean = clean
    .replace(/[{}\[\]"]/g, '')
    .replace(/\s+/g, ' ')
    .trim();

  return clean.length <= 80 ? clean : clean.slice(0, 79) + '…';
}
```

### 4.2 用户交互三大痛苦面

1. **输入黑盒化（Non-Shell Blindness）**：
   - 当调用 `read_file`、`grep_search`、`manage_task`、`replace_file_content` 时，展开卡片**完全不显示入参**（如读取了哪几行、搜索了什么正则、替换了什么目标代码）。用户想要核对 Agent 是否传对了参数，界面上一片空白。
2. **输入与输出无视觉界限（Boundary Blur）**：
   - 对于 Shell 工具，上方的命令仅仅带一条微弱的下边框，与下方输出文字使用几乎相同的字体字号和颜色，滚屏时命令与输出混在一起，极易造成认知混淆。
3. **缺少基础开发者交互（Missing Actionability）**：
   - 无法一键复制【输入参数 / 完整命令】；
   - 无法一键复制【完整原始输出】；
   - 无法切换结构化视图（Key-Value 属性表）与原始 JSON 视图；
   - 缺少退出码（Exit Code）、耗时（Duration）、输出大小等核心可观测性指标的分区呈现。

### 5.2 结构化渲染模式自适应规范

针对不同类型的工具参数与输出形态，提供三种响应式渲染模式：

#### 模式 A：Shell 与终端执行类（CLI Command Mode）

- **输入区**：渲染带有 Terminal 提示符（如 `$` 或 `pwsh>`）的代码高亮块，下方以标签小字展示 `工作目录 (CWD)`、`超时设置 (Timeout)`。
- **输出区**：渲染标准输出（Stdout）与标准错误（Stderr，带警告边框与颜色），支持超长行预计算 Pretext 截断与一键展开。

#### 模式 B：结构化数据与文件操作类（Structured Key-Value Mode）

- **输入区**：
  - 核心标量参数（如 `文件路径`、`行号范围`、`搜索词`、`Action`、`TaskId`）渲染为精致的 **Key-Value 键值对表格 / 徽标标签组**；
  - 大文本入参（如 `content` 写入内容、`patch` 补丁内容、`Prompt`）渲染在下方折叠代码块中。
- **输出区**：渲染文本结果、结构化表格或内置的 `ToolCallDiffPreview` Git 差异视图。

#### 模式 C：无输出/短操作类（Minimalist Empty-State Mode）

- **输入区**：完整保留入参表格或命令。
- **输出区**：以极具质感的柔和微标提示 `✓ 执行成功，无返回内容` 或 `⚠️ 任务已在后台运行中`，彻底告别粗暴的 `（无输出）`。

### 6.1 `toolCardPresenter.ts` 核心逻辑重构

重构 `extractToolCommand`、新增全健壮的 `extractToolArguments`、深度重写 `toolLabelFromArgs` 与 `humanizeShellCommand`：

```typescript
// ============================================================================
// 1. 深度健壮的参数对象提取器（支持 PascalCase、snake_case、嵌套及双重 JSON）
// ============================================================================

export interface ExtractedToolArgs {
  /** 规范化后的键值映射表（统一转为小写键索引，原键保留） */
  props: Record<string, unknown>;
  /** 提取出的核心命令/路径/动作 */
  primaryTarget?: string;
  /** 原始解析对象 */
  rawObject?: Record<string, unknown>;
  /** 是否解析出有效对象 */
  isObject: boolean;
}

export function parseToolArgsSafe(argsStr?: string | null): ExtractedToolArgs {
  if (!argsStr || !argsStr.trim()) {
    return { props: {}, isObject: false };
  }
  const raw = argsStr.trim();
  let parsed: unknown = null;

  try {
    if (raw.startsWith('{') || raw.startsWith('[')) {
      parsed = JSON.parse(raw);
    }
  } catch {
    // 处理双重编码的 JSON 字符串
    try {
      const unescaped = JSON.parse(`"${raw}"`);
      if (
        typeof unescaped === 'string' &&
        (unescaped.startsWith('{') || unescaped.startsWith('['))
      ) {
        parsed = JSON.parse(unescaped);
      }
    } catch {
      /* plain string */
    }
  }

  if (!parsed || typeof parsed !== 'object' || Array.isArray(parsed)) {
    return { props: { _raw: raw }, primaryTarget: raw, isObject: false };
  }

  const obj = parsed as Record<string, unknown>;
  // 解包嵌套层级: parameters / input / arguments
  const inner =
    (obj.parameters &&
    typeof obj.parameters === 'object' &&
    !Array.isArray(obj.parameters)
      ? (obj.parameters as Record<string, unknown>)
      : null) ||
    (obj.input && typeof obj.input === 'object' && !Array.isArray(obj.input)
      ? (obj.input as Record<string, unknown>)
      : null) ||
    (obj.Arguments &&
    typeof obj.Arguments === 'object' &&
    !Array.isArray(obj.Arguments)
      ? (obj.Arguments as Record<string, unknown>)
      : null) ||
    obj;

  const props: Record<string, unknown> = {};
  for (const [k, v] of Object.entries(inner)) {
    props[k.toLowerCase()] = v;
    props[k] = v; // 同时保留原命名
  }

  // 优先级检索核心目标（路径 / 命令 / 查询词 / 动作）
  let target: string | undefined;
  const targetKeys = [
    'commandline',
    'command_line',
    'command',
    'cmd',
    'script',
    'absolutepath',
    'directorypath',
    'targetfile',
    'target_file',
    'filepath',
    'file_path',
    'path',
    'filename',
    'file',
    'query',
    'pattern',
    'searchpath',
    'search_path',
    'action',
    'taskid',
    'task_id',
    'url',
    'uri',
  ];

  for (const k of targetKeys) {
    const v = props[k];
    if (typeof v === 'string' && v.trim()) {
      target = v.trim();
      break;
    }
  }

  return {
    props,
    primaryTarget: target,
    rawObject: inner,
    isObject: true,
  };
}

/** 抽出用于标题展示与搜索的核心参数字符串（绝对不返回未清洗的 JSON） */
export function extractToolCommand(args: string): string {
  const extracted = parseToolArgsSafe(args);
  if (extracted.primaryTarget) {
    return extracted.primaryTarget;
  }
  // 若未提取出明确主键，严禁直接返回 raw JSON 字符串
  if (extracted.isObject) {
    return '';
  }
  return args.trim();
}

// ============================================================================
// 2. 智能 Shell 命令意图翻译器
// ============================================================================

export function humanizeShellCommand(cmd: string): string {
  const full = cmd.replace(/\s+/g, ' ').trim();
  if (!full) return '运行命令';
  const unwrapped = /^(?:powershell|pwsh)\b/i.test(full)
    ? unwrapPowerShellCommand(full) || full
    : full;
  const raw = primaryShellSegment(unwrapped);
  if (!raw) return '运行命令';
  const lower = raw.toLowerCase();

  // 包管理与脚本
  if (/\b(npm|pnpm|yarn|bun)\s+(ci|install|i)(\s|$)/i.test(raw)) {
    const rest = raw.replace(/^.*\b(?:ci|install|i)\s*/i, '').trim();
    const pkg = rest.split(/\s+/).find((t) => t && !t.startsWith('-'));
    return pkg ? `安装依赖 ${pkg}` : '安装项目依赖';
  }
  if (/\b(npm|pnpm|yarn|bun)\s+add\s+/i.test(raw)) {
    const pkg = raw
      .replace(/^.*\badd\s+/i, '')
      .split(/\s+/)
      .find((t) => t && !t.startsWith('-'));
    return pkg ? `添加依赖 ${pkg}` : '安装项目依赖';
  }
  if (/\b(npm|pnpm|yarn|bun)\s+(?:run\s+)?([\w:-]+)/i.test(raw)) {
    const m = raw.match(/\b(?:npm|pnpm|yarn|bun)\s+(?:run\s+)?([\w:-]+)/i);
    const script = m?.[1]?.toLowerCase();
    if (script && !['i', 'install', 'ci', 'add'].includes(script)) {
      if (['build', 'prod', 'compile'].includes(script)) return '构建项目';
      if (['dev', 'start', 'serve'].includes(script)) return '启动开发服务';
      if (script === 'test' || script.startsWith('test'))
        return `运行测试 (${script})`;
      if (script === 'lint' || script.startsWith('lint')) return '检查代码规范';
      if (['typecheck', 'tsc', 'check'].includes(script)) return '检查代码类型';
      return `运行脚本 ${script}`;
    }
  }
  if (/\bnpx\s+([\w@/:-]+)/i.test(raw)) {
    const tool = raw.match(/\bnpx\s+([\w@/:-]+)/i)?.[1];
    return tool ? `运行工具 ${tool}` : '运行命令行工具';
  }

  // Rust & Cargo
  if (/\bcargo\s+test\b/i.test(raw)) return '运行 Rust 测试';
  if (/\bcargo\s+check\b/i.test(raw)) return '检查 Rust 编译';
  if (/\bcargo\s+clippy\b/i.test(raw)) return '运行 Clippy 审查';
  if (/\bcargo\s+build\b/i.test(raw)) return '构建 Rust 项目';
  if (/\bcargo\s+run\b/i.test(raw)) return '运行 Rust 程序';
  if (/\bcargo\b/i.test(raw)) return '执行 Cargo 命令';

  // Git 操作
  if (/\bgit\s+status\b/i.test(raw)) return '查看代码变更状态';
  if (/\bgit\s+diff\b/i.test(raw)) return '查看文件差异';
  if (/\bgit\s+log\b/i.test(raw)) return '查看提交历史';
  if (/\bgit\s+commit\b/i.test(raw)) return '创建 Git 提交';
  if (/\bgit\s+add\b/i.test(raw)) return '暂存代码改动';
  if (/\bgit\s+push\b/i.test(raw)) return '推送到远程仓库';
  if (/\bgit\s+pull\b/i.test(raw)) return '拉取远程更新';
  if (/\bgit\s+checkout\b|\bgit\s+switch\b/i.test(raw)) return '切换 Git 分支';
  if (/\bgit\s+/i.test(raw)) return '执行 Git 操作';

  // 基础文件与搜索
  if (/^(ls|dir|Get-ChildItem|gci)\b/i.test(raw)) return '列出目录内容';
  if (/^(cat|type|Get-Content|gc|head|tail)\b/i.test(raw)) {
    const file = raw
      .split(/\s+/)
      .find((p) => /[./\\]/.test(p) && !p.startsWith('-'));
    return file ? `查看 ${basename(file)}` : '查看文件内容';
  }
  if (/\b(rg|grep|findstr|Select-String)\b/i.test(raw)) {
    const q =
      raw.match(/['"]([^'"]{1,40})['"]/) ||
      raw.match(/\s(-e\s+)?(\S{2,40})\s*$/);
    const term = q?.[1] || q?.[2];
    return term && !term.startsWith('-') ? `搜索「${term}」` : '搜索代码';
  }

  // 简明命令摘要提取：若无复杂逻辑，直接提取前两个 token
  const words = raw.split(/\s+/).slice(0, 3).join(' ');
  if (words.length <= 32) return `运行 ${words}`;

  return '运行终端命令';
}

// ============================================================================
// 3. 全类别工具标题生成器（无缝覆盖所有 Conex、Antigravity 与 MCP 工具）
// ============================================================================

export function toolLabelFromArgs(tc: MessageToolCall): string {
  const name = (tc.name || 'tool').toLowerCase().replace(/[\s-]+/g, '_');
  const args = parseToolArgsSafe(tc.arguments);
  const p = args.props;

  // 1. Shell / 终端命令
  if (
    isShellToolName(name) ||
    name.includes('bash') ||
    name.includes('powershell') ||
    name.includes('exec')
  ) {
    const cmd =
      args.primaryTarget || (typeof p.command === 'string' ? p.command : '');
    return cmd ? humanizeShellCommand(cmd) : '运行终端命令';
  }

  // 2. 后台任务管理 (manage_task / background_task)
  if (
    name === 'manage_task' ||
    name === 'background_task' ||
    name.includes('task_manager')
  ) {
    const action = String(p.action || '').toLowerCase();
    const taskId = String(p.taskid || p.task_id || '').trim();
    const taskTag = taskId ? ` (${taskId})` : '';

    if (action === 'list') return '查询后台任务列表';
    if (action === 'status') return `查询后台任务${taskTag}`;
    if (action === 'read_log') return `读取任务日志${taskTag}`;
    if (action === 'send_input') return `向任务发送输入${taskTag}`;
    if (action === 'kill') return `终止后台任务${taskTag}`;
    return `管理后台任务${taskTag}`;
  }

  // 3. 文件读取 / 浏览 (read_file / view_file / cat / open_file)
  if (
    name === 'read_file' ||
    name === 'view_file' ||
    name === 'open_file' ||
    name.includes('read') ||
    name.includes('view')
  ) {
    const path = String(
      p.absolutepath ||
        p.path ||
        p.filepath ||
        p.file_path ||
        p.targetfile ||
        p.file ||
        ''
    );
    const startLine = p.startline || p.start_line;
    const endLine = p.endline || p.end_line;
    const lineTag = startLine
      ? ` (L${startLine}${endLine ? `-${endLine}` : ''})`
      : '';

    if (path) {
      return `查看 ${basename(path)}${lineTag}`;
    }
    return '查看文件';
  }

  // 4. 文件写入 / 创建 (write_file / write_to_file / create_file)
  if (
    name === 'write_file' ||
    name === 'write_to_file' ||
    name === 'create_file' ||
    (name.includes('write') && !name.includes('edit'))
  ) {
    const path = String(
      p.targetfile || p.target_file || p.path || p.filepath || p.file || ''
    );
    return path ? `写入 ${basename(path)}` : '写入文件';
  }

  // 5. 文件编辑 / 代码替换 (replace_file_content / multi_replace / edit_file / apply_patch)
  if (
    isEditToolName(name) ||
    name.includes('replace') ||
    name.includes('patch') ||
    name.includes('edit')
  ) {
    const path = String(
      p.targetfile || p.target_file || p.path || p.filepath || p.file || ''
    );
    if (name.includes('multi_replace')) {
      return path ? `批量修改 ${basename(path)}` : '批量修改文件';
    }
    return path ? `修改 ${basename(path)}` : '修改文件';
  }

  // 6. 目录列表 (list_dir / list_directory / ls / dir)
  if (
    name === 'list_dir' ||
    name === 'list_directory' ||
    name.includes('list') ||
    name.includes('dir') ||
    name.includes('glob')
  ) {
    const dir = String(
      p.directorypath || p.directory_path || p.path || p.dir || ''
    ).trim();
    if (!dir || dir === '.' || dir === './' || dir === '{}') {
      return '列出当前目录';
    }
    return `列出目录 ${basename(dir) || dir}`;
  }

  // 7. 代码与文本搜索 (grep_search / search / ripgrep)
  if (
    name.includes('grep') ||
    name.includes('search') ||
    name.includes('find')
  ) {
    const query = String(p.query || p.pattern || p.term || '').trim();
    if (query && !query.startsWith('{')) {
      const qClip = query.length > 24 ? query.slice(0, 23) + '…' : query;
      return `搜索「${qClip}」`;
    }
    return '搜索代码';
  }

  // 8. 多 Agent 与子任务 (run_subagent / invoke_subagent / wait_subagents / send_message)
  if (
    name.includes('subagent') ||
    name === 'invoke_subagent' ||
    name === 'run_subagent'
  ) {
    const role = String(
      p.role || p.typename || p.description || p.prompt || ''
    ).trim();
    if (role && !role.startsWith('{')) {
      const rClip = role.length > 28 ? role.slice(0, 27) + '…' : role;
      return `子任务：${rClip}`;
    }
    return '启动协作子任务';
  }
  if (name === 'wait_subagents' || name.includes('wait_sub')) {
    return '等待子任务完成';
  }
  if (name === 'send_message') {
    const recipient = String(p.recipient || p.recipientid || '').trim();
    return recipient ? `发送消息 (${recipient})` : '发送消息给子代理';
  }

  // 9. 定时器与计划 (set_timer / cancel_timer / schedule)
  if (name === 'set_timer' || name === 'schedule') {
    const duration = p.durationseconds || p.duration_seconds || p.duration;
    if (duration) return `设置定时器 (${duration}秒)`;
    const cron = p.cronexpression || p.cron_expression;
    if (cron) return `设置定时任务 (${cron})`;
    return '设置定时器';
  }
  if (name === 'cancel_timer') {
    return '取消定时器';
  }

  // 10. MCP 扩展服务 (call_mcp_tool / mcp_*)
  if (name === 'call_mcp_tool' || name.startsWith('mcp_')) {
    const summary = String(p.toolsummary || p.toolaction || '').trim();
    if (summary) return summary;
    const toolName = String(p.toolname || p.tool_name || '').trim();
    const serverName = String(p.servername || p.server_name || '').trim();
    if (toolName && serverName) return `调用 MCP [${serverName}:${toolName}]`;
    if (toolName) return `调用 MCP [${toolName}]`;
    return '调用扩展服务';
  }

  // 11. 终极安全清洗兜底（严禁裸 JSON 逃逸）
  if (args.primaryTarget) {
    const short = basename(args.primaryTarget);
    if (
      short &&
      short !== '.' &&
      short !== './' &&
      !short.startsWith('{') &&
      short.length < 40
    ) {
      return `处理 ${short}`;
    }
  }

  const prettyName = name.replace(/_/g, ' ').trim();
  return `调用 ${prettyName || '工具'}`;
}
```

  const [copiedInput, setCopiedInput] = useState(false);
  const [copiedOutput, setCopiedOutput] = useState(false);

  const raw = tc.output || '';
  const images = useMemo(() => extractImageRefs(raw), [raw]);
  const full = useMemo(() => fullToolOutput(raw), [raw]);
  const parsedArgs = useMemo(
    () => parseToolArgsSafe(tc.arguments),
    [tc.arguments]
  );
  const shellTool = isShellToolName(tc.name || '');

  // 1. 复制输入处理
  const handleCopyInput = () => {
    const textToCopy = parsedArgs.primaryTarget || tc.arguments || '';
    if (textToCopy) {
      void navigator.clipboard.writeText(textToCopy);
      setCopiedInput(true);
      setTimeout(() => setCopiedInput(false), 2000);
    }
  };

  // 2. 复制输出处理
  const handleCopyOutput = () => {
    if (raw) {
      void navigator.clipboard.writeText(raw);
      setCopiedOutput(true);
      setTimeout(() => setCopiedOutput(false), 2000);
    }
  };

  // 3. Pretext 文本排版测量（保留高性能布局计算）
  const bodyRef = useRef<HTMLDivElement>(null);
  const [containerWidth, setContainerWidth] = useState(0);
  useLayoutEffect(() => {
    const el = bodyRef.current;
    if (!el) return;
    const measure = () => setContainerWidth(el.clientWidth - 24);
    measure();
    const ro = new ResizeObserver(() => measure());
    ro.observe(el);
    return () => ro.disconnect();
  }, []);

  const fontConfig = useMemo(() => {
    const fontSizePx = getResolvedFontSizePx('--font-size-xs');
    const fontStr = buildPretextFont('mono', 'normal', fontSizePx);
    const lineHeightPx = Math.round(fontSizePx * 1.45);
    return { fontStr, lineHeightPx };
  }, []);

  const { prepared } = usePreparedText({
    text: full || '',
    font: fontConfig.fontStr,
    whiteSpace: 'pre-wrap',
  });

  const budget = useMemo(() => {
    if (showFullOutput || !full || !containerWidth || containerWidth <= 16) {
      return { text: full, truncated: false, originalLength: full.length };
    }
    try {
      const totalHeight = layout(
        prepared!,
        containerWidth,
        fontConfig.lineHeightPx
      ).height;
      if (totalHeight <= TOOL_OUTPUT_PIXEL_CAP) {
        return { text: full, truncated: false, originalLength: full.length };
      }
      const pws = prepareWithSegments(full, fontConfig.fontStr, {
        whiteSpace: 'pre-wrap',
      });
      const lineRanges: LayoutLineRange[] = [];
      walkLineRanges(pws, containerWidth, (line) => {
        lineRanges.push(line);
      });
      let accumulated = 0;
      const parts: string[] = [];
      for (const lr of lineRanges) {
        if (accumulated + fontConfig.lineHeightPx > TOOL_OUTPUT_PIXEL_CAP)
          break;
        parts.push(materializeLineRange(pws, lr).text);
        accumulated += fontConfig.lineHeightPx;
      }
      return {
        text: parts.join('\n') + '\n…（已截断）',
        truncated: true,
        originalLength: full.length,
      };
    } catch {
      return { text: full, truncated: false, originalLength: full.length };
    }
  }, [showFullOutput, full, containerWidth, fontConfig, prepared]);

  const out = budget.text;
  const hasDiffs = Boolean(tc.diffs && tc.diffs.length);

    tc.status as MessageToolCall['status'] | undefined
  );

    shellTool && (raw.length > 2000 || raw.split('\n').length > 80);

    if (shellTool) {
      const cmd = parsedArgs.primaryTarget || tc.arguments || '';
      return (

          <span className={styles.terminalPrompt} aria-hidden>
            $
          </span>
          <pre className={styles.toolResultPreCmd}>{cmd}</pre>
        </div>
      );
    }
    // 结构化入参属性卡片
    const entries = Object.entries(parsedArgs.props).filter(

    );
    if (entries.length === 0) {
      return tc.arguments?.trim() ? (
        <pre className={styles.toolResultPreCmd}>{tc.arguments.trim()}</pre>
      ) : (
        <span className={styles.toolParamEmpty}>无参数</span>
      );
    }
    return (

            </span>
          </div>
        ))}
      </div>
    );
  }, [shellTool, parsedArgs, tc.arguments]);

  return (
    <div
      id={bodyId}
      ref={bodyRef}
      className={styles.toolResultBody}
      role="region"
      aria-label={`${statusZh}的工具调用详情`}
    >
      {/* ─── 1. 【输入分区】(Input Section) ─── */}
      <section className={styles.toolSection} aria-label="输入参数">
        <div className={styles.toolSectionHeader}>
          <div className={styles.toolSectionTitle}>
            <span className={styles.toolSectionBadge}>输入</span>
            <span className={styles.toolSectionName}>
              {shellTool ? '执行命令' : `${tc.name || '工具'} 参数`}

            </Tooltip>

        </div>
        <div className={styles.toolSectionContent}>{renderedInput}</div>
      </section>

      {/* ─── 2. 【输出分区】(Output Section) ─── */}
      <section
        className={`${styles.toolSection} ${styles.toolSectionOutput}`}
        aria-label="执行结果"
      >
        <div className={styles.toolSectionHeader}>
          <div className={styles.toolSectionTitle}>

                  onClick={handleCopyOutput}

  );
};
