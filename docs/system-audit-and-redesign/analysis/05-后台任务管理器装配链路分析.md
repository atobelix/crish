# 后台任务管理器（BackgroundTaskManager）装配链路分析与修复方案报告

**分析师角色**：后台任务管理器装配分析师  
**被分析模块**：`crates/agent-tools/`、`crates/session-loop/`、`apps/agent-workbench/src-tauri/`  
**核心现象**：
当 AI 执行后台命令后调用 `background_task` 查询任务状态时，抛出：
`[common.unsupported] background_task 未接线：后台任务管理未装配（引擎侧注入 BackgroundTaskManager 后可用）`

---

## 一、根因定性（M6 缺陷）

- **核心断裂点**：`crates/session-loop/src/exec_single.rs:299` 在为每个工具调用组装会话级 `ToolContext` 时，**硬编码注入了 `background: None` 与 `log_root: None`**。
- **中间传递断层**：`session-loop` 层的 `SessionLoopOptions`（`loop_options.rs`）和 `ToolExecCtx`（`tool_exec.rs`）均未定义 `background` / `log_root` 字段，`AgentSessionLoop::with_options` 亦未透传。
- **行为不对称根因**：
  1. `ShellCommandTool` 在注册时接收并持有了 `self.background_manager` 作为 fallback，因此 `shell` 工具执行后台模式时，能成功将进程转交 `BackgroundTaskRegistry` 托管；
  2. 但 `BackgroundTaskTool` 设计为纯无状态工具，执行期**唯一依赖** `ToolContext.background`。当它读到 `ctx.background == None` 时，直接触发未接线阻断。

---

## 二、装配链路断裂拓扑

```
[main.rs]
  └─ background_tasks: Arc<BackgroundTaskRegistry>
        │
        ▼
[CoreRunState::new]
  └─ state.background = Arc<RunAwareBackgroundManager>
        │
        ▼
[run_launch.rs: core_run_task]
  ├─ state.background.set_current_run(&run_id) (已就绪)
  ├─ SessionLoopOptions { ... } ───► ❌ 未注入 background / log_root
        │
        ▼
[SessionLoopProducer::produce]
  └─ AgentSessionLoop::with_options(options) ───► ❌ 未透传到 tool_ctx
        │
        ▼
[ToolExecutor::execute_batch -> execute_single]
  └─ ToolContext {
         session_id: ...,
         workspace_root: ...,
         write_claims: ctx.write_claims.clone(),
         explore_docs_quota: ctx.explore_docs_quota.clone(),
         output_dir: ctx.output_dir.clone(),
         note_backend: ctx.note_backend.clone(),
         background: None,   ◄── ❌ 硬编码 None
         log_root: None,     ◄── ❌ 硬编码 None
     }
        │
        ▼
[BackgroundTaskTool::execute]
  └─ ctx.background == None ───► 💥 报错 common.unsupported: "background_task 未接线..."
```

---

## 三、精准修复方案

1. **`crates/session-loop/src/tool_exec.rs`**：
   在 `ToolExecCtx` 中增加 `background` 与 `log_root` 字段；
2. **`crates/session-loop/src/loop/loop_options.rs`**：
   在 `SessionLoopOptions` 中增加 `background` 与 `log_root` 字段；
3. **`crates/session-loop/src/loop/loop_runner.rs`**：
   在 `AgentSessionLoop::with_options` 中进行透传赋值；
4. **`crates/session-loop/src/exec_single.rs`**：
   组装 `ToolContext` 时改为 `background: ctx.background.clone()` 与 `log_root: ctx.log_root.clone()`；
5. **`apps/agent-workbench/src-tauri/src/run/run_launch.rs`**：
   在组装 `SessionLoopOptions` 时注入 `state.background` 与日志目录。
