## 一、方案制定背景与前置成果收敛

在经历【阶段一：前置审计与逆向排查】（8 份审计报告与 9222 CDP 实机真值巡检）与【阶段二：多 Agent 方案生成与第一轮交叉评审】（6 份独立整体方案 337 KB + 3 份严苛评审报告 152 KB）后，主控综合裁决收敛出以下**不可动摇的系统级架构定论**：

1. **Rust 引擎唯一真源（SSOT）**：废除前端 LocalStorage 对模型配置的真源地位，凭据物理隔离至 Windows DPAPI，由底层提供原生 `provider_probe_ping` / `provider_probe_scan_models` 原生探测；
2. **全系统四级视觉曲率（Curvature Hierarchy）**：Pills 饱满胶囊 `var(--radius-full)`（9999px）、Buttons 柔和圆润 `var(--radius-xl)`（10px）、Containers 内嵌卡片 `var(--radius-3xl)`（14px）/ `var(--radius-xl)`（10px）、Items 选区 `var(--radius-md)`（6px）；
3. **Shell 容器与设置中心彻底解耦**：专属 `--settings-sidebar-width: 240px` 变量隔离，主侧栏折叠状态严禁污染全屏设置导航；
4. **侧栏底栏按图 2/3/5 双列重构**：左列 `UserProfileCard`（点击展开主题与快捷菜单）+ 右列 `SettingsIconButton`（32×32px 齿轮直达全屏设置）；
5. **设置中心双栏温润色彩同构映射**：左侧导航继承 `--bg-secondary`（暖灰），右侧主配置区采用内嵌 `--bg-primary`（暖白）卡片外壳，同心曲率 $R_{\text{inner}} = R_{\text{outer}} - P$；
6. **核心聊天 S6【软件内部错误】全链路清零**：修复 `softFailureMessage('network')` 无参黑洞与宽泛正则误伤，会话串行并发拒绝自动入队平滑排队，用户输入草稿 100% 回滚保护；
7. **工作区右坞与二叉树全功能打通**：根除 `TreeLeafPanel` 空回调断层，恢复 Diff 虚拟滚动高度，单会话独立工具坞状态隔离；
8. **行数门禁严格遵守与前置拆解**：针对 `useSlashSend.ts`（457行）、`useModelProfilesState.ts`（501行）与 `run_launch.rs`（1328行）实施前置模块化解耦，严守 CI 红线。
