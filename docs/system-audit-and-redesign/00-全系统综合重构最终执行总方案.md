## 一、战役总纲与终态目标（Universal Objectives）

2. **重构侧栏底栏为图 2/3/5 双列架构**：左列 `UserProfileCard`（点击展开主题与快捷菜单）+ 右列 `SettingsIconButton`（32×32px 独立齿轮直达全屏设置）；
3. **设置中心双栏温润色彩同构继承**：左侧导航继承 `--bg-secondary`（暖灰），右侧主配置区采用内嵌 `--bg-primary`（暖白）卡片外壳，同心曲率 $R_{\text{inner}} = R_{\text{outer}} - P = 14\text{px}$；
4. **根除智能-模型设置 `models-split` 区域鼠标滚轮失效**：拔除 `overscroll-behavior: contain` 阻断，改为流式高度并入外层单一主滚动流；

7. **打通工作区右坞 6 大交互断层**：根除 `TreeLeafPanel` 空回调，修复 Diff 虚拟滚动高度锁死，隔离多会话分屏展开状态；

## 二、五大核心维度终态技术契约（Architectural Contracts）

### 2.1 维度 1: 视觉曲率、Token 体系与浮层基座治理

- **四级曲率阶梯**：
  - **Level 1 Pills (`var(--radius-full)` / 9999px)**：`.permPill`、`.modelBadge`、`.cascadeSelectTrigger`、预设 Chip、TabStrip 顶栏 Tab；
  - **Level 2 Buttons (`var(--radius-xl)` / 10px)**：`.plusBtn`、15 个 `.shortcut-key-btn`、下拉 Select 触发器、对话框按钮；
  - **Level 3 Containers (14px / 12px / 10px)**：外壳底座 14px、模态对话框 12px、浮层外壳 10px；
  - **Level 4 Items (`var(--radius-md)` / 6px)**：下拉菜单项统一为 6px（满足 $10\text{px} - 4\text{px} = 6\text{px}$ 同心圆角）。
- **`Menu.tsx` 双模演进与 React 19 适配**：彻底移除 `element.ref` 属性访问（改用 `props.ref`），全面支持显式 `Popover.Anchor virtualRef={anchor}` 模式，消除双击/四击震荡。
- **`Tooltip.tsx` 零坐标拦截**：注入 `isValidDOMRect` 严格几何谓词，拦截全 0 坐标，隔离 `items[0]?.focus()` 程序化焦点污染。

### 2.2 维度 2: 核心聊天链路、S6 错误根治与并发容错状态机

- **S1~S8 完备错误域分流**：重写 `softFailureMessage(kind, detail?)` 签名，`networkUserMessage` 默认兜底从 S6 改为 S4（网络异常）；收窄 `INTERNAL_ERROR_RE`，剥离 `aborted` 错误码（正常取消静默收口）。
- **串行并发平滑排队 (Auto Follow-up)**：Rust 串行守卫返回 `SESSION_BUSY` 时，前端自动将消息置为 `queued` 并挂载至 `ChatQueuePanel` 排队调度，0 次红条报错。
- **草稿 100% 原地回滚与卡片重试**：前置拦截时原子撤回时间线孤儿消息并还原输入框 Prompt；流式中断时消息卡片渲染【🔄 重新生成】按钮。

### 2.3 维度 3: 设置中心布局解耦、底栏双列重构与温润色彩继承

- **专属 Token 隔离**：在 `tokens.css` 中注入 `--settings-sidebar-width: 240px`，改造 `useSidebarResize.ts` 消除向 `:root` 写入 0px 的全局副作用，设置左侧导航 100% 稳定可见。
- **底栏双列重构（对齐图 2/3/5）**：左列 `UserProfileCard.tsx`（点击展开主题与快捷菜单）+ 右列 `SettingsIconButton.tsx`（32×32px 独立圆角齿轮，直达全屏设置）。
- **设置双栏温润色彩同构映射**：左侧导航继承 `--bg-secondary`（暖灰），右侧主区重构为内嵌 `--bg-primary`（暖白）卡片（`border-radius: 14px`），内层分组 `--bg-card`，注入 `scrollbar-gutter: stable both-edges`。

### 2.4 维度 4: 模型配置全真源、原生 DPAPI 探测与滚轮死锁消除

- **Rust 引擎唯一真源**：Rust `profile-config.json` + `secrets/*.dpapi` + `ModelCatalog` 权威管理，服务商删除级联清理物理 DPAPI 密钥文件。
- **独立探测模块 `probe.rs`**：在 `apps/agent-workbench/src-tauri/src/probe.rs` 独立实现 `provider_probe_ping` 与 `provider_probe_scan_models` 原生 IPC，冷启动探活 0 报漏 Key。

### 2.5 维度 5: 工作区右坞、多会话分屏与二叉树全功能打通
