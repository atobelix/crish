### 1.1 数据真实性危机（假数据零容忍）
- **现场表现**：用户今天未发起过任何对话，界面却凭空展示了 12.9 万 Token、¥3.17 预估金额以及 4 个模型的时序分布。
- **根因**：此前在开发联调阶段，测试脚本向本地真实 SQLite 数据库（`apps/agent-workbench/sessions.db` 的 `usage_records` 表）注入了 26 条带有 `sess-test-*` 前缀的假数据。开发试图用假数据把图表填满来遮掩空态，触碰了工程诚信红线。
- **治理**：已在本地数据库执行物理 `DELETE FROM usage_records WHERE session_id LIKE 'sess-test-%'`，真实记录归零。前端各组件确立**真源铁律**：有就是有，没有就是没有，全面接入高质感**标准空态（Clean Empty State）**。

### 1.2 系统既有组件未对接（图三标号 ① 和 ②、图一顶部）
- **现场表现**：顶栏时间切换、折线图走势维度切换、热力图跨度切换，全部使用裸 `div` 拼装 `Button` 手写伪分段样式，在 CSS 里私造了 `.segmented`、`.segmentedBtn`、`.segmentedBtnActive`、`.segmentedSm` 等类，并私造了 `--usage-seg-pad`、`--usage-seg-radius` 等变量。
- **根因**：忽略了工程中已有的具有同心大圆角、物理贝塞尔滑块动画、WAI-ARIA 1.2 RadioGroup 规范与键盘方向键漫游的原子组件：
  [`apps/crish-desktop/src/components/ui/SegmentedControl/SegmentedControl.tsx`](file:///c:/Software/conex/apps/crish-desktop/src/components/ui/SegmentedControl/SegmentedControl.tsx)。
- **治理**：全量清退手写伪分段与私造类，100% 对接系统自研的 `SegmentedControl`（`size="sm"` 与 `size="xs"`）。

### 1.3 折线走势图 X 轴刻度严重拥挤叠字（图三标号 ③）
- **现场表现**：在 24 小时模式下，整整 24 个“HH:00”标签挤在单行，变成 `09:0010:0011:00...` 无法辨识的长串字符。
- **根因**：无脑遍历 `points.map` 渲染全部 24 个 `<span>`，未做任何时序刻度抽稀。容器宽 580px ~ 760px，24 个 32px 宽的标签加上内边距在 flex 容器内互相重叠挤压。
- **治理**：引入**均匀抽稀自适应算法（Axis Decimation）**，24h 仅保留 4~6 个代表性锚点（如 00:00、06:00、12:00、18:00 及当前最新时间），其余刻度自适应隐藏，彻底消灭叠字。

### 1.4 私造样式类物理删除与卡片不对齐
- **现场表现**：`UsageSummaryHero.module.css` 私造了大量临时类：`.heroSubtext`、`.labelDot`、`.labelDotTokens`、`.labelDotCost` 等；左右两张卡片（总用量 vs 预估金额）没有使用系统统一的 [`SettingsCard`](file:///c:/Software/conex/apps/crish-desktop/src/components/settings/SettingsUI.tsx)；左卡片是 4 项紧凑网格小字，右卡片是 1 行纯文本，左右高度、字阶、基线完全脱节。
- **治理**：
  - 用户明确指令：**“发给你的那些类都是要删除的”**，物理删除上述全部私造类名；
  - 全面使用系统统一的 `SettingsCard` 标准容器；
  - 左右卡片做严格对称重构（指标名、大数字+单位基线对齐、底部 3 列等宽栅格子项信息）。

### 1.5 模型用量百分比 3573.3% 荒谬 Bug 与胶囊条重构（图二）
- **现场表现**：百分比显示为 `3573.3%`，圆环 SVG 变成实心粗红圈；hover 柱状图时其他条目变成 0.6 透明度的死灰、圆环发生突发膨胀抖动。
- **根因**：
  - 后端 Rust 聚合引擎（`crates/conex-db/src/usage_analytics.rs:495`）返回的 `percentage` 已经是乘了 100 的数值（如 `35.73`）；而前端 `usageSpline.ts` 中的 `formatPercentage(ratio)` 内部又做了一次 `(ratio * 100).toFixed(1)`，导致二次放大 100 倍！
  - 圆环 SVG 切片 `dash = pct * CIRCUMFERENCE`，当 `pct = 35.73` 时 dash 暴涨至 15714，导致 SVG 虚线偏移直接溢出溢满，把所有切片都渲染成了实心粗圆！
  - hover 时使用 `opacity: 0.6` 粗暴变暗其他条目，圆环 `strokeWidth` 突变 4px 导致剧烈几何抖动。
- **治理**：
  - 设计统一步长守卫 `normalizeModelRatio`，彻底切断双重乘 100 链路，严格钳位在 `0 ~ 1.0`；
  - 100% 对齐用户图二右侧的标准高质感胶囊列表设计（左侧纯色圆点 + 模型名，右侧加粗 Token 数 + 灰度百分比，浅色同心底条）；
  - 拔除粗暴的 `opacity: 0.6`，采用单行叠加 `var(--tint-hover)`，圆环仅做微弱高光，根治脏灰与抖动。

### 1.6 三个带图标按钮对齐与 Token 纯净化
- **现场表现**：“配置单价”、“刷新数据”、“清空历史”按钮图标和文字没对齐；清空历史在 `:hover` 里硬编码 `rgba(220, 38, 38, 0.08)` 和 `#dc2626`。
- **根因**：将 `<Lucide.* />` 作为 children 裸传且外加手写 class 覆盖，破坏了 `Button` 内部的 flex 居中机制与图标间距；未复用系统标准的 `variant="danger"`。
- **治理**：统一规范使用系统的 `<Button variant="secondary" / "ghost" / "danger" size="sm" icon={<Lucide.* />} >`，由组件内部标准 Tokens 与容器统一步距与居中，清退所有外部覆盖 class 与硬编码。

### 1.7 活动热力图 32px Y 轴字字相叠与手写 Tooltip（图一）
- **现场表现**：左侧 Y 轴 `width: 32px` 导致“凌晨 00-06”等 7 字符长文本强制折行、字字相叠；单元格悬浮手写绝对坐标与伪浮层。
- **根因**：未考虑多分辨率下中英文与数字混排宽度，在组件内维护 `activeTooltip` 状态并手写 `getBoundingClientRect` 计算坐标，违背 `AGENTS.md` §12 的 Tooltip 统一规范。
- **治理**：放宽 Y 轴至充足宽度（64px），采用“主标（时段）+ 微标（小时段）”宽松两行排版；单元格 100% 对接系统标准单槽 `<Tooltip content="...">`。

## 二、数学模型、抽稀算法与归一化公式

### 2.1 时序刻度均匀抽稀算法（Time-Series Axis Decimation）

#### 1. 抽稀规则
- **24h 模式（总点数 24 点）**：仅渲染 5 个锚点刻度：`00:00`、`06:00`、`12:00`、`18:00` 以及 `最新/当前时间`；
- **7d 模式（总点数 7 点）**：7 个点在 600px 以上空间充裕，保留全量渲染；
- **30d 模式（总点数 30 点）**：均匀抽取 5~6 个代表性锚点（每隔 6 天展示 1 个：`T-29d`、`T-23d`、`T-17d`、`T-11d`、`T-5d`、`今天`）。

#### 2. 数学公式与绝对百分比对齐
设视口内部绘图区左边距为 $X_{\text{start}}$，右边界为 $X_{\text{end}}$，总点数为 $N$。第 $i$ 个数据点的理论物理百分比为：
$$ \text{posRatio}(i) = \frac{i}{N - 1} $$
对应的容器百分比位置为：
$$ \text{leftPct}(i) = \frac{X_{\text{start}} + \text{posRatio}(i) \times (X_{\text{end}} - X_{\text{start}})}{W_{\text{viewport}}} \times 100\% $$

应用**边缘位移补偿（Edge Transform Compensation）**：
$$ \text{transform}(i) = \begin{cases}
\text{translateX}(0\%) & \text{if } i = 0 \text{ (最左端齐平，防左溢出)} \\
\text{translateX}(-100\%) & \text{if } i = N - 1 \text{ (最右端齐平，防右溢出)} \\
\text{translateX}(-50\%) & \text{otherwise (几何中心对齐数据采样点)}
\end{cases} $$

#### 3. 核心实现（注入 `usageSpline.ts`）
```typescript
export interface DecimatedTick {
  index: number;
  label: string;
  leftPercent: number;
  transform: string;
}

export function computeDecimatedTicks(
  points: { label: string }[],
  range: '24h' | '7d' | '30d',
  xStart = 40,
  xEnd = 750,
  totalWidth = 760
): DecimatedTick[] {
  const n = points.length;
  if (n === 0) return [];
  if (n === 1) {
    return [{ index: 0, label: points[0]!.label, leftPercent: 50, transform: 'translateX(-50%)' }];
  }

  const targetIndices = new Set<number>();
  targetIndices.add(0);
  targetIndices.add(n - 1);

  if (range === '24h' && n >= 24) {
    for (let i = 0; i < n - 1; i++) {
      const lbl = points[i]!.label;
      if (lbl.endsWith('00:00') || lbl.endsWith('06:00') || lbl.endsWith('12:00') || lbl.endsWith('18:00')) {
        targetIndices.add(i);
      }
    }
  } else if (range === '30d' && n >= 30) {
    for (let i = 6; i < n - 1; i += 6) {
      targetIndices.add(i);
    }
  } else {
    if (n <= 8) {
      for (let i = 0; i < n; i++) targetIndices.add(i);
    } else {
      const step = (n - 1) / 4;
      for (let k = 1; k < 4; k++) {
        targetIndices.add(Math.round(k * step));
      }
    }
  }

  const result: DecimatedTick[] = [];
  const sorted = Array.from(targetIndices).sort((a, b) => a - b);

  for (const idx of sorted) {
    const pt = points[idx]!;
    const posRatio = idx / (n - 1);
    const chartX = xStart + posRatio * (xEnd - xStart);
    const leftPercent = (chartX / totalWidth) * 100;

    let transform = 'translateX(-50%)';
    if (idx === 0) transform = 'translateX(0%)';
    else if (idx === n - 1) transform = 'translateX(-100%)';

    result.push({
      index: idx,
      label: pt.label,
      leftPercent,
      transform,
    });
  }

  return result;
}
```

### 2.2 模型用量百分比归一化与 SVG 防御模型

#### 1. 归一化守卫公式
定义统一适配函数 `normalizeModelRatio`，无论输入是已乘 100 的百分数（如 `35.73`）还是原始比例值（如 `0.3573`），输出严格收敛在 $[0, 1.0]$ 区间内：
$$ \text{ratio}(v) = \begin{cases}
0.0 & \text{if } v \le 0 \text{ or not finite} \\
\frac{v}{100} & \text{if } v > 1.0 \text{ (后端已乘 100 态)} \\
v & \text{if } 0.0 < v \le 1.0 \text{ (原始比例态)}
\end{cases} $$

```typescript
export function normalizeModelRatio(rawVal: number): number {
  if (typeof rawVal !== 'number' || !Number.isFinite(rawVal) || rawVal <= 0) {
    return 0.0;
  }
  if (rawVal > 1.0) {
    return Math.min(1.0, rawVal / 100.0);
  }
  return rawVal;
}
```

#### 2. SVG 饼图切片防御性公式
圆环半径 $R = 70$，基准周长 $C = 2 \pi R \approx 439.82297$。
对于第 $k$ 个模型切片，其标准弧长 $\text{dash}_k$ 和偏移量 $\text{offset}_k$ 严格计算如下：
$$ \text{dash}_k = \text{ratio}_k \times C $$
$$ \text{offset}_k = -\sum_{j=0}^{k-1} \text{dash}_j $$
由于 $\sum \text{ratio}_k \le 1.0$，累加偏移绝不会超过周长，实心红圈 Bug 在数学上彻底根除。

#### 3. 胶囊背景条同心几何尺寸
同心几何标尺：
- 胶囊外壳圆角：`--usage-capsule-outer-radius: 9px`
- 内部内边距：`--usage-capsule-pad: 3px`
- 背景填充条同心圆角：`--usage-capsule-inner-radius: calc(9px - 3px) = 6px`
- 填充宽度：
$$ \text{barWidth} = \max(2, \min(100, \text{ratio}_k \times 100))\% $$
最少保留 2% 确保可见度，上限 100% 杜绝撑爆。

### 5.1 `usageSpline.ts` 纯逻辑工具扩展
```typescript
/**
 * apps/crish-desktop/src/components/settings/usage/usageSpline.ts
 */

export interface SplinePoint {
  x: number;
  y: number;
  val?: number;
}

export interface DecimatedTick {
  index: number;
  label: string;
  leftPercent: number;
  transform: string;
}

export function formatTokens(v: number): string {
  if (typeof v !== 'number' || !Number.isFinite(v) || v <= 0) return '0';
  if (v >= 100_000_000) {
    const yi = v / 100_000_000;
    return `${yi >= 10 ? yi.toFixed(1) : yi.toFixed(2)} 亿`;
  }
  if (v >= 10_000) {
    const w = v / 10_000;
    return `${w >= 100 ? w.toFixed(0) : w >= 10 ? w.toFixed(1) : w.toFixed(2)} 万`;
  }
  return v.toLocaleString('zh-CN');
}

export function formatCost(v: number, prefix = '¥ '): string {
  if (typeof v !== 'number' || !Number.isFinite(v) || v <= 0) return `${prefix}0.00`;
  return `${prefix}${v.toFixed(2)}`;
}

/**
 * 统一步长与比例归一化守卫函数，将 0~100 或 0~1 安全规约为 0.0 ~ 1.0
 */
export function normalizeModelRatio(rawVal: number): number {
  if (typeof rawVal !== 'number' || !Number.isFinite(rawVal) || rawVal <= 0) {
    return 0.0;
  }
  if (rawVal > 1.0) {
    return Math.min(1.0, rawVal / 100.0);
  }
  return rawVal;
}

export function formatPercentage(ratio: number): string {
  const norm = normalizeModelRatio(ratio);
  return `${(norm * 100).toFixed(1)}%`;
}

/**
 * X 轴刻度均匀抽稀算法，生成绝对百分比与边缘位移补偿
 */
export function computeDecimatedTicks(
  points: { label: string }[],
  range: '24h' | '7d' | '30d',
  xStart = 40,
  xEnd = 750,
  totalWidth = 760
): DecimatedTick[] {
  const n = points.length;
  if (n === 0) return [];
  if (n === 1) {
    return [{ index: 0, label: points[0]!.label, leftPercent: 50, transform: 'translateX(-50%)' }];
  }

  const targetIndices = new Set<number>();
  targetIndices.add(0);
  targetIndices.add(n - 1);

  if (range === '24h' && n >= 24) {
    for (let i = 0; i < n - 1; i++) {
      const lbl = points[i]!.label;
      if (lbl.endsWith('00:00') || lbl.endsWith('06:00') || lbl.endsWith('12:00') || lbl.endsWith('18:00')) {
        targetIndices.add(i);
      }
    }
  } else if (range === '30d' && n >= 30) {
    for (let i = 6; i < n - 1; i += 6) {
      targetIndices.add(i);
    }
  } else {
    if (n <= 8) {
      for (let i = 0; i < n; i++) targetIndices.add(i);
    } else {
      const step = (n - 1) / 4;
      for (let k = 1; k < 4; k++) {
        targetIndices.add(Math.round(k * step));
      }
    }
  }

  const result: DecimatedTick[] = [];
  const sorted = Array.from(targetIndices).sort((a, b) => a - b);

  for (const idx of sorted) {
    const pt = points[idx]!;
    const posRatio = idx / (n - 1);
    const chartX = xStart + posRatio * (xEnd - xStart);
    const leftPercent = (chartX / totalWidth) * 100;

    let transform = 'translateX(-50%)';
    if (idx === 0) transform = 'translateX(0%)';
    else if (idx === n - 1) transform = 'translateX(-100%)';

    result.push({
      index: idx,
      label: pt.label,
      leftPercent,
      transform,
    });
  }

  return result;
}
```

1. **Hero 卡片**：总用量显示 `0 tokens`，预估金额显示 `¥ 0.00`，子指标显示 `0` 与 `—`，基线齐整，零视觉错乱；
2. **走势图表**：渲染平缓的零位基线，展示轻量温和的空态文案：“当前周期暂无用量调用数据”；
3. **模型占比**：展示中性圆环轨道底色，右侧展示：“暂无模型使用记录”；
4. **热力图**：渲染 0 级浅底网格（`--usage-heat-0`），数据统计指标展示“无记录”；
5. **底栏操作区**：自动隐藏“清空历史”按钮，保留“刷新数据”按钮。
