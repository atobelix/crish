## 三、阅读顺序建议

```
01 调研（10 份参考软件）→ 02 对比（comparison.md 差距与现状证据）
→ 03 方案（P1 → P2 → P3 → P4 → P5 → P6，按逻辑链读）
→ 04 审计（A1 → A2 → A3，逐层收敛）→ 90 最终方案（执行主线）
```

- **主 agent**：1 → 3 → 5 → 6（调研与方案细节按需回查）。
- **方案执行 agent**：3（本方案对应份）→ 5（涉及本方案的修正标注）→ 6（本人在轮中的任务单元）。任务单元中标注的【A1/A2/A3 审计修正】【调度者裁决】为已生效约束，必须遵守。
- **审计 agent**：1 → 2 → 4（对应份）→ 5（全部）→ 6（门禁与约束）。
- **数据核对**：涉及价格/窗口/缓存机制数字时，一律以 `00-vendor-model-pricing-catalog.md` 为权威来源，P3 的 catalog.json 转录与其逐条核对。
