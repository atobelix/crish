## 0. 调研口径

- 本调研只收录**针对特定模型/模型系列的特化处理**（"某某模型特殊适配"），不含通用缓存策略（前缀稳定、断点预算、usage 恒等式等通用机制见 01-reference-research 各文档）。
- 「已覆盖」判定口径：crish 现状代码（数据表或接线面）存在对应事实，且语义与参考软件等价；「部分覆盖」= 数据/接口存在但未接线或语义不等价；「缺」= 无对应实现。
- 诚实边界：标注为「待核实」的条目均为口径差异或未获官方一手确认，不自行断定。
- 每条证据均给出 `文件:行号`，可复核。

## 3. 结论与建议

1. **高优先（缓存/成本直接影响，建议进入 P4/P5 排期）**：G1（Anthropic 1h 档 catalog 路径修复）、G2（x-grok-conv-id 接线）、G7（adaptive + display summarized）、G10（gpt-5 effort 档位门控）。
2. **中优先（协议正确性）**：G4/G5（DeepSeek/MiniMax/Zhipu thinking 形态口径复核与对齐）、G8（Mistral 序列）、G11（gpt-5 默认参数）。
3. **数据面先行**：G1/G2/G6 本质是 models/ 数据层字段缺失（supports_long_retention、会话亲和头开关、5.6 显式模式位），可在模型目录 v2 数据模型中一次补齐，再接线到 request/ 层。
4. **已覆盖且钉死良好的部分无需回改**：DeepSeek cache_control 全略 + reasoning_content Require（deepseek_invariants.rs）、GPT-5.6 explicit none 档、MiniMax M2/M3 缓存开关分流、Kimi prompt_cache_key、xAI cache hit 解析、gpt-5.5/5.6 TTL 分档。
