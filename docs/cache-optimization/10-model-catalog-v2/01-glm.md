### 3.5 结构性差异确认（国内站口径，R1 校正重点）

- **① 计费模式：命中价 + 存储费，非 cache_write**。国内站定价列结构为「输入单价 | 输出单价 | 缓存命中 | 缓存存储(元/百万tokens/小时)」——缓存计费由「缓存命中价（按输入 token 计）」与「缓存存储费（按 元/百万 tokens/小时 计时）」两个字段构成，**不存在 Anthropic 式 cache_write 写价**（z.ai USD 站同样无写价，仅 Cached Input Storage 列）。目录建模不得套用 cache_write，应使用「cache_hit_per_1m + storage_price_per_1m_hour」双字段（见 §7 字段设计）。
- **② 长度分档**：
  - 输入长度分档主边界 **32K**：GLM-5.1 / 5-Turbo / 5 / 5V-Turbo / 4.7 / 4.5-Air 均有 [0, 32K) 档；次边界 **128K**（GLM-4.6V 的 [32K, 128K)、4.5V 的 [32K, 64K)）与 **200K**（GLM-4.7 输入 [32K, 200K) 档）；1M 上下文的 GLM-5.2 不分档。
  - 输出长度分档仅 GLM-4.7（输出 [0, 0.2M) / [0.2M+)）与 GLM-4.5-Air（输出 [0, 200K) / [200K+)）——分档按「输入档 × 输出档」组合展开。
  - 用户数据明确写出「输入 [32, 200K)」与输出 0.2M 边界，与 §3.1 的 0.2 推断一致——**§6 未确认项 9 降级为已确认**。
- **③ 视觉模型标记**：GLM-5V-Turbo 与 GLM-4.6V 为视觉/多模态模型（5V-Turbo 支持图像/视频/文本/文件四类输入，属智谱首个多模态 Agent 基座），目录条目必须单独标记 `supports_vision`，不得混入纯文本价格表语义；多模态输入按实际内容构成计量计费，成本评估时不能按纯文本 token 等价折算。

## 4. 缓存机制说明（两站口径一致，2026-08-03 已确认）

### 4.1 自动隐式缓存

- **类型**：自动隐式缓存（Implicit Caching），基于内容相似度自动识别重复上下文（非严格前缀哈希），无需手动配置、无缓存断点
- **命中条件**：内容完全相同命中率最高，轻微格式差异可能影响命中；缓存有合理时限，过期后重新计算
- **计费**：新内容按标准价、命中按优惠价、输出按标准价；命中价两站不同口径并存：
  - 定价页实际数字（推荐口径）：USD 站命中 ≈ 输入价 **14%~20.6%**（5.2 为 18.6%）；CNY 站命中 ≈ 输入价 **20%~25.7%**（5.2 为 25%）
  - 缓存文档示例口径：**「usually 50% of standard price」**（0.005/0.01 示例，两站缓存文档原文一致）——计算成本时以定价页数字为准
- **缓存写入费**：两站定价页均无 cache_write 价目（隐式缓存，创建免费）；有「Cached Input Storage」列，**存储费限时免费**（国内站标注有效期至 2026-08-31，注意到期后需复核）
- **最低缓存量**：官方文档未标注（未获取）；参考百炼通道 GLM 最低缓存 token = 512
- **计量字段**：`usage.prompt_tokens_details.cached_tokens`（OpenAI Chat Completions 兼容 v4 格式；两站缓存文档示例 JSON 一致）
- **支持模型**：官方文档列名「GLM-5、GLM-4.7、GLM-4.6、GLM-4.5 系列等全部主流模型」（国际站）；国内站列名「GLM-5.2、GLM-5.1、GLM-5 系列等」

### 4.2 GLM-4.7 保留式推理（Preserved Thinking，已确认）

- **机制**：自动保留多轮对话中的推理块（reasoning_content），从而提高**缓存命中率、降低计算成本**，适合长期复杂任务；与交错推理（Interleaved，GLM-4.5 起）、轮级推理（Round-Level，按轮开关）并列为三类推理机制
- **开关**（docs.z.ai/guides/capabilities/thinking-mode，2026-08-03）：
  - **Coding Plan 端点默认开启**；**标准 API 端点默认关闭**
  - 开启方式：请求体 `"thinking": {"type": "enabled", "clear_thinking": false}`
  - 客户端必须**完整、原样回传**上轮生成的 `reasoning_content`（连续块须与模型初始生成序列完全一致，不得重排/编辑），否则性能下降且缓存命中率受影响
- **思考默认行为**：GLM-5.2/5.1/5/4.7 系列 thinking 默认开启（与 GLM-4.6 的默认混合思考不同），可通过 `thinking.type: disabled` 关闭

### 4.3 cache_control 支持状态（重点缺口核实）

- 官方缓存文档（国际/国内两站）均**只描述自动缓存，无任何 cache_control 断点机制说明**——维持上轮结论：官方 OpenAI 兼容端点无 Anthropic 式断点
- **Anthropic 兼容端点存在**：国际 `https://api.z.ai/api/anthropic`、国内 `https://open.bigmodel.cn/api/anthropic`（国内站 Claude API 兼容文档 2026-08-03 确认，模型编码用智谱模型名，如 `glm-5.2`）；**文档仍未说明该端点是否接受/处理 Anthropic 式 `cache_control` 断点——未确认，需实测**（发带 cache_control 的请求观察 `usage.cache_read_input_tokens` 等字段）
- **Responses API**：两站 llms.txt / 文档索引均无 Responses API 条目——**未确认（大概率不支持）**

- **关键模型 5 条必收录**（现行主力）：glm-5-2、glm-5-1、glm-5、glm-5-turbo、glm-4-7（+glm-4-7-flash 免费档、glm-4-7-flashx、glm-4-5-air 如需）；旧 00-catalog §12.4.1 的 glm-5/glm-4-5-air 条目价格需按本表更新；视觉模型 GLM-5V-Turbo / GLM-4.6V 用于多模态 Agent 场景时须收录并标记 supports_vision（§3.5③）
- **双币种条目**：USD（provider=zai）与 CNY（provider=bigmodel）分别建条目，CNY 侧需支持「输入长度分档」与「输出长度分档」的多档结构（5.1/5-Turbo/5/4.7/4.5-Air 均为多档价）
- **缓存字段建议**：`cacheWritePrice: 0` + `cacheWriteFree: true`（隐式缓存无写价）；`cacheReadPrice` 按两站各自比例；`storage_price_per_1m_hour: null`（当前限时免费，9/1 前复核）；`supports_cache_control: false（未实测确认）`；`supports_responses: false`

  ```jsonc
  {
    "id": "glm-5-2",
    "provider": "bigmodel", // zai = USD 国际站；bigmodel = CNY 国内站
    "currency": "CNY",
    "context_window": 1000000,
    "supports_vision": false, // GLM-5V-Turbo / 4.6V / 4.6V-FlashX / 4.6V-Flash / 4.5V 必须为 true
    "pricing": {
      "mode": "tiered", // 分档价；单档模型亦可用单条 tier
      "tiers": [
        {
          "input_length": { "gte": 0, "lt": 32000 }, // 输入长度档边界（32K/128K/200K）
          "output_length": null, // 输出长度档（GLM-4.7/4.5-Air 有 0.2M = 200K 边界）
          "input_per_1m": 5, // 元/百万 tokens
          "output_per_1m": 22,
          "cache_hit_per_1m": 1.2, // 缓存命中价
        },
      ],
      "cache": {
        "mode": "hit_plus_storage", // 国内站口径：命中价 + 存储费；两站均无 cache_write
        "cache_write_per_1m": null, // 无写价概念（隐式缓存）
        "storage_price_per_1m_hour": null, // 元/百万 tokens/小时，按小时计时；当前限时免费
        "storage_free_until": "2026-08-31", // 到期需复核恢复价
        "supports_cache_control": false, // 未实测确认
        "supports_responses": false,
      },
    },
  }
  ```

  要点：① tiers 数组按「输入档 × 输出档」组合展开（GLM-4.7 为 3 条、4.5-Air 为 3 条）；② 存储费单位是「元/百万 tokens/小时」、按小时计时，不是按请求一次性计费；③ GLM-5.1 输入 [32K+) 档命中价用户数据未提供，取 §3.1 ¥2 时须标注来源
