## 2. 缓存机制（2026-08-03 官方文档确认，双轨制）

**A. 隐式缓存（透明前缀缓存，自动）**

- 全自动、**无需配置且无法关闭**；官方计费文档口径「部分模型在 **2025-04-14 21:00** 开始支持透明前缀缓存能力」。
- 工作原理：系统基于请求输入**公共前缀**建缓存；后续请求开头与既有缓存条目前缀相同即尝试复用。**不保证命中**（缓存容量有限会被淘汰、分布式路由影响命中概率）、**不保证最长前缀命中**。
- **最低可缓存量：1024 tokens**（缓存块最少 1024 tokens 才会参与命中匹配，即请求输入至少 1024 tokens 才可能命中）。
- 命中输入按**缓存命中单价**计费（在线=输入价 20%、批量=40%），未命中按输入原价；**缓存存储不计费**；命中单价随模型输入长度分段变化（如 Seed 2.0 三档 0.64/0.96/1.92）。
- 支持模型（在线推理）：`doubao-seed-code`、**doubao-seed-2.0 及之后系列**（含 2.1-pro/turbo、evolving）；批量推理场景：支持模型全部开启。API：Responses / Chat / Batch 均生效。
- 计量字段：`usage.prompt_tokens_details.cached_tokens`（>0 命中，=0 未命中）。

**B. 显式缓存（需主动创建，确定性命中）**

- 与隐式互斥：**请求使用显式缓存时隐式缓存不生效**。
- 两种类型：**Session 缓存**（存储初始信息并随每轮对话更新，适合多轮对话/工具调用）与**前缀缓存**（固定初始信息，适合标准化开场白/超长文本静态模板）。
- 两种 API：Responses API（`"caching": {"type":"enabled"}` 创建 Session、`{"type":"enabled","prefix":true}` 创建前缀缓存，`previous_response_id` 引用；**前缀缓存最低 256 tokens**，Session 无限制；保留期最长 7 天，支持删除任意 ID）与 Context API（`context_id` 引用；仅文本；TTL 最大 168 小时，到期未使用自动过期）。
- **缓存存储计费**：显式缓存存储按小时计费（单价见下 §存储费），隐式不计费。
- 计费项：存储费 + 命中输入折扣价（与隐式相同分段单价）。
- 支持模型（Responses 前缀/Session）：doubao-seed-evolving / 2.1 / 2.0 / 1.8 / 1.6 系列、glm-5.2、glm-4.7、deepseek-v4-pro/flash、deepseek-v3.2 等；**doubao-1.5 系列（即将下线）仅 Context API 的 Session/前缀（rolling_tokens 模式）**。

**C. 计费公式与存储费**

- 在线推理：`费用 = 输入(非音频)单价 × 输入(非音频)token + 输入(音频)单价 × 输入(音频)token + 缓存命中(非音频)单价 × 缓存命中(非音频)token + 缓存命中(音频)单价 × 缓存命中(音频)token + 缓存存储单价 × 缓存存储token × 时长 + 输出单价 × 输出token`。
- **缓存存储单价 = 0.017 元/百万 token/小时**，适用表 1.1/1.2 中所有带缓存价格的模型（seed-translation、1.5-vision-pro 等无缓存模型除外）；存储按**每个自然小时内存储的最大 token 数**计费。
- 计量计费项字段：`prompt_token`（未命中输入）/ `cached_token`（命中输入）/ `completion_token`（输出）。
- 缓存命中计费/出账：在线与批量推理的缓存命中均为**准实时计费出账**（5 分钟级），缓存存储为按小时出账。

## 3. 特化优化线索（seed 2.1 / 长上下文档位 / 分段计费）

1. **seed-2.1 单档定价（关键差异 vs 2.0）**：2.1-pro/turbo 的「条件」列为 `输入长度 [0, 256]` 千token——**256K 内单一单价、无分段加价**；而 2.0 系三档（[0,32]/(32,128]/(128,256]）命中价与输入价逐档上浮（3.2→9.6，命中 0.64→1.92）。长上下文（>128K）场景下 2.1 的成本显著优于 2.0。
2. **上下文/输出/思维链全 256k**：seed-2.1 最大输入 256k、最大回答 256k、思维链 256k（与 2.0 的 224k 输入/128k 输出/128k 思维链不同）；doubao-seed-evolving 为 1024k 上下文单档。
3. **命中折扣差异**：在线常规 20%、批量推理 40%（官方「4 折」口径）；低延迟命中同为 20% 但输入价是常规 2~3 倍——批量推理是长上下文高命中场景的最优通道。
4. **音频输入仅 seed-2.0-lite 在售**：其他模型的音频列均为「-」（不支持或未开放），成本计算无需为 2.1 预留音频项。
5. **1.8/1.6 系命中价恒定**：seed-1.8/1.6/1.6-lite/1.6-vision/1.6-flash 命中价不随分段变化（0.16/0.06/0.03 恒值），长分段下命中折扣实际放大（如 1.6-flash 256k 段命中 = 输入价的 5%）。
6. **转售 GLM/DeepSeek 缓存语义与自研一致**：同样按 20% 命中（glm-5.2 为 25%）+ 0.017 存储费，无厂商差异（与 z.ai 官方通道的 18% 命中价不同，见 00-catalog §4）。
