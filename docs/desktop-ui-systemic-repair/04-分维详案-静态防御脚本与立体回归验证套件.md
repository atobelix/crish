## 一、维度目标与断言防御哲学

根据用户裁决：「我们的断言应该都是根据当前软件出现的问题，一步步地加强才对，以保证防御脚本能够设计的更全面、坚固和可靠，这样后面的 agent 在改动代码的时候，就能快速根据防御脚本的指引正确的配置（包括不限于 token 体系、色彩体系等前端内容，当然后端内容也一样重要）」。

本维度负责将本次排查出的**所有物理缺陷、并发状态机竞态、几何避让规则与 Design Token 约束**硬编码转化为永久性、刚性的防御脚本与立体验证套件，构建全方位的防回归护城河。

## 二、纯逻辑执行步骤与任务单元

### 任务单元 4.1：静态卫生检查防御脚本 `scripts/check-tooltip-hygiene.mjs`
- **文件域**：`scripts/check-tooltip-hygiene.mjs`
- **防御目标与拦截规则**：
  1. **拦截原生 HTML `title` 属性回潮**（零容忍）：
     - 扫描 `apps/crish-desktop/src` 源码，除特定 SVG 标签外，严禁任何 JSX 节点使用裸 `title="..."`（违反 §12 规则）；
  2. **拦截裸文字复读机式 Tooltip**：
     - 静态 AST/正则检测：当 `<Button>文本</Button>` 或类似组件被 `<Tooltip content="文本">` 包裹且两者文字完全相同时，直接报错阻断并输出优化指引；
  3. **拦截 Tooltip 相关裸色值与硬编码**：
     - 检查 `Tooltip.module.css` 及消费方样式，禁止裸写 `#fff`、`rgba(...)`、`px` 魔术数字，强制调用 `tokens.css` 变量；
  4. **门禁集成**：接入 `package.json` 的 `npm run check:desktop` 链条。

### 任务单元 4.2：布局几何与 Token 契约防御脚本 `scripts/check-layout-geometry.mjs`
- **文件域**：`scripts/check-layout-geometry.mjs`
- **防御目标与拦截规则**：
  1. **顶栏单轨同层高度校验**：
     - 检查 `AppTopBar.module.css` 中的 `height` / `min-height` / `max-height` 必须严格等于 `var(--header-height)` 或 `36px`，严禁多层顶栏或双重高度；
  2. **避让体系 Token 引用校验**：
     - 检查 `PaneHeader.module.css` 必须包含基于 `[data-top-row="true"][data-right-edge="true"]` 对 `var(--edge-reserve-right-win)` 的避让声明，严禁物理缺失避让或裸写像素。

### 任务单元 4.3：Tooltip 高频并发争抢与孤儿 rAF 压力测试套件
- **文件域**：`apps/crish-desktop/src/components/ui/Tooltip/Tooltip.adversarial.test.tsx`
- **测试场景设计**：
  1. **高频扫射测试（100ms 快速刷过 10 个按钮）**：
     - 模拟真实用户快速划过工具栏，在 100ms 内连续派发 10 组 `mouseEnter -> 10ms -> mouseLeave`；
     - 断言：所有嵌套 rAF 被彻底取消，`isMounted` 同步为 `false`，DOM 树中的 `[data-tooltip-portal="true"]` 节点数为严格为 0；
  2. **单槽互斥排他性测试（并发激活）**：
     - 两个 Tooltip 同时触发 `scheduleShow`，断言后者抢占插槽后，前者立刻销毁，任何瞬间 DOM 树中 Tooltip 数量绝对 $\le 1$；
  3. **离屏/失焦/滚动自毁测试**：
     - Tooltip 显示期间，触发 `window.scroll`、`blur`、`Escape`，断言立即物理销毁；
  4. **Shortcut 徽标渲染测试**：
     - 验证传入 `shortcut="Ctrl+N"` 或 `shortcut={['Ctrl', 'Shift', 'P']}` 时，徽标结构正确生成并附带可访问性属性。

### 任务单元 4.4：顶栏同层避让与窗控可点性回归测试
- **文件域**：`apps/crish-desktop/src/components/top-bar/AppTopBar.test.tsx`
- **测试场景设计**：
  - 断言 `AppTopBar` 挂载在工作区列上时不占据垂直文档流空间；
  - 断言 `.trail` 内部按钮在全屏和分屏状态下均具有正常的 pointer-events 与点击响应。

## 三、闭环验收准则（客观物证清单）

1. **静态防御物证**：
   - 执行 `node scripts/check-tooltip-hygiene.mjs` 输出 `✓ Tooltip hygiene check passed (0 violations)`；
   - 执行 `node scripts/check-layout-geometry.mjs` 输出 `✓ Layout geometry check passed`；
2. **测试套件物证**：
   - 执行 `npx vitest run src/components/ui/Tooltip/Tooltip.adversarial.test.tsx` 全绿（100% 通过）；
   - 执行 `npx vitest run src/components/top-bar/AppTopBar.test.tsx` 全绿；
3. **真实环境物证**：
   - 启动 Tauri 桌面宿主（4000 端口），实测顶栏 Tab 与 Windows 窗控并排处于第一行，总高锁定 36px，无第二行空白；
   - 鼠标在界面各处扫射，悬停提示精准呈现、移开即灭，零幽灵、零残留。
