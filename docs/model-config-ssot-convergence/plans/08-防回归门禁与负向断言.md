## 4. 交付物三：防回潮文档（供后续 AI 阅读）

**内容**（面向「后面的其他 AI」）：

1. **本战役锁定的不变量清单**（INV-1…INV-13），每条附「违反示例 + 正确做法」。
   - 2026-09-13 新增：INV-13（词表外键必须显式诊断）；INV-11/INV-12 已按 W9/W10 定案修订。
2. **允许与禁止的对照表**：
   - 模型字典：✅ 仅新增表单预填；❌ 任何兜底/能力判定
   - 活动选择：✅ localStorage 单键成对读写；❌ AppSettings 第二轨
   - 解析：✅ `(providerId, modelId)`；❌ 裸 modelId 跨厂商
   - 协议：✅ `modelsNormalize.PROTOCOLS`；❌ 各处字面量
   - 缓存 TTL：✅ yaml `cacheTtl`；❌ 字典/前缀表推断
   - 配置读失败：✅ 显式错误；❌ 静默返回空
3. **门禁脚本使用方式**：`node scripts/check-model-config-ssot.mjs`，以及失败时的定位方法。
4. **改代码前的检查清单**：若你的改动触碰模型/供应商配置，先跑门禁，读本速查，再改。

**这份文档是本维最重要的「用户可感知增量」** —— 它让后续 AI 无需读完整战役历史即可正确配置。
