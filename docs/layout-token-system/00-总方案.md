## 1. 旧方案评审结论（冻结，不再返工叙事）

**诊断可用，施工文本需按本 v2 收敛。** 已确认仍成立的病理（代码实证）：

1. small 档 `--space-1: 3px` / `--space-2: 5px` 奇数；`2_5` 与 `3` 同为 6px、`3_5` 与 `4` 同为 10px 塌缩。
2. large 档间距与 `:root` 完全相同（零缩放），大字下反向拥挤。
3. `var(--space-2, 6px)` 等错误 fallback 认知错位（真实值 8px）。
4. 根 `--button-radius: 8px` 与 light 块 `var(--radius-btn)`(7px) 撕裂；组件 fallback 7/8 混用；部分单测仍钉 8px。
5. `AppTopBar` 绝对定位 + `100vw`，下游多层 `--edge-reserve-*` / `--header-height` 手工避让。
6. macOS 展开态侧栏与交通灯重叠；`--shell-gutter` 被注释为 0。
7. `.leafChatColumn` 后代穿透；宿主内嵌 note 绝缘补丁；`.leafBody` 边框失效。
8. `.listInner` 纵向 `padding: 48px` 与 `chatScrollGeometry.ts` 双轨；契约测试持续红。
9. Composer 进度条 `margin-bottom: -10px` + `calc(100%-36px)`；单多行 padding/radius 突变；184 行重复块。
10. 工具卡多层边框 + `!important`；`SettingsUI` 0.1px；`handleRootWheel` 被误定性为纯补丁。

**已否定 / 必须废弃的旧主张：**

| 废弃主张 | 原因 |
|:---|:---|
| 全站按钮圆角改 8px | 推翻用户锁 U1 |
| Compact 矩阵 00/01 两套数 | 互殴且公式≠表、仍有碰撞 |
| Primitive 数字系全面 `--space-50/100` 三轨命名 | 迁移面过大，BATCH 内不做 |
| AST 自动升格语义 Token | 意图不可判定 |
| Composer 22/24 自由推导 | 改为 U2 阶梯 20/24 |
| 清全部 `.sendBtn` | field 模式仍消费，只删重复第二份 |
| leaf-insulate 测试整文件替换 | 会毁掉 IA / FloatHandle 等资产 |
| 拔除全部 `handleRootWheel` | 先保留侧栏联动职责；models 已早退；另波处理 |
| `check:desktop` 写进 apps 包并缩链 | 必须挂根目录既有链 |

## 2. 架构原则（收紧版）

1. **效果锁**：用户裁决（§0）与 AGENTS 铁律优先于「偶数公理」「工业级引用」。
2. **诚实分层（可落地版）**：
   - **Tier 1 物理刻度**：`--space-*` / `--radius-*` 字面量；**默认档**为权威物理值。
   - **密度换挡**：允许在 `[data-ui-size]` 上改写**同一套** `--space-*` 名（现网消费方式），但必须 **严格单调、全偶数、零碰撞**；禁止再发明第三套数字名。
   - **Tier 2 语义**（本战役渐进）：`--chat-*` / `--composer-*` / `--shell-*` 等**场景契约 Token**，组件优先消费语义层。
   - **Tier 3**：组件模块内局部变量；**不**把组件契约堆进 `:root`。
3. **同心圆角**：适用于「子元素贴满 padding box、均匀 padding」的嵌套卡/滑块；有 border 时按 $R_i=\max(0,R_o-P-b)$；贴边 header/footer、非贴角布局 **豁免**。
4. **负 margin**：文档流破坏性负 margin 清零；允许 `-1px` 分割线贴合；位移优先 `transform` / 流内布局。
5. **几何 SSOT**：虚拟滚动纵向几何以 `chatScrollGeometry.ts` 为唯一真源；CSS 不得再写同值纵向 padding。
6. **反过度设计**：不新增平行门禁解析器；不写数学定理修辞；矩阵以**表 + 单测**断言，不写「封闭性证明」。

## 3. 圆角阶梯（U2 定稿 · SSOT · 保守迁移）

**目标阶梯（U2）**：`4 / 6 / 8 / 12 / 16 / 20 / 24` + 按钮锁 7px。

**现网兼容落点（BATCH-01 不得破坏像素）**：

```
--radius-xs:   2px;  /* 维持现网 micro */
--radius-sm:   4px;
--radius-md:   6px;
--radius-lg:   8px;
--radius-xl:  12px;
--radius-2xl: 12px;  /* 过渡：与 xl 同值（现网）；消费者迁到 xl 或 3xl 后再在 BATCH-05 升 16/20 */
--radius-3xl: 24px;  /* U2 新增：Composer 多行等 */
--radius-full: 9999px;

/* 用户锁例外（U1）——不进入通用阶梯 */
--radius-btn: 7px;
--button-radius: var(--radius-btn); /* :root 唯一定义；密度档禁止改写 */
```

**组件落点：**

| 组件 | 圆角 |
|:---|:---|
| Button / Input / 设置类控件 | `var(--button-radius)` → **7px** |
| SegmentedControl default | `var(--button-radius)` → **7px** |
| Composer 单行胶囊 | `var(--composer-radius-single, 20px)`（新语义 Token） |
| Composer 多行 | `var(--composer-radius-multi, var(--radius-3xl))` → **24px** |
| 用户气泡 | `var(--chat-bubble-radius, 16px)`（新语义 Token，**禁止**改全局 `--radius-2xl` 去凑气泡） |
| 叶卡 / 工具卡 | `var(--radius-lg)` → **8px** |

**迁移纪律**：BATCH-01 只新增 `--radius-3xl` / composer/chat 语义 Token 与 7px 单源；**不**把 `--radius-2xl` 从 12px 改成 16/20（避免 Dialog/侧栏菜单等未点名消费者静默变圆）。

## 8. 门禁体系（v2）

1. **扩展而非新建**：在 `scripts/` 增加 layout 规则时，**复用** `check-input-guardrails.mjs` 的 `extractCssRules` 块级解析，或抽共享 parser；禁止第三套行级正则引擎。
2. **基线**：沿用仓库 markdown 标记区 + `--update` 约定（同 `check-token-consistency`），**禁止**仅口号无代码的 Phase 0。
3. **规则优先级（落地顺序）**：
   - R1 负 margin（>2px，白名单 -1px）
   - R2 错误 fallback 与 default 不等价
   - R3 密度表完整性/单调/偶数（读 tokens.css）
   - R4 破坏性 `:global(子组件类)` 穿透（选择器语义，非字符串一刀切）
4. **接线**：只挂**根** `package.json` 的 `check:desktop` 追加一项；不新建同名脚本覆盖。
5. **`layout-contract.test.ts`**：与密度/7px/负 margin 源码断言绑定；断言写解析结果而非脆弱引号字面量。
