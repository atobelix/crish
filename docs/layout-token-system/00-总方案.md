## 一、战役背景、全景愿景与战略原则

### 1.1 核心病理全景与战役迫切性

在第一阶段（8 份深度调研报告，总计 4,869 行源码事实）与第二阶段（6 份专项方案，总计 5,337 行工程详案）的深入分析中，Conex / Crish 桌面端的内外边距、祖父/父子容器链与布局系统暴露出一组相互咬合、连锁劣化的**六大深层结构性断层**：

1. **Token 单层裸标量与密度换挡崩溃**：
   - 现存系统仅有 `--space-0_5` 至 `--space-10` 扁平裸标量，缺乏语义与组件层；
   - `[data-ui-size='small']` 引入 3px 与 5px 奇数像素，破坏偶数网格并引发高分屏模糊；发生刻度塌缩（2_5 与 3 同为 6px，3_5 与 4 同为 10px）；遗漏 `--space-8` 与 `--space-10`；
   - `[data-ui-size='large']` 间距零缩放，大字大按钮下界面“反向拥挤”；全仓充斥 `var(--space-2, 6px)` 错误 fallback 与代偿性负外边距。
2. **`AppTopBar` 绝对定位浮动的穿透代价**：
   - 顶栏 `position: absolute; top: 0; width: 100vw; pointer-events: none;` 在普通流中占位为 0，迫使侧栏、工作区窗格、PaneHeader、全屏 SettingsPanel 各自感知 `--header-height: 36px` 手写避让；
   - macOS 展开态侧栏因缺少系统安全区避让，开关按钮与系统交通灯（0~70px）直接物理重叠；全屏态右侧窗格仍死板保留 144px/38px 预留；
   - `--shell-gutter` 因绝对顶栏与二叉树 Sash 绝对坐标冲突，被一刀切注释为 `padding: 0`，致使画布硬贴边、丧失进深。
3. **二叉树工作区 Descendant Hacking 与绝缘死锁**：
   - `BinaryTreeWorkspace.module.css` 声明 `.leafChatColumn > *:not(...) > * > *:not(...)` 跨越两层强加弹性，与包装组件的 `display: contents` 产生规范断层；
   - 宿主外壳越权硬编码笔记扩展的 `[data-note-leaf-host]` 与 `[data-testid='note-paper-strict-panel']` 绝缘补丁，并被既有单测 `leaf-insulate.test.ts` 固化为负向债务；
   - `.leafBody` 卡片边框被注销，导致激活态 `.leaf[data-active='true'] .leafBody` 高亮完全失效。
4. **消息流几何 SSOT 断裂与负 Margin 破坏**：
   - `ChatMessageList.module.css:36` 的 `padding: 48px 20px 16px;` 与虚拟滚动切片 `MessageVirtualizer.tsx` 依赖 `chatScrollGeometry.ts`（`top: 48px`）形成双重内边距冲突，导致 `VirtualScrollGeometryContract.test.ts` 持续报红；
   - 搜索高亮行采用 `margin-left: -6px; margin-right: -6px; width: calc(100% + 12px);` 且增加了 `padding-top: 4px`，引发物理高度突增与虚拟滚动密集失效；
   - 用户气泡 16px 圆角因 `:root` 定义 12px 导致 fallback 欺骗性失效；元数据栏助手 22px 与用户 28px 撕裂；残留 116 行 `.pinnedBar` 僵尸代码。
5. **Composer 抽屉舌头负边距与四层堆叠耦合**：
   - 计划进度条与权限审批条硬编码 `width: calc(100% - 36px); margin-left: 18px; margin-bottom: -10px;`，用负边距塞入主卡片底部制造抽屉假象，迫使折叠态反向加内边距 `padding: 6px 12px 14px 12px;` 垫高文字；
   - 单多行切换四向内衬剧烈突变，权限胶囊从右侧融合跨区域瞬移至左下角独立药丸；
   - 多行外圆角 20px 破坏同心圆角法则（$20 < 14 + 8 = 22\text{px}$）；附件卡片 58px vs 52px 跨主题漏配分裂；残留 184 行重复代码与 32px 旧按钮。
6. **复合卡片发丝边框污染、设置页滚轮补丁与样式门禁失效**：
   - 工具卡片层层嵌套产生 3 重发丝边框，使用 4 个 `!important` 暴力重置；头部高度存在 8 级离散（22~36px），指示点 4/5/6px 混用；
   - 全屏设置面板长文档与工作台共享容器，在 TSX 中书写 29 行 `handleRootWheel` 补丁代码防御双倍速狂飙滚动；`SettingsUI` 存在 0.1px 亚像素危险边框；
   - 现存 `style-contract.test.ts` 现场 5 项断言失败（暗色漏定义、裸混色通胀至 53 处、8px 圆角锁冲突等），全仓对裸像素间距与负 margin 零拦截。

### 1.3 六大不可突破工程铁律（零容忍）

依据 `AGENTS.md` §1 与 §7，本战役全生命周期严格执行以下硬性铁律：

- **铁律一（效果锁与纯逻辑）**：严禁以“先做简化版”、“砍掉自研布局”、“直接用现有样式凑合”等理由退避；所有尺寸必须在数学公式与盒模型公理下获得严格解释与立体验证。
- **铁律二（绝对偶数防线）**：除 1px 物理发丝边框白名单外，全仓间距与圆角严禁 3px、5px、7px、11px 等奇数像素与 0.1px 亚像素数值，高分屏缩放必须保持纯净整数或半整数。
- **铁律三（零破坏性负 Margin）**：严禁在文档流中使用负 margin 进行位置侵入、高度抽离或制造遮盖假象；除 -1px 分割线贴合白名单外，所有浮动位移一律移交 GPU 合成层（`transform: translateY`）。
- **铁律四（零后代穿透与单一真理路径）**：严禁宿主样式表向子组件深层注入 `:global(...)` 穿透规则；组件高度与内衬由组件表面契约自闭环；样式变量严禁在 fallback 中随意捏造。
- **铁律五（几何单一真理 SSOT）**：CSS 样式定义与 TypeScript 虚拟计算模型必须单轨归一，杜绝双重内边距与双轨数据漂移。
- **铁律六（绝对禁止绕过门禁）**：严禁 `--no-verify`，严禁调高契约基线来掩盖新增违规；既有 5 项契约失败必须正向根除。

- **同心圆角刚性数学法则**：

```
├────────────────────────────────────────────────────────────────────────┤
│ 规则 4: Fallback 单源与奇数像素校验 (Fallback & Even-Grid Guard)        │
│   - 校验 var(--space-N, fallback) 的 fallback 必须与 :root 静态值等价  │

```
