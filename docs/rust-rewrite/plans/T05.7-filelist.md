## 4. 豁免清单（wire 契约 / 运行时匹配，不动）

| 项 | 理由 |
|---|---|
| `apps/agent-workbench/` 全部 daemon 引用（`shared/workbench-contract/daemon-session.ts`、`daemon-status.ts`、`Daemon*` 类型、`tauri-command-registry.ts` 的 `update_daemon_config` / `workbench_restart_daemon` / `DAEMON_DISCONNECTED_CODE = "daemon-disconnected"`、`DaemonLifecycleDiagnosticSource` 字面量 `"daemon"`/`"websocket"` 等） | agent-workbench 的 daemon = **存活的引擎 daemon**（Rust 侧仍用 daemon 命名：`network.daemon_dead`、`daemon-restarted`、`update_daemon_config`），为 commandManifest/transport 契约层，命令名/事件名必须不变（任务书「wire 层不动」） |

| `api/engineConfig.ts` 全部 daemon/websocket 提及 | legacy 配置兼容（`normalizeEngineEndpointKind('websocket') → undefined`）+ 注释；配置值是 wire 形状 |
| 历史注释（`binaryFrame.ts` 文档、`directFetchBridge.ts`、`transport/types.ts` 职责替换表、`error-translation.ts`、`store/*` 注释等）与测试 prose（describe/it 文案） | 任务验收「旧名文件引用归零，除文档/注释」；注释/文案非文件引用 |
