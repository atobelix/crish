## 二、终局融合收敛方案架构

### 1. 领域数据源（SSOT）与聚合 Hook

在 `apps/crish-desktop/src/components/overview/changes/useSessionScopedChanges.ts` 中实现专有 Hook：
- **第一真理源**：当前激活会话 `sessionsById[activeSessionId]` 的 `messages`（包含主消息与 `agents[].messages`）；
- **派生算法**：复用经过严密验证的纯函数 `selectSessionDiffFiles(messages, workspaceRoot)`；
- **实时编辑联动**：合并 `terminalStore.diffFiles` 中属于当前会话的最新编辑项；
- **纯净性保证**：无消息或无修改工具调用时，严格返回 `[]`，改动计数严格为 `0`。

### 2. 组件树单一职责拓扑（全面接入 @/components/ui）

```
apps/crish-desktop/src/components/overview/changes/
├── ChangesSection.tsx             # 容器协调器（≤ 100 行）：管理展开折叠与当前 scope
├── ChangesSectionHeader.tsx       # 头部：标题、Badge 计数胶囊、SegmentedControl、刷新按钮
├── SessionChangesView.tsx         # 会话主视图：仅展示当前对话产生的改动
├── WorkspaceGitChangesView.tsx    # Git 次级视图：仅在用户显式切入时展示工作区 51 个改动及分支
├── ChangesFileList.tsx            # 通用文件列表：接入 ScrollArea、Tooltip 与 DiffStatBar
├── ChangesEmptyState.tsx          # 规范纯净空状态：无背景色/描边违规，优雅灰阶排版
└── types.ts                       # 强类型定义
```

### 3. 设计系统组件接入规范

- 模式切换：`<SegmentedControl size="xs" options={[{ value: 'session', label: '当前会话' }, { value: 'git', label: 'Git 仓库' }]} />`；
- 改动计数：`<Badge tone="neutral" size="sm">{count}</Badge>`（仅在 `count > 0` 时显示）；
- 刷新按钮：`<IconButton variant="ghost" size="sm" icon={<RefreshCw />} />`；
- 列表滚动：`<ScrollArea maxRelativeHeight={320} type="auto">`。

### 4. 负产出与删除面

1. 物理删除 `ChangesSection.tsx` 中三元操作符 `treeGitFiles.length > 0 ? treeGitFiles : normalizedConvoFiles`；
2. 物理删除头部 `({branch})` 强行绑定；
3. 物理删除会话模式下无差别弹出的 `gitHelp` 侵扰块；
4. 物理删除散落的 `.pill` 裸 `<span>` 样式。
