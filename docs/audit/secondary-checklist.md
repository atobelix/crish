## A. 安全（Security）

- [ ] **命令/路径注入**：Tauri / 本地文件服务 / 终端相关 API 是否校验路径沙箱（禁止跳出工作区）。
- [ ] **IPC 入参校验**：前端 → Rust 命令参数有类型与边界校验，拒绝异常大 payload。
- [ ] **Markdown / 富文本 XSS**：渲染流水线（BATCH-21/16）是否消毒或安全组件；外链/图片策略明确。
- [ ] **附件与预览桥**（BATCH-24/26）：多模态附件、外置预览是否限制协议（`file://` / 自定义 scheme）与扩展名。
- [ ] **密钥与供应商配置**（BATCH-19/25）：API Key 是否只存安全存储，日志/崩溃上报不泄露。
- [ ] **扩展契约边界**（BATCH-26）：第三方扩展权限最小化，无任意代码执行后门。
- [ ] **注入卡片废除**（BATCH-08）：确认无残留注入路径、定时任务确认流程不可被伪造绕过。

## B. 并发（Concurrency）

- [ ] **Rust 侧**：`relay` / `db` / markdown 管线（BATCH-09）共享状态是否用正确锁或消息通道，无阻塞 UI 线程。
- [ ] **流式对话**：流式状态槽（BATCH-23）并发更新是否竞态（重复 token、乱序、重复 finalize）。
- [ ] **文件服务 / 端口探测**（BATCH-15/21）：异步任务取消是否彻底（组件卸载后不再回调）。
- [ ] **桌面运行期引擎**（BATCH-14）：多窗口 / 多会话下资源是否串扰。
- [ ] **输入区发送控制**（BATCH-24）：斜杠命令 / 发送防抖，避免双发。

## C. IPC（Tauri / 宿主契约）

- [ ] **契约文档与实现一致**（BATCH-14）：命令名、参数、错误码前后端对齐。
- [ ] **错误传播**：Rust `Err` → 前端可观测，无静默吞错。
- [ ] **事件订阅**：`listen` / `emit` 生命周期与卸载解绑成对。
- [ ] **拖拽区域**（BATCH-27）：自定义标题栏拖拽不拦截按钮点击；多平台差异已覆盖或注明。
- [ ] **设置中心 / 主程序装配**（BATCH-26）：启动顺序无死锁；插件加载失败可降级。

## D. 虚拟列表 / 滚动性能

- [ ] **对话虚拟列表**（BATCH-23）：跟随底部、流式增高时无跳抖；估算高度 / 测量策略合理。
- [ ] **差异 / 代码引擎虚拟滚动**（BATCH-10）：大文件行缓冲正确，滚动不丢行、不错位。
- [ ] **MarkdownDocumentView / ScrollArea**（BATCH-16）：长文档滚动性能与滚动条 token 一致。
- [ ] **文件差异列表**（BATCH-10/11）：列表与预览导航联动时无全量重渲染。
- [ ] **Avatar Studio 视口**（BATCH-13）：虚拟化身工作室列表/画布在大数据下可交互。

## E. 内存泄漏 / 资源泄漏

- [ ] 组件 `useEffect` / 订阅 / `ResizeObserver` / `IntersectionObserver` 有清理。
- [ ] 流式 reader / AbortController 在卸载或切会话时 abort。
- [ ] Blob / ObjectURL（附件预览）有 `revokeObjectURL`。
- [ ] Tauri 事件 listener 成对 `unlisten`。
- [ ] 虚拟列表缓存 / 行缓冲有上限或 LRU，长会话不无限涨。
- [ ] WebView / 预览桥关闭后进程或窗口资源释放。

## F. 死代码 / 架构腐化

- [ ] BATCH-08「废除注入大卡片」后无死引用、死路由、死样式。
- [ ] 旧 diff/note 路径与新架构并存时，废弃模块有标记或删除计划。
- [ ] 设计 Token（BATCH-17）落地后无大量硬编码色值回潮。
- [ ] 门禁脚本（BATCH-18）覆盖真实违规路径，无空跑。
- [ ] 文档 BATCH（12/19/25）与代码实现无「文档已写、代码未接」断层。

## G. 测试缺口

- [ ] **单元**：块编辑原子操作 / 块 ID 索引（BATCH-20）；消息行/工具卡片渲染边界（BATCH-22）。
- [ ] **IPC 契约测试**：关键 command round-trip 与错误路径。
- [ ] **虚拟列表**：大数据集滚动 / 跟随 / 流式追加冒烟（可自动化或手测清单）。
- [ ] **Markdown 渲染**：XSS 用例、代码块、表格、长文档。
- [ ] **门禁脚本**（BATCH-18）：CI 或本地可复现；失败信息可定位。
- [ ] **回归**：BATCH-08 防回潮铁律是否有自动化守卫。
- [ ] **缺失清单**：主审未覆盖的 BATCH，二次核查需补抽查。
