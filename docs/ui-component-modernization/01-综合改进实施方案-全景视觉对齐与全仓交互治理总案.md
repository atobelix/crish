## 二、详细技术实现规格与分步施工图

### Track 01：Switch 几何对称与纯粹流体胶囊
1. **源码文件**：[`apps/crish-desktop/src/components/ui/Switch/`](file:///c:/Software/conex/apps/crish-desktop/src/components/ui/Switch/)
2. **改造要点**：
   - 彻底移除 `checkIcon` 与 `@keyframes checkmark-draw`；
   - 滑块定位由静态 `top: 1px` 改为 `top: 50%; transform: translateY(-50%)`；
   - 注入 `0 0 0 0.5px color-mix(in srgb, var(--border-color) 40%, transparent)` + `0 1px 2px rgba(0, 0, 0, 0.05)`，消除阴影下坠视错觉；
   - 保留 Pill Stretch 流体果冻物理形变与 `hasInteracted` 挂载门闩。

### Track 02 & Track 05：Select / Combobox 架构拆解与多行自适应
1. **源码文件**：[`apps/crish-desktop/src/components/ui/Select/`](file:///c:/Software/conex/apps/crish-desktop/src/components/ui/Select/)、[`apps/crish-desktop/src/components/chat-composer/PermissionModeMenu.*`](file:///c:/Software/conex/apps/crish-desktop/src/components/chat-composer/PermissionModeMenu.tsx)
2. **改造要点**：
   - **Select 拆解**：`SelectRoot.tsx`, `SelectTrigger.tsx`, `SelectValue.tsx`, `SelectContent.tsx`, `SelectItem.tsx`, `SelectGroup.tsx`, `SelectSeparator.tsx`, `SelectLegacyAdapter.tsx`；
   - **Combobox 拆解**：`ComboboxRoot.tsx`, `ComboboxInput.tsx`, `ComboboxChips.tsx`, `ComboboxContent.tsx`, `ComboboxList.tsx`, `ComboboxItem.tsx`, `ComboboxEmpty.tsx`；
   - **多行自适应**：`.menuItem` / `.permMenuItem` 改为 `min-height: 32px; height: auto;`，内部使用 Flex 垂直弹性排版，浮层宽度自适应（260px~340px），彻底根治文字重叠；
   - **无状态正则**：移除 `highlightMatches` 中带 `g` 的正则测试，根除 `lastIndex` 变异 Bug；
   - **IME 状态锁**：引入 50ms 缓冲门闩拦截拼音回车穿透。

### Track 03 & Track 04：设置页分段控件与字体选择器升级
1. **源码文件**：
   - [`apps/crish-desktop/src/components/ui/SegmentedControl/`](file:///c:/Software/conex/apps/crish-desktop/src/components/ui/SegmentedControl/)

   - **大圆角规格**：分段控件外壳支持 12px/14px 大圆角规格，滑块严格满足同心公式 $R_{\text{inner}} = R_{\text{outer}} - \text{Padding}$；
