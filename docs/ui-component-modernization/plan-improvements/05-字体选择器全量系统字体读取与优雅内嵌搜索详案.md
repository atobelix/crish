## 一、方案背景与核心痛点解剖

### 1.1 存量字体选择器痛点清单

在当前的 Conex / Crish 桌面端设置页中，字体选择器 (`FontSettingsSection.tsx` / `FontSelectField.tsx` / `fontStoreCatalog.ts`) 承担着界面字体（UI Font）与代码字体（Mono Font）的定制职责。然而经过深度代码审查与交互体验审查，现存架构存在以下 5 大核心痛点：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            存量字体选择器痛点拓扑                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [痛点 1: 本机字体探测极为受限]                                              │
│  仅依赖 Canvas 测宽 15 个硬编码精选字体，用户安装的上百款优质中文字体无法探测   │
│                                                                             │
│  [痛点 2: 搜索与下拉菜单脱节]                                               │
│  顶部输入框仅作为独立的「自定义字体名草稿」，键入时不改变下方下拉列表内容       │
│                                                                             │
│  [痛点 3: 缺少拼音/缩写模糊搜索]                                             │
│  用户输入 "yahei" / "wryh" / "pf" 无法命中 "Microsoft YaHei" / "PingFang SC" │
│                                                                             │
│  [痛点 4: 操作栏与搜索栏混杂堆叠]                                           │
│  右侧操作按钮与输入框挤在 28px 狭小头部，缺乏清晰的 Warm-Gray 层级与交互动效    │
│                                                                             │
│  [痛点 5: 大列表潜在卡顿与 IME 冲突]                                         │
│  若读取 1,000+ 系统字体，缺乏切片优化；中文输入法选词回车易误触提交           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **本机字体探测能力极为简陋（仅探测 15 种字体）**：
   `fontStoreCatalog.ts` 的 `listLocalFonts()` 仅对平台预设字典（如 Windows 下 10 个 UI 字体与 5 个 Mono 字体）循环调用 Canvas `measureText` 测宽。用户在系统中安装的数百款专业字体（如 HarmonyOS Sans、思源黑体、霞鹜文楷、Maple Mono、Fira Code、Monaspace 等）根本无法被列出，必须手动输入准确英文名称，门槛极高。
2. **搜索输入框与下拉列表完全脱节（非即时过滤）**：
   当前 `customHeader` 中的 `<input>` 仅仅是一个“自定义字体名称输入器”，键入文本时，下方的 `options` 依然全量静态展示，无法起到搜索过滤作用；用户无法边搜边选，违背了现代 Combobox / Select 的交互直觉。
3. **缺少 CJK 拼音首字母与模糊搜索支持**：
   绝大多数中文桌面用户在寻找字体时习惯输入拼音全拼或首字母（如 `wryh` 找微软雅黑，`syht` 找思源黑体，`jb` 找 JetBrains Mono）。当前组件完全无搜索过滤能力，更无拼音索引。
4. **背景色彩杂乱与操作栏缺少设计规范**：
   搜索头部使用了透明或未归一化的背景，操作按钮缺少统一定义的 Hover 态与加载旋转动效，与 `tokens.css` 的 Warm-Gray 纯中性灰色阶未严格对齐。
5. **缺少 IME 输入法保护与大列表渲染优化**：
   在输入中文拼音时，按下 Enter 键会直接触发 `applyCustom`，导致未完成选词的拼音串被误写入字体配置；当读取全部系统字体后，大量 DOM 节点可能引起首帧展开轻微掉帧。

### 1.2 架构演进目标与达标矩阵

本方案旨在对字体选择体系进行全链路现代化重构，构建**双引擎全量系统字体读取**、**自研零依赖拼音模糊搜索**与**符合 Conex Warm-Gray 极简视觉的沉浸式内嵌选择器**。

| 维度 | 存量现状 | 本方案重构目标 | 达标标准 |
| :--- | :--- | :--- | :--- |
| **系统字体探测** | Canvas 硬编码测宽 15 个候选字体 | **双引擎读取**：优先 Chromium / Tauri `window.queryLocalFonts()`，降级 Canvas 精选探测 | 支持探测系统已安装的 **100% 全部字体**（通常 300~2,000+ 款），无感毫秒级响应 |
| **搜索与过滤** | 输入框仅充当孤立自定义文本，不联动过滤 | **原地实时双向过滤**：键入即刻对预设 + 系统字体列表进行模糊高亮过滤 | 过滤耗时 $\le 5\text{ms}$，首屏过滤结果无缝响应 |
| **拼音与模糊匹配** | 无任何匹配支持 | **内置零依赖 CJK 拼音首字母 + 全拼 + 英文子串加权算法** | 支持 `wryh` -> 微软雅黑、`pingfang` -> 苹方、`jb` -> JetBrains Mono |
| **自定义字体直达** | 点击右侧小 Check 图标或回车手动应用 | **回车直达状态机**：若无匹配项按 Enter 直接应用为 `local:XXX`，有高亮项回车选中高亮项 | 支持 IME 组合锁，50ms 时间窗口拦截输入法回车 |
| **底板与操作栏** | 杂乱样式，缺乏 Warm-Gray 归一 | 统一纯中性 `var(--bg-secondary)` 头部底板，右侧聚合 `<HardDrive>`（带 Spin）、`<RotateCcw>`、`<Check>` | 严格对齐 Design Tokens，消除冷蓝偏色，同心圆角方程精确对齐 |
| **性能与内存** | 无本地字体缓存，每次重复测宽 | **LRU + LocalStorage 双级元数据缓存 + 渲染切片** | 二次打开秒开（0ms 延迟），滚动 60fps 流畅不卡顿 |

## 二、全量系统字体读取双引擎架构

### 2.1 引擎 A：Chromium / Tauri `window.queryLocalFonts()` 全量提取

#### 1. Web Local Font Access API 原理与规范
在现代 Chromium 浏览器（Chrome 103+）以及基于 WebView2 / Chromium 的 Tauri 2.0 桌面环境中，标准提供了 `window.queryLocalFonts()` API。此 API 可直接枚举操作系统底层字体管理器（Windows DirectWrite / macOS CoreText / Linux Fontconfig）中注册的全部字体元数据。

```typescript
interface FontData {
  family: string;        // 字体族名，如 "Segoe UI", "Microsoft YaHei", "PingFang SC"
  fullName: string;      // 完整字体名，如 "Segoe UI Bold", "Microsoft YaHei Regular"
  postscriptName: string;// PostScript 名，如 "SegoeUI", "MicrosoftYaHei"
  style: string;         // 字形样式，如 "Regular", "Bold", "Italic"
  blob(): Promise<Blob>; // 字体二进制数据（本方案不读取 blob，确保零内存与零磁盘开销）
}
```

#### 2. 安全权限判定与无感知获取流程
在独立桌面端环境（Tauri WebView2 / Chromium Desktop）中，`window.queryLocalFonts()` 具有桌面级特权，无需弹窗或自动授权。在 Web 运行环境中，若受到浏览器的权限策略约束，系统将通过 `navigator.permissions.query({ name: 'local-fonts' as PermissionName })` 进行前置嗅探。若用户拒绝授权或浏览器抛出 `SecurityError` / `NotAllowedError`，系统自动捕获异常并无缝回退至引擎 B，绝不阻断 UI。

### 2.2 引擎 B：Canvas 测宽平台精选字体库降级探测

#### 1. 差分测宽探测原理
当处于不支持 Local Font Access API 的浏览器（如 Firefox、Safari、移动端浏览器）或用户未授权环境时，系统自动激活引擎 B。
引擎 B 采用 Canvas 2D 上下文差分渲染测宽法：
- 选择跨平台基准回退字体 `monospace` 与高敏感度多语言测试字符串：
  $$\text{ProbeString} = \text{"mmmmmmmmmmlli@字国Ww10"}$$
- 将字号设置为超大尺寸（$72\text{px}$）以放大微小字体特征差异；
- 先后测量基准字体与目标字体的渲染宽度 $w_{\text{base}}$ 与 $w_{\text{target}}$：
  $$\Delta w = |w_{\text{target}} - w_{\text{base}}|$$
  若 $\Delta w > 0.1\text{px}$，则判定该字体已在宿主操作系统中正确安装并生效。

### 2.3 字体族名归一化、多语言去重与本地元数据缓存（LRU / LocalStorage）

#### 1. 字体族名归一化与去重算法
操作系统中安装的字体可能存在别名重复（例如 `Microsoft YaHei` 与 `微软雅黑`、`PingFang SC` 与 `苹方-简`、`Noto Sans SC` 与 `思源黑体`）。同时，不同字重（Bold、Light、Regular）会产生多个 `FontData` 对象。
扫描引擎执行三道清洗工序：
1. **族名提取**：只取 `font.family`，忽略特定字重后缀（如 `Bold`, `Italic`, `Light`）；
2. **符号与控制字符清洗**：剔除 C0 控制符、非打印字符与可能引起 CSS 语法逃逸的特殊符号（如 `;`, `{`, `}`, `<`, `>`, `\\`）；
3. **大小写不敏感 Map 去重**：使用 `Map<string, LocalFontEntry>` 保持字体族名唯一，保留最规范的族名大小写。

#### 2. 双级缓存架构（Memory Map + LocalStorage）
为避免每次打开设置下拉面板时重复执行昂贵的系统字体全量扫描，系统建立双级缓存：
- **L1 内存缓存（Memory Cache）**：运行时单例 `cachedLocalFonts: LocalFontEntry[] | null`，会话生命周期内秒级复用；


当用户输入查询词 $Q$ 与候选字体项 $T$ 计算匹配分值 $S(Q, T)$：

$$S(Q, T) = \begin{cases}
100 & \text{完全相等 (Exact Match: } Q = T \text{)} \\
85 & \text{前缀匹配 (Prefix Match: } T \text{ starts with } Q \text{)} \\
70 & \text{连续子串匹配 (Substring Match: } T \text{ contains } Q \text{)} \\
60 & \text{拼音首字母匹配 (Pinyin Acronym Match: } \text{Acronym}(T) \text{ contains } Q \text{)} \\
50 & \text{拼音全拼连续匹配 (Pinyin Full Match: } \text{Pinyin}(T) \text{ contains } Q \text{)} \\
35 & \text{英文别名模糊匹配 (Alias Match)} \\
0 & \text{未命中 (Mismatch)}
\end{cases}$$

根据计算出的分值从高到低排序，并在 $\ge 35$ 分的所有项目中高亮呈现。

本方案设计**时间戳微任务合成锁门闩（Composition Guard）**：

```typescript
const isComposingRef = useRef(false);
const compositionEndTimestampRef = useRef(0);

const handleCompositionStart = () => {
  isComposingRef.current = true;
};

const handleCompositionEnd = () => {
  isComposingRef.current = false;
  compositionEndTimestampRef.current = Date.now();
};

const handleKeyDown = (e: React.KeyboardEvent<HTMLInputElement>) => {
  // 核心拦截：若处于组合中，或距离组合结束不足 50ms，坚决拦截 Enter
  if (isComposingRef.current || (Date.now() - compositionEndTimestampRef.current < 50)) {
    if (e.key === 'Enter') {
      return;
    }
  }

  if (e.key === 'Enter') {
    e.preventDefault();
    handleApply();
  }
};
```

```typescript
export function sanitizeFontFamily(raw: string): string {
  if (!raw) return '';
  return raw
    .replace(/[\u0000-\u001f\u007f]/g, '')
    .replace(/[;{}<>\\]/g, '')

/** 读取 LocalStorage 缓存 */
function readStorageCache(): LocalFontEntry[] | null {
  try {
    const raw = localStorage.getItem(CACHE_KEY);
    if (!raw) return null;
    const parsed = JSON.parse(raw) as { timestamp: number; fonts: LocalFontEntry[] };
    if (Date.now() - parsed.timestamp > CACHE_EXPIRY_MS) {
      localStorage.removeItem(CACHE_KEY);
      return null;
    }
    return parsed.fonts;
  } catch {
    return null;
  }
}

/** 写入 LocalStorage 缓存 */
function writeStorageCache(fonts: LocalFontEntry[]): void {
  try {
    localStorage.setItem(
      CACHE_KEY,
      JSON.stringify({ timestamp: Date.now(), fonts })
    );
  } catch {
    /* swallow quota error */
  }
}

/** 引擎 A: 通过 Chromium / Tauri 原生 API 获取全量系统字体 */
async function scanViaQueryLocalFonts(): Promise<LocalFontEntry[]> {
  const win = window as WindowWithLocalFonts;
  if (typeof win.queryLocalFonts !== 'function') {
    throw new Error('queryLocalFonts is not supported');
  }

  const rawFonts = await win.queryLocalFonts();
  const fontMap = new Map<string, LocalFontEntry>();

  for (const f of rawFonts) {
    const clean = sanitizeFontFamily(f.family);
    if (!clean || clean.startsWith('-') || clean.startsWith('.')) continue;
    
    if (!fontMap.has(clean.toLowerCase())) {
      fontMap.set(clean.toLowerCase(), {
        family: clean,
        fullName: f.fullName,
        postscriptName: f.postscriptName,
        style: f.style,
      });
    }
  }

  return Array.from(fontMap.values()).sort((a, b) =>
    a.family.localeCompare(b.family, 'zh-Hans-CN', { sensitivity: 'accent' })
  );
}

/** 引擎 B: Canvas 2D 差分测宽平台精选探测 */
export async function scanViaCanvas(): Promise<LocalFontEntry[]> {
  const curated = curatedLocalFonts();
  const candidates = [...new Set([...curated.ui, ...curated.mono])];
  const fontMap = new Map<string, LocalFontEntry>();

  const canvas = document.createElement('canvas');
  const ctx = canvas.getContext('2d');
  if (!ctx) return [];

  const testStr = 'mmmmmmmmmmlli@字国Ww10';
  const testSize = '72px';
  const baseFamily = 'monospace';

  ctx.font = `${testSize} ${baseFamily}`;
  const baseWidth = ctx.measureText(testStr).width;

  for (const fam of candidates) {
    const clean = sanitizeFontFamily(fam);
    if (!clean) continue;

    ctx.font = `${testSize} '${clean.replace(/'/g, '')}', ${baseFamily}`;
    const measuredWidth = ctx.measureText(testStr).width;

    if (Math.abs(measuredWidth - baseWidth) > 0.1) {
      fontMap.set(clean.toLowerCase(), { family: clean });
    }
  }

  // 让出主线程切片
  await new Promise((r) => setTimeout(r, 0));

  return Array.from(fontMap.values()).sort((a, b) =>
    a.family.localeCompare(b.family, 'zh-Hans-CN')
  );
}

/** 双引擎统一扫描入口（带缓存与自适应降级） */
export async function scanSystemFonts(forceRefresh = false): Promise<LocalFontScanResult> {
  const startTime = performance.now();

  if (!forceRefresh) {
    if (memoryCache && memoryCache.length > 0) {
      return {
        engine: 'none',
        fonts: memoryCache,
        totalCount: memoryCache.length,
        durationMs: 0,
      };
    }

    const diskCached = readStorageCache();
    if (diskCached && diskCached.length > 0) {
      memoryCache = diskCached;
      return {
        engine: 'none',
        fonts: diskCached,
        totalCount: diskCached.length,
        durationMs: 0,
      };
    }
  }

  let engine: FontScanEngine = 'queryLocalFonts';
  let fonts: LocalFontEntry[] = [];

  try {
    fonts = await scanViaQueryLocalFonts();
    logger.info(`[fontStoreScan] scanned ${fonts.length} fonts via queryLocalFonts`);
  } catch (err) {
    logger.warn('[fontStoreScan] queryLocalFonts failed or unsupported, fallback to Canvas', {
      error: String(err),
    });
    engine = 'canvas';
    fonts = await scanViaCanvas();
  }

  memoryCache = fonts;
  writeStorageCache(fonts);

  const durationMs = Math.round(performance.now() - startTime);

  return {
    engine,
    fonts,
    totalCount: fonts.length,
    durationMs,
  };
}
```

```typescript
import { CJK_FONT_PINYIN_MAP } from './fontPinyinMap';
import type { FontSelectOption, FontMatchScore } from './fontStore';

/** 常见中文字体中英文双向别名索引表 */
const FONT_ALIASES: Record<string, string[]> = {
  'microsoft yahei': ['微软雅黑', 'yahei', 'wryh'],
  'microsoft yahei ui': ['微软雅黑 ui', 'yahei ui', 'wryhui'],
  'pingfang sc': ['苹方', '苹方-简', 'pingfang', 'pf'],

  'harmonyos sans sc': ['鸿蒙黑体', 'hongmeng', 'hmht'],
  'simsun': ['宋体', 'songti', 'st'],
  'simhei': ['黑体', 'heiti', 'ht'],
  'kaiti': ['楷体', 'kaiti', 'kt'],
  'fangsong': ['仿宋', 'fangsong', 'fs'],
  'jetbrains mono': ['jb', 'jetbrains'],
  'cascadia code': ['cascadia', 'cc'],
  'fira code': ['fira'],
};

/** 将汉字转换为首字母缩写字符串与全拼字符串 */
export function extractPinyin(text: string): { acronym: string; full: string } {
  let acronym = '';
  let full = '';

  for (let i = 0; i < text.length; i++) {
    const char = text[i];
    const info = CJK_FONT_PINYIN_MAP[char];
    if (info) {
      acronym += info.initial;
      full += info.full;
    } else {
      // 英文或数字保持原样
      acronym += char.toLowerCase();
      full += char.toLowerCase();
    }
  }

  return { acronym, full };
}

/** 计算单个选项的匹配分值 */
export function calculateMatchScore(option: FontSelectOption, rawQuery: string): FontMatchScore | null {
  const query = rawQuery.trim().toLowerCase();
  if (!query) {
    return { option, score: 100, matchedField: 'label' };
  }

  const labelLower = option.label.toLowerCase();
  const valueLower = option.value.toLowerCase();

  // 1. 完全相等 (Exact Match)
  if (labelLower === query || valueLower === query) {
    return { option, score: 100, matchedField: 'label' };
  }

  // 2. 前缀匹配 (Prefix Match)
  if (labelLower.startsWith(query)) {
    return { option, score: 85, matchedField: 'label' };
  }

  // 3. 连续子串匹配 (Substring Match)
  if (labelLower.includes(query) || valueLower.includes(query)) {
    return { option, score: 70, matchedField: 'label' };
  }

  // 4. 别名匹配 (Alias Match)
  const key = option.label.toLowerCase();
  const aliases = FONT_ALIASES[key] || [];
  for (const alias of aliases) {
    if (alias.toLowerCase().includes(query)) {
      return { option, score: 65, matchedField: 'alias' };
    }
  }

  // 5. 拼音首字母与全拼匹配 (Pinyin Acronym / Full Match)
  const { acronym, full } = extractPinyin(option.label);
  if (acronym.includes(query)) {
    return { option, score: 60, matchedField: 'acronym' };
  }
  if (full.includes(query)) {
    return { option, score: 50, matchedField: 'pinyin' };
  }

  return null;
}

/** 批量过滤与排序字体选项 */
export function filterAndSortFontOptions(
  options: FontSelectOption[],
  query: string,
  maxResults = 120
): FontSelectOption[] {
  if (!query.trim()) {
    return options;
  }

  const scoredList: FontMatchScore[] = [];

  for (const opt of options) {
    const res = calculateMatchScore(opt, query);
    if (res && res.score > 0) {
      scoredList.push(res);
    }
  }

  // 按得分降序排序，同分则按字母序排列
  scoredList.sort((a, b) => {
    if (b.score !== a.score) return b.score - a.score;
    return a.option.label.localeCompare(b.option.label, 'zh-Hans-CN');
  });

  return scoredList.slice(0, maxResults).map((s) => s.option);
}
```

```tsx
function sanitizeFontFamilyName(raw: string): { ok: true; name: string } | { ok: false; reason: string } {
  const stripped = raw.replace(/[\u0000-\u001f\u007f]/g, '').trim();
  if (!stripped) return { ok: false, reason: '请输入字体名称' };
  if (/[;{}<>\\]/.test(stripped)) return { ok: false, reason: '字体名称含非法字符' };
  const name = stripped.length > FONT_NAME_MAX ? stripped.slice(0, FONT_NAME_MAX) : stripped;
  return { ok: true, name };
}

      value: o.id,
      label: o.label,
      group: '预设',
      ...(o.previewFamily !== undefined && { previewFamily: o.previewFamily }),
      ...(o.kind === 'embedded' ? { hint: '内嵌' } : o.kind === 'auto' ? { hint: platformLabel() } : {}),
    }));

    const locals: FontSelectOption[] = localFonts.map((f) => ({
      value: `local:${f}`,
      label: f,
      group: '本机',
      previewFamily: f,
    }));

    if (isLocalFontChoice(prefs.monoFont)) {
      const fam = localFontFamily(prefs.monoFont);
      if (fam && !localFonts.includes(fam)) {
        locals.unshift({
          value: prefs.monoFont,
          label: fam,
          group: '本机',
          previewFamily: fam,
        });
      }
    }

    return [...base, ...locals];
  }, [localFonts, prefs.monoFont]);

  return (
    <>
      <SettingsRow
        title="界面字体"
        control={
          <FontSelectField
            value={prefs.uiFont || 'auto'}
            options={uiOptions}
            disabled={busy}
            onChange={(v) => void apply({ uiFont: v as UiFontChoice })}
            onScanLocal={handleScanLocal}
            isScanning={scanning}
            onResetDefault={() => void apply({ uiFont: DEFAULT_FONT_PREFS.uiFont })}
            isDefault={prefs.uiFont === DEFAULT_FONT_PREFS.uiFont}
            onApplyCustom={(name) => handleApplyCustom('ui', name)}
            maxHeight={340}
          />
        }
      />

      <SettingsRow
        title="代码字体"
        control={
          <div className={styles.monoControlRow}>
            <label className={styles.settingsRowCheck} aria-label="启用代码连字（liga / calt）">
              <input
                type="checkbox"
                checked={!!prefs.monoLigatures}
                disabled={busy}
                onChange={(e) => void apply({ monoLigatures: e.target.checked })}
              />
              <span>连字</span>
            </label>
            <FontSelectField
              value={prefs.monoFont || 'auto'}
              options={monoOptions}
              disabled={busy}
              onChange={(v) => void apply({ monoFont: v as MonoFontChoice })}
              onScanLocal={handleScanLocal}
              isScanning={scanning}
              onResetDefault={() => void apply({ monoFont: DEFAULT_FONT_PREFS.monoFont })}
              isDefault={prefs.monoFont === DEFAULT_FONT_PREFS.monoFont}
              onApplyCustom={(name) => handleApplyCustom('mono', name)}
              maxHeight={340}
            />
          </div>
        }
      />
    </>
  );
};
```

```tsx
    fireEvent.compositionStart(searchInput);

    fireEvent.compositionEnd(searchInput);
```
