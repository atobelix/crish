# 原子组件双轨收敛与 A11y 修复详案

## 一、领域概念与收敛目标

本方案针对 UI 原子组件库中的 `Select` 与 `Combobox` 领域概念，目标是消除历史遗留的双轨 API 兼容层，收敛为单一主路径复合组件架构，并根除 A11y 键盘漫游与浮层解算中的逻辑缺陷。

* **当前路径**：2 条（复合组件主路径 + LegacyAdapter 属性兼容路径 + 动态分支路由）
* **收敛后路径**：1 条（纯粹复合组件单一路径）
* **收敛动作**：先删后改，彻底删除 Legacy 适配器与兼容分支。

---

## 二、做什么（修复与增强清单）

1. **`SelectTrigger` 键盘导航修复**：
   * 修复 `SelectTrigger.tsx` 中的死变量 shadow 问题；
   * 上下键漫游使用基于 `ctx.items.filter(i => !i.disabled)` 的有效列表计算，跳过被禁用的选项；
   * 确保 `highlightedIndex` 在首尾循环时正确映射到有效可用项。
2. **`useFloatingPosition` 依赖补齐与鲁棒性增强**：
   * 在 `updatePosition` 的 `useCallback` 依赖项中补齐 `alignItemWithTrigger`；
   * 移除未挂载时的硬编码魔术数字（160/200），改为基于内容实际渲染或 Anchor 基准尺寸的严格边界计算。
3. **`SelectRoot` 纯净单主路径导出**：
   * `Select.tsx` 移除 `if ('options' in props)` 分支，直接导出 `SelectRoot` 与子复合组件；
   * 统一消费方使用复合组件或现代化适配层。

---

## 三、删什么（删除面与负产出清单）

1. **删除文件**：
   * `apps/crish-desktop/src/components/ui/Select/SelectLegacyAdapter.tsx`
   * `apps/crish-desktop/src/components/ui/Select/ComboboxLegacyAdapter.tsx`
2. **删除符号与分支**：
   * `Select.tsx` 中的 `SelectLegacyAdapter`、`LegacySelectProps`、`LegacySelectOption`、`Select.LegacyAdapter`；
   * `Select.tsx` 入口处的 `if ('options' in props ...)` 动态兼容路由分支；
   * `Combobox.tsx` / `Select/index.ts` 中的 `ComboboxLegacyAdapter` 导出；
   * `SmartExpandablePanel/adapters/SelectAdapter.tsx` 中对 `LegacySelectProps` 的依赖，改为纯粹的 Select 复合组件渲染。

---

## 四、依赖与逻辑顺序（先删后改）

1. **第 1 步（删除）**：删除 `SelectLegacyAdapter.tsx` 与 `ComboboxLegacyAdapter.tsx`；
2. **第 2 步（收敛导出）**：精简 `Select.tsx`、`Combobox.tsx`、`Select/index.ts` 与 `SmartExpandablePanel/adapters/SelectAdapter.tsx`；
3. **第 3 步（修复缺陷）**：修复 `SelectTrigger.tsx` 键盘导航、`useFloatingPosition.ts` 依赖与尺寸计算。

---

## 五、文件域

## 六、验收标准

1. **功能验收**：
   * `SelectTrigger` 键盘上下键漫游能顺畅跳过 disabled 项，且按 Enter/Space 能正确选中高亮项；
   * 浮层弹出定位准确，在 `alignItemWithTrigger` 动态切换时能即时重新计算；
   * 业务组件无运行时报错。
2. **负产出验收**：
   * 净删除代码行数 ≥ 150 行；
   * 彻底消除 `LegacyAdapter` 符号与双轨分支。
