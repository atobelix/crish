# 01 · 收敛优先与删除面最完整方案

> 独立方案 · 视角：**收敛优先**、**删除面最完整**
> 覆盖问题池 P1–P6 全部；对齐 `00-总方案.md` 不可变条件 1–6 与 D1–D6 草案。
> 本文不改代码、不估工期、不排人员、不用波次命名；同权处理各条。
> 来源锚点：`surveys/01-问题池.md`（2026-09-15 主控核对）。

## 0. 方案定位与原则

- **收敛优先**：同一语义存在多条读/写路径时，先归并到单一真理源（SSOT），再谈增强；能物理删除的旧入口不保留兼容壳。
- **删除面最大**：在产品契约不变的前提下，优先「删旧入口 / 删旧字段 / 删双源同步 / 删失真注释」，而非「双轨并存 + 适配」；兼容只允许显式、可测、可到期的薄适配，且完成定义必须包含删除。
- **效果锁**：P1–P6 全部纳入，不砍项、不降级；问题同权。
- **四条旧路径 SSOT 锚点**（贯穿全文）：
  1. `config_get` / `config_update` → **统一配置树 / settings 单一读写面**（断链真值，见 P1）；
  2. LS `hasKey` 双轨 → **树 `credentialStates[*].hasKey` 唯一真源**（总方案不可变条件 2）；
  3. `loadProfiles` / `AppSettings.defaultModel` / 裸 `recent.modelId` → **树 `activeModel` 二元组 `(providerId, modelId)`**（不可变条件 3）；
  4. 字典预估价 → **`pricingExplicit` 闸门**（`catalogWriteGate.ts:92-103` 写入门禁**已落地**；读侧/展示侧与字典残留对齐，不回退写门禁）。
- **正面样板**：`protocol.rs` 快照唯一装载/刷新口；`ModelsStore` + `models.yaml` 单一写者（已立，不得回退）。

- **路径现状 → 收敛到几条**：
  - 读：`config_get` 旧命令 +（可能）REST 孪生 + 统一树/settings 投影 ⇒ **收敛到 1 条合法读写面**（统一树 / `settings_*` / 明确退役后的封装——实现期以代码注册点为准，方案不并行保留）。
  - 写：`config_update` + 树写 ⇒ **收敛到 1 条（树写）**。
  - 现状影响：`loadEngineConfig` / `updateEngineConfig` 恒失败或静默 null——**删除断链、改接单一通道后不得再静默吞错**。
- **收敛后断言**：
  - 全仓无对退役命令的活调用；`ENGINE_API_DEBT` 相关 drift 检查目标为 0；
  - `transport.request` 仅走 Tauri invoke 单一传输，不出现「文档写 REST、实走 invoke」的双口径；
  - 正/逆向回归：合法树读写通；对已删入口的调用在测试层失败（钉死删除面）。
- **证据**：问题池 P1 表；`command_manifest.rs` 已记载退役；`command-contract-drift.test.ts`。
