# 移动端抽屉改版总方案（crish-mobile-drawer 原型移植）

> 输入：`reference/crish-mobile-drawer/`（本地原型，仅视觉与交互参考，不入库）。
> 目标：把原型敲定的视觉效果与交互手感移植到 `apps/crish-mobile`（Expo / RN 0.86 / expo-router），架构同步收敛。
> 边界（用户裁决，2026-11-01）：
> 1. **颜色体系定稿不动**——现有 `theme.ts` 色板即权威（浅灰 canvas + 纯白 surface 卡片结构恰与原型同构），移植时禁止微调色值；
> 2. **图标体系沿用现有内联库**（`iconPaths.ts`），仅「展开箭头 chevron-*」与「对号 check」按几何直线折角自制（锐角渲染），其余图标不换；
> 3. **字体统一克制**：同一层级文字字号/字重一致；正文 400（不细）、强调 500–600、绝无 300 细体与忽大忽小；
> 4. 原型仅敲定视觉与手感，**禁止机械照抄 HTML/DOM**；mock 数据驱动的假功能不移植（诚实化），真实能力补齐边界。

## 1. 原型要点（移植权威）

| 区域 | 规格 |
| --- | --- |
| 抽屉 | 顶部搜索胶囊（点击原地展开为输入 + 外部叉号，扫一扫/通知收拢）；中部纯会话列表；底部头像昵称 + 设置/新建白圆钮 |
| 主屏 | 头栏左组 = 汉堡白圆钮 + 设备胶囊（电脑图标+状态点+名称+下箭头）；右侧更多白圆钮 → 下拉菜单；离线白色圆角横幅（图标+文案+动作）；**平铺会话列表**（标题+状态+时间 + 摘要行，行间大间距+虚线分隔，少条目垂直居中）；底部 Composer |
| Composer | 恒定 26px 圆角白胶囊（单行 52 / 多行自适应），零描边微阴影；展开时列表/横幅联动淡出上移 |
| 对话页 | 顶栏通透悬浮（返回白圆钮 + 白色标题胶囊 + 更多）；消息流全屏滚动 + 上下渐变羽化；用户气泡带尾角；审批卡悬浮输入框上方（白卡 + 等宽代码块 + 拒绝/同意），待审批时 Composer 锁定 |
| 设置 | 账号白卡（头像+名+右箭头）；分组白卡行（行首图标+标签+值+右箭头，虚线分隔）；退出登录白底红字胶囊；二级子面板右侧滑入（主题单选/通知开关组） |
| 通用 | 白圆钮（≈40 + 微柔阴影）；下拉菜单 18 圆角白卡；底部 Sheet 28 圆角 + 把手 + 关闭灰圆钮 + 浅灰圆角行（激活=对号无高亮）；弹窗 36 圆角 + 胶囊按钮对；Toast 顶部墨色胶囊下滑入 |

## 2. 现状审查结论

**架构底子良好**（路由/VM/store 分层、token 守卫、性能预算测试齐全），问题集中在 presentation 层与原型的偏差：

- **主屏错位**：`newChatScreen` 为居中问候空态；原型主屏 = 平铺会话列表 + Composer（空态时才显示问候）。
- **头栏错位**：设备胶囊居中 + 右侧铃铛；原型 = 汉堡 + 设备胶囊左组、右侧更多下拉。
- **抽屉冗余**：搜索胶囊无展开交互；底部按钮为透明底（原型白圆钮）；容器带 scale 景深（原型无，仅位移+圆角+阴影）；视差 -36（原型 -60）。
- **对话页**：头栏非浮动、无羽化遮罩、用户气泡无尾角、审批浮卡无代码块样式、Composer 无锁定语义。
- **设置**：SegmentedControl 三选、无行首图标体系、无二级子面板；原型为分组卡 + 子面板导航。
- **废代码**：`NewTaskSheet.tsx`（守卫白名单已标「待清理」且无引用）、`SegmentedControl`（设置改版后无使用者）、`MainHeader`（被新头栏取代）。
- **缺失原子**：下拉菜单（DropdownMenu）、Sheet 选项行（SheetOptionRow）、边缘羽化（EdgeFade）、平铺会话行（ChatFlatItem）。

## 3. 移植映射（原型 → 真实数据面，诚实化裁决）

| 原型元素 | 移植裁决 |
| --- | --- |
| 主屏平铺列表 | 真实数据：`useSessionsVm` + `lastPreviewOfWindow`（摘要）+ `formatRelativeTime`（时间）；运行=灰环 spinner、待审批=橙点+文案、其余=绿点 |
| 设备胶囊 → 设备 Sheet | 真实单一配对桌面（authStore.host + 连接相位）+「扫码添加新设备」→ `/pair/scan`；多设备列表为 mock，不移植 |
| 离线横幅 | `ConnectionBanner` 改版为白色圆角横幅（图标+文案+重试+帮助），仅非 ready 时出现 |
| 主屏更多菜单 | 真实入口：通知中心 / 偏好设置（下拉菜单原子） |
| 会话页更多菜单 | 真实能力：运行详情 / 终端输出 / 工具调用（沿用现有动作，换成下拉菜单形态） |
| Composer 附件 + / 语音 / 模型选择 / 项目选择 / 权限模式 | **不移植**：协议无附件与模型选择能力（RunTaskParams 仅 prompt/sessionId/permissionMode 且 R2-07 裁定恒 ask）；无语音基础设施。Composer = 输入 + 发送 |
| 设置语言 / 字体 / 触感反馈 | **不移植**：无 i18n / 无字号缩放 / 无 expo-haptics，做假 UI 违反诚实化 |
| 设置主题 / 通知子面板 | 移植为独立路由页 `/settings-theme`、`/settings-notification`（跟随系统/浅色/深色单选；通知总控+分场景开关，真实 VM） |
| 抽屉待审批/审批记录行 | 保留（真实功能可达性）：待审批仅 count>0 显示；审批记录常驻，样式压缩弱化 |
| 审批锁定 Composer | 会话页 `pendingApprovalCount>0` 时禁用输入 + 引导文案（对齐原型 approval-locked） |

## 4. 设计规则（执行时刚性约束）

1. **色**：只消费 theme token（守卫测试强制零裸 hex）；层级 = canvas 灰底 / surface 白卡 / fillSubtle 浅灰面。
2. **形**：圆角走 radius 阶梯（新增 `composer 26` / `dialog 36` / `overlay 30` / `bubble 18` + `bubbleTail 4`）；白圆钮 = IconButton floating（40 + 微阴影）；零描边，阴影只做微柔浮雕。
3. **字**：variant 单一来源；正文 400 不细、强调 500–600、无 300；同层级同 variant；数字用 tabular-nums。
4. **图标**：chevron-*/check = 自制几何直线折角（Icon 渲染层 miter join + butt cap），其余沿用库内圆角风格。
5. **动效**：沿用 theme.motion（emphasized 曲线族）；下拉 = 淡入下移；Toast 顶部滑入；抽屉弹簧（spring.drawer）。
