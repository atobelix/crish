## 1. 战役背景与研究目标

当前 Conex / Crish 桌面端需要重构与打磨正文对话界面。本次战役深度调研业界两个顶级开源参考标杆：
1. **BytePioneer-AI / codex-host** (`reference/codex-host/`)：
   - 深入 Codex Desktop 原生交互，逆向与分析其 Transcript DOM、Turn 结构、Reasoning 预览与持久化投影、Composer 宿主注入；
2. **deepseek-ai / deepseek-harness** (`reference/deepseek-harness/`)：
   - 基于 Cordis 时空可组合微内核的高性能 Web UI / Desktop Client；
   - 拥有极致简洁、无冗余卡片框线的线性对话流、24px 单行可折叠思考/工具调用、视口防抖动 PagingAnchor 滚动跟随、Lexical 富文本 Chip 输入。
