## 核心发现精要：人家为什么做得如此简洁？

在对两套数十万行工业级开源系统的深入剖析中，我们提炼出打造顶级极简 AI 对话界面的**五大核心定律**：

### 1. “内容即画纸”定律（Flattened Canvas）
- **传统错误做法**：为每一条助手消息套上外层 Card、粗实线描边与深重阴影，当出现多轮对话和代码块时，形成层层嵌套的“卡片套娃”；
- **标杆做法**：彻底剥离 Assistant 消息的外层卡片与边框，将 Markdown 正文和代码块直接投射在纯净的背景 Canvas 上；段落间仅靠 16px 自然留白呼吸，使代码和文字拥有如同专业文档一般的阅读质感。

### 2. “70.2% 黄金宽比与外置操作栏”定律（Asymmetric User Bubble）
- **标杆做法**：用户气泡严格锁定在 `max-width: min(calc(width * 0.702), 82%)`，右对齐，22px 超椭圆圆角，单行高度 42px；
- **关键细节**：复制、重试等微操作按钮绝不塞入气泡内部，而是外置在气泡下方 6px 处，气泡内部保持 100% 的纯文本呼吸感。

### 3. “24px 极简行与渐进式披露”定律（Progressive Disclosure）
- **标杆做法**：将所有思考过程与工具调用严格约束为 **24px 单行**（`[16px 图标] gap 6px [13px 标题] · [13px 参数摘要]`）；
- **动态呼吸**：流式生成中，思考行自动追踪最新输出的一行（`latestLine`），配合 2.6s 跑马灯柔光（`color-mix` 冲淡文字）；完成后无缝收束为首行主题（`firstLine`）；
- **专有展开**：点击后在原位展开专有的 Diff、Terminal、Read 卡片，绝不提前使用大色块霸占视口。

### 4. “轮次过程折叠”定律（Turn Process Folding）
- **标杆做法**：一轮交互包含 10 次工具调用时，在执行期间完整展开以供观察；
- **终态收拢**：一旦轮次闭合（`turnClosed`）且输出最终回答，过程行自动隐藏，统一收束为一条 33px 发丝底线控制栏（`"1 tool call · 1 message · 1 subagent"`）；
- **搜索穿透**：折叠节点标记 `hidden="until-found"`，用户 `Ctrl+F` 页面搜索命中时瞬间自动就地展开，完美解决“简洁”与“可查性”的矛盾。

### 5. “亚像素防抖与单一账本”定律（PagingAnchor & Anti-Clamping）
- **标杆做法**：抛弃易受干扰的全局滚动差值，基于视口顶部前沿向下 1px 的射线投射（`elementsFromPoint`）与二分查找锁定稳定语义行 `PagingAnchor { key, top }`；
- **零跳动补偿**：历史 Prepend 插入时在 `useLayoutEffect` 执行 `scrollTop += flowTop - anchor.top`，实现人类肉眼下的 0 像素位移；
- **防地表钳位**：建立 `observedTopRef` 单一账本，在大段内容折叠导致容器剧烈变矮时，精确识别为浏览器内核的强制钳位，保持底层跟随状态不丢失。

## 对 Conex / Crish 的工程落地行动纲领

建议 Conex 桌面端研发波次分四步有序实施：
1. **波次 1（视觉换肤与气泡重构）**：落地冷调中性蓝灰（`neutral-bluish`）三层 Token，清空 Assistant 外框，应用 70.2% 用户气泡；
2. **波次 2（24px 极简单行组件化）**：实现符合 Figma 122:9479 的 `DisclosureRow`、带跑马灯扫光的 `ReasoningRow` 与专有视图 `ToolRow`；
3. **波次 3（轮次过程折叠状态机）**：在虚拟化列表层引入 7 布尔量折叠引擎，落地 33px 发丝底线控制栏与 `hidden="until-found"` 搜索透传；
4. **波次 4（滚动引擎重构）**：引入双径 `PagingAnchor` 算法与 `observedTopRef` 单一真理账本，彻底根除视口跳动与跟底失效。
