## 2. DeepSeek 三层 Design Token 体系与色彩工程

在 `packages/client/ui-theme/src/styles/design-platform.css` 中，DeepSeek 建立了极度严谨的三层 Token 抽象：

```mermaid
graph TD
    subgraph Tier 1: 原始静态色阶 (Static Raw Palettes)
        StaticNeutral["--dsw-static-neutral-bluish-00 ~ 1000 (冷调灰阶)"]
        StaticDeepSeek["--dsw-static-deepseek-50 ~ 900 (品牌冷蓝)"]
        StaticFunctional["--dsw-static-green / red / amber (语义红绿黄)"]
    end

    subgraph Tier 2: 语义别名 Token (Semantic Alias)
        AliasBg["--dsw-alias-bg-base / layer-1~3 (背景分层)"]
        AliasBorder["--dsw-alias-border-l1 ~ l4 (半透明 Alpha 边框 0.04~0.16)"]
        AliasLabel["--dsw-alias-label-primary / secondary / tertiary (字阶对比)"]
        AliasInteractive["--dsw-alias-interactive-bg-hover (6%~14% 极淡交互)"]
    end

    subgraph Tier 3: 组件专属 Token (Component-Specific)
        SpecificBubble["--dsw-specific-bubble (用户气泡基准色)"]
        SpecificInput["--dsw-specific-input-major (主输入框背景)"]
        SpecificNav["--dsw-specific-sidebar-nav-item-active"]
    end

    Tier 1 --> Tier 2
    Tier 2 --> Tier 3
```

### 2.1 告别纯黑：墨黑文字哲学
在浅色模式下，正文主色并不是 `#000000`，而是：
`--dsw-static-neutral-bluish-1000: rgb(15, 17, 21);`
这种带微弱蓝冷倾向的墨黑色，在白色与浅灰背景上能显著减弱屏幕发光的刺眼对比度，保护开发者长时间注视代码的双眼。

### 2.2 气泡专有色（`--dsw-specific-bubble`）
- **浅色模式**：`rgb(237, 243, 254)`（`deepseek-50`），在白底上呈现出一抹极其微弱清透的天空冷白蓝，既与背景形成微妙区分，又没有任何粗糙的边界感；
- **暗色模式**：`rgb(33, 33, 35)`（`neutral-bluish-850`），与深黑背景融为一体。

## 3. 用户气泡的 70.2% 黄金律与几何规范

在 `MessageItem.module.css` 中记录了来自 Figma 原型稿（`659:38813`）的严格数学比例：

```css
.userStack {
  display: flex;
  flex-direction: column;
  align-items: flex-end;
  gap: 8px;
  min-width: 0;
  /* 525px / 748px ≈ 0.702: 保持 70.2% 宽度比例，窄屏 82% 兜底 */
  max-width: min(calc(var(--dsh-chat-content-width, 748px) * 0.702), 82%);
}

.bubble {
  max-width: 100%;
  background: var(--dsw-specific-bubble);
  border-radius: 22px;
  /* 单行高度严格对齐 42px：22px 行高 + 上下各 10px padding */
  padding: 10px 16px;
  font-size: var(--dsh-content-font-size, 14px);
  line-height: calc(22px + var(--dsh-content-font-delta, 0px));
  color: var(--dsw-alias-label-primary);
  white-space: pre-wrap;
  word-break: break-word;
}
```

- **操作栏垂直下沉**：按钮组（`MessageIconActions`）被移出气泡内部，放置在气泡底部的 `gap: 6px` 外层，彻底释放气泡内部空间；
- **22px 超椭圆圆角**：现代移动端与高端桌面端推崇的超椭圆（Superellipse）平滑过渡，告别尖锐感。

## 4. Assistant 消息的扁平化排版与发丝边框工程

### 4.1 彻底抛弃外层卡片
在传统 AI 对话界面中，往往会为助手消息包裹一层带边框或阴影的 Card。当输出多段文字、多个代码块时，内部嵌套的卡片会形成令人窒息的“套娃”视觉。
DeepSeek-Harness 采取**完全零外框的画纸设计**：
- 助手消息正文直接铺陈在窗口 Canvas 上；
- 段落间距仅通过 `margin-bottom: 16px` 呼吸；
- 代码块自身具备紧凑的圆角与发丝线（`0.5px solid rgba(0,0,0,0.06)`），与画纸浑然一体。

### 4.2 "Hairline Stroke Drawn in Shadow" 架构
在浮层、弹窗与工具展开块上，DeepSeek 推行了由自动化 CI 门禁（`elevation-styles.client.spec.ts`）守门的**内嵌发丝描边**：
```css
/* 禁止直接写 border: 1px solid #xxx，一律使用阴影内嵌发丝 */
box-shadow:
  0 0 0 0.5px var(--dsw-elevation-stroke-color), /* 0.5px 发丝级描边 */
  0 2px 4px rgba(0, 0, 0, 0.03),                 /* 超浅柔光 */
  0 8px 16px rgba(0, 0, 0, 0.04);
border: 0;
```
这种设计不仅消除了 Windows WebView2 下常见的 1px 黑边发虚瑕疵，而且在视网膜屏和普通 1080P 屏幕上均能呈现细腻刀锋质感。

## 5. 对齐 Conex 根目录铁律（AGENTS.md §12、§13、§14）

本次对标研究的所有视觉结论，完全契合并强化了 Conex 仓库已有的 UI 铁律：
1. **§12 禁用原生 title 提示框**：DeepSeek 全面采用自定义 12px 胶囊 Tooltip，与 Conex `<Tooltip>` 纪律一致；
2. **§13 严禁输入框重阴影与实心黑边**：
   - DeepSeek 的输入卡片默认无重阴影，常态透明，聚焦态仅通过 `color-mix` 微弱提亮边框至约 6%~10% 混入量，且利用品牌蓝色光标（`caret-color`）明确焦点，严禁粗厚黑环；
   - CodexHost 在 `design-qa.md` 中也严格裁决：程序化聚焦禁止使用实心蓝边，统一采用克制灰线；
3. **§14 现代色彩空间与 HSLA / color-mix**：
   - 扫光动画全面采用 `color-mix(in srgb, var(--bg) 60%, transparent) 55%`，渐变过渡自然平滑，零视觉脏色。
