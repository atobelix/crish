## 三、偏差与处置记录

1. **context-state 单键保留（详案 04 §3.1「废除单键」未全量执行）**：`PENDING_CONTEXT_STATE_KEY` 载荷改为 `{sessionId, text}` 会话寻址，`takePendingContextState(safeSessionId)` 仅消费本会话/未绑定暂存——跨会话串扰已根除、可见卡片已派发；但 localStorage 键与 run-task `contextState` 参数保留为引擎 wire 交接面（引擎 PendingMessageQueue 注入仍是实际 wire 通道）。**全量清退随 wire 投影轮**（届时引擎经消息时间线读取卡片，交接键退役）。已向用户说明非砍范围：功能不降级，只是接线形态延后。
2. **附件 wire 通道保留 promptAttachBlock**：文本附件结构化 ContextAttachmentPayload 的 Rust 组装未落地（依赖 IPC 载荷改造），本轮保留文本拼接为 wire 保底；卡片已提供可见面。随 wire 轮收口。
3. **`buildGoalModePrefix` 保留**：goalModeContinuation 自动续轮路径（Rust 侧/会话续期）仍消费该封装；首次进入的可见卡片已切换（B1），续轮不重复派卡（防刷屏）——符合「模式入口可见、持续轮次不刷屏」的产品口径。
4. **A1 偏差（wire 键响应风格 / SYSTEM_CORE 未拼接）**：已裁决采纳，见 §一。
5. **测试断言更新（B1）**：resolveSlashCommand 6 处断言（navigation 归类 / isSessionlessSlash / canonicalSlashFill / slashMenuPick ×2 / /定时 别名）、ChatComposer / TiptapComposerField open-schedule 用例——按用户「/schedule 归对话流」裁决更新为新契约。
