1. **增量状态机孤岛：`ConversationAssembler` 与 `PublicationScheduler` 生产 0 引用**
   - **现场证据**：全仓搜索 `ConversationAssembler` 与 `PublicationScheduler`，除了各自的单元测试文件外，在生产业务代码（`apps/crish-desktop/src/api/chat-bridge/`、`apps/crish-desktop/src/hooks/`、`apps/crish-desktop/src/store/`）中**引用数为 0**。

   - **现场证据**：
     - `chatMessageListProps.ts` 设计了优雅的 8 大领域分组接口；
     - `MessageVirtualizer.tsx:42-80` 编写了繁重的向后兼容解包逻辑，将 8 大领域对象与 flat props 合并解压出 25 个局部变量；
