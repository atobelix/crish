## 一、核心总原则（严禁违背）

1. **推进单位是「领域概念」，不是「方案批次」**：
   - 任何任务开工前必须回答：这个概念在代码里有几条路径？哪条是唯一主路径？本任务会把它收敛到几条？回答不了，禁止拆解任务。
   - 战役全域围绕 6 大核心领域概念展开：单轨数据装配器、纯净画纸排版、单一滚动宿主与视口锚定、24px 极简思考流、24px 工具单行与自适应卡片、轮次过程折叠状态机与双轨检索。
2. **纯逻辑执行顺序，问题同权**：
   - 不涉及任何工期时间表（无天数/小时）、无人员分配（无姓名排班）、无 P0/P1 优先级；
   - 缺陷（修复）、缺失（新增）、重复/死层/未接线标记（删除）；
   - **收敛在逻辑顺序上先于增强**：同一概念已有多条路径时，必须先删到一条主路径，再谈功能增强。
3. **主控亲查代码与决策锚点**：
   - 主控定夺任何维度前，必须亲自阅读该维度至少 3 个关键文件（实现、调用点、测试各至少一个），并将事实记录在案。「子 Agent 文档里说了」不是决策依据，代码才是。
4. **禁止波次与批次命名**：
   - 新增文件、函数、模块一律使用领域词命名；禁止带有 `round`、`batch`、`wave`、`w1` 等批次词汇；现有代码中发现的批次命名文件强制列入删除/重命名清单。
5. **严禁打补丁与魔术数字**：
   - 禁止在 UI 布局、坐标偏移、视口防抖中使用 `setTimeout(..., 40)` 等盲目猜测补丁；
   - 物理拔除基于盲猜的高频测高与局部滚动条，采用原生硬件级隔离（`contain: size layout`）与相对坐标差分锚定。

## 三、子 Agent 调度守则与执行红线

1. **嵌套禁止（REQ-D08）**：
   - 仅主 Agent 拥有派发子 Agent 的能力；子 Agent 调度深度严格限制为 1，严禁子 Agent 再行派发子 Agent。
2. **派发数量约束与弹性原则**：
   - 前期审计与方案评审阶段：2～4 个；
   - 方案生成与深化阶段：5～8 个；
   - 执行阶段：每轮弹性派发 5～12 个并行子 Agent；
   - 战役收官阶段允许按需少于 5 个；
   - 任意时刻存活子 Agent 数量上限 ≤ 16。
3. **执行环境与文件编码**：
   - 命令执行统一采用 `pwsh7`（PowerShell 7+），杜绝 GBK 与内联变量转义隐患；
   - 文件读写统一采用 **UTF-8 无 BOM** 格式。
4. **Git 提交权垄断与收口纪律**：
   - 仓库内仅主 Agent 拥有 Git 提交权；子 Agent 严禁执行 `git commit`、`git push`；
   - 严禁任何子 Agent 执行 `git reset --hard`、`git checkout .`、`git restore` 等回撤或冲掉他人代码的操作；
   - 主 Agent 收口提交必须严格使用 `git commit --only <paths...>` 限定本次落地路径，严禁使用 `--no-verify` 绕过校验。
5. **双验收门禁**：
   - **功能正确性验收**：全量单元测试、集成测试、类型检查 100% 通过；
   - **负产出净收敛验收**：每轮必须有明确的代码净删除（死层拔除、寄生类名消除、旧路径废弃）。

## 六、长效防回潮门禁与架构不变量契约

为防止后续日常迭代对本战役重构成果产生破坏，确立以下不可违背的架构不变量：

1. **唯一滚动宿主铁律**：
   - 对话流视口中仅允许存在一个挂载 `[data-chat-scroll-container]` 的单一滚动宿主；
   - 严禁在消息气泡、思考行、工具展开卡片中重新引入 `overflow-y: auto` 导致局部嵌套滚动；
   - 严禁使用原生 `scrollIntoView`，所有滚动定位必须通过基于容器相对坐标差分的受控算法实现。
2. **24px 硬件级尺寸隔离铁律**：
   - 所有思考折叠行与工具调用单行未展开态必须保持 `24px` 紧凑尺寸，且必须声明 `contain: size layout`；
   - 严禁移除硬件隔离声明以防流式 Token 引起文档流测高回流风暴。
3. **单轨数据装配铁律**：
   - 所有流式消息必须且仅能由 `ConversationAssembler` 依单调递增 Sequence 组装；
   - 页面渲染发布必须由 `PublicationScheduler` 的 3-RAF 节流管线调度，严禁组件内私自高频触发全局 store 更新。
4. **单轮过程折叠与检索穿透铁律**：
   - 助手回复中的多段思考与工具调用必须统一接入 `turnProcessState` 状态机；
   - 任何全局检索或跳转高亮逻辑必须通过 `searchExpandBridge` 统一调度穿透展开，严禁组件内部私自 hack 折叠状态。
