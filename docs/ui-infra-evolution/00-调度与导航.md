## 一、本次战役核心铁律与红线（100% 达成）

1. **纯底层改动，视觉与样式绝对零变化**：
   - 严禁修改当前页面的任何既有视觉外观、排版尺寸或视觉效果；
   - 对于项目中散落、不统一的规范进行整合时，**必须以当前项目中用得最多的形态为绝对基准**。
2. **坚决避免双轨（No Dual-Track）**：
   - 杜绝“新旧两套并存、双轨混用”的设计；
   - 方案具备明确、一步到位的单一真理源（SSOT）收敛路径，禁止任何长期双轨过渡态。
3. **坚决避免任何硬编码（Zero Hardcoding）**：
   - 彻底清除硬编码色值、硬编码过渡时长、硬编码魔术数字；
   - 彻底铲除任何形式的选择器白名单（如 focusTrap 中的 30+ 硬编码选择器列表）。
4. **无障碍暂时不用管（Exclude A11y）**：
   - 严禁在 a11y / ARIA / 读屏适配上空耗精力，全神贯注解决底层稳定性、动效连贯性、架构解耦与开发体验。
5. **彻底根除门禁拉锯战（End Lint-Guessing Loops）**：
   - 坚决解决“写代码 -> 触发静态门禁拦截 -> 盲目猜测修复”的高耗拉锯痛点；
   - 建立完备的事前规则基建（`agent-rules.md`、`llms.txt`、独立免打包 Vite UI Playground、Codemod 一键自动修复）。
