## 四、跨任务冲突与调度裁决建议（阻断项）

### 4.1 A1：`vitest.config.ts` e2e 项目处理方案互斥（PS-02 T2.1 vs PS-05 T5.6）

- PS-02 T2.1（方案 A 推荐）：**删除 e2e 项目块**（include 三行全删）+ tauri-native-smoke 重归属 native-smoke 项目。
- PS-05 T5.6 产出①：e2e 项目**保留**，`exclude` 追加 `'tests/e2e/**'`。
- 互斥后果：若 T2.1 先落地（项目块删除），T5.6 验收①命令 `npx vitest run --project e2e` 将报 project 不存在 → **T5.6 验收①必红**；若 T5.6 先落地（exclude 方案），T2.1 的「删除项目块」再执行将推翻 exclude 且 native-smoke 归属已变化。
- 建议：统一为**单一方案**（推荐 T2.1 方案 A 的「删除 e2e 项目块 + native-smoke 重归属」，语义更干净），并同步改写 T5.6 验收①（改为 `npx vitest run` 全量收集不含 tests/e2e 即等价证明）；两份任务书的 P0-2 归属声明合并到一处，防止双记。

### 4.2 A2：`sessionRustDbWriteModel.test.ts:278-308` 处理冲突（PS-03 T3.2 vs PS-05 边界）

- PS-03 T3.2：**删除** :278-308 并**翻转**断言方向（「禁止保留任何形式的旧覆盖新断言」）。
- PS-05 边界：该契约断言**原样保留**，本组不得改动。
- 互斥后果：先 PS-03 后 PS-05 → PS-05 的「原样保留」要求无法满足；先 PS-05 后 PS-03 → PS-05 的 37/37 基线记录（含旧断言）被推翻。
- 建议：**先 PS-03 后 PS-05**，并把 PS-05 边界条款改为「不重复处理 D6；T3.2 翻转后的断言原样保留」；PS-05 的 37/37 基线表述改为「T3.2 转绿后的会话持久化面基线」。
