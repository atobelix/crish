## 1. 目标与边界

### 1.1 目标

封堵命令门禁的**包裹/分隔形态绕过链**：命令替换 `$()`、反引号、换行分隔、PowerShell `iex`/`Invoke-Expression`/`Start-Process`/`-EncodedCommand`、PowerShell 删除别名 `ri` 等形态，使 R1 实测的 **8/8 形态全部 Blocked**（当前全部 Allowed），且**确定性毁灭目标**（`rm -rf -- /`、`ri C:\ -Recurse -Force`、`Write-Output x\nri C:\ -Recurse -Force` 等）在**任意权限模式（含 full-access）下无审批执行**的承诺恢复成立。

### 1.2 边界（明确不修什么）

- **不重构三层管线**：静态正则层（`blocked_patterns`）→ 语义层（`analyze`）→ 执行面接线（shell.rs gatekeeper 调用）的结构保持不变，只在现有管线内补洞。
- **不做 base64 解码**：`-EncodedCommand`/`-enc`/`-e` 参数检测到即**整体按 Redline（Blocked）**处理，不追求静态解出内层命令。
- **不改执行面**：shell.rs:596-667 的 `bash -lc` / `[scriptblock]::Create` 调用形态不动（门禁层拦截是唯一修点）。
- **不做十六进制/其它编码隐藏形态**、**不做 POSIX shell 全语法解析**：只覆盖审计点出的形态。
- **不碰 T-AB-05 冻结签名**：`classify_command_segments`（semantics.rs:741）签名与语义不可破坏。
- **不处理 P1 组**（symlink 写逃逸、git push refspec、cmd /C 注入、meta 相对路径）：分属后续 PS-0x 任务。
- **禁止删除/弱化任何既有测试与断言**：conex-sandbox 79 个 + shell.rs tests mod 42 个 + 壳相关测试全量保留（见 §6 防作弊条款）。
