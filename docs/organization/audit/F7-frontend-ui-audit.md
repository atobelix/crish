# F7 前端组件与 UI 层审计报告

- 审计日期：2026-08-07
- 审计范围：`apps/crish-desktop/src/components/`（ui/ 原子层、chat-card/、chat-composer/、chat-message-list/、chat-message-row/、chat-tool-call/、workspace/、settings/、overlay/、diff/、files/、sidebar/、shell/、binary-tree/）+ `src/styles/`（tokens.css、z-index.css、theme-dark.css、reduced-motion.css、focus-visible.css）+ 相关 hooks（usePointerDragBase、useVirtualScroll、useChatAutoScroll、useStreamRenderThrottle）+ 渲染链路（AsyncMarkdownBlock、markdownRenderAsync、Rust conex-markdown）
- 模式：只读审计，未修改任何代码
- 严重度口径：P0 = 崩溃/高破坏性（安全或数据损坏面）；P1 = 特定场景下功能失效或明显错位；P2 = 边界缺陷/资源泄漏/一致性问题/中危安全面；P3 = 健壮性/可维护性瑕疵

## 结论（先行）

**无 P0。** UI 层整体质量高：原子层契约清晰、a11y 属性体系完整（Dialog 三件套 + aria-labelledby/describedby 全覆盖）、markdown 双路径（Rust ammonia + TS escape）消毒结构合理、虚拟列表与拖拽基座设计成熟（phase 状态机 / pointerId 隔离 / rAF 批量回写）。

**P1 共 3 项**，按影响排序：

1. **`+` 菜单（ComposePlusMenu）锚点缺失，弹出位置错误** —— 用 `display:none` div 作 Radix Popover 锚点，浮动定位计算得到 (0,0) 视口原点，菜单出现在左上角而非按钮上方（已核对 @floating-ui/dom 对不可见 reference 的 rect 返回全 0 的行为）。
2. **`usePointerDragBase` 无指针捕获与 `lostpointercapture` 兜底** —— tree/leaf/tab 拖拽与 sidebar resize 在指针移出 WebView 后释放时，`pointerup` 事件丢失，拖拽状态悬挂（isDragging 恒 true、body class 残留），需重启手势才恢复。
3. **嵌套 Dialog（设置面板内开规则编辑器）Esc 竞态** —— 两个 Dialog 都在 document 层挂 Esc 监听且各自 preventDefault+onClose，一次 Esc 两层同时关闭；外层 FocusTrap 的 inert 旁路在重新激活时会把内层 portal 一并 inert，存在内层弹窗不可交互的时序风险。

其余为 **P2 × 11、P3 × 13**，集中在：固定行高虚拟化的折行错位、focus 圈定边界（非键盘路径、多弹窗场景）、dark 主题 token 覆盖缺口、硬编码 z-index/颜色残留、协议相对 URL 走私（TS/Rust 两端一致的 scheme 白名单缺口）、tool 输出图片 src 无 scheme 校验等。
