# F6 前端状态与持久化审计报告

- 审计日期：2026-08-07
- 审计范围：`apps/crish-desktop/src/store/`（layout-helpers / layout-tree / workspace-shell / middleware / sessionStore / layoutStore / streamingStore / 各域 store）+ `src/hooks/`（chat-stream、agent、树交互、工具 hooks）+ `src/app/`（AppBootstrap / useEngineBootstrap / compositionRoot / hydrateWorkspaceShell）+ `src/api/store-access/` + `src/api/session-persistence/` + `src/api/beforeunloadFlush.ts`
- 模式：只读审计，未改动任何代码
- 严重度口径：P0 = 无条件/高概率数据破坏或白屏；P1 = 特定场景数据丢失/损坏或功能失效；P2 = 边界缺陷/资源泄漏/一致性瑕疵；P3 = 健壮性与整洁度

## 结论（先行）

**无 P0。** 状态层整体纪律良好：store 单一真相源（layoutStore god-object + 域 store 拆分）、immer 写路径的 `getSessionForWrite`/`rebindSessionById` 防分叉、selector 收敛（useShallow / useSyncExternalStore 相等拦截）、hydration 空正文护栏、I-DRAFT 哨兵过滤、ownership 注释纪律均有系统性落地。

**P1 共 3 项**，集中在两个方向：

1. **持久化写路径无串行化**（F1 懒水合单页截断 + F2 批次交错无 CAS）——这是 Q02/Q03 三写路径收敛后的残余风险，且前端侧测试为零覆盖。
2. **流生命周期与组件生命周期脱钩**（F3）——ChatCard 卸载后孤儿流不可停止，重开会话可触发同会话双并发流。

**Q02/Q03 三写路径现状验证（通过）**：当前三写路径为 ① store-persistence 回灌（store-persistence.ts:169-240）② setActiveSessionId 引擎懒水合（sessionCrudActions.ts:195-223）③ 350ms debounce persist（store-persistence.ts:128-145）。三路已由「空 body 不落盘（sessionRustDb.ts:936）」「仅补空正文（store-persistence.ts:200-239）」「PENDING_DRAFT 哨兵全链路过滤」收敛，未复现覆盖竞态。残余风险即 F2/F5。
