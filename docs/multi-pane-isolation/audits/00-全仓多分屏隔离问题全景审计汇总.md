# 全仓多子窗口（Split-Pane）隔离性问题全景审计汇总报告

> **审计范围**：`apps/crish-desktop/src/` 全量组件、Hooks、Store、事件总线与 IPC 桥接层
> **审计维度**：
>
> 1. UI 事件总线（`uiEvents` / `CustomEvent`）
> 2. 全局 DOM 事件监听（`window` / `document.addEventListener`）
> 3. Tauri IPC 监听（`useIpcListener` / `listen`）
> 4. `ChatCard` / `ChatComposer` 会话状态与草稿 `sessionId` 归属
> 5. 二叉树叶子与右侧工具抽屉（`Preview` / `Files` / `Overview` / `Diff` / `Terminal` / `Agent`）及静态 DOM `id`
> 6. 剪贴板粘贴、键盘快捷键与全局 `document.querySelector`

---

## 一、 四大架构级根因总结

1. **隐式全局会话读取（Implicit Global `activeSessionId`）**：
   大量子窗口内组件与 Hook 直接订阅或读取 `useSessionStore(s => s.activeSessionId)` / `getCompositionRoot().session.getActiveSessionId()`，而非从所属子窗口（Leaf）上下文中读取绑定的 `sessionId`。
2. **交互焦点与激活叶脱节（Pointer/Focus vs. Active Leaf Desync）**：
   `TreeLeafPanel.tsx:108-131` 的 `handleActivate` 对 `button, input, textarea, select, a, [role="button"], [contenteditable="true"]` 提前 `return`，导致用户直接点击非激活子窗口的输入框打字、粘贴、回车发送或点击按钮时，全局 `activeLeafId` 与 `activeSessionId` 未切换到当前子窗口。
3. **无寻址的全局事件广播（Unscoped Global Event Bus）**：
   `uiEvents.ts`（`emitUiEvent` / `onUiEvent`）与 `window.dispatchEvent(new CustomEvent(...))` 缺少作用域路由机制，所有挂载的子窗口实例同时监听同一事件名并无条件响应。
4. **越界的全局 DOM 查询与捕获监听（Unscoped DOM Queries & Window Listeners）**：
   组件内直接调用 `document.querySelector(...)`（永远命中 DOM 树第一个子窗口）以及无焦点包含守卫的 `window.addEventListener('keydown' / 'message')`。
