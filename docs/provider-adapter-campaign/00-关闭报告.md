## 一、战役概要

### 1.1 目标与范围

**目标**：系统性完善 Conex 多模型适配（`crates/agent-provider` + `session-loop` + 壳层 `engine_provider` 接线面），使软件获得与 DeepSeek Harness 同级别的多供应商能力面——多协议、多供应商注册、模型级思考强度档位、能力描述与请求校验分离、主循环真实接线（`00-问题基线.md:9`）。

**范围**：`00-问题基线.md` G1-G8 八个问题（全部优先级相同，仅按逻辑依赖排布），经 6 轮执行闭环收敛。

- G1 适配层能力面受限 → R3 接线主干
- G2 模型级档位白名单无消费端 → R1 载体 + R4 改名消费
- G3 单提供方配置层 → R1 配置/凭据/env + R5 壳层 profile 服务
- G4 模型级协议路由消费端缺失 → R1 纯函数 + R3 接线 + R4/R5 数据激活
- G5 compat 探测面窄 → R1 纯函数 + R2 序列化 + R4 方言
- G6 wire 改名语义缺失 → R1 载体 + R4 改名/头/off disabled
- G7 边缘协议未覆盖 → R2 协议面 + R5 边缘解析器
- G8 能力描述与请求校验分离 → R2 描述面 + R4 拒绝语义 + R5 请求面接线
