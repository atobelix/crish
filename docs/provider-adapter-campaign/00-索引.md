- **不变式 I1-I6**：多协议 / 多供应商 / 模型级档位 / 描述-校验分离 / 真实接线 / 回归门禁（`00-总方案.md` §一）
- **6 轮执行编排**（每轮 5-12 Agent，收尾轮不保底；纯逻辑顺序，无优先级）：
