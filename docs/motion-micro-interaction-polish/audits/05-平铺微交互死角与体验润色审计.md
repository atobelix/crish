## 1. 执行摘要与审计结论

经过对客户端全部核心界面的微交互代码进行逐行深挖审计，发现目前大量关键交互场景普遍存在**“平铺直叙、0ms 生硬硬切、交互状态断代、缺少顺滑过渡”**的严重体验死角。

归纳核心审计结论如下：

1. **“直接 `display: none` / `block` 硬切”广泛泛滥，视觉割裂严重**：
   - **侧边栏分组手风琴**（`SidebarSessionList.module.css:26-37`）：置顶区、项目分组、常规会话折叠时，直接采用 `display: none` 与 HTML `hidden` 属性，点击收起或展开时界面瞬间闪现或闪灭，伴随几十像素的硬性高度断层。
   - **工具调用折叠组**（`FoldableToolGroup.tsx:93-96`）：依赖原生 `hidden="until-found"`，展开时直接 `removeAttribute('hidden')`，内部成百上千行的工具调用内容单帧爆出，造成严重的累积布局偏移（CLS）。
   - **工作区多标签切换**（`TreeLeafPanel.tsx:468-479`）：Dock 内已打开的终端、Diff、预览等面板通过 `display: isActive ? 'flex' : 'none'` 粗暴直切，标签切换毫无过渡感，极度生硬。

2. **存在反模式的“伪高度动画”（`max-height: 2000px`）**：
   - **工具调用卡片**（`ChatToolCallBlock.module.css:403-416`）：依然使用古老的 `max-height: 2000px` 展开反模式。对实际仅几十像素的内容，头 6ms 就把高度拉满导致动画空转，折叠时头 210ms 毫无反应，末尾突然闭合，且每帧触发昂贵的主线程 Reflow。

3. **关键操作触觉微反馈（Active Feedback）全面缺失**：
   - **侧栏新对话按钮**（`SidebarNav.module.css:10-75`）：`.navItem` 仅有 `:hover` 背景变化，**完全没有 `:active` 按压伪类**。用户点击创建新对话时，鼠标按下毫无缩放与光色反馈，反馈扁平如同点击死文字。
   - **会话项时间戳与动作按钮**（`SidebarSessionList.module.css:580-591`）：时间戳与更多操作按钮交替切换时仅有纯透明度跳变，缺失 X 轴微位移过渡，视觉呈现突兀。

4. **长文本与比对视口缺乏“软着陆”折叠缓冲**：
   - **思考思维链**（`ReasoningRow.tsx:244-255`）：展开指示符 Chevron 有 150ms 优雅旋转，但下方数十 KB 的思考正文却被 `{isExpanded && <div />}` 条件硬拔；尤其在 AI 回复完成瞬间从工作态自动折叠时，整块区域在 1 帧内直接蒸发，引起视口剧烈震颤。
   - **Diff 文件比对视口**（`DiffCardFileList.tsx:381-386`）：文件比对面板同样采用 `{active ? <div /> : null}` 单帧切入切出，高达 560px 的代码区域缺乏微交互缓动。

## 2. 用户核心诉求与体验痛点剖析

### 用户诉求原文

> _“你多找找这种没有做好的微交互吧，我看有很多还是比较平铺直叙的呢。最重要的理念就是我们的动画要做到不打扰以及恰到好处，不过喧宾夺主。不要弄的和果冻一样上下跳，响应要及时，动画时长尽可能干净利落。”_

### 核心准则映射与红线对齐

| 维度                    | 用户原意诉求                                           | 工业级微交互落地准则                                             | 严禁触碰红线（反模式）                                           |
| :---------------------- | :----------------------------------------------------- | :--------------------------------------------------------------- | :--------------------------------------------------------------- |
| **不打扰 / 不喧宾夺主** | 动画是辅助，绝不能抢走用户视线，保持中性灰度与克制幅度 | 几何位移不超过 **2px ~ 4px**，缩放幅度控制在 **0.985 ~ 1.0**     | 严禁大红大紫闪烁、大幅度拉扯（$\Delta y > 8\text{px}$）          |
| **拒绝果冻弹跳**        | 严禁上下反弹晃动，动作一次到位，坚决摒弃橡皮筋感       | 严禁使用过冲弹簧，曲线严格限定在 `cubic-bezier(0.16, 1, 0.3, 1)` | 严禁 $y > 1.0$ 的过冲曲线（Overshoot Spring / Jelly Bounce）     |
| **响应及时 / 干净利落** | 点击立即响应，无迟滞感，起步果断                       | 按压反馈在 **60ms** 内瞬间响应，展开收起收敛于 **120ms ~ 180ms** | 严禁 $>220\text{ms}$ 的拖泥带水延迟，严禁 `max-height` 假死空等  |
| **告别平铺直叙**        | 杜绝 0ms 瞬间闪现闪灭，赋予自然的空间连续性与层级流动  | 统一应用 CSS Grid 纯合成层零重排尺寸过渡与微透明度同步缓动       | 严禁裸奔的 `display: none` / `block` 硬切，严禁直接 unmount 塌陷 |

## 4. 克制利落微交互设计系统与数学建模

针对上述排查出的五大模块深层死角，严格恪守用户关于**“不打扰、恰到好处、不过喧宾夺主、响应及时、干净利落、拒绝果冻跳跃”**的铁律，制定一套工业级微交互重构标准。

### 4.1 零重排折叠展开标准：CSS Grid `grid-template-rows: 0fr -> 1fr`

在现代渲染引擎（Blink / WebKit）中，`grid-template-rows` 是实现不定高尺寸平滑过渡的最优解。它彻底解决了 `max-height: 2000px` 的时间扭曲问题，且无需 JavaScript 计算实际高度：

```
折叠态 (0fr):
┌───────────────────────────────┐  grid-template-rows: 0fr
└───────────────────────────────┘  (内部 min-height: 0; overflow: hidden; opacity: 0)
               │
               ▼  150ms ~ 180ms cubic-bezier(0.16, 1, 0.3, 1) [纯单调曲线，零过冲]
展开态 (1fr):
┌───────────────────────────────┐  grid-template-rows: 1fr
│  内容固有高度（自动弹性贴合）      │  (内部 opacity: 1; transform: translateY(0))
└───────────────────────────────┘
```

#### 核心数学与 CSS 规范模板

```css
/* 折叠宿主层（纯尺寸驱动） */
.foldableHost {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows 160ms cubic-bezier(0.16, 1, 0.3, 1);
  overflow: hidden;
}

.foldableHost[data-expanded='true'],
.foldableHost.isExpanded {
  grid-template-rows: 1fr;
}

/* 内部内容插槽（纯合成层透明度与微位移） */
.foldableSlot {
  min-height: 0;
  overflow: hidden;
  opacity: 0;
  transform: translateY(-2px);
  transition:
    opacity 130ms ease-out,
    transform 130ms cubic-bezier(0.16, 1, 0.3, 1);
  will-change: opacity, transform;
}

.foldableHost[data-expanded='true'] .foldableSlot,
.foldableHost.isExpanded .foldableSlot {
  opacity: 1;
  transform: translateY(0);
}
```

### 4.2 触觉微反馈规范：60ms/0.985 紧凑按压与零振荡恢复

对于所有按钮、会话条目、卡片点击，必须具备清晰的按压物理反馈，但严禁软绵绵的弹性：

```
静止态:            scale(1)
按下态 (:active):   scale(0.985) + 极低对比度底色加深（时长 60ms ease-out，即按即下）
释放态:            scale(1)（时长 100ms ease-out，干净利落弹回，无任何 overshoot 往复）
```

- **缩放极限量**：缩放比例绝对不得低于 `0.98`（推荐 `0.985`），防止文本重采样引起字模模糊；
- **颜色混入量**：完全符合 `AGENTS.md §13`，激活态混入文本色不得超过 10%。

### 4.3 工作区 Tab 切换视口：120ms 无感交叉淡入（Zero-Lag Cross-fade）

当工作区面板（Terminal, Diff, Preview, Dag, Files）在 `display: none` 与 `flex` 之间切换时，为激活的新面板赋予极度克制的淡入效果：

```css

}

    opacity: 0;
    transform: scale(0.996);
  }
  to {
    opacity: 1;
    transform: scale(1);
  }
}
```

- **120ms 超短时长**：比人眼视觉暂留（~100ms）稍长，既让视网膜感受到界面的平稳出现，又完全察觉不到任何等待感；
- **0.4% 微缩放**（`scale(0.996) -> 1`）：提供微微前浮的深度质感，杜绝跳跃。

### 4.4 时间与缓动曲线数学验证（Zero-Overshoot 单调渐近）

为彻底落实用户“不要弄的和果冻一样上下跳”的诉求，战役统一锁死缓动曲线：

- **推荐曲线**：`cubic-bezier(0.16, 1, 0.3, 1)`（Ease-Out Quartic 变体）。
- **数学单调性验证**：其控制点 $P_1(0.16, 1.0)$ 和 $P_2(0.3, 1.0)$ 的导数在 $t \in [0, 1]$ 区间内恒满足 $f'(t) \ge 0$，函数值曲线严格单调递增，且在 $t \to 1$ 时平滑收敛于 $1.0$，**最大位移比 $y_{\max} = 1.0000$**（超调量 Overshoot 为 $0.00\%$）。物理上完全切断任何果冻、振荡与反弹。
