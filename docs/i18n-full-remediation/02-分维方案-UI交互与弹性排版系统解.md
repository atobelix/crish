## 一、总体架构与核心突破矩阵

### 1.1 问题定性与架构根因分析
在前期勘察中，UI 与交互层暴露出 5 大致命缺陷：
1. **声明式与呈现式混淆**：`useAppearanceSchema.ts` 与 `settingsTabsMeta.ts` 在静态声明层将汉字硬编码为属性，UI 组件无法感应当下激活语言并动态重构表单。
2. **数据层越俎代庖写死呈现**：`api/chatEmptyState.ts` 作为脱水业务纯逻辑，却直接输出了 `CHAT_EMPTY_TITLES` 等中文常文字符串，导致 UI 消费端沦为被动展示中文的“哑终端”。
3. **物理排版缺乏弹性防御（Defensive CSS Missing）**：SettingsSidebar 等容器硬编码固定宽度（220px）和固定高度（32px），在英文翻译字符宽度膨胀 30%~70% 时缺乏 `white-space: nowrap; text-overflow: ellipsis; min-width: 0;` 兜底，引发严重的恶性换行、高度塌陷与视觉挤压。
4. **业务逻辑与特定自然语言产生深度耦合**：`SessionRow.tsx:270` 依赖中文正则 `replace(/ - 分支$/, '')` 判定和还原会话标题，直接导致英文用户创建的分支会话展示异常与状态机撕裂。
5. **无障碍读屏的科学怪人式字符串拼接**：`UserProfileCard.tsx` 等组件使用模板字符串 `${t(...)}` 混拼中文标点与中文字符，导致跨语言 TTS（文字转语音）引擎遭遇严重的语音合成畸变和破音。

## 二、15 个设置 Tab 与动态表单重构系统解

### 2.1 SchemaRenderer 原生 i18nKey 支持契约

#### 2.1.1 现有契约缺陷穿透
在现有 [`apps/crish-desktop/src/components/settings/SettingsSchemaRenderer.tsx`](file:///c:/Software/conex/apps/crish-desktop/src/components/settings/SettingsSchemaRenderer.tsx#L6-L42) 中：
- `SchemaProperty` 仅声明了 `title: string`、`desc?: string`、`options?: { value: string; label: string; hint?: string }[]`；
- `SchemaSection` 仅声明了 `title: string`；
- 这导致任何由 Hook（如 `useAppearanceSchema`）动态构造的 Schema 必须在定义阶段将自然语言字符串物化。若要支持多语言，开发者必须将 `t` 函数层层透传给各个 Schema 构造器，不仅代码极其冗余，且破坏了 Schema 描述性数据结构的纯粹性。

#### 2.1.2 升级后的类型契约设计（SSOT 单一真理源）

#### 2.1.3 SettingsSchemaRenderer 内部原生解析机制
在 `SettingsSchemaRenderer` 内部直接挂载 `useI18n()`，通过纯函数进行无缝求值，实现完全向后兼容与运行时动态响应：

```tsx
// SettingsSchemaRenderer.tsx 内部核心解析逻辑
import { useI18n } from '../../i18n';

export const SettingsSchemaRenderer: React.FC<SettingsSchemaRendererProps> = React.memo(
  ({ schema, values, onSave, ready }) => {
    const { t } = useI18n();

    // 辅助解析纯函数：优先消费 Key，次选 fallback
    const resolveI18n = (
      key: string | undefined,
      fallback: React.ReactNode | string | undefined
    ): React.ReactNode => {
      if (key) {
        const translated = t(key);
        // 若找不到词条返回了 key 本身，且提供了非空 fallback，优先使用 fallback
        if (translated !== key) return translated;
      }
      return fallback ?? '';
    };

    if (!values) {
      return (
        <SettingsSection>
          <SettingsCard>
            <SettingsRow
              title={<span className={uiStyles.listEmpty}>{t('common.loading', '加载中…')}</span>}
            />
          </SettingsCard>
        </SettingsSection>
      );
    }

    return (
      <>
        {schema.map((section, sIdx) => {
          const sectionTitle = resolveI18n(section.titleKey, section.title);
          return (
            <SettingsSection key={sIdx} title={sectionTitle}>
              <SettingsCard>
                {section.properties.map((prop) => {
                  const domId = getElementId(prop.key);
                  const val = (values as Record<string, unknown>)[prop.key];
                  const propTitle = resolveI18n(prop.titleKey, prop.title);
                  const propDesc = resolveI18n(prop.descKey, prop.desc);
                  const propPlaceholder = typeof prop.placeholderKey === 'string'
                    ? t(prop.placeholderKey, prop.placeholder)
                    : prop.placeholder;

                  let control: React.ReactNode = null;

                  if (prop.type === 'toggle-group') {
                    control = (
                      <SegmentedControl
                        id={domId}
                        options={(prop.toggleOptions ?? []).map((opt) => ({
                          value: opt.value,
                          label: resolveI18n(opt.labelKey, opt.label),
                          icon: opt.icon,
                          badge: opt.badge,
                        }))}
                        value={String(val ?? '')}
                        disabled={!ready}
                        onChange={(next) => void onSave({ [prop.key]: next })}
                      />
                    );
                  } else if (prop.type === 'select') {
                    control = (
                      <Select
                        id={domId}
                        className={uiStyles.controlSelect}
                        options={(prop.options ?? []).map((opt) => ({
                          value: opt.value,
                          label: String(resolveI18n(opt.labelKey, opt.label)),
                          hint: typeof opt.hintKey === 'string'
                            ? String(resolveI18n(opt.hintKey, opt.hint))
                            : opt.hint,
                        }))}
                        value={String(val ?? '')}
                        disabled={!ready}
                        onChange={(next) => void onSave({ [prop.key]: next })}
                      />
                    );
                  }
                  // ... 其余控件统一遵循 resolveI18n

                  return (
                    <SettingsRow
                      key={prop.key}
                      title={propTitle}
                      desc={propDesc}
                      control={control}
                    />
                  );
                })}
              </SettingsCard>
            </SettingsSection>
          );
        })}
      </>
    );
  }
);
```

### 2.3 静态 TAB_META 升级为动态 useSettingsTabs() Hook

#### 2.3.1 架构缺陷与响应式瓶颈
现有 [`apps/crish-desktop/src/components/settingsTabsMeta.ts`](file:///c:/Software/conex/apps/crish-desktop/src/components/settingsTabsMeta.ts#L63-L323) 将 15 个 Tab 的 `label`、`group`、`keywords` 写死为全局静态常量 `TAB_META`。当用户在设置中将语言由中文切换为英文时，由于 `TAB_META` 在模块加载时即被固定，设置侧边栏和搜索功能完全无法感应语言变更，发生严重失真。

#### 2.3.2 语言中立规范元数据：TabIdentity 定义

1. **不变身份层（TabIdentity）**：仅包含 `id`、`icon`、语义化翻译 Key 和标准不可变标识符；
2. **动态呈现层（TabMeta）**：由 Hook 在运行时响应当前语言，动态计算求值。

#### 2.3.3 useSettingsTabs() 动态响应 Hook 落地
构建全局响应式 Hook，提供国际化求值、多语言搜索索引构建和 Tab 分组管理：

```typescript
// apps/crish-desktop/src/components/settings/useSettingsTabs.ts

import { useMemo } from 'react';
import { useI18n } from '../../i18n';
import { TAB_IDENTITIES, type TabIdentity, type TabMeta, type TabType } from '../settingsTabsMeta';

export interface UseSettingsTabsResult {
  /** 当前激活语言下的全部 Tab 列表 */
  tabs: TabMeta[];
  /** 快速根据 ID 检索当前语言 Tab 属性 */
  getTabMeta: (id: TabType) => TabMeta | undefined;
  /** 跨语言双向匹配检索函数（支持中文拼音/汉字与原生英文词根） */
  searchTabs: (query: string) => TabMeta[];
  /** 分组列表，便于侧栏按 Section 组织呈现 */
  groupedTabs: { group: string; items: TabMeta[] }[];
}

export function useSettingsTabs(): UseSettingsTabsResult {
  const { t, language } = useI18n();

  const tabs = useMemo<TabMeta[]>(() => {
    return TAB_IDENTITIES.map((identity) => {
      const label = t(identity.labelKey);
      const group = t(identity.groupKey);
      const localizedKeywordsRaw = t(identity.keywordsKey);
      
      // 字典内以逗号或竖线分隔 keywords: '账户,账号,工作区'
      const localizedKeywords = localizedKeywordsRaw
        .split(/[,|、]/)
        .map((k) => k.trim())
        .filter(Boolean);

      // 合并本地化关键词与不可变规范别名（英文缩写），去重
      const mergedKeywords = Array.from(
        new Set([...localizedKeywords, ...identity.canonicalAliases, label.toLowerCase()])
      );

      return {
        id: identity.id,
        icon: identity.icon,
        label,
        group,
        keywords: mergedKeywords,
        demoOnly: identity.demoOnly,
      };
    });
  }, [t, language]);

  const tabsMap = useMemo(() => new Map(tabs.map((tab) => [tab.id, tab])), [tabs]);

  const groupedTabs = useMemo(() => {
    const groups: { group: string; items: TabMeta[] }[] = [];
    tabs.forEach((tab) => {
      const existing = groups.find((g) => g.group === tab.group);
      if (existing) {
        existing.items.push(tab);
      } else {
        groups.push({ group: tab.group, items: [tab] });
      }
    });
    return groups;
  }, [tabs]);

  const searchTabs = useMemo(() => {
    return (rawQuery: string): TabMeta[] => {
      const q = rawQuery.trim().toLowerCase();
      if (!q) return tabs;
      return tabs.filter((tab) => {
        if (tab.label.toLowerCase().includes(q)) return true;
        if (tab.group.toLowerCase().includes(q)) return true;
        return tab.keywords.some((k) => k.toLowerCase().includes(q));
      });
    };
  }, [tabs]);

  return {
    tabs,
    getTabMeta: (id: TabType) => tabsMap.get(id),
    searchTabs,
    groupedTabs,
  };
}
```

#### 4.2.2 核心纯函数 resolveChatEmptyDescriptor 实现
```typescript
// apps/crish-desktop/src/api/chatEmptyState.ts

export interface ChatEmptyCopyInput {
  kind: ChatEmptyKind;
  firstRunOpen?: boolean;
  needsKeySetup?: boolean;
  needsModelSetup?: boolean;
  filterQuery?: string | null;
  engineOk?: boolean | null;
}

export function resolveChatEmptyDescriptor(
  input: ChatEmptyCopyInput
): ChatEmptyDescriptor {
  const {
    kind,
    firstRunOpen = false,
    needsKeySetup = false,
    needsModelSetup = false,
    engineOk = null,
  } = input;

  const density: 'compact' | 'default' = firstRunOpen ? 'compact' : 'default';

  switch (kind) {
    case 'no-session': {
      const primaryAction = resolveChatEmptyPrimaryAction(kind, { firstRunOpen });
      return {
        kind,
        titleKey: 'chat.empty.noSession.title',
        subKey: firstRunOpen
          ? 'chat.empty.noSession.subFirstRun'
          : 'chat.empty.noSession.subDefault',
        primaryAction,
        actionKey: primaryAction ? 'chat.empty.action.createSession' : undefined,
        ariaKey: 'chat.empty.noSession.aria',
        showProjectBar: false,
        showQuickPrompts: false,
        density,
      };
    }
    case 'filter-empty': {
      const preview = truncateFilterPreview(input.filterQuery || '');
      const primaryAction = resolveChatEmptyPrimaryAction(kind);
      return {
        kind,
        titleKey: 'chat.empty.filterEmpty.title',
        subKey: preview
          ? 'chat.empty.filterEmpty.subWithQuery'
          : 'chat.empty.filterEmpty.subDefault',
        subParams: preview ? { query: preview } : undefined,
        primaryAction,
        actionKey: primaryAction ? 'chat.empty.action.clearFilter' : undefined,
        ariaKey: 'chat.empty.filterEmpty.aria',
        showProjectBar: false,
        showQuickPrompts: false,
        density,
      };
    }
    case 'session-empty': {
      if (firstRunOpen) {
        return {
          kind,
          titleKey: 'chat.empty.sessionEmpty.title',
          subKey: 'chat.empty.sessionEmpty.subFirstRun',
          primaryAction: null,
          ariaKey: 'chat.empty.sessionEmpty.aria',
          showProjectBar: false,
          showQuickPrompts: false,
          density,
        };
      }
      if (engineOk === false) {
        return {
          kind,
          titleKey: 'chat.empty.sessionEmpty.title',
          subKey: 'chat.empty.sessionEmpty.subEngineDown',
          primaryAction: null,
          ariaKey: 'chat.empty.sessionEmpty.aria',
          showProjectBar: true,
          showQuickPrompts: false,
          density,
        };
      }
      if (needsKeySetup) {
        return {
          kind,
          titleKey: 'chat.empty.sessionEmpty.title',
          subKey: 'chat.empty.sessionEmpty.subNeedsKey',
          primaryAction: null,
          ariaKey: 'chat.empty.sessionEmpty.aria',
          showProjectBar: true,
          showQuickPrompts: true,
          density,
        };
      }
      if (needsModelSetup) {
        return {
          kind,
          titleKey: 'chat.empty.sessionEmpty.title',
          subKey: 'chat.empty.sessionEmpty.subNeedsModel',
          primaryAction: null,
          ariaKey: 'chat.empty.sessionEmpty.aria',
          showProjectBar: true,
          showQuickPrompts: true,
          density,
        };
      }
      return {
        kind,
        titleKey: 'chat.empty.sessionEmpty.title',
        subKey: 'chat.empty.sessionEmpty.subDefault',
        primaryAction: null,
        ariaKey: 'chat.empty.sessionEmpty.aria',
        showProjectBar: true,
        showQuickPrompts: true,
        density,
      };
    }
    default: {
      const _exhaustive: never = kind;
      return _exhaustive;
    }
  }
}
```

#### 5.1.2 跨语言中立的分支标题与呈现算法

我们制定双层根治方案：
1. **分支命名工厂多语言化**：在创建分支时，根据当前激活语言生成符合当地习惯的初始标题；
2. **标题净化纯函数中立化**：在呈现层，使用跨语言正则同时接纳中文 ` - 分支` 与英文 ` - Branch`（不区分大小写）；
3. **读屏标签完整参数化**。

```typescript
// apps/crish-desktop/src/utils/sessionTitle.ts

import type { SupportedLanguage } from '../i18n/types';

/** 跨语言分支后缀正则匹配器 */
export const BRANCH_SUFFIX_REGEX = / - (?:分支|Branch)$/i;

/**
 * 语言中立的分支纯净标题提取纯函数
 */
export function getSessionCleanTitle(title: string, isBranched: boolean): string {
  if (!isBranched) return title;
  return title.replace(BRANCH_SUFFIX_REGEX, '').trim();
}

/**
 * 分支标题生成工厂（创建新分支会话时使用）
 */
export function generateBranchTitle(parentTitle: string, lang: SupportedLanguage): string {
  const clean = parentTitle.replace(BRANCH_SUFFIX_REGEX, '').trim();
  const suffix = lang === 'en-US' ? ' - Branch' : ' - 分支';
  return `${clean}${suffix}`;
}
```
