# 多 Agent 协同修复方案（文档索引）

本目录是 Crish 项目多 Agent 协同修复方案与多 Agent 协作功能设计的中枢文档。所有参与修复的 Agent（主/子）开工前先读 `00-方案总览.md`，执行具体轮次时读对应执行手册，操作安全红线以 `05-协同操作约束与安全.md` 为准。

## 使用方式

1. **主 Agent**：读 `00-方案总览.md` 定轮次与任务，读 `05-协同操作约束与安全.md` 定分配纪律，然后按执行手册（01/02/03）逐轮分配子 Agent。
2. **子 Agent**：开工前读 `05-协同操作约束与安全.md`（git 安全与文件所有权是硬约束），执行手册中自己的任务章节（含文件域、验收命令）。
3. **每轮结束**：主 Agent 按 `00-方案总览.md` 的轮次报告模板汇总，输出作为下一轮输入。
4. **后续功能轮（R7）**：读 `04-Agent功能需求设计.md`，按 C1-C10 能力规格与验收断言实现。
