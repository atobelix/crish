## 一、已完成

- **注入内容模块** `crates/agent-tools/src/subagent_inject.rs`（新增，agent-tools
  是叶子 crate，对齐 revert_guard.rs 接线约定——不触达 conex-db，只收纯值）：
  - `started_at_section(ms)`：started_at 注入正文——`@dynamic` 标记（M1 约定 2，
    不在 C10 字节级一致断言范围内）+ ISO8601（毫秒精度，与 engine.rs
    `now_iso_utc` / session-loop `iso8601_from_epoch_millis` 同源
    Howard Hinnant 手工换算，不引入 chrono）+ epoch ms（= 库值，验收 1 精确
    匹配）+ 隔离边界声明（04 C2 行为 1）；
  - `git_revert_caution_section(threshold_hours)`：git 回退谨慎指引固定文案
    （04 C2 行为 2，快照断言对象）——单文件修复优先（`git checkout -- <file>` 级）、
    不要整体回退、单文件修复失败才整体回退、整体回退走 C3 审批门禁（审批人=user、
    full-access 不豁免）；阈值参数化（默认 24h = C3 的
    `DEFAULT_REVERT_MAX_REF_AGE_HOURS`，消除双权威）；
  - `resolve_started_at(existing, fallback_now)`：**续跑不刷新**（C2 边界 2）——
    库中已有首次创建时间 → 原值；新 spawn（库中无值）→ 生成当前时间；非正数
    坏值容错走生成；
  - `ref_older_than_threshold(started_at, ref_commit_time, threshold_hours)`：
    ref 年代判定（C2 行为 2 引擎侧辅助；真实 git 年代查询 `git log -1
    --format=%ct <ref>` 由引擎侧接线，对齐 revert.rs「不猜命令参数」契约）；
    含等于触发（对齐 C3「≥」语义）；ref 晚于 started_at → false（不保守误判）；
  - `subagent_session_injections(Option<started_at_ms>, threshold)`：
    `(标题, 正文)` 注入项集合——None（主 agent / 非子代理 run）→ 空列表
    （无注入行为不变）；标题常量 `STARTED_AT_SECTION_TITLE` /
    `REVERT_CAUTION_TITLE` 供 M1 `ContextInjection.title` 使用；
  - 导出：`lib.rs` `pub mod subagent_inject` + `pub use`（DYNAMIC_MARKER /
    DEFAULT_REF_AGE_THRESHOLD_HOURS / 6 函数 / 2 标题常量）。
- **测试**：`subagent_inject` 6 用例全绿，覆盖任务 4 全部断言：
  1. 注入内容存在（mock M1 render 拼接后 system prompt 含 ISO8601 且等于库值

  （engine.rs:1239），produce 时 render（engine.rs:1290-1291）。

**挂载方式确认**（本模块与 M1 接口的适配已做：title/content 分离，content
不含 `##` 标题行，标题由 ContextInjection.title 承载）：

```rust
// 合并点接线示例（M2 run_subagent spawn 路径，M4 只读消费）
let mut injector = ContextInjector::new();
for (title, content) in
    agent_tools::subagent_session_injections(started_at_ms, threshold_hours)
{
    injector.push(ContextInjection::new(
        ContextInjectionKind::System,
        title,
        content,
    ));
}
let producer = SessionLoopProducer::new(...).with_context_injector(Some(injector));
```
