## 3. 持久化字段分析（旧 key：`crish-layout-v1`）

拆分前 `withPersist` partialize 仅持久化 **4 个布局域字段**（`workspaces` / `sidebarCollapsed` / `activeWorkspaceIndex` / `tabModeEnabled`）。因此：

- **旧 key 兼容读取**：`layoutStore` 保留 `crish-layout-v1` + 原 partialize 不变（key 与形状不变，无需迁移）。
- **新分片**：
  - `settingsStore` → `crish-settings-v1`（partialize：`scheduledTasks`）
  - `workerStore` → `crish-workers-v1`（partialize：`killedWorkerIds`）
  - `terminalStore` → 不持久化（瞬时缓冲，语义即"运行期会话产物"）
  - `permissionStore` → 不接入 zustand persist；`permissionMode` / `commandPermissions` 的落盘继续由既有 `api/permissionModes`（`persistPermissionMode` / `loadStoredPermissionMode`）与 `api/commandPermissions`（`saveCommandPermissions` / `loadCommandPermissions`）承担，避免双写冲突。

## 4. 行为保留与变更说明

1. **保留**：terminal 缓冲按会话隔离 + `terminalLines` 活动镜像语义、diff 缓冲 coherence（`setDiffFiles`/`removeDiffFile` 自动修正 `activeDiffSource`）、权限三态联动（`setPermissionMode` 派生 `planModeEnabled` 并重置 `planApproved`）、`syncTelemetryData` 的 tokenUsage 清洗 + worker 合并。
2. **变更（低风险，已记录）**：`killWorker` 不再扣减 `tokenUsage`（原"input-1500 / cost-0.0045"为 demo 记账；`tokenUsage` 为遥测权威值，归 settingsStore，避免 worker↔settings 双向 import 成环）。
3. **跨域写**：`settingsStore.syncTelemetryData` → `workerStore.applyTelemetryWorkers`（settings→worker **单向**依赖，无环）。
