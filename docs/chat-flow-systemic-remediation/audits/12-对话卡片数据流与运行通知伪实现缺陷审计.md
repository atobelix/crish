## 一、`toolStackProps` 透传断层与动作缺失缺陷

### 缺陷 01：【契约断裂与渲染击穿】`useChatMessageState` 组装 `toolStackProps` 时遗失 `renderLinkedAgentPanel`，迫使下游每帧裸构对象破坏 Memo 隔离

- **危害后果 / 真实运行期隐患**：
  无论系统是否真正存在后台任务，前端都在以 3000ms（3秒）为间隔频繁轮询底层 API。更严重的是，`fetchTasks` 每次通过 `filter` 产生全新引用的数组 `list` 并调用 `setBgTasks(list)`。这导致即使任务列表没有任何实质变化，甚至列表恒为空，`ChatStatusRibbons` 也会被无条件每 3 秒强制重渲染一次，持续消耗 CPU 算力，严重违反了本仓库禁止短间隔轮询、必须依赖 Reactive Wakeup 推送通知的架构纪律。
