### 【缺陷分类与编号】：虚假回调与状态脱钩 · DEFECT-INJ-02

## 二、路径打开安全性与校验转义缺陷

### 【缺陷分类与编号】：系统安全性与本地代码执行漏洞 · DEFECT-INJ-05

- **【断层事实】**：

  ```ts
  // apps/crish-desktop/src/components/chat-card/useChatSessionActions.ts:85-88

    /\.(pptx?|docx?|xlsx?|pdf|zip|rar|7z|tar|gz|exe|png|jpe?g|gif|webp|bmp|ico|tiff?|mp4|mov|webm|mp3|wav)$/i.test(

    );
  ```
  当路径为外部绝对路径时：
  ```ts
  // apps/crish-desktop/src/components/chat-card/useChatSessionActions.ts:126-133
  if (isAbsoluteFsPath(trimmed)) {
    if (isOfficeOrBinary) {
      // Office/PPT/二进制外部文件：通过系统默认程序打开

        toast.show('文件不存在');
  ```

### 【缺陷分类与编号】：路径解析与锚点语法破坏 · DEFECT-INJ-06
- **【代码文件与精确行号】**：

  ```ts
    .then(...)
    .catch((err: unknown) => {

        msg.includes('Path does not exist') ||
  ```

## 四、可访问性与键盘交互缺陷

## 五、Diff 状态与架构契约虚假声明缺陷

### 【缺陷分类与编号】：Diff 结构未就绪导致视图切换至脏状态 · DEFECT-INJ-15
- **【代码文件与精确行号】**：

  - `apps/crish-desktop/src/api/store-access/telemetryAccess.ts:50-82`
- **【断层事实】**：
  在 `useChatDiffPanel.ts` 中：
  ```ts

    (diff: FileDiff) => {
      setActiveDiffSourceAccess(diff);
  ```

  而在 `telemetryAccess.ts` 中：
  ```ts

  export function setActiveDiffSource(diff: FileDiff | null): void {
    if (diff === null) {
      useTerminalStore.getState().setActiveDiffSource(null);
      return;

    useTerminalStore.getState().setActiveDiffSource(normalized);
  ```

  `normalizeFileDiff`（L50-66）对 `diff` 结构有严格字段要求（必须包含数值型 `additions`、`deletions` 及合法的 `changes` 数组）。如果注入卡片携带的 Diff 快照格式稍有欠缺，`normalizeFileDiff` 返回 `null`，`setActiveDiffSource` 静默退出，Store 未被更新。

- **【危害后果 / 真实运行期隐患】**：
  右侧标签页强行切换到了 Diff 面板，但由于当前活跃的 Diff 数据没有写入，Diff 面板展示的依然是上一次操作的旧代码文件或白屏。用户点击“查看 A 的 Diff”，看到的却是“B 的 Diff”，引起严重的业务决策与代码混淆。
