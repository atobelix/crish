## 缺陷 08：【事件冒泡穿透与双重触发】未阻止冒泡导致拖放文件被 chatBody 与 window 连续触发两次

- **断层事实**：
  在 `ChatCard.tsx:58-82` 中，宿主监听了全局 `window` 的 `drop` 事件：

## 缺陷 10：【长按取消竞态与误停】ComposerSendControls 异步确认对话框导致抬手瞬间误触发常规停止

## 缺陷 15：【数据流逆向穿透与 DOM 窥探】ChatComposer 绕过父级 props 采用 DOM MutationObserver 窥探状态

  ```tsx
    emptyKindProp ?? undefined
  );
  useEffect(() => {
    if (emptyKindProp !== undefined && emptyKindProp !== null) return;
  ```
