## 缺陷与危险代码清单

### 1. 【功能不联通 / 虚假契约】`onRetryTool` 工具重试链路完全断空
- **代码位置**：
  - `apps/crish-desktop/src/components/chat-tool-call/ToolCallHeader.tsx:405`
  - `apps/crish-desktop/src/components/chat-tool-call/CompactToolRow.tsx:63, 258`
- **断层事实**：
  `ToolCallHeader` 声明了重试逻辑 `{tc.status === 'error' && onRetryTool ? <Button onClick={() => onRetryTool(tc.id)}>重试</Button> : null}`。
  但在生产组装树中，`ChatCard.tsx`（L157-193）与 `useChatMessageState.ts`（L279-312）的 `toolStackProps.actions` 从未定义或传入 `onRetryTool`。
- **危害后果**：
  当真实工具执行失败（`tc.status === 'error'`）时，重试按钮因 `onRetryTool === undefined` 永远无法渲染；单测 `ChatToolCallBlock.test.tsx` 依赖人工 mock 传参产生虚假全绿假象，生产环境用户无法重试失败工具。

---

### 2. 【功能不联通 / 虚假契约】`onRetryInjection` 注入重试链路完全断空
- **代码位置**：
  - `apps/crish-desktop/src/components/chat-injection/InjectionHeader.tsx:126`
  - `apps/crish-desktop/src/components/chat-message/MessageContent.tsx:162-176`
- **断层事实**：
  `InjectionHeader` 声明了 `{isFailed && onRetryInjection ? <Button onClick={() => onRetryInjection(injection.id)}>重试</Button> : null}`。
  然而在 `MessageContent.tsx` 组装 `CompactInjectionRow` 时，仅解构了 `onOpenDiff` 与 `onOpenPath`，根本未传入 `onRetryInjection`；上游 `toolStackProps.actions` 中亦完全缺失该方法。
- **危害后果**：
  当上下文注入（如规则解析、技能加载、文件读取）失败时，错误卡片上的重试机制彻底失效。

---

### 3. 【UI 硬编码残存】TSX 组件内联样式裸写 `#10b981` 与魔术 Hex 颜色
- **代码位置**：
  - `apps/crish-desktop/src/components/chat-tool-call/ModernTerminalToolCall.tsx:90, 105`
  - `apps/crish-desktop/src/components/chat-tool-call/ModernCodeBlock.tsx:44`
  - `apps/crish-desktop/src/components/chat-tool-call/ToolCallDiffPreview.tsx:96`
  - `apps/crish-desktop/src/components/chat-tool-call/ToolCallHeader.tsx:312, 322`
- **断层事实**：
  在复制成功态图标上直接硬编码内联样式：
  `<Check size={12} strokeWidth={2.4} style={{ color: '#10b981' }} />`；
  在 `ToolCallHeader.tsx` 中直接指定属性 `color="var(--accent-red, #c45c5c)"`、`color="var(--text-tertiary, #8c877d)"`。
- **危害后果**：
  直接违背用户指令“严禁硬编码，不论是纯逻辑还是 UI”与 Conex UI Design Tokens 规范；绕过了 CSS 模块的统一主题控制与暗黑模式适配。

### 4. 【暗黑模式闪白隐患】周边对话流 CSS 模块硬编码 `#ffffff` 回落
- **代码位置**：
  - `apps/crish-desktop/src/components/chat-card/UnitChromeActions.module.css:15-18`
  - `apps/crish-desktop/src/components/chat-message-row/FlowPlanMilestone.module.css:74, 82, 88`
  - `apps/crish-desktop/src/components/chat-message-row/ReasoningRow.module.css:260`
  - `apps/crish-desktop/src/components/chat-card/SubagentHeaderPanel.module.css:45, 144, 154`
- **断层事实**：
  在 CSS 变量回退值中广泛硬编码 `#ffffff`、`#10b981`、`#ef4444`：
  - `background: var(--bg-card, #ffffff);`
  - `background: var(--bg-surface, #ffffff);`

- **危害后果**：
  在变量未注入、主题切换瞬间或暗黑模式降级下，页面将强制闪现亮白色背景，引发视觉闪白与高对比度割裂。

### 5. 【高频重渲染性能隐患】`CompactToolRow.tsx` 独立 100ms 轮询未收敛
- **代码位置**：
  - `apps/crish-desktop/src/components/chat-tool-call/CompactToolRow.tsx:67-72`
- **断层事实**：
  ```ts
  const [liveNow, setLiveNow] = useState(Date.now());
  useEffect(() => {
    if (tc.status !== 'running' || !tc.startedAt) return;
    const id = setInterval(() => setLiveNow(Date.now()), 100);
    return () => clearInterval(id);
  }, [tc.status, tc.startedAt]);
  ```
- **危害后果**：
  当并发运行 5~10 个工具时，每个组件实例均启动独立的 100ms `setInterval`，每秒产生 50~100 次独立的 React 状态更新与局部重渲染，缺乏单一时钟源（Ticker）驱动。

---

### 6. 【双轨类型强转隐患】`MessageVirtualizer.tsx` 不安全空回退
- **代码位置**：
  - `apps/crish-desktop/src/components/chat-message-list/MessageVirtualizer.tsx:75-77`
- **断层事实**：
  ```ts
  const toolStackProps =
    interaction?.toolStackProps ??
    ({ activeSessionId } as import('../chat-tool-call/ChatToolCallBlock').ChatToolStackSharedProps);
  ```
- **危害后果**：
  使用 `as` 强转断言欺骗 TypeScript 编译器；当 `interaction?.toolStackProps` 为空时，下游访问 `toolStackProps.actions.onOpenPath` 或 `expandedTools` 将发生未定义取属性抛错。
