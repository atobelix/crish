## 三、纯逻辑依赖拓扑与执行顺序（Pure Logical Execution Sequence）

本方案严格依据自底向上的数据与架构依赖次序排列，不排工期，不分主次，每一项均为同权闭环要求：

### 阶段一：跨层通讯与核心协议契约层（基石对齐）
- **逻辑依赖**：无前置依赖，是整个对话系统前后端通信的绝对基石。
- **任务单元**：
  1. `crates/conex-types/src/history.rs`：为 `blocks_json`、`tool_calls_json`、`tool_call_results_json` 增加 `#[serde(default, alias = "...")]`，双向兼容 camelCase 与 snake_case，杜绝工具调用在反序列化时被丢弃；
  2. `apps/crish-desktop/src/api/chat-bridge/historyMessages.ts`：在发送给 Rust 引擎前，过滤空文本且无内容的 `user` 消息，杜绝向模型服务发出空 user 触发 400 Bad Request；
  3. `crates/conex-types/src/injection_card.rs`：补齐 `diffs` 字段定义，确保前后端 Diff 数据契约镜像一致；
  4. 单一化 `ContextStateMetadata` 类型定义，消除组件层与 store 层的双源声明漂移。
- **验收断言**：
  - `cargo test -p conex-types` 100% PASS；
  - `ConnectionLifecycle.test.ts` 34 项测试 100% PASS。

### 阶段二：存储层事务、会话生命周期与并发隔离层（数据一致性）
- **逻辑依赖**：依赖阶段一的协议与结构契约。
- **任务单元**：
  1. `apps/crish-desktop/src/hooks/chat-stream/`：改造 `renderBufferRef`，以 `Map<sessionId, string>` 替代全局单例，杜绝会话切换时流式正文相互窜写；
  2. `apps/crish-desktop/src/api/session-persistence/sessionRustDbHydrate.ts`：修正持久化保存门禁，当 `msgs.length === 0` 时显式向下发清空指令，杜绝已被用户清空的消息在刷新后“僵尸复活”；
  3. `crates/conex-workspace-store/src/note_documents.rs`：新建便签文档时修正初始 `rev = 0`，与内存水合一致，彻底根除 CAS 冲突导致的首笔写入 100% 报错回滚问题；
  4. 改造 `useNoteTextPersistence.ts` 与 `sessionCrudActions.ts`：持久化防抖增加 `maxWait` 保护，并在 `window.addEventListener('beforeunload')` 中触发紧急同步刷盘，杜绝关窗与刷新时丢失最后编辑内容；
  5. `sessionCrudActions.ts`：`deleteSession` 删除当前活动会话时，自动原子切换焦点至相邻有效会话，杜绝 `useActiveSession()` 出现 `undefined` 导致白屏。
- **验收断言**：
  - 编写并发会话切换停机单测，断言会话 A 与会话 B 正文互不污染；
  - 编写清空会话持久化单测，断言刷新页面后消息数组依然为 `[]`。

### 阶段三：虚拟滚动列表几何稳定与统一测高（消除晃动与颠簸）
- **逻辑依赖**：依赖稳定的数据结构。
- **任务单元**：
  1. `apps/crish-desktop/src/components/chat-message-list/ChatMessageList.module.css`：消除 `[data-chat-list-inner] > :not([hidden]) + :not([hidden])` 相邻兄弟选择器的 `margin-top: 16px`，收敛为每一行包裹节点自身的内部盒模型 padding，消除累积达 1600px 的物理测高黑洞；
  2. `apps/crish-desktop/src/components/chat-message-row/ChatMessageRow.module.css`：彻底拔除 `.row` 上的 `content-visibility: auto` 与 `contain-intrinsic-size: auto 120px`，消除视口滚近时的 120px ↔ 800px 尺寸剧烈颠簸；
  3. `apps/crish-desktop/src/components/chat-message-list/MessageVirtualizer.tsx`：ResizeObserver 采用 `el.offsetHeight || Math.ceil(entry.contentRect.height)` 统一度量完整盒模型高度；
  4. 完善展开折叠生命周期：思考链、Diff、注入详情、流式表格在动画展开/折叠完成时精准触发 `invalidateActual(msgId)`，通知虚拟滚动管理器重新计算。
- **验收断言**：
  - `MessageVirtualizer.test.tsx` 100% 通过；
  - 快速来回滚动长会话列表时无任何白屏占位（Checkerboarding）与几何高度突变跳跃。

### 阶段四：视图状态机、去助手化与全景功能保全（极致美学与完整功能）
- **逻辑依赖**：依赖阶段二的数据存储与阶段三的虚拟化容器。
- **任务单元**：
  1. `apps/crish-desktop/src/components/chat-injection/CompactInjectionRow.tsx`：

  2. `apps/crish-desktop/src/components/chat-message-row/ChatAssistantMessageRow.tsx`：
