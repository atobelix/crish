## 二、任务七条逐项落实

1. **自研悬浮条（ScrollArea 先例同构）**：列 `right: 2px`、宽 `var(--scrollbar-thumb-width)`=10px，thumb 为 div 以 height + `translate3d` 表达尺寸/位置。显隐与 ScrollArea `.visible` 三元组逐项相同——入场 `opacity/transform var(--duration-fast) var(--ease-decelerate) var(--duration-micro)`（150ms + 100ms 延迟），退场 `var(--duration-normal) var(--ease-emphasized)`（200ms）；滑入落在 track 的 `translateX(calc(100% + 2px)) → 0`，列自身 `overflow: hidden` 自裁剪，不依赖祖先裁剪、永不溢出宿主右缘。与先例的差异（有意，登记）：**不移植步进按钮**——聊天长列表步进无实际语义且会吃轨道长；thumb 构造与原生细条同构（整列 10px 可抓、2px 透明边框收 6px 净宽、`background-clip: padding-box`），hover/dragging 同色 `--scrollbar-thumb-active`（先例铁律，无第三态）。
2. **右侧预留 14px**：核实结论见第三节——现有净空已覆盖，**未新增任何正文 padding**。
3. **滑块几何平滑**：`decideThumbSync` 逐帧裁决，经 thumb 的 `data-smooth` 落 CSS 过渡（`height`/`transform var(--duration-fast) var(--ease-standard)` = 150ms standard）：
   - 纯总高阶跃（虚拟器离散提交、滚动位置未动）→ 尺寸+位置同平滑（`both`）；
   - 总高与位置同帧变化（流式贴底增长）→ 仅尺寸平滑、位置直写（`size`）——位置由内容侧逐帧补偿驱动，再叠过渡即滑块撒谎；
   - **用户手势窗内（wheel/touch/滚动键 200ms）与拖拽中：一律全直写**，组件层明文门控 + 6 例组件测试中 2 例钉死；
   - 几何无变化的同步不触碰 DOM（尤其不改写 `data-smooth`），防腰斩在途过渡（组件测试钉死）；
   - 内容侧既有逐帧补偿与虚拟器同步提交时序**零改动**：本组件只读已提交状态（scroll 事件 + RO），晚一帧可接受。
4. **遮罩/FlowScrubber 对齐**：遮罩右避让 12→14px 已改（实机计算值验证 14px，见第五节）。FlowScrubber `.wrapper` 现值即 `calc(var(--scrollbar-thumb-width, 10px) + 4px)` = 14px，**与新预留天然对齐、无数值可改**；常量组（条 [2,12] / 缝 2 / 遮罩与 scrubber 起点 14 / scrubber [14,38]）已钉入 ChatMessageList.module.css 与 ChatOverlayScrollbar.module.css 两处头注释，FlowScrubber 文件本体未动（其 source 测试钉有模式断言，避免无谓扰动）。
5. **S2 交叉口径**：视口尺寸（clientWidth/clientHeight）任一变化的帧，裁决恒为全直写——侧栏布局动画期间（含文字重排引发的总高连带变化）滑块直接跟随，绝不双重平滑；平滑只响应「视口不变前提下的总高变化」。几何 + 组件测试各 1 例钉死。
6. **Reduce Motion**：本批全部过渡只消费 `--duration-fast/normal/micro`、`--ease-*` 与 `--transition-fast`。已逐行核 `styles/tokens-base.css:202-262` 的 `prefers-reduced-motion` 段：上述 token 全量归零（含 `--transition-fast: 0ms`），故新动画自动归零、只随系统设置，**未新写任何媒体查询分支**。直播应用计算样式亦证过渡为 token 表达式（第五节）。未做：操作系统级减动效开关的实机翻转验证（登记）。
7. **滚动锚定不许改坏**：组件对滚动位置只读（唯一写回 = 拖拽经 useThumbDrag，与原生条拖拽同性质）；未触 `messageVirtualizerScrollState` / `useScrollAnchor` / 虚拟器提交路径。既有锚定相关套件（useScrollAnchor、chatTailBuffer、chatScrollGeometry、MessageVirtualizer 四套）全绿（第四节）。
