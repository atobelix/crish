## 2. M6 · 图片加载高度跳变 —— 两面坐实有跳变；尺寸加载前不可知 → 登记数据面缺口，未修

**逐面结论**

- **(c) 过程/工具内联图片（ProcessItemRenderer）——跳变成成立**。`extractImageRefs`（`api/tool-presentation/toolCardPresenter.ts:197`）只返回 URL 字符串数组；`<img className={styles.mdImg}>`（ProcessItemRenderer.tsx:163-172）无宽高属性；`.mdImg`（MessageContent.module.css:176-183）只有 `max-width: min(100%,420px) / max-height:280px / object-fit:contain` → 加载后撑高至多 280px 并顶动下方内容。

**登记（数据面缺口，含修复规格）**
