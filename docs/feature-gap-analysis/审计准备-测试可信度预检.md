## 结论速览

- **总体判断：F 轮测试整体质量偏高**，未发现系统性"空断言刷绿"或"跳过测试装完成"的作弊模式；
  大部分测试是真实执行（真实 SQLite、真实子进程、真实引擎执行器）加精确断言。
- **发现 1 条高严重度问题**：`crates/agent-tools/src/tools/subagent.rs:3162` 的测试会
  **真实执行 `git push --force origin main`**，且执行目录位于仓库内（mock 上下文 workspace_root =
  测试进程 current_dir），存在真实强推远端分支的隐患与网络依赖。
- **中严重度 12 条**集中在三类：真实时间 sleep 导致的时序敏感断言（timers/sched/escape_watch）、
  测试替身/探针"重实现被测逻辑"导致的同源镜像断言（DbSpawner/ProbePending）、以及"契约模拟分支"
  的静默降级（g02）。
- **可信度标杆**：conex-types cron/timer、watchdog、wait_channel、orchestrator kill_all、
  session-loop e01/g02、subagent_spawner DAG 端到端——这些是高质量样本，应作为后续轮次测试风格基线。

## 高严重度详述（须在复审阶段优先处置）

### H1：测试真实执行 `git push --force origin main`（`crates/agent-tools/src/tools/subagent.rs:3162-3182`）

- 链路：`ShellCommandTool.execute` → 门禁 `RequiresApproval`（与 shell.rs:1507 同命令同分类）
  → `ctx.ask`（`RecordingAskChannel::allowing()`，subagent.rs:1364-1368）返回 `Allowed` →
  继续执行（shell.rs:235-252 放行分支）→ `run_command_maybe_background` 以
  `workspace_root` 为 cwd 真实 spawn 子进程。
- `create_mock_tool_context()`（context.rs:177-190）的 `workspace_root = std::env::current_dir()`，
  `cargo test -p agent-tools` 运行时即 `crates/agent-tools/`——位于本 git 仓库内。
- 风险：若仓库配置了 origin 且存在 main 分支，测试可能真实触发强推；即使失败也是
  网络/认证依赖的非封闭测试；与并发跑的其他测试共享 git 锁。
- 测试注释自认"命令失败非致命，只断言审批记录"——本意是验证审批通道接线，命令执行是副作用。
- 处置建议：改用 `git push --dry-run origin main`（仍走审批形态但无写入），或注入临时
  workspace_root；断言语义不变。

## 总评：哪些可信度高、哪些需重点复审

### 可信度高（可作为测试风格基线）

1. **conex-types cron/timer**：全部固定偏移/固定时刻注入，边界完备（跨年/闰年/2 月 30 日/dow 0-7），
   公开入口仅做结构性冒烟——教科书级。
2. **watchdog**：注入时钟 + 纯 tick，零真实 sleep——timers/sched 应向此看齐。
3. **orchestrator kill_all / resume**：真实 SQLite + 真实调度器 + 真实协调器/预算池，
   幂等、过滤面、失败投递均有精确断言；测试内 spawner 仅为脚手架不镜像被测逻辑。
4. **agent-workbench subagent_spawner DAG 端到端**：生产实现 + 真实依赖，断言编排推进全链。
5. **wait_channel**：真实 EventStreamBroadcast + 真实 ControlBus，订阅同步用轮询护栏。
6. **e01/g02 集成**：真实引擎执行器链路 + 磁盘字节级断言 + 配额/互斥/幂等全覆盖。
7. **write_paths / replace / output_dir**：字节级断言、回滚不写盘断言、注入时钟与并发收敛断言。

### 需重点复审（建议列入复审轮清单）

1. **timers.rs 全套**（真实时间 sleep + 精确计数，含 1 条析取弱断言）。
2. **sched.rs**（fire_override 钩子 + ProbePending 同源替换语义）。
3. **agent-tools subagent.rs 的 DbSpawner 段落**（镜像实现，验收与生产解耦）+ **H1 危险命令**。
4. **escape_watch 集成段**（固定 sleep 抖动面 + targets 计数平台假设不一致）。
5. **g02 resolve_output_dir_contract 模拟分支**（静默降级应删除）。
6. **spawn_model Debug 字符串断言**（脆弱镜像）。
