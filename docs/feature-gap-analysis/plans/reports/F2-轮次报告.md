## 三、新发现

1. **（B1a）shell.rs:753 仍 Stdio::null()**：模式 2/3 真实路径暂不带 stdin，adopt 后 send_input 会得到 stdin_closed——需把模式 2/3 spawn 改为 Stdio::piped() 才接通（一行改动，agent-tools 域，登记 F3 或专项承接）。
2. **（B1a）Windows Read-Host 语义**：stdin 重定向时提示行不写进 stdout 管道（写往控制台宿主）；交互测试改为 adopt 后立即注入；Read-Host 会把输入行回显到 stdout。
3. **（B1a）PowerShell -Command 花括号解析怪癖**：含 {} 的脚本经 -Command 直传 ParserError；测试改用临时 .ps1 + -File spawn。
4. **（B1a）测试隔离修正**：test_registry 改为每测试独占日志目录（F1 时共享 task-<seq> 路径，落盘后并行测试互相污染）。
5. **（B1b）Windows taskkill 无 /F 行为不稳定**：时而报错、时而成功但进程存活——两情形优雅均不生效，实现正确升级（Err 跳过 5s 直接升级省时）；kill_graceful_path Windows 断言 via_force:true。
6. **（B1b）Child::wait() 移动所有权** → 改用 poll_exit（try_wait 轮询）；&JoinHandle 非 Future（Arc 共享不可 join）→ is_finished 轮询收口。
7. **（B1b）Unix 无 SIGKILL 升级原语**（优雅=强制=SIGTERM）：忽略 TERM 进程 kill 返回 Failed（平台限制，验收以 Windows 为基准）。
8. **（B2）KillResult 序列化形状裁决**：serde camelCase 不作用于 struct variant 内字段（external tagging + snake_case 实际形状）；主调度裁决保持现状（B3 已按实际形状适配），不追加 rename_all_fields。
9. **（B2）文件域冲突事件**：background_task.rs 曾被外部进程删除/还原（并行域 git 操作），已重新应用并二次验证。
10. **（B3）killed 状态映射缺口**：TaskState::Killed 不在 normalizeBackgroundTaskState 别名集 → 归一到 unknown、被 filterActiveBackgroundTasks 隐藏；B3 未改（解析层原样保留纪律），登记 F3 或后续补别名（killed→cancelled）。
11. **（B4）审计事件不落库**：BridgeAuditSink 走实时轨（sequence=None 广播），append_event 落库留 F12 端到端验收。
12. **（B4）core_run_commands.rs 并行域冲突**：接线在 15:28/15:30 两次被并行域整体重写覆盖（一次 GBK 乱码 317 行）；按纪律停止写该文件，产出补丁由主调度整合；主调度应用补丁时发现并行域附件改动（LFI/parse_attachment）已自行移走，文件最终干净；AgentEventEnvelope::new 需 event.clone()（&AgentEvent 入参）。
13. **（B4）run 起停钩子位置漂移**：core_run_task 结构在 F2 期间三变（双 ActiveRun 构造 → 预占 Arc 原地更新 → 单次构造+直接 spawn），补丁基于 15:30 版本；主调度整合时锚点核验一致。
