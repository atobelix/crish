## 三、新发现

1. **（A4）本地时区零依赖**：conex-types 不能加 chrono——Windows GetLocalTime FFI（unsafe 豁免评审先例）+ 非 Windows 回退 UTC；DST 窗口内不做小时级精修（文档明示）；next_fire_after_in_offset 供引擎按会话时区精修。
2. **（A4）dow 联合匹配 AND 语义**（Vixie OR 不同，文档显式标注）；40 年扫描窗口（2 月 30 恒 None、2 月 29 必有命中）。
3. **（A5）RunProducer 不可达**：produce 无 prompt 入参——DaemonRunLauncher trait 抽象（launch(prompt)->bool），A3 装配适配；None/false 降级 steering（防丢唤醒）。
4. **（A3）EventQueue 旁路点无单一实例**：wait 通道自持 EventStreamBroadcast（feed 同步旁路 + 满通道丢弃 + 超时兜底）；引擎暴露 terminal_stream() + last_wakeup()。
5. **（A3）ControlBus 可达性**：ActiveRun.control_bus 是 A8 域私有——inject 生产缺省 NoopControlBusResolver（InjectFailed 降级），真实 resolver 需 T-D-13 接线。
6. **（A3）tokio 陷阱**：timeout(_, JoinHandle) 三层 Result，测试三层 unwrap。
7. **（A8）RunProducer 每轮重建 loop**：无跨 produce 输入队列——续 run 落地为收口后复用 run_task_impl 装配新 run（注入消息=新 run 初始用户消息）。
8. **（A8）空闲期唤醒缺口**：无「入队即触发」机制——由活跃定时器/Cron 保持待命续 run + watchdog 兜底覆盖；登记。
9. **（A8）跨会话串扰风险**：PendingMessageQueue 条目无会话归属字段——续 run 转出注入当前收口会话，登记。
10. **（A7）「每引擎一个」vs「每会话一个」口径差异**：按任务书每引擎实现（session_id 空串占位），会话级 spawn 移交后续。
11. **（A9）trigger/update 偏差**：update 换调度=cancel+re-register（cron_id 可能变更）；trigger 手动次数不计入注册表 fired_count（列表以元数据为准）；sched_runs 为命令层近似真源。
12. **（A9）A8 域跨 Agent 解锁补丁**：core_run_commands.rs guard 跨 await Send 错误 1 处最小补丁，A8 重构同向后无残留。
13. **（多 Agent）normalize.rs CronFired arm 反复出现/回退**：A4 落盘→回退→A3/A6 临时补→A3 正式补回——轮末确认在场（编译对齐登记）。
