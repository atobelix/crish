3. **（D3-2）session_agents 主键**=(session_id, agent_id)：子代理每会话至多一行；fork spawn 必须产新 agent_id。
4. **（D3-2）fork_and_reassign 幂等判定先于预算判定**：同源重复 resume 返回既有记录不计数；预算耗尽仅「未 fork 过」时可达。

6. **（D3-3）共享 TestProvider 跨 run 并发序号交错**——测试基建按会话路由的 Provider 确定性解决。
7. **（D3-3）FlowScheduler 引擎侧回传缺失**：workbench 无 FlowScheduler 装配面，on_subagent_terminal 引擎侧调用点缺失——DAG 链路测试域契约等价覆盖，生产回传接线待 workflow 域。
8. **（D3-3）wait_channel inject 的 ControlBusResolver 仍 Noop**：活动 run 注册表跨模块不可达——子代理运行中注入（L1）未接线。
9. **（D3-3）批量路径 task_type 恒 None**（D3-1 冻结契约），装配按缺省 analysis（fail-closed）。
