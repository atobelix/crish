## 三、新发现

1. **（G-A1）本地时区零依赖**：kernel32 GetLocalTime/GetSystemTime 同刻差值（含夏令时，15 分钟取整消抖）——仓库首个 FFI 面（unsafe 豁免登记）；非 Windows 回退 UTC。
2. **（G-A1）只读信号复用**：explore_docs_quota.is_some() 即探索类（read-only）子代理契约——无需新增 engine 字段。
3. **（G-A1）OutputDirResolver 需 Debug 上界**（ToolContext 派生 Debug）——§4.4 草案外追加，对齐 ExploreDocsQuotaStore 先例。
4. **（G-A3）声明时效性**：写工具执行期临时声明随守卫 Drop 释放——等待完成时仅 run 期长声明存活；T-EG-13 集成测试需自行持有声明（与 e01 同款）。
5. **（G-A3）holder 身份映射**：引擎以 run id 作声明 holder，session_agents id≠subagent_run_id——真实链路需 F11 spawn 接线统一。
6. **（G-A5）session_meta 键残留**：独立 KV 表无 FK，会话删除后 meta 键残留——清理链已消费，无害。
7. **（G-A5）manifest 镜像**：前端 79 vs Rust 91 的漂移在 F10 内已同步至 84/88（G-A5 3 条 + F10 主调度 3 条 outputs 命令）；后续新命令仍需双端手工同步。
8. **（G-A6）冲突窗口语义**：写工具执行期声明 + overwrite 保护双层分层（M2 语义）；run 全程持有声明需改 claim 语义（超范围）。
9. **（主调度）引擎装配缺口**：G-A1 的 resolver 在 tool_exec.rs 为 None 占位——轮末最小装配（with_options 自动装配 InMemory OutputWorkspace）使 G02 真实工具分支激活；生产 session_meta 持久化后端归 F11。
