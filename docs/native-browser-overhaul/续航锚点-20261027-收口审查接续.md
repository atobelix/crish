## 二、关键裁决与文档对照记录（接续者必读）

1. **03-分维 §3.4 Ephemeral 布局 = `browser-storage/ephemeral-[id]` 子目录**——native_commands 的实现符合设计，**偏离设计的是 security.rs 旧 Ephemeral 臂**（已删）。GC 与清理一律针对 `browser-storage/ephemeral-*` glob。
2. **03-分维 §7.3 file: 双规则**：① 公网上下文 100% 阻断（现由 None-root 缺省拒绝满足）；② "地址栏手动输入 / 文件管理器唤起"的合法入口需要 workspace_root——机制已接线（`CreateWebviewArgs.workspaceRoot` → `ManagedWebview.workspace_root` → `on_navigation` 门禁 + `navigate()` 校验），前端 UI 尚未传参（传 None = 安全全禁）。后续做本地文件预览 UI 时只需在 `NativeBrowserSurface` 传入 workspace root，**禁止绕过该门禁另开通道**。
3. **TokenGuard 不做成 Drop 的设计理由**（写进 native_tokens.rs 头注释）：COM 接口注销必须在创建它的 STA 主线程执行，Drop 的执行线程不可控，RAII 守卫在该场景是错误抽象。
4. **Audit 06 自相矛盾问题**：总裁决"无条件签字交付"与其自身缺陷矩阵（DEF-05-01/02/07 未闭环）冲突，且部分描述已过时（`workbench_set_browser_hit_test` 已清零、`browserWebviewClose` 现有 3 处生产调用点：`DockSplitWorkspace.tsx:156,268` + `teardownDockTree`）。A2b 处理时以代码现状为准修正文档。
5. **审查期间并行 Agent 曾修复**：session-loop 编译错误（thiserror/as_str）、conex-run 编译错误、前端 SessionContextMenu 类型错误——均自愈。任何"编译失败"结论必须重跑确认。
