## 交叉引用

- **03-P9**：旁路背压完备（fanout/push 有界队列）——本方向再确认并指出 push 解析成本独立存在
- **03-R1/R2**：token 逐条 emit 放大 fanout/push 解析次数（XOV01 叠乘）
- **07 启动**：TLS 材料生成在服务开启/重绑路径，不在窗口 setup 主路径
- **16 可观测性**：`dropped_total` / `pending_len` 可纳入指标面；cleanup_logs 接线与稳定性闭环文档已交叉
- **10 工具执行**：无关；本方向不触碰 agent-tools
