### 1.2 可并行化点（静态分析）

1. **WorkspaceRegistry::init / TokenStore::load / AuthManager** 可与双 DB open 并行（当前在 block_on(db) 之后串行）。
2. **CoreRunState::new 内 EngineHandle::build** 的工具注册、BrowserSlot/ComputerSlot 构造若延迟到首次 run / 首次命令，可缩短 setup 返回时间；当前全量前置。
