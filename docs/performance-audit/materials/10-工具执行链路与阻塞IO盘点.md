## 1. 执行链路全景

```
LLM tool-calls
  → executing_tools::handle (loop/handlers/executing_tools.rs)
  → ToolExecutor::execute_batch (exec_batch.rs)
      → BatchPlanner::plan（Parallel 组先、Sequential 各单元素组后）
      → BatchRunner::run / run_single | run_parallel
          → execute_single_with_retry → execute_single (exec_single.rs)
              → middleware before → tool.pre hook
              → race_execution (timeout + abort select)
                  → execute_stream_with_output_policy (agent-tools/executor_run.rs)
                      → Tool::execute_stream（默认 = execute 包 Terminal）
              → middleware on_result / on_error + tool.post
  → emit_tool_events（批收口一次性广播）
  → record_message(tool role) × N
```

## 4. 输出路径 clone 链（单次成功工具）

1. tool.execute → Value
2. summarize 可能 clone/重组（未截断时 `value.clone()`：output.rs:196）

7. tool_result_message → tool_output_from_result 再 clone（executing_tools.rs:153-208）
8. 上桥/IPC/DB（03 报告 C1）

## 5. 事件时序

- 并行组：先全部 ToolStart（exec_batch.rs:313-327）→ 审批链 → join_all → 按组序 ToolEnd。
- **全部事件仅在 execute_batch 返回后**经 `emit_tool_events` 发出（executing_tools.rs:98）。
- 契约注明批收口广播（tool_events / EV-09）；前端 toolHandlers 收到时工具已全部结束（无执行中卡片实时更新）。
- Progress：`race_execution` 传 `None`（exec_single.rs:546,556）→ shell execute_stream 构造的 ToolProgress 被丢弃。

## 6. 并发

- 并行组 Semaphore(max_parallel) FIFO 排队（exec_batch.rs:431-527）。
- 每任务 clone：call（含 input Value）、ctx、options、approval Arc。
- MCP 并发 tools/call：stdin Mutex 串行写；响应经 id→oneshot pending 表并发配对。
