```text
D0 预算 SSOT
  → D2 ∥ D1 减载（NoPersist 必须先于 D3 组提交；真缓冲 flush ≠ PE-02 合并）
      → D3 写单轨
          → D4 persist 出口切除（票A可与 D3 并行部分见 §6；dirty+CAS 必须后于 D3）

                      → D7 渲染 / D8 终端 Diff
  D9 门禁 fail 骨架可与 D0 后尽早（防修复期体积漂移不可见）
```

**禁止顺序反例：**

1. 未 NoPersist 跳取号 → 不得宣称组提交完成（否则事务包白付取号）。

3. 未删 `conn.lock` 写旁路 → 不得只加 debounce 冒充 DB 修复。  
4. 未 PE-02 通过 → 禁止 token N 合 1；**允许**改 flush 时机（真缓冲）。  
5. 未会签 Progress → 禁止静默删构造；也禁止假接线传 `None`。  
6. memo 前必须先收窄注入面（禁伪 memo）。  
7. motion 删除前必须 bundle/import 复核（06-P12）。
