## 二、执行纪律

1. **一次一个方向**：每轮只做一个方向的全面检查，完成后更新本文件状态并产出对应编号报告，再进入下一方向。
2. **效果锁**：每方向的检查覆盖面以本清单「范围」栏为准，不自行降级缩减；发现范围外问题记入对应方向待检清单，不丢弃。
3. **证据链**：每条问题必须带 `文件路径:行号` 证据与代码摘录；严重度分级（高/中/低）必须给判定理由。
4. **不谈工期**：报告只谈逻辑问题与修复路径，不做工作量估算与人员安排。
5. **产出位置**：方向报告 `NN-<方向名>审查报告.md` 放本目录根；原始素材（agent 汇总、扫描输出）放 `materials/` 子文件夹（仅一级）。
6. **运行时验证缺口**：静态审查无法覆盖的项（如真实帧率、内存曲线）单列「运行时验证建议」小节，不冒充已验证结论。
