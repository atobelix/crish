## 1. 范围界定（二期 MVP）

### 1.1 首发范围（Windows 首发双通道）

| 面 | 一期（MVP，Windows） | 依据 |
|---|---|---|
| 截屏 | `xcap`（DXGI Desktop Duplication / Windows Graphics Capture 首选，GDI `BitBlt` 回退）；多显示器逐屏捕获 + 缩放信息 + 布局表；缩放后 PNG 输出 | 18 §3.1 |
| 输入 | `enigo`（底层即 SendInput）为主实现；Unicode 直送（`KEYEVENTF_UNICODE`）与滚轮 delta 等用 `windows` crate 直连 SendInput 补足 | 18 §2.2 |
| 感知 | **UIA（UI Automation）结构化辅助为必选降级通道**（与截屏双通道并存：结构化为主、截屏回显/兜底）——开放问题 5 裁决立项 | 18 §3.3、22 §8.2 |
| 形态 | 独立模块（建议 crate：`conex-desktop`），与浏览器线共享面板/执行框架/安全门槛/审计，与浏览器会话互斥 | 18 §1、08 §3.10 |
| 动作面 | 17 个动作全量对齐 computer.py 三版（20241022 基础集 10 + 20250124 扩展 6 + 20251124 zoom 1），统一挂 `computer_*` 工具族 | 18 §2.1 |
| 启用门槛 | 会话级显式开启 + 全动作审批 + 三级急停 + 与浏览器会话互斥 | 08 §3.10 |

### 1.2 明确不做（一期边界）与理由

| 不做项 | 理由 |
|---|---|
| **macOS / Linux 首发** | 一期平台面仅 Windows：UIA/enigo/SendInput 均有既有实证基础与 `windows` crate 完整 COM 面；`InputBackend`/`PerceptionSource` trait 面按 18 §2.2 平台映射表抽象，macOS（CGEvent/AXUIElement）与 Linux（XTest/ydotool/AT-SPI）留作二期扩展，不在一期摊开三平台（平台差异隔离在实现内，接口面零差异） |
| **隔离桌面（虚拟机/沙箱桌面）** | 与 08 §1.2 复杂度红线一致（常规方案复杂度 3 倍以上弃用）：虚拟化桌面引入会话隔离/输入重定向/显示通道三套独立机制，复杂度远超 3 倍；替代 = 真实桌面 + 全量安全门槛兜底（显式开启/全动作审批/三级急停/空闲挂起/白名单窗口，§4），效果等价且可控 |
| **视觉主控模式** | 成本硬约束（18 §3.3 理由 2）：vision 有 token 成本、cache 白名单只缓存 text 块，长会话全截屏感知成本不可接受；UIA 结构化快照廉价、可缓存、无多模态开销，且 UIA 元素边界矩形坐标精度高于视觉模型像素估算（理由 3）。视觉仅作回显/兜底（降级矩阵 §3.3 项 8） |

### 1.3 与浏览器线关系（D-10）

- **共享**：面板帧渲染、指示条/接管、输入归一化管线、工具执行框架、安全门槛/审计（核对结论见 §3）。
- **互斥**：与浏览器会话不可同时活跃（`ActivationGate`，§2 S3）；切换仅用户显式操作，AI 无切换能力。
- **落地窗口**：P2（08 §4，R-13 §8.2 第 3 层），前置浏览器线 P1 完成（指示条/接管、帧渲染组件为复用对象）；本文档为实施轮直接派单依据。

### S1 动作原语（OsInputBackend + 键名归一化）

**输入**：S0-3 实证结论；18 §2.1/§2.2/§2.3/§2.4。
**任务单元**（文件域：`conex-shared` 定义 trait，`conex-desktop/src/input/`）：

1. `InputBackend` trait 定稿（对齐 18 §10 签名：`mouse_move/click/button/drag/scroll/type_text/key/cursor_position`，坐标一律 `PhysicalPoint`）。
2. `OsInputBackend`（Windows 实现）：`enigo` 主实现 + `windows` crate 直连 SendInput 补 Unicode/滚轮 delta；双击/三击由后端生成间隔（≤系统双击时间）；按下/抬起分离；拖拽 = 起点 DOWN → 分步移动 → 终点 UP。
3. `KeyNameRegistry`：`ctrl/alt/shift/win/a-z/0-9/F1-F24/enter/...` 映射表（Windows VK 表一期，接口三平台可扩展）；组合键数组语义（不做字符串解析）。
4. 输入节奏：`TYPING_GROUP_SIZE=50`、`TYPING_DELAY_MS=12`（Windows 可配 12-30ms）；每块写入前自查 `abort_token`；`duration ≤100s` 硬约束。
5. 光标位置查询 `GetCursorPos`（物理坐标输出）。

**验收断言**：`InputBackend` 单测（键名解析/分块切分纯函数）+ 记事本注入 smoke e2e（S1 末）+ 既有 `InputPipeline` 单测不回退。

### S2 坐标换算与感知（ScaleCoordinator + 截屏源 + UIA 源）

**输入**：S0-1/S0-2 结论；18 §3/§4。
**任务单元**：

1. `ScaleCoordinator`（纯函数，`conex-shared`）：缩放目标选择（XGA/WXGA/FWXGA，`abs(ratio_diff)<0.02` + 目标宽 < 物理宽 + 有序优先；未命中不缩放，强制缩放为配置项）；API↔物理双向换算（独立 X/Y 因子）；往返一致性约束（≤1px）。
2. 布局表：`Monitors[] { id,x,y,w,h,dpi_scale,image_w,image_h }`，虚拟桌面左上角为原点（负坐标）；启动置 `SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`；注入全物理像素，面板回显走逻辑像素换算。
3. 校验链：API 空间边界 → 越界返回 `tool.computer.coords_out_of_bounds`；物理空间回检钳制；光标回检（|Δ|>容差告警审计）。
4. `DesktopCaptureSource`（`FrameSource` 桌面实现，`conex-desktop/src/capture/`）：xcap 捕获 → 缩放 → PNG/JPEG（quality 档）→ `FrameOut` 语义输出；事件驱动 + 可选 2-5fps 轮询档；隐私感知暂停（UIA 密码控件聚焦时暂停截屏）。
5. `PerceptionSource`（UIA 实现，`conex-desktop/src/uia/`）：树遍历 → 紧凑序列化（元素/角色/名称/边界矩形/索引）→ **数据面抑制**（PasswordBox/IsPassword 不读文本、占位符 `<password>`、名称/值过键名模式脱敏）；`ElementFromPoint` 命中测试；能力探测输出 `DesktopCapabilities`。

**验收断言**：缩放算法单测 4 类用例（4:3/16:10/16:9/超宽屏）+ DPI/多显示器双向换算往返单测 + UIA 序列化脱敏单测全绿。

### S3 会话互斥（ActivationGate）

**输入**：18 §6。
**任务单元**（文件域：`conex-desktop/src/session/` + agent-tools executor 层守卫接线）：

1. 状态机：`enum SessionMode { Idle, Browser, Desktop }` + 全转换表（Idle→Browser/Desktop、Browser↔Desktop 需用户确认、任态→Idle 清理）。
2. 切换清理清单（阻塞完成）：① Browser→Desktop 停 screencast → 吊销浏览器 AI 令牌 → 浏览器快照版本作废 → 浏览器工具面拒绝态 → 启动桌面截屏源 + UIA 会话；② Desktop→Browser 逆序（停轮询/销毁 UIA 订阅/吊销桌面令牌/恢复 screencast）。
3. 工具面互斥守卫：挂 agent-tools executor 层，`browser_*` 非 Browser 态返回 `tool.session.exclusive`，`computer_*` 非 Desktop 态同理；守卫检查点在审批**之前**。
4. 状态广播：`ActivationGate` 变更 → 事件总线 → 面板指示条（当前模式）+ 工具执行器守卫。
5. 接管语义对齐 U-9：接管后稳定窗 800ms 后 AI 可重试获取令牌（引用浏览器线 `TOKEN_MIN_STABLE_WINDOW` 常量）。

**验收断言**：状态机全转换表单测 + 双向切换清理断言（screencast 停/令牌吊销/版本作废无残留）+ 互斥守卫工具级测试。

### S4 安全门槛（§4 全量落地）

**输入**：18 §7；本文档 §4。
**任务单元**（文件域：`conex-desktop/src/security/`）：

1. 会话级显式开启：`session_meta` 落盘 `computer_use_enabled=true`（新会话默认关闭；持久化范式对齐 `conex-types/src/timer.rs:43` 的 `session_meta` 键约定，开关范式对齐 `BrowserToolsConfig.mcp_attach_allowed`，`conex-browser-tools/src/lib.rs:124`）。
2. 全动作审批接线：17 动作全 `dangerous=true` → 既有 `ctx.ask`/`AskChannel` 审批面（`agent-tools/src/context.rs:68`）；默认拒绝型（type/key/hold_key/scroll 大 amount/click 系列）；纯感知类可配会话内免审（默认也审批）；审批载荷 = 动作 + 参数摘要 + 目标窗口标题 + 物理坐标；`type` 明文显示。
3. 三级急停：全局（复用既有 AbortToken）+ 热键（`RegisterHotKey` 默认 `Ctrl+Shift+F12`，注册冲突检测 + 失败降级面板按钮）+ 面板常驻按钮；急停 → `abort_token.abort()` → 在途注入批次自查 → 感知源停止 → 回 Idle。
4. 空闲挂起：无 AI 动作/无审批超时默认 120s → 自动挂起回 Idle；恢复需重新显式开启。
5. 审计脱敏：desktop 扩展字段（动作/坐标/窗口标题/时间戳/审批结论/急停事件）；`type` 只记 `sha256(text)`+长度；UIA 字段只记类型/角色/索引/边界矩形；截屏不入审计库（记感知版本号/图像哈希）。
6. 白名单窗口（可选默认关）：标题/进程匹配；非白名单动作在审批阶段拦截（复用动作前检查点）。
7. 误操作兜底：动作前后回显（注入后自动截屏回显面板）；物理输入即抢占令牌（桌面线天然一致）。

**验收断言**：§5 验收项 5/6/7 对应测试全绿 + 空闲挂起计时单测。

## 3. 共享层复用清单核验（逐项签名核对结论）

> 核对基准：18 §5 清单 9 项 + §10 trait 签名 vs 仓库现状（`crates/` 与前端代码）。结论三档：**复用成立**（签名存在，零改造）/ **需抽象**（同名 trait 不存在，需抽接口，语义对等点已定位）/ **接口抽取**（框架存在但需抽通用接口）。

| # | 共享组件 | 18 §10/§5 预期 | 仓库现状（证据） | 结论 |
|---|---|---|---|---|
| 1 | 面板帧渲染 | `FrameSource { next_frame, request_sync_frame, set_frame_policy }` | **无同名 trait**。对等点：`ScreencastSession`（`conex-browser/src/frames/session.rs:255` new / `:314` start / `:344` stop / `:396` subscribe_frames / `:416` set_fps_level）、`FrameReceiver::recv`（`frames/sink.rs:118`）、`FrameOut { seq,width,height,data }`（`sink.rs:22`）、`FrameSink` 背压丢帧（`sink.rs:58`）、`FrameChunk`（`cdp/bus.rs:108`）、`FpsLevel`（`frames/fps.rs`） | **需抽象**：现为 CDP 专用会话形态；S6 抽 `FrameSource` trait，`CdpScreencastSource` vs `DesktopCaptureSource` 双实现 |

## 4. 安全门槛细则

> 依据：18 §7 全量 + 08 §3.10（启用门槛：会话级显式开启 + 全动作审批 + 全局急停 + 与浏览器会话互斥）。

### 4.1 会话级显式开启

1. 用户点击「启用电脑操作」→ 风险确认对话框（说明：可注入本机全部输入/截屏、动作逐次审批、急停方式）。
2. 确认后 `session_meta` 落盘 `computer_use_enabled=true`（会话级持久化；**新会话默认关闭**；持久化键约定对齐 `conex-types/src/timer.rs:43` 的 session_meta 机制）。
3. 注册面按标记挂载 `computer_*` 工具族——**未开启时工具不存在，模型侧 tool schema 亦不含**（S5 断言）。
4. 开启后首次动作前一次性提示（操作可见性说明）。

### 4.2 全动作审批

- 17 动作全 `ToolDefinition.dangerous=true` → 既有 `ctx.ask`/`AskChannel` 审批面（`agent-tools/src/context.rs:68/106`，与 browser 交互类工具接线一致）。
- **默认拒绝型**：`type`（文本）、`key`/`hold_key`（快捷键）、`scroll`（大 amount）、`click` 系列——审批弹窗默认焦点在「拒绝」；`screenshot`/`cursor_position`/`wait`（纯感知）可配置会话内免审（默认也审批）。
- 审批载荷：动作名 + 参数摘要 + 目标窗口标题 + 坐标（物理值）；`type` 明文显示供用户确认。
- 审批等待期支持 `abort_token` 取消（复用既有）；拒绝时零注入（审批通过前不触碰输入设备）。
- 会话内一键放行（可选）：仅限感知类动作集；交互类**永不**整会话放行。

### 4.3 三级急停

| 级 | 触发 | 实现 |
|---|---|---|
| ① 全局急停 | 既有全局急停设施 | `AbortToken::abort()`（幂等，`context.rs:44`） |
| ② 桌面热键 | `RegisterHotKey` 默认 `Ctrl+Shift+F12`（可配） | 注册冲突检测；注册失败弹提示并降级仅面板按钮，不静默 |
| ③ 面板按钮 | 常驻显眼位置 | 面板急停按钮 → 同一吊销链 |

急停语义：`abort()` → 在途注入按批次自查（type 分块间/拖拽分步间，S1）→ 感知源停止 → 会话回 Idle（S3）；急停全局生效不区分会话。

### 4.4 空闲挂起

- 桌面会话无 AI 动作/无审批超时（默认 120s，可配）→ 自动挂起回 Idle（不等用户手动）；恢复需重新显式开启（4.1）。

### 4.5 密码框 UIA 抑制（数据面抑制，22 §3 落点）

- UIA 树序列化：`PasswordBox` 控件类型 / `IsPassword=true` 元素——**跳过文本内容**（ValuePattern/Name 不输出实际字符）；输出占位符 `<password>`（长度可记、内容不记）。
- 名称/值字段脱敏：元素 `Name`/`Value` 过键名模式（password/passwd/pwd/secret/token 等命中 → `<redacted>`）；`IsPassword` 为判定优先信号。
- 联动：① 密码框聚焦时**暂停截屏**（凭据不入图）；② 审计不落 UIA 密码字段；③ `ElementFromPoint` 命中密码框时文本同样不回传。

### 4.6 与浏览器会话互斥

- `ActivationGate` 状态机（Idle/Browser/Desktop）+ 切换需用户确认 + 切换清理清单阻塞完成（S3）；工具面互斥守卫（`tool.session.exclusive`）在审批**之前**检查；急停强制回 Idle。

### 4.7 审计脱敏（§3 项 5 扩展）

- 审计字段：动作、坐标（API 空间值）、目标窗口标题、时间戳、审批结论、急停事件；`type` 只记 `sha256(text)` + 长度；UIA 元素不落 Name/Value 原文（只记类型/角色/索引/边界矩形）；密码框元素任何字段不落；截屏不进审计库（记感知版本号/图像哈希）。
