# 软件内 AI 协同浏览器 —— 方案敲定文档（Decision Record）

> 本文件为决策记录：每个决策点的敲定结论、否决项与理由、待验证项。
> 输入：4 份候选方案（01-04）+ 3 份评审裁决（05-07）；输出：最终总文档（08）与各维度文档（10-18）。

---

## 1. 决策点清单（敲定）

| # | 决策点 | 敲定 | 否决项 | 敲定理由 |
|---|---|---|---|---|
| D-1 | 渲染实例 | 受管独立 Chromium 进程（CfT 优先，系统 Chrome/Edge 回退） | 内嵌 WebView2；iframe 改造；CEF | WebView2 数据导入不互通（profile 格式不兼容）+ CDP 受限子集无 SLA；iframe 跨域隔离铁律；CEF 复杂度 3 倍+ 红线 |
| D-2 | 用户可见方案 | CDP screencast 帧流渲染进 React 面板 + 面板输入转发 | 独立窗口直操；截图轮询 | 独立窗口直操时用户输入绕过 CDP 控制面，协同同屏断裂；截图轮询延迟与资源不可接受 |
| D-3 | 控制通道 | CDP 单通道（loopback 随机端口 + token） | 注入脚本桥为主通道；双轨 | 注入桥合成事件 isTrusted=false、跨平台维护面 3 倍陷阱；CDP 提供真实输入与完整事件面 |
| D-4 | CDP 客户端 | 自研薄客户端（长连接 + 事件总线），命令全过统一发送层 | 外部重型客户端 | 全命令经自研发送层才能零死角挂载审计/审批/急停；依赖上游库存在维护与握手风险 |
| D-5 | 感知快照 | DOM 简化树为主 + AX 辅助 + 截图按需；backendNodeId 直作索引 | AX 主通道；视觉主通道 | DOM 主覆盖无 a11y 语义的交互元素（div 点击器），定位链最短；当前模型无视觉能力，视觉留待升级 |
| D-6 | 协同模型 | 软互斥令牌 + abort 抢断 + snapshotVersion 失效 + 指示条/接管，四合一 | 纯 busy 互斥；纯版本号 | 纯 busy 无在途取消；纯版本号无实时中止；四合一覆盖用户接管、AI 中止、页面失效全场景 |
| D-7 | 数据导入 | 面板内引导登录（主）+ 最小文件集 profile 复制（迁移）+ storage_state 辅助；密码/历史显式排除 | 整目录复制；storage_state 主路径 | 整目录复制隐私面大且触碰密码库；storage_state 覆盖不全且易明文落盘；引导登录零解密零隐私面 |
| D-8 | 工具集 | browser_* 工具族挂 agent-tools 注册面；外部 MCP 经桥 attach 同一端点补深 | 仅自研；仅外部 MCP | 自研保证核心闭环；MCP 并存获得生态深工具（调试/性能）且零适配 |
| D-9 | 安全 | 随机端口 + DevToolsActivePort + token + 域名门禁（含 IP 阻断）+ 分级审批 + 脱敏审计 + 急停 | 固定端口；无 token | 对齐安全基线网络监听要求；token 防本机探测；IP 阻断防 SSRF |
| D-10 | 电脑操作二期 | 独立模块立项，共享面板/执行框架/安全门槛，与浏览器会话互斥 | 一期并入；不做 | 一期聚焦浏览器闭环；二期共享层复用控制总成本；互斥防双重注入 |

## 2. 专项裁决（评审争议点）

| 争议点 | 裁决 |
|---|---|
| 用户输入可见性 | 面板输入转发（用户事件经 CDP Input 注入）是协同闭环的**必要条件**；独立窗口直操使 AI 无法感知用户操作，令牌机制失效——裁决：面板转发 |
| profile 复制 vs App-Bound 加密 | 高版本浏览器 cookie 加密绑定家族（App-Bound）：复制可尝试，但必须回读校验；失败引导"面板内登录"。同家族（Chrome→Chrome 系）约束写入导入向导 |
| storage_state 明文面 | 默认不落盘（内存传递），导出需显式授权 |
| evaluate 策略 | 受限白名单 + 审批；默认拒绝敏感面 |
| 快照失效机制 | snapshotVersion 内置进事件总线与快照，动作前校验——实施顺序 S1 即内建，非后补 |
| 外部 MCP 与自研并存 | 命名空间隔离（browser_ vs mcp_<server>__*），权限各自独立，互不覆盖 |

## 3. P0 验证清单（S0 spike 必须产出结论）

| # | 验证项 | 通过标准 |
|---|---|---|
| P0-1 | CDP Input 域能力实测（dispatchMouseEvent/dispatchKeyEvent 注入可信事件） | 注入后页面收到 isTrusted=true 事件 |
| P0-2 | screencast 帧延迟（本地 loopback，8-15fps 配置） | 端到端均值 ≤120ms |
| P0-3 | 随机端口 + DevToolsActivePort 解析闭环 | 启动即读端口/WS 路径，失败可重试 |
| P0-4 | profile 最小文件集复制 + 回读校验（含高版本 App-Bound 实证） | 回读结论落盘：可读/需同家族/需引导登录 |
| P0-5 | CfT 可用性（下载/启动/版本匹配）与系统浏览器回退 | 两条路径均启动成功 |
| P0-6 | 崩溃重启（导航栈保留） | 杀进程后自动拉起并恢复 URL |

## 4. 开放问题（进入维度文档时裁决）

1. 快照序列化的预算参数（最大层级/元素数/文本长度）——维度 13 定。
2. 面板输入转发的 IME/合成事件覆盖策略（中文输入法场景）——维度 12 定。
3. 域名白名单默认策略（空=全允许还是默认本机）——维度 17 定。
4. 多标签页数量上限与快照预算分摊——维度 15 定。
5. 电脑操作二期的结构化辅助（无障碍 API）是否立项——维度 18 定。

## 5. 复杂度与边界声明

- 全链路复杂度评级：主链路 1-2 倍（S0 验证后收敛），无 3 倍+ 项。
- 明确不做：内嵌 WebView2 渲染、注入脚本主通道、CEF 家族、整目录 profile 复制、密码导入、storage_state 默认落盘、一期并入电脑操作。
