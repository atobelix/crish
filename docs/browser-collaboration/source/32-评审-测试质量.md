# 32 评审 · 测试质量与防回归（E4）

- 评审范围：conex-browser（src 全模块单测 + tests/e2e_browser.rs + tests/snapshot_samples.rs）、conex-browser-tools（单测 + registration/contract/success_paths 集成）、agent-workbench src-tauri/src/browser 单测、crish-desktop workspace 前端测试
- 评审方式：只读，实读测试代码与被测代码；对照 A3 已加固的 `job_kill_tree_terminates` 模式（browser/platform/windows.rs:300）
- 评审日期：2026-08-09

## 总评

测试体系的**存量质量与回归价值总体优秀**：状态机穷举（独立规格镜像）、动作管线零副作用断言、错误策略表穷举、fixture 驱动快照检出、订阅时序回归（恢复期事件/JoinHandle/CancellationToken）均达"行为级 + 防退化"水准，需求→用例命名可追溯（E2E-N/T-N/R-N/验收 9.1-N/§N 全链引用）。

但存在**两个阻塞级平台/门禁衔接问题**（详见 P1-1/P1-2），以及若干覆盖缺口（错误映射全表、总线转译表、发现回退链）与 flaky 隐患（sleep 式等待、真实进程时序）。
