**丢点（两处合成，缺一不可）**：

1. **合成项无 startTime**：`MessageContent.tsx` 的 `linearItems` 在流式中且最后工具块之后尚无 text 项时，合成流式尾正文项 `tailTextItem`（`kind:'text', key:'text-N', isFinal:true`），**不带 startTime 字段**。该项先于分段记账块挂载（流式快缓冲 `streamText` 先于 `msg.blocks` 更新），常以空容器形态出现（`sliceActiveStreamText` 剥离已封口段后余文为空时）。
2. **钩子一次判定**：`useEntranceReveal` 以 `decidedKeyRef` 每键只判定一次；挂载时 `eventTs===undefined` → `decideEntrance` 必拒绝；落块后同键块项（`text-N`，块自带 `startTime`）复用同一 DOM 节点，钩子永不重判。首段例外：其块在流式首帧前已由 `applyStreamedTextToBlocks` 建块（`startTime: now`），故挂载即带戳、fade 触发。

对照：`buildAssistantTimeline` 中 thought 块有 `b.startTime ?? msg.timestamp` 兜底，text 块只透传 `b.startTime`；`applyStreamedTextToBlocks` 的 `createSegment` 建块即带 `startTime: now`——块层本身不丢，丢在“块落地之前先挂载的合成尾项”。
