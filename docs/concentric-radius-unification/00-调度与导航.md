# 全仓同心圆角与边距现状统一调查战役 — 调度与导航

> **战役代号**：CONCENTRIC-RADIUS-UNIFICATION  
> **启动日期**：2026-10-25  
> **核心原则**：
> 1. **全仓圆角与边距立体勘察**：全面摸清全仓弹层（Pop/Dialog/Modal）、设置界面（Settings）、输入区（Composer）、侧边栏（Sidebar）及消息卡片的圆角与内边距现状；
> 2. **同心几何标尺（Concentric Geometry）**：严格以 $R_{outer} = R_{inner} + Padding$ 为真理标准（以内外圆弧处处平行同心为目标，如 `SetupHintBanner` 的 18px = 8px + 10px 范式），调查记录所有内外容器的嵌套几何关系；
> 3. **反退避与架构优雅**：不打修补式魔术补丁，穿透到 Design Token 与父子容器布局契约，为下一步统一治理提供确凿证据与数学模型。

## 二、 纪律与操作守则

1. **单文档配额**：各调查子 Agent 严格执行 1 份调查报告配额，不得散落创建零星碎文件；
2. **纯只读探索**：调研阶段子 Agent 仅读取代码、分析样式并输出报告，**严禁修改任何代码与执行 git 操作**；
3. **数据证据链**：必须详细列出 `文件路径:行号`、当前 CSS 声明、计算出的像素值（px）、内外容器内边距（padding）、以及同心差值 $\Delta = R_o - (R_i + P)$。
