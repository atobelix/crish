# 全仓同心圆角与微圆双形态统一改造总方案（CONCENTRIC-RADIUS-UNIFICATION）

> **方案状态**：评审全票通过（VERDICT: APPROVED）· 准入进入执行波次  
> **双形态定义**：
> - **圆角形态（Rounded Mode，20px 枢纽）**：专供顶级悬浮大模态（Dialog / Settings / ProjectManageModal）、底部 ChatComposer、ChatBubble 与 SetupHintBanner，消除顶层弹窗比底层输入框更方的空间倒挂；
> - **微圆形态（Compact Mode，14px / 16px 枢纽）**：专供二级级联浮层、小下拉菜单（14px 外壳）、设置表单卡片（16px 外壳）、会话列表项（8px 外壳）、内部标准控件（8px 输入框 / 6px 小项 / 7px 实体按钮），满足桌面高密度生产力诉求。
> **同心公理**：$$R_{outer} = R_{inner} + Padding \quad \Longleftrightarrow \quad R_{inner} = \max(0, R_{outer} - Padding)$$
> 一个容器内所有嵌套元素必须严格符合同心公式，处处平行同心，绝不允许外小内大或同径挤压！
