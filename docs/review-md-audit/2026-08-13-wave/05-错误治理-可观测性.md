## 总判：🟡 黄

错误治理与可观测性基建整体在轨：吞错有双基线门禁（Rust `let _=` 50 处 / 前端空 catch 余 1 处）、前端有顶层 Error Boundary 且错误经 errorStore→telemetry 上报、Rust 有结构化 tracing（含 session_id/run_id span）与 panic hook、Tauri 侧有 `core_get_status` 健康状态命令。**主要缺口**：跨 IPC/Agent 分布式追踪完全缺失；性能指标埋点薄弱（慢序列化/长锁等待无耗时指标）；session 持久化批写在 SQLite probe 失败时整批 Fail-Open 降级 localStorage（有日志但数据面分叉风险仍在）。

## §6 错误与异常治理

### 1. 空 catch 吞噬 —— 🟢 绿（有基线收敛，点名余量）

- 前端门禁口径余 **1 处**：`apps/crish-desktop/src/bootstrap-full.ts:8` `.catch(() => {})` 未注解空 catch（`ensureEngineConnected` 失败静默），与 `frontend-swallowed-errors-baseline.md:55` 标记区一致（03-D2 域留待，基线内放行）。
- 已知有意吞且有注释：`packages/block-paper/src/chrome/SlashMenuModel.ts:205-213` `emit()` 中 `catch { /* 监听方异常不打断 model */ }`——与主控说明一致，可接受。
- `apps/crish-desktop/src/bootstrap-full.ts:20` `catch { /* 主题读取失败时保持默认主题 */ }` 有注释，阶段 A 注解豁免。
- Rust 侧 `let _ =` 主导模式为 **hook 回调结果丢弃**（fail-closed 扩展面）：`crates/session-loop/src/tool_exec.rs:1113/1173/1232/1244`、`loop/mod.rs:810/868/982/1052`、`loop/handlers/mod.rs:587/821` 等 `let _ = hooks...`；`hooks.rs:698` `let _ = Box::pin(self.dispatch_inner(&error_event, false)).await`。均属「已分类错误后的扩展通知」路径，与 `swallowed-errors-baseline.md`（session-loop 17 处）口径一致。
- `crates/session-loop/src/hydrate.rs:125` `Ok(_) => {}`、`cache_tracker.rs:379` `let _ = now_ms` 为命名/形状占位，非热路径吞错。
- 结论：无**新增**未登记吞错；余量全部在基线内。未真跑 lint/门禁脚本验证计数，依据为标记区 + 源码 grep 形状。

### 2. Fail-Open 降级分叉 —— 🟡 黄（有日志无强感知，数据面分叉风险在）

- **session 持久化批写降级**：`apps/crish-desktop/src/api/session-persistence/sessionRustDb.ts:1367-1379` — `list_sessions` probe 失败时整批 `persistAllSessionsLocalFallback` 降级 localStorage，注释自述「P1-F1：整批降级必须可观测；fallback 写入的 LS 正文是 SQLite 缺失的最新快照（启动竞态期 invoke 未就绪即触发），由 fallback 打戳供 hydrate 回灌」。降级**有** `logInternalError('persist-degraded-ls', ...)`（同文件 1373/743/800/822）但**前端无面向用户的强提示**，LS 与 SQLite 双份真相并存期间若 hydrate 回灌链路任一环失效即静默分叉。属设计内降级（打戳可回灌），但「多份数据分叉无感知」的兜底不完整——UI 无 degraded 状态展示。
- **hydrate transport fixture 回退**：`apps/crish-desktop/src/api/noteHydrateIpc.ts:88-89` 「无 Tauri / 测环境仍 fixture。成功 source 恒 `tauri-ipc`（≠ fixture 伪装）」——fixture 回退是**诚实标签**的（`data-hydrate-source` 区分 `fixture` vs `tauri-ipc`，见 §11 证据），不构成伪装分叉；但无 Tauri 时产品 Strict 静默走 fixture 数据（仅 dev/测环境，非生产形态，可接受）。
- 其他 swallow-ok 降级（quota/隐私模式）均单键尽力而为、带 `logInternalError` 打点（sessionRustDb.ts:440/505/524/569/592/610/636/658），且 `ls-quota-truncated`/`ls-agents-truncated` 有专名日志。
