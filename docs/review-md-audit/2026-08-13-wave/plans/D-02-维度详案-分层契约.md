## 四、CT-02 字节级操作命令（pwsh7，执行轮用）

> 纪律：禁止 shell 重定向/echo 重写含中文文件；逐字节读写保证「仅头 3 字节差异」。

```powershell
# 1. 前置核验：3 文件当前头 3 字节（应为 EF BB BF）
$files = @(
  'crates/agent-provider/tests/ttfb_measure.rs',
  'crates/orchestrator/tests/multi_agent.rs',
  'crates/session-loop/src/steering/strategy.rs'
)
foreach ($f in $files) {
  $b = [IO.File]::ReadAllBytes($f)
  Write-Output "$f head3=$([BitConverter]::ToString($b[0..2])) len=$($b.Length)"
}

# 2. 去 BOM（仅当首 3 字节为 EF BB BF 时截断头 3 字节，其余原样写回）
foreach ($f in $files) {
  $b = [IO.File]::ReadAllBytes($f)
  if ($b.Length -ge 3 -and $b[0] -eq 0xEF -and $b[1] -eq 0xBB -and $b[2] -eq 0xBF) {
    [IO.File]::WriteAllBytes($f, $b[3..($b.Length - 1)])
  }
}

# 3. 字节级复检断言（应输出 head3=EF-BB-BF 之外的值 / 或 3E-XX-…）
foreach ($f in $files) {
  $b = [IO.File]::ReadAllBytes($f)
  $head = [BitConverter]::ToString($b[0..([Math]::Min(2, $b.Length - 1))])
  if ($head -eq 'EF-BB-BF') { throw "仍含 BOM: $f" }
  Write-Output "OK $f head3=$head len=$($b.Length)"
}
```

复检要点：去 BOM 后 `len` 应比去前小 **3**（7354→7351 / 39217→39214 / 26574→26571，本会话实测原值）；`git diff` 显示仅首行头部差异。防再犯（BOM 检测并入 `check:css-encoding` 同族门禁面）归 G-06，本任务不建门禁。
