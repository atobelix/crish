## 一、拆分范式（统一方法论 · 全波共用）

> 基线取自 block-workspace 已消化九面（post-sd13c2 05：SD-17 projection 277+tests 521 `#[path]`、SD-13-R turnInto barrel 61 等）+ 本波代码实测复核（note_backend 294 行旁挂范式直接验证，见 §6 锚点表）。

### 1.1 一包一刀与派单粒度

- 一个任务单元只切一个文件/一个域；主控每轮写死 2–3 个任务单元（附录 B §6 工作量均衡），不一包同时切四个文件。
- SR-06 批仅为派单分组：**每文件 = 1 任务单元**，批内按轮取 2–3 个文件；大文件（subagent 3107 / router 3098 / shell 3076）独占一槽，小文件（keyboard 953 / write_paths 962）可两文件合一槽。

### 1.2 测试外置（第一刀 · 统一先做）

- 外置方式：**`#[path]` 旁挂 + 父模接线**（非直接 `mod`，**无孤儿**）。范式实证（本会话直读）：
  `crates/agent-tools/src/note_backend.rs:310-312` = `#[cfg(test)] #[path = "note_backend_tests.rs"] mod tests;`；
  同范式实测存在 `note_backend_tests.rs`（528B）+ `note_backend_tests_memory.rs`（5281B）+ `note_backend_tests_w4.rs`（10278B）+ `note_backend_json.rs`（3031B），lib.rs `pub use note_backend::{…}` 维持公开符号。
- **散落 `#[cfg(test)]` 块处理（SR-01 核心难点）**：除主 `mod tests` 外，实现段内的 `cfg(test)` 注入方法/辅助函数**逐块随行搬入旁挂测试文件**（在测试文件内以 `impl CoreRunState { … }` 扩展块或独立辅助函数形式重建；Rust 允许同一类型多处 inherent impl，只要每方法单定义）。搬移后主文件 `rg "#\[cfg\(test\)\]"` 必须零命中（裁决 #11）。
- 零删除：全部测试搬入旁挂文件，禁止删除/合并任何既有测试（测试资产保护铁律 §9）。

### 1.3 门面不 break（第二刀 · 域切分）

- barrel 模式：主文件变薄门面，`pub use` 维持全部公开符号（`lib.rs:36/45/46` 实测 `pub mod background; pub mod core_run_commands; pub mod engine;` 接线不变），调用方路径零改动或仅 import 路径微调。
- `run/` 目录模式（SR-02）：`core_run_commands.rs` 保留为薄门面（`pub use run::{…}`），`run/mod.rs` 内 `mod run_core; mod run_retry; …` 接线；**不**为拆模引入 trait 抽象层（无第二实现需求）；`CoreRunState` 单定义持有于 `run_core.rs`，其余模经 `super::run_core::CoreRunState` 引用。

### 1.4 验收总纲（每单元共性）

1. `cargo check` 对应包**可编译**；对应包既有测试**真跑绿**（形状不变；源码形状 + 真跑双轨，执行 Agent 必须真跑）。
2. **无孤儿**：`run/` 每模均被 `mod` 或 `#[path]` 接线；测试文件不直接 `mod`（经父模 `#[path]`）。
3. **公开 API 不 break**：调用方编译零改动或仅 import 微调；`rg` 单定义核验（CoreRunState / run_task_impl / execute_single 等各仅 1 处权威定义）。
4. **一次交齐可编译**：禁止半拆红编强推（拆一半、编译红就交）。
5. 头钉纪律：源码头钉「SR-xx · 拆分 · ≠ EL」；诚实边界句全保留。
6. 行数口径：主文件达标数值见各单元；实现/测试分离后行数以 `node scripts/check-crate-size.mjs` 输出为权威口径（REV-03 §四-4）。

### 1.5 禁止项通则（全单元适用）

- 改行为语义（run/restore/snapshot/retry/approval/工具执行/装配顺序/任务状态机）；只切不修——拆分轮不夹带功能改动。
- 半拆红编强推；测试外置漏散落块（`rg "#\[cfg\(test\)\]"` 非零即 FAIL）。
- git 操作（子 Agent 留工作区，主控统一 `git commit --only`）；`--no-verify`；reset/checkout/restore。
- 用拆分关任何 EL；宣称「结构债清零 / 壳层无巨石」。
- 同文件双 Agent 并行写（以 REV-01 §二.2 冲突矩阵 + 本详案 §四/§五 串行链为准）。
- 整包重派已消化项（SD-01…49 全 ✅；note_backend 294 已消化——**禁重派**，裁决 #10）。

### 1.6 派单前开工动作（全波强制 · 裁决 #13）

每单元派单前必须：① 复核 G-00 快照（当前状态列）；② `git status` 实测目标文件无并行 Agent 在途（M 即冻结待收口）；③ **行号锚点重定位**（本详案 §6 锚点表是 2026-08-13 工作区实测瞬间值，派单时点必重新计量——core_run_commands 已从 15101 → 16724 且仍 M）。

### 1.7 编号与核销纪律（裁决 #1/#10）

- audit 02 报告的「SD-26…31」债包**作废**（与 block 域 SD-22…49 同名不同义）；本波统一用 **SR-**_；禁与 block 域 SD-_ 互引。
- 问题池 #8/#9（note_backend / SD-22…25）**已核销**：note_backend 实测 294 行 + 旁挂测试族，禁止重派。
