## 三、轮间门禁（每轮结束强制，主控验收）

1. Rust：`cargo test --workspace` 全绿（新增 S5 测钉/迁移测试/LogCapture 断言计入）。
2. 前端：`npm run typecheck` + `npm run test:coverage -- --project=unit` + `npx vitest run --config vitest.integration.config.ts` 绿。
3. 行数门禁：`npm run check:line-counts --all` 0 violation / 0 hard block（新增文件 eventNormalizers.ts ≤400、RunTimelinePanel.tsx ≤350）。
4. 契约：registry_drift 绿 + 生成绑定 --check 幂等零 diff + 保真清单核对（无新死事件）。
5. git：主控 `git commit --only <paths>` 逐文件域提交；不 `--no-verify`。

## 四、执行纪律（引用 00 框架 §四/§七）

- 任务单元五要素：派单卡必须含 ID/文件域锁/完成定义/验收断言/禁止项（从详案原样提取）。
- 锚点重定位：轮 1 产出锚点表，派单卡行号以锚点表实测值为准（F-13 两处漂移已标注）。
- 同文件串行矩阵：core_run_commands.rs 冻结窗口（轮 2~5 每轮 ≤2 壳层单元）；conex-types/src/events.rs 契约窗口单写锁；migrate.rs 单写锁（DM-01 独占）。
- 每轮 ≥1 审计位：审计位 agent 只读核查轮产出与验收断言的证据链（测试名可点/命令可跑），产出简短审计注记。
- 诚实边界句：死事件核销 ≠ 契约完备；未验证项显式标注；空返回按接续纪律处理。
