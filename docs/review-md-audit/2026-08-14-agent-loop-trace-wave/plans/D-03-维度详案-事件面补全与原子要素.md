## 一、维度目标

**一句话**：把「契约承诺了但运行期不发射 / 动作真实发生但事件面无声 / 事件发射了但原子要素残缺」三类缺口全部收敛——死契约逐件定态（接线/核销/转交），无声动作按「决策类值得事件、细节类日志即观测」分级补点，turn 对恒成对，工具原子要素字段真实化，输入留痕生产接线，并以契约变更集中窗口 + 四同步 + 测钉收口。

**逻辑递进图**（依赖序，前序产出是后续输入）：

```
EV-01 契约保真清单落盘（账本先行：核销清单/未接线清单/死事件清单/日志即观测登记）
  │  ← 契约窗口开启，全部后续新事件/字段在此账本登记、四同步联动
  ▼
【死事件处置（R-15）】
EV-02 checkpoint-created/restored 接线（真动作点接线；tool-input-repaired 核销已并入
       EV-01；GitRevert/D8/continuityHandlers 转交登记，本维度不实现）
  ▼
【无声动作补事件（R-16，值得事件组按「循环内决策 → 控制面 → hook 面 → 后台任务 →
   壳层收口 → 恢复/队列面」递进）】
EV-03 循环决策组（steering-evaluated + length-escalation）   ← 事件变体定义入契约窗口
EV-04 control-intent（入队/消费两态）
EV-05 hook-outcome
EV-06 summary-background（本组优先）
EV-07 壳层收口组（stage-summary-milestone + goal-continuation-decided 语义对齐 R-20）
EV-08 恢复/队列留痕组（nudge-enqueued + recovery-acknowledged + retry-attempted）
  ▼
【成对性与原子要素（R-17/R-18）】
EV-09 孤儿 turn-start 修复（pending_turn_index + emit_missing_turn_end + 恒成对测试）
EV-10 工具耗时与时刻真实化（duration_ms + occurred_at 打点 + 批收口语义文档化）
EV-11 工具载荷结构化（批 calls 摘要级 + attempt/deduplicated/实际入参/turn_index）
  ▼
【输入面与请求/usage 面（R-19/R-20）】
EV-12 输入留痕（RingBuffer 覆盖计数+warn + save_pending_input 生产接线）
EV-13 provider 请求锚点时间戳 + turn 级 usage/model 列（schema 评估并入 v9 窗口）
  ▼
【契约窗口收口（R-21）】
EV-14 契约变更集中窗口收口（新事件四同步 + regen + registry_drift + normalizer-drift
       全链绿 + CT-01/S5 测钉 + 日志即可组显式登记防误补）
```

**关键裁决锚点**（主控定稿，不得偏离）：GitRevert 补发射点归 D-06 唯一执行；continuityHandlers 归 D-06；D8 fallback 归 D-01；tool-input-repaired 核销（观测需求由 tool-start 实际入参字段承载）；核销清单并入契约保真清单（与 D-06 OV-01 合并一文件）；批收口语义文档化不建实时轨（REV-03 接受结论）；新事件一律 Delta/Soft 级可丢、禁新增 Critical；禁 OTel/新通道/新服务/新表/新指标系统（加字段不加系统）。
