# 叶子拥有会话标签 — 架构收敛总方案

> **战役工作区**：`docs/leaf-owned-tabs/`  
> **取代**：`docs/pane-tab-system/` 维 04/06 里「全局 `openTabs` + `leaf.sessionId` 1:1 + `tabsForUnit` 投影」的半落地模型。顶栏瘦身与 `PaneHeader` 视觉已接上，本战役不动皮肤，只改所有权与状态机。  
> **对照**：`reference/chat-composer-component/js/popovers.js` 的 `TreeStore`（所有权闭合）。禁止抄 `cloneNode` 双开会话、就地 `Object.assign` 变异节点。  
> **效果锁**：标签长在 chat 叶子上；二叉树只切会话窗格；工具坞回到叶子内部；单一拖拽提交；禁止多轨并存与兼容补丁。

---

## 1. 目标效果

1. 每个 chat 叶子自己拥有 `tabs: SessionTab[]` 与 `activeTabId`。条带成员 = 该数组，不再投影。
2. 点 / 建 / 关 / 拖只改目标叶子的 `tabs`；空叶才 prune（兄弟提升）。
3. 同一 `sessionId` 全树至多出现在一个叶子的 `tabs` 里。已打开则聚焦，禁止再拆一份。
4. 开 files / diff / terminal 只展开该会话在叶子内部的抽屉，不在布局树上再切 `H(chat, tool)`。
5. 草稿是该叶子上的真 tab（每叶可独立 `+`），不是全局唯一 `__pending_draft__` 抢画面。
6. UI 只调一个命令门面；禁止 `PaneHeader` 再手写 `setLeafSessionId` + `activateTab` + `bindActiveChatLeafSession`。

非目标：改胶囊尺寸、颜色、顶栏皮肤；保留遗留 columns 当第二布局；兼容旧「关 tab = 摘 Conversation Unit」。

---

## 2. 数据模型（唯一写源）

布局树仍是严格二叉。`LayoutLeaf` 对 **chat 叶** 升级为携带会话标签；工具不再作为树叶。

```ts
interface SessionTab {
  tabId: string;
  sessionId: string;       // 真会话，或该叶 draft 哨兵（每叶独立，禁止全局单例抢画面）
  title: string;
  workspaceKey: string;
  dock: RightToolDockState; // 坞跟 tab 走，不跟树几何走
}

interface LayoutLeaf {
  type: 'leaf';
  id: string;
  panelId: 'chat';         // 树上只有 chat 叶；旧 tool 叶在迁移时折叠进所属 tab.dock
  tabs: SessionTab[];      // 权威。禁止再把 panelId 字符串塞进这个数组
  activeTabId: string;     // 必属于 tabs
}
```

派生（只读，禁止当写源）：

- 窗口打开了哪些会话 = 先序扫描全部 `leaf.tabs`
- 当前画面会话 = 活动叶的 `tabs.find(activeTabId).sessionId`
- 侧栏高亮 / composer 作用域 = 上述画面会话（活动叶）

`workspaceShellStore.openTabs` / `activeTabId` **不再是写源**。Shell 收缩为命令门面（转发到 tree）+ `shellReady`。需要顺序列表时读树。

`LayoutLeaf.sessionId` 删除。身份只在 `SessionTab.sessionId`。

## 3. 不变量（写路径必须守）

I1. 一个 `sessionId`（非 draft 哨兵）全树至多属于一个 `ChatLeaf.tabs`。  
I2. 每个 chat 叶 `tabs.length >= 1`，`activeTabId ∈ tabs`。删空则 prune 该叶。根被删光时退化成带一个 draft tab 的单叶。  
I3. 激活 / 新建 / 关闭只改目标叶，不改其它叶的 `tabs`。  
I4. 切分 = 从源叶拿走该 `SessionTab` 对象，放到新叶或目标叶；源空则 prune。禁止用全局列表随便抓一个 session 填源叶。  
I5. 树上没有 tool 叶。坞是叶子内容区内部抽屉，状态在 `SessionTab.dock`。  
I6. 所有会话手势只走 tree 命令：`activateTab` / `addTab` / `removeTab` / `moveTab` / `splitTab`。UI 不得直写 `setLeafSessionId`。

`dedupeDuplicateSessionChatLeaves` 降为 persist 损坏兜底，禁止当日常纠偏。

---

## 4. 命令语义

| 命令 | 行为 |
|---|---|
| `activateTab(leafId, tabId)` | 设该叶 `activeTabId`；`setActiveLeaf`；`setActiveSessionId`（draft 则 `enterDraftMode` 且作用域绑该叶）。其它叶不动 |
| `addTab(leafId)` | 该叶 push 一个 draft tab 并激活。邻叶不动 |
| `openSession(sessionId, opts?)` | 若已在某叶 tabs 中 → `activateTab` 那一叶；否则 push 到**当前活动 chat 叶**并激活。禁止偷绑别的叶已有会话 |
| `removeTab(leafId, tabId)` | 从该叶删除；若删的是 active，邻居只在该叶内退（优先左邻）；空则 prune；杀该 session 的 PTY |
| `moveTab(srcLeafId, tabId, dstLeafId, insertIdx)` | 同一对象 splice；源空 prune；目标激活该 tab |
| `splitTab(srcLeafId, tabId, dstLeafId, region)` | 从源拿走，在目标旁 split 出新叶 `tabs=[该tab]`；源空 prune。region 为 center 则走 `moveTab` |
| `updateTabDock(tabId, patch)` | 只改该 `SessionTab.dock`，重绘该叶内部抽屉，不改树拓扑、不改 `activeLeafId` |

拖拽落点：条内 = `moveTab`；叶面中心 = `moveTab`；边缘 = `splitTab`。单一 controller，提交进上述命令。

## 5. 坞下树

- `openToolInSession` 只 `updateTabDock`：`collapsed=false`，把 panelId 写入 `openPanelIds` / `activePanelId`。
- `TreeLeafPanel` 的 chat 叶内容区：`flex` 行 = 对话流 +（未折叠时）内部 resizer + 抽屉。抽屉头复用现有工具条视觉，但 DOM 在 `.leafBody` 内，不是第二片绝对定位 leaf。
- 删除：`expandSessionUnitDock`、`applyDockToTree` 把 chat 换成 `H(chat, tool)`、`applyDockToSession` 把 `activeLeafId` 拨到 tool 叶、`reprojectAllSessionDocks` 剥光 tool 再挂回、`stripToolLeavesPreserveChats` 拍扁多 chat 拓扑。
- `tabModeEnabled` 若仍存在：只决定抽屉内是「单条多 tab」还是「抽屉内垂直堆叠」，禁止重建会话树。

## 6. 迁移（一次，冷启动）

输入：现树（可能含 tool 叶 + `leaf.sessionId`）+ `workspaceShellStore.openTabs`。

1. 收集 chat 叶：每个有 `sessionId` 的叶 → `tabs = [对应 TabSurface 或 mint]`，`activeTabId` 取该 session。
2. `openTabs` 里未出现在任何叶上的 tab → 并入当时活动 chat 叶（或第一片 chat 叶）的 `tabs` 末尾，不新建叶。
3. 每个 tab 的 `dock` 从旧 `TabSurface.rightDock` 拷入；若树上该 session 已有 tool 子树，把 `openPanelIds` / `activePanelId` / 宽度从 unit 推断进 `dock`，然后**丢掉 tool 叶**，只留 chat 叶拓扑。
4. 垂直/水平会话分屏拓扑保留（只删 tool 叶并 promote）。
5. 此后不再读 `openTabs` persist；shell persist 可停写标签列表。

非法树（空 tabs、重复 sessionId）在迁移函数内归一化，不要留到运行期 dedupe。

## 9. 验收（效果，不是「文件改了」）

- 单叶三 tab，关中间绑定 tab：叶还在，tabs 剩两个，dock 不丢，leaf id 不变。
- 两叶 A=s1 / B=s2，侧栏打开 s3：s3 进入**活动叶**的 tabs，另一叶内容不变。
- 两叶，在 B 点 s3（若 s3 已在 B.tabs）：只改 B.activeTabId；A 不动。
- 两叶，在非 first 叶点 `+`：该叶多一个 draft tab 并显示空白欢迎面；邻叶 tabs 与画面不变。
- 把 A 的一个 tab 拖到 B 条/中心：该 tab 从 A 消失、出现在 B；A 若空则 prune，否则留下剩余 tabs。
- 把 A 的唯一 tab 拖到 B 边缘：新叶出现且只含该 tab；A 消失（prune）；B 原 tabs 不变。
- 开 terminal：同一叶子内出现抽屉，树仍一个 chat 叶；`listChatLeaves` 仍为 1；没有第二条 sash 把会话树切开。
- `PaneHeader` 点击路径零次直调 `setLeafSessionId`。
- 相关旧测试（「不 auto-split」「关 tab 摘 unit」「tabsForUnit 投影」）删除或改写成新不变量；不得为了保绿而改回投影模型。

## 10. 诚实边界

- Demo 没有真实 session / PTY / persist。本方案补上，但不因此把标签所有权再拆回 shell。
- 同一会话不允许两个叶子各画一份（与 Demo `cloneNode` 不同）。这是产品约束，写进 I1。
- 旧 persist 树必须迁移；不保留「双读 openTabs 或 leaf.sessionId」的运行期分支。
