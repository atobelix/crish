## 0. 结论

工具坞离开布局树，变成 **chat 叶 `.leafBody` 内的抽屉**。开 files / diff / terminal / 文件查看器 **只改目标 `SessionTab.dock`**，树拓扑、`activeLeafId`、sash 集合不变。

现码把坞投影成 `H(chat, tool)`（`expandSessionUnitDock` → `applyDockToTree` → `setTreeWithDock`），再靠全局 `toolColumnCollapsed` + `flattenTree({ collapsedDomain: 'tool' })` 把 tool 叶压成 0 宽。这直接违反 I5，也是「开 terminal 出现第二条会话级 sash」的根因。本维拆掉整条投影轨。

**本维不改 `TreeLeafPanel.tsx`。** DOM 契约由本文锁定，实现归维 05。

## 2. DOM 结构（契约；维 05 实现）

树上只有 chat 叶。每个 chat 叶的盒树：

```
.leaf[data-panel-id="chat"][data-leaf-id][data-dock-open="true|false"]
├── PaneHeader                          // 会话标签条；维 05。不进抽屉。
└── .leafBody                           // 卡片皮肤不动（bg / border / radius / shadow）
    ├── .leafChatColumn                 // flex: 1 1 0; min-width: 0; 列方向
    │   ├── UnitChromeActions           // 覆盖层，流内 sticky；皮肤不动
    │   └── SlotOutlet(chat)            // 对话流
    ├── .leafDockResizer                // 仅 dock.collapsed===false 时存在
    │                                   // class 对齐 Demo: layout-resizer layout-resizer-panel
    └── .leafDockDrawer.chat-side-panel // 仅 collapsed===false 时存在
        ├── LeafToolTabStrip            // 抽屉头；视觉复用，DOM 在 .leafBody 内
        └── SlotOutlet(activePanelId)   // 或 tabMode=off 时抽屉内垂直堆叠
```

### 2.1 折叠时不占树几何

- **树**：`listChatLeaves` 不变；`flattenTree` 产出的 leaf rect / branch sash **零变化**。禁止为坞创建 `LayoutBranch`，禁止出现第二条会话级 sash。
- **叶内**：`collapsed===true` 时 **不挂载** `.leafDockResizer` 与 `.leafDockDrawer`（不要 `width:0` 占 flex，也不要靠 `collapsedDomain:'tool'` 把树上的 tool 叶压扁——树上已无 tool 叶）。
- 数据源：`const tab = leaf.tabs.find(t => t.tabId === leaf.activeTabId)`；`const dock = tab.dock`。禁止再读 `openTabs.rightDock`、禁止再读 tool 叶。

### 2.2 展开时的内部几何

- `.leafBody` 在 `data-dock-open="true"` 时为 **flex 行**：对话列 | resizer | 抽屉。
- 抽屉宽度 = `clampDockWidthRatio(dock.widthRatio) * leafBody.clientWidth`。写源仍是 `SessionTab.dock.widthRatio`（0.20–0.75，沿用 `adapterShapeTreeOps.ts:72-74` 的钳制），不改成第二套像素 persist。
- 内部 resizer **不是** `TreeResizeSash`，不走 `resizeBranch` / `useTreeResize`。手感对齐 Demo 2115-2228：`col-resize`、拖时 `is-dragging`、min 200px、max 叶宽 70%、松手才 `updateTabDock({ widthRatio })`。拖中只写叶上 CSS 变量（如 `--leaf-dock-width`），避免每帧打 store。
- 现 `.leafBody { flex-direction: column }` 与 `.leafBody > *:not(header)` 的 `width:100%` 会和行布局打架——维 05 改 **结构 CSS**（flex 方向 / 子项 flex），**不改** 卡片皮肤 token。

### 2.3 现码必须停用的几何

- `flattenTree({ collapsedDomain: 'tool' })`（`BinaryTreeWorkspace.tsx:164-166`、`useTreeResize.ts:182-189`）：坞不在树里，折叠域无意义。维 05 停止传入；维 02 可随后删 `collapsedDomain` 参数。
- canvas 级 sash：只服务 **会话分屏**（两片 chat 叶之间）。开坞不得新增 branch。

### 3.2 `openToolInSession`（本维重写；`openTool.ts`）

```ts
const TOOL_ALIASES: Record<string, string> = {
  tasks: 'overview',
  plan: 'overview',
  browser: 'preview',
}

function openToolInSession(sessionId: string, panelId: string): void {
  const mapped = TOOL_ALIASES[panelId] || panelId
  const hit = findTabBySessionId(tree.root, sessionId.trim())
             ?? findActiveLeafActiveTab()   // 草稿 / 未绑：退到活动叶活动 tab
  if (!hit) return                          // 失败：原样

  if (mapped === 'chat') {
    // 收起该 tab 的抽屉；不 ensureChatOnlyTree、不剥 tool 叶
    updateTabDock(hit.tab.tabId, { collapsed: true })
    return                                  // I5
  }

  const openPanelIds = hit.tab.dock.openPanelIds.includes(mapped)
    ? hit.tab.dock.openPanelIds
    : [...hit.tab.dock.openPanelIds, mapped]

  updateTabDock(hit.tab.tabId, {
    collapsed: false,
    openPanelIds,
    activePanelId: mapped,
  })                                        // I3 + I5

  if (mapped === 'terminal') {
    void ensurePtyForSession(hit.tab.sessionId)  // PTY 与树无关，保留
  }
  // 删除：applyDockToTree / setToolColumnCollapsed / setActiveLeaf(tool)
}

function openToolInActiveTab(panelId: string): void {
  const leaf = findNodeById(tree.root, activeLeafId)
  const tab = leaf?.tabs.find(t => t.tabId === leaf.activeTabId)
  if (!tab) return
  openToolInSession(tab.sessionId, panelId)
}

function collapseActiveTabRightDock(collapsed: boolean): void {
  const tab = findActiveLeafActiveTab()
  if (!tab) return
  const patch: Partial<RightToolDockState> = { collapsed }
  if (!collapsed && !tab.dock.activePanelId) {
    patch.activePanelId = 'overview'
    patch.openPanelIds = tab.dock.openPanelIds.length
      ? tab.dock.openPanelIds
      : ['overview']
  }
  updateTabDock(tab.tabId, patch)
}
```

## 5. tabMode：降级为抽屉内展示，删除对树的投影

- `tabModeEnabled===true` → 右坞 = **一枚 tool 叶**，`tabs = openPanelIds`

## 6. 文件查看器：`openFileViewerInSession` 禁止 `splitLeaf`

现码 `openTool.ts:94-141`：

1. 若活动叶是 chat，把目标拨到 **第一个 tool 叶**；
2. 有 tool 叶 → `addTabToLeaf`；无 → **`splitLeaf(chat, 'horizontal', file-viewer:path)`**；
3. 再 `updateRightDock` + `applyDockToTree`。

这会在树上切出第二片叶（或往 tool 叶塞 tab），违反 I5 与本维验收。

**重写：**

```ts
function openFileViewerInSession(
  filePath: string,
  _initialMode: 'plain' | 'diff' = 'plain'
): void {
  const panelId = `file-viewer:${filePath}`
  const tab = findActiveLeafActiveTab()
  if (!tab) return
  // 与 openToolInSession 同一条写径；禁止 splitLeaf / addTabToLeaf / setToolColumnCollapsed
  openToolInSession(tab.sessionId, panelId)
```

## 11. 采用总案 / 缺口上报

**采用总案**：I5；`updateTabDock` 只改 dock；删除 `expandSessionUnitDock` / `applyDockToTree` / `reprojectAllSessionDocks` / `stripToolLeavesPreserveChats`；tabMode 不对树投影；开 terminal 后仍 1 个 chat 叶、无第二条 sash。

**缺口（不上改模型，只上报）：**

1. `updateTabDock` 写在总案 §4 树命令表，文件域却划在 02；04 是消费者。若 02 未交出该函数，04 不能用 shell `updateRightDock` 顶替（那会把写源拉回 `openTabs`）。
