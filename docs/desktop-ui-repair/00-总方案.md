# 桌面界面一致性 · 总方案

> 2026-08-19。依据真机图 + 11 路调研交稿。效果锁不得降级。禁止 AI 假图、禁止搬示例假壳、禁止复活 `src/plugins` / 第 12 view / `shell-scrollbar.css` 这个**文件名**。

## 1. 产品句

主壳仍是 BinaryTree + 叶槽。本战役修的是**已经画出来却不能用、或用起来像系统网页**的交互与皮：按下不要果冻；提示层同时一颗、快移一颗都不出；点击展开同时一层；设置按钮 7px 且能用；滚动条细；Toast 不再是堵心的灰胶囊。

## 2. 用户锁（盖过旧战役）

| 锁 | 口径 |
| --- | --- |
| 果冻 | 去掉点击按压缩放。过弹弹簧（y>1 贝塞尔）Toast 入场一并收掉 |
| Tooltip | 同时只能一颗；指针过快则一颗都不出；滚动/开菜单立刻灭 |
| 展开面板 | 所有点击展开同一时间只开一个，判断逻辑统一 |
| 四击 | `_left_gu32j_18`（模型槽）与 `_permPill_icyue_1` 必须一开一关，和加号一样 |
| 设置圆角 | **按钮 = 7px**。旧「08 胶囊化」不得盖过 |
| 设置能用 | 外观/通用几乎全死；整体失效 >80、样式退化 >60% 必须拉回来 |
| 滚动条 | 不再露出 Windows 粗条+三角 |
| Toast | 「已自动获取 7 个模型」这套竖分割灰块不要再铺 |

Dialog 确认盒允许叠在面板上。Tooltip 不进展开互斥组，但菜单开时必须灭。

## 3. 根因（不是 80 个互不相干的坏按钮）

1. **`ui/Button:active { transform: scale(0.98) }`** 全仓继承。权限丸 0.97、会话行 0.985。加号菜单项也有。模型 pill 没有——手感不齐。
2. **Tooltip 每实例一份 `visible`，无 `delayShow`。** `mouseEnter` 立刻亮；滚动只重定位不关；离屏被钳回视口所以残影钉在空画布。`isTooltipSilenced()` 无业务调用。
3. **没有 exclusive group。** LayerStack 只入栈、外点只关顶层。Composer 权限/模型/`+`/思考四份 `useState`。`ChatCard` 不传 `onCloseSiblingMenus`。会话右键自绘 portal，不进栈。
4. **四击 = 两个写者对打。** 外点 `setOpen(false)` 之后，按钮 `setOpen(prev => !prev)` 或 Radix toggle 立刻再开。模型徽标仍是 `Popover.Trigger` + Tooltip。加号能关，是因为它写死 `false`。
5. **设置全局表被删、类名还在。** 红队按「`SettingsUI.module.css` 已取代 `settings-base.css`」抽空 6 张表，但控件仍写 `.ui-segment` / `.settings-choice-btn` / `.settings-field-input`。`* { padding:0 }` + 无 `button { appearance:none }` → WebView2 UA 黑框连体。`ui/SegmentedControl` 生产 0 引用。
6. **设置壳 `--z-modal:1000`，`ui/Menu` `--z-dropdown:300`。** 外观/通用/模型的 Select 等于没开。Tooltip 反而是 9000。
7. **写了没人读。** 发送快捷键写 `crish_settings.sendShortcut`，读 `crish_send_shortcut`。内置七家无密钥区。`已自动获取 N 个模型` 漏过 `/^已获取\s/` 过滤。
8. **`--button-radius` 默认 6 且全仓 0 消费。** 默认档没有任何 `--radius-*` 等于 7px。
9. **`shell-scrollbar.css` 已删，门禁只封顶不保底。** 真机回落经典粗条。壳换代禁复活**该文件名**；效果锁要求细条 → **新文件新出口**。
10. **Toast × 是 `Button ghost sm` 常驻 `--tint-active`，高 28px，看起来像竖分割。** 入场 400ms 过冲从右侧弹入。
11. **OpenCode Go 两行 = `opencode-go` 种子 + `preset-opencode-go` 另 id 同名。**
12. **空叶「打开文件」是 UnitChrome 图标的 Tooltip 被钳到画布上，不是空态 CTA。** 顶栏「未命名会话」是壳层 caption 写死，权威标题是「新会话」。

## 4. 冲突取舍

| 冲突 | 取舍 |
| --- | --- |
| 08 胶囊化 vs 设置 7px | **7px** |
| 禁 `shell-scrollbar.css` vs 要细条 | 新文件（例如 `overlay-scrollbar.css`），不碰禁名 |
| 整表找回 `settings-base.css` | **禁止**。会把 999 胶囊一并复活。改接原子组件 + 7px token |

## 6. 验收

- 连点权限丸、模型槽：一次开、一次关，不会叠开，也不会要点死。
- 鼠标快速划过侧栏：一颗 Tooltip 都不出；停住才出一颗；滚动立刻灭。
- 设置外观/通用：主题、密度分段有选中态，下拉能开，按钮 7px。
- 定时/扩展/快捷键不再是 UA 黑框。
- 侧栏/设置/模型菜单是细轨道，没有上下三角粗条。
- Toast 不再出现「文案 | 灰方 ×」。
- 模型列表同一名称只一行。
- 相关 vitest 绿。不宣称 EL/H2。不 `--no-verify`。
