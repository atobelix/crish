# 分维终稿 · 设置控件与 7px

对应总案 I4 I5 I9。调研：`survey/04` `05` `06` `07`。

## 死皮

不要整表找回 `settings-base.css`。

- `.ui-segment` / `.ui-segment-item` → 接现成 `ui/SegmentedControl`（外观主题/密度）
- `.settings-choice-btn` → 同一分段原子（定时筛选、扩展已安装/发现）
- `.settings-field-input` / 快捷键搜索 / 键位钮 → `ui/Input` + 真正的快捷键按钮皮（不要 UA `<input>`）
- 裸 `<button>` 能换成 `ui/Button` 的都换

## 7px

- `:root` `--button-radius: 7px`（不要再别名到 `--radius-md` 的 6）
- `ui/Button` `--btn-radius: var(--button-radius)`
- 设置页局部覆盖 999 / 12 / 4 的**按钮**改读 `--button-radius`
- Switch 轨道、头像仍 full/circle
- 卡片外壳可以大于 7，不要把卡片强行 7

## 层叠与 Esc

- 设置 Dialog 打开时，其内部 Menu/Select 的 z 必须高于该 Dialog（1000 压 300 是外观/通用「点了没反应」的主因）
- Esc：先退栈顶下拉，再关设置。`useSettingsNav` 捕获阶段直接关整页必须让路
- 规则 overlay 回调名接错（`_onBlockingOverlayChange` vs `onBlockingOverlayChange`）一并修

- 发送快捷键：写 `crish_settings.sendShortcut` 与读 `crish_send_shortcut` 收成一把
