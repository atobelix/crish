# 分维终稿 · 交互基座（果冻 / Tooltip / 展开 / 四击）

对应总案 I1–I3。调研：`survey/01` `02` `03` `10` `12`。

## 果冻

删这些按下缩放，改成色/透明度，不要位移：

- `ui/Button` `.button:active { transform: scale(0.98) }`
- `ComposePlusMenu` `.item:active`
- 侧栏 `.sessionItem:active` 0.985
- `.permPill:active` 0.97

Toast / popover 入场不要用 `--transition-enter` 的 1.275 过冲。Switch 拇指 1.51 另条，本维一并收成无过冲。

## Tooltip

基座唯一：`ui/Tooltip`。

- 全局单例（同时 `visible` ≤ 1）
- `delayShow`：未满 delay 就离开 → 从未显示。快移 = 零颗
- 滚动 capture、开 Menu、失焦：立刻灭，不要只重定位
- 离屏目标：灭，不要钳回视口当残影
- 业务调用 `isTooltipSilenced()` 或等价：菜单开着静音
- 改测试：删掉「mouseEnter 立刻亮」的错误契约

## 展开互斥 + 四击

一条规则：点击展开的面板走同一套 open 源。打开 B 必须关 A。LayerStack 登记时驱逐同级 dropdown，不只入栈。

四击修法（根因，不是点次数补偿）：

- 禁止 `setOpen(prev => !prev)` 与外点 `onOpenChange(false)` 对打
- 外点已关时，同一 pointer 落到 trigger 上不得再 toggle 开
- `_left` 里的模型徽标改 **Anchor + 受控 open**，与加号同构，去掉 `Popover.Trigger`+Tooltip 抢 click
- `permPill` 同样：注释里「已消除 Quad-Click」作废，按加号的「关则写死 false」对齐
- `ChatCard` 接上 sibling close，或基座互斥后这条自然成立

会话右键迁到 `ui/Menu` 或至少登记 LayerStack，并进入同一 exclusive。
