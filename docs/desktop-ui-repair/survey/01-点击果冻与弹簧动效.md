## 0. 读法与分类口径

本清单按**机制**分类，不是按业务优先级。同一控件可能同时落在多类（例如 `ui/Button` 既是按下缩放，又被 Composer「+」、设置页按钮、空叶「打开文件」继承）。

| 标签 | 含义 | 与用户锁关系 |
| --- | --- | --- |
| **果冻-按下缩放** | `:active` / 按下时 `transform: scale(<1)` | 用户锁去掉 |
| **过冲-贝塞尔 y>1** | `cubic-bezier` 终点 y>1（会越过目标值再回落） | 用户锁「太弹」相关 |
| **弹入-打开缩放** | 浮层/对话框/Tooltip 进出场 `scale(0.95~0.96)`，配套曲线 y≤1 | **可保留候选**（不是按下果冻，但是弹） |
| **弹簧感-无过冲** | 命名 spring / 用 `cubic-bezier(0.16, 1, 0.3, 1)` 一类 expo-out，曲线不过 1 | **可保留候选** |
| **微位移 / 色变 press** | 按下或 hover 只有 tint / 边框 / `translate`，无 scale | **可保留候选** |
| **非点击缩放** | 脉冲、加载呼吸、hover 放大、拖拽幽灵、发丝线 `scaleY` | 不是点击果冻；仍写入，防误删 |
| **死代码 / 断引用** | 定义了但无消费，或引用了不存在的 `@keyframes` | 实现时别当活效果修 |

**过冲判定（证据口径）**：CSS cubic-bezier 四个参数 `(x1, y1, x2, y2)`，**y2>1 或 y1>1** 才记「动画过冲=是」。`cubic-bezier(0.16, 1, 0.3, 1)` 的 y 顶到 1、不越过 1，记「过冲=否」，即便 token 名叫 spring。

仓库内 **未发现** framer-motion / `useSpring` / JS 弹簧。果冻全是 CSS `transform: scale` + token 贝塞尔。

## 2. 果冻-按下缩放（用户锁去掉）

按下时整体缩小。这是真机「点一下会弹」的主因。**四条活规则 + 一条枢纽继承。**

### 2.1 枢纽：`ui/Button`（blast radius 最大）

| 字段 | 值 |
| --- | --- |
| 文件 | `apps/crish-desktop/src/components/ui/Button/Button.module.css` |
| 选择器 | `.button:active:not(:disabled)` |
| 行号 | 72–74（过渡在 46–48） |
| 组件 | `Button` / `IconButton`（`IconButton.tsx` 转发到 `Button`，同样带 `.button`） |
| 当前值 | `transform: scale(0.98)`；过渡 `transform var(--transition-micro, 120ms) cubic-bezier(0.2, 0, 0, 1)` |
| 触发 | **mousedown `:active`**（不是 `data-active` 选中态；选中态是 `.buttonActive` 只改底色，175–180 行） |
| 过冲 | **否**（曲线 y≤1）。果冻来自 **整钮缩小 2%** + 120ms 回弹，不是 1.275 贝塞尔 |
| 叠加 | `:active` 同时把 `::before` 换成 `--btn-active-overlay`（67–70），色变 + 缩放一起做 |

`Button.tsx` 始终拼接 `styles.button`（约 71–78 行），业务 `className` **不会取消** `:active` 缩放，除非自己写更高优先级的 `transform`。现查：Composer `.plusBtn` / `.sendCircle` / `.retractBtn` **都没有**覆盖 `transform`，因此 **照样果冻**。

**继承面（问题同权，不按重要性删）**：凡 `import { Button }` / `IconButton` 的产品按钮，按下都是 `scale(0.98)`。至少包括：

| 备注 | 用户锁点名的是点击果冻；开关过冲是否一并去掉由主控定。轨道 hover 只改边框（43–45），无 scale。 |

### 4.3 死 token `--transition-spring`

`tokens.css:308` 与 `--transition-enter` **同一条过冲曲线**，时长 500ms。  
`rg "var\\(--transition-spring\\)"` 在组件 CSS/TSX **零命中**（只有 tokens 自己和 `reduced-motion.css` 置 0）。改它不会改变当前真机手感，除非以后有人接上。

## 11. 覆盖了什么、没覆盖什么、额外发现

### 覆盖了什么

- `apps/crish-desktop` 内全部 `transform: scale(`（CSS + `tabDragGhost.ts`）。
- 全部 `cubic-bezier(...)`（CSS + `App.tsx` / `AppTopBar.tsx` / `tabDragGhost.ts`）。
- 全部 CSS `:active` 规则（只有 6 个文件：Button、会话行、权限 pill、「+」菜单项、FontSelect 触发器、NotePaper badge）。
- Token `--transition-spring*` / `--transition-enter` / `--transition-press` / `--transition-popover*` / `--transition-modal*` 的定义与消费。
- Menu / Tooltip / Dialog / 模型菜单 / 权限菜单 / 会话右键 / Toast / Switch / Slider 的打开或 press 动效。
- 用户点名的会话行、设置钮（侧栏齿轮 **vs** 设置页 Button）、Composer「+」、权限 pill、模型 pill。
- `ui/Button` 继承面（Composer / 设置 / 空叶 / 顶栏 / 审批等）。
- reduced-motion / eco 闸门。

### 没覆盖什么（诚实边界）

- **未跑真机 WebView2/9222**，未对每个按钮截「按下瞬间」；分类依据是 CSS/TS 源码，不是本轮截图逐帧。
- **未扫** `apps/agent-workbench`、`packages/*`、`reference/*`（任务范围是 `apps/crish-desktop`）。
- **未扫** 运行时由 JS 写入、但源码里字符串拆开的 `transform`（当前 `rg transform:` 于 `*.tsx` 只有虚拟列表位移、分段滑块、拖拽幽灵等，无 press scale）。
- Tooltip 孤儿、浮层互斥、7px 圆角、滚动条、空叶布局：**不在本文件展开**（边界文档锁给其它 `survey/02–08`）。
- `ChatStatusRibbons.ribbon.test.ts:141` 的 “clamps overshoot” 是进度比例数学，**不是 CSS 过冲**。
- 无法从源码证明用户手指下的「太弹」100% 来自 Button 0.98 还是权限 0.97 还是 Toast 1.275；四条按下缩放 + Switch/Toast 过冲 **全部写入**，由主控定刀，不在这里猜主因然后砍项。

### 额外发现（任务外但会害实现）

1. **按下果冻不齐**：模型 pill 无 scale，权限 pill `0.97`，Button `0.98`，会话行 `0.985`。去果冻若只改 Button，Composer 权限钮和侧栏行仍弹。
2. **打开弹入也不齐**：模型菜单 / 会话右键有 `crish-popover-enter`；「+」菜单没有；权限菜单 keyframes 写错所以没有。不能假设「浮层已统一」。
3. **`cds-popover-enter/exit` 断引用**：`PermissionModeMenu.module.css:73,87` 引用的 keyframes **不存在**。`reduced-motion` 的 `cds-animate-*` 也打不中它。
4. **Exit 类未接线**：`.mbMenuExit` / `.permMenuExit` / `.contextMenuExit` 只有 CSS，无 TSX。关闭是卸载，退场缩放多数播不到。
5. **死 token / 死工具类**：`--transition-spring`、`--easing-enter`、`--easing-emphasized`、`.ui-popover-animate`、`.ui-modal-animate`、`panel-enter/exit`、`.compact-menu-container`、`.modernSelectTooltip`。
6. **`WorkspaceEmptyState` 已显式 `transform: none`**（注释提到旧 scale）——空态图标不是当前果冻源；空叶「打开文件」仍是 `ui/Button`，**会果冻**。
7. **Switch 过冲是注释里的有意设计**（`1.51`），与点击果冻不同刀；主控需单独裁决是否纳入「太弹」。
8. **Toast 是 `--transition-enter` 唯一活消费者**：若把该 token 的 1.275 改掉，影响的是 Toast 滑入，不是按钮。
9. 对工作流：去果冻的**完整**收口点是 `Button.module.css:72-74` + 三条手写 `:active` scale（会话行 / 权限 pill / 「+」项），外加是否动 Switch/Toast/打开弹入。只改 Composer 会漏设置页与空叶。

### 对主控的实现提示（仍不定案）

- 用户锁已经足够：按下 `scale(<1)` 四条活规则应视为同一效果族。
- 打开弹入（Tooltip/Dialog/模型菜单）与过冲 token 是**另一族**；本调研不把它们标成「必须留」或「必须删」。
- 禁止用「业界都用 spring」或「0.98 很微」劝退去掉果冻。
