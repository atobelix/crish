## 1. 总根因：全局 settings CSS 被抽空，幽灵 class 仍挂在 DOM

设置三页大量写的是**全局字符串 class**，不是 CSS Modules。这些选择器在现行 `apps/crish-desktop/src/**/*.css` 里 **零命中**（`rg` 全仓 `*.css` 无 `.settings-choice-btn` / `.settings-field-input` / `.shortcut-key-btn` / `.settings-create-path` / `.settings-btn-rect` / `.ext-toolbar` / `.ext-row` / `.sched-preset-chip`）。

历史皮在 `styles/settings/settings-base.css`、`settings-plugins.css`、`settings-advanced.css`、`shell-scrollbar.css`。现行入口 `apps/crish-desktop/src/index.css` 只 import tokens / design-system / responsive / z-index / shell-reset / shell-layout / focus / reduced-motion / sr-only / breakpoints。`src/styles/` 下已经没有 `settings/` 子目录。

叠加 `shell-reset.css:10-14` 的全局复位：

```css
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
```

裸 `<button>` / `<input>` 失去 UA 默认内边距，又没有产品皮，于是：

- WebView2 默认 `appearance: auto` → Windows 经典 **1.6px outset / inset** 3D 边框、直角、系统灰底
- `margin: 0` → 相邻按钮贴死，真机「黑框连体」
- `padding: 0` → 字贴边，高度塌到内容行高

这不是「某几个按钮漏写样式」，是**一整层设置皮肤被删、消费方 class 名没改**。红队 / 壳审计已登记过同构（BUG-08 / 09 / 11 / 26），真机 2026-08-19 三张图证明仍在。

本三页已有的 CSS Modules 几乎帮不上：

| 文件 | 实际覆盖 |
| --- | --- |
| `SettingsScheduleTab.module.css` | 只 `.toolbar`（flex 两端对齐）+ `.controlGroup`（行操作 gap） |
| `SettingsShortcutsTab.module.css` | 只 `.controlGroup`（5 行） |
| `SettingsExtensionsTab.module.css` | 只 `.detailMeta` / `.emptyCompact` / `.detailMdSans`。**Tab 外壳自己不 import 这份 module**（只有 `ExtensionBody` / `McpToolsSection` import） |
| `ScheduledTasksPanel.module.css` | 只管对话内嵌面板，不管设置页全局 class |

## 2. 圆角对照（用户锁 7px）

默认 token（`tokens.css:262-266`）**没有 7px 这一档**：

| token | 默认值 | compact | large |
| --- | --- | --- | --- |
| `--radius-sm` | 4px | 3px | 5px |
| `--radius-md` | **6px** | 5px | **7px** |
| `--radius-lg` | **8px** | **7px** | 9px |
| `--radius-xl` | 12px | 10px | 14px |
| `--radius-full` | 9999px | 9999px | 9999px |

设置按钮若走 `ui/Button` size=`sm`，写死 `--btn-radius: var(--radius-md, 6px)`（`Button.module.css:99-106`）→ **6px，不是 7px**。
`ui/SegmentedControl` 外圈 `--radius-lg`（8px）、内滑块 `--radius-md`（6px），也对不上 7px。
`ui/Input` sm 同样 `--radius-md`（6px）。

因此即便把幽灵 class 换成原子组件，**不改 token / 不给设置面单独 7px 契约，圆角锁仍不成立**。

本三页额外违例：

- 对话内嵌定时模板芯片 `ScheduledTasksPanel.module.css:105`：`border-radius: 999px`（满胶囊，和 7px 锁正面冲突）
- 设置页「+ 收起」走 `ui/Button` secondary sm：6px 圆角 + `--control-soft-bg` 灰底 → 真机「灰胶囊」（相对旁边 UA 黑框显得像胶囊，相对 7px 锁仍偏圆、偏灰）
- `Button.module.css:72-74`：`:active { transform: scale(0.98) }` → 用户锁「点击果冻去掉」在设置新建钮上仍生效

### 4.8 描述只剩 `>`

frontmatter 解析是逐行切 `key: value`，**不展开 YAML folded/literal**：

- JS：`skillsApiHelpers.ts:71-77` `^([^:#]+):\s*(.*)$`，值原样 trim
- Rust：`skills.rs:67-75` `split_once(':')`，值原样 trim

因此 `description: >` 的值就是字面量 `>`。后续缩进行全部丢掉。

`.grok/bundled/skills` 里大量官方技能就是这种写法（例：`build-with-ai/SKILL.md:3` `description: >`）。Rust 发现**默认扫这个目录**，扩展页「技能」过滤下这些行的描述都会显示成单独一个 `>`。

`chinese-encoding-guard` 手头两份 SKILL.md 的 description 是完整中文单行。若真机图上**这两行自己的描述也是 `>`**，则还有第三份 folded 副本，或详情区/截断把正文吃掉 —— **源码推不出「这两份会被解析成 `>`」**，标不确定。
「描述只剩 `>`」作为现象，对 grok bundled 技能是**确定的解析缺陷**，与 CSS 无关。

### 4.9 安装 / 卸载是半假的

- `useExtensionMarket.tsx:268-315` `handleInstallCatalog`：插件只把 `installRef` 推进 `settings.packages`，toast「仅登记包名（未连接引擎安装）」；其它 kind 只 `markCatalogInstalled`（localStorage），toast「仅标记本机已装，未连接引擎安装」

## 11. 文末总结

定时、扩展、快捷键三页的真机「浏览器默认控件」，不是个别漏样式，而是**设置全局皮肤被抽空后，DOM 仍挂着一串没有选择器的 class**。`* { padding:0; margin:0 }` 再把 UA 钮的内边距和间隙扒光，筛选项就变成黑框连体。

对照用户三张图：

- **定时**：五枚筛选、两张创建路径卡 = 裸 button + 零 CSS；「+ 收起」是 `ui/Button` 6px 灰胶囊加果冻，不是 7px。
- **扩展**：已安装/发现、全部/插件/MCP/技能、搜索 = 同一套幽灵分段和幽灵 input；详情/配置是有皮的灰 Button，矩形 class 是空的；列表 `ext-*` 整卡无皮。`chinese-encoding-guard` 因「name+路径」双 id、技能不做 name 去重而出现两行。描述 `>` 是 frontmatter 把 YAML `description: >` 当成字面量，`.grok/bundled/skills` 会成批中招。
- **快捷键**：搜索和键位全是裸 HTML；module 只剩 5 行 gap。键位是系统 button。右侧被 `.coverContent` 的 `overflow-x:hidden` + `contain:strict` + Card `overflow:hidden` + 控制列不收缩裁掉，裁切外是更深的 secondary（暗色即露黑）。滚动条是设置内容区的 Windows 经典条，因为 `shell-scrollbar.css` 已不存在。

功能上这些钮大多**能点**（筛选、新建路径、录制、还原、展开详情都有 handler）。坏的是皮、圆角锁、重复数据、假安装、YAML 描述、以及裁切。设计系统里 SegmentedControl / Input 已经在仓库里，本三页几乎没用；Kbd 还不存在。圆角 token 默认也没有 7px。后续方案必须同时处理「幽灵 class → 原子组件」和「设置按钮 = 7px」，不能只补回已删除的全局 CSS 当验收。
