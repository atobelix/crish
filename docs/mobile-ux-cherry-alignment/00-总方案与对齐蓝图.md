## 二、主控决策与收口实施批次（Phased Implementation Plan）

经主控综合审查，8 项详案互补且高度自洽，现裁决划分为 **三个工程实施批次**：

### 批次一：视觉基座与两大急迫交互修复（Immediate Fixes & Visual Polish）
- **范围**：
  1. **长按语音唤醒透明层落地**：覆盖 `homeScreen.tsx` 顶层透明手势分流，接入 `haptics.snap()`，更新文案为“点击发消息、长按语音输入”；
  2. **输入框正圆胶囊、均一描边与 3 阶弥散阴影落地**：`theme.ts`、`SoftShadow.tsx`、`SoftShadowSurface.tsx` 消除椭圆畸变与 `operator="out"` 截断；
  3. **底色灰度提升 1.96% 与纯白白名单锁定**：`theme.ts` 更新 `canvas`（244）、`canvasDrawer`（240），运行 `styleTokens.guard.test.ts` 锁定纯白组件。
- **验收标准**：长按必唤醒语音、输入框几何正圆柔光弥散、界面层次显著分明。

### 批次二：抽屉面板与输入框展开 60fps 性能重构（Drawer & Composer Performance）
- **范围**：
  1. **抽屉面板重构为 Front Overlay**：改造 `CrishDrawerLayout.tsx`，移除整屏 Card Push 平移缩放与动态圆角剪裁；移除 `renderToHardwareTextureAndroid`，抽屉手势纯 worklet 驱动；
  2. **ComposerDock 绝对定位键盘避让落地**：移除全屏 `<Screen avoidKeyboard>`，改用 UI 线程 `translateY` 贴合软键盘，消除点击聚焦时的全屏 Yoga 重排风暴。
- **验收标准**：抽屉划开与输入框聚焦展开彻底告别卡顿掉帧，实测满帧丝滑。

### 批次三：对话流触底、通知体系与工具卡片深度升级（Chat Timeline & Rich Interactions）
- **范围**：
  1. **对话流触底与 Inset 修复**：修复 `useTimelineBottomInset.ts` 与 `EdgeFade` 遮挡层级，接入 `onContentSizeChange` 与 `useViewportFollowState`；
  2. **思考链恢复与工具紧凑卡片**：在 `buildTimeline.ts` 解封 `thought`，引入 `ProcessGroupCard` 与详情下钻；
  3. **In-App Toast 与通知状态感知**：实现轻量跟随键盘的墨色 Actionable Toast。
- **验收标准**：对话划底无任何阻滞，流式思考过程优雅呈现，通知闭环完整。
