   - 依赖 `.dropBefore` / `.dropAfter` 的静态内阴影（`box-shadow: inset 0 ±2px 0 0 var(--accent-primary)`）；

   - 导致长列表高频 re-render，触发级联组件重绘与 GC 抖动，破坏了“拖拽中仅计算瞬态 DOM Transform，松手时单次原子提交”的基本准则。

   - 侧栏拖拽仅在侧栏内部封闭循环，探测器未与二叉树工作区（`BinaryTreeWorkspace` / `LayoutTreeStore`）接线；
   - 用户无法将侧栏中的历史会话拖拽至右侧工作区创建分屏，亦无法拖入其它窗格的顶栏。

### 1.2 架构重塑 5 大核心支柱

1. **1D 轴向同构动力学引擎**：将水平 TabStrip（X 轴）与垂直 SessionList（Y 轴）在数学模型、让位公式、滞后防抖上完全统一；

## 二、 1D 轴向同构动力学引擎与数学严格闭环

### 2.1 1D 连续空间几何投影与参数模型

设拖拽目标容器内包含 $N$ 个已有项（若源项来自该容器，则将其排除后剩余 $N$ 项），有序集合为 $\mathcal{I} = [I_0, I_1, \dots, I_{N-1}]$。

在 1D 投影轴上（水平模式 $u = x$，垂直模式 $u = y$），每个项目 $I_k$ 在视口中的静态物理跨度为闭区间：
$$\mathcal{S}_k = [u_{\min}(k), u_{\max}(k)], \quad \text{跨度} \ \Delta u(k) = u_{\max}(k) - u_{\min}(k)$$

单个槽位的标准移动步长为：
$$S = \overline{\Delta u} + g$$
- **水平 TabStrip 模式**：$S_x = \text{tabWidth} + g_x = 150\text{px} + 4\text{px} = 154\text{px}$；
- **垂直 SessionList 模式**：$S_y = \text{rowHeight} + g_y = 28\text{px} + 0\text{px} = 28\text{px}$（或 $32\text{px}$ 自适应）。

### 2.2 双向对称让位与补位显式数学方程

设源项在目标容器内的原始下标为 $s = \text{sourceIndex} \in \{0, \dots, N\} \cup \{\text{null}\}$，目标插入下标为 $k = \text{insertIndex} \in [0, N]$。

位移向量 $\mathbf{O} = [O_0, O_1, \dots, O_{N-1}]^T \in \mathbb{R}^N$ 由纯函数精确计算：

#### 定理 1（同列表重排序双向对称守恒）
当 $s \ne \text{null}$ 时：
$$\mathbf{O}[i] = \begin{cases}
-S, & \text{若 } k > s \ \land \ s \le i < k \quad (\text{向后拖动：区间 } [s, k-1] \text{ 的项向前补位}) \\
+S, & \text{若 } k < s \land k \le i < s \quad (\text{向前拖动：区间 } [k, s-1] \text{ 的项向后腾位}) \\
0, & \text{其它情况}
\end{cases}$$
*证明*：当 $k > s$ 时，原占据槽位 $s$ 的项被移出，插入至位置 $k$。原区间 $[s+1, k]$ 的项在重排后下标变为 $i-1$，故其物理坐标必须平移 $-S$；其余项下标不变，位移为 $0$。反向同理。绝不向后多推产生双倍鸿沟。$\blacksquare$

#### 定理 2（跨列表/跨分组插入单向腾位）
当 $s = \text{null}$ 时：
$$\mathbf{O}[i] = \begin{cases}
+S, & \text{若 } i \ge k \quad (\text{插入点及其后续所有项向后平移 } +S \text{ 腾出 1 个槽位}) \\
0, & \text{若 } i < k
\end{cases}$$
- 特殊边界：末尾追加（$k = N$）时，$\forall i \in [0, N-1], \mathbf{O}[i] = 0$。$\blacksquare$

### 2.3 方向感知型 $\eta=1/3$ 滞后容差防抖方程

设当前指针坐标为 $u_p$，当前帧运动方向矢量为 $\Delta u_p$。插入点计算函数 $\Phi(u_p, \Delta u_p, \mathcal{I})$ 定义为：

$$\Phi(u_p, \Delta u_p, \mathcal{I}) = \begin{cases}
0, & \text{若 } u_p < u_{\min}(0) \\
N, & \text{若 } u_p > u_{\max}(N-1) \\
\operatorname{HysteresisIndex}(k, u_p, \Delta u_p), & \text{若 } u_p \in \mathcal{S}_k
\end{cases}$$

其中单项内部滞后判定为：
$$\operatorname{HysteresisIndex}(k, u_p, \Delta u_p) = \begin{cases}
k + 1, & \text{若 } \Delta u_p \ge 0 \ \land \ u_p \ge u_{\min}(k) + \frac{1}{3} \Delta u(k) \quad (\text{正向深入 } > 1/3 \text{ 后插}) \\
k, & \text{若 } \Delta u_p \ge 0 \ \land \ u_p < u_{\min}(k) + \frac{1}{3} \Delta u(k) \\
k, & \text{若 } \Delta u_p < 0 \ \land \ u_p \le u_{\max}(k) - \frac{1}{3} \Delta u(k) \quad (\text{反向回退 } > 1/3 \text{ 前插}) \\
k + 1, & \text{若 } \Delta u_p < 0 \ \land \ u_p > u_{\max}(k) - \frac{1}{3} \Delta u(k)
\end{cases}$$

### 2.4 多分组（置顶 / 项目文件夹 / 常规）跨区动力学投影

侧栏由三大逻辑分组构成：$\mathcal{G}_{\text{pinned}}$（置顶区）、$\mathcal{G}_{\text{project}}^{(m)}$（各项目文件夹）、$\mathcal{G}_{\text{general}}$（常规区）。
- **源分组离开**：源项保持 `.isDraggingSource`（占位高度 28px，内部隐藏），源分组内其余项平移归零；
- **目标分组进入**：检测到源会话不属于目标分组，目标分组按 **定理 2（跨列表）** 在 $k$ 处平滑向下腾出 28px 空间；
- **空/折叠分组感应**：当指针悬停在空折叠区（如空 Pinned 区）上方时，自动触发展开并腾出槽位。

## 三、 空间索引落点探测与跨域路由网络

### 3.1 $O(1)$ 视口包围盒空间索引（Spatial DropZone Resolver）

为避免高频遍历 DOM 或 `document.elementsFromPoint` 穿透失效，构建基于视口包围盒的空间索引判定：

```mermaid
flowchart TD
    A[Pointer Coordinates: x, y] --> B{x <= sidebarWidth?}
    B -->|Yes| C[Sidebar Domain: 计算所属分组与 1D 垂直插入点]
    B -->|No| D{命中 [data-pane-header] 且 y <= stripBottom + 12px?}
    D -->|Yes| E[TabStrip Domain: 计算 1D 水平插入点]
    D -->|No| F{命中 [data-leaf-id] 且通过 Guard 互斥校验?}
    F -->|Blocked| G[Detached Outside: 禁用分屏，Ghost 呈游离态]
    F -->|Allowed| H[PaneSplit Domain: 22% 边缘切分 或 中心合并]
```

### 3.3 严格互斥守门矩阵（Mutual Exclusion Guard Matrix）

#### 形式化定义
设全局二叉树为 $\mathcal{T}$，活动 Chat 叶集合为 $\mathcal{L}_{\text{chat}}$，叶总数 $M = |\mathcal{L}_{\text{chat}}|$。被拖拽会话为 $S_{\text{drag}}$，目标叶为 $\ell_{\text{dst}}$。

分屏判定谓词 $\Psi_{\text{guard}}(S_{\text{drag}}, \ell_{\text{dst}}, \mathcal{T})$：
$$\Psi_{\text{guard}}(S_{\text{drag}}, \ell_{\text{dst}}, \mathcal{T}) = \begin{cases}
\text{BLOCKED}, & \text{若 } M = 1 \ \land \ S_{\text{drag}} = \operatorname{activeSessionId}(\ell_{\text{dst}}) \\
\text{ALLOWED}, & \text{其它情况}
\end{cases}$$

#### 全场景真值表

| 场景 | 全局叶数 $M$ | 拖拽会话状态 | 目标区域 | 守卫判定 | 视觉表现 | 松手行为 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **G-01** | $M = 1$ | 唯一叶当前活动会话 | 叶面边缘 (22%) | **BLOCKED** | 指示器隐藏，Ghost 变半透明游离态 | **NO-OP**（严禁无意义自自分裂） |
| **G-02** | $M = 1$ | 唯一叶当前活动会话 | 顶栏 TabStrip | **BLOCKED** | Tab 不腾位，指示器隐藏 | **NO-OP**（位置无需变更） |
| **G-03** | $M = 1$ | 唯一叶当前活动会话 | 叶面中心 | **BLOCKED** | 指示器隐藏 | **NO-OP** |
| **G-04** | $M = 1$ | 未打开会话 / 历史非活动会话 | 叶面边缘 (22%) | **ALLOWED** | 高亮绿色边缘分屏指示框 (2px 内缩) | `splitSessionFromSidebar` 新建叶子 |
| **G-05** | $M = 1$ | 未打开会话 / 历史非活动会话 | 顶栏 TabStrip | **ALLOWED** | 顶栏执行 1D 水平腾位 | `openSession` 追加至顶栏 |
| **G-06** | $M > 1$ | 任意会话 | 任意叶面边缘 | **ALLOWED** | 高亮目标叶边缘分屏指示框 | `splitTab` (若已开) 或 `splitSession` |

| **G-08** | 任意 $M$ | 任意会话 | 侧栏内部 | **ALLOWED** | 侧栏执行 1D 垂直让位 | `commitSessionSidebarMove` |

### 3.4 跨域过渡 12px 物理滞后缓冲区（Domain Hysteresis Buffer）

- 当处于 `tab-strip` 模式时，指针纵向向下离开顶栏时，赋予 $+12\text{px}$ 滞后死区（$y \le \text{stripBottom} + 12\text{px}$ 维持顶栏判定）；
- 当指针离开侧栏横向向右滑动时，跨越侧栏右边界 $+8\text{px}$ 才激活二叉树工作区判定，杜绝侧栏边缘微颤触发全屏指示器闪烁。

### 4.2 零 Store 污染：rAF 单帧动力学管线与 GPU 合成层

```typescript
// rAF 动力学单帧管线
let rafId = 0;
let pendingPointer: { x: number; y: number; dx: number; dy: number } | null = null;

function handlePointerMove(e: PointerEvent) {
  pendingPointer = { x: e.clientX, y: e.clientY, dx: e.clientX - startX, dy: e.clientY - startY };
  if (!rafId) {
    rafId = requestAnimationFrame(flushFrame);
  }
}

function flushFrame() {
  rafId = 0;
  if (!pendingPointer) return;
  const { x, y, dx, dy } = pendingPointer;

  // 1. GPU 硬件加速跟随
  ghostPill.style.transform = `translate3d(${x - grabOffsetX}px, ${y - grabOffsetY}px, 0)`;

  // 2. 空间索引路由
  const target = resolveCrossDomainDropTarget(x, y, dx, dy, dragContext);

  // 3. 驱动 1D DOM 让位（零 React 状态重排，零 Store 写入）
  applyTransientTransforms(target);
}
```

### 4.3 虚拟滚动（Windowed List）动态视口保护与非线性边缘自动滚动

1. **虚拟化动态视口放宽**：
   - 拖拽启动瞬间（`isDragging = true`），侧栏虚拟化控制器自动将挂载视口放宽为可见全量项，保证所有可见项均能接收 `translateY` 变换；
2. **非线性边缘自动滚动（Exponential Edge Auto-Scroll）**：
   - 当指针进入侧栏顶部/底部 $\le 36\text{px}$ 区域时，按指数增长步长（$4\text{px} \sim 18\text{px}$）进行平滑自动滚动，并在滚动过程中实时更新几何缓存。

### 4.4 硬件级多模态手势防死锁与幂等取消协议

为应对一切意外终端事件，建立全局生命周期安全网：
- **`keydown (Escape)`**：立即中断拖拽，执行 `resetAllTransientStyles()`；
- **`lostpointercapture` / `pointercancel`**：立即触发清理；
- **`window.blur`**：当窗口失去焦点时，自动幂等回滚所有 DOM 位移并销毁 Ghost；
- **拖拽结束吞噬随后的 `click` 事件**（`swallowNextClick`），防止松手误激活源会话。

### 5.3 叶面 22% 边缘分屏原子算子（`splitSessionFromSidebar`）

在 `layoutTreeInsert.ts` 中新增纯函数算子：

```typescript
export function splitSessionFromSidebar(
  tree: LayoutTree,
  sessionId: string,
  dstLeafId: string,
  region: SplitRegion,
  splitRatio?: number
): LayoutTree {
  if (!sessionId || !dstLeafId) return tree;
  const dst = requireChatLeaf(tree.root, dstLeafId);
  if (!dst) return tree;

  // 1. 创建新会话 Tab 实体
  const newTab: SessionTab = {
    tabId: generateNodeId('tab'),
    sessionId,
    title: '',
    dirty: false,
  };

  // 2. 创建新叶节点
  const freshLeaf: LayoutLeaf = {
    type: 'leaf',
    id: generateNodeId('leaf'),
    panelId: 'chat',
    tabs: [newTab],
    activeTabId: newTab.tabId,
    dock: createDefaultDock(),
  };

  // 3. 切分二叉树分支
  const dir: SplitDirection = region === 'left' || region === 'right' ? 'horizontal' : 'vertical';
  const ratio = clampSplitRatio(splitRatio ?? 0.5);
  const isFirst = region === 'left' || region === 'top';
  const newBranch: LayoutBranch = {
    type: 'branch',
    id: generateNodeId('branch'),
    direction: dir,
    splitRatio: isFirst ? ratio : 1 - ratio,
    children: isFirst ? [freshLeaf, dst] : [dst, freshLeaf],
  };

  return replaceNode(tree, dstLeafId, newBranch);
}
```

### 5.4 二叉树拓扑不变量守恒与自动修剪（Auto Prune）闭环

1. **严格二叉性（Strict Binary Invariant）**：全树任意 Branch 严格拥有 2 个子节点；
2. **真会话唯一性（Unique Real Session Invariant）**：全树最多存在一个该 `sessionId` 实例；
3. **空源修剪（Auto Prune）**：若跨叶迁移使源叶变空，`pruneEmptyLeaves` 自动向上合并父 Branch，零残留空窗格。

### 5.5 事务撤销重做（Undo/Redo History Snapshot）保障

每次跨域分屏与移动操作，均由 `layoutTreeStore` 压入不可变历史快照，完整支持 `Ctrl+Z` 撤销与重做。
