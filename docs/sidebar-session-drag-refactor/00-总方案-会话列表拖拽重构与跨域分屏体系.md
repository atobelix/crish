## 一、 战役愿景与核心架构断言

彻底重构 Conex / Crish 客户端的会话列表拖拽体系，消除历史遗留的生硬绿线、重影叠加、判定失配与拖拽死锁问题，实现：
1. **纯视觉优雅**：零绿线、零绿框，原汁原味会话卡片浮层，纯依靠 `140ms cubic-bezier(0.2, 0, 0, 1)` 平滑 `translateY` 腾出插入空位；
2. **同构底层数学**：顶栏 Tab 水平 1D 拖拽与侧栏会话垂直 1D 拖拽共享相同的 1D 连续轴向动力学几何抽象；
3. **跨域无缝分屏**：支持直接从侧栏抓起历史会话，拖入右侧二叉树工作区（22% 边缘高亮分屏或顶栏追加），一气呵成；
4. **单窗口互斥守门**：单窗口且拖拽当前活动会话时，向右分屏刚性拦截（防止无意义自裂变），仅侧栏内重排序；其余情况完全放行；
5. **绝对高可靠**：几何优先空间路由、静态未位移坐标反向解算、松手同步求值与原子提交，彻底根除“拖拽毫无动静”。

## 三、 1D 连续轴向动力学几何引擎（数学模型与证明）

### 3.1 严格连续性中点插值方程

设当前活动分组内肉眼可见的 $N$ 个列表项静态区间序列为：
$$\mathcal{S} = [ [y_{\min}(0), y_{\max}(0)], \dots, [y_{\min}(N-1), y_{\max}(N-1)] ]$$

定义相邻项过渡中点序列 $\mathcal{B} = [b_0, b_1, \dots, b_N]$：
$$b_0 = -\infty$$
$$b_k = \frac{y_{\max}(k-1) + y_{\min}(k)}{2}, \quad \forall k \in [1, N-1]$$
$$b_N = +\infty$$

方向感知滞后因子 $\eta_k = \frac{1}{3} (y_{\max}(k) - y_{\min}(k))$。插入索引求解方程 $\Phi(y, v_y) \to [0, N]$：

$$\Phi(y, v_y) = \begin{cases}
0, & \text{若 } y \le y_{\min}(0) \\
N, & \text{若 } y \ge y_{\max}(N-1) \\
k+1, & \text{若 } v_y \ge 0 \land y \ge y_{\min}(k) + \eta_k \\
k, & \text{若 } v_y < 0 \land y \le y_{\max}(k) - \eta_k \\
k, & \text{其它情况}
\end{cases}$$

### 3.2 静态未位移坐标映射（Static Geometry Unwarping）

$$\operatorname{StaticTop}(k) = \operatorname{BoundingTop}(k) - \operatorname{readTranslateY}(\text{el}_k)$$
$$\operatorname{StaticBottom}(k) = \operatorname{BoundingBottom}(k) - \operatorname{readTranslateY}(\text{el}_k)$$

通过消除动态位移的几何形变，彻底隔绝判定振荡。

### 3.3 局域分组（Section-Scoped）平滑让位位移定理

设源项在当前分组内的索引为 $s$（若跨分组拖入则 $s = \text{null}$），当前插入点为 $k$。
位移向量 $\mathbf{O}[i]$（步长 $S = 28\text{px}$）严格满足双向对称：
- **同分组重排序（$s \ne \text{null}$）**：
  - 向后拖（$k > s$）：$i \in [s, k-1] \implies \mathbf{O}[i] = -S$（向上补位）；
  - 向前拖（$k < s$）：$i \in [k, s-1] \implies \mathbf{O}[i] = +S$（向下腾位）；
  - 其余项位移恒为 $0$。
- **跨分组拖入（$s = \text{null}$）**：
  - $i \in [k, N-1] \implies \mathbf{O}[i] = +S$；
  - 末尾追加（$k = N$）所有项位移恒为 $0$。

## 四、 几何优先跨域空间索引探测器（CrossDomainDropRouter）

### 4.1 视口几何包围盒 $O(1)$ 判定拓扑

```typescript
export function resolveCrossDomainTarget(
  clientX: number,
  clientY: number,
  dx: number,
  dy: number,
  draggedSessionId: string,
  tree: LayoutTree
): CrossDomainTarget {
  // 1. 侧栏视口包围盒判定优先
  const sidebarEl =
    (document.querySelector('aside[data-sidebar-root="true"]') as HTMLElement | null) ||
    (document.querySelector('aside.crish-sidebar') as HTMLElement | null);

  if (sidebarEl) {
    const sbRect = sidebarEl.getBoundingClientRect();
    if (
      clientX >= sbRect.left &&
      clientX <= sbRect.right &&
      clientY >= sbRect.top &&
      clientY <= sbRect.bottom
    ) {
      return {
        domain: 'sidebar',
        sectionEl: sidebarEl,
        sectionKind: 'general',
        folder: '',
        insertIndex: 0,
        targetSessionId: null,
        isPinned: false,
      };
    }
  }

  const hit = document.elementFromPoint(clientX, clientY);
  if (!hit) return { domain: 'outside' };

  // 2. 顶栏 TabStrip 探测
  const toolStrip = hit.closest('[data-leaf-tool-tab-strip]');
  const stripWrap = !toolStrip ? (hit.closest('[data-pane-header="true"]') as HTMLElement | null) : null;
  const tabStrip = stripWrap ? (stripWrap.querySelector('[role="tablist"]') as HTMLElement | null) : null;
  if (tabStrip && stripWrap) {
    const targetLeafId = stripWrap.closest('[data-leaf-id]')?.getAttribute('data-leaf-id') || '';
    if (targetLeafId) {
      return { domain: 'tab-strip', targetLeafId, stripEl: tabStrip, insertIndex: 0 };
    }
  }

  // 3. 窗格内容区 PaneCanvas 22% 边缘分屏探测
  const paneLeaf = hit.closest('[data-tree-canvas="true"] [data-leaf-id]') as HTMLElement | null;
  if (paneLeaf) {
    const leafId = paneLeaf.getAttribute('data-leaf-id') || '';
    const r = paneLeaf.getBoundingClientRect();
    const region = detectPaneDropRegion(clientX, clientY, {
      left: r.left,
      top: r.top,
      width: r.width,
      height: r.height,
    });

    if (region && leafId) {
      const guard = evaluateSessionSplitGuard(tree, draggedSessionId, leafId, region);
      if (guard.allowed) {
        return {
          domain: 'pane-split',
          targetLeafId: leafId,
          region,
          paneRect: { left: r.left, top: r.top, width: r.width, height: r.height },
        };
      }
    }
  }

  return { domain: 'outside' };
}
```

### 4.2 单窗口同会话互斥守门状态机（Mutual Exclusion Guard）

形式化判定谓词 $\Psi_{\text{guard}}$：
$$\Psi_{\text{guard}}(\mathcal{T}, s_{\text{drag}}, L_{\text{target}}, R) = \begin{cases}
\text{BLOCKED}, & \text{若 } |\operatorname{Leaves}(\mathcal{T})| = 1 \land s_{\text{drag}} = \operatorname{ActiveSession}(L_{\text{target}}) \land R \in \{ \text{L}, \text{R}, \text{T}, \text{B} \} \\
\text{ALLOWED}, & \text{其它情况}
\end{cases}$$

## 五、 DOM 卫生、GPU 合成层与 React 渲染隔离

1. **原汁原味 Ghost 克隆与脱敏**：
   - 先调用 `rowLi.cloneNode(true)`；
   - 注入 `pointer-events: none !important; z-index: var(--z-tooltip);`；
   - 深度遍历子节点，设置 `style.pointerEvents = 'none'` 与 `tabIndex = -1`；
   - 克隆完成后，再为原项添加 `isDraggingSource`（`opacity: 0.25; visibility: hidden;`）；

   - 严格过滤 `r.offsetParent === null || r.getBoundingClientRect().height === 0` 的项；

   - 拖拽期零 React State 调度，纯 GPU `transform: translateY(±28px)` + `transition: 140ms cubic-bezier(0.2, 0, 0, 1)`。

## 六、 完整手势生命周期与原子持久化提交

1. **`pointerup` 同步终态刷新**：
   - 同步调用 `applyPointer(ue.clientX, ue.clientY, ...)` 锁定最终槽位；
2. **`swallowNextClick()`**：
   - 在 `window` 捕获阶段拦截接下来的 1 次原生 `click` 事件（超时 300ms 自动注销），防止会话误触激活；
3. **原子提交**：
   - 侧栏内排序：单次调用 `onMoveRef.current(sessionId, targetSessionId, folder, isPinned)`；
