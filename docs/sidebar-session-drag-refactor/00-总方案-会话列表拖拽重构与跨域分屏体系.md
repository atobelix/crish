# 一、 战役愿景与架构宪法

本战役旨在为 Conex / Crish 桌面客户端打造业界一流的会话组织、流式交互与拖拽分屏体验。贯彻以下四大不可动摇的架构宪法：

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│                           【 架构四大不可动摇宪法 (Four Invariants) 】                          │
├─────────────────────┬───────────────────────────────────────────────────────────────────────────┤
│ 1. 真实 AI 对话纯洁 │ 主对话历史只允许持久化用户指令与模型真实生成的输出。                     │
│    (Pure AI Only)   │ 坚决杜绝任何前端伪造的 assistant 消息或嵌入气泡内部的红框错误横幅落盘！   │
├─────────────────────┼───────────────────────────────────────────────────────────────────────────┤
│ 2. 瞬态进行时错误态 │ 错误、断网与异常作为临时的进行时状态（灰色字体、呼吸指示、具备重试能力）  │
│    (Volatile Status)│ 挂载于消息流底部，内存独占，发送新对话或重试自动消失，单例去重不堆叠。    │
├─────────────────────┼───────────────────────────────────────────────────────────────────────────┤
│ 3. 侧栏所见即所得   │ 彻底摒弃列表项局部截断手风琴与“查看全部”多轨逻辑；列表有多少项就自然撑开，│
│    (WYSIWYG Flow)   │ 下方内容自然下推，统一由最外层单轨滚动条滚动，彻底消除文字重叠 Bug。      │
├─────────────────────┼───────────────────────────────────────────────────────────────────────────┤
│ 4. 跨域分屏与 1D 动 │ 侧栏拖拽支持 1D 垂直消抖位移、拖入右侧工作区边缘分屏、拖入顶栏 TabStrip  │
│    力学插排 (Split) │ 行内自由让位插排，分屏落位 Zero-Click 自动聚焦激活。                      │
└─────────────────────┴───────────────────────────────────────────────────────────────────────────┘
```

# 三、 维度 1：主对话流纯洁性与瞬态进行时错误态（Volatile Ephemeral Status）架构

## 3.1 真实 AI 回答唯一真理源原则（Pure AI Invariant）

主对话历史（Session Messages）只允许存在两种物理实体：
1. **用户真实指令**：`role: 'user'`；
2. **AI 真实生成**：`role: 'assistant'`（包含真实的 `text`、`thought`、`toolCalls`）。

**清退项目**：
- 拔除 `slashSendPreflight.ts` 中 `/learn` 构造的 `addMessage('已记录用户偏好')` 伪造回复，改为全局轻量 Toast；
- 拔除 `MessageContent.tsx` 中内嵌在助手气泡内部的 `ErrorMessageBanner`；
- 拔除 `SessionMessage.errorDetail` 持久化字段；
- 拦截 `streamSession.ts` 中将网络错误降级为 `callbacks.onChunk(msg)` 的风险分支。

## 3.2 独立内存状态机：`ephemeralChatStore` 设计

```typescript
// apps/crish-desktop/src/store/ephemeralChatStore.ts
import { create } from 'zustand';

export type EphemeralErrorKind =
  | 'network'       // 网络中断 / DNS 解析失败 / 连接重置
  | 'rate_limit'    // 429 频率超限
  | 'auth'          // 401 / Key 失效
  | 'quota'         // 额度耗尽
  | 'context_length'// 上下文超限
  | 'server_error'  // 5xx 服务端故障
  | 'stream_abort'  // 异常中断
  | 'generic';      // 通用错误

export interface EphemeralChatStatus {
  id: string;                      // 唯一指纹 ID
  sessionId: string;               // 绑定的会话 ID
  kind: EphemeralErrorKind;        // 错误分类
  message: string;                 // 用户可读提示
  technicalDetail?: string;        // 技术堆栈信息
  retryable: boolean;              // 是否可直接重试
  timestamp: number;               // 发生时间
  retryContext?: {
    userMsgId?: string;
    promptText?: string;
  };
}

interface EphemeralChatState {
  statusBySession: Record<string, EphemeralChatStatus | null>;
  setEphemeralStatus: (sessionId: string, status: Omit<EphemeralChatStatus, 'sessionId'>) => void;
  clearEphemeralStatus: (sessionId: string) => void;
  clearAll: () => void;
}

export const useEphemeralChatStore = create<EphemeralChatState>()((set) => ({
  statusBySession: {},

  setEphemeralStatus: (sessionId, status) => {
    if (!sessionId) return;
    set((state) => ({
      statusBySession: {
        ...state.statusBySession,
        [sessionId]: { ...status, sessionId },
      },
    }));
  },

  clearEphemeralStatus: (sessionId) => {
    if (!sessionId) return;
    set((state) => {
      if (!state.statusBySession[sessionId]) return state;
      const next = { ...state.statusBySession };
      delete next[sessionId];
      return { statusBySession: next };
    });
  },

  clearAll: () => set({ statusBySession: {} }),
}));
```


## 4.2 自然伸长与整体下推流式动力学方程

设单行高度 $H_{\text{row}} = 28\text{px}$，行间距 $G = 3\text{px}$，单行物理步长 $S = 31\text{px}$。
对于置顶区高度 $H_{\text{pinned}}$ 与项目区高度 $H_{\text{projects}}$：
$$H_{\text{pinned}} = H_{\text{header}} + G_{\text{sec}} + N_{\text{pinned}} \cdot S - G + M_{\text{sec}}$$
$$H_{\text{projects}} = \sum_{p \in \text{Projects}} \left( H_{\text{p\_header}} + ( \text{open}_p \ ? \ (N_p \cdot S - G + G_{\text{folder}}) : 0 ) \right) + M_{\text{sec}}$$
常规对话区起始 Y 坐标：
$$Y_{\text{general}} = H_{\text{pinned}} + H_{\text{projects}}$$

当上方任何分区展开或新增会话时，下方所有内容在原生 CSS 文档流中自动平滑整体下推，零 JavaScript 补丁！

# 五、 维度 3：1D 轴向动力学拖拽、跨域分屏与顶栏 TabStrip 插入（已落地体系）

## 5.1 实数域全连续中值分割序列方程与 31px 网格步长

中值分割序列：
$$\mathcal{B} = [-\infty, \frac{y_0 + y_1}{2}, \frac{y_1 + y_2}{2}, \dots, \frac{y_{N-2} + y_{N-1}}{2}, +\infty]$$
指针在 $[b_i, b_{i+1})$ 内结合 $1/3$ 滞后容差判定，彻底消灭 $1.5\text{px}$ 缝隙死区回退。

## 5.2 跨域 TabStrip 水平 1D 让位动力学

侧栏会话拖入顶栏时，Tab 项平滑向右 `translateX(+154px)` 腾位（140ms 曲线），松手在指定下标 `insertIdx` 插入并激活。

## 5.3 三 Store 协同 Zero-Click 自动激活协议

分屏落点提交统一由 `workspaceShellStore.splitSessionFromSidebar` 处理：
1. `treeStore.splitSessionFromSidebar`；
2. `rememberChatLeaf(L_new)`；
3. `setActiveSessionId(sessionId)`；
