# 共享追加协议（全员）

## 用途

- `问题发现.md`：任意 Agent 发现的问题、缺口、假完成风险、断点（**提议性质**）。
- `工作流改进建议.md`：对派单、提示词、阶段顺序、主控习惯的改进想法（**提议性质**）。

用户启动「工作流改进 / 巡航历史计划」时，专用 Agent 再扫这些文件 + 战役文档；**日常不必通读全文**。

## 只追加

1. 不要改、不要删、不要重排已有内容。
2. 不必理会前面是否重复；定位到文件**末尾最新一行之后**追加即可。
3. 甚至不必阅读历史正文；打开 → 跳到末尾 → 追加一块 → 关闭。

## 追加块格式（建议）

```text
---
time: YYYY-MM-DD HH:mm（本地）
agent: 主控|子Agent|包ID或角色
campaign: 战役目录名或 none
---
（正文：问题或建议；可含路径:行号；可分类标签如 [连通][结构][测试]）
```

## 编码护栏（追加前后）

1. **追加前**：确认文件能按 UTF-8（无 BOM 优先）解码；若已是 UTF-8-sig，追加后仍写回无 BOM 的 UTF-8。
2. **追加时**：使用 UTF-8 写回；禁止 PowerShell 5 默认重定向写中文。优先：编辑器/工具直接写，或 Python：

```python
from pathlib import Path
p = Path("docs/agent-roles/shared-append/问题发现.md")
block = """..."""  # 含结尾换行
data = p.read_bytes()
text = data.decode("utf-8-sig") if data.startswith(b"\xef\xbb\xbf") else data.decode("utf-8")
if not text.endswith("\n"):
    text += "\n"
text += block if block.endswith("\n") else block + "\n"
p.write_text(text, encoding="utf-8", newline="\n")
```

3. **追加后**：再读一遍解码；抽查刚追加的中文是否仍在；若出现大量 `?` 或乱码 → **停止继续写**，报告主控，不要用坏编码覆盖。

## 禁止

- 覆盖整文件、truncate、为「去重」删除旧条。
- 把此处当成正式总方案或验收关闭依据（只是提议池）。
