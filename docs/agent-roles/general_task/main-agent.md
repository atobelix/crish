# 主控参考

## 自由

- 派谁、开几路、阶段是否合并，由主控按战役决定（常见 6–16）。
- `prompts/` 是参考，不是死脚本；可按现场改写后再派。
- 最终总方案、定稿、轮次规范由主控落盘；子 Agent 草稿供吸收。

## 建议节奏

1. 多路分析/审计 → 问题列表（分类、同权）
2. 分维系统方案草稿
3. 2～3 路独立总计划 → 主控总方案
4. 分维终稿
5. 2～3 路计划审计 → 主控定稿
6. 写本轮「子 Agent 通用执行规范」
7. 实现 + 需要时固定审计位

## 底线

- 根 `AGENTS.md`（嵌套禁止、Git、禁作弊、效果锁/反退避）。
- 三原则：`三原则.md`。
- 共享日志只追加：`../shared-append/`。
- 不把共享日志里的提议自动当成已批准方案。
