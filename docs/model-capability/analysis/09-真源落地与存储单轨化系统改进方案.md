## 二、架构裁决（单轨权属矩阵）

### 2.1 数据实体权属（每实体唯一真理路径）

| 数据实体 | 唯一存储 | 说明 |
| :-- | :-- | :-- |
| **模型字典**（模型是什么：vendor/displayName/上下文窗口/最大输出/协议/能力/计价） | **`~/.conex/models.yaml`（磁盘文件，Rust 懒播种）** | SSOT。前端内存镜像只是缓存视图，改字典只能经 YAML 编辑器 |
| **用户 per-profile 模型配置**（enabled/displayName 覆盖/contextLength 覆盖/思考档位/lastTest/能力断言） | `crish_model_meta_v1`（localStorage，现状保留） | 用户状态，不是字典。字典→配置是**添加时一次性填充**（仅新模型），不是运行时双读 |
| **服务商档案**（profiles） | 现状保留（LS + DPAPI） | 不在本轮范围 |
| ~~`crish_models_config_v2`~~ | **删除** | 与 YAML 双轨，硬编码种子违禁 |
| ~~`crish_models_yaml_backup_v1`~~ | **删除** | 假备份轨；真备份由 `AtomicWriteTx` 的 `.bak` 承担 |

### 2.2 四禁令落地口径

1. **禁兼容**：`vision→image` 做**一次性幂等迁移**（迁移后旧键不存在，类型系统删除 `vision`，非永久双读）；`thinkingGear` 旧双字段读取删除（Rust v2 已单源）；`KNOWN_MODELS_CATALOG` Proxy 兼容层删除。
2. **禁硬编码**：初始字典种子从前端 TS 数组改为 **Rust 侧资源文件 `models.default.yaml`**（`include_str!`），首次读取时懒播种到磁盘。数据即文件，随版本演进。
3. **禁伪实现**：IPC `missing`/`error` 一律显式失败态（fail-closed），校验服务不可用 → 禁止保存；不弹假成功；无 localStorage 回退路径。
4. **禁多轨**：YAML 解析只在 Rust（serde_yaml）发生，前端直接消费解析产物；字典写路径唯一（YAML 编辑器→save 命令→原子写）；meta 写路径唯一（`upsertModelMeta`）。

### 2.3 本轮范围线（明确不做，防伪造）

- **不实现** 02 方案的 L2 工作区级联、LKG 影子、父目录 watcher、指数退避读取器——外部编辑场景由「重载磁盘」按钮 + 弹窗打开即重读 + 保存后镜像即时重载覆盖；上述能力留待后续波次，**UI 不得出现相关入口或暗示**。
- **`thinkingFormat`/`thinkingBudget*` 不进 v1 schema**：当前无任何消费方，进 schema 即死字段（伪实现变体）。引擎思考档位真源是 describe 接口 `thinking_tiers`（Rust v2 单源）。

## 六、实施补充记录（真机验收发现，同轮修复）

### T7 Tooltip 克隆注入吞掉组件子元素内部点击链（用户原始抱怨「开关不能用」的真根因）

**现象（真机复现）**：`<Tooltip><Switch/></Tooltip>` 场景下，真实指针点击开关无任何反应（`aria-checked` 与 localStorage 双双不变）；直接调用 React props 链验证：`onCheckedChange` 正常、Switch 内部 `handleToggle` 永不被触达。

**根因（双层叠加）**：
1. `Tooltip.tsx` `cloneElement` **无条件**向子元素注入合成 `onClick: handleClick`；`handleClick` 只会链式调用「子元素**元素 props** 上的 onClick」——组件型子元素（Switch）的点击 handler 在组件内部而非元素 props 上，于是调用 `undefined`，点击被静默吞掉。原生元素子元素不受影响（其 props.onClick 就是真 handler），这解释了为何 Tooltip 包裹的 Button 一直正常。
2. `Switch.tsx` 渲染 `{...restProps}` 位于 `onClick={handleToggle}` **之后**——Tooltip 注入的 onClick 经 restProps 覆盖内部处理器，构成完整的「注入→覆盖→吞掉」链。

**修复（双侧防御）**：
- `Tooltip.tsx`：仅当「子元素 props 或外部 restProps」存在同名 onClick/onPointerDown 时才注入合成覆盖；两者皆无时不注入，子组件内部点击链原样保留。
- `Switch.tsx`：`{...restProps}` 前置，内部 `onClick={handleToggle}` 恒为权威（任何注入只能叠加不可覆盖）。

**真机复验**：指针点击 → `aria-checked` 翻转 + `crish_model_meta_v1` 落盘同步；停用当前活动模型 → 级联选择器同厂商自愈收敛（`muse-spark-1.3-contributor` → `glm-5.3`，未跨厂商），符合「审计 1」裁决。
