## 一、核心需求与问题全景

1. **思考等级全面英文呈现**：
   - 彻底废除“提供方默认”等生硬中文字样，统一为：`Default`, `Off`, `Minimal`, `Low`, `Medium`, `High`, `X-High`, `Max`；
   - 修复前端 `thinkingGear.ts` 漏读字段导致的思考等级蒸发 Bug，恢复真实思考档位展示。
2. **通用思考协议与外部自定义（去 AI 幻觉与去死绑定）**：
   - 清洗内置 catalog 中虚构的 `claude-fable-5` 等幻觉模型；
   - 抽象通用思考参数形态（`reasoning_effort`, `thinking_budget`, `thinking_level`, `qwen_enable_thinking`, `adaptive`）；
   - 确立正交三层能力解析（显式覆盖 ➔ 通配符规则 ➔ 协议预设模板），允许用户通过外部配置文件自主定义任意新模型的思考能力，支持 Anthropic 动态预算钳制不变量（Token Clamp）。
3. **外部配置文件热更新管线（Hot Reloading Pipeline）**：
   - 外部配置文件路径：`~/.conex/models.json`（全局）与 `<workspace>/.conex/models.json`（项目）；
   - 目录级防换 Inode 监听器（Parent-Directory Watcher），免疫 Windows 编辑器原子保存掉监听；
   - 基于 RCU（Read-Copy-Update）与 `arc_swap::ArcSwap` 架构，读操作零等待、零锁争用，热重载原子 CAS 指针替换；
   - 指数退避重试（防 Windows 独占锁与 0 字节截断）+ LKG 影子容灾（坏配置不崩溃、UI 精准告警并在修复后自愈）。
4. **模型名称智能自适应缩写（SADA-v2）**：
   - 解决 `muse-spark-1.2-contributor`、`sensenova-6.8-flash-lite`、`muse-spark-1.3-contributor` 超长且简单截断导致判别度全无的问题；
   - 核心分词模型：$\text{Brand} \oplus \text{EntropyKey} \oplus \text{Specifier}$；
   - 核心版本号（`1.2`, `1.3`, `6.8` 等）作为高信息熵锚点，**任何压缩态下 100% 绝对保留**；
   - 结合 CSS Container Queries (`@container`) 实现阶梯式平滑降级，纯 GPU 合成层渲染，零 JS 重排抖动（Zero-Thrashing）。
5. **纯英文思考等级与零浪费紧凑胶囊**：
   - 非思考模型彻底隐藏思考胶囊与分割线，100% 空间让渡给模型名称；思考模型显示微光图标 `[ 🧠 High ]`，悬停呈现全息英文规格。

## 三、分阶段实施路线图

### Phase 1：前端 Bug 根治与纯英文零浪费交互（立即可见收益）
1. **修复 `thinkingGear.ts`**：切到 Rust v2 单源 `thinkingTiers`，恢复真实思考档位选项；
2. **纯英文标准化**：替换所有 Label 为 `Default`, `Off`, `Minimal`, `Low`, `Medium`, `High`, `X-High`, `Max`；
3. **零浪费胶囊重构**：`ComposerFusedTrigger.tsx` 中非思考模型隐藏思考槽与分割线，100% 宽度让渡模型名。

### Phase 2：SADA-v2 模型名称智能自适应缩写引擎
1. **实现 SADA-v2 算法**：在前端工具层提取语义锚点，保证核心版本号不可收缩；
2. **CSS Container Query 接线**：在 `ChatHeaderControls.tsx` 与 `ComposerFusedTrigger.tsx` 应用容器查询，实现阶梯式降级。

### Phase 3：Rust 外部配置热更新管线（Hot Reloading Pipeline）
1. **引入 `arc_swap` 与目录级 Watcher**：实现 RCU 无锁读取与父目录原子重命名监听；
2. **实现指数退避读取器与 LKG 容灾**：保障 Windows 独占锁自愈与坏配置安全隔离；
3. **打通 Tauri IPC 广播**：实现 `catalog:reloaded` 与 `catalog:config-error`。

### Phase 4：通用思考契约真接线与内核去幻觉
1. **清理 `catalog.json` 虚构模型**；
2. **接线 `dialect.rs` 通用思考映射**，加入 Anthropic 动态预算钳制不变量（Token Clamp）；
3. **改造 `validate_reasoning_effort`** 消费动态 Catalog 实例。

### Phase 5：Tauri 真机全链路立体验证与全量测试
1. 在真实 Windows 环境编辑 `~/.conex/models.json`，保存即刻观察 UI 零重启刷新；
2. 窄屏拖拽验证 `muse-spark-1.2-contributor` 与 `muse-spark-1.3-contributor` 判别度 100%；
3. 跑通 Rust 与前端全量单测门禁。
