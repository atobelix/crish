# 实现轮执行纪律

- 任务按 `00-总方案.md` 顺序执行；不得以重要性、成熟度或难度删减效果。
- 每个实现者只改派发的代码文件域；发现任务外问题先报告主控，不扩展冲突文件域。
- 中文源码和文档使用 UTF-8 无 BOM；中文文本写入使用 `apply_patch`，修改后运行 `chinese-encoding-guard` 检查。
- Cargo 构建串行执行，避免共享 target 冲突；不得停止用户的桌面 dev server 或相关长运行进程。
- 主控统一复核并提交；子 Agent 不提交、不回撤。任何 Git 提交均使用限定路径的 `git commit --only`，禁止绕过 hook。
- 验收记录要列出命令、实际结果、未覆盖项与风险；静态类型检查不能代替行为回归。
