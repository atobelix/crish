## 1.1 四级状态拓扑物理分域模型 (Tier 1~4 State Scoping Architecture)

在原有代码实现中，`apps/crish-desktop/src/store/` 存在严重的「上帝对象（God Object）」反模式与「伪门面（Pseudo-Facade）」广播污染：

- `sessionStore.ts` 第 35 行通过 `export const useSessionStore = useLayoutStore;` 建立别名引用；
- `workspaceStore.ts` 与 `settingsUiStore.ts` 同样指向 `useLayoutStore`；
- 全局 20+ 个不同维度的状态全部寄生在同一个 Zustand 实例内部，共享同一个单一的 `listeners = new Set()` 事件总线。

## 1.2 独立 Zustand 实例与细粒度原子选择器契约 (Atomic Selectors)

### 1.2.1 物理独立 Store 实例构建

在 `apps/crish-desktop/src/store/sessionStore.ts` 中彻底销毁别名导出，使用独立 `create<SessionStore>()` 构建物理隔离的 Zustand 实例：

```typescript
// apps/crish-desktop/src/store/sessionStore.ts
import { create } from 'zustand';
import { immer } from 'zustand/middleware/immer';
import { withDevtools } from './middleware/withDevtools';
import { withPersist } from './middleware/withPersist';
import type { SessionState, SessionAgent } from './types';
import { createSessionActions, type SessionActions } from './sessionActions';
import { getSessionById as getSessionByIdFromIndex } from './sessionIndex';
import { sessionRuntimeRegistry } from '../api/SessionRuntimeRegistry';

export interface SessionStoreState {
  sessions: SessionState[];
  sessionsById: Record<string, SessionState>;
  folderOrder: string[];
  activeSessionId: string;
  draftFolder: string;
  activeAgentId: string | null;
  panelAgentId: string | null;
  composerDrafts: Record<string, string>;
  hydrationComplete: boolean;
}

export type SessionStore = SessionStoreState & SessionActions;

/**
 * 物理独立 SessionStore 实例 (彻底清除 autoIndexMiddleware 隐式全量重构)
 * 彻底消除与 layoutStore 的别名同体引用，独占单一事件总线与订阅者集合
 */
export const useSessionStore = create<SessionStore>()(
  withDevtools(
    withPersist(
      immer((set, get) => ({
        sessions: [],
        sessionsById: {},
        folderOrder: [],
        activeSessionId: '',
        draftFolder: '',
        activeAgentId: null,
        panelAgentId: null,
        composerDrafts: {},
        hydrationComplete: false,
        ...createSessionActions(set, get),
      })),
      { name: 'crish_session_store_v1' }
    ),
    { name: 'CrishSessionStore' }
  )
);
```

### 1.2.3 彻底废除 `autoIndexMiddleware.ts` 与会话索引原地维护

**中间件反模式病理深度解剖**：
在原有 Zustand 中间件设计中，`autoIndexMiddleware.ts` 存在极其严重的隐式副作用与性能缺陷：

1. **隐式全量扫描与 $O(N)$ 重建**：在 `autoIndexMiddleware.ts:27-37` 中，中间件柯里化包裹了 Zustand 的 `set` 函数。每次状态发生变化时，如果 `state.sessions !== prevSessions`，中间件在同步事件循环中全量遍历整个 `sessions` 数组，执行 `buildSessionsById(currentSessions)` 重建 Map；
2. **第二轮全 Store 广播风暴**：Map 重构后强制修改 state，触发**第二轮全局 Selector 广播**。在 AI 消息流式接收（Token 帧推进）时，单帧即触发 2 轮全站 Selector 重新求值，伴随 Immer 代理对象的剧烈颠簸；
3. **架构职责倒错**：会话的创建、删除、重命名等操作本就在 Action 内部明确发生，完全无需依赖外层中间件进行低效的黑盒引用比对。

**架构级废除与原地维护规约**：

1. **物理清退中间件资产**：
   - 执行 `git rm apps/crish-desktop/src/store/autoIndexMiddleware.ts` (-85 行)；
   - 执行 `git rm apps/crish-desktop/src/store/autoIndexMiddleware.test.ts` (-120 行)；
   - 严禁在任何独立 Store（如 `useSessionStore`）构造链中机械保留或重新引入 `withAutoIndex`！
2. **会话索引职责收敛为 CRUD Actions 原地增量更新**：
   - 会话创建（`createSession`）：在 Action 内部直接将新会话同时追加到 `draft.sessions` 并在 `draft.sessionsById[session.id] = session` 原地写入；
   - 会话删除（`deleteSession`）：在 Action 内部直接 `delete draft.sessionsById[sessionId]` 原地删除，并更新 `draft.sessions` 列表；
   - 会话消息流式写入（`appendMessage` / `updateMessage`）：通过 `getSessionForWrite(sessionId)` 精准定位单条 Session 对象并只修改其内部 `messages` 数组，**绝对不触碰与重建全局 `sessionsById` 映射，彻底杜绝无谓的全局引用变更与二次广播**。

## 1.4 会话专属 Diff 纯函数即时派生算法 (`selectSessionDiffFiles`)

### 1.4.1 全局 Git 状态越界入侵病理解剖

现有 `apps/crish-desktop/src/components/chat-card/useChatCardState.ts` 第 165 行通过 `const diffFiles = useTerminalField(selectDiffFiles);` 粗暴读取全局工作区的本地 Git 未提交变更。

### 1.4.2 纯函数派生算法实现

实现纯函数 `selectSessionDiffFiles(messages)`，严格基于当前会话实际执行过的 Tool Calls（`write_file`、`replace_file_content`、`multi_replace_file_content`、`apply_diff`、`edit_file`）计算修改产物：

```typescript
// apps/crish-desktop/src/api/sessionDiffDerivation.ts
import type { SessionMessage, FileDiff } from '../store/types';

/**
 * 纯函数：从指定会话的消息列表中即时派生该会话专属的文件变更清单
 *
 * @param messages 当前会话的消息历史数组
 * @returns 该会话产生的 FileDiff 数组
 */
export function selectSessionDiffFiles(
  messages: readonly SessionMessage[] | undefined
): FileDiff[] {
  // 1. 空态与空白消息历史快速短路返回空数组
  if (!messages || messages.length === 0) {
    return [];
  }

  const fileMap = new Map<string, FileDiff>();

  for (const msg of messages) {
    if (!msg.toolCalls || msg.toolCalls.length === 0) {
      continue;
    }

    for (const tc of msg.toolCalls) {
      const fnName = tc.function?.name || tc.name || '';

      // 仅拦截产生文件写入/变更的合法工具名称
      if (
        fnName === 'write_file' ||
        fnName === 'replace_file_content' ||
        fnName === 'multi_replace_file_content' ||
        fnName === 'apply_diff' ||
        fnName === 'edit_file'
      ) {
        try {
          const args =
            typeof tc.function?.arguments === 'string'
              ? JSON.parse(tc.function.arguments)
              : tc.function?.arguments || tc.arguments || {};

          const filePath =
            args.target_file ||
            args.TargetFile ||
            args.targetFile ||
            args.path ||
            args.file_path ||
            args.filePath;

          if (filePath && typeof filePath === 'string') {
            const existing = fileMap.get(filePath);
            const isCreation = fnName === 'write_file' && !existing;

            fileMap.set(filePath, {
              path: filePath,
              status: existing?.status || (isCreation ? 'added' : 'modified'),
              additions:
                (existing?.additions || 0) + (Number(args.additions) || 1),
              deletions:
                (existing?.deletions || 0) + (Number(args.deletions) || 0),
              hunks: existing?.hunks || [],
            });
          }
        } catch {
          // 安全容错：跳过参数解析异常的脏数据
        }
      }
    }
  }

  return Array.from(fileMap.values());
}
```

   ```typescript
   // apps/crish-desktop/src/components/chat-card/useBackgroundTaskPolling.ts
   export interface UseBackgroundTaskPollingOptions {
     sessionId?: string;
     enabled?: boolean; // 核心门闩控制
     onTasksUpdate?: (tasks: BackgroundTask[]) => void;
   }

   export function useBackgroundTaskPolling({
     sessionId,
     enabled = true,
     onTasksUpdate,
   }: UseBackgroundTaskPollingOptions) {
     useEffect(() => {
       // 当处于门闩拦截态 (enabled === false) 或无效草稿态时，彻底静默并不启动任何定时器
       if (!enabled || !sessionId || sessionId.startsWith('__pending')) {
         return;
       }

       let timer: number | null = null;
       const poll = async () => {
         try {
           const tasks = await listBackgroundTasks(sessionId);
           onTasksUpdate?.(tasks);
         } catch {
           /* 静默捕获 */
         }
       };

       timer = window.setInterval(poll, 3000);
       return () => {
         if (timer) clearInterval(timer);
       };
     }, [sessionId, enabled, onTasksUpdate]);
   }
   ```
