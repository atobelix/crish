# 一、 执行摘要与红队找茬缺陷全景矩阵

### 1.1 缺陷等级统计与总体裁决

经过红队联合审查组对全仓样式资产、组件代码、历史删除台账及 CI 门禁脚本的深度白盒穿透审计，**全仓收敛防回潮体系目前存在严重的「虚假繁荣」与「隐蔽回潮」**。现存主要矛盾在于：

1. **门禁规则大开后门**：CI 脚本 `check-frontend-convergence.mjs` 中为迎合通过率，在 Rule 4、Rule 5、Rule 6 中配置了极其宽泛的目录排除黑名单（如排除 `chat/`, `sidebar/`, `settings/`, `workspace/`, `src/styles/` 等），导致全仓 **564 处 `!important`** 与大量非法 Pill 药丸在门禁扫描中全部被掩盖，呈现虚假全绿；
2. **物理删除执行不彻底**：52 个法定删除文件中仍有 3 个核心文件（`workspaceLayoutStore.ts`、`WorkspaceCanvas.tsx`、`theme-dark.css`）实体滞留磁盘且被 Git 跟踪；同时 14 个已在 `index.css` 解除 `@import` 的全局样式表（共 **4,845 行**）未执行 `git rm`，沦为庞大的幽灵代码堆；
3. **关键算法与性能反模式**：Diff 虚拟滚动行稳定 Key 错误绑定局部索引 `localIdx`，导致用户滚动时 DOM 节点全量销毁与重建；后台任务轮询守卫存在逻辑后门，导致全局任务向独立会话渗透；
4. **代码卫生与编码腐化**：`tokens.css` 充斥硬编码 Hex 色值与 Tailwind 污染，CSS 注释存在大面积 GBK 乱码，且通过 290 行的 `css-encoding-whitelist.json` 进行挂账免检。

### 5.1 `check-frontend-convergence.mjs` Rule 12 换行漏检与正则绕过漏洞

在 `scripts/check-frontend-convergence.mjs` 中，Rule 12 (`runRule12_NoNativeTitle`) 的实现代码如下：

```javascript
// scripts/check-frontend-convergence.mjs:640-660
function runRule12_NoNativeTitle() {
  const tsxFiles = collectFiles(
    join(DESKTOP_SRC, 'components'),
    /\.tsx$/,
    /(\.test\.|\.spec\.)/
  );
  for (const file of tsxFiles) {
    if (file.includes('/ui/Tooltip.tsx')) continue;
    const content = readFileSync(file, 'utf8');
    const lines = content.split('\n');
    lines.forEach((lineText, idx) => {
      const trimmed = lineText.trim();
      if (trimmed.startsWith('//') || trimmed.startsWith('*')) return;
      if (
        /<(button|div|span|a|input|select)\b[^>]*\btitle=["'{]/i.test(lineText)
      ) {
        report(12, 'G-12', file, idx + 1, `禁止使用原生 HTML title 属性...`);
      }
    });
  }
}
```

#### 致命漏洞机制：

```tsx
<button

  title="关闭"
  onClick={onClose}
>
```

- 第 3 行 `title="关闭"`：不以 `<(button|div...)` 开头，正则判定不匹配！
- **结论**：任何通过 Prettier 格式化为多行的原生交互标签，只要 `title` 属性不在起始标签同一行，**100% 绕过 Rule 12 门禁拦截**！

# 七、 维度六：算法缺陷、虚拟滚动 DOM 震荡与会话隔离隐患

### 7.1 `DiffCardSplitView` 与 `UnifiedView` 拼接 `localIdx` 摧毁虚拟滚动 DOM 复用

在 `apps/crish-desktop/src/components/diff/DiffCardSplitView.tsx:166` 与 `apps/crish-desktop/src/components/diff/DiffCardUnifiedView.tsx:136` 中：

```typescript
// DiffCardSplitView.tsx:166 & DiffCardUnifiedView.tsx:136
// ❌ 违规代码：在 Key 中拼接 localIdx
const stableKey = `${f.filePath}-${left?.oldLine ?? 'x'}-${right?.newLine ?? 'y'}-${localIdx}`;
```

#### 致命性能机制分析：

- `localIdx` 代表当前可视视口内的**数组下标（0 ~ 30）**；
- 当用户向下滚动 1 行代码时，原先可视区第 2 行（`localIdx: 1`）的代码在下一帧变为第 1 行（`localIdx: 0`）；
- 此时该行生成的 `stableKey` 从 `...-localIdx: 1` 突变为 `...-localIdx: 0`；
- **React 认为所有可见节点的 Key 全部发生了变化，因此直接将视口内的全部 DOM 节点彻底销毁并重新创建（Mount/Unmount），而不是复用既有 DOM 节点！**
- 这直接导致虚拟滚动在长文档快速滑动时出现严重的 CPU 飙升与掉帧卡顿，彻底摧毁了虚拟滚动的核心复用价值。

### 7.2 `useBackgroundTaskPolling.ts` 过滤守卫逻辑错误导致无主任务渗透会话

在 `apps/crish-desktop/src/components/chat-card/useBackgroundTaskPolling.ts:56-60` 中：

```typescript
// apps/crish-desktop/src/components/chat-card/useBackgroundTaskPolling.ts:56-60
const list = (tasks || []).filter((t) => {
  const taskSessionId = (t as unknown as { sessionId?: string }).sessionId;
```

### 7.3 `sessionDiffDerivation.ts` 路径大小写分裂与虚假 `additions` 计数

在 `apps/crish-desktop/src/api/sessionDiffDerivation.ts:64, 72` 中：

```typescript

const normalizedPath = rawFilePath.replace(/\\/g, '/').replace(/^\/+/, '');
const isCreation =
  (fnName === 'write_file' || fnName === 'write_to_file') && !existing;
```

2. **虚假 `additions` 计数**：
   - 标准 `write_to_file` 或 `replace_file_content` 工具参数中并不携带 `additions` 字段；
   - 代码直接回退为 `|| 1`，导致任何一次文件写入操作都被粗暴记录为 `+1` 行，完全脱离了真实的 Diff 变更行数统计。
