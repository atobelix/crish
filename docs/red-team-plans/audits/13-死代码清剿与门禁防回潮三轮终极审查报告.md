### 4.2 致命层级倒挂：`--z-context-menu: 8500` 越权与 `--z-toast: 2000` 偏低

### 7.1 `DiffCardSplitView` 与 `UnifiedView` 虚拟滚动 Key 冲突隐患 (`:::`)

在 [`apps/crish-desktop/src/components/diff/DiffCardSplitView.tsx:166-168`](file:///c:/Software/conex/apps/crish-desktop/src/components/diff/DiffCardSplitView.tsx#L166-L168) 与 [`DiffCardUnifiedView.tsx:134-136`](file:///c:/Software/conex/apps/crish-desktop/src/components/diff/DiffCardUnifiedView.tsx#L134-L136) 中：

```typescript
const oldLine = left?.oldLine !== undefined ? String(left.oldLine) : '';
const newLine = right?.newLine !== undefined ? String(right.newLine) : '';
const stableKey = `${f.filePath}:${f.oldPath || ''}:${oldLine}:${newLine}`;
```

#### 致命缺陷分析：

- 当 Diff 包含没有明确行号的占位行、折叠摘要行、或者连续多行空行时，`oldLine` 与 `newLine` 均为空字符串 `""`；
- 此时生成的 `stableKey` 均为 `${f.filePath}:::`；
- 在同一个虚拟列表中，多个 DOM 节点拥有**完全相同的 React Key**！
- 导致 React 报出 `Warning: Encountered two children with the same key`，并在虚拟滚动复用时引发 DOM 状态错乱与闪烁。
