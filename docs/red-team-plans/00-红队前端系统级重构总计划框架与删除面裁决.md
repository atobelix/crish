### 1.1 冲突仲裁 1：浮层管理体系收敛 (LayerStackManager vs OverlayManager)

- **冲突事实**：Plan 01 设计了 `OverlayManager` 集中挂载弹窗，Plan 04 设计了 `LayerStackManager` 调度事件与 LIFO 退栈，存在平行状态机风险。
- **主控终审裁决**：**两层合一，单轨收敛**。
  - 底层核心为 **`LayerStackManager`**，独占掌管事件分发、LIFO 逐级关闭、50ms 冷却防重入锁、Branch 拓扑白名单与 `data-floating-active` 全局 Tooltip 静默广播；
  - 上层为轻量级 **`OverlayHost`**，通过命令式 `openModal()` 挂载高阶弹窗到 `#modal-root`，严禁在 `App.tsx` 顶层维护 `useState` 弹窗状态矩阵；
  - 彻底消除两套浮层栈的平行造轮。

---

### 1.2 冲突仲裁 2：通知能力全局解耦 (消除 `onShowToast` 跨层透传)

- **冲突事实**：Plan 08 建立了 `useToast()` Context 单例，但 Plan 01/06/07 的组件 Props 中仍保留了 `onShowToast`。
- **主控终审裁决**：**全仓 100% 物理清除 `onShowToast` 的 Prop-Drilling**。
  - `ToastProvider` 挂载于应用根节点；
  - 任何组件（包括 `ViewRenderContext`）需要弹出通知时，100% 直接调用 `const { showToast } = useToast();`；
  - 全仓所有组件 Props 接口与 `ViewRenderContext` 中物理删除 `onShowToast` 字段。

---

### 1.3 冲突仲裁 3：全局规格与物理尺寸统一标尺

- **主控终审裁决**：
  1. **顶栏高度**：全局主顶栏严格死锁为 **36px**（`--header-height: 36px;`），Diff/文件工具栏锁定为 **34px**，二叉树树项行高锁定为 **30px**；
  2. **Z-Index 标尺**：严格收敛至 7 级标准标尺（最大值 9000，`--z-tooltip: 9000`，`--z-modal: 1000`，`--z-dropdown: 300`），并在 `index.html` 预置 5 大独立 Portal 挂载点（`#popover-root`, `#modal-root`, `#tooltip-root`, `#toast-root`, `#drag-root`）；
  3. **同心圆角标尺**：全站阶梯严格锁定为 **12px (xl) / 8px (lg) / 6px (md) / 4px (sm) / 2px (xs)**，桌面端坚决执行 0-药丸铁律（除 Switch 轨道与 Avatar 外，禁绝 `9999px`）；
  4. **原子控件尺寸**：全仓统一为 **24px (xs) / 28px (sm) / 32px (md) / 40px (lg)** 四档，变体轴与尺寸轴职责绝对正交。

---

### 1.4 审计裁决 4：`crish_workspace` 存储键双语义清洗与项目 CWD 绝对保护

- **冲突事实**：`crish_workspace` 键被 `createSsrGlobals.ts:26` 滥用为判断是否降级回退到旧 columns 布局的开关，同时被 `projectStore.ts:23` / `clientApi.ts:658` 作为当前打开项目的本地工作目录绝对路径（CWD）。
- **主控终审裁决**：**精准清理模式读取，绝对保留 CWD 语义**。
  - 从 `createSsrGlobals.ts` 中彻底删除 `workspaceKind` 字段、`localStorage.getItem('crish_workspace')` 模式读取与 `isTreeWorkspaceFast()` 函数；
  - `App.tsx` 100% 直挂 `<BinaryTreeWorkspace />`；
  - 严格保留 `projectStore.ts` 与 `clientApi.ts` 对 `crish_workspace` 作为项目根路径的合法存取；
  - 门禁规则精确定位至 `createSsrGlobals.ts` 与 `App.tsx`，严禁全仓盲目清零导致项目 CWD 丢失。

---

### 1.5 审计裁决 5：`autoIndexMiddleware` 彻底废除与索引维护原地增量化

- **冲突事实**：`autoIndexMiddleware.ts` 在每次 store set 时全量扫描重建 `sessionsById` 并触发二次广播；红队独立方案中存在机械复活 `withAutoIndex` 的回潮风险。
- **主控终审裁决**：**物理删除中间件，原地增量维护索引**。
  - 彻底物理删除 `store/autoIndexMiddleware.ts` 与 `store/autoIndexMiddleware.test.ts`；
  - 独立 `useSessionStore` 实例严禁包裹 `withAutoIndex`；
  - 会话增删改等结构性 Action 显式维护 `sessionsById`，流式 Token 更新通过 `getSessionForWrite` 精准修改单个会话，禁止触发全量索引重算与二次广播。

---

### 1.6 审计裁决 6：`file-viewer` 结构化 `viewParams` 与全局可变 Map 清剿

- **冲突事实**：历史实现通过 `file-viewer:${filePath}` 字符串拼接与全局可变 `fileViewerInitialModeMap` 旁路传参，导致内存泄漏与多实例状态污染。
- **主控终审裁决**：**结构化 `ViewInstance` + 原生持久化**。
  - 建立 `ViewInstance { viewInstanceId: string, viewId: string, viewParams?: Record<string, unknown> }` 完备契约；
  - `FileViewerCard` props 显式接收 `filePath` 与 `initialMode`；
  - 物理删除 `openTool.ts` 中的 `fileViewerInitialModeMap` 与 `storeAccess.ts:254` 脏导出；
  - `viewParams` 随二叉树布局 JSON 序列化落盘与水合。

---

### 1.7 审计裁决 7：`TerminalCard` MutationObserver 彻底拔除与单源尺寸收敛

- **冲突事实**：`TerminalCard.xterm.tsx:491-499` 挂载 `document.body` 的 `MutationObserver` 监听 `class` 属性，全站任意 UI 变动均触发昂贵的终端 `scheduleFit()` 与跨进程 Tauri PTY resize IPC。
- **主控终审裁决**：**彻底拔除 DOM 监听，100% 收敛至 ResizeObserverManager**。
  - 物理删除 `TerminalCard.xterm.tsx` 中的 `MutationObserver` 监听代码与 cleanup；
  - 终端容器尺寸统一接入单例 `ResizeObserverManager`，在分屏拖拽手势期间由 `layoutAnimationStore` 统一挂起，拖拽 settle 后单次触发 fit 计算。

---

### 1.8 审计裁决 8：`WorkspaceEmptyState*` 资产确权与旧列式精细剥离

- **冲突事实**：蓝队方案误将 `WorkspaceEmptyState*` 判定为旧列式死代码而整组删除，导致 44+ 块工作区（NotePaper）单测与核心产品资产险遭损毁。
- **主控终审裁决**：**刚性确权核心资产，精细剥离旧列式胶水**。
  - 刚性确权 `WorkspaceEmptyState` 为 W5-B 块工作区核心资产与 44+ 单测守护的 Strict 宿主，严禁误删；
  - 仅剥离旧列式宿主独占胶水代码，装配 `!onEmptySurface` 门闩，保持与二叉树容器无缝集成。

全案重构必须 100% 通过专有门禁脚本 `scripts/check-frontend-convergence.mjs`（挂载于 `npm run check:desktop` 与 Git pre-commit）：

1. **[G-01 业务层零裸标签]**：业务层 TSX 严禁直接书写 `<button>`, `<input>`, `<textarea>`, `<select>`，100% 消费 `@/components/ui`（Primitive Bridge 严格白名单）；
2. **[G-02 浮层零 cloneElement 与零 stopPropagation]**：Menu 严禁使用 `cloneElement` 劫持触发器，严禁 `stopPropagation()` 截断全局事件流；
3. **[G-03 零裸 RO / 零 window.resize / 零 0px 回流]**：严禁裸 `new ResizeObserver`，严禁业务层监听 `window.resize`，严禁 `height='0px'` 强制回流与 `flushSync`；
4. **[G-04 零非白名单 9999px 药丸圆角]**：除 Switch 轨道、Avatar 与 PulseDot 白名单外，CSS/TSX 严禁使用 `9999px` / `radius-full`；
5. **[G-05 零废弃 Z-Index / 零裸数字 / 零内联 zIndex]**：彻底清退 26 个废弃 Token 与裸数字（>0），100% 收敛至 7 级标准 Token（封顶 9000）；
6. **[G-06 业务样式零 `!important`]**：业务 CSS 模块 `!important` 100% 清零，仅保留无障碍与拖拽光标系统级白名单；
7. **[G-07 入口 index.css 零废弃样式表引入]**：`index.css` 严禁引入任何 `settings/`, `panels.css`, `shell/`, `chat.css` 废弃样式表；
8. **[G-08 视图分发零 `switch(panelId)` 与零字符串前缀解析]**：`TreeLeafPanel.tsx` 100% 声明式经由 `ViewRegistry` 渲染；
9. **[G-09 状态层零伪门面别名同体与零 `autoIndexMiddleware`]**：`useSessionStore` 必须物理独立，彻底删除全量扫描中间件；
10. **[G-10 会话空态零全局 Git / 状态渗透]**：Diff 计数 100% 由 `selectSessionDiffFiles(messages)` 纯函数派生，动态胶囊必须受 `!onEmptySurface` 刚性门闩拦截。
