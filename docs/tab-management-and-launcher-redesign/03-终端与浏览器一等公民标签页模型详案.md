# 分维详案 03：终端与浏览器一等公民标签页模型详案

> **文档位置**：`docs/tab-management-and-launcher-redesign/03-终端与浏览器一等公民标签页模型详案.md`  
> **所属战役**：顶栏标签管理与加号启动器重构战役  
> **设计原则**：一等公民判别联合、动态视图解耦（G-08 遵从）、路径强绑定、进程确定性析构

---

## 1. 目标与范围

将终端（Terminal）与浏览器（Browser）从既有的侧边抽屉或辅助面板升级为二叉树布局（`LayoutTree`）中的一等公民标准标签页，支持与聊天标签无缝混排、同级切换、以及四方向几何分屏。

---

## 2. 核心架构设计

### 2.1 判别联合数据模型（`UnifiedTab`）
在 `sessionTabModel.ts` 中定义：
```typescript
export type TabKind = 'chat' | 'terminal' | 'browser';

export interface BaseTab {
  readonly tabId: string;
  readonly title: string;
  readonly workspaceKey?: string;
  readonly dock?: Partial<RightToolDockState>;
}

export interface ChatTab extends BaseTab {
  readonly kind: 'chat';
  readonly sessionId: string;
}

export interface TerminalTab extends BaseTab {
  readonly kind: 'terminal';
  readonly terminalKey: string;
  readonly cwd: string;
}

export interface BrowserTab extends BaseTab {
  readonly kind: 'browser';
  readonly url: string;
  readonly favicon?: string;
}

export type UnifiedTab = ChatTab | TerminalTab | BrowserTab;
```

### 2.2 动态叶子分发与 ViewRegistry 接入（G-08 合规）
- 遵从 `check:convergence` 规则 G-08，严禁在 `TreeLeafPanel.tsx` 编写死静态 `switch(kind)`，而是通过声明式视图适配器：
  ```typescript
  export function resolveTabView(tab: UnifiedTab): { viewId: string; context: Record<string, unknown> } {
    if (tab.kind === 'terminal') {
      return { viewId: 'terminal', context: { terminalKey: tab.terminalKey, cwd: tab.cwd } };
    }
    if (tab.kind === 'browser') {
      return { viewId: 'browser', context: { url: tab.url, favicon: tab.favicon } };
    }
    return { viewId: 'chat', context: { sessionId: tab.sessionId } };
  }
  ```
- 窗格中统一通过 `<SlotOutlet slotKey="workspace.leaf.panel" />` 动态挂载对应的 `ChatCard`、`TerminalCard` 或 `BrowserCard`。

### 2.3 终端路径绑定与 PTY 进程治理
- **项目路径绑定**：创建终端时提取当前激活工作区根路径 `cwd = getWorkspacePath()`，作为 PTY 初始化上下文；
- **资源确定性回收**：当用户点击 `closeTab` 关闭终端时，前端释放 xterm / WebGL 实例，后端通过 IPC `workbench_pty_kill` 终止 PTY 进程，并由操作系统的 Job Object 确保子 Shell 彻底退出，无僵尸进程。

### 2.4 浏览器导航与 Favicon 动态映射
- 默认提供本地开发导航页（自动感知 `localhost:3000/5173` 等开发服务器）；
- 复用 `ToolTabFavicon.tsx` 基建，提取网站 Favicon 与标题，自适应更新 Tab 项。

---

## 3. 验收断言

- 支持 Chat、Terminal、Browser 三类标签混排在同一叶子中并顺畅切换；
- 拖拽 Terminal 标签至下边缘，成功分出上下分屏并在下半屏渲染终端；
- 终端进程在 Tab 关闭后从系统进程树中彻底销毁。
