## 1. 战役背景与用户核心诉求（REQ）

1. **就地切换复用，杜绝标签无限滋生**：
   - 现状痛点：点击左侧列表对话时，顶栏就会无节制新开标签，导致用户只想切换对话时标签栏迅速挤满，极不利于管理；
   - 目标：用户不点加号/快捷键/拖拽时，点击左侧列表一律在当前活动标签中**就地切换复用**（In-Place Switch），顶栏标签数量保持恒定。
2. **显式创建标签与拖拽分屏**：
   - 只有用户使用快捷键（`Ctrl/Cmd+T`、`Ctrl/Cmd+N`）、主动点击标签栏“加号 `+`”按钮、或将左侧对话拖拽到顶部标签栏/分屏区域（上/下/左/右）时，才创建新标签或切分窗格。
3. **加号 “+” Popover 综合启动器（New Tab Quick Launcher）**：
   - 点击顶部加号弹出一个精致、高信息密度的 Popover 菜单界面，提供 5 大功能区：
     - **① 创建新对话**（空白对话落地）；
     - **② 运行中对话快速导航**（若后台有正在生成/工具运行但不在当前标签的会话，列出并支持一键直达）；
     - **③ 新建 Terminal 终端标签**（一等公民标签页，自动定位至当前项目/工作区默认路径）；
     - **④ 新建浏览器标签**（一等公民标签页，提供内置网页与预览功能）；
     - **⑤ 常用国际项目预置/模板**（位于底部，快速开启经典模板或项目）。
4. **多 Agent 方案优中选优机制**：
   - 派发多个专业 Agent 分别探索与推导不同维度的技术架构与交互方案；
   - 设立评选/评审 Agent（Jury Agent），对多种备选方案进行客观矩阵评分，优中选优，推导出最纯粹、最优雅的最终实现方案。
