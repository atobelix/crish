> **所属战役**：顶栏标签管理与加号启动器重构战役  
> **设计原则**：标签数量守恒律、浏览就地复用、显式增生机制

---

## 1. 目标与范围

重构 `workspaceShellStore.openSession`、`useLayoutTreeStore` 以及侧边栏会话点击逻辑，彻底根除“点击侧栏对话顶部无界追加 Tab”的历史缺陷。

---

## 2. 精确改动明细

### 2.1 workspaceShellStore 与 LayoutTree 重构
1. **重写 `openOrFocusSession` 状态流**：
   ```typescript
   openOrFocusSession: (sessionId, opts) => {
     const sid = (sessionId || '').trim();
     if (!sid || isPendingDraft(sid)) return;

     const treeStore = useLayoutTreeStore.getState();
     const existingLoc = treeFindTabBySessionId(sid);
     
     // 分支 A：会话已在树中打开 -> 直接激活并聚焦该 Tab（跨窗格自动切叶）
     if (existingLoc) {
       treeActivateTab(existingLoc.leafId, existingLoc.tab.tabId);
       rememberChatLeaf(set, existingLoc.leafId);
       useSessionStore.getState().setActiveSessionId(sid);
       syncSessionFromActiveLeaf(existingLoc.leafId);
       return;
     }

     const targetLeaf = resolveActiveChatLeaf(get().lastChatLeafId);

     // 分支 B：当前叶处于草稿态 (activeTabId === '') -> 平滑物化草稿槽
     if (targetLeaf.activeTabId === '') {
       treeStore.materializeDraftSession(targetLeaf.id, sid, {
         title: resolveSessionTabTitle(sid, opts?.title),
         workspaceKey: canonicalSessionFolder(opts?.workspaceKey),
       });
       return;
     }

     // 分支 C：就地替换模式 (In-Place Reuse) -> 原地替换当前活动 Tab 会话指向
     treeStore.replaceActiveSessionInLeaf(targetLeaf.id, sid, {
       title: resolveSessionTabTitle(sid, opts?.title),
       workspaceKey: canonicalSessionFolder(opts?.workspaceKey),
     });
     
     rememberChatLeaf(set, targetLeaf.id);
     useSessionStore.getState().setActiveSessionId(sid);
     syncSessionFromActiveLeaf(targetLeaf.id);
   }
   ```
2. **新增原子树操作算子（`layoutTreeTransform.ts`）**：
   - `replaceActiveSessionInLeaf(leafId, newSessionId, meta)`：保持该 Tab 的 `tabId` 原位不动，原子修改 `sessionId`、`title`、`workspaceKey`；
   - `materializeDraftSession(leafId, sessionId, meta)`：将虚拟草稿物化为真实会话 Tab 并激活。

### 2.2 显式创建与拖拽分屏支持
- **加号与快捷键**：点击加号或按快捷键显式调用 `addTab`，方才推入新草稿或新标签；
- **拖拽至标签条**：保持现有 `reorderSessionTab` / `insertTab` 语义，放置到 TabStrip 时插入新标签；
- **拖拽至边缘分屏**：保持现有 `splitSessionFromSidebar`，根据 `top` / `bottom` / `left` / `right` 4 区域优雅切分二叉树窗格。

### 2.3 后台流式输出解耦
- 切走当前正在流式生成的会话时，**严禁发送 cancel 信号**；
- 后台继续正常接收网络或进程流，通过 `sessionStore.sessionsById[sid].messages` 实时入库，侧栏保留转动呼吸微光。
