## 1. 维度目标与验收断言

### 1.1 目标

子代理的「显式恢复与关闭」决策面完整闭环,覆盖用户新增诉求的三条路径:

1. **接管继续**:主 agent 收到子代理失败通知后不重派、下一轮自己继续输出——机制已成立,本轮文档化确认并补齐通知信息完整性(裁决 #16,01-敲定方案.md:30);
2. **关闭重来**:主 agent / 用户可**单目标**关闭子代理(kill_subagent,裁决 #15,01-敲定方案.md:29)或**批量**关闭(kill_all),再经 resume / run_subagent 重派;
3. **重派恢复**:resume_subagent(关闭+重派合体,引擎侧已实现)与 kill_all 翻注册为 Tauri 命令面(双端四步),成为 UI 与主 agent 工具面的正式入口。

配套:wait 声明持久化 MemoryWaitStore → LocalDb 真适配(dispatch_* 键形状已冻结);命令面同步 SQLite 全走 spawn_blocking(F2-27,selection-02 §2.5)。

### 3.2 kill_subagent(单目标)命令设计

**lifecycle.rs 新增(约 50 行,selection-02 §4.3-2 评估 40-60 行)**:

```rust
/// 单目标终止结果(三态:已终止 / 已终态幂等 / 未投递汇总)
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
pub struct KillSubagentResult {
    pub subagent_id: String,
    pub subagent_run_id: String,
    /// killed = L3 强停投递成功 + 行归一 failed
    /// already_terminal = 行非 running(失败/完成),无动作(幂等)
    pub outcome: &'static str,          // "killed" | "already_terminal"
    pub force_cancel_delivered: bool,   // killed 时 L3 是否实际投递(引擎无运行实例=false)
}

/// 新增方法(挂 SubagentLifecycleService impl)
pub fn kill_subagent(
    &self,
    session_id: &str,
    subagent_id: &str,
    reason: &str,
) -> Result<KillSubagentResult, LifecycleError> {
    let reason = if reason.trim().is_empty() { "kill_subagent" } else { reason };
    // ① 定位:会话内 (session_id, agent_id) 主键,至多一行;缺行 → NotFound
    let rows = self.db.load_session_agents(session_id).map_err(db_err)?;   // agents.rs:44
    let Some(row) = rows.iter().find(|a| a.id == subagent_id) else {
        return Err(LifecycleError::NotFound { message: ... });
    };
    // ② 已终态 → 幂等 no-op(不投递、不强写 ended_at,保留终态审计事实)
    if row.status != "running" {
        return Ok(KillSubagentResult {
            outcome: "already_terminal",
            force_cancel_delivered: false,
            .. /* subagent_id / subagent_run_id */
        });
    }
    // ③ L3 强停投递(复用 ForceCancelSink,同 kill_all:189-203)
    let delivered = self.control.request_force_cancel(&row.subagent_run_id, reason);
    // ④ 行归一 failed(复用 mark_row_failed,lifecycle.rs:328-348)
    self.mark_row_failed(session_id, &row.subagent_run_id)?;
    Ok(KillSubagentResult { outcome: "killed", force_cancel_delivered: delivered, ... })
}
```
