## 3. 接线时序约束(实现时必须遵守)

1. **阶梯 1 = 收口后重派**:原 run failed(reason=recovery-retry)→ 预算内 spawner 重派新 run(mode=recovery-retry)→ 不消费 Episode 预算、无 steering 通知。禁止按「重试不置 failed」注释字面接线。
2. **D1+D2 同批**:stream_error.rs 的退避/熔断/provider_error 填充 + decide_idle_resume 的 error 分支一次改完;禁止分批串行(退避未接时 error 续 run 会在跨 run 层面复现「快速连打」风暴)。
3. **D2 与 D5 同区接线**:decide_idle_resume :2513 区域一次改完(error 分支 + goal_pending 分支并存);error 轮不计 goal stalled;用户停止(Stopped/Aborted)永不误放行。
4. **事件登记集中**:禁止按维度分两次改 events.rs。
5. **F2-27 spawn_blocking 全表**:RecoveryCoordinator::new + persist_* ×4 + on_subagent_run_failure 内部 + restore_steering_notifications + kill_all/resume/kill_subagent 命令面 + goal_state/provider_fail_streak 读写 + store 真适配调用面——全部走 spawn_blocking(先例:session_commands.rs:269-288、core_run_commands.rs:2958 save_run_usage)。
6. **同文件串行**:core_run_commands.rs(10278 行,全部维度汇聚面)派单按文件互斥;stream_error.rs 单批。

## 4. 红线(不可谈判)

1. 12/5/1 递归守卫只增不减;恢复路径 fork 显式走 spawn 守卫;嵌套禁令不变。
2. 用户显式停止(Stopped/Aborted/abort_signal/user_touched)永不自动续。
3. 子代理 interrupted 只通知不自动 fork(自动重派违反「所有子 Agent 由主 Agent 分配」)。
4. 测试资产门禁:recovery.rs 24 单测 + 4 集成测试 37 用例作回归面;markdown-editor 门禁与 5 个专项 spec 不受影响;禁止 --no-verify 绕门禁。
5. 探索类文档配额不绕过(fork 沿用同 session_id 自动延续)。
6. 禁止假接线/占位实现后再二次接线。
