## 4. 改进建议

1. **装配三工具通道（最高优先）**：生产 BuiltinToolConfig 补 subagent_kill_channel（包装 lifecycle service 的 kill_subagent）、subagent_inject_channel + main_agent_message_channel（以真 ControlBusResolver 替换 Noop，engine.rs:1294 同区）——与 subagent_wait_channel（engine.rs:1357）同模式，一次装配四通道闭环。
2. **补端到端回归**：Error 分支恢复条目 → 拉起 run 全链路（预算/退避/熔断/重启 restore_steering_notifications）增加壳层集成测试（现 decide_idle_resume 四源单测 :10549+ 已全，Error 面建议补跨 run 断言）。
3. **口径标注**：在最终文档标注「kill_subagent/send_message 工具=契约+单测就绪，生产通道待装配」，避免与命令面混淆。
4. **前缀不变性回归**：将「继续任务」固定串与 kind 解耦纳入测试断言（对齐 :4432 E1 模板已绑定先例），锁住 §9.2 缓存亲和。
5. **W2 补审**：resume_subagent 三态继承 + Episode 预算 + 幂等作为下一轮审计项排期。
