## 一、五大核心落地领域维度确立

经过对 3 份独立提案的交叉验证，正式确立 Conex 下一代流式 Markdown 架构的 5 大领域维度：

### 1. 维度一：极速吞吐与速率自适应调度域（Throughput & Rate-Adaptive Scheduling）
- **核心概念**：$5 \sim 2000+\text{ tokens/s}$ 全速率自适应不变性调度器。
- **唯一主路径**：`SlidingWindowRateEstimator (SW-TRE)` + `AdaptiveAnimateTimeline` + 纯 GPU CSS 变量交错动画（低速微步淡入，高速 $\ge 300\text{ t/s}$ 自动切入 TURBO 宏块无 Span 零分配追加）。
- **删除面（DEL）**：
  - 彻底删除任何纯 JS `setInterval` 逐字 `setState` 反模式代码；
  - 彻底删除单体追加组件 `StreamingTextBlock.tsx` 及单测；
  - 移除 `useStreamBatchers.ts` 中死引用 `renderBufferRef`。

---

### 2. 维度二：渐进词法分块与无缝双缓冲晋升域（Progressive Chunking & Double-Buffered Promotion）
- **核心概念**：$O(1)$ 增量边界分块与绝对零骨架屏（Zero-CLS）双缓冲晋升。
- **唯一主路径**：基于行前缀和的 `IncrementalBlockSplitter` + `Remend` 投机未闭合语法补全 + 语义哈希稳定 Key（`${msgId}-blk-${hash}`）+ 原地纯文本 DOM 垫片双缓冲晋升。
- **删除面（DEL）**：
  - 彻底物理删除 `AsyncMarkdownBlock.tsx`、`AsyncMarkdownBlock.module.css` 及单测（彻底销毁 `.skeletonLine` 骨架屏闪烁源）；
  - 物理删除 `parseMarkdownIntoBlocks.ts` 中未调用的死导出 `hasIncompleteCodeFence` 与 `hasTable`；
  - 彻底删除 `hasFootnote` 粗暴退化单块的自杀式逻辑；
  - 清除 `openTagPatternCache` / `closeTagPatternCache` 无界 Map 缓存。

---

### 3. 维度三：流式表格排版与视口锚定稳定域（Streaming Table & Viewport Anchor Stability）
- **核心概念**：GFM 表格流式中间态语法保护、列宽防抖与自适应吸底滚动。
- **唯一主路径**：表格定界行 DFA 状态机（首字锁定 Table 布局）+ `hasTable` 末尾 Caret 自动隐藏 + 8px 容差 `usePinnedScroll` 双向吸底锁定 + `table-layout: fixed` 容器查询。
- **删除面（DEL）**：
  - 彻底删除表格流式期间生成段落 `<p>` 标签导致的二次突变 DOM 重建代码；
  - 移除表格单元格内部裸插光标导致的布局畸变。

---

### 4. 维度四：自定义 HTML 组件流式渲染与沙箱域（Custom HTML & Streaming Artifacts Sandbox）
- **核心概念**：CommonMark HTML 块穿透、未闭合组件即时流式呈现与 React 沙箱挂载。
- **唯一主路径**：`preprocessCustomTags` 空行三明治规范化 + `normalizeUnclosedOpenTags` 流式即时中断 + React Portal 沙箱挂载（`<widget-diff>`, `<file-tree>`, `<ai-card>`）。
- **删除面（DEL）**：
  - 彻底物理删除沉浸式思维链弹窗全套套娃残留（`FullThoughtModal.*`, `ThoughtOutline.*`, `ThoughtSearchBar.*`, `thoughtWorker.*`, `thoughtInspectorStore.*` 15 个文件）；
  - 彻底删除 `TimelineThoughtSection.tsx` 与 `ChatMessageRow.module.css` 中的全屏放大按钮、字数统计与遮罩层；
  - 彻底物理删除 `api/markdown-render/IncrementalMarkdownParser*` 历史手写解析器死代码包（1,500+ 行）。

---

### 5. 维度五：多轮生命周期单源收敛与时间线幂等域（Message Lifecycle & Turn-Idempotent Timeline）
- **核心概念**：单生产者状态机与基于 `(turnIndex, type, id)` 三元槽位的确定性无损合并。
- **唯一主路径**：`onMessageDelta` 唯一增量入口 + `onMessageEnd` 权威快照覆盖 + 三元槽位 `reconcileAssistantMessageBlocks` + 顶层 `ErrorMessageBanner` 永不吞噬。
- **删除面（DEL）**：
  - 彻底删除 `onMessageEnd` 中 `prevLen` 切片差额二次注入代码（根除千字重复）；
  - 彻底删除 `sessionMessageActionsTools.ts` 中的二次冗余 `reconcileAssistantMessageBlocks`；
  - 彻底删除 `continuityUiStore.ts` 中的禁令 9 违规项 `circuitBanners`；
  - 将超标文件 `timelineNormalizer.ts`（616 行）拆分模块化，单文件行数严格控制在 $\le 300$ 行以下。
