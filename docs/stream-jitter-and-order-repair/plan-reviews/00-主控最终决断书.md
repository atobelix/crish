## 二、六份评审报告审议与逐项裁决

### 1. 审议 Review 01（效果锁与意图守护）

- **采纳项 1.1**：确定增量单元快照树 `lockedUnitsRef` 为第一真源透传，禁止逐字全量 `toHtml()`。
- **采纳项 1.2**：坚决统一采纳 Plan 04 的 Hook 实例代际令牌，彻底否决 Plan 05 的全局变量 `let isProgrammaticScrolling`。
- **采纳项 1.3**：补全多标签分屏保活（`WorkspaceShellStore.openTabs` 标签感知三级保活），纳入 Wave 1。
- **采纳项 1.4**：存量脏历史会话自愈逻辑纳入 `sessionRustDbHydrate.ts`。

### 2. 审议 Review 02（架构收敛与删除面）

- **采纳项 2.1**：消灭双头调度器，统一收口至 `sessionActivateHydrate.ts:triggerSessionMessageHydrateIfNeeded`，严禁新建 `sessionHydrationCoordinator.ts`。
- **采纳项 2.2**：全战役刚性执行《物理级硬性删除清册》：
  - 彻底切除 `MessageToolCallsSection.tsx` 私有 RO、`virtualScrollManager` prop、`invalidateActual` 调用及 `ProcessItemRenderer` 透传；
  - 物理删除 `useVirtualScroll.ts` 中 `setActual` 的 `bumpGestureEpoch` 续期调用；
  - 物理删除 `messageOrderKey.ts` 旧三元组与裸字典序回退；
  - 物理删除 `sessionEventProjection.ts` 盲目回退 `Date.now()` 的老旧实现；
  - 物理剔除 Plan 03 的死类草案 `FrameCoalescingScheduler`。
- **采纳项 2.3**：坚决否决 Plan 06 的魔术序列号 `syntheticSequence = 1000000 + eventIndex`。
- **采纳项 2.4**：几何容差常量集中收口至 `virtualScrollConstants.ts`。

### 3. 审议 Review 03（跨层连通与代码证据）

- **采纳项 3.1**：纠正事件类型：全仓不存在 `message-create` 事件，仅有 `message-start`, `message-delta`, `message-end`。
- **采纳项 3.2**：时间戳字段层级确认：`event.message.createdAt`（ISO 8601 字符串），顶层无 `timestamp`。在 `sessionEventProjection.ts` 中解析为权威时间戳。
- **采纳项 3.3**：在 `store/types.ts` 的 `SessionMessage` 中补齐 `engineSequence?: number` 声明。
- **采纳项 3.4**：修复会话水合卫语句：必须以 `messagesHydrated === true` 作为已水合标志，允许空会话合法结束，杜绝无限死循环拉取。

### 4. 审议 Review 04（并发时序与状态机）

- **采纳项 4.1（重大死锁 C1 修复）**：在懒水合协调器中，当高频切换同会话（A -> B -> A）时，将 `bumpSessionToken` 移至 `inFlightMap` 未命中分支之后，彻底消除同会话复用 Promise 导致的永久骨架屏白屏死锁。
- **采纳项 4.2（重大状态机漏洞 C2 修复）**：补全 MarkdownBlockItem 在取消流式（Abort）时的状态机闭包，增加隐式封口封闭律：
  ```typescript
  const isEffectivelySealed =
    isSealed || (!isStreaming && Boolean(lockedUnitsRef.current));
  ```
- **采纳项 4.3（令牌早泄 C3 修复）**：加固 `performProgrammaticScroll` 令牌生命周期，改用“单次事件消费自销毁 + 双帧兜底超时”，防止单帧哨兵早泄引发手势误判。
- **采纳项 4.4**：在 Web Worker 解析层增加批次丢弃协议（Backpressure Coalescing），防止慢解析积压。

### 5. 审议 Review 05（防御性测试与立体门禁）

- **采纳项 5.1（行数门禁阻断硬修复）**：`sessionEventProjection.ts`（有效行 348，门禁基线 350）前置拆离外置模块 `apps/crish-desktop/src/api/sessionEventTimestamp.ts`，主文件行数压降至 $\le 320$ 行，严禁触碰 350 行红线！
- **采纳项 5.2**：`useVirtualScroll.ts`（295行）与 `sessionRustDbHydrate.ts`（337行）进行纯逻辑辅助函数外置拆分（`useVirtualScrollGesture.ts` / `sessionHydrationMessages.ts`），严守 340 行预警线。
- **采纳项 5.3**：在 `VirtualScrollManager.setActual` 增加 `if (!Number.isFinite(h) || h < 0) return;` 刚性守门，并在单元测试中覆盖 NaN 与负数魔鬼用例。
- **采纳项 5.4**：Wave 4 验收与 DoD 中显式恢复 `reference/markdown-editor` 门禁（`npm test`）与 5 大 Markdown E2E 专项 spec。
- **采纳项 5.5**：修复 S-CLS 探针脚本算法，过滤正常流式向下的增量延伸，仅针对反向位移计算抖动。

### 6. 审议 Review 06（执行拓扑与文件域排他）

- **采纳项 6.1**：解除 Wave 2 与 Wave 3 内部同文件竞争，锁定严格互斥的 5-Agent 交付矩阵。
- **采纳项 6.2**：更正物理路径拼写错误：`apps/crish-desktop/src/api/session-persistence/sessionHydrationMessages.ts`。
