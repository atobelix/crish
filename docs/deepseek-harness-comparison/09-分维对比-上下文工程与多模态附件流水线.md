## 二、架构设计与机制对比

### 1. 多模态与超长附件处理
- **DSH**：专注于通用多模态图片、文件附件的类型安全抽象与流式投递。
- **Conex**：自研了极度严格的 Head-Tail 首尾截断算法，对超长日志与大文件注入进行 Token 预算硬性钳制，防止上下文爆仓。

### 2. 优劣裁判
- **DSH 优势**：多模态附件模型抽象更标准化，支持更通用的文件类型。
- **Conex 优势**：代码开发场景下的防爆护栏、Token 预算控制和检索召回更加硬核。
