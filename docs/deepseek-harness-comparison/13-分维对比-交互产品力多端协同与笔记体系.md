## 二、架构设计与机制对比

### 1. 产品力与端侧外延
- **DSH**：
  - 核心定位于“智能体框架（Harness）”，UI 部分相对偏向标准的 Web 演示台和 Electron 壳封装，强调配置项（Settings Card）的插件化注册。
- **Conex**：
  - 核心定位于“次世代 AI 开发者超级工作台”，在产品外延上做了大量创新：
    1. **Composer 输入体验**：类似 Cursor 的极速悬浮输入、精确 Token 预算感知、斜杠命令系统；
    2. **多端互联体系**：局域网内 PC 与移动端配对，TLS 证书固定通信，随时从手机查看与接管桌面 Agent；
    3. **自研笔记与文档系统**：将 Agent 思考输出与本地知识库（Note Runtime）深度绑定，集成专业级 Markdown 编辑器。

### 2. 优劣裁判
- **裁判**：**Conex 具有无可争议的产品力领先优势**。Conex 已经超越了纯后端框架范畴，形成了完备的软硬件端侧生产力生态闭环。
