## 二、架构设计与机制对比

### 1. 终端与代码执行抽象
- **DSH**：
  - 支持持久化 shell 会话（`tool-bash-persistent`, `tool-pwsh-persistent`），可保持环境变量和会话上下文；
  - 集成了强大的 `E2B` 云端沙箱，无需本地执行即可在云端安全沙箱中运行不可信代码。
- **Conex**：
  - 聚焦于本地桌面工作台的极速 PTY 交互，通过 Rust 原生通道直接对接 xterm.js 前端。

### 2. 优劣裁判
- **DSH 优势**：支持持久化 Shell 会话与 E2B 云端执行，远程安全与容器化生态更成熟。
- **Conex 优势**：本地原生 PTY 性能强劲，与桌面 UI 的集成极度紧凑。
