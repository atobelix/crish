## 二、架构设计与机制对比

### 1. 缓存核算与思考流处理
- **DSH**：
  - 采用紧凑的增量流记录（`AssistantStreamRecord`），保留精确的 delta-time 时间戳，极大方便回放和精确用量复盘。
- **Conex**：
  - 针对大模型落地细节做了极致的工程下沉：
    1. 区分 OpenAI 与 Anthropic/DeepSeek 的 Prompt Cache 统计口径（`CacheAccounting::Included` vs `Excluded`）；
    2. 自研 `think_tags.rs`，在流式传输阶段实现思考内容（`<think>...</think>`）与正式回答的正交分离；
    3. 支持动态加载 YAML 价格表（`live_pricing.rs`），精确计算每次 Run 的法定货币花费。

### 2. 优劣裁判
- **裁判**：**Conex 更加接地气且深入细节**。Conex 在模型流式思考解析、多厂商缓存核算公式和实时计费方面的工业落地成熟度明显高于 DSH。
