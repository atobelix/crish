## 二、架构设计与机制对比

### 1. 任务规划机制
- **DSH**：将 Goal、Todo、Plan 做成了微内核下的通用可拔插能力库（`ctx.goals`, `ctx.todos`, `ctx.plans`），向模型暴露直接操作 Todo 清单和 Goal 状态的标准化工具。
- **Conex**：通过战役规范、角色专业分工（Planner / Auditor / Implementer）、反退避纪律和纯逻辑规划驱动，侧重工程战役的高强度攻坚。

### 2. 优劣裁判
- **DSH 优势**：面向通用 Agent 的任务状态跟踪（Todo/Goal/Skill）抽象非常清晰且产品化。
- **Conex 优势**：在大规模工程重构与复杂战役协作上的刚性约束和容灾纪律更为健全。
