# 06 · 性能与虚拟化（贯穿 + Scrubber）

| 字段 | 内容 |
| --- | --- |
| **效果** | 叙事挂上后长会话仍走现虚拟列表与增量 TextNode；参考仓重绘器永不替换热路径 |
| **贯穿** | S2–S8 |
| **Scrubber** | 进计划，默认关 |

## 1. 热路径锁

| 保留 | 禁止照搬 |
| --- | --- |
| `MessageVirtualizer` + Fenwick VSM | `FlowMount` `innerHTML=''` 全量 append |
| `StreamingTextBlock` append TextNode + 48ms batcher | 老虎机 interstitial 当流式 |
| `streamingStore` 无 immer | 每 token 打 layoutStore |
| ResizeObserver → `setActual` | `height-lock.js` 写 minHeight |
| 折叠合上卸载子树 | `hidden`/`0fr` 但仍挂全部 Action/output |

参考仓是视觉矿，不是性能矿（`survey/07`）。

## 2. 块级纪律（实现 03 时强制）

1. Purpose/Action/Thinking/Subagent：**按需挂载**展开体。
2. 输出 DOM 对齐 `TOOL_OUTPUT_PIXEL_CAP` / 字符帽。
3. live 计时 ≤ 1Hz；插件卸必须 `clearInterval`。
4. 至多一条 live 用脉冲，不做默认 shimmer 墙。
5. 展开/折叠打 Virtualizer invalidate；流式中不每 token invalidate（跟现助手行纪律）。

## 3. FlowScrubber（拍板 #6）

- 完成句：可选无轨刻度，高度来自 VSM 已有 offset，不 `getBoundingClientRect` 扫 DOM。
- 默认关；叙事开后仍默认关，设置再开。
- 禁止独立绝对定位迷你图抄参考仓像素。
- S3 高度通知未稳之前只留接口，不画假条。

## 4. 体积

- 不搬 Geist / MiSans 200 片 / Google Fonts。
- 不搬 `icon-assets.js` 167 色 SVG；扩展名映射 lucide。
- `ci-scroll-twitch-detector` 留在 reference，产品 CI 不接。
- `reference/` 测试资产禁止删除。

## 5. 反过度设计

demo 文案里的 EventBatcher + 环形缓冲 **禁止当真**。不为 Purpose 加六段中间件、不为流再造第三套 virtualizer。

## 6. 验收

- 叙事开：折叠 Purpose 的闭合态 DOM 不含全部 output `<pre>`。
- 长列表仍 `data-virtual-scroll="true"`。
- 包/扩展无 `SharedArrayBuffer`、无 `innerHTML` 清空对话根。
