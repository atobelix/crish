## 1. 产品要做成什么

1. 主壳不变：`App → BinaryTreeWorkspace → TreeLeafPanel → SlotOutlet('workspace.leaf.panel')`。对话仍住唯一 primary 叶 `chat`。
2. **未挂叙事插件**：用户气泡 ↔ 助手正文。后端若下发思考/工具，走现成扁平行（`TimelineThoughtSection` / `ChatToolCallBlock`），**没有** Purpose 树、竖轨、Composer 上方 PermissionBar、流内 Task 根、Artifact chip。计划/目标条只在已有 plan/goal 模式出现。
3. **挂上叙事插件**：同一 `chat` 叶替换/装饰 stream renderer。投影出 Purpose → Action、思考预览行、Subagent 两行根、产物 chip、Composer 上方审批条；计划模式才出 Task 根。`deactivate` 立刻回到第 2 条。
4. Composer 继续挂在 `ChatCard` 叶底，与流同一 surface。缺件（附件卡精致度、inline tag、`@@`、模型×思考融合、拖放皮）补在现模块，**禁止**用参考仓 `composer-core.js` / TS 桩覆盖。
5. 文件预览进已有 `file-viewer` / `files` 叶；产物 Notebook 是阅读面，代码路径走 Files。Markdown 编辑内核仍是笔记扩展，不注册第二套。
6. 参考仓整页壳（侧栏、假窗控、假二叉树、`demo-data`、Google Fonts、原生 `title`）永不进产品。
