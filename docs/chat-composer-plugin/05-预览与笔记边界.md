## 1. 文件预览（S6）

完成句：点附件 / `@` / 工具路径，代码与工作区文件在 `files` / `file-viewer` 叶打开，填该叶包含块。

| 锁 | 口径 |
| --- | --- |
| 宿主 | 已有 `preview` / `file-viewer` / `files`。`openToolInSession` / URI |
| 禁 | `fp-root` `position:fixed; inset:0`、`document.body` 模态、`92vh` 第二视口 |
| 适配器 | 可吸收参考仓 router/adapter 思想，重写进现 `FilePreview` / `FileViewerCard` |

| 轻预览 | 若做，绝对定位在 **该对话叶** `.leafBody` 内，禁止盖整棵二叉树 |

## 2. Artifact + Notebook（S7）

完成句：文档类产物出 chip；悬停/钉住打开阅读面；代码永不进 Notebook。

| 锁 | 口径 |
| --- | --- |
| 数据 | 引擎 `ToolOutput.artifacts` 弱；无字段则前端从工具输出派生并标注 |
| 阅读面 | 现 `AsyncMarkdownBlock` / markdown 渲染路径，不是 `js/markdown-editor` |
| 要编辑 | `openToolInSession(..., 'note')` + **已有** docId |
| 禁 | 打开当场 `apply+commit`；`sendToNoteMount` 静默新 doc 当主路径；第二套 conex-mdx 注册为 view |
| 与打开完成 | Notebook 绿 ≠ H2 / EL |
