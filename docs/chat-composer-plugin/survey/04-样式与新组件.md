## 0. 结论（先读）

参考仓的「高级感」不在 Geist 整包、不在绿勾墙、不在 1966 行的 `composer.css` 星壳。真源是三层克制：

1. **纸 + 暖墨 + 发丝线**（`brand.css` 的 `--paper` / `--ink` / `--line`），完成态无彩，绿只标「agent 活着」。
2. **Composer 与用户气泡同一套 surface**（圆角卡片、弱 bevel、几乎无焦点跳变）。
3. **大 gap / 小 chrome**：对话 14/1.65、微元 11–12、图标不得大于字。

产品桌面**已经走在同一条路上**，且在焦点与阴影上比参考仓演示壳更干净：

| 面 | 产品现码 | 参考仓演示 |
| --- | --- | --- |
| Composer 焦点 | `color-mix(... border 94%, text 6%)`，空态 5%；`box-shadow: none` | `focus-within` 几乎不变（好），但 `--shadow-composer` 仍叠 lift |
| 发送 | `Button variant="primary"` + `CornerDownLeft`，自定义 Tooltip | 品牌绿实心圆 + `rgba(16,185,129,0.25)` 光晕 |
| 提示 | `ui/Tooltip`，Composer 注释已禁 `title=` | `index.html` **34** 处原生 `title=` |
| 完成勾 | 工具行大量 `--accent-green` **绿勾墙** | 规范禁绿勾，现码 popover 勾仍走 `--brand` |
| 字体 | `fontStore`：系统 / Inter / IBM Plex；无 Geist、无 MiSans | 文档写 Geist+MiSans，运行时却是 Plus Jakarta + 谷歌字体 |

**插件边界（样式）**：叙事流皮肤挂在对话流插件上，只消费产品语义 token（映射，不另开色盘）。Composer 新件（附件卡、inline tag、融合触发器、圆形发送、权限胶囊、slash/@/树）进现有 `chat-composer/` 模块，**禁止**新开第二套 `css/brand.css` 真源。

## 1. 设计 token 分层

参考仓自称三层，文件也确实如此；但 **文档 / `@font-face` / 运行时 `--font-sans` 已漂移**。

```
brand.css          基元真源（纸/墨/线/品牌绿/语义/材质/几何/运动）
  ↓ 只映射、不发明色
design-tokens.css  组件语义名（--text-* / --bg-* / --perm-* / --shadow-*）
  ↓ 对话流再派生
conversation-tokens.css  --flow-*（rail、字号档、折叠高）
  ↓ 子系统私有
file-preview/tokens.css  --fp-*
.mdx-root（07-visual-system §2） --mdx-*
```

证据：`brand.css:1-8,34-150`；`design-tokens.css:1-6,18-38`；`conversation-tokens.css:1-7`；`css/file-preview/tokens.css:1-29`；`docs/markdown-editor/07-visual-system.md:27-69`。

## 6. 与 AFFiNE / AppFlowy（气质差，≤5 条）

不写竞品功能对照。只帮主控排「像谁」：

1. **参考仓更像「一张纸上的对话」**：用户气泡与 composer 同卡面，助手是文档流无泡（`composer.css:553-572`；`design-system-guidelines.md:37-38`）。AFFiNE 的干净来自 edgeless 画布；AppFlowy 更像带侧栏的块应用。产品应对齐**纸面对话**，不是对齐 AppFlowy 工作区密度。
2. **AFFiNE 可借的只有克制**：发丝、弱悬停、少分割线。不要借 AFFiNE 的板式画布 / 斜线全屏网格，也不要借其品牌蓝。
3. **AppFlowy 可借的只有「块与行的扫读」**：工具行像一行日志而不是卡片墙。不要借其彩色 sidebar、数据库彩点、重 elevation。
4. **三者都不是「绿成功体系」**：参考仓把绿收成活着信号；AFFiNE/AppFlowy 也不靠完成勾铺绿。产品工具行绿勾（§5.3）比三方都吵。
5. **禁止截图对齐**：调研边界 §6。间距以 `design-system-guidelines.md` 的 32px 轮次 / 14px 20px 用户泡 / 16px 20px 输入为**量级**参考，落地用产品 `--space-*`，不拿 PNG 量像素。
