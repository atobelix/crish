## 0. 结论（先读）

**参考仓是视觉矿，不是性能矿。** 叙事投影纯函数和 CSS 动效 token 能进产品；整页 `innerHTML` 重挂、折叠仍挂整棵 DOM、老虎机入场、JS 测高锁高、子像素 CI、4MB 字体、167 色图标字典都不能进。产品 chat 流**已经**有虚拟列表 + 增量 TextNode，迁入叙事插件必须接在这条热路径上，禁止用参考仓的静态重绘器替换。

| 面 | 参考仓现状 | 产品现状 | 裁决 |
| --- | --- | --- | --- |
| 长列表 | 无虚拟化；`FlowMount.renderConversation` 清空后全量 append | `MessageVirtualizer` + Fenwick `VirtualScrollManager`，overscan 6 | **保留产品**；参考仓零可搬实现 |
| 流式 token | 无逐 token 写 DOM；演示是一次投影 + 老虎机入场 | `StreamingTextBlock` `appendChild(TextNode)` + `streamingStore`（无 immer）+ 48ms batcher | **保留产品**；参考仓不是流式 |
| 折叠 | CSS `grid 0fr` / `hidden` / `display:none`，子树仍在 DOM | SPEC 自己写「展开体按需挂载」，参考仓没做 | **按 SPEC 改写**，禁止照搬折叠实现 |
| 动效 | token 克制（opacity/transform）；另有 JS 锁高、SVG 量轨、无限 shimmer | 产品已有 `--duration-*` / `--easing-*` | **只迁 CSS token**；JS 测高/锁高丢掉 |
| 包体积 | Geist ~140KB + MiSans 200 片 ~3.9MB + Google Fonts 双栈；`icon-assets.js` 153KB / 167 键 | 系统 CJK + lucide | **不搬字体全集 / 不搬图标字典** |
| 13 条红线 | 代码面**未撞**环形缓冲 / 六段中间件 / CircuitBreaker 等；demo 文案里**口头**提了 EventBatcher+环形缓冲 | 禁令已生效 | 口头方案**禁止当真**实现 |

建议插件边界：叙事 UI（Purpose / Action / Thinking / Subagent / Permission）作为 **chat 叶上的可选扩展**；默认直来直去仍走现 `ChatMessageList`。投影层可抽纯函数包。**不**把参考仓 markdown 编辑器注册成第二笔记内核；**不**把演示壳（侧栏 / 假二叉树 / 计划底栏 / scrubber）当产品布局。

## 3. 动效：哪些 CSS token 可迁，哪些 JS 测高/锁高必须丢掉

### 3.1 可迁（token / 原则，不是整份 CSS 文件）

参考仓动效文档自己写对了原则（`css/flow/motion.css:4-8`、`css/markdown-editor/motion.css:3-9`）：

- 只动 `opacity` + `transform`；不 anim 高/margin/top；不 transition `box-shadow`
- 短弧 90–260ms；软 settle，无回弹 overshoot
- `prefers-reduced-motion: reduce` 把 duration 置 0

与产品 token 已接近，**映射即可，不要第二套名字**：

| 参考仓 | 值 | 产品已有 |
| --- | --- | --- |
| `--t-micro` / `--t-fast` / `--t-base` / `--t-slow`（`css/brand.css:146-149`） | 100 / 150 / 200 / 300ms | `--duration-micro/fast/normal/slow`（`apps/crish-desktop/src/styles/tokens.css:321-325`） |
| `--ease-out` `cubic-bezier(0.22, 1, 0.36, 1)` | 同左 | `--easing-enter` 已是 `(0.16, 1, 0.3, 1)`，接近 `--ease-soft` |
| `--flow-accordion-ms: 180ms`、`--flow-entrance-ms: 160ms`、`--flow-hover-ms: 90ms`（`css/conversation-tokens.css:85-89`） | 叙事专用时长 | 作为 flow 插件局部 token，或并入现 duration 阶梯 |
| `.flow-acc`：`grid-template-rows: 0fr → 1fr`（`css/flow/motion.css:114-128`） | 纯 CSS 手风琴 | **可迁作视觉**；子节点仍须懒挂载（见 R3） |
| `css/file-preview/motion.css` fade-in + 前 5 行 stagger 20ms | 短、可关 | 预览插件可用；必须带 reduced-motion |
| `js/markdown-editor/edit/motion.js:40-83` `prefersReducedMotion` + 读 CSS 变量毫秒 | 小 helper | 若要 JS 等 animationend，用这套思路；不要连 height-lock 一起搬 |

### 3.2 必须丢掉（JS 测高 / 锁高 / 坐标补丁 / 布局动画）

| 丢掉什么 | 证据 | 原因 |
| --- | --- | --- |
| `MdxHeightLock.lock/unlock/raise/around` | `height-lock.js:37-126` | 同步测高写 `minHeight`；双 rAF 清。对话流高度归 Virtualizer + ResizeObserver（`MessageVirtualizer.tsx:84-98`） |
| `withScrollPreserve` 手动存 `scrollTop` | `height-lock.js:134-179` | 产品已有 `useScrollAnchor` / `useUndoWithScrollAnchor` |
| `FlowTimelineRail` 量 `getBoundingClientRect` 画 SVG | `FlowTimelineRail.js:32-115` | 坐标补丁；`iconX` 默认 8、短连线 ±4px 是魔术数 |
| `void el.offsetWidth` 强制 reflow 重启动画 | `motion.js:125-126` | 对话流高频路径禁止 |
| composer 单行/多行 `measureSpan` | `composer-core.js:35-48` | 输入热路径强制布局 |
| `transition: all` | `css/composer.css:1559,2024`；`css/popovers.css` 多处；`css/file-cards.css:144,270`；`css/flow/scrubber.css:57` | 会把 width/padding/shadow 拖进动画，正是 motion.css 自己禁止的 |
| 老虎机 `.flow-slot` 定高 `1.65em` + `translateY(index * -1.65em)` | `css/flow/motion.css:152-204` + `TextBlock.js:91-127` | 演示入场；真流式高度在变，slot 会裁切/抖 |
| `.flow-shimmer-text` 无限动画 | `css/flow/motion.css:23-47` | 合成层常驻 |
| `will-change: transform, opacity` 挂在数字单元上 | `css/flow/motion.css:84` | 非动画期不要 will-change |
| markdown `motion.css` 里的 `--mdx-var(--ease-default)` | `css/markdown-editor/motion.css:70` 等 | **非法 CSS**（像没展开的模板），迁了也无效 |
| FlowScrubber 小地图 | `js/components/FlowScrubber.js` | 演示导航；产品消息虚拟列表自带滚动 |

### 3.3 产品对话流动效落点

叙事插件展开/收起：CSS grid 或现组件折叠；**高度变化只通过行上 `ResizeObserver` → `setActual(msgId, height)`**（`MessageVirtualizer.tsx:90-98`）。不要为 Purpose 再写一套 height-lock。

## 4. 流式渲染：逐 token 写 DOM 会不会抖滚动；twitch detector 是门禁还是补丁

### 4.1 参考仓根本不是逐 token 渲染

- `stream-renderer.js:1-6` 自称 V7，「Thin bootstrap over FlowProjector + FlowComponents」。
- `autoInit`（:24-57）在 DOMContentLoaded 把 **整份** `DemoData` 交给 `FlowMount.mount`。
- 助手正文：`TextBlock.renderPrimary` 一次 `root.innerHTML = html`（`TextBlock.js:65-78`）；过渡句是 3 帧 slot，双 rAF 后 `settle`（:122-127）。
- 没有 token 循环、没有 `appendChild` 增量、没有 rAF 节流的流式管线。

因此：「参考仓流式会不会抖」——**演示路径上几乎不发生 token 抖**，因为它不流。真正的滚动风险在 **重挂整树（R1）** 和 **折叠节点仍增高（R3–R7）**。

### 4.2 产品已经在做禁令 12 要求的增量写

```38:45:apps/crish-desktop/src/components/chat-message-row/StreamingTextBlock.tsx
    useLayoutEffect(() => {
      const el = ref.current;
      if (!el) return;
      if (lastSeqRef.current === seq) return;
      lastSeqRef.current = seq;
      if (delta) el.appendChild(document.createTextNode(delta));
    }, [delta, seq]);
```

热缓冲：`streamingStore.ts:1-16` 明文「plain zustand, NO immer」；`useStreamBatchers.ts:39-51` 48ms / 8000 字符封顶。时间线稳定区 `TimelineBody` memo，增长中的最后 text 剥离到 StreamingTextBlock（`MessageContent.tsx:46-47`）。

**逐 token 写 DOM 会不会抖滚动：**

- 只 append TextNode、父行高度由 RO 更新 VSM：通常不抖视口（锚点在 `useScrollAnchor`）。
- 若每 token 还触发：Markdown 全量 innerHTML、Purpose 重投影、Action `<pre>` 重写、SVG rail `updateAll`、虚拟列表错误复用——**会抖**。这正是参考仓迁入时的主要回归面。
- SPEC 已写（`CONVERSATION_FLOW_SPEC.md:802-807`）：流式热路径不进 immer；展开体按需挂载；高度变化通知 Virtualizer。参考仓实现与 SPEC 这一段**不一致**——迁入以 SPEC + 产品热路径为准，不以 `FlowMount` 为准。

### 4.3 twitch detector 是什么

`js/ci-scroll-twitch-detector.js` 文件头（:1-7）自称 **CI Quality Gate**，不是运行时补丁，也**不是**流式滚动检测：

| Gate | 实际测什么 | 阈值 |
| --- | --- | --- |
| 1 | composer 单行时，滚 stream / window / 模拟 overscroll，voice/send 相对 plus 的 Y | `> 0.001` px 即 fail（:137-142） |
| 2 | 按钮内 SVG 相对按钮的物理像素偏移是否「整数」 | 分数即 fail |
| 3 | `#planDuration` 相对计划条，来回 `scrollTop` | 同 0.001px |
| 4 | 一串 composer/plan DOM 的 `height * dpr` 是否整数 | 非整数即 fail |
| 5 | stylesheets 里 `!important` | 零容忍（display:none/flex 例外） |
| 6 | 抽几个元素 `backgroundColor` 跑 ColorAdaptor | 「测到元素」就算过，几乎无断言 |
| 7 | `.composer-wrapper` 与 `.flow-stream-inner` 左右对齐 | 0.05px |

**定性：演示壳视觉门禁（偏对齐洁癖），不是流式抖的修复器，也不是产品补丁。**

- 当作参考仓自测资产：**保留**（测试资产保护铁律；禁止建议删除）。
- 当作产品 CI：**不要接**。0.001px 在 WebView2 + 系统 DPI 下不稳定；Gate 6 几乎恒真；ColorAdaptor 与产品「CSS 里直接写 HSL」重复。
- 流式不抖的验收应写：pin-to-bottom 时 token append 不改变已滚离视口的消息 offset；展开 Action 后 `setActual` 一次、列表不跳到顶。这些用现 `MessageVirtualizer.perf.test.tsx` / `StreamingTextBlock.test.tsx` 扩一条即可。

`bindScrollChain` 已是 no-op（`dom-utils.js:223-236`），注释写明先前 `preventDefault + scrollTop += deltaY` 才是抖动源。这条**教训可迁**（嵌套面板用 `overscroll-behavior`，不要手搓 wheel）。

## 8. 能进产品的（架构与性能同权后的白名单）

在「不要做」约束下，仍值得迁的能力——全部以**插件边界**挂到现 chat 叶，默认关闭时 UI 仍是用户 ↔ 助手线性流。

| 块 | 怎么进 | 性能约束 |
| --- | --- | --- |
| `flow-projector.js` 纯函数 | 抽 TS，单测；`purposeId` 优先，启发式 30s 仅兜底 | O(n) 过 toolCalls；流式时对**增量 tool 事件**做追加合并，禁止每 token 全量 `projectConversation` |
| Purpose / Action / Thinking / Subagent **视觉语言** | 现 `ChatToolCallBlock` / `MessageThinkingSection` / `InlineAgentPanel` 上改皮肤与信息层次 | 折叠卸载；输出帽 600px / 8000 字；高度 `setActual` |
| PermissionBar 上提 | SPEC 已要求审批不进 purpose 树（`flow-projector.js:385-404`） | 条数极少，无虚拟化需求 |
| CSS 时长/缓动/reduced-motion | 映射到产品 `--duration-*` | 只 opacity/transform |
| `.flow-acc` grid 手风琴 **作为动画** | 可在已挂载的展开体上用 | 不得当作「未挂载」的替代 |
| `bindScrollChain` 的结论 | 嵌套 overflow 用原生 overscroll | 不要手搓 wheel |
| 文件 kind → lucide | 扩展现 `BcFileIcon` | 不引进 icon-assets |
| 预览 PDF 单页 canvas | 若做预览插件可参考 `PdfViewer.js` 的「当前页 + 取消 inflight renderTask」 | 不要一次渲全部页；大表另案虚拟化 |

**默认直来直去**（调研边界 §1.2）时：上述 Purpose 树不挂载，产品继续 `MessageVirtualizer` + `StreamingTextBlock`。插件激活不得关闭虚拟列表。
