# 03 · 叙事块与权限条（S3 / S5 / S8 终稿）

| 字段 | 内容 |
| --- | --- |
| **效果** | 插件开时，同一 chat 叶可扫读 Purpose 树；审批上提；计划根仅 plan 模式 |
| **切片** | S3 + S5 + S8 |
| **依赖** | S2；S5 另依赖 S4 的 composer 上沿槽 |

## 1. 目标效果

### S3 块

| 节点 | 完成句 | 现码落点 |
| --- | --- | --- |
| Thinking | 默认预览行 + 限高 fade；live 不默认展开全文 | 装饰 `TimelineThoughtSection`，不另起查阅器 |
| Purpose | 人话主文案折叠 N 个 Action | 新件；替换「N 步」组头 |
| Action | 折叠行人话，展开才见命令/输出 | 皮向 `CompactToolRow`，逻辑留 tool-presentation |
| Subagent | 默认两行 + 限高同构子流 | 装饰 `InlineAgentPanel` 外壳，不重写 `useAgentPanel` |
| Artifact chip | 「已生成」文档胶囊 | 新件；代码路径仍 `onOpenPath` |

展开体 **按需挂载**（合上不挂整棵 Action DOM）。高度变化 `invalidateActual` / ResizeObserver。CSS `max-height` 对齐 `TOOL_OUTPUT_PIXEL_CAP`。

### S5 权限条

插件开：`workspace.chat.composerAbove` 挂冷静条（首条 +「还有 N」）；流内去掉 `ApprovalAskCard` 重卡。回调仍走 `useChatApproval` / `engineApproveTool`。不要 5 分钟老虎机。

插件关：现卡 + dock 不动。

### S8 计划根

仅 `selectPlanModeEnabled` 等已有状态为真时，流内可挂 Task 根。Composer 上沿继续用现 `PlanGoalRibbons`，不搬 `index.html` 五步剧本。默认线性不得出现演示 Hub。

## 2. 文件域

- `packages/conversation-flow/components/`：Purpose / Action / Thinking / Subagent / Artifact / PermissionBar
- `extensions/conversation-flow/`：host 装配、composerAbove 登记
- 现 `CompactToolRow` / `ChatComposerWrapper`：插件开时开关内联卡 / 插槽
- **禁止**迁 `FlowTimelineRail.js`、`subagent.css` 左边框、`plan.css` `::after` 竖线

## 3. 验收

- 开插件：一条回合里多 inspect 合成 1 个 Purpose；展开才见 `<pre>` 输出。
- 开插件 + pending：条在 composer 上，流内无重审批卡。
- 关插件：回归 01 扁平行 + 现审批卡。
- 无竖轨 SVG、无 `getBoundingClientRect` 画线。
- 绿勾墙去掉（成功态无彩）。

## 4. 非目标

不做 IDE 侧栏；Notebook 编辑核归 05；Scrubber 归 06；不改审批协议。
