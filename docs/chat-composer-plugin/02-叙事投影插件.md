# 02 · 叙事投影插件（S2 终稿）

| 字段 | 内容 |
| --- | --- |
| **效果** | 可卸投影器把 `SessionMessage` 编成叙事树；未激活时产品零引用该包 UI |
| **切片** | S2 |
| **依赖** | 01 / S1 |
| **被依赖** | 03、08 |

## 1. 目标效果

1. 新建 `packages/conversation-flow`（`@crish/conversation-flow`）：`projectMessage` / `projectPurposes` / `extractPendingApprovals` 纯函数。
2. 输入 = desktop 已有 `SessionMessage` / `MessageToolCall` 的**结构类型**（最小接口，不反向依赖 desktop）。
3. 输出 = `FlowNode[]` + `pendingApprovals[]`。无 `purpose_id`：Phase A 用 `explanation` 归一 + 30s 窗，字段标前端派生。
4. 人话/路径/命令抽取 **调用** 现 `tool-presentation` 可抽纯函数，或把纯函数下沉到共享处一次；禁止再抄 `js/tool-presentation.js`。
5. `extensions/conversation-flow` 的 activate 把 host 组件登记进 `workspace.chat.stream`。host 读同一 session 消息，喂投影器。
6. 崩溃走 SlotOutlet 已有 abdicate → fallback 线性列表。

## 2. 文件域

| 路径 | 动作 |
| --- | --- |
| `packages/conversation-flow/` | 新建包：projector + types + 单测 |
| `apps/crish-desktop/src/extensions/conversation-flow/host.tsx` | 喂源 + 先可只渲染「已投影节点数」占位，块在 03 |
| workspace / desktop package.json | 加依赖，方向：desktop → 包，包 ─╳→ desktop / block-paper / reference |

## 3. 任务单元

1. 类型与 `projectMessage` 对无工具消息 = 仅 text（+ 可选 thought 节点，由 03 决定是否画）。
2. `projectPurposes` 单测：同窗合并、pending_approval 不进树、无 explanation 时 humanize 回退。
3. activate 挂 host；默认仍关。
4. 边界测：包不 import `apps/crish-desktop`。

## 4. 验收

- 包内 vitest 绿，夹具用真实形状的 `MessageToolCall`，**不用** `demo-data` plan 块。
- 关插件：产品 UI 无 Purpose DOM。
- 开插件：host 吃投影结果（即使 03 未齐，也不得回退成 innerHTML 整页重挂）。

## 5. 非目标

不发明 IPC；不投影 `demo` 专有 `kind:'purpose'`；不迁 Rail/Scrubber/SessionStart；不改 session-loop。

## 6. 与 input-stream 对齐

时间线 SSOT 仍是事件 → `SessionMessage`。本投影是展示层，挂在 `buildAssistantTimeline` **之上或旁路组装**，不另起事件源。
