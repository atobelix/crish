# 战役纪律与调度状态：工具调用体验与沙箱误报系统性整改

## 一、战役背景与用户诉求

用户在实际使用中反馈了一系列严重影响体验的排版、交互与安全沙箱误杀问题：
1. **沙箱阻断误报**：`[tool.command_blocked] PermissionDenied: 命令包含指向系统核心关键目录的敏感路径：/.，硬性阻断！`。用户即使已全权允许，常规 `git grep` 命令因包含正则 `\.\.?/.*` 仍被硬性阻断。
2. **文字字号统一到 14px**：过程折叠栏、工具调用头等文字统一从 13px/12px 调整至 14px，提升可读性；代码/终端输出保留紧凑等宽小号。
3. **数字滚动（NumericText）乱动**：打开展开界面时数字不必要地空转一圈，必须优化为仅数值实质变动时平滑递增或直接禁用展开时的初次旋转。
4. **流式输出平滑与节流**：输出突发出现，缺乏合理的节流平滑控制。
5. **高度限制容器的上下区域透明度渐变（ScrollFade）**：所有 max-height 受限容器必须有明确的上下透明度渐隐，清晰区分内容归属。
6. **工具调用结果展开和折叠卡顿**：展开折叠动画掉帧、重排阻塞，需彻底排查手风琴、VSM 测高、DOM 渲染的性能瓶颈。
7. **展开内容样式与边框规范化**：外层卡片与输入/输出分隔区增加细腻描边，统一左右内边距（解决贴边与错位），去除多余重复“复制”按钮与垂直空白。
8. **双层折叠套娃与 PowerShell CLIXML 噪音**：单工具调用穿透外层控制栏消除套娃；后端彻底剔除 Windows PowerShell `#< CLIXML` 噪音，防止 LLM 复述污染正文。

## 二、协作纪律

1. 遵循《AGENTS.md》2026-11-03 裁决：每轮子 Agent 上限按 8 个精细化拆解，方案由子 Agent 产出，主控负责全局调度与决策。
2. 遵循《LOGIC_PLAN_NO_RETREAT.md》反退避铁律，不降级、不砍功能，追求架构优雅与根因穿透，严禁临时打补丁或魔术数字。
3. 文档落盘于 `docs/tool-experience-and-sandbox-repair/`，子文件夹只允许一级（`analysis/`）。
