## 二、审查与验证机制

每项修改均按“修改 ➔ 检查 ➔ 即查即改”流程闭环：

1. **语法与格式检查**：JSON / TOML / Markdown 严格符合标准；
2. **构建与门禁测试**：运行 `npm run typecheck`、`cargo check --workspace` 与 `npx depcruise --config .dependency-cruiser.cjs packages apps`；
3. **红线验证**：`git status --porcelain reference/` 必须保持绝对为空。
