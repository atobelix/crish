# 开源准备度全面检查战役（Open-Source Readiness Audit）

> **战役工作区**：`docs/open-source-readiness/`
> **权威依据**：根目录 `AGENTS.md`（§1 逻辑规划与反退避、§2 子 Agent 调度、§4 战役工作区规范）、`.agents/LOGIC_PLAN_NO_RETREAT.md`。
> **战役目标**：全面、深入、严谨地审查当前 Conex / Crish 项目距离正式在 GitHub 等公网平台开源所欠缺的全部关键工作，形成生产级差距清单与落地方案。

---

## 一、审查原则与纪律

1. **反退避与事实求是**：所有发现必须有确凿证据（`文件路径:行号`、Git 状态、命令输出、网络端点等），不凭空推测，不掩盖问题。
2. **问题同权**：法律合规、安全密钥、社区文档、CI/CD 构建、代码整洁度、测试门禁与上手体验同等重要，不因难度而降级。
3. **工作区目录规范**：
   - 战役根目录：`docs/open-source-readiness/`（仅放纪律总案与分维详案）。
   - 审计产出子文件夹（仅一级）：`docs/open-source-readiness/audits/`。
4. **子 Agent 产出规范**：每个调研子代理仅产出一份独立审计报告，UTF-8 无 BOM 格式。

## 三、产出汇总与验收

各 Agent 完成审计后，主 Agent 负责收口并汇总为整体开源就绪评估大纲，形成具体的改造优先级与执行路线图。
