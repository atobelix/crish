## 一、物理现场与根因全景汇总（8 大维度审计结论）

经 8 个专项审计子 Agent 对前端状态机、持久化水合链路、事件投影排序、虚拟滚动、分屏作用域隔离、Markdown 渲染及本机真实 SQLite 数据库（`C:\Software\conex\apps\agent-workbench\sessions.db`，61.85 MB）的穿透核查，定位出以下完整事故链：

### 1. 本机 SQLite 数据库物理铁证（`audits/01` & `audits/06`）

- **`sessions` 表**：**81 行**（81 个会话索引全部存在）。
- **`session_messages` 表**：**仅剩 3 行**！其余 **79 个历史会话**在 `session_messages` 表中的消息被清空为 0 行，且全部留有特征：`message_count = 0, body_version = 0, hydrated_from_engine = 1`。
- **`events` 表（Rust 引擎权威事件日志表）**：**77,403 行完好无损**！跨 21 个有对话的历史会话完整保留了 **7,445 条 `message-start` 与 7,445 条 `message-end` 完整对话消息载荷**及 207 次工具调用事件（如 `sess-1786798945840` 存有 7,557 条事件 / 654 条消息；`sess-1786798366231` 存有 7,071 条事件 / 619 条消息）。**所有历史对话均可从 `events` 表 100% 无损恢复！**
