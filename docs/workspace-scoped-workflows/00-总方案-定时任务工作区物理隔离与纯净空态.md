# 00-总方案-定时任务工作区物理隔离与纯净空态

> **战役代号**：`workspace-scoped-workflows`  
> **核心原则**：定时任务无全局概念；物理工作区隔离；未绑定定时任务时呈现纯净空态；架构净收敛。  
> **用户权威裁决**：“第二个就是定时任务没有全局这一说，只能在工作区目录里面选择，所以其他项目在未绑定定时任务的情况下，是没有东西显示的。”

---

## 一、方案全景与目标架构

```mermaid
flowchart TD
    A[当前激活工作区 / 会话 Folder] -->|解析物理路径| B[Current Workspace Path (CWD)]
    C[全局任务数据源 ds.workflows] --> D[filterWorkflowsByWorkspace 纯函数选择器]
    B --> D
    D -->|精准过滤| E{当前项目有任务?}
    E -- 是 --> F[渲染任务列表 + 显示数量 Badge]
    E -- 否 --> G[纯净空态: 隐藏 Badge + 展开显示极简「无」]
```

### 核心改造指标：
1. **彻底拔除伪“全局”表单项**：在创建/编辑定时任务时，物理删除“默认工作区（全局）”；强制选择已有具体项目物理路径；
2. **修复创建时 `cwd` 丢失缺陷**：在 `useWorkflowsState.ts` 创建调用中补齐遗漏的 `cwd: draft.cwd`；
3. **右侧抽屉 `OverviewCard` 严格过滤**：按当前项目物理路径对任务进行 `areWorkspacePathsEqual` 比对过滤，净化掉历史遗留 `cronJobs` 伪遥测数据；
4. **纯净空态**：在当前项目未配置定时任务时，徽标（Badge）物理隐藏（不显示数字），展开后展示极简单行「无」，绝无跨项目污染。
