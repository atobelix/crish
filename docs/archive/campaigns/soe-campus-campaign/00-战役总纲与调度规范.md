# 2027届央国企与科研院所技术岗投递战役总纲

> **战役工作区**：`docs/archive/campaigns/soe-campus-campaign/`
> **核心目标**：针对 2027 届硕士（GIS+海洋科学，强前端/全栈/Agent技术栈），地毯式核查并交付 **上百家真实可报、高薪高质、绝不卡死学历与届别的央国企/院所岗位清单**，并提供针对性的投递策略与材料支撑。

---

## 一、战略背景与指导方针

1. **企业重心转向**：大厂目前不在优先考虑范围，全面转向 **央国企、科研院所、军工集团、省属龙头国企数字化科技子公司**。
2. **量级要求**：必须达到 **上百家** 的真实投递储备量，扩大面试与录取概率。
3. **真实性与准入红线（铁律零容忍）**：
   - **必须真实能报**：每一个推荐给用户的岗位，必须经过实质审查（毕业时间、学历层次、专业范围、投递入口有效性）。
   - **严禁虚假推荐**：严禁中介虚标的假 2027 岗（实际系统只允许 2026 届选）、严禁硬卡博士的科学家岗、严禁必须 985 本科的死板机构。
4. **时效性优先**：严格审查**截止时间**与**发布时间**。优先挑选**近 1 个月内（9月下旬至10月中旬）最新发布、仍在火热接收简历**的活水岗位。

## 三、子 Agent 调度纪律（单次 15 个）

1. **任务切片**：每个子 Agent 分配 **15 个左右** 的初筛央国企/院所目标岗位。
2. **审查动作**：
   - 查验招聘公告与网申系统真实页面；
   - 核查毕业时间要求（是否明确包含 2027 年，或是否为 27 届实习转正/提前批）；
   - 核查专业限制（是否包含 GIS、地理信息、海洋、测绘、计算机、软件、理工科不限）；
   - 核查学历要求（硕士是否可以报考，是否非博士专属）；
   - 核查发布时间与截止日期（是否还在有效期内）；
   - 提取真实直接投递链接与投递方式。
3. **交付标准**：产出结论格式化入库，明确标注【**确认可报 / 存在疑点 / 严禁报考（附原因）**】。
