# 简历硬核素材与央国企对口技术栈指南

> **适用对象**：参与央国企岗位分析的子 Agent。
> **目的**：在给每个岗位给出【针对性投递策略】时，直接调用以下经过量化验证的硬核技术资产。

---

## 一、候选人核心技术资产库（来自真实生产级代码）

### 资产 1：Crish 桌面端大模型多智能体工作台（多代理 / 系统级工程）
- **核心架构**：基于 Rust（Tauri 2.0）内核 + React 19 前端，超过 110 万行高质量工程实践。
- **调度系统**：自研两阶段状态机（Planning -> Execution），支持最多 16 个并发子代理的树状生命周期治理。
- **强制面防护**：实现 I4-M3 文件级写路径互斥锁，多代理并行写冲突由引擎守卫拦截，冲突率降至 0。
- **协议与集成**：完整落地 Model Context Protocol (MCP) 协议，实现本地与跨进程工具的无缝解耦。
- **央国企对口应用**：适用于央国企、科研院所的“企业内部 AI 知识中台”、“多智能体协同仿真平台”、“安全审计与流程自动化系统”。

### 资产 2：Flowbit 流式 RAG 知识检索系统（数据 / 算法 / 检索增强）
- **混合召回**：向量密集检索 + BM25 稀疏检索双路召回，自研倒数排名融合（RRF）重排算法，Top-5 命中率显著提升。
- **动态上下文修剪**：双水位动态修剪机制，避免长文档大模型推理的“Lost in the Middle”退化，节省 40% Token 消耗。
- **引用精准溯源**：基于浏览器原生 `CSS.highlights` 范围高亮，实现研报/文档引用原文的零延迟无缝锚定与跳转。
- **央国企对口应用**：适用于科研院所、军工、大型国企的“海量工程资料库智能问答”、“科研论文知识挖掘”、“合规法务智能审查”。

### 资产 3：现代 Web 极致性能与流式渲染引擎（前端 / 全栈 / 工业软件）
- **高刷渲染**：建立 120 FPS（8.3ms/6ms 帧预算）极致流畅渲染管线，面对 10 万字大模型长对话零掉帧。
- **流式增量解析**：DFA 词法分析器，将全量 AST 重解析优化为 O(1) 尾部增量推导，首字响应耗时降低 75%。
- **虚拟滚动与数学公式**：自研树状数组（Fenwick Tree）动态高度虚拟滚动，KaTeX 双态轻量渲染，规避长文档重排重绘抖动。
- **央国企对口应用**：适用于工业软件、EDA/CAD/GIS 交互界面、大屏监控与指挥大厅、数字化看板。

### 资产 4：本硕 GIS + 遥感 + 海洋空间科学（绝对稀缺专业壁垒）
- **空间数据分析**：精通 GIS 空间分析模型、空间坐标转换、矢量与栅格数据处理、空间拓扑分析。
- **遥感图像与海洋**：掌握多源遥感影像处理、海洋数值模拟、时空时序数据挖掘。
- **央国企对口应用**：自然资源、海洋局、测绘院、水利水电设计院、航天遥感院所的“数字孪生”、“空间大数据平台”、“智慧海洋/数字江河”系统。

## 二、央国企投递“三大兵器谱”选择法则

子 Agent 在给具体央国企岗位写【针对性投递策略】时，请按单位类型精准匹配：

1. **科研院所 / 航天 / 军工数字化单位**：
   -> **主打【资产 4 (GIS/海洋空间)】+【资产 1 (Rust/系统架构)】**
   -> 策略：强调“地学与空间领域复合背景，具备系统底层 Rust 开发能力与严谨工程规范，能胜任高可靠性国家级科研平台开发”。

2. **央国企数字化科技子公司 / 银行与金融科技研发中心**：
   -> **主打【资产 2 (RAG知识库)】+【资产 3 (高刷前端与复杂系统)】**
   -> 策略：强调“掌握企业级 RAG 检索增强技术与大规模长会话流式交互架构，具备支撑大规模企业级生产系统的性能优化实战经验”。

3. **智能硬件 / 自动化 / 智慧交通与城市**：
   -> **主打【资产 1 (多代理调度)】+【资产 3 (DFA增量解析/工业交互)】**
   -> 策略：强调“精通多状态机并发调度、任务拆解与可视化，对前端高帧率交互与嵌入式/多进程通信有扎实落地经验”。
