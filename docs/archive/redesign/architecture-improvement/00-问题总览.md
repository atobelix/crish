# 问题总览

> 基于 10 个架构诊断方向（01-10）、Round 2 摸底发现的 150+ 问题、5 个改进方案整合。
> 按模块分组，每条包含：ID、分类、问题简述、严重度、涉及文件。

---

## 严重度定义

| 级别 | 含义 |
|------|------|
| **P0** | 阻塞性 — 影响核心功能/安全/数据完整性 |
| **P1** | 高风险 — 明显技术债，短期可能出问题 |
| **P2** | 中风险 — 可维护性/可观测性/性能问题 |
| **P3** | 低风险 — 代码风格/命名/文档问题 |
