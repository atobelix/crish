## 冲突热点文件及串行化策略

| 文件 | 涉及工作包 | 策略 |
|------|-----------|------|
| `SettingsPanel.tsx` | T2, T3, T4, T5 | 最高冲突，建议同一 agent 或严格分块 |
| `clientApi.ts` | T5, T4 | 建议同一 agent 处理 |
| `ChatCard.tsx` | T6 | 独立，不与 T2/T3/T4 同 agent |
| `skillsApi.ts` | T1, T2 | T1 优先，T2 紧随 |

| `schema.ts` | P1-A | 独占，迁移期间保持兼容导出 |
