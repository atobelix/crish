## 三、物理拔除伪兼容与 SOTA 单轨替代论证

### 1. 物理切除 `flow_graph_advance.rs` 进程级全局静态互斥锁补丁（PC-11）

- **原代码缺陷**：历史补丁为了逃避修改 `FlowGraph` 结构体，外挂了进程级全局静态 `static DECLARATION_ORDER_CACHE: OnceLock<Mutex<HashMap<String, CachedDeclarationOrder>>>`。导致跨会话严重锁争用，且会话结束后条目永不释放，造成内存永久泄漏。
- **SOTA 单轨替代**：在 `advance_flow_graph` 局部栈上按需建立轻量级索引，节点 ID 查找从 $O(V^2)$ 线性循环优化为 $O(1)$ 局部查找，完全消除全局锁与内存泄漏。

### 2. 物理切除 `steering_queue.rs` 废弃 `context_state` 伪兼容分支（PC-09）

- **原代码缺陷**：已废弃的 `context_state` 构造器与 `CONTEXT_STATE_GROUP` 分支残留在热路径中，导致 `has_pending` 必须以 $O(N)$ 遍历全队列过滤该废弃分组。
- **SOTA 单轨替代**：物理切除该废弃构造器与过滤逻辑，`has_pending` 恢复为纯粹的 $O(1)$ 检查 `!self.items.is_empty()`，同时在 `src-tauri/src/run/` 中全面切除其引用。

### 3. 物理切除 210 行孤儿死文件 `cli_bridge.rs`（PC-13）及退役僵尸 Tauri 命令（PC-14, PC-15）

- **原代码缺陷**：`apps/agent-workbench/src-tauri/src/cli_bridge.rs` 从未被 `main.rs` 引入，是历史 Node 架构遗留的 211 行调用 `npm.cmd` 的孤儿文件；`perf/encoding.rs` 与 `markdown_commands.rs` 残留退役且仅靠 `#[allow(dead_code)]` 掩盖的废弃命令。
- **SOTA 单轨替代**：直接物理删除 `cli_bridge.rs`；切除退役命令包装，保留底层纯逻辑函数，代码库净收敛。

### 4. 彻底消灭 Markdown 热路径动态编译 7 个正则与伪静态 `Lazy`（PC-21, PC-22）

- **原代码缺陷**：`strip_thought_placeholders` 每次渲染现场动态执行 7 次 `Regex::new(...)` 编译并引发 7 次全量堆分配；`handle_task_marker` 逆向全文正则扫描重分配整个 HTML（$O(M \cdot |HTML|)$）。
- **SOTA 单轨替代**：全部提升为静态 `static Lazy<Regex>` 并引入无特征子串零拷贝快速预检（< 50ns 直通）；`handle_task_marker` 优化为从尾部 `rfind("<li")` 原位替换，复杂度严格收敛至 $O(1)$。

### 5. 零分配流式哈希 `Fnv1aWriter`（SL-PERF-14）与零拼接安全点扫描（SL-PERF-08）

- **原代码缺陷**：`cache_tracker::message_hash` 仅预分配 64B `Vec<u8>` 却拼接整条消息（50KiB 工具输出）并重序列化 JSON；`safe_point` 倒序拼接全量字符串。
- **SOTA 单轨替代**：实现栈上零分配 `Fnv1aWriter(u64)`（实现 `io::Write` 与 `fmt::Write`），在序列化过程中流式吸入字节，实现严格的 0 字节堆分配；安全点扫描直接在文本切片上滑动匹配，消除巨型堆拼接。
