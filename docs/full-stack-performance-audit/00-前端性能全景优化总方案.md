### 1. 物理双轨状态隔离红线（Strict State Bipartition）

- **流式期间 0 触碰持久化树**：所有高速推流（正文、思考、工具调用进度）严禁写入 `useSessionStore`，全量收敛至裸 Zustand 临时热容器 `useStreamingStore`。
- **终态单事务写入**：流结束时通过复合原子 Action `finalizeStreamingTurn` 一次性完成状态合并，并使用 `queueMicrotask` 异步排空热容器，彻底消除流式期间全分屏级联重绘与流终态白屏闪烁。

### 2. 渲染管线零强制同步布局红线（Zero Forced Reflow）

- **测量与排版绝对分离**：任何高频击键（Composer）、视口滚动（VirtualScroll）、分屏拖拽（Resizer）事件回调内，**严禁在修改 DOM 样式同帧内读取** `offsetHeight`、`scrollHeight`、`clientWidth` 或调用 `getBoundingClientRect()`。
- **几何优先原生消费**：`ResizeObserver` 回调必须优先解构消费 `entry.borderBoxSize[0].blockSize`；高度与滚动位置计算优先基于内存数据结构（树状数组/Canvas 指标）纯数学推导。

### 3. 长会话资源有界性红线（Strict Resource Boundedness）

- **撤回栈与快照真实计税**：`MessageSnapshots` 必须采用纯差量（Pure Delta）补丁，刚性执行 5MB 上限；会话软逐出时即刻释放快照栈。
- **终端后台门闩有界环形截断**：`BoundedRingWriteGate` 严格限制 512KB 字符窗口，后台持续输出溢出时滑动淘汰最老块，切回前台以 32KB/帧 平滑排空，彻底终结切回主线程秒级卡死。
- **全仓缓存禁止无界增长**：全仓所有模块级 `Map`、`Set`、LRU 缓存均必须设立明确容量上限（64~2048 槽位），严禁满额断崖式全表 `.clear()`。

### 4. 交互期间全局观察器冻结红线（Interaction Layout Freezing）

- **Resizer 拖拽 100% 挂起观察器**：二叉树分割线、侧边栏宽度、工具栏抽屉调整拖拽期间，必须显式调用 `beginLayoutInteraction`，全树挂起 `ResizeObserverManager`，仅更新局部差量 CSS 变量，确保 120fps 满帧无卡顿，交互释放后单帧集中 Flush。

### 5. 跨模块单一真理源与语法对齐红线（SSOT & Grammar Alignment）

- **双向解析契约统一**：富文本输入器（Tiptap）、块编辑器（Block Paper）与增量 Markdown 解析器在 Mention、数学公式 `$$`、下划线标识符 `_` 以及代码围栏的语法规则上必须 100% 对齐，杜绝两套解析器行为漂移。
- **生命周期调度唯一入口**：会话删除与清理必须全量收口至 `SessionLifecycleRegistry`（SLR），无论上层从何种入口触发，必须确保 12 处模块级容器自洁、PTY 进程杀死与内存回收。

### 6. 构建拆包纯逻辑封闭红线（Pure Logic Bundle Isolation）

- **Store 零 UI 依赖**：数据层 Store（Zustand、API Client、IPC Codec）绝对禁止静态导入 UI 组件、图标、样式表或重型工具库，打破 Rollup 贪婪分包黑洞与双向循环依赖。

### 7. 反过度设计红线守护（Anti-Overengineering Compliance）

- 坚决杜绝以 95% `React.memo` 覆盖率作 CI 硬门槛、严禁引入内核级沙箱、严禁引入 SharedArrayBuffer 环形缓冲。所有优化聚焦于真实瓶颈的净收敛。

### 1. 协议一：流式行-块几何测量与无抖动补偿协议（BlockGeometryBook Protocol）

- **参与方**：`Part 02 流式引擎` $\to$ `Part 04 增量 Markdown` $\to$ `Part 03 虚拟滚动`
- **协议语义**：
  1. 增量 Markdown 解析器将文本划分为「已封口稳定块（Frozen Blocks）」与「尾部活跃块（Active Tail Block）」。
  2. 封口块首次测高后立即调用 `observer.unobserve(el)` 永久移出测量队列，几何高度不可变固化；
  3. 活跃尾块样式声明 `contain: layout style`，仅向虚拟滚动管理器以 16ms 节流上报高度增量；
  4. 当 Worker 后台完成异步代码高亮或 KaTeX 渲染回填 DOM 导致高度突变 $\Delta h$ 时：
     - 若位于当前视口上方（Above Viewport），触发**无抖动原子滚动补偿（Anti-Jitter Scroll Anchoring）**：在同一帧内执行 `spacer.style.height += \Delta h` 并同步补偿 `container.scrollTop += \Delta h`，可见视口内容物理像素实现 **0 漂移**；
     - 若处于贴底状态（At Bottom），直接追随平滑滚动；若处于阅读交互态，视口维持绝对静止。

### 2. 协议二：重型工具待机休眠与无缝恢复协议（Dock Standby & Rehydrate Protocol）

- **参与方**：`Part 06 多窗格分屏布局` $\to$ `Part 07 重型工具视图` $\to$ `Part 08 UI 合成管线`
- **协议语义**：
  1. 分屏 Dock 标签页切换至后台（`display: none`）时，宿主组件下发 `DockVisibilityContext { isVisible: false }`；
  2. 终端 Xterm 挂起 WebGL 渲染循环与光标闪烁，PTY 输出无缝切换至 `BoundedRingWriteGate` 512KB 有界环形缓冲；Diff 视图完全休眠 Worker 高亮派发；内置预览页向 iframe 发送挂起消息；DAG 编排图与后台任务停止 3s/1s 轮询；
  3. 切回前台激活时，原地保留 DOM 节点与 WebGL 上下文（零闪白、零纹理重建），`BoundedRingWriteGate` 以 32KB/帧分片平滑流式排空，首帧交互延迟严格控制在 $\le 16\text{ms}$ 以内。

### 3. 协议三：会话生命周期级联自洁协议（Session Lifecycle Cascade Protocol）

- **参与方**：`Part 01 状态管理` $\to$ `Part 09 内存生命周期` $\to$ `Part 08 UI 浮层栈` $\to$ `Part 10 冷启动`
- **协议语义**：
  1. 在 `sessionCrudActions.deleteSession` 核心原子入口直接触发 `SessionLifecycleRegistry.emit('delete', sessionId)`；
  2. SLR 具名调度中枢同步广播，自动注销该会话在 12 个模块级容器（Probes、HydrateTokens、Signatures、Buffers、Drafts 等）的全部残留条目；
  3. `PtyRegistry` 通配提取该会话下所有终端前缀（`${sid}:terminal:*` 与 `${sessionKey}:split-*`），批量向 Rust 发送 `pty_kill` 杀死后台子进程并释放历史缓冲；
  4. `LayerStackManager` 遍历浮层栈，关闭绑定于该会话的所有上下文菜单与对话框，并通过 `WeakRef` 断开 DOM 强引用，使内存精准回落至初始水位。

## 五、立体化性能验收门禁体系（Verification & Guardrails）

为保证所有性能提升指标确凿落地、严防后续迭代代码回潮，工程设立 **三层立体化防退化门禁**：

### 1. 第一层：CI 静态语法与构建预算刚性门禁（编译期阻断）

- `scripts/check-chunk-cycles.mjs`：Rollup 产物有向循环依赖检测，**有向环数量严格为 0**，退出码非 0 阻断 CI；
- `scripts/check-startup-budget.mjs`：首屏同步加载图体积上限严格收紧至 **$\le 980\text{ KiB}$**（主包入口 $\le 280\text{ KiB}$），禁止任何未白名单模块混入首屏；
- `scripts/check-perf-ui-css-guardrails.mjs`：静态扫描全仓 CSS 与样式文件，**刚性拦截**任何新增的 `[class*='...']`、伪元素空格、`transition: all`、非合成 `will-change` 以及 `body.leaf-dock-resizing *`。

### 2. 第二层：Vitest 自动化确定性契约测试（单元与集成层）

- **状态拓扑隔离测试**：断言单会话追加 100 条消息时，全局 `sessionIds` 引用与无关分屏会话引用严格保持不变，重渲染次数为 0；
- **持久化防抖测试**：断言在 60Hz 流式推流持续 5 秒期间，主线程调用 `localStorage.setItem` 的次数精确为 **0 次**；
- **虚拟滚动倍增寻址单测**：断言在 5,000 条非等高消息列表中，1,000 次随机偏移寻址总耗时 $\le 5\text{ms}$，二分倍增步数 $\le 13$ 步；
- **内存自洁测试**：断言连续创建 50 个复杂会话（包含终端与附件）后全量硬删除，12 处模块级 Map/Set 长度精确归零，底层 PTY 进程存活数为 0。

### 3. 第三层：桌面端真实宿主现场验收基线（Tauri MCP 4000 现场测定）

在真实 WebView2 / Tauri 宿主环境下，通过 Tauri MCP Socket（`127.0.0.1:4000`）执行端到端物理验收：

- **首屏冷启动**：从进程唤起到首屏交互就绪（LCP / TTI）时间由 1,200ms 下降至 **$\le 380\text{ms}$**；
- **输入延迟**：在 500 行长文本草稿中快速连续打字，单按键事件主线程耗时（Input Latency）严格 **$\le 1.0\text{ms}$**；
- **分屏拖拽帧率**：在打开终端、Diff 与长聊天的 4 分屏复杂布局下拖拽分割线，120Hz 屏幕实测稳定 **$\ge 115\text{fps}$**，长任务（>50ms）为 0；
- **长会话流式帧率**：在累积 500 条消息的大会话中持续流式输出，列表滚动与界面帧率稳定保持在 **$\ge 58\text{fps}$**（60Hz 屏幕）；
- **终端切回耗时**：隐藏终端积压 10 万行日志时切换至前台 Tab，主线程阻塞时间由 2,500ms 降至 **$\le 16\text{ms}$**；
- **长期驻留内存基线**：全功能重度使用 4 小时后，Vite/V8 堆内存占用稳定控制在 **$\le 180\text{MB}$**，删除所有会话后内存偏差 $|M_1 - M_0| \le 5\text{MB}$。
