# 移动端界面设计规范（crish-mobile）

> 隶属：`docs/mobile-app-rebuild/`
> 定位：移动端设计系统单一真源。所有页面与组件按本文实现，不再逐页自造样式。
> 对齐：桌面 `apps/crish-desktop/src/styles/tokens-*.css`；移动端在字号 / 触控尺寸上做适配，不改变视觉语言。

---

## 1. 设计原则

1. **布局解释一切**：分组、层级、留白已经表达关系，不再用副标题重复解释「这是什么」。
2. **少标签，多状态**：能用颜色点、图标、位置表达的，不加文字标签（如「运行中」「未读」用点 + 数字，不用长 chip）。
3. **主路径唯一**：每屏一个主操作；次要操作进图标按钮或更多菜单。
4. **内容优先**：卡片无重阴影、无渐变、无装饰边框；发丝线 + 表面色分层。
5. **与桌面同语言**：品牌绿、暖灰画布、发丝线、克制的圆角与字阶；移动端只放大触控尺寸与正文。
6. **诚实**：不展示未实现功能；错误给人话，技术码只进诊断区。

### 2.2 使用纪律

- 组件只消费语义 token，禁止裸 hex / rgba（阴影与遮罩除外，统一走 `shadow` / `scrim` token）。
- 语义色只用于状态，不作大面积背景。
- 品牌绿面积受控：主按钮、激活 Tab、开关、链接、少量强调；不让整页泛绿。
- 深色板独立定义，不做浅色取反。

## 3. 字体与排版

| Token | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `display` | 28 / 34 | 700 | 配对欢迎、根级大标题 |
| `title` | 22 / 28 | 700 | 页面大标题（Tab 根） |
| `heading` | 20 / 26 | 600 | 卡片主标题、详情标题 |
| `subhead` | 17 / 24 | 600 | 列表主文字、按钮 |
| `body` | 15 / 22 | 400 | 正文、对话 |
| `bodyStrong` | 15 / 22 | 600 | 强调正文 |
| `meta` | 12 / 16 | 400 | 时间、辅助信息 |
| `caption` | 11 / 14 | 500 | 徽标、极小标注 |
| `mono` | 13 / 20 | 400 | 终端、代码 |

规则：
- 正文默认 15（移动端可读性），不再出现 13/14 混用。
- 一屏最多 3 个字阶；标题与正文之间至少差 2 档。
- 数字（时间、计数）使用 `fontVariant: ['tabular-nums']`。
- 不写死 `fontFamily`（系统默认），终端使用平台等宽字体。

## 4. 间距 / 圆角 / 尺寸

### 4.1 间距（4pt 阶梯）

`space.xs=4` · `sm=8` · `md=12` · `lg=16` · `xl=20` · `xxl=24` · `section=32`

- 页面水平内衬：16（根列表 / 详情）；卡片内衬：16。
- 分组间距：24；组内行间距：0（靠分隔线）；段落间距：12。
- 图标与文字：8；行内小元素：4/6。

### 4.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius.xs` | 4 | 小徽标、内嵌小控件 |
| `radius.sm` | 8 | 按钮、输入框、行内块 |
| `radius.md` | 12 | 卡片、分组容器、Sheet 内卡 |
| `radius.lg` | 18 | Sheet / Dialog 外框 |
| `radius.pill` | 9999 | 仅 Badge、分段控件、composer 胶囊 |
| `radius.input` | 20 | 会话 composer 主输入 |

- 禁止 10/14/16/17/23 等自由值。
- 嵌套容器同心：外圆角 = 内圆角 + 内边距（仅在必要时）。

### 4.3 尺寸

| Token | 值 | 用途 |
| --- | --- | --- |
| `size.touch` | 44 | 最小触控 |
| `size.touchLarge` | 48 | Android 主按钮 |
| `size.icon` | 20 | 默认图标 |
| `size.iconSmall` | 16 | 行内图标 |
| `size.iconLarge` | 24 | Tab / 空态 |
| `size.row` | 56 | 列表行最小高 |
| `size.rowTall` | 64 | 会话行 |
| `size.header` | 44（内容）+ 安全区 | 紧凑头栏 |
| `size.tabBar` | 49 + 安全区 | 底部 Tab |

### 4.4 动效

- 只做**状态解释**，不做装饰：出现 / 消失 / 层级切换，必须有信息意义。
- 列表与时间线新块：180ms 淡入 + 6px 上移（opacity 0→1，translateY 6→0）；流式正文复用同一节点更新，禁止重挂载重播动画。
- 审批弹窗：`presentation: transparentModal` + `animation: fade`，遮罩同步淡入；关闭反向淡出，不做弹簧。
- Sheet：系统 slide 或 220ms 缓出；Toast 淡入 + 轻微上移。
- 统一使用 `ease-out` 曲线；禁止回弹、抖动、无限循环吸引注意（骨架脉冲除外）。
- reduce-motion：所有位移与缩放降级为纯淡入或直接切换。

## 5. 组件契约

### 5.1 `Screen`
- Props：`children`、`background`（默认 canvas）、`edges`（默认 all）、可选 `scroll`。
- 统一处理安全区；内容不被状态栏 / 手势条遮挡；不负责导航。

### 5.2 `AppHeader`
两种形态：
- `large`：Tab 根页。大标题（title）+ 右侧最多 2 个图标动作；可选下方副行状态（仅连接状态）。
- `compact`：二级页。左侧返回图标（`chevron-left`，44 热区），中间标题（居中），右侧最多 1 个图标动作。
规则：
- 不出现「← 返回」文字；返回仅为图标 + 无障碍标签。
- 头栏背景 = 页面底色，底部发丝线可有可无；滚动时保持固定。
- 标题 1 行截断。

### 5.3 `AppText`
- `variant` 见字阶；`color` 语义名（`primary/secondary/tertiary/danger/warning/success/info`）。
- 禁止页面直接写 `fontSize/fontWeight/color`（终端 / 特殊展示除外）。

### 5.4 `Icon`
- 图形库与桌面端一致：Hugeicons（`@hugeicons/react-native` + `@hugeicons/core-free-icons`），保证两端图标语言统一。
- `name` 为语义受控枚举（`IconName`），映射表在 `src/presentation/ui/iconData.ts`；页面不得直接从图标库导入。
- 每个图标按子路径单独导入（`@hugeicons/core-free-icons/<Name>Icon`），禁止从包根聚合导入（Metro 会因索引文件过大触发 EMFILE）。
- `size` 默认 20（行内 16 / Tab 与空态 24）；`color` 默认 `text.secondary`；`strokeWidth` 固定 2，与桌面一致。
- 不内嵌文字、不使用 Emoji；图标按钮必须带 `accessibilityLabel`。

### 5.5 `Button`
- 变体：`primary`（品牌绿实底）、`secondary`（surface + 描边）、`ghost`（透明）、`danger`（红实底）。
- 高度 48；圆角 8；字号 subhead/500；水平内衬 20。
- 加载态：左侧 16 spinner + 文案，按钮宽度不跳变（固定最小宽）。
- 禁用：opacity 0.5；不改变布局。

### 5.6 `IconButton`
- 44×44；图标 20；透明底，按压 `bg.subtle`；可带角标（绝对定位右上）。

### 5.7 `Input`
- 标准表单 / 搜索：高 48，圆角 8，`bg.subtle` 底，`border.strong` 描边；聚焦时描边为 `border.strong` 与 `text.primary` 的 ~5% 混合，**禁止黑框 / 重阴影**。
- Composer：高自适应，圆角 20，`bg.surface` 底 + 发丝线；聚焦同样柔和。
- 下拉 / 浮层内搜索：透明底、无边框、无阴影，只有光标（项目四态规范形态 ④）。

### 5.8 `ListRow`
- 结构：`leading`（可选图标 / 头像） + `content`（title + optional subtitle） + `trailing`（value / badge / chevron / switch）。
- 最小高 56；水平内衬 16；分隔线只画在内容区右侧（从文字起点开始），首行与分组底部不画。
- 副标题只在**携带真实补充信息**时出现（时间、来源、错误原因），不用来解释标题。
- 点击反馈：整行 `bg.subtle`，无缩放。

### 5.9 `SectionHeader`
- 小号 `caption` 大写字距，`text.tertiary`；仅用于分组列表；Tab 根页不用。

### 5.10 `Card`
- 表面 `bg.surface`，圆角 12，发丝线描边（或无描边，仅与 canvas 色差）；内衬 16；无阴影。
- 卡片之间间距 12；卡片内元素间距 8/12。
- 卡片不嵌套卡片（必要时用 `bg.subtle` 内块）。

### 5.11 `Badge`
- 圆点：6–8px；数字：最小 18×18、pill、caption/600。
- 颜色：未读/危险红、待审批 warning、运行绿、普通中性。
- 数字 >99 → `99+`；0 不显示。

### 5.12 `SegmentedControl`
- 高 36–40，圆角 pill，底 `bg.subtle`，选中块 `bg.surface` + 轻微描边；文本 body/500。
- 仅 2–4 项；超过 4 项用 Sheet 单选。

### 5.13 `EmptyState`
- 图标（24–32，tertiary）+ 标题（subhead）+ 可选一个动作按钮。
- 不写副标题解释；若必须提示操作，用动作按钮文案表达。
- 垂直居中或列表顶部 64 内衬，二者全 App 一致。

### 5.14 `Sheet`
- 使用 RN `Modal`（transparent, animationType slide）+ 底部安全区；顶部圆角 18；拖拽指示条可选。
- 最大高度 85%；内容可滚动；关闭：遮罩 / 下滑 / Android 返回。
- 用于：发起任务、工作区选择、排序、更多操作。

### 5.15 `Dialog`
- 使用 RN `Modal`（fade）；宽 min(320, screen-48)；圆角 18；标题 heading；正文 body；按钮纵向排列（危险动作最后）。
- 必须处理 Android 返回键与遮罩点击取消。

### 5.16 `Toast`
- 底部（Tab 上方）悬浮，圆角 pill，surface + 发丝线 + 轻阴影；2.5s 自动消失。
- 只用于操作结果（已提交、已全部已读、已断开、复制成功）；错误用 Toast + 可重试动作，不在页面顶部堆横幅。

### 5.17 加载态
- 首屏数据未就绪：`Spinner` 居中；不以骨架块伪装真实内容。
- 已有数据刷新：保留列表 + 下拉刷新，不清空、不回退到加载态。
- 加载完成且确实为空才显示 `EmptyState`（避免「还没有会话」闪现）。

## 6. 页面布局规范

### 6.1 Tab 根页
```
[SafeArea]
大标题（title）                     [动作图标]
可选：连接状态行（仅非 ready 时出现）
内容（列表 / 卡片，水平 16）
[TabBar]
```

### 6.2 详情页
```
[SafeArea]
[chevron-left]      标题（居中）        [动作]
可选：状态行（小号，meta）
内容
可选：底部固定操作区（安全区 + 发丝线）
```

### 6.3 会话详情
- 时间线内容左右内衬 20，块间距 20；助手消息为无边框正文，用户消息为右侧浅灰圆角气泡（最大宽度 82%，右下角收小），不使用绿色大面积气泡。
- 工具调用：折叠行（圆形/圆角浅底容器 + 图标 + 名称 + 状态 + 一行摘要），点击展开等宽输出；审批：圆角卡片；错误：danger 文本；系统提示：居中 caption。
- Composer 固定底部、白色胶囊（圆角 20）+ 柔和浮层阴影；输入单行可横向滚动，发送按钮 44 圆形；未连接时输入禁用但仍显示发送按钮的禁用态。
- 滚动上翻暂停吸底；「回到底部」为小 pill，仅在离开底部时出现。
- 新块进入使用 180ms 淡入 + 6px 上移（FadeIn）；流式正文同节点更新，不重挂载。

### 6.3.1 审批
- **审批详情以底部弹窗呈现**（路由 `presentation: transparentModal`）：遮罩 + 24 圆角底部卡片 + 拖拽指示条；关闭按钮在右上。
- 内容：会话标题（meta）→ 工具名 + 风险徽标 + 倒计时 → 命令/参数摘要块 → 主 Agent 只读说明（如有）。
- 底部操作：拒绝（secondary）+ 允许（primary）等宽；L2 允许改为滑动确认；弹窗内不重复页面头栏。
- 列表页保持轻量卡片列表；历史入口使用圆形图标按钮。

### 6.4 审批列表
- 列表卡：工具名（subhead/600）+ 风险徽标 + 倒计时（右）+ 命令摘要（2 行）+ 会话标题 + 时间。
- 点击进入 §6.3.1 底部弹窗；列表本身不直接放允许 / 拒绝按钮，避免误触。
- 剩余 15s 倒计时变 danger；过期后卡片转为只读历史样式。

### 6.5 文件
- 头栏：返回 + 当前目录（或工作区名）+ 更多（刷新 / 排序 / 切换工作区）。
- 面包屑：横向滚动，仅显示末两级 + `…`；当前目录高亮。
- 行：文件类型图标（16–20）+ 名称 + 大小 / 时间（meta）；目录有 chevron。
- 预览：标题 + 相对路径（meta）+ 内容（等宽、行号可选）；顶部敏感提示为细条，不是大卡片。

### 6.6 设置
- 分组：连接、外观、通知、关于、危险区。
- 行：图标 + 标题 + 右值/开关；副标题仅在必要时（如权限被拒绝的原因）。
- 本地偏好离线可用；远端能力（重新连接）在离线时禁用并给出一句原因。
- 解除配对：危险区一行 + Dialog 确认。

### 6.7 配对
- 欢迎：品牌图标 + display 标题「连接桌面」+ 一句说明（仅一句）+ 「扫描二维码」主按钮 + 「手动输入」文字按钮。
- 扫码：全屏相机 + 中央取景框 + 顶部关闭 + 底部提示「对准桌面端二维码」；权限拒绝时给「去设置」。
- 手动：主机、配对码、端口（高级折叠）；主按钮「连接」；错误内联显示；返回脏输入确认。

## 7. 文案规范

- 用户文案不使用：`run`、`session`（用「会话」）、`phase`（用「连接状态」）、`schema`、`buffer`、`token`、`F1 §4.7`、`M4 §5.9`、`R2UX` 等。
- 空态标题 ≤ 8 字；说明 ≤ 20 字，且只在必须解释下一步时出现。
- 按钮文案用动词：「连接」「重试」「允许」「拒绝」「继续对话」「全部已读」「解除配对」。
- 错误文案结构：发生了什么 + 下一步（「无法连接桌面，请确认在同一网络后重试」）。
- 不在界面中显示原始 ID；需要区分时使用短 ID（前 4–6 位）并放在诊断 / 设置中。
- 全系统禁用 Emoji；状态用图标 / 色点 / 文字。

---

## 8. 无障碍

- 所有可点击元素 `accessibilityRole` + 明确 `accessibilityLabel`；图标按钮必须带标签。
- 触控目标 ≥44×44；小图标用 hitSlop 补足。
- 状态不能只靠颜色：未读同时有数字，运行同时有文字 / 图标，错误同时有文案。
- 支持动态字体：不写死行高导致截断；`maxFontSizeMultiplier` 默认不限制，关键按钮最大 1.3。
- reduce-motion：骨架脉冲、滑动回弹、Sheet 动画降级为无 / 静态。
