## 4. 分层与依赖规则

- `presentation` 不得 import `expo-router`、`@/adapters/wiring`（仅 route 注入回调）。
- `presentation/ui` 不得 import 业务域组件。
- `domain` 不得 import `network / db / presentation`（现状大体满足；`domain/store` 可依赖纯函数）。
- `network` 不得 import `domain`（WsPhase 已归位；继续保持）。
- `app/` 只做路由、守卫、参数解析、导航注入。
- 新增移动端样式守卫脚本：
  - 禁 `#[0-9a-fA-F]{3,8}`（theme 文件除外）
  - 禁 `borderRadius: <number>`（theme / 图标除外）
  - 禁 Emoji（U+1F300–U+1FAFF / U+2600–U+27BF）
  - 禁 `from 'expo-router'`（`app/**` 除外）
  - 禁 `Alert.alert`（改用 Dialog / Toast）
- 行数预算：移动端 UI 组件 ≤ 400 有效行、业务 ≤ 350、screen ≤ 300；超限拆分。
