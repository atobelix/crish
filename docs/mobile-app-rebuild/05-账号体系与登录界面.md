# 05 · 账号体系与登录界面（桌面 + 移动）

> 状态：**已实现**（2026-10-29）；桌面账号中心与移动端账号流程均已接线到生产账号中心，密码登录 / 资料 / 头像 / 登录会话已用真实账号验证。
> 关联：`00-总方案.md`、`04-远程接入与账号自发现方案.md`

---

## 1. 范围

账号体系是远程控制的前提，不是装饰性入口。本轮补齐「完整账号生命周期」：

1. 密码登录、邮件验证码登录；
2. 邮箱注册（验证码确认）；
3. 找回 / 重置密码（验证码确认）；
4. 账号资料：昵称、简介、头像；
5. 登录会话列表与逐会话撤销；
6. 账号内在线设备列表（中继房间状态）；
7. 退出登录（服务端吊销 refresh token + 本地清理）。

微信扫码登录 / 账号合并 / handoff 不在本轮范围（属于账号中心其它产品面）。

---

## 2. 账号中心契约

生产 `https://auth.flowbit.me`（Fastify + SQLite），全部接口只接收/返回 JSON：
账号 token 只放 `Authorization: Bearer`，头像地址为相对路径。

| 能力 | 接口 |
| --- | --- |
| 密码登录 | `POST /api/auth/email/login/password`（email / password / deviceId） |
| 验证码登录 | `POST /api/auth/email/login/code/request` → `…/confirm` |
| 注册 | `POST /api/auth/email/register/request`（email / password）→ `…/confirm` |
| 重置密码 | `POST /api/auth/email/password/reset/request`（email / 新密码）→ `…/confirm` |
| 会话 | `POST /api/auth/refresh`、`POST /api/auth/logout` |
| 资料 | `GET /api/auth/me`、`GET/PATCH /api/auth/profile` |
| 头像 | `POST /api/auth/profile/avatar`（JSON `dataUrl`，≤3 MiB，png/jpeg/webp/gif） |
| 登录会话 | `GET /api/auth/sessions`、`DELETE /api/auth/sessions/:id` |

实现位置：`C:/Software/account-center/navigation-site/zennav-server/src/modules/auth/`。
生产部署曾存在密码登录 500（`findAccountByIdentity` 未查询头像字段），已修复并部署，见 04 §3.1。

## 3. 桌面实现

### 3.1 Rust 后端

- `apps/agent-workbench/src-tauri/src/auth/client.rs`：
  - `EmailCodeScene`（login / register / reset）统一验证码请求与确认；
  - `request_email_code` / `confirm_email_code` / `logout_remote`；
  - `AccountProfile`（get/update/avatar）；
  - `AuthSessionInfo`（list/revoke）；
  - `CloudAuthError::Rejected { status, message }`：4xx 业务错误直接透传服务端中文提示，UI 不再显示 HTTP 状态码。
- `auth/auth_daemon.rs`：
  - `apply_session` 统一持久化 refresh token（DPAPI）并更新会话快照；
  - 密码登录 / 验证码登录 / 注册 / 重置复用同一会话建立路径；
  - `wait_restored`：冷启动凭据恢复完成前，`auth_get_session` 等待首次恢复结束，
    修复「前端先读到未登录且不再刷新」的竞态；
  - 登出先尽力吊销服务端会话，再清本地凭据。
- `auth_commands.rs` 新增 7 条命令：
  `auth_request_email_code`、`auth_confirm_email_code`、`auth_get_profile`、
  `auth_update_profile`、`auth_upload_avatar`、`auth_list_sessions`、`auth_revoke_session`。

### 3.2 前端

- 全局单实例 **账号中心** `components/account/AccountCenterDialog.tsx`：
  - 未登录：登录（密码 / 验证码）、注册、找回密码；
  - 已登录：头像、昵称、简介、在线设备、登录会话、退出登录。
- 入口（三处，均直达同一浮层）：
  - 侧栏用户卡片：未登录显示「登录账号」；
  - 侧栏快捷设置菜单第一项：登录账号 / 当前账号；
  - 设置 → 账号：状态卡 + 「登录 / 注册」/「管理账号」。
- `store/authStore.ts`：登录、资料、在线设备、登录会话统一状态；
- `api/authApi.ts`：与 Rust 命令一一对应的类型化调用；
- CSP：`vite.config.ts`（dev + prod）与 `tauri.conf.json` 的 `img-src` 放行
  `https://auth.flowbit.me`，头像可在 WebView 内加载。

界面纪律：沿用现有 Dialog / Input / Textarea / Button / SegmentedControl 与设计 token；
不新增装饰性标题与说明文案，布局自解释。

## 6. 边界

- 邮箱验证码注册/重置依赖账号中心 SMTP 可达；发送失败会以服务端错误消息返回。
- 账号中心没有设备注册表，「在线设备」来自中继房间；「登录会话」来自账号中心 sessions，
  两者语义不同（在线 vs 登录态）。
- 撤销会话只吊销 refresh token；对方 access token 最长 15 分钟内仍有效，立即断连由
  中继连接生命周期/退出登录保证。
- 头像 URL 域名固定为 `auth.flowbit.me`；若账号中心迁移域名，需要同步 CSP 与
  客户端头像解析基准。
