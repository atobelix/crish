# 模型配置产品链闭环修复总方案

> **权威工作区**：`docs/model-config-product-chain/`
> **文档性质**：主控合并后的最终总方案。实现 Agent 读本文件 + 本维 `plans/0N` + 上轮报告，不必读历史会话。
> **合并输入**：`00-调度与执行纪律.md`（L1–L12）；独立总计划 `independent-plans/01`（数据流闭环切）、`02`（运行时单一入口切）；分维指示 `plans/01`–`08`；二次审计 11–21。
> **取舍键**：效果完整度 → 正确性/不变量 → 可验证性 → 与 L1–L12 一致 → 结构干净。禁止工期、人员、P0、MVP、流行栈。
> **前序旧 00**：`docs/provider-model-unification/00-全线打通与净收敛系统性实现总方案.md` **仅第二节三条原则有效**（thinking 拍平、cacheRead 独立单价、字典仅预填）。其余「已打通」句作废。

## 0. 本产品要做什么

用户在设置里配置的模型能力，必须就是发消息时模型真正用到的能力，也必须就是账单上的数字所依据的牌价。中间不允许再有一份 LocalStorage、一份 `catalog.json`、一份 URL 猜测来「帮忙」。

完成定义不是「系统里有 yaml 模块」。完成定义是下面这条链上的每一个动词都能在本会话被断言：

```
设置抽屉编辑 modalities / thinking / pricing / protocol
    → 点保存
    → 磁盘 ~/.conex/models.yaml 出现同等字段
    → modelsCatalogStore 与 live_catalog 同时反映该树
    → Composer 模型徽标 / 思考档位 / 附件入口读同一棵树
    → 用户选档位、发消息（纯文本或带图）
    → 出站 HTTP JSON 含 yaml 字典映射出的 wire 键值
       （无图模型若带图：入口不可挂，出站硬拒，不得静默改成文本）
    → SSE usage 进入 PricingEngine
    → 会话 UI 展示的费用 = 微元定点结果
```

视觉（token、四态输入、思考区物理卸载、保存钮可达）是同一条链的用户面。没有真实数据链的样式修补视为未完成。

模块内「函数被调用 / 单测绿 / 命令已注册」不得关账。

## 1. 双脊柱（合并两份独立总计划）

两份独立总计划效果锁相同、切分角度不同。主控全部吸收，不选弱的那条。

| 脊柱 | 来源 | 在本方案中的角色 |
| --- | --- | --- |
| **数据是否还活着（R0→R6）** | 独立总计划 01 | 产品叙事与验收：草稿 → 磁盘 → IPC → 双镜像 → HTTP → 费用。每一环只允许投影，不允许换一份无关字节冒充。 |
| **I-LOOKUP** | 独立总计划 02 | 运行时不变量：进程内只允许 `lookup(provider_id, model_id) → ModelSpec`。协议、思考字典、模态、价格、窗口都从这一次命中长出。 |

拒绝的假换源：把 yaml 灌进旧扁平 `ModelCatalog::lookup`（带后缀/`*`/跨厂商 `[0]`），再宣称「已经是 live」。树对象第一公民是 `UnifiedModelsConfig`；扁平目录若暂留，只能是丢失信息的调试投影，禁止生产消费。

```
R0  设置草稿
      ↓ saveConfig（唯一写）
R1  ~/.conex/models.yaml  v2 providers 树
      ↓ workbench_read/save，消费 providers
R2  同构 DTO
      ↓ 同时灌
R3  modelsCatalogStore          前端唯一镜像
R4  live_catalog()              内核唯一镜像
      ↓ lookup(provider_id, model_id)
R5  HTTP JSON = 字典与 modalities 的函数
R6  费用 = PricingEngine(yaml 四维单价, usage)
```

## 2. 主控合并裁决（原独立计划冲突表）

下列一经写入总方案，分维不得再开平行解。未缩小效果锁。

| ID | 议题 | 裁决 |
| --- | --- | --- |
| M1 | 选中思考档是否写入 yaml | **不写 yaml。** yaml 只存可用字典。选中 TitleCase 活在会话运行时（S3 交给 S4 的 handoff）。效果锁未要求「杀进程后仍记住档位」；若会话仓已有偏好可继续当会话态，不得变成第二份模型规格。 |
| M2 | `EngineProviderConfig` 扩字段 vs 每次 lookup | **两者都要，职责不同。** S1 必加 `provider_id: String`（lookup 键，空则引擎未就绪）。`request_options` **每次**用该键 `live_catalog().find`，保证 yaml 保存后下一请求立即吃到新字典，不必重建 Handle。配置结构上的 `thinking_map` 等槽位不得充当过期副本：`request_options` 禁止 `..Default::default()` 清空后再走前缀表。 |
| M3 | flatten `models` 数组 | **生产路径删除消费。** DTO 若暂留 `models`，注释必须写明 lossy、禁止 Store/live 读取。禁止为「喂 store」去补全 flatten。 |
| M4 | 未注册 `models_yaml_*` | **删除前端生产调用与测试桩。** 不登记这三名来「让测试绿」。只保留 `workbench_{read,validate,save}_models_yaml`。 |
| M5 | `capabilities` vs `modalities` | 运行时只信 `modalities.input/output`。`capabilities` 仅 S2 一次性导入只读；S7 删除双写。 |

| M11 | `context_window` 必填会逼出 128000 | 改为 `Option`。UI 缺省显示「—」。引擎不发明 128000 / 128k。用户要钳制必须自己填。 |

| M13 | lookup Miss 时能否用 env 三件套发请求 | **不能。** Miss → 引擎未就绪。env 只用于**创建** yaml 供应商，不绕过 lookup。 |
| M14 | Gemini JSON 路径注释打架 | 以 yaml 字典 value + 该协议官方字段为准，S4 用抓包/集成测钉路径。禁止用过期注释当 SSOT。 |
| M15 | 无 `protocol` 字段 | S2 保存时若供应商未填，**写出** `openai/chat` 到 yaml（磁盘上有字面量）。运行时禁止 URL 猜。lookup 不到供应商 → 未就绪。 |
| M16 | 全局 `x-deepseek-harness-session-id` | 删除无条件注入。需要时写在 yaml `providers.*.headers`。 |
| M17 | `--surface-primary` | 禁止新增该 token。用已有 `--bg-*`。`--brand` 本体若仍是 `#10b981`，S6 不掀全仓品牌定义。 |
| M18 | S3 与 S6 同改 Composer/Picker TSX | **同文件串行。** S3 改读路径；S6 改卸载谓词与样式。S6 不发明第二套「是否思考模型」表。 |

## 3. 身份合一

下列三套 id 必须是同一个字符串，否则 I-LOOKUP 无法构造参数：

```
yaml providers.<id>  ≡  活动选择 providerId  ≡  EngineProviderConfig.provider_id
```

凭据按 `provider_id` 取。导入时 LS profile id 能对齐则沿用，不能对齐则生成稳定 id 并改选择指针。禁止运行时常驻「双 id 映射表」。

`findCatalogModel(model)` 无 `providerId` 的跨厂商 `[0]` 必须删除（S3）。

## 5. 各维必须遵守的接口（跨文档锁）

### 5.1 磁盘树形状（S1 输出，S2 写入，S3/S4/S5 读取）

只许 v2 `providers` 树。写出键名：`contextWindow`、`input`/`output`/`cacheRead`/`cacheWrite`、`google/generate-content`、拍平 `thinking`。旧键只在导入边界认一次。

`defaultThinkingLevel` **不进 yaml**。

### 5.2 IPC

只打 `workbench_read_models_yaml` / `workbench_validate_models_yaml` / `workbench_save_models_yaml`。读成功 = 命令命中 ∧ `parseError` 空 ∧ `providers` 为对象（含诚实 `{}`）。禁止 `wire.tree || convertFlatModelsToTree(wire.models)`。

解析失败：保持上一份成功快照或显式错误态。禁止把坏文件吞成空 `providers` 再写盘。

### 5.3 live_catalog

```
live_catalog() -> Arc<LiveModels>
LiveModels.tree: UnifiedModelsConfig
LiveModels.find(provider_id, model_id) -> Option<&ModelSpec>
```

与 IPC **同一套** v2 解析。禁止 `DynamicYamlModalities` 第二解析器当生产投影。文件缺失 = 诚实空树，不是 `catalog.json`。

### 5.4 写路径（S2）

```
ensureLsImported（一次性）
  → ensureLoaded
  → CT-01（store 签名，不是 getModelMeta）
  → draftToModelPatch
  → modelsCatalogStore.updateModel
  → workbench_save_models_yaml
  → 成功才 models-catalog-changed
```

废止 `applyMetaForModel` / `setModelModalities|Thinking|Pricing` / `upsertPrice` 作为配置真源。未提交旧岛 setter **丢弃，不提交**。

YAML 弹窗与抽屉共写同一文件：CT-01 冲突则拒绝陈旧覆盖，不静默 LWW。

### 5.5 读路径（S3）

唯一读 API 由 S3 指示列出（`getLiveModel` / `listThinkingOptions` / `modelAcceptsInput` 等）。生产 UI 不得再读 `getModelMeta` / `thinkingGear` / `loadProfiles` 当规格。刷新只订 `models-catalog-changed`。

### 5.6 出站（S4）

```
profile = live_catalog().find(config.provider_id, config.model)
request_options.thinking_map / thinking_format / protocol 来自 profile
四条出站只走 assemble_thinking_dialect
ensure_content_modalities 唯一挂在 HttpProviderCall::stream（HTTP 前）
```

`build_chat.rs` 兜底枝（`infer_thinking_capability`）删除。无删除日期的兼容枝禁止进入产品默认。

### 5.7 计费（S5）

workbench 收口（`engine_build` / `RunUsage`）调用 `PricingEngine`。前端只渲染。三态：未定价 / 免费（四价全 0 且无阶梯）/ 有价微元。禁止 `$`+`toFixed` 与 `cost>0` 再走 JS。禁止 `input * 0.1` 填 cacheRead。

S1 未灌 `provider_id` 时本维 lookup 打空 → 全员「未定价」。禁止用 `infer_vendor` 冒充闭合，上报阻断依赖。

## 10. 明确不做
