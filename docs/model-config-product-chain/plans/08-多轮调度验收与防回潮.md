## 0. 本维效果、非目标、相邻维接口

### 0.1 本维交付的效果

交付一套**可复用**的多轮操作系统，使：

1. 每一轮的输出成为下一轮的**唯一增量输入**（不必重读聊天记录）。
2. 验收终点永远是调度 §3 的用户侧产品链，不是「符号存在 / 单测绿 / 命令已注册」。
3. 源码形状、本会话真跑测、Tauri 4000 用户路径**三栏分开记录**；任一栏缺失不得抬关。
4. 防回潮 grep/脚本有入库位置与零命中断言；S7 删除清单在 η 轮必须 grep 为零。
5. 主控按模板即可开下一轮，不必发明第二套调度语言。

### 0.2 非目标（诚实边界）

- **不改产品代码**。S1–S7 的类型、IPC、保存、出站、计费、样式、删旧轨由对应维实现。本文件只规定怎么派、怎么验、怎么传下一轮。
- **不发明第二真源**。不得在调度层允许 LocalStorage / `catalog.json` / 预填 JSON 作为运行真源「先顶一阵」。
- **不把模块内事实写成产品链闭合**。`assemble_thinking_dialect` 进入 builder、`devil_cases_tests` 28 绿、保存钮 `variant="primary"`，都只是源码形状或单测栏的证据，不能单独关账。
- **不要求 Agent 读完整聊天记录**。输入包只有：`00-总方案.md` + 本维指示 + 上轮报告（α 轮用本文件 + 调度纪律 + 总方案；总方案未落盘时用调度纪律代替，见 §7）。
- **不强制每轮 12 人**。按需 5–12；收尾轮（η，以及 δ/ε 已并入后的空轮）可不保底。同时存活 ≤16。子 Agent 深度 1。
- **不回撤工作区清旧轨**。八文件「丢弃」≠ `git restore` / `checkout` / `reset`（见 §2.5、§6）。

### 6.1 空返回（AGENTS.md §2）

子 Agent 汇报空（无最终消息/无产出）时，**默认先当供应商网络问题**：

4. 6 次以上：主控接管实现。

禁止无限原样重派而不查盘。

### 6.2 Git（AGENTS.md §3 / 附录 B）

- **只有主控提交**。子 Agent 禁止 `git commit` / `push` / `restore` / `reset` / `checkout .`。旧提示词 `实现-任务交付.md` 里「子 Agent 可用 commit --only」**作废**，以 AGENTS.md 为准。
- 主控：`git commit --only <本轮路径...>`，排除八文件与他人脏路径。
- 禁止 `--no-verify`。
- 被吞并：只验证内容完整性，完整不管归属，缺失再精确追加。
- 提交信息：`feat|fix|refactor|test|docs|chore` + 范围 + 本战役批次标记（如 `BATCH-MODEL-CHAIN-α`）。
