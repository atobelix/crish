## 根因澄清（供后续）

- 「不显示思考强度」：用户当前模型（OpenCode 的 deepseek-v4-flash / muse-spark-1.3-contributor）在 yaml 里是**裸 id**（无 thinking 字典）→ 思考槽正确物理卸载。OpenCode 的 deepseek-v4-pro 有字典则显示。**问题不是卸载逻辑，是手填模型只写了 id、没补全能力**（见遗留 #3）。
