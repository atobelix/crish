## 四、执行纪律

1. **严格文件互斥**：每位 Agent 仅允许修改自己专属范围内的文件，严禁跨域修改；
2. **Git 提交权集中**：子 Agent 一律不执行 `git commit`、`git reset` 或 `git checkout`，改动全部保留在工作区；由主控 Agent 在波次结束后统一收口；
3. **前期轻量测试**：子 Agent 仅执行针对自身代码的轻量语法/类型校验或对应门禁验证，不执行全量繁重测试套件。
