# 三、核心组件架构纯粹性专项深度审计

### 3.1 专项 A：`LayerStackService` 原生轻量性与 O(1) 复杂度审计

#### 1. 架构骨架审查（`apps/crish-desktop/src/services/LayerStackService.ts`）

- **数据结构选型**：
  ```typescript
  private layers: LayerRegistration[] = [];
  ```
  使用原生 TypeScript 数组表达 LIFO（后进先出）栈。
- **操作复杂度分析**：
  | 方法名               | 算法实现                                   | 时间复杂度                   | 空间复杂度 | 评级        |
  | :------------------- | :----------------------------------------- | :--------------------------- | :--------- | :---------- |
  | `register(layer)`    | `filter(l => l.id !== id)` + `push(layer)` | $O(N)$（$N \le 5$ 极小常数） | $O(1)$     | 🟢 极致轻量 |
  | `unregister(id)`     | `filter(l => l.id !== id)`                 | $O(N)$（$N \le 5$ 极小常数） | $O(1)$     | 🟢 极致轻量 |
  | `getTopLayer()`      | `this.layers[this.layers.length - 1]`      | $O(1)$                       | $O(1)$     | 🟢 绝对最优 |
  | `dismissTop(reason)` | `getTopLayer()` + `dismissLayer()`         | $O(1)$                       | $O(1)$     | 🟢 绝对最优 |
  | `getDescendants(id)` | 递归查找直接与间接子节点                   | $O(N)$（深度通常 $\le 3$）   | $O(N)$     | 🟢 简单清晰 |

#### 2. 事件监听器占用审查

### 3.2 专项 B：`calculateMenuPosition` 纯函数无副作用与确定性数学推导审计

#### 1. 架构纯粹性审查（`apps/crish-desktop/src/components/ui/Menu/position.ts`）

- **函数签名与入参契约**：
  ```typescript
  export function calculateMenuPosition(
    options: CalculateMenuPositionOptions
  ): CalculatedMenuPosition;
  ```
- **纯函数不变量断言**：
  1. **零外部状态修改**：入参 `options.anchor` 为不可变只读对象，函数内部绝不修改 `anchor.x` 或 `anchor.y`；
  2. **零 DOM 侵入**：函数内部不执行任何 `document.querySelector`、`element.style` 改写或 `window` 状态变更；
  3. **确定性（Determinism）**：对于给定的 `(anchor, menu, viewport)` 三元组，计算输出的 `(x, y, transformOrigin, isFlippedX, isFlippedY)` 恒定唯一，100% 具备数学确定性。

#### 2. Double Flip 根因根除验证

- **历史两段式污染根因**：
  - 阶段 1：`useSidebarContextMenu` 调用 `clampPosition(1130, y, 160)`，将点击点 1130 提前篡改为 970 并存入 React State；
  - 阶段 2：`SessionContextMenu` 获取真实宽度 180，以 970 为输入再次调用 `clampPosition(970, y, 180)`，由于 $970 + 180 = 1150 \le 1272$，算法判定“未贴边”，保持 970 不翻转，导致菜单与鼠标间产生 160px 空白断层！
- **重构后纯函数单源闭环**：
  - React State 仅记录用户原始点击不可变真源：`setContextMenu({ x: e.clientX, y: e.clientY })`；
  - 真实 DOM 挂载后，调用 `measureAndCalculateMenuPosition(el, { x: 1130, y })`，直接以不可变真源 1130 与真实宽度 180 进行单步计算：
    $$1130 + 180 = 1310 > 1272 \implies x = 1130 - 180 = 950\text{px}, \quad \text{transformOrigin} = \text{'top right'}$$
  - **审计判定**：单步直达真值，彻底根除了中间态篡改与二次翻转（Double Flip）。

  ```typescript
  export function shouldBypassInert(
    node: Element,
    activeTrapElement: Element

    if (node === activeTrapElement) return true;
    if (node.hasAttribute('data-focus-trap')) return true;
    if (node.hasAttribute('data-radix-popper-content-wrapper')) return true;

    if (node.classList.contains('toastStack')) return true;

  }
  ```
