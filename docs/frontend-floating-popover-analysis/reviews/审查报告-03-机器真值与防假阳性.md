# 二、5 大专项 36 组测试用例机器真值逐项对抗审查

审查官对《05详案》第 5 章中的 5 大专项共计 **36 组** 测试用例骨架进行了逐行、逐断言的对抗性核验。核验标准：

- ❌ **绝对禁止**：`waitForTimeout`、`setTimeout` 盲等；
- ❌ **绝对禁止**：仅断言元素存在（`toBeInTheDocument`）而不断言物理坐标或状态变化的空壳断言；
- ❌ **绝对禁止**：断言条件恒成立的逻辑废话断言（如 `x >= 0`、`typeof x === 'object'`）；
- ✅ **必须具备**：基于真实物理坐标（$X, Y, W, H$）、视口安全边距（$\ge 8\text{px} \sim 12\text{px}$）、DOM 树层级脱离（`closest === null`）、真实输入法合成态（`isComposing: true`、`keyCode: 229`）与全局层叠栈出栈单一性的机器真值断言。

```typescript
// 加固后的 Range 测量逻辑（增加文本行号与段落推断）
Range.prototype.getBoundingClientRect = function (): DOMRect {
  const ancestor = this.commonAncestorContainer;
  const parentEl =
    ancestor instanceof Element ? ancestor : ancestor.parentElement;

  if (parentEl) {
    // 1. 检查节点或祖先是否有显式 data-mock-rect 属性注入
    const attr = parentEl.getAttribute('data-mock-rect');
    if (attr) {
      const parts = attr.split(',').map(Number);
      if (parts.length === 4 && parts.every((n) => Number.isFinite(n))) {
        return new DOMRect(parts[0], parts[1], parts[2], parts[3]);
      }
    }

    // 2. 检查弱引用注册表
    if (engine.elementRectMap.has(parentEl)) {
      const baseRect = engine.elementRectMap.get(parentEl)!;
      const startOffset = this.startOffset || 0;

      // 检测是否为 CJK 中文字符串（CJK 字符占用约 14px，英文字符占用约 8.5px）
      const textContent = ancestor.textContent || '';
      const textBeforeCaret = textContent.slice(0, startOffset);
      const cjkMatches = textBeforeCaret.match(/[\u4e00-\u9fa5]/g) || [];
      const cjkCount = cjkMatches.length;
      const latinCount = Math.max(0, startOffset - cjkCount);
      const computedCharOffset =
        latinCount * engine.defaultCharWidth + cjkCount * 14;

      return new DOMRect(
        baseRect.left + computedCharOffset,
        baseRect.top,
        engine.defaultCharWidth,
        engine.defaultLineHeight
      );
    }
  }

  // 3. 保底默认 LineBox
  const startOffset = this.startOffset || 0;
  const defaultX = 24 + startOffset * engine.defaultCharWidth;
  const defaultY = engine.currentViewport.height - 80;
  return new DOMRect(
    defaultX,
    defaultY,
    engine.defaultCharWidth,
    engine.defaultLineHeight
  );
};
```

## 5.2 CJK 中文多字节字符宽度支持

如上代码所示，加固后的仿真引擎支持区分 CJK 汉字（14px 宽）与 ASCII 拉丁字符（8.5px 宽），使得 `GEO-IME-05` 中文输入法上屏后的光标几何偏移计算更加真实可信。

## 5.3 异常属性输入（`data-mock-rect` 非法值）防御性容错

在解析 `data-mock-rect` 字符串时，增加了 `parts.every(Number.isFinite)` 校验，防止单测手误写入空字符串或非法格式导致 `NaN` 扩散崩溃。
