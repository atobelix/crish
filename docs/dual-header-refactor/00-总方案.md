## 1. 战役背景与现状拓扑断层剖析

在多 Unit 分屏和日常桌面交互中，两处 Header 存在严重的结构性倒置与交互缺失：

### 1.1 现状缺陷拓扑定位

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 【当前对话顶栏 UnitChromeActions 现状】                                                                │
│ [leading?]  项目名 / 会话长标题 / (2个运行中) ─── [总览] [文件] [差异] [终端] [笔记] | [⋯] [🔗] [◨]      │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘
   ▲                ▲               ▲                      ▲                    ▲   ▲   ▲
 (死文本)         (死文本)      (静态文本无面板)         (产品工具组)        (更多)(分享)(右坞)
 🔴 缺陷：
 1. 项目名与会话标题均为静态 <span>，点击无响应，无法快速新建对话或就地重命名；
 2. 子代理仅为静态文字，无法点击展开管理面板（与后端 session.agents 断开）；
 3. ChatHeaderMore（更多操作）被错误排在右侧工具栏末尾，信息架构混乱；
 4. 右侧混杂了独立的分享按钮（chat-share）和右坞折叠，视觉密度过高。

┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 【当前工具面板顶栏 LeafToolTabStrip 现状】                                                             │
│ [总览] [文件] [差异] [终端] [笔记] | [ 文件 Tab  × ] [ 差异 Tab  × ] [ + ]                           [◨] │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘
   ▲                                    ▲                             ▲                         ▲
 (冗余的固定工具条 dockToolNav)        (关闭叉号过大/无图标)        (混在滚动条内，溢出即被截断)   (展开/折叠)
 🔴 缺陷：
 1. 左侧硬编码了 5 个固定工具按钮（dockToolNav），与对话顶栏重复，违背“纯标签栏”规范；
 2. 标签缺少专属工具图标（Icon）；
 3. 关闭叉号（tabClose）尺寸过大、Padding 过厚，甚至超越标签本体，且带突兀的 90° 旋转变形；
 4. 加号按钮（+）混在水平滚动流中，打开 4~6 个以上 Tab 时被滚走裁切，用户无法添加新面板！
```

```tsx
import React, { useState, useRef, useEffect, useCallback } from 'react';
import { Pencil } from 'lucide-react';
import { Tooltip } from '../ui';
import styles from './SessionInlineRename.module.css';

export interface SessionInlineRenameProps {
  title: string;
  onRename: (newTitle: string) => void;
  disabled?: boolean;
}

export const SessionInlineRename: React.FC<SessionInlineRenameProps> = ({
  title,
  onRename,
  disabled = false,
}) => {
  const [isEditing, setIsEditing] = useState(false);
  const [editValue, setEditValue] = useState(title);
  const inputRef = useRef<HTMLInputElement>(null);

  useEffect(() => {
    setEditValue(title);
  }, [title]);

  useEffect(() => {
    if (isEditing && inputRef.current) {
      inputRef.current.focus();
      inputRef.current.select();
    }
  }, [isEditing]);

  const handleCommit = useCallback(() => {
    const trimmed = editValue.trim();
    if (trimmed && trimmed !== title) {
      onRename(trimmed);
    } else {
      setEditValue(title);
    }
    setIsEditing(false);
  }, [editValue, title, onRename]);

  const handleKeyDown = (e: React.KeyboardEvent<HTMLInputElement>) => {
    if (e.key === 'Enter') {
      e.preventDefault();
      handleCommit();
    } else if (e.key === 'Escape') {
      setEditValue(title);
      setIsEditing(false);
    }
  };

  if (isEditing) {
    return (
      <div className={styles.renameContainer}>
        <input
          ref={inputRef}
          type="text"
          className={styles.renameInput}
          value={editValue}
          onChange={(e) => setEditValue(e.target.value)}
          onBlur={handleCommit}
          onKeyDown={handleKeyDown}
          maxLength={64}
          aria-label="修改会话名称"
        />
      </div>
    );
  }

  return (
    <Tooltip content={disabled ? undefined : '点击修改会话名称'}>
      <button
        type="button"
        className={`${styles.titleBtn} ${disabled ? styles.disabled : ''}`}
        onClick={() => !disabled && setIsEditing(true)}
        disabled={disabled}
        aria-label={`会话名称：${title}`}
      >
        <span className={styles.titleText}>{title}</span>
        {!disabled && <Pencil size={11} className={styles.editIcon} aria-hidden />}
      </button>
    </Tooltip>
  );
};
```

### 3.3 `apps/crish-desktop/src/components/chat-card/SubagentHeaderPanel.tsx`
```tsx
import React, { useMemo } from 'react';
import { Bot, XOctagon } from 'lucide-react';
import type { SessionAgent } from '../../store/types';
import { countRunningSubagents } from './unitChromeLabel';
import { Menu, IconButton, Tooltip } from '../ui';
import { openAgentInSidePanel } from '../../api/openAgentPanel';
import { killSubagent } from '../../api/subagentRecoveryApi';
import styles from './SubagentHeaderPanel.module.css';

export interface SubagentHeaderPanelProps {
  agents: SessionAgent[];
  parentSessionId: string;
}

export const SubagentHeaderPanel: React.FC<SubagentHeaderPanelProps> = ({
  agents,
  parentSessionId,
}) => {
  const runningCount = useMemo(() => countRunningSubagents(agents), [agents]);

  const trigger = (
    <button
      type="button"
      className={`${styles.agentTrigger} ${runningCount > 0 ? styles.isRunning : ''}`}
      aria-label="展开子代理状态面板"
    >
      {runningCount > 0 ? (
        <>
          <span className={styles.liveDot} aria-hidden="true" />
          <span className={styles.triggerText}>{runningCount} 个运行中</span>
        </>
      ) : (
        <>
          <Bot size={13} className={styles.botIcon} aria-hidden="true" />
          <span className={styles.triggerText}>{agents.length} 个子代理</span>
        </>
      )}
    </button>
  );

  return (
    <Menu
      trigger={trigger}
      position={{ align: 'start', side: 'bottom', sideOffset: 6 }}
      panel={{ contentClassName: styles.subagentMenuPanel }}
      options={agents.map((agent) => ({
        id: agent.id,
        label: agent.name || agent.role || agent.id,
      }))}
      renderItem={(opt) => {
        const agent = agents.find((a) => a.id === opt.id);
        if (!agent) return null;
        const isRunning = agent.status === 'running';

        return (
          <div key={agent.id} className={styles.agentItemRow}>
            <div
              className={styles.agentInfo}
              onClick={() =>
                openAgentInSidePanel({
                  mode: 'focus',
                  agentId: agent.id,
                  parentSessionId,
                })
              }
              role="button"
              tabIndex={0}
            >
              <div className={styles.agentHeaderLine}>
                <span className={styles.agentName}>
                  {agent.name || agent.role || '子代理'}
                </span>
                <span
                  className={`${styles.statusBadge} ${styles[agent.status || 'idle']}`}
                >
                  {isRunning
                    ? '运行中'
                    : agent.status === 'completed'
                      ? '已完成'
                      : '空闲'}
                </span>
              </div>
              {agent.task && (
                <div className={styles.agentTask}>{agent.task}</div>
              )}
            </div>
            {isRunning && (
              <Tooltip content="终止子代理">
                <IconButton
                  size="xs"
                  variant="ghost"
                  className={styles.killBtn}
                  onClick={(e) => {
                    e.stopPropagation();
                    killSubagent(agent.id);
                  }}
                  aria-label="终止子代理"
                  icon={<XOctagon size={12} />}
                />
              </Tooltip>
            )}
          </div>
        );
      }}
    />
  );
};
```

    const handleExport = useCallback(() => {
      if (onExportMarkdown) {
        onExportMarkdown();
        return;
      }
      const byId = getCompositionRoot().session.getState().sessionsById;
      const session = byId[sid];
      if (!session) return;
      const result = tryDownloadSessionMarkdown(session, new Date(), {
        sessionsById: byId,
      });
      if (result.ok === false) {
        toast.show(result.error || '导出失败');
      }
    }, [onExportMarkdown, sid]);

    const handleClear = useCallback(() => {
      if (onClearHistory) {
        onClearHistory();
        return;
      }
      if (!realSession) return;
      clearSessionMessages(sid);
    }, [onClearHistory, realSession, sid]);

    const handleMoveToFolder = useCallback(
      (folderId: string) => {
        if (!realSession) return;
        getCompositionRoot()
          .session.getState()
          .moveSessionRealtime(sid, null, folderId, isPinned);
      },
      [realSession, sid, isPinned]
    );

    const handleShare = useCallback(() => {
      const byId = getCompositionRoot().session.getState().sessionsById;
      const session = sid ? byId[sid] : undefined;
      if (!session) {
        toast.show('没有可分享的会话');
        return;
      }
      void (async () => {
        try {
          const md = exportSessionToMarkdown(session, { sessionsById: byId });
          const clip = navigator.clipboard?.writeText;
          if (typeof clip === 'function') {
            await clip.call(navigator.clipboard, md);
            toast.show('已复制 Markdown');
          } else {
            const result = tryDownloadSessionMarkdown(session, new Date(), {
              sessionsById: byId,
            });
            if (result.ok === false) {
              toast.show(result.error || '分享失败');
              return;
            }
          }
          setShareFlash(true);
          if (flashTimerRef.current != null) {
            window.clearTimeout(flashTimerRef.current);
          }
          flashTimerRef.current = window.setTimeout(() => {
            setShareFlash(false);
            flashTimerRef.current = null;
          }, SHARE_FLASH_MS);
        } catch {
          toast.show('分享失败');
        }
      })();
    }, [sid]);

    const handleOpenTool = useCallback(
      (panelId: string) => {
        openToolInSession((activeSessionId || '').trim(), panelId);
      },
      [activeSessionId]
