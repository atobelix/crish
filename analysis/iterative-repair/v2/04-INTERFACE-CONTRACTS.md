# 04 - 接口契约速查表

> **本文件**是 v2 方案 12 份 ROUND 文档的接口契约速查表，作为 `implementation_plan.md` 附录 B 的补充。
>
> **目的**：汇总所有 Round 产出的关键接口/类型签名，方便后续实现时快速查询，避免在各 ROUND 文档中反复检索。
>
> **使用约定**：
>
> - 接口签名从各 ROUND 文档中**真实提取**，不臆造。
> - 若文档中有 TypeScript / Rust 代码块，直接复制签名。
> - 若文档仅有文字描述而无代码，标注"见 ROUND-XX §Y"。
> - 每个 Round 的接口按"导出形态"分组（class / interface / type / function / const）。
> - 跨 Round 演进的接口（如 `RecursionGuard`）在对应 Round 行注明演进状态。
