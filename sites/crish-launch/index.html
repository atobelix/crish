在你的机器上跑起来。

直接下载安装包，不必从源码编译。从源码跑需要 Node.js 20 或更新，以及 Rust stable。

下载安装包 阅读 README 
git clone https://github.com/atobelix/crish.git
cd crish
npm install
npm run dev:workbench

各平台的 Tauri 依赖写在仓库 README 里。页面上的窗口、差异和终端都是示意，不是你的会话。

Crish · atobelix 界面为示意，随版本变化。
