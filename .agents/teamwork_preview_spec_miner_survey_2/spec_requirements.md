## 1. System Overview & Scope Boundary

The **Notion-like Markdown Rendering Engine and Editor** in `docs/composer-preview` is a commercial-grade, rich-text hybrid editor built on Tiptap v3 and ProseMirror. It serves as both a high-performance interactive editor and a bi-directional Markdown rendering engine.

### Core Architectural Pillars
1. **Bi-directional Lossless Serialization**: Continuous round-trip conversion between ProseMirror Rich-Text AST and Standard GFM Markdown strings via `tiptap-markdown`.
2. **Notion-Style Block UX**: Drag-and-drop block reordering, contextual bubble formatting menus, `/` slash menu popover, and continuous curvature typography.
3. **Advanced Grid & Structured Media**: Rich table manipulation (column drag/drop, sorting, cell merging, formula properties) and media block handling.
4. **AI & Sci-Tech Extension**: Offline-capable synthetic mock AI writing pipeline and scientific document extensions (BibTex, KaTeX, Mermaid, Dataset, Experiment records).
5. **Multi-Format I/O & History**: Version snapshot/diff/rollback engine and multi-format document conversion (Import/Export for MD, HTML, Word, PDF, Notion, LaTeX).
