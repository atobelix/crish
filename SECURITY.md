# Security Policy

## Supported Versions

We actively support and patch security issues in the latest release of Crish.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | yes       |
| < 0.1.0 | no        |

## Reporting a Vulnerability

We take the security of Crish seriously. If you find a security vulnerability, please do not report it publicly via GitHub issues.

Please report vulnerabilities privately through one of the following channels:

Report it through [GitHub private vulnerability reporting](https://github.com/atobelix/crish/security/advisories/new). There is no separate security mailbox.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:

- A description of the vulnerability and its potential impact.
- Affected components (e.g. `conex-sandbox`, IPC commands, Provider credentials, Tauri shell).
- Detailed steps to reproduce the vulnerability (including proof-of-concept code, minimal test cases, or steps).
- Any potential mitigations or suggested fixes.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to resolve the issue as quickly as possible.
