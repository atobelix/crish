# Security Policy

## Supported Versions

We actively support and patch security issues in the latest release of Crish.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of Crish seriously. If you find a security vulnerability, please do not report it publicly via GitHub issues. Instead, please report it directly to our security team.

Please email your report to **security@conex-community.org**.

Your email should include:
- A description of the vulnerability and its potential impact.
- Detailed steps to reproduce the vulnerability (including proof-of-concept code or steps, if applicable).
- Any potential mitigation steps or fixes.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to resolve the issue as quickly as possible.
